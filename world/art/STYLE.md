# 河谷日常插画

标志、背景和职业纹章由 tools/build-m6-art.mjs 的原创几何绘制程序生成，没有调用图像服务或真实模型。统一使用松绿、旧木褐、麦金轮廓；场景为 1600×900 SVG，纹章为 128×128 SVG。logo.png 使用同源的山峰、日轮与河流几何，供酒馆的 PNG 角色卡容器使用。

背景覆盖十类场景，每类有白昼与夜间、晴与阴雾及雨与雪，共 80 张。各类有独立的建筑、地貌或工作器具；夜间改变天空、月轮、室内灯光与整体亮度；雨画雨线和云，雪画雪片和地表积雪，阴雾画云和低雾。室内降水限制在窗外，家具不会下雨或积雪。晴映射晴；阴和雾共用阴雾组；雨和暴雨共用雨组；雪映射雪。背景不细分降水强度，风险与数值以原有天气引擎和顶栏为准。

mapping.json 和 assets/visual/manifest.json 登记全部已发布地点及 446 名 LOD0 人物的职业纹章，包括 152 名完整人物及 294 名名簿人物。portrait-prompts.json 为每名人物保留已发布姓名、年龄、职业与可复用日常纹章提示，未采用私密记忆或关系信息；未成年统一用书本纹章，没有恋爱、亲密或性感元素。职业纹章可多人复用；它不表示人物长相或额外能力。

酒馆本机 public/scripts/backgrounds.js 的 setBackground 未导出，设置会写全局 background_settings；锁定聊天使用 custom_background 元数据。扩展在 #bg1 内放置自己的双层 SVG 视图，隔离页无 #bg1 时放在 body，900ms 交叉淡入；减少动画直接切换。离开新版游戏聊天时移除视图，不写入酒馆全局背景设置或锁定背景元数据。消息名牌只对原知情投影已识别的人物显示纹章，玩家自起的未知人物称呼仍保留问号或首字。

部署工具现有的 assets 递归复制会包含全部素材，浏览器 URL 使用扩展内 assets/visual/ 路径。构建脚本只写 assets/visual/ 和 world/art/，不写 dist/。生成文件许可见 assets/LICENSES.md。
