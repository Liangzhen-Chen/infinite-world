# U15 余下动词

钓鱼使用 `world_field {operation:"wildlife_fish",species:"monster_black_fin_perch"}`。本人须在 K8 水域栖地，有完好的厨房刀和一份水；每次花 30 分钟、磨刀一点，按季节、鱼种活动时段与渔夫技能检定。一尾鱼从本地生态账的 count 转入 withdrawn，产出一份剖净鲜鱼，失败不产鱼；用现有交易出售，或 `wildlife_eat` 花一份水、一袋自有木炭和 20 分钟煮食，最多恢复两点生命。渔夫技能按现有每日练习上限与重复衰减增长。

开矿使用 `world_field {operation:"site_mine",item:"item_iron_ore",authorization:"许可回执"}`。矿产优先读地点 minerals，其次读 rules.extraction.mining.locations，最后按 traits 地形标签用默认表；普通矿镐须完好且达到现有装备等级。每次耗时 60 分钟、耐久两点，成功取一公斤含铁矿石；储量与 extracted、recovered 对账，碎矿按规则周期恢复，recoveryDays 为零则永久耗尽。矿主在场同意时，可用 `world_settlement {operation:"mining_permit",authority:"矿主",consent:true,minutes:1440}` 签发限时许可；已登记法域中的盗采使用 illegal_mining 罪名进入现有判罚流程。

约斗使用 `world_settlement {operation:"duel_challenge",member:"对手",authority:"独立见证人",choice:"touch"}`，choice 另可为 death。speaker 默认玩家，也可指定在场 NPC 向 member=player 下战书；NPC 按性格、立场与灵智决定是否愿意约斗，玩家用 duel_answer、proposal=战书回执、consent=true/false 答复。对方接受后，现有 world_combat 对该 NPC 的交锋自动套用战书，见证人须在场，战书有效一日；touch 以首次命中结算且保留双方生命，death 依原伤害公式结算。duel_yield 用 proposal 指定战书认输，结果写入名望与见证人立场；rules.law.duels 按法典独立规定合法性，现有五村均允许 touch、禁止 death，禁止的致死决斗仍登记杀人案。

走私先用 `world_trade {operation:"smuggle",seller:"目的地买方",item:"货物",quantity:1,location:"目的地",mode:"boat",coins:0}` 登记本批实货。货物留在行囊，不能重复托运同一数量；随后正常 world_move，在实际途经收费路线的检查点按守卫在岗情况、廉洁度与隐藏检定查验，coins 是每站愿出的贿金。收钱被目击时复用 U5 的撤职与通缉流程；查获的实物转入守卫保管并登记 smuggling 案件，罚款、到案与通缉沿现有法律程序处理，客运路费照常支付。到目的地用 deliver_smuggled、contract=货单回执当面交货，差价来自有限买方货款。可先按 U1 加入章程包含“走私”或“私运”的组织，再以 business=组织 ID 装货；本卡未凭空给既有人物增加走私身份。

竞选在组织议事地点用 `world_settlement {operation:"election_start",org:"组织"}` 发起，组织须实行成员投票且玩家已入会。村长竞选用 settlement=四村之一、name=office_village_head，在村议事屋登记，本人须是登记公民；三日后按成年住户立场投票，胜出后仍须到有登记员在岗的镇公署用 election_finish 开票递件，现有贡献、头人举荐和上级任命要求继续有效。竞选操作的 proposal 均填竞选回执；election_campaign 的 choice 为 gift、speech、promise 或 buy_votes，speaker 指向选民，item 指向礼物，content 填演说或承诺，失败也耗时；同一天不能向同一选民重复同种拉票。公开行动写入选民记忆与舆论投影；贿选的 coins 转给选民，authority 指向被“赠礼与选票无关”说法误导的第三人，以 U8 保存谎言。election_expose 用 sourceEvent=贿选行动、speaker=收款选民，在第三人在场时揭发，接入 vote_buying 案件并取消参选资格。组织 election_finish 经 U1 的多数决与任命执行器改任会长。

新增规则与矿石未调用真实模型审校。法典目前只覆盖既有五村；无可执行法典的野外或怪物矿区会记录非法开采与矿产损失，但不会伪造执法机构。系统地图已重新生成，静态提示在本分支基线 10916 上增加 59 token，工具仍为 25 个；推进快照未重生成。
