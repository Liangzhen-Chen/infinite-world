## 2. 主观知识规则
- docs/架构设计/02-不变量.md:22 I12 知情可溯：知情集合只能是见证、被转述、阅读文书、作者知情种子、聚合传闻；"不在场的持有与义务的状态不经上述来源不得进入主观视图"。
- subjective-view.mjs:104-105 observable 只有在场人员、天气、`marketReports` 报价、服务；:80-98 除同户成员外不含任何他人背包。subjective-view.mjs:92-93 注释明确只对同户互知开例外（李白 11-11 决定）。
- shop.mjs:385 同函数对 `settlement` 来源明确 `if(view||...)continue`（主观不读聚落公共库存）；shop.mjs:404 注释："主观视图只认收到的报价，与店铺一致，不读他人私有存量"。:393 主观用 subjectiveMarketQuote。可见 :383 与本文件自己的规则不一致，漏了一个 view 守卫。
- K2 设计原文（docs/审查/2026-11-04-内容与规律脱节-发现.md:40）只说"持货人补货/出售决策推广成通用分销规律"，是执行侧（真实成交读真实持货人，合理）。全 docs 搜不到"店主预测补货时可知他户余粮"的规定，也没有市集观察、交易记录或传闻渠道的设计。代码里也没有这类渠道：店主无关于他户余量的记忆/事实条目。
- 可能的渠道评估：市集观察（view 里没有他户持货数据，observable 只有在场人员与报价）；交易记录（own 店铺有 ledger `state.records['shop:id']`，只记自己与对方的成交，不含他户当前余量）；传闻（无）。所以没有渠道。

## 3. 判定依据
真实成交（buyFromHolders，shop.mjs:646 / distribution.mjs:66）读客观持货人是正确的，那是执行，不是预测。错的是预测路径（view 存在时）把客观余量当作店主的预期，使别户存粮变化直接改变店主自己的主观 nextFoodAt/physicalFloor，因而改变他的购买与进食决策。这正是 I12 禁止的。#15 测试注释（:281）把它写成"既有进货渠道，不是户内信息"，并把隐藏存货从面包改成铁钉来躲开它，等于为测试绕开而没有修规则（按"为测试造设施、放宽断言"的标准应打回）。

## 4. 修法方向（规则层、整类）
- 主观预测一律只读 view 与 own 记录。在 shop.mjs:383 加 view 分支：view 存在时不调 localSpare；数量取店主自己已知的信息——自己店铺 ledger 里上一次该物品的实际 added（:373 已取 last），无记录则按"没有可指望的口粮来源"（continue）或按已知先验（货架定量，需李白/主会话定口径；建议保守取 last.added，无记录则不计入，与 :390 route 来源"无已知账单就不预测"同口径）。非 view（内核/客观）路径保持 localSpare 不变，真实成交不变。
- 整类防护：把"客观读取器不得在 view 路径调用"变成规则。具体：给 localSpare 加显式参数或命名（如 localSpareObjective），在 view 存在时抛错或由测试扫描 `shop.mjs` 中所有 view 分支（:347、:385、:393、:405 现有守卫）确认每个客观读取都有 view 守卫。
- 其他受影响调用点：
  1. shop.mjs:383（唯一确认的预测泄漏点）。
  2. distribution.mjs:119：advanceDealers 里非店铺经营者用 `holdersIn+spare` 判"本聚落有没有人有余量才尝试进货"，决策者是 NPC，用了客观余量作门槛，是同类轻度泄漏（只泄漏"有无"，不泄漏数量）；真实成交之后才应暴露结果。建议改为按本人已知（上次成交记录）决定是否尝试，失败则记录。
  3. shop.mjs:362-363 `physicalOf`/`sellerShare` 与 :405 非 view 分支：已被 `view` 守卫，客观路径，无需改。
  4. distribution.mjs:84 `wakingView(seller)` 作持货人是否同意出让的主观判断，读的是其自己视图，正常。
- 范围估计：代码约 3 处（shop.mjs:383、distribution.mjs:119、新增守卫/测试）；测试：恢复 #15 把隐藏存货改回面包（食物）验证主观预算不变，加一条 view 下 localSpare 不被调用的断言；预计影响店主口粮预测的既有用例（shop-restock、s5 食物链、K2 分销相关）数字可能变化，需云上跑受影响测试。无需改数据或存档（按"不做旧存档兼容"）。
