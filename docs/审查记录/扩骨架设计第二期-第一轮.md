A3. 出处字段 source{citation,quote} 不足以让 L4 逐条核"出处确实支持这一步"

 (1) 文档第 3 条"步骤不能照抄原句，要补原句没写的具体，且每步有出处"，与"原句写到的工序都要有对应步骤"同时成立时，锚定步骤的出处就是 processFacts 本身（照抄原句作 quote），而"补原句没写的具体"的出处只能是外部工艺资料；两类出处的核对办法完全不同，设计没分。
 (2) 外部资料只能证明"这类工艺通常这样"，证明不了"这个世界这条配方这样"。例如 s_hook 的"磨钝尖头到不扎手"若引一篇铁钩工艺页面，页面支持工艺常识，不支持本配方。
建议 source 加 kind 与校验：
 - kind=processFacts：quote 必须是该配方 processFacts 的子串（L1 确定性核对），citation 固定写 recipe 的 id；该步骤只允许复述原句已有的动词与对象，不得带原句没有的 detail；
 - kind=reference：citation（页面或条目）与 quote（原句）必填，L4 核"引文真实且支持该 detail 本身"；该步骤只能是某个锚定步骤的 detail，且 detail 类型限定（动作对象、成形结果、检验点、必要前置），不得新增动词（同 A2）；

 - L4 抽查清单固定三问：quote 是否真实存在、是否支持该 detail、detail 是否被写成了这条配方的断言而不只是常识。
 这样 L4 面对的是三种不同的核对，而不是一个模糊的"出处核对"。

# 第四轮复审（针对 2a743a22 "第二期修订五"；只列方向性与会放过编造的问题，实现细节记非阻断）

## 还有没有会放过编造的路径（设计层面逐一过）
 1. 抽取器在工序部分内误取（如"挖出绕线凹槽"取出"绕"）+ 有人写"绕"步骤，quote 取该原句：L1 能通过（quote 在工序部分、抽取器能抽回绕）。这一条 L1 无法封，只能 L4。李白条件 ① 已规定 L4 逐条核对"出处支持该步"，覆盖了这条；只要 L4 对 kind=processFacts 的步骤也是全读（核对"quote 里这个词真是这一步的动作"），就闭合。应在设计里写明：processFacts 型步骤的 (verb, quote) 对 L4 全读（单条很短，约几百对），不是抽样。
 2. 派生前置：触发条件已改为"原文动词+材料类别"，等价词去重，冷标记限修饰动词；推演结论上轮已确认（s_hook 派生，冷加工与陶作 0 步）。
 3. details：文本过同一抽取器，动词不得越出集合；名词形状类内容靠 L4 全读。闭合。
 4. 允许集合的构成：原文抽取 ∪ 派生前置 ∪ 检验动词；不含工具功能表的动词。oat_crisp 的"切"被拒。闭合。
 结论：L1 封死动词层的新增，剩下的"这个动词在这句里是不是真动作"交 L4 全读，分工清楚。

## 非阻断（开卡前写进设计）
N1. "误取"裁决要落成机制：裁决为误取的 (配方, 动词) 应写入排除表，允许集合 = 抽取集合 − 排除表；或把对应词形加入词表的排除词形并重跑对账。现在第 1 条只说"判为误取，写明理由"，没说它如何从允许集合里去掉，容易只留记录不生效。
N2. 步骤的 source.kind 只允许 processFacts 与 derived，citation 只用于 details（修订三第 2 条的意思，修订六没有再强调）。写成确定性规则，免得有人给步骤写 citation 型出处绕开"quote 落在工序部分"的校验。
N3. 冷标记夹具的第二条：我扫 185 条，真实原文里没有"冷锻""冷态锻"这类冷标记直接修饰锻的句子（有的是"冷锉""冷却后""冷态试滑"，都修饰别的动词）。第 4 条"从 185 条里挑，不另编"在反面夹具上做不到，应明确：正面夹具用真实原文（如 hinge_pin、door_latch：含锻、冷标记修饰别的动词，仍派生加热），反面夹具允许合成句，并在测试里标注为合成。
N4. L4 工作量：processFacts 型步骤全读、citation 型细节全读、裁决记录全读，三项合计量不大但应在数据卡的额度里列明；derived 型由 L1 核对，L4 抽样。

## 小结
设计层面可以进入数据卡（词表等数据，食物外观、金属细分）和代码卡（抽取器、L1 对账、字段登记）。抽取器的具体词形和边角由对账暴露修正，实现走两轮审。

## 非阻断
N1. 快照完整性：修订七写"旧版本不改不删"，但没有机制强制。建议每个版本快照的内容哈希写入入库记录（同第 3 条表哈希做法），L1 先核哈希；并在发布时校验"最新版快照 = 用当前规则和数据重新派生的结果"，防止快照被手工改而与规则脱节。快照由脚本生成，不手写；recipeSteps 的来源仍是 recipe-steps 数据文件，快照只是它的固化副本，写明单一来源。
N2. "复合物品体积写未知"（补充第 2 条）要给规则化的判据：复合 = 配方里非燃料、非耗材（不含木炭、水、配额水）的材料横跨两个以上材料类别（如钢料+木柄）。锻造台几乎每条配方都带木炭小袋，若不排除燃料会把所有金属件判成复合；"重量份额"也要写成 amount × 每份重量。
N3. 0 失效验收只放进腾讯云测试（补充第 3 条）偏晚：它是只读复算，建议同时做成本机只读入口（与三个 --check 同类），改词表、材料表、抽取器时先本机跑，云上再复核。另外复算范围写明含 household 基础批的 51 件改写记录，它们在第二期之前没有 skeletonFields，应按 v0 复算且全部通过。
N4. 存量重扫用最新版本、指纹核对用记录版本（修订八第 4 条）合理；需补一句：存量重扫命中的记录走"人工改写后标新版本"，不得直接改记录里的版本号去通过扫描，否则版本号成为绕过手段。
