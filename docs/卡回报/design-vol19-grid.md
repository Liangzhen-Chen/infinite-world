## 做了什么

- 旧版留底：`版本快照/卷十九-v15.md` 与改前正文 cmp 逐字节相同，只给文首加【作废】与现行指向；正文卷首写"本卷全文即现行规则"。
- 形制到蓝图（§4.5 规则 7–11）：形制以 `walled`、`aspect`、`storeyBase`、`roofed`、`deck`、`windowEvery` 取代周长系数与屋面、开口比例，`rooms` 加 `level`、`open`；`planBlueprint` 定外包、层号、外墙、隔墙、门（正门、内门、地下入口）、窗、楼梯、顶面（楼板、屋面、桥面）、房间格，只按四分之一圈旋转；结构元与"重料在下"派料；设计围合值；门窗扇（`leaf`、`leafOpen`）；朝向。建筑行新增存储 `planCells`。
- 围合逐格（§4.1 规则 3）：本卷不再写 `aperture`、`skyExposure`；给卷五蓝图、门窗扇开合与按完好度派生的破口、缺顶（数量取账、位置取序），泡外给 `openingCounts`。
- 拆一格（§4.1 规则 12）：泡内砸墙经 `breakStructure` 记实物账、写破口格标记，开合由缺口体积派生。
- 选址与建造（§4.4）：意图加锚点、朝向；格侧四条（足迹、地势、差分、朝向）；体积读蓝图；翻修不改锚点、房间不挪位置不写面积；装置占格、摆放次序、`installFixture`；使用格（§4.3 规则 8）。
- 可移动建筑（§4.10）：无跨界边；收起装置落点置空、展开重落；展开与随载具移动带锚点朝向（C17-17）；之下不嵌套设施。
- 聚落模板（§4.6）：分片是区域足迹行、相邻读足迹相接（C10-23）。机关落闸改为关门窗扇，轨道修正目标改 `travel.passFactor`。
