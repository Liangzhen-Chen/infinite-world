## 做了什么

- `tools/convert-geo.mjs`（可重跑；`--check` 只比对）：world/geo 旧数据 → place.json 的 rows 与 edges、world/i18n/labels.zh.json 的 499 个显示名。表头未动。
- 499 行 = 世界根 1 + 省 9 + 郡 31 + 旧地点 458；边 462 条（旧路线一条一条，两端字典序小者为 from；仅含 boat 方式的 3 条为水路边，两端相同的陆路水路两条并存 1 对：loc_far_hupo 与 loc_yandu）。
- 旧 id 折新 id：loc_、bld_ 原样（344 个），其余整类加 `loc_` 前缀（site_ 114、prov_ 9、county_ 31）。旧 id 记在每行 `basis` 里可反查。
- 坐标：旧 coordinates、center 是千米，照转成米（×1000，四位小数）。边距 lengthKm 同。面积：biomes.json 的 17 处照转（平方千米折平方米）。
- parent：旧 parent 照转；旧 parent 为空的 12 处挂所属郡；county.places 点名所属郡、却与旧 parent 冲突的 6 处（loc_yandu、loc_capital 的旧 parent 是 loc_hw，四处站点的旧 parent 在别郡的地点之下）改以所属郡为父（卷五 §4.14 规则 A5-14.2：每个非根地点至多属每个层级的一个政区；且 loc_capital 距 loc_hw 440 公里，不可能在村的半径内）。
- 政区：世界根（juris_world）、省（juris_province）、郡（juris_county），都挂 comp_region 与 regionLevel；juris 族四条（卷五 :1060 加王国级与世界根）：郡 1、省 2、王国 3（juris_kingdom，旧数据没有王国行，不挂行）、世界 4，条目带 basis。
- 进入档：旧 access.mode 三种折 access_public（55 行）、access_private（237 行）、access_council（6 行）；没有旧 access 的行不写。
- 水体类：water 族 water_navigable（navigable 真）；只给旧水路边的两端行写。
- 天气单元（必过项③④）：31 个郡行都挂 comp_weather_cell；垄渠郡（旧 places 含 loc_hw 者）带 weather-cell.json 的全部 cell 值（经加载器校验、weatherAt 可算），引用 cpr_taiyuan，elevationM 取其 cellElevationM（779，单元值所在海拔）；其余 30 郡不写任何气候值、不引原型，七个单元必填列登记为未建；当日天气按未知并报缺口 weather_climate_proto（测试核），不借太原。
- 必过项①：真实世界根恰一个（loc_world）。②：access、water 两族条目随灌行补上（juris 一并）。

## 自定裁定

1. 世界根一行：卷五 §4.14.1（:1062）要世界根，旧数据只有 mapHierarchy 的"已知大陆片区"；其 id 取 loc_world，显示名"已知大陆"，只有层级与父空，coord、terrain 登记未建（不编坐标与地形）。
2. 旧 id 折新 id 的前缀规则：卷二 :287 place 表实体前缀只有 loc_、bld_，site_、prov_、county_ 不是；site 族前缀 site_ 也不许当实体前缀（E-DIM-VOCAB-PREFIX 的口径）。
3. terrain：旧文本 → 封闭十项，取文本里列在最前的主地形（卷二 §6.3 :2216 "离线候选，人工核对入库"）；对照表在脚本里按旧文本（不按 id）写；候选，需人工核对——特别是 玄岩台地（hill）、封闭高山岩坳（mountain）、山林坡地（mountain）、河岸岩石（river）这几条是在十项里取近似。
4. waterway 判据：旧路线 modes 只有 boat（卷五 M5-33 "陆路、水路"；modes 含 walk 的"walk+boat"路线按陆路）。
5. 来源冲突的 parent 取所属郡（上节）。
6. 起始地区取垄渠郡（6-29 回报第一节已定）；elevationM 取 cellElevationM 是因为卷二十 §2.7 :355 "单元所在地点海拔处的年均温"。
7. labels：显示名进 world/i18n/labels.zh.json（卷二 :293 "显示名在 labels"），旧 aliases 不进（表头无该形态）。
