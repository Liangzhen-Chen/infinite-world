## 结构要点

- 旧版：版本快照/卷二十-v10.md 与改前正文 cmp 逐字节相同，只加【作废】标题与现行指向；卷首未写"旧版规则照旧有效"。
- 环境两种读法：`envAt(at, minute)` 的 `at` 取地点（地点层）或位置（位置层）；泡外或 `coarse` 的位置等于 `zoneAt(pos)` 的地点层；泡内按格求露天、照度、能见距离、场强、声场与室外气温的海拔。
- 林冠：卷五露天比例不再含林冠，本卷加 `env.openSky = skyExposure × canopyCurve(forestCover)`，天光、雨雪暴露、风寒同读（保第十版行为）。
- 场两层：地点层背景照旧推进，相接改为足迹相接（自有区格四邻、建筑取 `aperture`、房间、体积看出口），不读路网边与门边；泡内细格增量承接泡内排放源，按格扩散、遇不透气格挡、露天格随风；展开不写（增量从零起），收起 `foldBubbleFields` 按面积份额折进背景，收起前后地点层读数逐位相同。
- `propagate(channel, sourcePos, observerPos, sourceLevel)`：衰减律读 `rules.env.channelLaw`；光为直线距离平方反比 × `losView`；声在泡内取格路最小损失（墙按材料隔声 × 墙厚，绕路每米 0.1 dB），"隔墙听见"回来，泡外按直线距离与包含树围护的 `soundLossDb`；气味持续来源读到达处场强、一次性来源按气路程曲线。
- 性能：场增量每步与项数成正比、上限泡内格数 × 场行数、推算村落场景 1–10 ms／步（暂定预算 50 ms）；声洪泛 ≤ 2×10⁴ 格（约 0.1 s，同源多观察者共用一次）；点光源 ≤ 64 个（约 0.1 s）；气路 ≤ 2×10⁴ 格。
- 白名单路段通行改 `travel.passFactor`；`rebaseBubble` 节拍一日登记进 `cadence`；纬度改由形心派生。
