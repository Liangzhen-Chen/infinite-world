## 怎么恢复

1. 本机全局 codex-cli 是 0.125.0，不认这两个模型；今天用的是会话临时目录里的 0.162.1，新会话需要重新 `npm install @openai/codex@0.162.1` 到一个临时目录，再按 logs/sessions/run-codex.sh 和 resume-codex.sh 的写法派工（或者用户自行把全局 CLI 升级）。
2. 执行会话的沙箱会拦截 git 写操作、测试子进程和浏览器：提交、合并、浏览器测试都由主会话在沙箱外做；卡的工作目录要先由主会话同步好主线。
3. 每合并几张同一领域的卡，把那个领域的测试整组跑一次；往正式世界加内容的卡，验收必须含发布构建。
4. 真实模型的卡同一时间只跑一个，而且跑的时候机器上不要同时压很多别的测试，第四轮 M2 的连接失败很可能与此有关。
