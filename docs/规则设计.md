# 阶段 2 规则设计

复活登记已接入独立工具world_revival，费用及最低等级写在rules.death.points，具体开发初值见D015。旧登记点免收费映射到真实祭坛；生命魔力恢复比例0.5，死亡时同行关系解除而NPC原位置保留。濒死计时不因追加伤害重置，只能等救治或尝试自救治疗。初始迁移以runtimeRuleVersion=1标记，增量分区通过事件提交，独立离线脚本保存备份和世界版本。

2026-10-10更新：经验结算及公开属性分配已接入progression.mjs，以下“尚未接入”描述保留为早期记录。奖励须引用真实已完成事件，来源去重；同类任务按发布人与完成目标识别，24小时收益逐次减半。首次发现、制造、研究与公共贡献暂取区间下限，完整升级节奏尚未验证。

新角色创建后端校验总值60与单项8–16，从0级开始，六项属性之外的隐藏幸运仅保存在私有状态。每级2点是可调初值；增加体质、精神或等级只改变生命魔力上限，不免费恢复当前值。200级超额经验不保留。创建界面及幸运实际玩法仍未实现，在线角色保持原状，具体决策见D014。

实际持续效果由时钟与交锋共同读取。石肤防御与闪避、恐惧命中、防护的伤害门类均取确定规则，重复同类取最高而非相加。照明绑定持有物，过期或离开背包后不再影响暗处命中。对别人施加防护需同意。强度上限与已接入类型在构建和运行时共同核对。

魔法结果与持续支持分开：凝水、去湿、修缮、读数为瞬时结果，不随计时回退；气囊与固堤等有具体时限。映射16条草稿仍欠现场媒介、距离与相应物理/社会条件，其他138条尚缺处理器，不能发布完整目录。初值和未解决限制见D013及已知问题。

职业当前65项，技能204项。12战斗职业各15技能、六次双方向升职，23生活职业具备上下游和典型产出，30隐藏职业有触发骨架与代价文本。认证、退职和升职已接入；作品证明、地域/元素变异、隐藏取得及独特能力、完整技能动作仍待实现。数值初值及299有效封顶解释见决策记录D012；数量达标不是可玩性验收。

世界数据是规则的发布源。当前版本engine-rules-3，引擎语义修订2；旧版engine-baseline-2使用已提交阶段1语义修订1。更新目录不会重算历史事件的伤害，世界升级事件之后才应用新规则。

角色生命上限为max(1,8+4×等级+2×体质差值)，魔力为max(0,8+2×等级+2×精神差值)，属性差值取属性减10。这样1级各属性10的开局生命12、魔力10，与原档一致。负重为10+2×力量公斤；攻击为3+1.1×等级+0.7×力量差值，正式战斗职业乘1.15；防御为1+0.45×等级+0.4×体质差值。装备修正在公式中独立相加，后续目录给出每件的数值。

命中基值0.82，敏捷每点差值增加0.005；敏捷每点差值产生0.004闪避，闪避封顶0.45。最终命中夹在0.1–0.98之间。伤害浮动±20%，扣防御后最低1，暴击率5%、伤害1.5倍。交锋10秒，六次交锋才累计一分钟，避免每次挥击都推进十几分钟；普通对话仍由回合尾注计时。

六组初始平衡目标完全沿用3.3。两个“约”设定采用50%±5%、60%±5%的容差，没有按实测修改阈值；怪兽等级在10–15之间均匀抽样，报告同时列出各等级胜率。初版单人怪兽55.33%、五人首领90.94%不合格，原报告另存。调整怪兽攻击等级系数为1.12，首领生命倍率7.5、攻击倍率1.65后，主种子结果为53.26%与58.81%；另外两种种子复核通过。

这只是无高级装备、复杂法术与战术时的基础平衡。角色属性推导和命中伤害函数已经接入实际交锋，模拟器使用相同函数；队伍协助、职业技能和完整首领生态仍要进一步实现并复测，不能据此结束阶段2。

所有硬设定写入rules.json，包括品质与装备门槛、技能书品级、魔法分阶耗魔范围、九阶怪物与神性屏障、宠物上限，以及行政五比一和任务额度。新增角色六项属性总和60，初始单项8–16，升级每级2个自由点。幸运隐藏，不从对话随意改写。具体属性分配与升级工具仍待接入，旧档生命魔力保持原值。

身份与爵位采用并存关系。村长贡献门槛1000，但仍须举荐和上级任命；公民先居住90天、无犯罪并付100铜。发布额度的一等男爵兼城主锚点为120D，任务报酬提前托管；高等级身份的数值作为可调初值，后续经营浸泡会复核。

升级节奏先按每天两小时、约30天到20级作为目标。奖励来自有效怪物战果、任务及首次里程碑，重复行为递减。规则数据列出了奖励区间，但完整获经验、分配属性和反刷机制尚未接入；阶段8按五种玩法检查节奏后再调整奖励，保持3.1经验公式。

完整目录仍按指南下限制作：12战斗职业每种至少15技能，生活职业至少22，隐藏职业至少30，法术150、物品400、配方200、怪物150、首领40。设计骨架由本地代码和本文件确定，批量模型起草只补充世界内细节，不让它选择核心数值。构建必须通过schema与引用等检查，后续加入完整文本质量和经济校验。

学习来源现在支持合格导师、持有的实物技能书，登记技能、法术或配方。学习失败仍花时间和教学费，保存来源、书籍作者/版次、起止时刻；已经掌握的相关技能不被重新置零。书籍需识字100，前置技能、品级与职业认证独立检查。专家以上法术不能由普通导师授予，须稀有典籍或已登记研究成果；后者仍待研究登记工具完成，当前不能冒充支持。

伤害、治疗、金属修缮与衣物去湿已有受限效果处理器，效果数值取目录，模型不能指定伤害。远处或死亡目标拒绝；普通NPC治疗需要同意记录，濒死急救例外；施法期间目标死亡不会复生。物品需实际持有且为单件，材质匹配，修缮消耗真实铁料。四种处理器以夹具验证，其他机制仍须逐项接入才能发布完整目录。

法术合法性描述正常预定用途，伤人、侵占及特殊公共设施授权另行评估，普通点火不自动等于纵火。起草不得改变固定射程、时限与材料。首批精读发现骨架自身欠铁料和气泡供氧参数，已经补入；水绳允许束缚一肢或同等粗细的轻物，载荷上限2公斤，保留合理物理延伸而不暗中获得固定重货能力。气泡为2升、静息最多1分钟，剧烈活动更短。
