## 三、真问题

1. **ns 表返回形状句仍用旧三词，漏了句柄，与类型规则冲突**（局部）。卷二 :1040"返回形状只许数值（带 §1.4 单位）、代号或布尔"、:1049 `ev` 行"载荷的数值与代号字段"。新规则 :1028 把"代号"限定为实体 id，泛称注释只放宽 slot、broader、显示档 ② 三处。照字面，ns 读数不能是句柄，`ev` 载荷里 `ref vocab` 字段（如卷二十四 :163 `kindFrom` 所指的 `ref vocab verb` 字段）也读不了。这和第 1 点"ns 随字段按所读字段取四种之一"、"与 ns 表返回类型列同词"冲突。改法：这两处补"句柄"（`ev` 行一并补"布尔"），或把它们列进泛称注释。按二审余项常规可只改这两处。
2. **`skillFrom` 要求的字段类型 `ref skill nullable` 无法对 `readShapes` 核对**（须报李白）。卷九 :195 要求所指字段"类型为 `ref skill nullable`"，卷二 :625 把 `readShapes.type` 封闭为四值，既不带所指族/类，也不带可空。卷二 :627 规定"类型与引用方要求不符"即报错，可这项比较定义不出来，两卷因此形成矛盾。`predicates`、`shapeFrom` 两处只核字段在不在，不受影响。四种类型是李白 ③ 亲定的"字段类型（①四种词）"，要解开，只能二选一：甲、行格式加所指族与可空（这是改结构）；乙、卷九把 `skillFrom` 的要求降为"句柄"（或"代号"，看 skill 是实体类还是词表族），族与可空改到求值时核。两条都超出只改列出项的范围。
