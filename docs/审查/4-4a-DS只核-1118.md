## 二、逐项核对

### 1. `tools/gen-det-tables.mjs`：BigInt 精确截断，无浮点标度乘

- e 与 e^(1/4096) 用 `expFixed` 的 Taylor 级数（`tools/gen-det-tables.mjs:43`），e^k、e^(m/4096) 用 `powFixed` 固定次序平方乘（:55）；工作标度 10⁶⁰。没有 `Math.exp`，没有「浮点真值 × 标度再取整」。
- 抽点复核（表值到 `world/ontology/dimensions/_distributions.json`）：
  - `expInt` k=1：真值 e×10⁸ = 271828182.8459…，向零截断 **271828182**；表白值为 `values[41] = "271828182"`（kMin=−40，故 k=1 在第 41 项）。
  - `expInt` k=−18：e⁻¹⁸×10⁸ = 1.522997974…，向零截断 **1**；表第 23 项为 `"1"`（前 22 项 0）。k=40：e⁴⁰×10⁸ = 23538526683701998540789991.…，表末项一致。
  - `expFrac` m=1：e^(1/4096)×10⁸ = 100024417.04…，表首段第二项 **100024417**；m=4096 表值为 **271828182**，与 `expInt[1]` 逐位相等（生成器 :185 也断言）。
  - 分位数 j=1：Φ⁻¹(1/4096) ≈ −3.4871，向零截断 **−34871**；j=2 ≈ −3.2971 → **−32971**；j=1024 = Φ⁻¹(0.25) = −0.67448975… → **−6744**；j=2048 = **0**；j=4095 = **+34871**；端点 **±39000**。表首尾对称（−34871/34871、−32971/32971），中点 0，与脚本 :161–:163 的单调/端点检查一致。
- 误差界推理：`expFixed` 每步整除丢 <1 单位（10⁶⁰），e¹ 级数约 25 项，绝对误差 <25；`powFixed` k≤40 最多 6 次乘方/乘法，相对误差放大 <2⁶；到 10⁸ 输出时绝对误差 <10⁻³⁰ 量级，远小于 1，所以 `floor(e^k×10⁸)` 的截断是精确的（e^k 对非零整数 k 为超越数，不会正好落在整数上；k=0 由表值 10⁸ 直接断言）。`expFrac` 相对误差更小（q 的误差 ~10⁻⁵⁹，m≤4096 只 13 次乘方），输出误差 <10⁻⁴⁷。分位数用 10⁵⁰ 工作标度 + 6 步 BigInt 牛顿，误差 ~10⁻⁴⁶，且 :146–:148 对每个点在 `k/10⁴`、`(k±1)/10⁴` 用高精度 Φ 复核截断区间；4 位边界在 10⁻⁴，余量约 40 个数量级。结论：表值是数学真值的精确向零截断，不是浮点近似。
- `--check`：`node --test tests/accept/det-tables.test.mjs` 首条实际重跑生成器并逐位比对入库文本，通过。

### 2. `server-plugin/kernel/det-math.mjs`：五函数逐步照卷文

- `fixedUnits8`（:208）：字串/数按十进制解析，`frac×SCALE / BASE^len` 整除、符号最后加 → 小数第 9 位起向零截断；`fixedMultiply8`（:226）`(a*b)/SCALE²`，BigInt 整除向零截断。
- `fixedExp`（:247）：`floorDiv`（:229）先取 `k=floor(x)`（负数正确向下取整），`r=x−k·10⁸ ∈ [0,10⁸)`，`m=(r·4096)/10⁸`，`rem=r·4096−m·10⁸`，`e^r=f0+(f1−f0)·rem/10⁸`，`expInt[k+40]·e^r/10⁸`；域由表长派生 `bound=40×10⁸`，±40 含等号、±(40+1/10⁸) 拒收。与 §1.10 :325 的 `floor`、插值、整数截断一致。
- `fixedPow`（:269）：`bitLength(e)-1` 到 0，每位先 `fixedMultiply8(result,result)`，该位为 1 再乘底数；`e=0` 返回 10⁸（1.0），负底数/负指数/非整数指数拒收。次序固定，与 :1333 一致。
- `fixedLn`（:294）：域 `0 < x ≤ expInt[40]`（表末项），越界即错；`w=BASE**18`、`up=BASE**10`；`a=x·up`。
  - `a≥w`：`n=bitLength(a/w)-1`；`a<w`：`r=w/a`，`rbits=bitLength(r)-1`，仅当 `w%a==0` 且 `r` 为 2 的幂时 `n=-rbits`，否则 `n=-(rbits+1)`。逐边界核过：`a=2w-1`→n=0、`a=2w`→n=1、`a=w/2`→n=−1、`a=w/3`→n=−2、`a=w-1`→n=−1，均满足唯一 `2ⁿW≤A<2ⁿ⁺¹W`，且 n 可为负的分支正确地用了整数乘法 `a<<(-n)`。
  - `t=(m−w)·w/(m+w)`、`t2=t·t/w`、20 项 `s+=p/(2i+1); p=p·t2/w`（i=0..19，分母 1..39）、`L=n·LN2+2s`、`L/up` 用 BigInt 除法。BigInt `/` 对负数向零截断，正是 :1340 要求的「L 为负时不是向下取整」。
  - `fixedLn(1)`：x=10⁸ → a=w → n=0、m=w、t=0、L=0，恰为 0。`fixedLn(10)` 与控制台手算 230258509 的差在 ±2 内（测试通过）。
- 结论：六步与卷文逐句对应，没有自造迭代次数、没有浮点、没有把入参钳进域。

### 3. `server-plugin/kernel/sample.mjs`：normal/lognormal 接表与原语

- `normalZ`（:314）：`u=uniformAt(seedKey,0)` 是 64 位；`shift=bitLength(TWO64)-bitLength(table.length-1)=65-13=52`（从表长与 2⁶⁴ 派生，不写 52）；`j=u>>shift`、`f=u&(2^shift-1)`、`z=table[j]+((table[j+1]-table[j])·f>>shift)`。表严格递增，差为正，`>>` 即向零截断；与 :324 的「高 12 位 / 低 52 位 / 线性插值」一致。
- `sampleNormal`（:324）：`fixedUnits(mean)+mul(fixedUnits(sd),z)`，`mul` 是 10⁴ 标度整除向零截断；`clampAndTrunc` 先 `truncateTo`（`(v/step)*step`，负值向零）再 clamp；与 :324、:327 一致。
- `sampleLognormal`（:331）：`lin=fixedUnits(mu)+mul(fixedUnits(sigma),z)`，`fixedExp(lin*fixedScale())` 升到 10⁸，`e8/fixedScale()` 降回 10⁴（BigInt 除法向零），再 `clampAndTrunc`；指数只经 `fixedExp`，没有第二份 exp。
- 采样种子键：`sample()` 用 `seedKeyFor(templateSeed, kind, id, dim, group)`，normal/lognormal 的 group 为 undefined；与 :320 一致。
- 特殊值：`fixedExp` 越界抛 `E-DET-DOMAIN`；`fixedLn` 的 0/负数/超上端抛 `E-DET-DOMAIN`；`fixedPow` 负底数/负指数/非整数指数抛 `E-DET-DOMAIN`；没有「0/空/不限」跳过校验的路径。
