# 卷三甲第三版纤维含量 `fiberContent`、卷四第八版猪的吸收率：上网核对

范围：卷三甲 §4.5.5 例 5（FIBER-DATA-BEGIN/END）里标"纤:未核"的 13 行；卷四 §4.7.5 猪吃粮 0.88（补核建议 0.80）、猪吃干草 0.30 的出处。没有改动任何卷文件。

## 口径

- 卷三甲 §2.1 把 `fiberContent` 定义为"干物质里粗纤维所占的质量比例（饲料分析的粗纤维测法）"，依据写"饲料成分表的粗纤维项"。所以全表统一按**粗纤维 CF（Weende 法），% 干物质**核，不用 NDF。NDF 只在找不到 CF 时作旁证列出，不拿来定值。
- 判定沿用前两轮的规矩：出处给单值，相差不超过 15% 算一致；出处给范围，落在范围内算一致；只有代用料，或几个出处互相矛盾，记"未核到"。
- 食物成分表给的是"每 100 克可食部"，我按"纤维 ÷（100 − 水分）"折成干基，这一步注明"按出处重算"。
- 出处缩写：
  - FP-wheat = Feedipedia 小麦粒 https://www.feedipedia.org/node/12754 （Main analysis 表）
  - FP-millet = Feedipedia 黍粒 https://www.feedipedia.org/node/12007
  - FP-soy = Feedipedia 大豆（全部，生与加工的整粒）https://www.feedipedia.org/node/12625
  - FP-straw = Feedipedia 麦秸 https://www.feedipedia.org/node/12758
  - FP-cocksfoot = Feedipedia 鸭茅干草 https://www.feedipedia.org/node/11990
  - FP-antelope = Feedipedia 羚羊草干草 https://www.feedipedia.org/node/11771
  - FP-leaves = Feedipedia 树叶各页：node/12346 马胡卡鲜叶、12226 红麻干叶、12080 花椒属鲜叶、12209 海南蒲桃鲜叶、11594 咖啡干叶
  - FAO-EA = FAO/美国卫生教育福利部《Food Composition Table for Use in East Asia》（1972），https://www.fao.org/4/x6878e/x6878e00.htm；说明页 X6878E01.htm 写明碳水按差减、含纤维，"无氮浸出物 = 碳水 − 粗纤维"，表里的纤维栏是粗纤维口径（说明页没有单独写测法，这一点按原文推断）

需要作者注意的两处：
- 干菜与鲜菜按定义同干基值，合理；但渍菜里的盐进了干物质，会摊薄纤维，出处的 9.1–12.9 % 已经含了这一摊薄，所以 0.12 仍在范围内。
- 夜帽菇按"食用菌类"核，是类推，不是该种测值；如果作者认为夜帽菇不该归到真实食用菌这一类，应改记未核到。
