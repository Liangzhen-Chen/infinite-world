## 三、改动带出的新矛盾（2 条）

### N1 污点规则没写清"经过算术后还算不算"，两种读法都出问题　类别 7、5　**新真问题，需报李白**
- 位置：P26-8 第 347 行、第 350 行；§3.1 读者闭集表第 298 行；§4.8.4 第 989 行。
- 证据：第 347 行列出的传播途径只有"别名、解构、函数返回值"，没有说算术结果是否继承污点；第 350 行又说"判据看的是值的来源"。
  - 如果算术结果**不**继承污点：`const s = sev * 1; if (s >= 0.8)` 就绕过了 P26-8，B26-7 要堵的整类旁路重新打开。
  - 如果算术结果继承污点：卷十三按闭集表把成员士气聚合成军团士气（第 298、989 行），之后卷十三拿军团士气与溃散门槛比较，同样命中 P26-8，卷十三 §4.8 的溃散判定就无法实现。
- 建议：写明污点经算术传播；同时给卷十三一条合法出口，二选一：(a) 军团士气由卷十三登记为自己的维度或容器，聚合值写进去时视为"经声明写者落地"，污点在此终止；(b) 军团层同样只经容器档修正项起作用，不做比较。登记进 §3.1 闭集表与 §8，交卷十三确认。

### N2 "severity 降到 0 即移除"被写成对一切容器相同的通用机制，卷二没有这条，且会误伤心理量容器　类别 4、5　**新真问题，需报李白**
