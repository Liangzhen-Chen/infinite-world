## 二、重点核

### 1. 偏离一：分料写法（第 304–306 行）

- **原公式回落属实**。三料配额各 1、`N_r = 3`：累计 2 升时前两项 `floor(2×1÷3) = 0`，末项取差 = 2，已超配额；累计 3 升时三项各 1，末项回落为 1，本次换出 −1。余项单核第一节建议的写法确有此缺陷（审查方失察，记在审查方）。
- **新写法逐项核**：
  - 切片无关：各料累计量只是 `R = doneL − F` 的函数，`doneL` 只做整数加法，所以任意切分提交后各料累计逐位相同。成立。
  - 单调：取的是同一固定序列的前 `R` 项，`R` 增大只多数不少数。成立。
  - 做满等于配额：`R = replaceL` 时取全列，各料恰为 `quotaL[k]`。成立。
  - 确定性：位置 `j ÷ quotaL[k]` 用整数交叉相乘比较，不做除法；并列按材料代号序，全序唯一；`quotaL[k] = 0` 的料不入列，无除零。成立。
  - 比例性：前缀计数与 `R × quotaL[k] ÷ replaceL` 之差不超过 1 升，中途按比例穿插。成立。
- **不算新增设计点**：裁定①的实质是"开修一次拆配额、其后只由累计量决定、不因切分漂移"，新写法只是把"由累计量取量"的函数换成一个满足单调的函数，存储（`repairLot`）、配额拆法（`floor(N_r × u_k)`、末项取差）与裁定一致，没有新概念、新存储或新规则表键。
- 小项：`j` 的起点未写（脚本按从 1 起算）；正文补"`j` 从 1 起"。

### 2. 偏离二：展开新建行、旧行经终止协议结束（第 659–671 行）

- **"保留原行就得改 `parent`"属实**：卷五第 243 行 `parent` 只有建行写者、建成后不改写；卷二与卷五都没有"改挂/迁移行"的原语（检索 `relocate`、`搬家`、`换标的`、`改挂` 于卷二、卷五、卷十八，零命中）。**不终止又不改 `parent` 的现成路径不存在**。所以"旧行结束、新地点另建"本身是现有规则下唯一可行写法，不算违背裁定。
- **持有边**：第 663 行收起前把以行为标的的边换标的到 `carrierItem`，第 667 行按 `edgeSlots` 换回；卷二 §2.6 第 4 步"以它为标的的边一律解除"届时无边可解。裁定"不丢边"在本卷侧成立（换标的操作待卷十八，Q22）。
- **存储维度与偏离行**：第 662 行整取、第 667 行整还，A19-10.2 按维度表枚举比对。本卷侧成立，但写者登记与位置量排除有缺口，见第三节新真问题 1 的 ③④。
- **引用不断**：第 671 行规则 7 + `currentRowOf`，成立（房间位次的回读方式作者已自记小项 9）。
- **但"无物可丢"不成立**。旧行仍走终止协议全五步，第 662–664 行只预先处理了持有边、存储维度、偏离行与本卷的 `facilityState`，协议自己处置的其余几类没有预先搬走，终止时照常执行：
  - 第 5 步清掉行上的**状态实例**（卷二封闭枚举 `status_target` 含 `place`，place 行可带状态）与以行为来源的修正项；
  - 第 5 步**撤销到期项**：以该行为 `owner` 或 `ref` 的到期项一律撤销；
  - 第 1 步**别卷登记在该行 id 下的领域记录**（`subjectRecords`，去留 `clear` 的被删，`hold` 待期满删）；第 662 行只写"`facilityState` 记录整条搬入"，别卷记录不在内，且由 `facilities.mjs` 搬写别卷路径本就越权；
  - 第 1 步**别卷对 place 类登记的清理函数**照常被调用，第 5 步 **`verb_entity_terminated` 订阅者**照常收到事件——它们无从区分"收起"与"毁坏"，除非约定某个原因代号的含义，而卷二没有这种约定（现稿检索：尚无卷对 place 类登记清理函数或订阅，但这是协议开放的口子，本卷第 662 行"以后别卷新加的都在内"的承诺对记录与订阅不成立）；
  - 第 3 步**账户余额**转给 `carrierItem` 后，展开时不转回（作者自记小项 10）；
  - **存档增长**：每次收起留终止标记与一条死行，且死行上的维度原值仍在（终止不删行属性），第 667 行"任一时刻这份内容只在一处"说法不准，死行与 `portableState` 各有一份（全书按 place 行做的聚合须一律滤已终止行）。
- **判断**：裁定"不靠收起即终止"的本意是不丢边、不丢状态、引用不断。第五版做到了边与引用，状态只做到"存储维度 + 本卷记录"，状态实例、到期项、别卷记录、账户、清理函数与事件这几类仍由终止协议处置，要逐类补"终止前搬走、展开后还原"，有的要动别卷写者（状态容器归卷二、到期项归卷二十）。这是"借终止原语做搬运"与终止协议语义（实体真正结束）之间的结构性冲突，单靠本卷补丁补不全。见第三节新真问题 1。

## 六、结论

新 1、新 2 **已改好**；作者对分料公式的偏离**成立**（原公式三料回落属实，排队写法切分无关、单调、做满等于配额、确定性），不算新增设计点。补缺按 `envelopeReq`、换料量式自洽。新 3 的持有边、存储维度、长期引用三项按裁定写到，"展开另建行"在现有规则下没有替代路径，**不算违背裁定**；但旧行仍走完整终止协议，状态实例、到期项、别卷记录、账户、清理函数与事件不在搬运范围，展开时的整还也缺写者登记，属结构性问题——**新真问题 1，需报李白**（甲补全终止协议 / 乙改挂原语，均动卷二或卷五）。`dirt` 算法正确，但表头写法与卷二第 96 行冲突，加载即报错——**新真问题 2，需报李白**，建议直接取 Q23 退路（只用扩展标度，删余数），改动局部。脚本未放宽。
