## 二、口径与局限

- 登记项：各卷 §3.1 节表格前两格、列表项行首的反引号记号（沿 collect-entry-callers.mjs 口径，自动取 426 项），并入各卷 DeepSeek 复核的驳回与补漏（docs/审查/总登记表-清点-分卷/）；每个入口名在其所在卷下算一项
- 提供方代码：server-plugin 下 .mjs 里导出的同名函数或常量（含经 export-from 转手），文件:行；没有导出只有文件内部同名顶层声明的，单独标注
- 调用方代码：按 import 绑定核对：调用文件须具名导入该名（沿转手导出追到定义处）或命名空间 空间.名 引用，且在 import 语句之外真有使用；生产 = server-plugin 下，仅测试 = tests 下，工具 = tools 下。未经 import 的 .名( 成员调用另列为疑似，不计入接通
- 接通状态：已接通 = 有生产调用者且提供方、调用者两个文件都沿静态 import 从 server-plugin/index.mjs 可达；有代码无生产调用 = 有导出（或仅文件内部同名函数）但不满足；未建 = 没有同名定义
- 调用方设计：他卷调用形提及 = 别卷里反引号或代码块内写成 名( 的行（卷:行，每卷最多列 5 行，次数为全部）；行内点名他卷 = 该入口所在行文字里直接写出的别卷名；两者都没有写"卷文未写"。同名泛词（如 check、route）会把无关出现也算进来，故按"调用形"取，仍可能偏多
- 绕开处：甲 = docs/研究/公共部件审查-甲/乙-1122.md 里"4. 绕开"块中带 文件:行 的行，归给该行、块首行、小节标题里点名的入口（已查出）；脚本新发现 = 别处自有同名顶层定义（未导出）。其余绕开处（不同名的另算）脚本找不到，需人工，本表可能漏报
- 依赖：代码 = 提供方函数体里 名( 调用的其他登记入口（须是 import 或本文件定义）；卷文 = 该入口所在行说明格里反引号写出的其他登记入口名。边 = 两者并集，按入口名合并同名多卷项
- 局限：词法级读取，不是类型检查：经对象属性、注册表、字符串名间接调用的看不见（疑似栏只补一部分）；函数体范围靠括号配对估计
