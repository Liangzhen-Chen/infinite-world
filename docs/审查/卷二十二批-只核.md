## 二、新真问题

**Y1 抄一件译本会退回原件语言（Q22-13 落地缺口，卷二十二与卷三乙同）**。卷三乙 R-2（:1172）`templateFrom` 只取“原件的模板”，不带实例偏离行；B-3（:1570）与 R22-6.5（:512）都写抄本“`language` 随模板自然相同”。译本的译入语言只在其实例 `props.language` 上，于是以译本为原件抄写，产物读到的是原件模板的语言，与 A22-6.2“读到的 `language` 只差在译本实例的偏离行”的本意相反。改法（局部）：B-3 与 R22-6.5 各补一句“抄写时原件实例的 `props.language` 偏离行照抄到产物”。

**Y2 X6 改后 R22-10.8 的总量上界不成立（类 4）**。:676 改为“不可释放则全部保留”，但未写此后何时再判；句末上界仍是“`frozenKeepDays` 内的死者数加有承接者的死者数”。`keepUntil` 时足迹非空或无成员身份（手写个体恒 `pin_identity`）的死者，快照与条目永久保留，不在此界内。另“R22-5.7 整人判据”含“所在单元有效层不是个体层”前提，死者在个体层单元时是否一律不可释放未写。改法（局部）：写明保留者在其后每个整拍边界复判（或随足迹清空时删），上界补“不可释放的死者数”项，并写清有效层前提对死者是否适用。

**Y3 研究项目的 `lead`、`members` 同样以 EntityId 钉住，无上界（X3 只覆盖谋划）**。`state.projects` 研究与谋划共用（:175），R22-9.2、R22-9.8 有“参与人数”“参与的成员”；§2.3 :168 把例外写成整个 `state.projects` 的 `lead`、`members`，但 :175 与 §5.3 :829 只对谋划给了 `plot.maxMembers` 上界，研究行无人数上限、无删除时机。按裁定③，换不成键的类别须给上界。改法：研究行同法给成员上限与上界，或停报李白确认研究成员是否同样钉住。

**Y4 `target.subject` 改键后，败露与成事未写解析为空（X3 下游）**。R22-7.6 :556“目标一方 = 目标本人……防范读数取最大值”须先把键解析到物化个体；目标不再被钉住后可能已折叠或已死，R22-1.5 解析为空，此时“目标一方”为空集、最大值无定义，R22-7.6 与 R22-7.7 都未写。改法（局部）：写明解析为空时目标一方为空、防范读数取 0（或本刻不抽），R22-7.7 前提照常由动作行判定。
