## ① 现有维度确实表达不了（复核）

- 卷二十二要求命题 `subject` 是实体、`dimKey` 是维度代号；状态实例 id 是 EventId，不是 EntityId，只能挂在主体上。
- 主体上没有维度能表达"这个实例是哪一行"：`struct:statusInstance.status` 是 state 字段不是维度（卷四:278、卷二十一:231）；`statusView` 只出实例→档→修正集合（卷二:397）；全书 Grep `status*[` 形式的维度只有本批 `statusRow`；`needRecover`、`crowding`、`chronic` 与此无关。
- 不带下标（如整张 map 一个维）时同一主体两个实例的认定落到同一 factKey `(claim, subject, dimKey)`，部分认定、认错一个会互相覆盖，故下标必需。
- 结论：现有维度（含已登记派生维）都表达不了，与 审查/机制项-卷十九卷二十一-二轮-只核.md 一致。
