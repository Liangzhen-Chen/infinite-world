## 重点 1：初值与 32 步收敛（推导）

卷文只写"牛顿法固定 32 步"/"固定步数"（卷二 :327、卷二十七 :574），没有规定初值。实现取的初值与 4-4b 的 `sqrt` 原样一致，也与离线生成器一致（`tools/gen-det-tables.mjs:211`），4-4c 没有新选初值。

- 初值（`det-math.mjs:477`）：k = bitLength(n)，y0 = 2^⌈k/2⌉。
  - k = 2m：2^(m−1/2) ≤ √n < 2^m，y0 = 2^m，故 y0/√n ∈ (1, √2]。
  - k = 2m−1：2^(m−1) ≤ √n < 2^(m−1/2)，y0 = 2^m，故 y0/√n ∈ (√2, 2]。
  - 即相对误差 e0 = y0/√n − 1 < 1。卡文担心的"初值取 n、前期每步约减半、需约 k/2 步"不成立：初值已经是 √n 同量级的上界。
- 牛顿相对误差递推 e_{i+1} = e_i²/(2(1+e_i))，从 e0 = 1 起：0.25 → 0.025 → 3.05×10⁻⁴ → 4.65×10⁻⁸ → 1.08×10⁻¹⁵ → 5.8×10⁻³¹（第 1…6 步后的上界）。
- 两个调用点的最大输入：
  - detfn sqrt：v ≤ domainMax = 9007199254740991（`world/rules/tables/det-numeric.json:3685`），n = v·outScale²/inScale = v·10⁸ < 9.01×10²³ < 2⁸⁰，√n < 1.1×10¹²。第 5 步绝对误差 < 1.08×10⁻¹⁵×1.1×10¹² ≈ 1.2×10⁻³ < 1，第 6 步后远小于 1。
  - 三角：a、b、c = fixedUnits(min/mode/max)，每个绝对值 ≤ safeIntMax = 2⁵³−1（checkedFixed：`det-math.mjs:68-70`；fixedUnits：`:127-143`）。两处 `mul` 的因子都非负（min≤mode≤max）、向零截断不放大，故 `fixedSqrtInt` 入参 n = v·10⁴ ≤ 4(2⁵³−1)² < 2¹⁰⁸，√n < 2⁵⁴ ≈ 1.8×10¹⁶。第 5 步绝对误差 ≤ 1.08×10⁻¹⁵×1.8×10¹⁶ ≈ 19，第 6 步后 ≈ 10⁻¹⁴ < 1。
  - 结论：两类最大输入都在 7–8 步内进入整数不动点，32 步有 ≥ 4 倍余量。32 步后的结果等于 ⌊√n⌋。
- 取整安全（min 为什么一定给 ⌊√n⌋）：设 s = ⌊√n⌋。
  - y0 > √n ≥ s（n < 2^k 时 y0 = 2^⌈k/2⌉ > √n，n 为 4 的幂时也 ≥ √n）。
  - 一旦 y ≥ s 就不会掉到 s 以下：y ≥ s+1 时 ⌊n/y⌋ ≥ s−1（n/y > n/(s+1) ≥ s²/(s+1) > s−1），故 y' = ⌊(y+⌊n/y⌋)/2⌋ ≥ s。
  - y ≥ s+2 时 ⌊n/y⌋ ≤ y−1（n < y²），故 y' ≤ y−1，严格下降直到 {s, s+1}。
  - 收敛后：y=s 时 ⌊n/s⌋ ≥ s，min = s；y=s+1 时 ⌊n/(s+1)⌋ ≤ s，若 n ≥ s(s+1) 则为 s，若 n < s(s+1) 则为 s−1——但后一种情形下 y=s+1 一步就回到 s（y' = ⌊(s+1+s−1)/2⌋ = s），y=s 也留在 s；第 32 步早已过收敛（剩 ≥ 24 步），终态不会是 s+1。
  - 边界：n=0 在 `det-math.mjs:476` 直接返回；n=1,2,3 手推都得到 ⌊√n⌋。
- 因此旧 `isqrt`（从 n 起迭代到稳定）与本实现（2^⌈k/2⌉ 起固定 32 步）对一切入参同值，三角采样值不变，重构成立。
- 说明：本卡测试里最大的开方输入只有 2.7×10⁷（`tests/kernel/sample.test.mjs:223`），没有覆盖近上界；上面的"最大输入"结论是推导（卡文允许"测试或推导"）。建议后续补一条近上界（如 9007199254740991 的 sqrt）断言，但不是本卡必须。
