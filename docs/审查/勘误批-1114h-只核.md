  - 原来的撞号是这样产生的：在 `aft.*` 事务内发出的内核事件，按（同一代号、上一条事件 id、`pos.only`）派生，结果等于善后链的下一条。换成专用位次后，内核链与所有事务事件的派生元组位次不同。不同事务事件下的内核链，链首主体 id 也不同。无事务事件的直写分支，与该钩子经执行器的事件位次不同。所以三种情况都不会撞号。
