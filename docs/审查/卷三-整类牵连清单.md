# 卷三 整类修改牵连清单（别卷要跟改的地方）

依据：`卷三-物品与材料.md` 第四版（快照 `版本快照/卷三-v4.md`）。第四版改了两件事：

- 材料表与物品表的 `class` 族类别一律由属性维度派生，行上不手写，没有任何显式指定类别的通道（卷三 M-9、C-1、C-8、P-11）。
- 赃物份额 `taint` 的唯一写者是账本，别处只读，定义只在卷三 §3.3 表后一处。

扫描范围：`docs/统一底层设计/` 下除卷三外的 14 份"卷*.md"（卷零、一、二、四、五、六、十四、十八、十九、二十、二十一、二十五、二十六、二十七）。本清单只列建议的改法，别卷一字未动。行号是 11-13 当天的行号。

## 三、`taint` 的牵连

卷三的单点定义在 §3.3 表后"`taint` 的写者"一段：批次与实例两条状态路径的唯一写者都是账本 `kernel/ledger.mjs`；转移与拆分原样带出，合并、制造入账、改赃份额三种记录改值；入赃、消赃由卷八b 的法律程序经原语执行器向账本提交"改赃份额"记录，提出方不直写。

别卷提到赃物份额的地方共 4 行，没有一处是写入：

| 位置 | 现在写的 | 建议改法 |
|---|---|---|
| 卷六 §4.1（329 行） | 批次元数据（品质、腐坏、赃物份额、表象）归卷三 §4.4，随资源键中的批次号走 | 要补。账本归卷六，卷三把 `taint` 的写入定在账本里，卷六须登记三件事：① 账本的转移、拆分记录原样带出 `taint`，合并记录按质量加权；② 制造入账记录接收 `craftOutcome` 提案里的 `taint` 作产物初值；③ 新增一种"改赃份额"记录 `{target, taint, cause}`，只改 `taint` 不改数量，`cause` 为入赃或消赃。并注明定义以卷三 §3.3 为准，卷六只引用 |
| 卷六 §4.20（1110 行） | 销赃：赃物批次带赃物份额，买方知情则折价 | 只读，不必改；可补一句"销赃成交不改变赃物份额，洗白只经卷八b 的法律程序提交改赃份额记录" |
