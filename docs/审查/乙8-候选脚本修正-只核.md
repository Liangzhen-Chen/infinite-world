## 不挡封记账

1. 否定判定只认紧挨的写法：否定词，可加“再”，可加一个列举的动词，然后就是名字。“不必调 `x`”“不直接读 `x`”“不调卷四的 `x`”这类，否定词和名字之间隔了副词或修饰语，仍会计入（构造 3 例不符）。全书迁移行里目前没有这种写法，第 1 批和第 2 批都不受影响。如果改成整分句一律算否定，又会把 M25-11（“不保留……，只经 `envAccum`”）误排，所以修法要等李白定范围，见需李白裁 1。
2. TAG 写死了日期前缀“1116”：`1116乙8-${BATCH}-卷`。如果第 2 批在 11-17 以后跑，勘误标签和快照名里的日期会不对。这不算行或卷的特判，但应该改成按运行日期取，或者把批次参数的值并入标签。
3. --snapshot pre 的注释写“不覆盖”，实际用 writeFileSync 照写；y38 撞上的就是这个。现在标签带了批次，撞名的可能低了，但同一批次重跑还会悄悄覆盖。属于旧代码。
4. 第 139 行的注释说本卷名在括注里不计，代码却照计（同生成器“出现即计”）。注释和实现不一致，判定本身是对的。
5. 跨进程用的 diff 和 plan 文件只按“批次+卷”命名，同一批次同一卷两路同时跑仍会互相覆盖。这是 --report、--print 设计上要读回这些文件，换一个批次号即可避开，可以接受。F:/dnd-tmp 里还留着修正前的旧格式文件（乙8-multi-卷X.json、乙8-diff-卷X.json、乙8-卷X-plan.json），无害，可以清掉。
6. 违禁记账：执行方自报误用过一次 sed -i，被权限拦截，没有执行。按自报记一次（未看执行记录，无法另行核实）。
