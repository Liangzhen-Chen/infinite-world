### 关于 Q14：资产种类取卷十九 §4.2 的设施类型，是否妥当

**判断：方向妥当，但措辞要收紧，否则会与卷十九的派生规则冲突。**

妥当的地方：
- 本卷没有另立资产种类表，避免重写卷十九已经定义的概念（符合台账归属，也符合“派生优先”）。
- 账户键用的是设施实例（L99），不是类型。

需要收紧的地方：
1. 卷十九 §4.2 规则 2（卷十九 L327）规定，`type` 可以为 null（空壳），并且在修缮换料、安装或拆走固定装置、改用途之后会变。如果把“资产种类”读成“每种设施类型一行资源种类”，那么类型一变账户就要改键，空壳又无行可挂，与 A6-1.2、A6-18.2 的“每处一万基点恒等”冲突。L107 的写法“资产的种类不另立表，取卷十九 §4.2……设施类型”容易被这样理解。应改为：`resfam_asset` 只对应一行资源种类（建筑份额），设施类型只在估值（§4.18 规则 3）和用地类别（§4.18 规则 1）时读取，不进资源键，也不作资源种类行的下标。
2. 卷十九 §4.1 规则 1 写“建筑是地点”，本卷 §4.18 规则 2（L1029）写“土地（地点）不进账本”。两者之间应写明判据：挂 `comp_facility` 的地点行有资产分录，其余地点没有。
3. 卷十九 §4.10 的可移动建筑，算物品（L345“可移动的制成品走普通成对腿”）还是算资产，需要卷十九一并确认。

以上三点都可以在 Q14 的对齐中一次写清，不构成本轮的新矛盾。

## 三、改动带出的新矛盾（5 条，均为“新真问题，需报李白”）

### N1 边界供货限额：外流余量按货分别计算，可以超过总上限；日终分配与即时成交、成交前校验互相冲突 —— 新真问题，需报李白
- 位置：§4.6 规则 8（L551–552、L550、L554）；§4.1 规则 6（L348）；§4.2 规则 3（L387）；A6-6.2（L575）。
- 类别：5、6。
- 证据：
  - L552 写每种货的日限额 = `min(份额 × 日需求, 外流余量 ÷ 该货边界报价)`。每种货都拿全部外流余量去除，于是 N 种货当日的合计付款最多可以达到 N 倍外流余量，超过 `boundaryCoinOutflowCapShare` 定下的上限。
  - L348 规定限额通道“在世界日结算步里一次分配……与处理先后无关”；但 L550 写边界售货“经 `executeTrade` 成交”（即时成交），L387 又把“当日剩余限额”计入 `marketSupply`。在日终才分配的口径下，日中的“剩余”没有定义；按即时口径，它又与处理先后有关。
  - A6-6.2 写外流上限“成交前校验”，这是逐笔先到先得，与 L348 的“只取决于当日申请的集合”相反。
- 建议：外流余量在日终同一个分配步里跨货联合分配（按申请额比例，余数按 id 补）；边界成交一律作为当日申请，在日终结算；`marketSupply` 中的边界项取当日开始时的限额；A6-6.2 改为核对日终分配后的余额。

### N2 燃料被重复记账，热量路径与卷三、卷二十不一致 —— 新真问题，需报李白
- 位置：§4.12 规则 5（L796）；对照卷三 §4.11 T-6、T-10（卷三 L1065、L1069），以及卷二十 §4.5 第 3 条（卷二十 L605）。
- 类别：4、5。
- 证据：
  - 第二版规定，当日用掉的量一律从储备记入 `sink_consume`，同时向卷十九炉窑和卷二十温度场发一条“燃烧事件”。
  - 但卷三 T-6 已规定，燃烧本身就是账本转移：逐分钟烧掉质量并留下灰烬，放热交给炉窑或环境场；卷二十的室温也是读卷三“燃烧中物品的放热状态”，并不订阅事件。
  - 结果是：同一捆柴先被本卷记为消耗，再被卷三按燃烧扣一次；或者本卷记完消耗后，卷三已经无柴可烧。灰烬产物也在 `sink_consume` 里丢失，违反卷三 V3-4.11-I 的质量收支。
  - 这一处是单通道改写时新加的。
- 建议：`ns_environment` 类用度的“满足”，定义为把燃料从储备转入炉膛（或燃烧用途分区），并调用卷三的点燃入口；消耗与灰烬只由卷三 T-6 记账，本卷不对燃料记 `sink_consume`，也不另发燃烧事件。满足量按转入炉膛的量计。

### N3 A6-25.2 的“复算”无法判定 —— 新真问题，需报李白
- 位置：A6-25.2（L1353）；对照 §4.22 规则 5 第三项（L1215）。
- 类别：5、7。
- 证据：A6-25.2 要求“每一期的价格指数都可由该期的 `marketSupply` 与 `demand` 代入同一 `priceFor` 复算得出（逐位相等）”。但价格指数是按“期内成交均价”和期初权重计算的；`marketSupply` 是某一时刻的量，“该期的 `marketSupply`”没有定义；成交均价又由期内多笔、各自不同的边际价构成，不能由一个 `priceFor` 调用逐位复算。所以这条断言要么必然失败，要么无法交给机器判定。
- 建议：改为可核对的形式，例如“围城期间每一笔成交的单价，等于其成交时刻按 §4.2 规则 4 复算的边际价（逐位相等），而且没有任何价格槽修正项引用围攻状态族维度”。指数一项只保留窗口期与容差两条。

### N4 非业主出资扩建：资产归属与“扩建不产生新资源”冲突 —— 新真问题，需报李白
- 位置：§4.7 规则 11 运行期一项（L610）；对照 §4.1 规则 5（L345）、§4.19 规则 5（L1071）。
- 类别：5。
- 证据：
  - L610 规定，`stationPlan` 的实际工位数大于现有工位数时，由 `ownerRef` 所指主体出资，没有余力时可以由“可及范围内任何家户、个人、组织”出资，并且“完工时建筑资产分录记给出资方”。
  - 但 L345 与 L1071 规定，扩建不产生新资源，份额不变。卷五把需求上升后的增产交给“同式扩建”，所以运行期的主要情形恰恰是扩建。
  - 外人出资扩建别人的设施时，规则 11 要给他分录，规则 5 又说没有新分录可给：出资方要么白出钱，要么凭空得到份额。
- 建议：在规则 11 中分两种情形。新建时，按 §4.1 规则 5 产出一万基点，记给出资方。扩建时，只允许现有份额持有人出资；或者把扩建出资写成一次份额买卖（出资换现有持有人的部分份额，同一笔 `post` 对转），不产生新的分录。

### N5 毁损而没有残料时，按“反向转换”写法缺产出腿，会被拒绝 —— 新真问题，需报李白
- 位置：§4.1 规则 5（L345：“拆除与毁损反向：资产分录记去处，拆出的材料记来源”；“缺一腿即拒绝”）；§4.18 规则 8（L1035）；A6-1.2（L370：每笔转换成对）。
- 类别：5、7。
- 证据：一处建筑被火烧光、被夷平而没有任何可回收的残料时，只有资产分录这一条去处腿，没有来源腿。按规则 5，转换缺一腿即拒绝，于是毁损记不了账；资产份额会停留在一处已不存在的设施上，与 A6-18.2 的“已毁损的为零”矛盾。文中也没有说毁损时资产记入哪一个去处（`sink_transform` 必须成对；`sink_loss` 是单向的，但没有登记到资产种类行的 `sinks` 里）。
- 建议：拆除（有残料）走 `sink_transform` 与 `src_transform` 成对；毁损（不论有无残料）中的资产分录一律记单向去处 `sink_loss`，有残料时，残料另以 `src_transform` 入账（或由卷十九、卷三的毁坏规则给出来源）。同时把 `sink_loss` 列入 `resfam_asset` 资源种类行的 `sinks`。
