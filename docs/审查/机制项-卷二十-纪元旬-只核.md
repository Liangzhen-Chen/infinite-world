## 真问题

1. **64 位整数超出状态整数上限**。卷二十 §4.2.3 第 3 条（:498）把 `eraId` 定为"派生值前 16 位十六进制为 64 位整数"，并由 §3.2 `eras.*`（:380）存进状态。卷二十七 R27-5.1（:537）规定状态里的整数绝对值不超过 `safeIntMax` = 2⁵³−1（:161），超出的写入报 E-DET-OVERFLOW 被拒，也不准用字串装大整数。卷二 §1.10（:275）的 64 位 `u` 是 BigInt 中间量，不进状态，不能照搬。现写法下纪元记录根本写不进去。

2. **"不撞键"的论证不成立，不变量 ⑥ 没有保证**。:498 写"不同纪元的五段必不相同……所以不撞"，这是把"输入不同"当成了"散列输出不同"。sha256 截断以后，输入不同也可能得到同一个值。截到 ≤53 位以满足第 1 条后，概率更高。§4.2.6 ⑥"全部纪元记录的 `eraId` 两两不同"因此没有依据，正文也没写撞了怎么办。这与卷二十七 X5 是同一类问题（用散列推出的号去声称"必一一"），但成因不同：X5 必须能"可重算"，又受位宽限制，所以只能改成定宽位段置换；纪元记录是存下来的，不需要重算，用不着照 X5 去做可逆编码。改法建议：仿 X5 的 `aggregates.<a>.aggNo`（卷二十七 :192、:342），在纪元记录建立的事务里分配一个序号，如 `eras.nextEraId`，取一次、只增不减、终身不改，按建立顺序（同一事务内按法域 id 键序）取号。这样一一对应是构造出来的，值 ≤ `safeIntMax`，复演时也确定。R27-8.9 的"不得含计数"只管事件 id、实体 id、到期项 id，`eraId` 不在其中，X5 已有存储计数的先例。要注意的是，这会增加一个状态键，属于新设计（见"须报李白"）。

3. **同一分钟连续两次重置会撞号**。:498 写"同一法域、同一历法同一分钟只有一个纪元起点"，正文没有出处。零耗时动作可以让同一法域在同一分钟里连发两个 `resetOn` 动词（例如君主死、嗣君随即又死）。这样会产生两条纪元记录（`eraOrdinal` 各加一），它们的五段相同，`eraId` 也就相同，⑥ 被破坏。改用第 2 条的分配序号就一并解决。

## 逐项核对

1. **固定数字 id 与派生**：思路"建立时定一次、此后不变、不读文字"合裁定④。派生做法有上面第 1–3 条的问题。新代号 `rule.calendar.era`：仿卷十七先例属实，卷十七 :160、:180 有 `rule.trip.start`，卷二十七 :714 有收件登记。只要沿用 R27-8.9，这个代号就有必要；改成分配序号后就不需要了，§5.2 新加的那行配合行也应一并撤掉。
2. **"生成期"的理解**：regnal 纪元在运行期才产生，世界生成时不可能把所有纪元的 id 都预先分好。把"生成期固定"读成"纪元记录在它建立的事务里一次定下"，是唯一能落地的读法，实质上没有偏离裁定（"固定、不随君主重计、名只做显示"都做到了）。措辞与卷十的术语"生成期"不同，记账。
3. **旬序**：除数 `weekDays` 的取值域是 [1, null]（:164），下界大于 0，除法成立。不过正文没有按全书"除数下界"的写法明写一句（卷三乙的先例），记账即可。onUnknown 为 gap 时 `weekOfMonth` 怎么处理，与 `weekDay` 的处理相同，没有新增缺口。"历法行代号加旬序"与已批的月键（历法行代号加 `months[].ordinal`，:172）写法相同。这是"登记代号加数据序号"的复合键，不是新造的文字代号，也不违反固定代号族登记；清单 :159 写的就是"由日序派生"。`floor((day−1)÷weekDays)+1` 合"由日序派生"，不变量 ⑦ 成立。旬部分通过。
4. **所请范围**：没有超出所请。显示名不进 `eras.*`，规则与存档只认 id（:172、:380、:498）。不变量 ⑥⑦ 已加，⑥ 的保证见真问题 2。卷二十七的登记配合行（:1002）只要求登记、不改该卷规则，写法合格；改用序号后应撤掉。
5. **勘误合规**：1114bc 的 sha256 等于 e22b2678~1 的卷二十（ad4c7542…）；v10.md 等于现卷（667a69ea…）；卷首仍是"第十版"，版本号没有升；附录戊第 14 行齐全。合规。

## 记账（不阻断）

- :172 写"纪元名是语言包条目，条目键取 `eraId`"。运行期才出现的纪元无法预先写进语言包，原问题（§8 第 17 条）已经指出过这一点。实际更像以 id 为键的运行期显示名，这归卷二十九 R29-1.13 处理，建议记为卷二十九的牵连项。
- `eras.*` 的路径形状只写了"每个法域"，派生却用到了历法行代号段。一个法域是一条纪元记录，还是每部历法各一条，没有写明。改用序号时一并写清。
- 月末不足一旬的余日会单独成一旬（30 日一月、`weekDays`=10 时，第 31 日是第 4 旬），与"下旬含月末"的习惯不同。语言包可以给第 4 旬同样的名字，不阻断。
