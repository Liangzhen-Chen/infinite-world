  2. 卷二十七:323 本来就把（种类, 单元, 键值）三者共同作为聚合体身份，“被俘”作为这三元中的一个取值，区分出一个独立聚合体，持续作用（不再在场、不劳作、不参战，受羁押位约束）都有了，二审 N1 的“无存法”已解决。
  3. 卷二十七:144 `keyHoldings` 路线也不可用：`aggk_detained` 的 keyHoldings 为空（卷八b:1216）。
- 字面偏离须报李白知悉（不需重裁）：裁定原话“分组键的一个取值”，作者落在“聚合种类”一位。
- 小项（记账，不阻封卷）：
