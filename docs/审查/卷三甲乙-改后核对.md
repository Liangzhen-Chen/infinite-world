## 二、核脚本有没有放宽

- **谷物七条件**：`check-卷三-全集.mjs` 有两处实现。L251–253 的 `isGrain` 与 L692–700 的 `SEVEN` 独立求值，七条齐全，阈值和代号都从正文规则表读。碳水未知、科留空或记未知的行一律不过。L708 要求派生规则、七条件、应得结果表、正文名单四方一致。L728 单独断言大豆被碳水、科两条各自挡住。L736 断言没有醪、酒的自生环。**没有放宽。**
- **燃料三来源**（丑组 L740–790）：断言了以下各点：
  - 有证据的行成堆是燃料，`reliefMax` 归 0 后结论不变；
  - 没有证据的行等于推算的结论；
  - 单件结论不受证据影响；
  - 燃料结论等于应得结果表；
  - 依据为"未知"的行不得判成燃料；
  - 证据行、未知行的名单都从正文读，脚本里不写名单；
  - 点名核了橡木、竹、柳条、沼泽树皮、雷击木炭五行。

  `verdictOf` 判法：低端严格高于门槛才算过线，正碰着门槛的判碰线。`R9` 只消浮点尾差，比法偏严，不偏松。直接证据仍须满足折合热量一条（`isFuel` 要求 `heatOk`）。**没有放宽。**

## 四、新真问题

### 新真问题 1，需报李白：聚合口径表没有覆盖第三、五、六版新加的三个材料维度（类别 5、7）

- **位置**：
  - 卷三乙 M-10（L574）："`rules.items.aggregation` 覆盖材料表的全部 number、map 与分态维度……缺一个键即加载失败……没有'没登记就按平均'的缺省"；
  - 聚合表（L542–558）；
  - T-15 第 ③ 款（L1369）："按与 F 相同的口径聚合"；
  - 卷三甲 §2.1 `fiberContent`（第三版）、`flammabilityRange`（第五版）、`carbContent`（第六版）。
- **证据**：聚合表里没有这三项。`fiberContent`、`carbContent` 是 number，`flammabilityRange` 是两栏 number 的结构，都在 M-10 的覆盖范围内。按 M-10 照字面执行，现有材料表加载就会失败。T-15 第 ③ 款要聚合 `flammabilityRange`，却只写了"与 F 相同"，表里没有登记它的口径，这正是 M-10 禁止的"隐含缺省"。此外：
  - 卷四按纤维扣减吸收率，碰到多料的吃食时要用 `fiberContent` 的聚合值；
  - 卷二十五主食类按需求块选料时，碰到多料的物品要用 `carbContent` 的口径。

  这三处都是新字段与已有的 M-10 之间的矛盾，第二版没有。现有自检只核 `none` 一行是否存在（`check-卷三.mjs` L420），不核覆盖面，所以没有报出来。
- **建议**：
  - 聚合表补三行，各给口径或 `none`。`flammabilityRange` 的两栏随 `flammability` 一起，取 `mean`、全部组。`fiberContent`、`carbContent` 由卷三乙按卷四、卷二十五的读法选口径。注意这两项都是"占干物质的比例"，多料合成时按干物质份额加权才对；若现有口径都做不到，须写明理由。
  - 自检加一条扫描式断言：卷三甲 §2.1 中类型为 number、map、struct、分态的字段，聚合表全部覆盖。
  - 只改这几处，不动别的结构。
