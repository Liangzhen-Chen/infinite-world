## C. 倒算与截断累积

### C0 根因（新真问题，需报李白）

卷二 §3.3（卷二:965、985）与卷二:135、269 只规定"每次运算按 precision 向零截断"，没有任何一条规定：① 累积量应存原值、派生量读时算；② 逐次更新时截掉的余数怎样结转；③ 锚点式（存起点值与起点时刻、读时一次求出）是首选写法。于是各卷凡"每拍或每次事件改一次存储值"的写法，都会出现两种毛病：小增量被逐次截成 0（"积小为零"，可借此整类绕过），或截断误差随次数单向累积。卷三 D-2、P-1 与卷二十一的浓度、免疫采用了锚点式，卷二十六 R26-4.4 写明"非闭式，只能逐拍"，各卷口径不一。
另：终核新真问题 3 的建议 ② 说"截断余数按卷二 §3.3 的余数规则归属"，卷二 §3.3 并无余数规则，该建议引用落空。
建议：卷二 §3.3 增设一条通用规则——存储值只存原值（质量、件数、总额、起点值与起点时刻），份额、单价、均值、积一律读时派生；必须逐拍改写的量，要么用锚点式，要么带整数余数字段逐次结转；并给出"切片不变"断言（同一总量拆成 n 次提交，结果与一次提交相同）供各卷引用。下列各条按此改。

**抽取定义点**（只认"定义"，不认"引用"）：
