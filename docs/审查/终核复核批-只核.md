## 四 finalize 脚本超范围改动

`finalize-卷十一.mjs` 只把读卷文这一处改成 `split(/\r?\n/)`，同文件原来读生成器输出、读 check 输出的两处已经是这个写法。

- **是必要接点**：本仓库 `core.autocrlf=true`，工作区卷文是 CRLF。按 `\n` 切行后每行末尾带 `\r`，附录甲按整行定位会失败，finalize 无法回写附录甲和 check 行。
- **没有副作用**：回写用 `join('\n')`，入库时 git 会归一化换行。本提交里卷十一的 diff 只有 R11-2.5、待补第 2 项、修订记录和 check 行四处，没有整文件换行变动。
