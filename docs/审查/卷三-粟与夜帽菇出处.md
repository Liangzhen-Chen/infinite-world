页面注：星号表示"均值由方程得出"，即总能 18.8 是方程推算值，不是实测。NDF、ADF 本页没有。

三栏结论：

1. 干基总能（`energyDensity`）：**18.8 MJ/kg DM**（FP 12108 Main analysis 表 "Gross energy" 行，方程推算，无范围）。
2. 干基碳水（`carbContent`，差减法）：100 − 粗蛋白 11.9 − 脂肪 4.9 − 灰分 3.6 = **79.6 % DM → 0.796**。原页三行取值核对无误，与卷三甲第六版例 8 备注所引"FP 12108 差减 79.6"一致。差减含粗纤维 8.9 与淀粉 57.9。
3. 粗纤维（`fiberContent`）：**8.9 % DM → 0.089**（FP 12108 Main analysis 表 "Crude fibre" 行，范围 6.5–12.0，n 6）。出处未写带壳与否。

对照现行第六版粟行（引的是黍 FP 12007）：总能 19.3、纤维 0.074、碳水 0.762。改为粟本种后三栏为 18.8 / 0.089 / 0.796。牵连：卷四按黍定的吸收率与 check-卷四.mjs 的参考值（已同步改参考值，见脚本）；谷物分界 17 仍在线上（18.8 > 17），碳水 0.796 仍在谷物线以上。

## 二、夜帽菇（mat_nightcap_mushroom）

- 卷三甲第六版正文：表行 525 "菌类不是植物……现记草本属未决（§8 Q-A9）"；纤维表 636 行、碳水表 720 行都写"按食用菌类推定，不是这一种自己的测值"。
- 卷二十一 736 行药性登记：`"一种毒菇：两条药性轴"`（神经毒 12、镇静 3）。
- 上网检索 "nightcap mushroom"：没有查到对应的真实菌种；唯一直接命中是一款游戏的虚构采集物（everafterfallswiki.com/index.php/Nightcap），无学名。

结论：**夜帽菇是本世界的假想料（虚构毒菇），无对应真实物种，碳水无直接出处——未核到。** 现行 0.58 是按食用菌六行（FAO-EA 504a、507a、511a、557、612a、615）类推的中位数，依据代号写"碳:推"属实；若按"查不到判未知"口径，应同月华浆果一样不填或另立"碳:设"（由设定者给值）。另需注意：它是毒菇，借食用菌成分类推本身就是借记，第七版应裁定处理方式。
