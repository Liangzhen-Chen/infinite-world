## 二、真问题

**N1 卷二十七 R27-8.9 :686 末句“本条已答卷二十六 Q12”与 :936 读者栏“卷二十六 Q12（已答）”名不副实**

改稿者的提示成立，理由有三条：

1. **问的不是同一个位置。** Q12（卷二十六 :1305、:1528）问的是**骰值键的对象段**，也就是 R27-8.5 五段键里的 `subjectId`（:676），要求卷二十七在 §4.8 的文法里写明。本条只定义了 `instanceIdOf` 的**父段**，即实体 id 派生的主体成分。两者都叫“主体 id”，却是两个函数的两个参数。R27-8.5 的 `subjectId` 定义（:676）仍然只列单个 id，本次没有改动。
2. **成分范围不同。** Q12 的限定成分包括“登记代号、实体 id、数据行内固定序号”三类。本条只允许“两个 id”，也就是群体 id 和对象 id。卷二十六 :208–:212 的五个抽取点里，四个的限定成分是排他组代号、发作行代号或绑定项序号，都不是 id，本条一个也覆盖不到。
3. **成分个数不同。** `draw_psych_bind` 的对象段是“主体 id 后接发作行代号与绑定项序号”，共三个成分，超出本条的“两个”。

另外，全书在骰值键对象段用“后接”的还有卷十六 :805、:851 等十余卷多处，它们同样没有文法依据。如果标为“已答”，Q12 会从待办里消失，这些写法就悬空了。

裁定原文（收尾待办 :340）写的是“答卷二十六 Q12”。这句话来自上一轮只核 P1 的“顺带回答”，那是只核者当时的判断失误，不是新发现的分歧。

应有措辞，二选一，须李白定：

- **甲（真正答掉 Q12，在已封卷的卷里加设计，须写必要理由由李白核）**：在 R27-8.5 `subjectId` 一项（:676）之后加一个子项：
  > - **复合对象段**（封卷后勘误，李白 11-14；答卷二十六 Q12）：`subjectId` 可以是一个主体 id 后接一到两个限定成分，各成分之间用内核分隔符 `|` 连接；限定成分只能是登记代号、实体 id 或数据行内的固定序号（R27-8.2），不得是计数（本条“禁止”项）。卷二 §1.10 规定各部件不含 `|`，所以复合对象段与它的成分组一一对应，也不会与任何单个 id 相同。R27-8.9“两个 id 合成的父段”是同一写法在 `instanceIdOf` 父段上的用法。

  同时把 :686 末句改为“同一写法用于骰值键对象段，见 R27-8.5‘复合对象段’（答卷二十六 Q12）”。:936 修订行和读者栏随之改，并补上读者：卷二十六 §2.2 抽取点表，以及卷十六 :805、:851 等用“后接”写对象段的各处。卷二十六 Q12 标为已答，并把“后接”改成 `|`。
