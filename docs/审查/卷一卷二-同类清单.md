"菜单回合"按任务定义：不开 AI，只点选。逐一核对 §2.7 `kernelApi`、`groupApi`、`assembly.calls` 与 §2.9 第 0 条路由、能力对象、回应通道各环。走不到的分两种：本来就不该在菜单回合出现（键入文字或 AI 专用），或者遗漏了通路。对 AI 专用入口，另看"开着 AI、只用菜单玩"和"删掉输入边（G4）"两种情形，因为终核 X3 就是在这两种情形下发现的。
