## 三、改动引出的新问题

### N1 物化建行由哪些量决定，两卷说法相反（类 5、6）——**新真问题，需报李白**
- 位置：卷十九 §4.4 规则 9（L517）："物化出的行只由世界内的量（世界种子、地点、世界日）决定"，同条前文还说以"当地可得料与居民技能为输入"；卷六 §4.1 规则 5"物化建行"（L356）与 §4.22 规则 3："第 0 日……由（世界种子、地点）的纯函数给出……墙料数量等于将来建行要砌入的各料质量"。
- 证据：卷六在第 0 日就按（种子、地点）定死并预置了墙料。卷十九的物化结果却还取决于世界日，以及物化那一刻当地的料和技能。只要两者有一处不同，"预置墙料与明细砌入逐料相等"（卷六 A6-1.2、§5.3）就做不到：要么墙料不够，物化失败；要么墙料剩下，余额不为零。
- 建议：卷十九规则 9 写明，物化建行的形制、用料和各料质量只由（世界种子、地点）决定，与第 0 日卷十的清单是同一个纯函数的输出；世界日只用来定物化之后的劣化之类，不影响用料。卷六不用改。

### N2 翻修时房间行的对应键不存在，改写位置量也违反卷二的写权（类 1、4）——一审第 8 条未改好，**新真问题，需报李白**
- 位置：卷十九 §4.4 规则 3 ④（L495）、§3.3 建行写者一行（L250）、A19-10.2 末段（L765）、Q26；卷二 §2.6"行改挂"第 7 点（卷二 L460）。
- 证据：
  - ④ 按"分区角色代号、同角色内的序号"对应房间，又说要"按新形制的布局"算房间集合。可是 `bform` 条目（L184）没有任何房间布局字段，房间行（卷五的 `comp_zone`）也没有分区角色这个维度。全卷 grep"分区角色"，只有 L495 和 Q26 两处在用它。`zrole` 是聚落布局模板的分片角色（L185），管的不是房间。
  - 对得上的房间行"照新布局整值重写位置量与面积"，这是在建行事务之外直接写位置量。卷二 §2.6 第 7 点与本卷 A19-10.2 都规定，这种写法报 E-VIEW-UNDECLARED-WRITE，计数为 0。Q26 只请卷五在说明里加一句，可写权的唯一定义在卷二，光改卷五解不开。
  - §3.3 L250 仍写着"一座建筑只建行一次"，没有写进 ④ 所说的"翻修是建行函数的第二种调用"，也没有"翻修时补建房间行"。
- 建议：① 在 `bform` 上登记房间布局，包括各房间的角色代号（开放族，本卷登记）与份额，房间行建行时存下这个角色代号，对应就只读它；② 写清位置量改写走哪条路：要么请卷二 §2.6 第 7 点把"原地翻修事务"列为建行写者可写的情形，要么对每个对得上的房间行调 `relocate(房间行, 建筑行, placement)`（这要求房间行所属组件类可改挂）；③ §3.3 L250 同步改写。

### N3 扩建砌入的料使"补缺修完回到新建值"不成立（类 5）——**新真问题，需报李白**
- 位置：卷十九 §4.4 规则 8（L516）、规则 11 表"扩建"一行；A19-4.2"扩建前后 `envelopeVolumeL` 逐位不变"；A19-1.2 补缺句"修到没有待办时……`envelopeMassKg`、`breachEnergyKJ` 回到用同样的料新建时的值（差在 1 升料之内）"；L338 `M_r = max(0, V − E)`。
- 证据：扩建往 `materialKg` 里加了料，`V` 却不变，于是 `E > V`。之后着火，只要烧掉的量少于扩建加进去的量，`M_r` 就仍为 0，不用补缺，质量也回不到新建值；烧掉的量更多时，补回的又只到 `V`，扩建砌入的那部分永久丢失。两种情形都使 A19-1.2 的补缺句被机器判为失败。
- 建议：二选一。(a) 扩建砌入的料，其升数在同一事务里加进 `envelopeVolumeL`，设计体积随扩建增大；此时 A19-4.2 的"扩建前后 `envelopeVolumeL` 不变"要改，§3.3 也要写明扩建是 `envelopeVolumeL` 的第二个写者。(b) 不动 `V`，把 A19-1.2 的补缺句改成"回到上一次建成或扩建之后的值"，并写明扩建砌入部分烧掉之后不补。推荐 (a)，它与"`V` 是修缮的唯一锚"的口径一致。

### N4 `stationFold.olderMinutes`、`olderCount` 没有读者，只为断言而存（类 7，原则：不为测试造设施）
- 位置：卷十九 L260、L455 ①、A19-3.2"逐条记录、`daily`、`olderMinutes` 三处的分钟总和等于……有史以来全部已结束占用的分钟总和"。
- 证据：日结只读当日，卷六只读窗口，卷二十七不读，全书 grep 这两个字段只出现在本卷的定义与这条断言里。它们唯一的用处，就是让那条"有史以来总和"的断言成立。
- 建议：删去这两个字段。保留期之外的逐条记录和 `daily` 各日直接删掉；A19-3.2 改为"保留期内每日每类的分钟数折叠前后逐位相同"，这一句已经在了。

### N5 换料可回收量按累计量取差后，与"读有效值"冲突（类 5）
- 位置：卷十九 L345（`S_k(d) = floor(W_k(d) × salvageFraction_k)`，`salvageFraction` 读有效值，卷三乙 M-12），A19-1.2"一笔之内任一时刻，料 k 的累计取出恰等于 `floor(累计换出质量 × salvageFraction)`"。
- 证据：有效值会随修正项变。一笔修缮之内，只要两次提交之间 `salvageFraction` 变了，各次差值之和就不再等于"floor(累计 × 当前值)"，切分不变也随之不成立。守恒本身不受影响（每次差值都在 0 和换出量之间）。
- 建议：改动很小。在 `repairLot` 开笔时把各料的 `salvageFraction` 存进配额，一笔之内用这个值；或者只把断言的前提写成"一笔之内各料 `salvageFraction` 的有效值不变时"。前者要加一个存储字段，后者只改措辞。

### N6 负荷的分母取"开放时段"，与 A6-10.2 冲突（类 5）——**新真问题，需报李白**
- 位置：卷六 §4.10 规则 1"分母"（L734）、§2.3 `stationLoad` 一行、A6-10.2（L757）"在零与一之间""窗口内每天排满的单席装置负荷为一"；卷十九 `openSpan`（L109、L162："对公众开放时段""null 即不对公众开放"）、§4.12 规则 2（L823）。
- 证据：
  - 分子是全部占用分钟，不论是否落在开放时段内（规则 8：占着就算）；分母却只算开放分钟。一座只在白天对公众开放、夜里有人看炉的炉子，负荷会大于 1。
  - 不对公众开放的私人作坊 `openSpan` 为 null，分母为 0，负荷恒为 0，天天排满也是 0。
  - 这两种情形都与 A6-10.2 的两句新断言直接矛盾。`openSpan` 是进入门槛的时段，不是工位可用的时段。这个口径沿用自第五版，但这次重写规则 1 并新增断言之后，矛盾才变得可以被机器判定。
- 建议：分母改为"这些装置的席数之和 × 窗口内的全部分钟"，与卷十九 §4.15 `ops.utilization` 的分母同一口径；L752 月相祭炼台一例改说"开放的时候席位被抢占"，不再依赖开放分钟。如果确实要把开放时段算进去，就把分子也裁到开放时段内，并写明 null 时取全天。

### N7 预置墙料放在聚合账户上，可被统计层花掉，"余额为零"也无从判定（类 7）——**新真问题，需报李白**
- 位置：卷六 §4.1 规则 5"物化建行"（L356）、A6-1.2"全部地点物化完毕后各聚合账户上……预置墙料的余额为零"；同卷 §4.7 规则 12（L629：统计层生产的投入从阶层聚合账户记去处）、§4.12 规则 9（L829：统计家户以聚合账户结算）。
- 证据：预置的墙料是普通物品，与阶层的其他财物混在同一账户、同一种资源键里。统计层的生产和家户消耗可以先把它用掉，到物化那一笔时，"砌入的料记出"就会透支，被拒，物化失败。而且墙料与同种的其他物品不分，"预置墙料余额为零"无法单独计算。
- 建议：预置墙料记进聚合账户的一个专用用途分区：`purpose` 族新增一行，`spendable` 为假，`visibleToMarket` 为假。统计层的生产、家户与市场都不能动用这一分区；物化时只从这里记出。A6-1.2 的"余额为零"改成指这个分区。只需在卷六加一行词表数据，不新增存储结构。
