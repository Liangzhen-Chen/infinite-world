# 落点对象 rules 的改写规则（乙-1 卡 1115y1c）

裁定：卷十一 §2.3 的六类（表代号、词表族条目、规则表键 rules.*、系统登记项键、模块组键、门禁设施代号）是封闭清单，不加新类，不改 R11-2.5。所以迁移行的落点对象不能写 rules（规则层）。机械改写规则如下，由 脚本/卷十一/rewrite-rules-object.mjs 执行，不手改。

对象为 rules 的每一行，按这行的落点（target）定：

1. 候选集合：
   - 落点里出现规则表键 rules.xxx（可带子键，去掉末尾的 .*）：每个键是一个候选，类别是规则表键。
   - 落点里出现规则号：R、S、A、C 加卷号再加 "-" 的写法（如 R9-2.4、S6-6、A19-2.2、C11-5），和显式的卷名（如"卷十七 §4.11"）：每个被指的卷是一个候选，取该卷在卷二 §2.7 补全表（乙-4 补，审查/脚本输出/乙4补-systems补全.json）里的系统行的系统键，类别是系统登记项键。写"规则 n"而没有卷号前缀的，属本行所在卷。只写"§x.y"没有规则号、也没有卷名的，不产生候选。卷号 3 分不出甲乙，不猜。
2. 候选恰好一个，并且没有对不上系统的引用：取它。
3. 没有任何候选：按卷二 §2.3 原文取锚点文件所在的模块组键。锚点文件全部解析到同一个已登记的模块组（inputEdge、gate、outputGate、aiGate、kernel、host、display）才取；落在规则层（server-plugin 根目录等不在任何已登记模块组的文件）、tools、tests、world 或解析不到的，不取。
4. 其余情况（候选多于一个、候选对不上系统行、没有候选而锚点取不出）：不猜，卷文里该行的落点对象保持原值，列入 审查/脚本输出/乙5-rules待裁清单.md，由李白逐行裁定。

系统键现在是卷二 §2.7 补全表的临时名（各卷 §3.1 首个读入口名），李白定名后整批替换。
