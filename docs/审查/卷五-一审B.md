**B-03 同一块地在包含树的各层重复计入存量与栖地容量**
- 位置：§4.7.3 规则 1、2（466–471 行）、§4.3.3 规则 3（312 行）。

**B-08 存量余额上界的不变量会被正常规则打破**
- 位置：A5-7.2（496 行）、§4.7.3 规则 2 第 3 项（470 行）、规则 6（479 行）、§4.8.3 规则 5（531 行）。
- 类别：5、7
- 证据：A5-7.2 要求余额在 [0, 有效容量 + 最小重启量] 之内。但以下三种正常情况都会让余额超出：①捕食者的容量随猎物现存量下降，当天捕食者余额就高于新容量；②取用伤及繁殖群后 persistence 下降，有效容量跟着降到余额以下；③扩散转入。断言写的是"恒成立"，而规则本身允许越界，机器判定会误报。
- 建议：断言改为"再生入账只在余额低于有效容量时为正；余额高于容量时只降不升"，并写明超出部分怎样处理（自然死亡入 sink，还是只停止增长）。

**B-09 persistence 的扣减式单位不一致，而且会除以 0**
- 位置：§4.8.3 规则 5（531 行）、§4.7.1（446 行"百万分比"）、A5-8.2（549 行）。
- 类别：5、7
- 证据：扣减量 = `… × taken ÷ (栖地容量 × persistence)`。persistence 是整数百万分比，这个式子算出来的是无量纲分数，没有换算就直接相减。persistence 到 0 时分母为 0；栖地容量为 0 时（例如 B-08 中猎物取光）也一样。
- 建议：把式子改写成定点运算，写明百万分比的换算；规定分母为 0 时 persistence 直接置 0。在 A5-8.2 里补上"分母为 0 的分支"用例。
