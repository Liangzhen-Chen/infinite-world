2. 燃烧扣减（877）每日 `materialKg[k] × b` 截断一次、不带余数。每日只结算一次、无法拆分提交，扣减与放热逐笔守恒，误差每料每日小于 10⁻⁴ kg；建议补一句误差界，或按第 3 条"末项取差"写。

4. 收起态劣化（653）要逐日结算 `portableState` 的 `condition`，但搬运清单只有"收起时刻"，没有结算到哪天的字段（原 `facilityState.lastSettledDay` 在终止第 1 步被删）；补 `lastSettledDay`。

6. 密度换到千克每升时，若卷三 `density` 以 kg/m³ 存且带小数，换算会截断；作者已把"density 精度不高于 4"列入卷三牵连，口径收尾对齐。
