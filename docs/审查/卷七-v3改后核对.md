## 四、(c) ④偏离——作者对

卷二 §3.5 作用域表（卷二:1133–1144）：
- `self`：来源自身，直接（:1135）。
- `integrated`：持有融入度记录、记录所指文化**即来源文化行**的个体；解析是主体 → `state.cultureIntegration[主体].culture`（:1143）。
- `mounted`：来源是组件类条目，主体是材料行（:1144），与本题无关。

`integrated` 的来源是文化行 L，一条修正项会作用于所有记录指向 L 的人。修正项的 `value` 是定值；`valueRX` 只能经 dim() 读来源与对象的基值（卷二:1045），读不到 `level`（那是状态记录）。所以挂在 L 上只能是同一个值，做不到逐人不同的 `level × (L − B)`。二审 N4 建议写的是"`scope: self`（或 `integrated`）"，裁定取 `integrated` 时显然没看到这一点。作者改为以个体为来源、`scope: self`，是卷二已有的作用域，不改机制，这样才写得对。卷二 §3.4"同一 (source.id, target, subject) 只计一条"（卷二:1129）：卷二十六 R26-2.2 的价值牵引修正项以人格轴条目为来源（卷二十六:489），不会和个体自身作来源的项相撞，A7-24.1 已把别处的提交者扫成 0。

遗留：卷二:1143 的 `integrated` 一行现在没人用，而且还写着"卷七 R7-24.8"，引用已经过时。是否撤回已封卷要李白定，已记 Q15，本卷不用改。

## 五、小项（措辞/类型写法，不阻断）

1. §2.6 `placeClass` 的类型写成 `ref class（组件类句柄）`（卷七:265）。卷二:226 规定组件类是单独的 `component` 族（`comp_`），与 `class` 族分开登记，`classes` 字段类型是 `set<ref refs[vocab class, vocab component]>`。按字面，`ref class` 会让加载校验拒收 `comp_settlement`。建议改成 `ref vocab component`；如果想同时允许 class 族，就用同一种 refs 写法。改这一格即可，牵连只有自检第 13 项若核了类型串。
2. A7-24.2"`level` 为 0 的键不在"：`level` 是按记录取的值，不按键分，宜写成"`level` 为 0 时一条都不在"。另外，`level` > 0 但定点乘截断成 0 的键，按 R7-24.8 ② 仍提交一条值为 0 的项，与 A7-24.2"各一条"的说法一致，① 里"值为 0 的键不提交"只指建记录时，读者可能会混。属措辞，可记账。
3. §5.2 卷二行 ⑦ 前半仍写"供 R7-24.8 的价值混合修正项用"，后面紧接"第三版起改用 `self`"，有覆盖句，不算矛盾。
