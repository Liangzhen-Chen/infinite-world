### (a) Q13-2 作者解释是否合裁定原意

- 裁定原文（收尾待办.md:274）："逐层先减 + 环世界式每层一次随机（弹开/转钝/穿透，标出处 03-环世界.md:164）"。
- 出处原文（`docs/统一底层调研/03-环世界.md:164`，第 10.2 节"护甲与保暖"）讲的是**穿戴护甲**：护甲值 = 物品倍率 × 材质 × 品质，逐层从外到内；先减穿透，再与 0–100 随机数比，低于剩余护甲一半弹开、一半到全额减半转钝、高于护甲无效；例 90% 护甲对 10% 穿透得 40/40/20。
- 现文 R13-3.4 :622–640 的护具层写法与出处逐项一致：`E` 是剩余护甲（防护量减当前穿透量，按 `armorScale` 折万分点、钳 200%）、三段阈值相同、穿透时不扣穿透量。我用现文数复算 §4.3.5 :653 三种抽签：钢刃 5600；铜刃 u=1200 弹开 0、u=2500 转钝 3300、u≥3400 穿透 5600，全对。
- 判断：**护具层合裁定、合出处**。**组织层不抽**是对"每层"的收窄。理由"组织吃掉的量就是伤，不存在弹开"对皮、肉、骨成立；但本卷 R13-3.1 :619 把天生的鳞与壳也定为组织层（"不另设天然护甲"），§4.3.5 :655 穿山兽例即此——对鳞、壳这类"天然护甲"，裁定所附理由"穿透量略低于甲的兵器永远 0 伤，不真实"（:640、:1493）同样适用，而它们仍是确定减法。是否接受这一收窄由李白定；作者已在 :1606 标"报李白知悉"，不算未改。

### N1【新真问题，需报李白】统计形态的俘获没有存法
- 位置：R13-11.7 :954；C13-18 :1412；§2.4 :255
- 类别：1（缺存法）、5
- 证据：第一版 R13-11.7（v1:927）统计形态俘获是"一个被俘聚合体"。第二版删去俘获持有种类后改为"统计形态只记 `captured` 人数并写进结果事件，人在实体化时（卷二十七换层）逐人经 `custodyStep` 收押"。但这些人既不经 `popApply` 改记或迁出，也不进卷八b 的任何统计层羁押记录，会战记录收场后也不再被读；败方聚合体里他们仍是普通成员，照样在场、劳作、下次参战。实体化时也无从知道聚合体里哪些人、多少人是俘虏，卷八b R8b-12.2（卷八b:987）要求的"同一事务里的制服事件"在那一刻也没有。"俘获"在统计形态下对世界没有任何持续作用，与 R13-11.12 把俘获计入战争分值、R13-19.1 快照记俘获人数都对不上。
