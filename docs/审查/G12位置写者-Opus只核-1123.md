## 2. 液体柱 fallStep —— 起点在液体里过；**从空中落进水里仍穿河床，仍须改 1**

fallStep 按 `c.state === STATE.solid` 与 `standable` 判，不认 id、名称；settleCell 以本格 `c.state === STATE.liquid` 开 sinkOnSolid；已在柱底时 fallCell 落点 z 等于起点，settleCell 返回 stay，不会每次结算反复"坠落 0 m"。"液体柱坠落"用例：z=5..3 液体、z=2..1 实体、z=0 洞，起点 z=5 落 z=3，不进洞，气态起点对照落 z=0，与裁定"沉到河床上、不穿河床"一致。用例是把 fallCell 的逐格循环抄进测试跑 fallStep（真实 gridView 读不出液体格），这一点与第一轮对 settleKindOf 的判法相同，可接受。
**缺口**：sinkOnSolid 只由起点格定。人从空中坠落（桥上、崖上掉进河）时起点是气态，sinkOnSolid 为假，往下经过水格（不可立足、非实体 → none 继续）、到河床实体仍不停，照旧穿过河床落进下面的洞或到底返回 none——正是裁定要堵的"穿河床"。改：fallCell 逐格下行时，一旦经过液体格即把 sink 置真（"人在液体格"含落进液体的那一刻；仍只按物态类判）；补一列用例：z=6 气态起点、z=5..3 液体、z=2 实体、z=0 洞，落 z=3。卷五 1122k1 勘误句"人在液体格时"已覆盖此情形，不必再改卷文。
