# 决策

## 2026-10-10：采用 v2 工作流程
以开发指南 v2 为执行依据，当前工作按 M0 至 M8 推进。用户随后要求清理全部文件，旧指南与历史记录从目录移除，保存在 Git 标签 `snapshot-20261010`，不再继续追加。

## 2026-10-10：发布构建与最终构建
`build:release` 保留结构、引用、原创屏蔽、年龄和法术处理器检查，暂不检查目录数量。`build:final` 保留原数量门槛；旧 `build-world` 和 `--engine` 调用继续兼容。最终内容质量与 LOD 规模仍需单独验收。

## 2026-10-10：生产资源与测试独立
运行时旧版核心与种子放在 `server-plugin/legacy/`；冻结测试夹具继续留在 `tests/fixtures/legacy/`。项目直接声明 YAML、Express 和 Playwright 依赖，测试不再借用酒馆的安装目录。

部署包隔离导入首次暴露 opencc-js 缺失，补带依赖后又暴露草稿审查文件不符合部署路径规则。原因是原打包器遗漏运行依赖、却递归包含未发布草稿；现只随包附带所需依赖并排除 drafts，保留原路径校验。

## 2026-10-10：已有偏好
其他玩家模拟与死亡包裹掉落默认关闭。DeepSeek 仅使用环境变量 `DEEPSEEK_API_KEY`，不读取酒馆密钥文件。

## 2026-10-10：磁盘迁移
主项目以 `F:/dnd` 为准，本次改动从 Codex 独立工作树同步回主项目。项目路径由脚本所在目录解析，浏览器检查截图不再写入旧项目的绝对路径。Chrome 的安装盘符与项目目录无关。

## 2026-10-10：按用户要求瘦身
删除旧开发文档和审查导出，历史由 Git 快照保留。草稿仅保留最近结果及相应审查，缺陷回归样本移入测试夹具。主项目保留最初备份、最近一份旧备份和本次校验备份；酒馆本体、运行依赖及用户数据保留。

## 2026-10-10：M1 真实试玩失配分析
首次运行遗漏酒馆 DeepSeek 提示转换，不能计作验收。改用已安装的 semi_tools 转换后，账本断言仍只有 89/147，多个动作直接被叙述完成而没有调用。
补强通用执行指令的一次定向检查仍未产生移动调用，继续堆叠禁令没有证据支持。现有示例只展示结算后正文，可能示范了省略执行；下一步用实际引擎产生的调用示例做对照，并按 9.7 比较思考设置，不调整通过阈值。
并发归档冲突已通过同一路径共用在途写入修复，16 个注册器并发测试通过。思考评分在 4,000 token 内多数未返回 JSON，需显式低推理强度并保留截断状态，不能记为评分成功。

调用示例和低强度思考各一次单步检查均产生正确移动调用，不足以选择最终设置。先采用非思考模式加完整示例：由正式引擎生成示例回执，写进角色卡扩展字段，通过酒馆提示事件与试玩共同注入，六段文风示例保留原用途。试玩也改用酒馆的具名 system 示例，避免示例角色差异。

连续住宿试验发现服务参数使用自由文本，模型把“普通客房”传入后收到无关的缺物品错误，最终耗尽调用次数。现限制 service 为已登记的“住宿”，引擎提供可纠正参数错误，不把失败转成成功。生成中断后仍评估所有预定账本断言，防止成功扣款却没有正文的回合被漏记。

## 2026-10-10：按实测缩减工具入口
对上一轮 125/149 报告标注明确动作及条件分支，共 38 次调用机会；3 次未调用、2 次把学习配方换成练习技能，分别为 7.9% 和 5.3%。未学会法术的施法回合排除在分母外；参数错误和正常工具拒绝不计作选错工具。两次明确职责错误已触发指南 7.2 的合并门槛，不能用 34 次拒绝代替这个比例。

入口由 31 减为 25：天气、农事、动物、环境与巢穴合为 world_field；宠物与召唤合为 world_companion；偷窃并入 world_law。共用路由仍执行原领域操作，原事件名可回放，不改存档格式。部署包带上同一工具模块，快速场景提示与断言也使用对应路由。

地点目录支持查询和分页，场景卡给出相关地点编号；未知名称仅建议候选，不自动把相近对象当成同一对象。“门柜小铰链”添加“铁铰链”“铰链”两个别名，其他物品资料不变。认罪缺少 authority 时返回在场执法者候选，查询区分已报案与已自认。

叙述评分保持思考模式，改为两回合一段、附前两回合上下文，单段预算 9,000 token；这不改变游戏回复 1,800 token 上限。任何分段失败都不生成整场分数，引用须与该回合原句一致；最终仍需按指南抽读，不能把模型评分当作已人工验收。

## 2026-10-10：生成设置对照与状态可见性

原十会话以同一世界种子运行四种设置，每场一次。非思考温度 0.6、0.8、1.0 为 141/149、142/149、142/149，低强度思考为 147/149。相对非思考 0.8，回合中位耗时约从 2.6 秒增至 3.4 秒；选择低强度思考，温度 0.8。预设和试玩共用生成设置，输出上限保持 1,800 token；截断算失败。新版视图隐藏推理区，不改变其他聊天显示。

该对照使用安装版酒馆的真实 DeepSeek 转换，工具历史由宿主补空推理字段。仅给预先选定的住宿、制造评分，八份中三份完整，整批费用上限约 3.75 元。新赊账逻辑与最后两条提示约束在对照启动后加入，结果不能冒充最终验收。

赊账使用实际欠款记录和商家限额；到期不自动扣钱，偿还需要明确操作。续住接在原有效期限之后。沿用 records 结构，不升级存档版本，不补写旧记录；修改前已做校验备份。定向模型场景通过不等于叙述无误，债务编号泄漏和等待时长偏差继续留在问题文档。

三场复测 58/59，模型将次日上午十点换算成错误分钟数。world_time 增加 until 日期钟点，由引擎计算时长，minutes 保留原用途；公开活动用枚举以免漏掉休息恢复，不改历史调用语义。单回合真实调用验证准确到十点，完整流程待复验。评分器另改为附全部此前回合证据，避免截断上下文误判早先付款；已通过回归，未改写既有评分结果。
