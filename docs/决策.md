# 决策

## 2026-10-10：采用 v2 工作流程
以开发指南 v2 为执行依据，当前工作按 M0 至 M8 推进。用户随后要求清理全部文件，旧指南与历史记录从目录移除，保存在 Git 标签 `snapshot-20261010`，不再继续追加。

## 2026-10-10：发布构建与最终构建
`build:release` 保留结构、引用、原创屏蔽、年龄和法术处理器检查，暂不检查目录数量。`build:final` 保留原数量门槛；旧 `build-world` 和 `--engine` 调用继续兼容。最终内容质量与 LOD 规模仍需单独验收。

## 2026-10-10：生产资源与测试独立
运行时旧版核心与种子放在 `server-plugin/legacy/`；冻结测试夹具继续留在 `tests/fixtures/legacy/`。项目直接声明 YAML、Express 和 Playwright 依赖，测试不再借用酒馆的安装目录。

部署包隔离导入首次暴露 opencc-js 缺失，补带依赖后又暴露草稿审查文件不符合部署路径规则。原因是原打包器遗漏运行依赖、却递归包含未发布草稿；现只随包附带所需依赖并排除 drafts，保留原路径校验。

## 2026-10-10：已有偏好
其他玩家模拟与死亡包裹掉落默认关闭。DeepSeek 仅使用环境变量 `DEEPSEEK_API_KEY`，不读取酒馆密钥文件。

## 2026-10-10：磁盘迁移
主项目以 `F:/dnd` 为准，本次改动从 Codex 独立工作树同步回主项目。项目路径由脚本所在目录解析，浏览器检查截图不再写入旧项目的绝对路径。Chrome 的安装盘符与项目目录无关。

## 2026-10-10：按用户要求瘦身
删除旧开发文档和审查导出，历史由 Git 快照保留。草稿仅保留最近结果及相应审查，缺陷回归样本移入测试夹具。主项目保留最初备份、最近一份旧备份和本次校验备份；酒馆本体、运行依赖及用户数据保留。
