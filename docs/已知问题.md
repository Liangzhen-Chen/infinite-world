## 压缩包之外的审查

play-town.js 的连接测试固定模型和参数，没有读取游戏当前参数；成功只能说明一条简短中文请求成功。页面没有角色创建、存档管理和语音设置，属于阶段 6 范围。

启动酒馆.ps1 已限制监听回环，后台进程隐藏；启动备份不含设置文件、配置文件和开始页面，也没有哈希验证。新增 backup.mjs 覆盖这些文件并验证副本。后续部署时仍需更新启动器。

configure-server.mjs 关闭密钥暴露、监听局域网和自动打开浏览器；配置中 enableServerPlugins 当前为 false，阶段 1 的部署需显式开启自有插件并关闭插件自动更新。

install-campaign.mjs 会覆盖运行时种子和世界书，且在检查角色是否已存在之前已执行覆盖。refresh-campaign.mjs 也直接写设置与世界书。它们不是版本迁移器，重构期间停止使用，后续以构建及部署脚本替代。

playtest.mjs 与 check-browser.mjs 使用已保存的酒馆连接，旧脚本不统计 API 花费和缓存；前者只测租房、照明和导入，创建分支时还复制已有事件。后续测试仅从环境变量调用，使用隔离夹具和费用上限。

## 1.4.7 思考模式核实

阶段 0 本地传输探针证实当前酒馆前端发送 include_reasoning:false，已安装后端显式写 thinking.type:disabled。此项没有发现指南推测的“仅隐藏而仍启用思考”问题。思考/非思考模型质量与 temperature 的效果比较仍未执行，属于阶段 5。
