# 首领实现与未完成项

依据指南3.8.4及第13章阶段2。四个低阶首领骨架仅位于world/design/boss-foundation.mjs，不是正式图鉴；world/meta仍0首领。正式内容必须补40个覆盖九阶的完整档，含8智能存在，并经过第10章起草与随机精读，不能用这四个夹具满足数量或世界规模。

bosses.mjs负责巢穴接触、已见战术防备及败亡后的空巢更替。战术由实际进攻或成功伤害法术分类，模型不能提交伤害或任意防备数值；换战术不继承未见的计数。同种进攻两次后每阶段降低伤害10%，最高30%；推搡降低命中，重复逃离提高检定门槛。此次未逐项验证全部魔法门类、推搡/逃离统计分布或完整装备战术，因此不能称全战术平衡完成。

原首领接触后保持同一实体，不靠再次进入重置血量或记忆。部下从当地未见种群扣除，只接触而未攻击不会给材料。原首领败亡后巢穴空置；达到指定天数才能从当地现存的另一物种迁入，物种耗尽则继续空置。原首领死亡、尸体和记忆保留；迁入者是不同编号和物种。迁入者也可再次死亡，下一轮按巢穴延迟处理。首领离开/改变归属后不能在原洞口隔空接触或复制，日结登记空巢。

迁移建立可选records中lair分区并补旧首领已知身份标签，不覆盖原健康、所有者、财物、人物记忆或旧战术。不回填过去战斗；已有死亡从当前日期开始计算以后更替。独立CLI只写新副本，可使用配套世界归档，拒绝版本不符、已有输出和secrets路径；原档不变。公开records不透露巢穴内部状态和战斗记忆。

共享tacticDefense用于实际交锋及战斗模拟器。首次带学习后的五人参考战胜率6.89%不合格，失败报告保留；搜索后独立生命倍率5.45仅在bossEcology启用时生效，旧规则保持7.5。三个种子各六组各10000次，五人60.61%、60.20%、61.09%，单人首领0%，全部参考目标通过。参考场景不是四个低阶首领各自的完整平衡报告，也不包含所有法术、队伍指令和战术组合。

首领还缺正式来历文本及完整弱点效果、部下协战、外交/贸易/联盟、智能首领的势力目标和成长。季节迁徙、农田害兽、季度/年度怪物觉醒尚未实现。新增巢穴机制仍未在玩家酒馆启用，阶段2至8未完成。
