## 偏离
- 分片文件名：卡文写 state-owners.d/time_env.json、entry-registry.d/time_env.json，加载器分片名规则 /^[a-z][a-z0-9-]*\.json$/（server-plugin/rules/load/registry-shards.mjs:61）不收下划线，改名 time-env.json，内容不变。
- 缺口不逐次 report：卡文 6 闸写「旧 report 改用 kernel/errors.mjs#report」。kernel/errors.mjs#report 只收登记码类型 ErrorCode，规则层要拿到它得引 kernel/handles.mjs#errorCodeOf，而该入口在主登记表 tools/accept/entry-registry.json 里 file 写的是过期路径（kernel/handles/vocab-handle.mjs，主文件不许改），新引会使 entry-registry --check 的「状态文件中的文件函数不在表里」比 master 多 1。改为缺口代号进返回值（Fact.gaps、Now.gaps），不逐次报 W-DIM-GAP；菜单每次 view 都报也会刷日志。读不到仍是 null 加缺口，没有兜底。
- 天气单元组件类登数据：卷二十:335 写明「挂 comp_weather_cell」，规则层原有先例不写组件类代号（rules.gen.roleFacility），本卡加 rules.season.cellClass 一键（卡文清单外，硬规矩 10 扩数据表）。
- 卷二十勘误（主会话另补卷文）：历法行 dayParts（Q2）、新词表族 solar_term（Q3）、日历模块路径 kernel/calendar.mjs → rules/time_env/calendar.mjs（Q6，L0 已满）。
- 门禁夹具四个只换路径（见改动清单），用例行与极性不变。
