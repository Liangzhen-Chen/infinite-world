## 写码期裁定（主会话 11-26 回复）
- A：不改 jsconfig；主会话装 @types/express@4.17.25。
- B：3a 生产入口为 world.act(intent)；菜单投影与可见集为 world.menu(subjectId) → {affordances, visible}（3a 提供）。不静态 import rules/act/*。
- C：载荷判别字段 kind 改名 payload。理由：卷二:976 未给判别字段名，草案 Q3 取名 kind 与全仓「实体 kind」同名撞义；pp_kind_branch 检测器正是为实体 kind 分支设的，命中的 byKind[body.kind] 实为线协议封闭枚举 menu_payload 的分流；改名消除撞义，不是换写法躲检查。出题方烟测由主会话通知同改。

- D（11-26，commit 钩子被旧验收测试 init() 的 TS2554 拦后）：init 的 router 参数改为可选。卷二:1033 原句：「它只做一件事：把 SillyTavern 以参数传进来的 `router`、从 kernel 与 textcore 取得的能力对象，交给各组的挂接函数」；本卡口径：宿主按位置传 router 时照挂四路；宿主之外的调用方（tools、只要引擎的单测、离线复演）本就没有 router，不给即「无路由模式」——照常装配 engine/state/logBook，只是不挂路由（server-plugin/index.mjs:92）。这是偏离（装配文件多一个条件，卷二:1033 不许条件），审卡判。
  **已撤回**（主会话 11-26 审卡第一轮后：出题迁移合入后全仓已无不传 router 的调用方，删除优先；且漏传 router 的宿主会静默不挂路由）：server-plugin/index.mjs:88 起 init(router, opts) 恢复必传，删无路由分支，JSDoc 同改。
