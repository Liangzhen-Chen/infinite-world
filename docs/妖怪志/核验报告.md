## 发现的规律与遗留问题

1. 名称 OCR 误字集中在生僻字：狨→诫、伥→依、𤢗→孺、鲿→蟆、褦襶→襁禰、馗馗→尴尴、羊魃→羊魅。未抽到的名称存疑条目可能还有同类错误。
2. 书名误字：养疴漫笔被识作养疳漫笔。另有书名写法差异（觚剩/觚賸、醉茶志怪/醉茶誌怪、异域志/异域誌、冤魂志即还冤记），不算错误。
3. 卷次错误多出在多版本书：法苑珠林所引白泽图条在卷五十八，整理本标作卷四十五（贾诎、罔象两条，未抽到的同类条目可能也有此误）；左传昭公六年应为七年。
4. 有些引注只能证明书里有相近的东西，并没有这个生灵本身：周礼只有庭氏射夭鸟，没有姑获鸟；酉阳杂俎前集卷四没有白骨妖事。这类出处已删除。
5. 维基文库的夜航船只有目录没有正文，埋忧集、异闻总录、枣林杂俎是残本；清东轩主人述异记、闲窗括异志、稗史汇编、集异新抄、庸庵笔记、天妃显圣录、偃曝谈馀查不到公开全文。引这些书的条目大多标为未能核实，等有原书时再核。
6. 重建保护：核验结论已写入 world/drafts/yaoguai/overrides.json（排除名单 3 条；199 条核验结论及核正字段，按 id 记录）。tools/yaoguai-index.mjs build 发现 index.json 已含核验字段时会拒绝覆盖，加 --force 才重建，重建时先套用 overrides。已用 --force 重跑验证，生成的 index.json 与核验后的版本逐字节相同；motifs.json、candidates.json、stats.json 和 docs/妖怪志/古籍书目.md 随之按核验后数据重新生成。
