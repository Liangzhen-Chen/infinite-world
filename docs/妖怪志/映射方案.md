# 妖怪志映射方案（YG-1 草案）

本文是 YG-2 映射设计的起点。数据都由 `node tools/yaoguai-index.mjs build` 从整理表与自拟标注生成，文件在 `world/drafts/yaoguai/`：`index.json`（事实索引）、`motifs.json`（母题目录）、`candidates.json`（物种与个体候选）、`stats.json`（分布统计）、`vocab-proposal.json`（建议词汇）、`tagging/`（逐条自拟标注，构建输入）、`pinyin.json`（生成 id 用的拼音表）。古籍书目见 `docs/妖怪志/古籍书目.md`。

版权边界：整理本是张云《中国妖怪故事》，其白话文字只在构建脚本的内存里读取。仓库里只有名称、类别、朝代、古籍出处和自拟的短标签。`node tools/yaoguai-overlap-check.mjs` 把仓库输出与整理本全文逐 8 字比对（只比汉字，跨标点也算连续，古籍出处句除外），当前命中 0。YG-3 撰写时以古籍原典为依据，不看整理本的叙述。

## 1. 清洗结果

整理表共 1228 行。其中 246 行是书眉（名字栏为书名加页码），另有脚注、编者注各若干行。这些行若带正文，就是上一条跨页的续文，已并回上一条；空行丢弃。清洗后得到 953 条。

名称修正：名字栏的 OCR 噪声（“鬼父e”“Q人鱼”“SL”“M 神”“2”等）先由脚本去掉页码与杂码，再按正文和原典逐条认定规范名，约 120 条改了名（如 皎人→鲛人、躯人→貙人、旱魅→旱魃、SL→犼、M 神→厕神、B 疏→䑏疏、2→兕），理由记在各条的 `OCR修正` 字段。认不准的 24 条标了 `名称存疑`（例：鳝男、贾诎、江依、黑眚、瞬→䍶䍶、貌），YG-2 需要对照原典复核。没有一条因正文残缺而无法识别；铁塔神正文被截断、家鬼缺古籍出处，已在备注中注明。

去重：名字栏里四组同名（蛟、鳍鱼、貌、木龙）核对正文后，前三组其实是 OCR 把不同的字认成了同一个字（蛟与蚑、䱻鱼与鮨鱼、貌与貘），按不同妖怪保留。改名后同名的有三组：蟡（《搜神记》与《管子》两处记载，是同一种涸水之精）已合并，合并来源序号 160、312；木龙（湖中巨木精与随船大蛇）和鵸鵌（《山海经》基山与翼望山两种同名的鸟）不是同一种，分开保留，登记在 `tools/yaoguai-defs.mjs` 的 `DEDUP.keepApart`。最终 952 条。

整理者拟名：有 5 条的编者注说名称是整理者所取（如目目童），原典没有确切名称。这类名称可能被视为整理者的创作，YG-3 应另起名称，已在 `作者拟名` 字段标出。

多妖一条：绿郎与红娘、语忘与敬遗、媪与鸡宝、鹤民与鹄民、金牛与银牛、满财与忽与室童、忌与作器等，一条讲了几个妖怪，各名列在 `成员` 字段，暂按一条处理；YG-2 决定是否拆分。

id：`yg_` 加名称的无调拼音（如 yg_a_zi、yg_bai_gu_yao），同音的依次加 `_2`、`_3`（共 19 个）。id 依赖整理表的行序与 `DEDUP` 表，两者不变 id 就不变。`yg_` 是知识条目，不是实体；落为实体时另用 monster_/pop_/boss_/npc_ 前缀，并以 `yaoguai` 字段回指。

## 6. 建议的词汇扩展（详见 vocab-proposal.json）

- 性状：标注只用了 traits.mjs 现有的 CREATURE_TAGS 与 ELEMENTS，没有新增性状词。spirit 304、beast 201、humanoid 214、undead 155 用得最多。
- 新标签族 `motif:*`：53 个母题各有英文 tag（如 motif:shapeshift、motif:haunting），供反应规则订阅。
- 新标签族 `habitat:*`：37 个出没环境，能落到 biome 的复用 biomes.json 群落词，其余是地点类型谓词（宅院、厕所、灶……）。
- `harm:*` 扩展：现有 harm:injury、harm:property、harm:reputation 只覆盖杀伤、盗窃与毁物；建议新增 harm:illness、harm:mind、harm:haunting、harm:drought、harm:flood、harm:epidemic、harm:soul、harm:childbirth。
- 动词：互动方式多数能用现有动词（deceive、marry、trade、gift、harm、tell、cast、pet、pact、summon）；建议新增 possess（附身）、haunt（作祟）、exorcise（驱除收服）、offer（供奉）。
- 特征前缀：形/能/弱/习/化 分别对应外形描写、能力、弱点与禁忌（修正项）、活动时间与栖地、化形与成精条件（灵智参数）。

这些词在 YG-2、YG-4 随规则或数据接入时再登记进 world/ontology，避免没有使用者的词进入词表。

## 8. 难点

1. 宅妖多于野妖。将近一半条目出没在宅院与人居，现有生态系统按栖地与种群建模，管不到“某宅某屋里的扫帚成精”。需要建筑与器物的年岁事实，再由时钟派生成精，这要等 S5。
2. 鬼类依赖阴间包。四分之一以上条目是鬼，阴间包没有建成以前，它们只能作书本与传闻条目，或者借用现有墓地亡灵怪物，后者会丢掉申冤、索命、超度这些核心母题。
3. 物种与个体的边界。169 条“两可”：名称是类名，正文讲的是一两个特定个体（狐妖、狼妖、龟妖）。派生优先要求同一个体由当前归属派生身份，所以两可条目最好拆成“物种模板 + 具名个体”两层；拆分规则要在 YG-2 定。
4. 《山海经》异兽占比大（129 条，“异兽记载”母题 234 条）。它们只有形貌与功用，没有行为与情节，作野外种群时栖地、作息、群居都要原创补齐，地名也要换成九省地貌。
5. 名称可靠性。约 120 条改了 OCR 名，24 条仍存疑，生僻字的拼音也有猜测（拼音表里已改正 蟡、䲹、䑏 三字）。存疑条目在 YG-3 撰写前要对照原典复核，否则 id 与名称会一起错。
6. 整理者拟名与现代工具书。5 条名称为整理者所取；3 种出处是现代工具书（《中国神怪大辞典》《中国鬼文化大辞典》《台湾之寺庙与神明》），只能用来回查古籍，不能作撰写依据。
7. 一条多妖、同名异物。成对条目要不要拆、同名异物（木龙、鵸鵌）的 id 区分，都会影响后续引用；现在用 `成员` 字段和 `DEDUP.keepApart` 记录，YG-2 定稿后不宜再改。
8. 母题与现有系统的语义差。报恩、复仇需要“欠情、怨恨”这类印象，现有立场是事件印象汇总，可以承接，但精怪对人的印象沿种群传导（动物复仇护子）还没有路径，要等 S6 的立场缓存。
9. 宗教敏感。PLAN 收录标准要求真实宗教中受崇拜的神圣存在一律不收、不改编，民间泛称的地方神职与自然精灵照收。妖怪志里有在世信仰的神祇（如梓潼神、七爷八爷、城隍、痘神一类）、佛典的饿鬼与地狱诸鬼（26 条饿鬼果报母题，多出《法苑珠林》《释禅波罗蜜次第法门》），也有《山海经》里只是山神形貌的条目。初筛按类型和出处一刀切，标出 105 条待审，误伤不少（如蚕女、河伯、雷公是否算在世崇拜对象各有争议）；需要 YG-2 逐条裁定，裁定结果也会决定阴间包能否用佛教冥府的结构（阎罗、牛头、饿鬼道），还是只用志怪里的泛称冥吏。
