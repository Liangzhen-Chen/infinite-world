## 七、反复把主会话叫醒的钩子

昨晚（11-16 晚）一遍遍出现的"Stop hook feedback: [持续推进无限世界……]: The condition is not satisfied…"有两层来源：

1. **Claude Code 内置的 /goal 会话目标**。旧会话按 AGENTS.md"开工时用 /goal 写下完成标准"设了目标。每次停下，它都用模型评估目标是否达成，没达成就把主会话叫回来。目标写的是"持续推进……直到完成"，永远达不成，所以会无限叫醒。日志里那种英文长段落"insufficient evidence… / The condition is not satisfied…"就是它。
   - **关法**：在会话输入框用 /goal 清掉或改写目标，例如改成某一张卡的完成标准，或者干脆不设。新会话设目标时要写**能达成的、具体到卡**的完成标准，并允许"所有余项都在等李白、亮圳或开机"时判达成。
