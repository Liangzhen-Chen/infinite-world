# 15 经济与货币：市场出清、货币与汇率、信用、远期、套利防线

（05 §5.1 保留"账户与义务怎样表达经济"，价格、货币、信用、估值全部在本章一处定义。原则：**价格、汇率、利率、银根、估值都是投影，不落盘**；账本仍是唯一的真相。修订历史见 修订记录.md：物品个体估值与劳务报价合并为统一估值 `value(x, frame)` + 估值表（§15.2）；计价单位可为任一资源、显示单位表（§15.3）。）

## 15.1 做到哪里、不做哪里

做：按数量出清的报价（滑点）、可售存量来自持有者的保留决策、**统一估值**（物品个体、生灵、土地与建筑、股份、债权、劳务都经同一派生与一张估值表，§15.2）、货币作为商品定价（汇率派生）、**信用货币的定价与超发贬值**（可兑现纸币、纯信用货币，§15.3）、计价单位由法典指定、**改币与退出流通**（§15.3）、购买力指数、钱庄的可贷资金与利率、破产清算（05 §5.2.7）、远期与预期、套利防线。
不做：订单簿与撮合（商品与劳务都不做）、逐笔报价的代理人行为（议价只在交易与雇佣动作里）、无准备金的信用创造（钱庄贷款只能把手里的钱贷出去，I2；纸币发行必须经 `src:issue` 发行守恒对并记准备金，§15.3）、金融衍生品、面额与找零（11 §11.1）。理由：11 §11.1——市场是投影，账本才是状态；上述"不做"的东西都要求存储报价状态或凭空产生价值。

## 15.1.1 价值有位置

账户没有自己的位置，但**账户所属实体有位置**（01 §1.2）：随身钱袋与行囊是 located 于本人的账户（用途 `carry`），仓库、柜台、公库、粮仓是建筑或聚落实体的账户，钱庄的现金挂在各网点建筑上。由此：
- **transfer 要求物理可达**：两端账户所属实体在同一节点（分区可及），或转移由显式载体承担——票据（bill 义务 + 代表物品，持票人到场提取）、托运（delivery 义务 + 车船在途）、钱庄汇兑（两网点间的内部 bill）。没有载体的远程转移被拒绝并给世界内原因（"钱在三郡之外"）。
- **obligation.settle 要求在场**：债务人（或其代理、代付者）与债权人（或其经营持有人、代收职位、网点）同节点；否则只能"寄汇"（创建 bill，由承运或驿传携带，到达后清偿）。配偶代还、第三人代偿同样要到场或寄汇。**无位置实体**（遗产、清算、工程、议案、政体与组织公库）以其执行人或 `seat` 为位置（附录 A §A.15 执行人）：工程托管账户在工地、遗产在宅第、公库在衙署；条款 `autoSettle` 的义务（工钱、俸禄、税）在 seat 内由到期项自动付，不需要发起人在场；遗产向钱庄支取存款由遗产管理人到网点办理或寄汇。
- **不在场债权人的清偿**：遗产与清算对不在场债权人的清偿进入**保管人**（程序 `escrowCustodian`：公库衙署或指定网点）账户的用途 `escrow:<义务 id>`（附录 A §A.15 托管与代收：义务与票据没有自己的账户，位置随保管人），凭证到场提取；到期未提取按法典程序归公或继续托管。**代收款项**：代收职位、自动征税的款项先落在征收地实体的 `collected:*` 用途账户，按程序 `remittanceDays` 解缴到 seat，公库可用余额 = seat 账户 + Σ collected。
- **承租人的存货**：承租建筑内的计量物记在承租人实体的账户、用途 `stored:<building>`（01 §1.6），位置取建筑——帐篷迁走了，毛皮还在仓里；租约关闭后按民事⑥ / ⑩ 处置。
- **汇票手续费与票据过关**：开票是出票网点的服务，手续费按网点经营条款 `billFee: {bps, min}`（`rules/tables/merchant.json` 钱庄行）同事务从本金扣入网点账户；票据随身过关**缺省不计关税**（价值未过关，在兑付地出账），法域要堵"带票不带钱"须在税表 `subjects` 显式列 `instruments{basis: represents}`（附录 A §A.7）。
- **总号与分号**：钱庄各网点各有现金账户；头寸调拨是托运或内部汇兑义务；总号倒闭后分号仍持有自己的现金，但 `branch` 持有随总号清算关闭 → 汇票的兑付前提消失 → 拒付 → 持票人的债权进入清算申报。

## 15.2 市场投影与出清

**报价**（显示用，同一刻内一致）：

```
value(地点, 商品类) = 基准(资源模板，以内部价值单位计，§15.3)
                   × 稀缺( 有效需求 ÷ 有效存量 ，钳制在 priceFactorLimits，弹性 ε 按商品类 )
                       有效存量 = 本地可售存量（批次按品质档；可售 = 持有者库存 − 自用保留）
                                + Σ 未到期、交付地为此、对价已付比例 ≥ 阈 的远期/托运义务 × 可靠度 × 时间折扣（§15.6）
                                − Σ 本地存量上已承诺的未到期交付
                       有效需求 = 近期需求流量 + 预期需求（季节、疫情、工程材料）+ 派生需求（工坊按配方 inputs × 计划产量的投入品缺口，闭式）
                   × 到岸成本( 最近有存量的供给地沿可通行路线：距离 + 运力 + 风险 + Σ 沿途关税与通行费；封关 = 无穷 )
                   × 季节(资源种类 × 季节表)
                   × 法域政策(规范栈税表与管制，含补丁，05 §5.2.8)
                   × 店家与关系(商号的 spread、立场、声望)
                   × 已注册修正项(槽 economy:price，05 §5.9)
```

显示报价 `quote` = value ÷ 计价铸币的 value（§15.3）。**买卖两个方向**：`quote(place, goods, side, business)`——`side: sell`（商号卖给顾客）= `value × spread.sell`，`side: buy`（商号收购）= `value × spread.buy`；`spread` 是商号实体的经营条款（`operates` 持有的 terms，作者数据或 core 表 `rules/tables/merchant.json` 按商号类型给缺省：杂货 `{sell: 1.0, buy: 0.6}` 之类，占位数据带 bounds），店主的定价候选以修正项改它（槽 `economy:spread`，附录 A §A.16），立场与声望进同一槽；没有商号（集市散卖、人对人）时两向都是 `value`。价差因此不是另一个价格，是同一 `value` 的两个方向因子。

**市场渠道出清**（成交，写账）：不含有效私约的市场渠道交易，一笔数量为 q 的大宗买入不按报价结算，而是沿稀缺曲线积分（小额见下文；私约见§15.2.3）：【修订来源：LAW-astra-001，DS5 / MKT01】

```
settlePrice(地点, 商品类, q) = (1/q) ∫₀^q  基准 × 稀缺(有效需求 ÷ (有效存量 − x)) × 其余因子  dx
```

卖出同理（存量 + x，乘 `spread.buy`）。成交后存量改变，投影版本号递增，下一笔报价已经反映新存量。于是"当日报价缓存"只保证**展示**一致，不保证成交价不变；一天内吃空一地存量的代价是陡峭上升的成交价。

**小额零售与收购口径**：积分只用于**大宗**。一笔 `q` 满足 `q ≤ max(retailFloor, 本地有效存量 × retailShare)`（`retailShare` 与绝对下限 `retailFloor` 都是商品类数据，`ontology/resources.json`，缺省 0.05 与 5，带 bounds——村铺存量 20 个馒头时买 3 个仍是零售）时按**零售口径**成交：成交额 = `quote(place, goods, side, business) × q`，`quote` 取成交时刻的投影值（不取缓存），**只对总额向零取整一次**（14 §14.6；不对单价取整）；商号的可售存量与钱柜照常同事务增减，存量改变后下一笔报价才反映。超过阈值的 `q` 走上面的稀缺曲线积分，两段的边界只由 `retailShare` 与存量给出，不由动作决定——同一个买馒头的动作，买三个是零售、买空半个铺子是大宗。算例：馒头 `quote(sell)` = 4 文，q = 3 → 12 文；兔皮 `quote(buy)` = 6 文，q = 5 → 30 文。**熟食与现做饮食**（面、卤肉、酒）是商号货物：成品由配方经 `src:craft` 进商号库存账户（01 §1.6），按本口径成交后 `transfer → sink:consume` 当场吃掉；只有不含货物的劳务（诊疗、修理、授课、住宿）才按服务义务的条款金额成交（06 §6.4）。集市散卖、人对人交易没有商号存量，`q` 一律按零售口径（两向都是 `value`，议价只改本次 transfer，06 §6.9.2）。

**深度**：市场渠道的单笔 q 超过 `有效存量 × maxShare`（商品类数据，例 0.3）→ 拒绝并给世界内原因（"市面上没这么多"）或分批。商号另有该渠道的每日成交量上限与自己的实际库存；店家的成交是 NPC 决策（05 §5.7），不是对任何报价的自动应允。有效私约不受这些渠道深度限制，但仍受§15.2.3的实物、支付、排他承诺与交付约束。【修订来源：LAW-astra-001，DS5 / MKT01】

**品质与批次**：报价按品质档给出：`quote × 品质系数(档)`（资源种类数据）；`lots` 资源的批次按入库周与品质档合并（批次合并规则：同周、同档、同 origin 合并，taint 加权），卖方指定批次时按该档计价，缺省先进先出；物品个体的品质经同一品质系数表进入价格。低品质充高价不可能，因为档是账户键的一部分。

**可售存量来自持有者**：每个持有者对每种商品的**自用保留**由需求和收入窗口派生（家户食用/种用、商号周转、军队军粮；§15.2.2）；一般渠道供给扣除保留与已承诺数量，不重复扣同一份存量。自用保留是可改变的偏好，排他承诺是必须履约或经合法程序解除的约束；私约改变前者不代表可以跳过后者。粮商"惜售"是自治决策把保留调高（05 §5.7），囤积由此涌现；灾期囤积是否构成罪名由状态类罪名谓词判定（05 §5.2.3）。【修订来源：LAW-astra-001，DS3、DS5 / HH01、MKT01】

**统一估值 `value(x, frame?)`**（此前物品个体与劳务各是一个公式，审查再要生灵、土地、债权的估值——改为**一个派生加一张可扩的估值表** `rules/tables/valuation.json`，每种可定价物一行给基准与因子；`itemValue`、`wageQuote`、`creatureValue`、`landValue` 只是别名）：

```
value(x, frame) = 基准(按 kind(x) 查估值表)
                × 品质 / 状态档(品质、做工、condition、品相)
                × 稀缺(同模板 / 同署名 / 同血统存世数，或劳务的 用工需求 ÷ 可雇劳力)
                × 来历与声望(作者名士投影含"身后"乘子；血统可信度 = 谱牒文书 records 与鉴定；债务人可靠度)
                × 真伪(frame.observer 的主观视图：他相信的 purports、来源与赝品传闻；无 observer 取真相，只供结算与损失评估)
                × 法域政策(frame.jurisdiction 的税与管制) × 修正项(槽 economy:value，when 可按 kind(x) 选择)
core 估值表（可扩）：
  资源批次      → quote(地点, 商品类, 品质档)（上文稀缺公式）
  物品个体      → quote(模板商品类)；稀缺 = 同模板 / 同署名存世个体数（实体索引）
  生灵个体      → quote(物种对应的种群资源) × 训练与年龄；稀缺 = 同血统存世数
  土地 / 资源点 → 按所估权利派生的预期净收益流折现（§15.2.1；面积、产能、投入、地权、区位）
  建筑          → 重置成本(配方或建造表按报价) × condition × 区位
  股份          → 组织净资产 × 份额
  债权          → 面值 × 债务人可靠度 × 折现（军需券贴现即此）
  劳务(技能族 × 阶) → 典型日收入表(06 §6.7) × 稀缺(有效用工需求 ÷ 有效劳力供给，弹性 ε_labor，钳制)
                      × 邻接(相邻聚落工价 × 迁居牵绊 作下限) × 季节 × 法域政策(工资管制、徭役)
                      有效用工需求 = 近期招工请求流量 + 空缺岗位 + 工程用工到期项；
                      有效劳力供给 = 本地可雇人数（技能阶 ≥ 要求、日程有空档、effective、无互斥持有；统计层按技能分布子账户，07 §7.3）
```

当铺估价、拍卖底价、以物抵债、损失评估、遗产估值、抵押覆盖率、地价、种畜溢价、雇佣动作的缺省条款、商号用工候选的出价、工程用工成本、辞工 / 跳槽候选的比较基准全部读它（NPC 读主观版本：本地 `market_report` 含报价与工价快照，异地只经转述）；成交价仍是动作（议价、拍卖出价、出清）的结果，`value` 只是基准与上限来源；已签的 wage 条款冻结，行情上升表现为新签与续签涨价、在职者被挖走；统计层按聚合率（`aggregate: "auto"`）。于是：唯一会某釉的窑工死后，同署名存世数不再增长而仿品另有模板 → 原作稀缺项与声望项升；仿品回流 → 稀缺项回落；赝品传闻经买家主观视图压低出价；风水包对 `economy:value`（land）的修正项卸下后地价回落到规则价。

**一处计算、多处引用**：制造成本（配方投入按报价 + 工时按 `wageQuote`）、建造成本、股份估值、损失评估、俸禄购买力全读本投影；税基读成交价。

**不存价格**：战后不"重置"，价格随存量与通路恢复而回落；猎物入市即压价。

### 15.2.1 土地、建筑与合约收益的估值

【来源：LAW-astra-001，DS1 / LAND01、LAND02；DS2 / AS01、AS02】统一估值不等于所有资产共享同一收益公式。土地租金以年预期产量、签约当地报价与地方惯例份额形成议价锚；按亩、作物与有效农时派生产量，再按历法换算租期。当前3/10惯例份额属于NUM-W10反推的待标定参数，须以地方租佃资料和分层收支检验回调，不当作史料常数，也不保证人人获利。

土地/资源权的价值按该权利可取得的净收益与终值折现：自营权的产出须扣真实投入、劳动机会成本、税费与持续使用所需成本；出租人权益读可取得的租金减其承担成本；有租约的所有权不能同时再计全部自营收益。建筑服务和价值读重置/维护成本、状态、用途及区位，不把住宅周租资本化作为土地估值。土地产能、灾害与水利事实已进入产量或成本时，不再叠乘建筑完好度或重复区位因子。资本回报率、期限和风险来源由世界数据声明；资料不足返回缺乏估值依据，不退回房租锚。

同一时点的估值可变，但已签租约的计价依据是合同快照，属于§15.3“不倒改条款”的例外留存而非价格缓存。定额租冻结具体金额；分成租冻结基数、比例、投入/风险分担和结算规则，金额由真实产出派生。先付、分期及秋后交租均列清计息/租期口径与到期日，已付额和待付额不能重复生债。正常报价带可指导开价，不代替对明确例外价格的真实同意与偿付判断。

### 15.2.2 家户现金流与经营资金

【来源：LAW-astra-001，DS3 / HH01–03、LAB01、AS03；DS2 / AS02；CR01接点】L1按主体已知的收入/支出时点派生现金流：家户看到下一次可靠收成或工资前的食用、种用、照料与履约缺口；经营者看到补货、维护、工资、税租、偿债与停工的资金需求。未来收入、储粮和可变现资产分别报告，不直接加进当前现金。时间配置须与实际雇佣、农时、照料、在途占用一致，同一投入只能归属一次实际使用。

资源池化依可支配权和家户规范派生，不另建余额或自动读取其他家户秘密账目。储备目标随收入波动、期限、可得信贷、共同灾害和偏好改变；自留粮不只看固定一天。互济是有同意的真实转移，礼物/人情不自动变成可强制债权。投资/继续经营比较未来增量净收益，另检当前资金缺口；亏损、缺现金、暂闭和破产不是同一状态。经营决策与维修责任见05 §5.1.2。

### 15.2.3 渠道、私约、集期与交付

【来源：LAW-astra-001，DS5 / MKT01–03、MIG02】报价是市场投影，成交可能来自市场渠道或具体双方的有效协议。有效私约的当事人、标的、数量、价款、时间/有效期与同意来源必须一致，成交按约定价执行，不能被聚合市场深度、渠道日限额或参考价格带再次否决。无有效协议不等于可以声明“私约”绕过NPC决定。商号服务容量、加工能力与实际交付时间若是该协议的物理前提，仍必须满足。

结算仍检查实际库存和权利、付款/明确授信安排、排他承诺、必要的地点与运力；同意低价或出售自留物可以合法发生，已锁定给第三人的物不能因此重复交付。私约计入真实成交流量与已获知的价格信息，但不消耗未使用的市场渠道深度，同一成交不能重复记账。第三方税费、法律后果仍按规范发生。

地方集期、常设营业与承运班次共同决定可交易窗口。集日只提供到场协调，供给须有真实持货者、旅行/携货和可用服务；非集日也允许常设店和现场私约。主观搜价、赶集、储货和套利读已知报价、时滞、时间机会成本、运储费与风险，外地货物只有真实交付后进入当地可消费库存。市场深度不等于运输容量，路线报价也不代替运力占用；封路不应否定同地双方现有物资的现场交换。

## 15.3 货币：铸币是商品，计价单位由法典指定

**铸币**是资源种类（01 §1.6），带货币事实 `money: {metal: copper|silver|gold|none, fineness, weight, issuer: 政体或组织, backedBy?: {coin, ratio}}`。各政体的铜钱、银两、金铢各是一种资源，`src:mint` 的使用者由法典认可条目 `recognition.issuers.mint` 给出（缺省只有发行政体），铸币量是发行者的自治决策（受合理性表与每日源汇预算约束）；私铸走 `src:craft` 配方并由规范栈判罪（05 §5.2.4）。**`metal: none` 的货币**（可兑现纸币、纯信用货币）由 `recognition.issuers.notes` 所列的发行者经 `src:issue` 发行（发行守恒对，01 §1.6），定价见下文"信用货币"分支。

**计价单位**：每个法域的法典有认可条款 `recognition.legalTender = {unit: 任一资源, accepted: [其他铸币或凭证]}`；本地一切报价以 `unit` 计，`quote = value(x) ÷ value(unit 资源)`——unit 可以是铸币，也可以是羊、谷、布（草原以羊计价），因为 `value` 对任何资源都有定义（§15.2）。"文 / 两 / 金"之间**没有固定换算**：显示换算是当地汇率的派生。**度量衡只是显示**：存量只有规范单位（01 §1.6），文化记录与法典 `units` 给斤 / 两 / 锭对规范单位的换算，投影按视角法域的单位表渲染，跨政体交易"自动换算"而总量守恒；换算差不构成套利面，真实差价只来自汇率、关税与运输（§15.9）。

**改币与退出流通**：认可条款可含 `demonetize = {coin: 旧铸币, newCoin, effectiveFrom, graceUntil, legalRate: 旧:新 的法定比（可空）, settle: convert_at_legal | convert_at_market(date) | creditor_option, exchange: {offices: [兑换职位或网点], fee, dailyCapacity}}`。规则：
- **既有义务的换算是一次显式事件**：条款快照"从不被派生改写"（§15.3 上文）仍成立——退出流通不是派生，而是法典条目生效时由反应规则对每条以旧币计价、债权人或债务人属该法域的义务写 `redenominated{obligation, from, to, rate, basis: 条目}` 事件，把**新的计价资源与数量**追加进条款快照（旧条款保留可审计），数量按 `settle` 方式：法定比、生效日市场汇率（§15.3 `rate`）或债权人选择（到期时二选一，由 npcDecision / 玩家给出）。`graceUntil` 之前两币并行受偿；之后旧币不再是 `accepted`，只能到 `exchange.offices` 兑换（兑换是服务，有容量与手续费，附录 A §A.16 `service:capacity`）。
- **无套利**：法定比与市场比价若不同，差价只能经有容量上限、要排队、收手续费的官方兑换实现，且旧币计价债务在生效日一次性换算、不再随后续比价浮动——"旧债按新钱面额偿还"与"用贬值旧币还新债"都不存在。
- **守恒**：回收旧币 = transfer → `sink:melt`，同一事务内按金属含量从 `src:mint` 流入新币（改铸守恒对，01 §1.6；审计要求金属量相等，铸币差额是政体的铸币税 = 新币含量低于旧币时的金属结余留在政体金属账户）。
- 他政体是否承认新币：各自的 `accepted` 列表与商户的主观信用判断（已有）。

**价值单位与货币的价格**：市场投影内部用一个不显示的**价值单位**（一篮子实物，粮为主，数据）计算一切报价；铸币也是商品（`goods:coin`），它的价值同样按 §15.2 的稀缺公式算出；显示给玩家的报价 = 价值 ÷ 计价铸币的价值：

```
value(地点, 商品类)   按 §15.2（价值单位）
value(地点, 铸币)     = value(地点, 金属商品类) × 含量 × 发行信用 × 货币充裕度
   金属商品类存量     = 本地金属锭存量 + 本地铸币存量 × 含量          （矿产出与外来白银都进这里）
   发行信用           = f(发行政体对本地法域的承认、成色事实、政体 standing)     （修正槽 economy:coinCredit）
   货币充裕度         = clamp(近期交易额 ÷ max(本地该铸币流通存量, 近期交易额 × k_floor))   （铸币越多越不值钱；分母有下限）
   流通存量           = 近 N 日（数据，缺省 30）参与过 transfer 的本地账户中该铸币的存量之和（"活跃存量"）；
                        窖藏（长期未动的账户）与在途载体中的铸币不计；一车铜钱运进小镇，在它参与交易之前不改变比价，
                        参与后被 k_floor 下限钳住，所以搬运铸币只能在大镇的大额交易里才有可观效应
quote(地点, 商品类)   = value(商品类) ÷ value(计价铸币)                         （显示报价，单位 = 法典 unit）
```

所以富银脉的白银流入 → 金属存量升、银币充裕 → 以铜计的银价跌、以银计的物价升；以银计的存款义务数量不变，但按 §15.4 购买力下降。**合同记资源种类与数量，从不换算**（避免"本金被错误换算"）。私铸轻钱是同一铸币资源的另一批次（`origin.counterfeit`、`purports: 足钱`，01 §1.6）或作者声明的单独资源种类：它流入本地活跃存量就抬高"本地铸币存量 × 含量"（按真实含量计）→ 足钱充裕度上升 → 以钱计的物价涨、以银计的不变；收缴 = 法典 `legalTender.accepted` 去掉它 + 执法动作的转移。

**信用货币的定价分支**（`metal: none` 时金属项为 0，上式不适用）：

```
value(地点, 货币 | metal = none) = 挂钩价值 × 兑付信心 × 货币充裕度
   挂钩价值   = backedBy 非空（可兑现纸币：发行者承诺按 ratio 兑付某铸币）→ value(地点, backedBy.coin) × ratio
               backedBy 为空（纯信用：冥币、法定不兑现纸币）→ value(价值单位) × 法定接受（该地法典 legalTender：unit 为 1，accepted 为数据值，都不是 → 无报价）
   兑付信心   = clamp( reserveRatio(发行者, 货币) ÷ 法典或章程的准备金率基准, 0, 1 )   （可兑现；纯信用取 1）
               × 发行信用（发行者对本地法域的承认、standing；槽 economy:coinCredit）
               × 持有者主观折价（挤兑 / 倒闭的 belief，05 §5.4；无 viewer 时取 1，只供结算）
   货币充裕度 = 同铸币：近期交易额 ÷ max(本地活跃流通存量, 交易额 × k_floor)   ——发行量进入活跃存量，超发即稀释
quote 与 rate 同上。
```

于是：钱庄超发交子 → 活跃存量升、充裕度降，同时 `reserveRatio` 降、兑付信心降 → 交子 value 跌 → 以交子计的物价涨（通胀），而以铜计的不变；挤兑 = 持票人 belief → 主观折价 + 兑付请求 → 准备金耗尽 → 停兑动作 → 破产案件（§15.5 同形）；远方郡不认 = 该地法典 `accepted` 不含它 → 市场投影"无报价"，只能持票回网点或由愿意收的 NPC 按自定汇率兑换（兑换动作 = 两笔互逆转移，§15.3 汇率段）；冥币在冥府法域是 unit（价值按冥府聚落的价值单位篮子），在阳间无报价、只经鬼市商贩的兑换动作定价。发行是否犯罪（`offense:overissue`）读 `recognition.issuers.minReserveRatio`（05 §5.2.4）。

**汇率**：`rate(地点, A, B) = quote(地点, A) ÷ quote(地点, B)`。兑换是钱庄或钱铺的动作：两笔互逆 transfer 按当时汇率 + 手续费（网点经营条款 `exchangeFee`，与开汇票的 `billFee` 同表，§15.1.1）。跨境套汇是真实现象，受运输成本、风险、关税与政体管制约束（可以是罪名谓词）。

## 15.4 购买力

`ppi(地点) = Σ 篮子(粮为主，数据) 报价 ÷ 基期`；实际价值 = 名义数量 × quote(铸币) ÷ ppi。俸禄购买力、存款实际价值、损失评估都读这一派生；界面"为什么我的俸禄不够花"由解释树给出（标杆 B03）。

## 15.5 信用：钱庄、可贷资金、利率、银根

- **钱庄** = 组织（`org/bank`），网点是 `branch` 持有（01 §1.3），分号是实体（被持有钉住，远方郡骨架物化时必然存在，07 §7.3）。
- **可贷资金**（派生）`loanable(钱庄) = Σ 其现金账户 − 准备金率 × Σ 存款义务余额`；准备金率来自法典认可条款或章程（core 缺省数据）。钱庄贷款只能从现金账户转出（I2），不创造货币。
- **利率**（派生，合同区间内）：
  ```
  interestRate(钱庄, 借款人) = clamp( base
                                     × 压力(需求流量 ÷ loanable)        （需求流量 = 近期**成立**的借贷义务额 + 被拒申请额；
                                                                            申请后撤回不计，撤回与违约记入借款人可靠度，同 §15.6；
                                                                            反复申请再取消不能抬高他人利率，R5 专项②第 6 条）
                                     × 违约史(借款人 standing 与逾期记录)
                                     × 主观风险(贷方主观视图中的挤兑/倒闭 belief，05 §5.4)
                                     × 修正项(槽 lending:interestRate),  terms.minRate, terms.maxRate )
  ```
- **存款利率**：`depositRate(钱庄) = interestRate(钱庄, 基准借款人) × spread`，`spread` 来自章程或法典认可条款（core 缺省 0.4）；**同一网点的存款与贷款条款取同一 `per`**（经营条款 `rateTerms.per: day | anchor`，缺省 anchor，写进每笔义务的条款快照）；利差因此恒为正，跨境存贷套利扣除汇兑费（§15.3）与关税后不形成稳定正收益，且借款侧压力项随借款额上升。
- **银根**（派生）`credit(地区) = Σ 该地区钱庄的 loanable`。钱庄倒闭 → 该项消失 → 压力升 → 利率升；谣言挤兑 → 储户主观视图 → 支取请求 → I2 → 停兑动作 → 债权人申请破产（05 §5.2.7）。贷方按**主观视图**收紧：东边陲郡的钱庄只有听说倒闭（公共知情 / 传闻）后才提高风险项（I25）。
- **统计层聚合变体**（I28）：未物化聚落的信贷是聚合量（聚落级存款余额、可贷资金、需求流量），按月闭式；利率投影对统计层聚落读聚合量；物化时按种子分配到个体钱庄与借款人，守恒。
- **挤兑中的偏颇清偿**：清算裁定前 N 天内（民事①数据）的全额支取可被撤销为返还义务，使"先取者全得"不成立。
- **汇票**：bill 义务 + 代表票据；兑付前提是兑付地有该钱庄 branch；钱庄解散后按 `onDebtorGone`（缺省 accelerate）进入清算的按比例清偿。

## 15.6 远期与预期

远期（forward）与托运义务进入有效存量的条件：对价已付比例 ≥ 阈（数据）、债务人可证实的产能或存量 ≥ 承诺量（田地产量预期、库存），超出部分不计；**可靠度从 0 起步**——债务人没有履约记录时其远期不计入预期，有 pledged 担保的按担保价值计入；一次违约把该债务人全部未到期义务的权重归零 N 季（数据）；**合意取消**（obligation.cancel）记入可靠度（视同一次不履行）。于是"与同伙签大量远期契约压低现货价再低价吃进"既不进投影（无对价、无产能、无履约记录），取消时还损信誉。

## 15.7 税与关税

税表、关税、通行费是规范栈条目（05 §5.2），按商品类标签与聚落等级；每条有收款人 `recipient`（法域公库 / 节点控制者 / 职位所属组织 / 持许可者）与可选分成 `split`、按人按期的免税额 `exemption`（附录 A §A.7）——包税与买路钱就是 recipient 指向 `controls` 或 `permit` 持有人；第三方的减免与优惠经规范补丁（05 §5.2.8）；市场投影的到岸成本与法域政策项读同一处数据。**征管**：条目的 `collection`（automatic / assessed / farmed，附录 A §A.7、05 §5.1）决定税是自动转移还是经申报、查验、放行；assessed 下走私与受贿有税额后果，`taxGap` 供稽查与审计读；关卡收入下降于是能成为 E20 长链的一环。

## 15.8 统计层的经济

远方聚落只有聚合账户（粮、木、铁、钱、药材）与聚合流量（产量、消耗、贸易），按月闭式结算；聚落实体的"聚合市集账户"可作义务端点（07 §7.3）；玩家到达时按种子物化个体账户并从聚合账户"借出"初始存量（守恒）。市场投影对未物化地点返回"未知"，对已骨架物化的地点返回聚合报价。

| 装卸循环注入核心货币 | 同一包在同一存档的 `src:genesis` 累计注入 ≤ 合理性表上限（记在 packs.lock 历史段），重装只能从聚合借出或在剩余额度内注入（12 §12.5.2 J6） |

| 物品个体无价可读：当铺 / 拍卖 / 以物抵债循环 | `value` 单一派生 + 当价系数 + 每轮利息；刷取探测器覆盖物品个体买卖循环（B04.4） |
| 同一货多份保险、多头赔付 | 义务种类 `exclusive`（01 §1.4、I8） |
| 擅自增资稀释他人股份 | `holding.rescale` 须章程授权 + 持有人同意或表决（06 §6.3） |
| 反复申请贷款再取消抬高竞争者利率（R5 专项②第 6 条） | 需求流量只计成立与被拒的申请，撤回记可靠度（§15.5） |
| 低成本告发冻结对手资产（R5 专项②第 7 条） | 程序成本：讼费、冻结担保、败诉承担、滥诉罪名（05 §5.2.4） |
| 旧债按新钱面额偿还 | 改币条款：一次性显式换算事件、官方兑换有容量与手续费（§15.3） |
| 制造凭空产出 / 配方链刷物 | `src:craft` 制造守恒对：产出 = 配方 yields(投入)，同事务消耗投入；每条引用它的规则与动作有每日预算；即兴制作只出 crude 物品个体（01 §1.6、06 §6.7） |
| 私铸与伪币入账造钱 | 铸币批次 `origin.counterfeit` 与 `purports`：结算按真实种类与含量，受骗只改变对价，不改变总量；行使伪币的罪名读 `knows(actor, origin)`（01 §1.6、05 §5.2.4） |
| 纸币无限签发 | `src:issue` 发行守恒对记准备金与 `issued`；超发压低兑付信心与充裕度（自贬值），`minReserveRatio` 可定为罪名；兑付是 `sink:redeem` + 准备金转出，准备金耗尽即停兑 → 破产（§15.3、§15.5） |
| 雇佣套利（受雇比自做划算或反之） | `wageQuote` 与期望值天花板读同一张典型日收入表（§15.2、06 §6.7） |
| 轻钱倒手存钱庄凭空造钱 | I1 按资源种类与批次守恒：存款义务记真实种类，利息按该种类累计，实值由投影给出 |
| 保险与承运赔偿双付 | 民事⑨损失填补：同一损失的赔偿与保险给付总额 ≤ `value` 评估，超出由后付者向先付者代位（附录 A §A.7） |
| 闰月套利：按月计息与按日计息口径并存 | 口径唯一定义在附录 A §A.15 期间与折算口径：`per: anchor` 的闰月不成期、其天数计入 `remDays` 按 `rateBasis` 折日，与 `per: day` 跨闰月结果相同；同一网点存贷同一 `per`（§15.5 `rateTerms.per`），跨网点差异上限 = 期额 ÷ `rateBasis.month`（一个小月之差，月息的 1/30），远小于存贷利差（`depositRate = interestRate × 0.4`，§15.5），不形成正收益 |
| 度量衡换算差套利 | 存量只有规范单位，单位表只是显示（§15.3） |
| 派生缺省开槽后多包叠加失控 | 缺省 bounds `mul ∈ [0.5, 2]`、每槽修正项数与总幅度预算、`exclusiveGroup`、平衡仿真"槽叠加极值"抽样全部派生（11 §11.2 第 26 条） |
