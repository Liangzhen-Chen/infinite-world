## 15.1 做到哪里、不做哪里

做：按数量出清的报价（滑点）、可售存量来自持有者的保留决策、货币作为商品定价（汇率派生）、计价单位由法典指定、购买力指数、钱庄的可贷资金与利率、破产清算（05 §5.2.7）、远期与预期、套利防线。
不做：订单簿与撮合、逐笔报价的代理人行为（议价只在交易动作里）、信用创造（钱庄只能把手里的钱贷出去，I2）、金融衍生品。理由：11 §11.1——市场是投影，账本才是状态；上述"不做"的东西都要求存储报价状态或凭空产生价值。

## 15.1.1 价值有位置（B-S3）

账户没有自己的位置，但**账户所属实体有位置**（01 §1.2）：随身钱袋与行囊是 located 于本人的账户（用途 `carry`），仓库、柜台、公库、粮仓是建筑或聚落实体的账户，钱庄的现金挂在各网点建筑上。由此：
- **transfer 要求物理可达**：两端账户所属实体在同一节点（分区可及），或转移由显式载体承担——票据（bill 义务 + 代表物品，持票人到场提取）、托运（delivery 义务 + 车船在途）、钱庄汇兑（两网点间的内部 bill）。没有载体的远程转移被拒绝并给世界内原因（"钱在三郡之外"）。
- **obligation.settle 要求在场**：债务人（或其代理、代付者）与债权人（或其经营持有人、代收职位、网点）同节点；否则只能"寄汇"（创建 bill，由承运或驿传携带，到达后清偿）。配偶代还、第三人代偿同样要到场或寄汇（R3-E15①）。
- **不在场债权人的清偿**：遗产与清算对不在场债权人的清偿进入该义务或票据的**托管账户**（instrument 可挂托管，01 §1.2），凭证到场提取；到期未提取按法典程序归公或继续托管。
- **总号与分号**：钱庄各网点各有现金账户；头寸调拨是托运或内部汇兑义务；总号倒闭后分号仍持有自己的现金，但 `branch` 持有随总号清算关闭 → 汇票的兑付前提消失 → 拒付 → 持票人的债权进入清算申报（R3-E1②③）。

## 15.2 市场投影与出清

**报价**（显示用，同一刻内一致）：

```
value(地点, 商品类) = 基准(资源模板，以内部价值单位计，§15.3)
                   × 稀缺( 有效需求 ÷ 有效存量 ，钳制在 priceFactorLimits，弹性 ε 按商品类 )
                       有效存量 = 本地可售存量（批次按品质档；可售 = 持有者库存 − 自用保留）
                                + Σ 未到期、交付地为此、对价已付比例 ≥ 阈 的远期/托运义务 × 可靠度 × 时间折扣（§15.6）
                                − Σ 本地存量上已承诺的未到期交付
                       有效需求 = 近期需求流量 + 预期需求（季节、疫情、工程材料）
                   × 到岸成本( 最近有存量的供给地沿可通行路线：距离 + 运力 + 风险 + Σ 沿途关税与通行费；封关 = 无穷 )
                   × 季节(资源种类 × 季节表)
                   × 法域政策(规范栈税表与管制，含规范补丁，05 §5.2.8)
                   × 店家与关系(店主加成、立场、声望)
                   × 已注册修正项(槽 economy:price，05 §5.9)
```

显示报价 `quote` = value ÷ 计价铸币的 value（§15.3）。

**出清**（成交，写账）：一笔数量为 q 的买入不按报价结算，而是沿稀缺曲线积分：

```
settlePrice(地点, 商品类, q) = (1/q) ∫₀^q  基准 × 稀缺(有效需求 ÷ (有效存量 − x)) × 其余因子  dx
```

卖出同理（存量 + x）。成交后存量改变，投影版本号递增，下一笔报价已经反映新存量。于是"当日报价缓存"只保证**展示**一致，不保证成交价不变；一天内吃空一地存量的代价是陡峭上升的成交价。

**深度**：单笔 q 超过 `有效存量 × maxShare`（商品类数据，例 0.3）→ 拒绝并给世界内原因（"市面上没这么多"）或分批。商号另有每日成交量上限（商号数据）与自己的可售存量；店家的成交是 NPC 决策（05 §5.7），不是对任何报价的自动应允。

**品质与批次**：报价按品质档给出：`quote × 品质系数(档)`（资源种类数据）；`lots` 资源的批次按入库周与品质档合并（批次合并规则：同周、同档、同 origin 合并，taint 加权），卖方指定批次时按该档计价，缺省先进先出；物品个体的品质经同一品质系数表进入价格。低品质充高价不可能，因为档是账户键的一部分。

**可售存量来自持有者**：每个持有者对每种商品的**自用保留**由需求派生（家户的口粮、商号的周转、军队的军粮）；可售 = 库存 − 保留。粮商"惜售"是自治决策把保留调高（05 §5.7），囤积由此涌现；灾期囤积是否构成罪名由状态类罪名谓词判定（05 §5.2.3）。

**一处计算、多处引用**：制造成本、建造成本、股份估值、损失评估、俸禄购买力全读本投影；税基读成交价。

**不存价格**：战后不"重置"，价格随存量与通路恢复而回落；猎物入市即压价。

## 15.3 货币：铸币是商品，计价单位由法典指定

**铸币**是资源种类（01 §1.6），带货币事实 `money: {metal: copper|silver|gold|none, fineness, weight, issuer: 政体}`。各政体的铜钱、银两、金铢各是一种资源，`src:mint` 只许发行政体使用，铸币量是政体的自治决策（受合理性表与每日源汇预算约束）。

**计价单位**：每个法域的法典有认可条款 `recognition.legalTender = {unit: 某铸币, accepted: [其他铸币]}`；本地一切报价以 `unit` 计。"文 / 两 / 金"之间**没有固定换算**：显示换算是当地汇率的派生。

**价值单位与货币的价格**：市场投影内部用一个不显示的**价值单位**（一篮子实物，粮为主，数据）计算一切报价；铸币也是商品（`goods:coin`），它的价值同样按 §15.2 的稀缺公式算出；显示给玩家的报价 = 价值 ÷ 计价铸币的价值：

```
value(地点, 商品类)   按 §15.2（价值单位）
value(地点, 铸币)     = value(地点, 金属商品类) × 含量 × 发行信用 × 货币充裕度
   金属商品类存量     = 本地金属锭存量 + 本地铸币存量 × 含量          （矿产出与外来白银都进这里）
   发行信用           = f(发行政体对本地法域的承认、成色事实、政体 standing)     （修正槽 economy:coinCredit）
   货币充裕度         = clamp(近期交易额 ÷ 本地该铸币流通存量)                   （铸币越多越不值钱）
quote(地点, 商品类)   = value(商品类) ÷ value(计价铸币)                         （显示报价，单位 = 法典 unit）
```

所以富银脉的白银流入 → 金属存量升、银币充裕 → 以铜计的银价跌、以银计的物价升（R3-E9①）；以银计的存款义务数量不变，但按 §15.4 购买力下降（R3-E9②）。**合同记资源种类与数量，从不换算**（避免"本金被错误换算"）。

**汇率**：`rate(地点, A, B) = quote(地点, A) ÷ quote(地点, B)`。兑换是钱庄或钱铺的动作：两笔互逆 transfer 按当时汇率 + 手续费。跨境套汇是真实现象，受运输成本、风险、关税与政体管制约束（可以是罪名谓词）。

## 15.4 购买力

`ppi(地点) = Σ 篮子(粮为主，数据) 报价 ÷ 基期`；实际价值 = 名义数量 × quote(铸币) ÷ ppi。俸禄购买力、存款实际价值、损失评估都读这一派生；界面"为什么我的俸禄不够花"由解释树给出（标杆 B03）。

## 15.5 信用：钱庄、可贷资金、利率、银根

- **钱庄** = 组织（`org/bank`），网点是 `branch` 持有（01 §1.3），分号是实体（被持有钉住，远方郡骨架物化时必然存在，07 §7.3）。
- **可贷资金**（派生）`loanable(钱庄) = Σ 其现金账户 − 准备金率 × Σ 存款义务余额`；准备金率来自法典认可条款或章程（core 缺省数据）。钱庄贷款只能从现金账户转出（I2），不创造货币。
- **利率**（派生，合同区间内）：
  ```
  interestRate(钱庄, 借款人) = clamp( base
                                     × 压力(需求流量 ÷ loanable)
                                     × 违约史(借款人 standing 与逾期记录)
                                     × 主观风险(贷方主观视图中的挤兑/倒闭 belief，05 §5.4)
                                     × 修正项(槽 lending:interestRate),  terms.minRate, terms.maxRate )
  ```
- **银根**（派生）`credit(地区) = Σ 该地区钱庄的 loanable`。钱庄倒闭 → 该项消失 → 压力升 → 利率升（R3-E1④）；谣言挤兑 → 储户主观视图 → 支取请求 → I2 → 停兑动作 → 债权人申请破产（05 §5.2.7）。贷方按**主观视图**收紧：东边陲郡的钱庄只有听说倒闭（公共知情 / 传闻）后才提高风险项（I25）。
- **统计层聚合变体**（I28）：未物化聚落的信贷是聚合量（聚落级存款余额、可贷资金、需求流量），按月闭式；利率投影对统计层聚落读聚合量；物化时按种子分配到个体钱庄与借款人，守恒。
- **挤兑中的偏颇清偿**：清算裁定前 N 天内（民事①数据）的全额支取可被撤销为返还义务，使"先取者全得"不成立。
- **汇票**：bill 义务 + 代表票据；兑付前提是兑付地有该钱庄 branch；钱庄解散后按 `onDebtorGone`（缺省 accelerate）进入清算的按比例清偿。

## 15.6 远期与预期

远期（forward）与托运义务进入有效存量的条件：对价已付比例 ≥ 阈（数据）、债务人可证实的产能或存量 ≥ 承诺量（田地产量预期、库存），超出部分不计；**可靠度从 0 起步**——债务人没有履约记录时其远期不计入预期，有 pledged 担保的按担保价值计入；一次违约把该债务人全部未到期义务的权重归零 N 季（数据）；**合意取消**（obligation.cancel）记入可靠度（视同一次不履行）。于是"与同伙签大量远期契约压低现货价再低价吃进"既不进投影（无对价、无产能、无履约记录），取消时还损信誉（A 专项② 第 3 条、B-S10）。

## 15.7 税与关税

税表、关税、通行费是规范栈条目（05 §5.2），按商品类标签与聚落等级；第三方的减免与优惠经规范补丁（05 §5.2.8）；市场投影的到岸成本与法域政策项读同一处数据。

## 15.8 统计层的经济

远方聚落只有聚合账户（粮、木、铁、钱、药材）与聚合流量（产量、消耗、贸易），按月闭式结算；聚落实体的"聚合市集账户"可作义务端点（07 §7.3）；玩家到达时按种子物化个体账户并从聚合账户"借出"初始存量（守恒）。市场投影对未物化地点返回"未知"，对已骨架物化的地点返回聚合报价。

## 15.9 套利与漏账防线（run-003 专项②逐条）

| 漏洞 | 防线 |
|---|---|
| 当日报价缓存 = 无限流动性 | §15.2 按数量出清与深度上限 |
| 可替代物洗白（偷来的粮入账即与合法存量混同） | `lots: true` 的资源按批次带 `origin` 与 `taint`（来源事件、赃物/违禁来源），转移随批次携带，批次合并按比例传播；赃物谓词对批次生效（taint 份额 ≥ 阈）。铸币与矿石不跟踪（现实中亦无法识别），追赃靠赔偿义务与判决金额（01 §1.6） |
| 虚假远期压价 | §15.6 对价、产能、取消记入可靠度 |
| 逃债转移（死前赠与、限定继承落空） | 民事⑨ 诈害行为撤销：消失或破产前 N 天内无对价或明显低价的转移，由遗产 / 清算实体以返还义务追回（04 §4.4） |
| 挤兑先取者全得 | §15.5 偏颇清偿撤销 |
| 兜底标签实体刷立场 | 同作者、同标签、同地点的 mark 在 7 日内引起的印象反应逐次减半（05 §5.6、06 §6.7） |
| 离屏无见证 = 无立案 | 规则层按见证概率模型给出见证（07 §7.2.1），统计层按聚合犯罪率立案 |
| 被毁物品账户悬空 | 04 §4.2 第 2 步：毁灭也有承接（残骸实体 / `sink:destroy`），I6 扩展到账户 |
| 固定兑换比的跨境套汇 | §15.3 汇率派生；套汇成为受成本约束的真实行为 |
| 运行期源汇无预算 | 每条规则对每个 `src:*` 声明每日总量预算（12 §12.8.3 的运行期部分）；超出熔断 |
| 守恒绕过市场（凭空造物） | I1、I20 不变 |
| 远程清偿、远程收款、清算资金瞬移（B-S3） | §15.1.1 价值有位置：转移与清偿要求在场或显式载体 |
| 送礼刷印象无上限（B 专项② 第 5 条） | 立场投影对同一 (持有者, 对象, 事件类) 的累计印象经饱和函数（05 §5.6），不只衰减 |
| mark 无数量上限 | 同作者同地点的兜底实体数有上限（数据），超出的新 mark 覆盖最旧的且不再引起反应（06 §6.9.5） |
| 聚合账户"借出"无回收（B 专项② 第 6 条） | 物化的个体带 `materialized` 标记；地区降级或玩家离开时按同一转换把个体账户并回聚合，反复进出不重复借出（07 §7.3） |
| 互开贷款制造负余额（B 专项② 第 8 条） | I2 无例外：账户永不为负，赊账只能是义务 |
| 提案引用源汇账户（B 专项② 第 9 条） | 提案不得以 `src:*` 为来源；`sink:*` 只作自有资源去向；源只能由声明了它的规则引用（01 §1.6） |
| 陈货充新货（B 专项② 第 10 条） | 品质档是账户键，报价按档（§15.2） |
