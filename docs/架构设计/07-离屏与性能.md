# 07 离屏与性能：分层模拟、降频与结果等价、存档结构

## 7.1 现状与预算

P3 已把设计上限场景（九省 31 郡、142 聚落、324 住区、约 3.5 万居民）的日推进从 57.9 秒降到 1.49 秒、月推进 38.8 秒、回合 382 毫秒、峰值内存 3.0GB、存档 23MB；预算：日 ≤ 5 秒、月 ≤ 120 秒、场景与提示 ≤ 150 毫秒、存档 ≤ 64MiB。advance-layers 已按郡的注意距离分三层（intelligent / rule / statistics），远方普通居民改存聚合，走近可重放补算。目标架构沿用这套分层，把"等价"从经验做法变成规则声明与测试。

## 7.2 三层（沿用指南 5.9 与 P3）

| 层 | 范围（按注意距离派生） | 做什么 | 不做什么 |
|---|---|---|---|
| 智能层 | 玩家所在郡及相邻郡；另加与玩家有持有/义务/强立场的实体，无论在哪 | 逐事件；日程逐人；NPC 决策规则逐人；（开 LLM 时）智能层行动提案 | — |
| 规则层 | 同省或两跳内的郡 | 按日时钟规则；义务到期项精确；人物以日为粒度 | 不逐分钟日程 |
| 统计层 | 其余 | 聚落级聚合账户按月闭式；个体只保留名册种子与稀疏的持有/义务；种群、资源点按月 | 不物化个体、不生成记忆 |

层级不写进人物；玩家移动时相邻地区先"补算到现在"再升层（P3 已做）。被任何到期项、持有或义务钉住的个体（任职、拘留、会籍、合同、效果）不参与聚合（P3 的 pinned 逻辑保留）。

## 7.3 等价原则（I14）

1. **义务与日程精确，与层级无关**：它们是稀疏到期项；离开 360 天也只处理真正到期的分期。到期项处理顺序按时间，骰值由种子 + 对象 + 日期决定，所以逐日推进与一次推进结果相同。
2. **累计量闭式**：利息、租金、工资、俸禄、再生（逻辑斯蒂）、作物生长（按积温）、耐久损耗（按天气与使用）都声明 `closedForm`，由 `accruedTo` 一次算到当前时刻。精确等价。
3. **迭代规则按层级放大步长**：价格（依赖需求流量）、疫病传播、迁徙、污染顺流是耦合迭代，声明 `tolerance`（例如总量 ±3%、分布 KL 散度阈）；统计层用月步长执行同一规则；等价测试同种子比对逐日与放大步长的结果，超出容差即测试失败，由规则作者改为更好的闭式或降低步长。
4. **补算无可见跳变**：玩家逼近时，规则层/统计层地区先按自己的步长补算到当前时刻，再升层；补算产生的事件不进入玩家知情集合（玩家不在场），只有见证规则允许的公告/景象才在到达时可见。
5. **远方未到达前只有纲要与聚合账户**：细节在首次到达时按种子物化（E05⑤）；物化从聚合账户"借出"存量，守恒；物化前任何投影对玩家返回"未知"。
6. **智能层 LLM 行动是提案**，经同一校验；无 LLM 时智能层退化为规则层逻辑，结果仍合法（只是 NPC 少了"主意"）。

## 7.4 成本来源的消除

| 现状成本 | 目标机制 | 预期 |
|---|---|---|
| 逐日写派生值（额度、职名、权限、日程副本、七份态度） | 派生不落盘；投影缓存带版本键 | 存档与快照体积下降；写放大消失 |
| 推进时扫描全部记录找到期项（57 个推进项各自扫） | 到期日程堆；推进只弹出到期项 | 日推进与世界规模解耦，与"今天到期的事"成正比 |
| 远方个体物化 | 统计层聚合账户 + 名册种子（P3 已做一半） | 峰值内存继续下降 |
| 转移时各模块各自遍历 | 持有索引（按持有人/标的）；协议复杂度 = 该实体的度 | 死亡结算 O(度) |
| 价格、立场多处重复计算 | 投影缓存，事件驱动失效 | 场景卡与提示组装时间下降 |

## 7.5 派生读的性能（风险对策）

一切派生意味着热路径上大量视图计算。对策：
- 投影声明依赖（持有种类、账户种类、事件动词、事实字段）；内核为每个 (实体, 种类) 维护版本号，写入时递增；视图缓存键 = 依赖版本的组合；命中即返回。
- 热投影（在场实体视图、价格报价、立场）在回合结束时预热。
- 统计层不计算个体投影。
- 预算守在 tests/scale.test.mjs（现有）：回合 ≤ 500 毫秒、场景卡 ≤ 150 毫秒、日 ≤ 5 秒、月 ≤ 120 秒；新增"派生读缓存命中率 ≥ 90%"。

## 7.6 存档结构

- `events/`：按时间分段追加（每段 N 个事件）；旧段可压成快照后归档；事件含提案原文与骰值（动作层可重放，不再调用模型）。
- `core/`：快照 = 实体事实 + 持有 + 义务 + 账户 + 日程堆 + 地区进度；按郡分片，未加载分片不读；智能/规则层分片全量，统计层分片只有聚合账户与名册种子。
- `cache/`：投影缓存（立场、价格、知情索引、场景卡素材），带版本键，可整体丢弃重建（I17）。
- 聊天只存战役引用（现状保留）。
- 迁移只在发布时写一次（C.7）；早期阶段把持有/义务/账户作为 `state.records` 的新 category 存放，不改存档格式；分片快照在后期阶段引入，附一次迁移。

## 7.7 测试

- 等价测试：对每条时钟规则，同种子跑"逐日 N 天"与"一次 N 天"，闭式类逐字节相等，迭代类在容差内；注册新规则时自动纳入。
- 补算测试：玩家从远处移动到某郡，比较"一直在智能层"与"统计层补算后升层"的账户总量与持有集合。
- 规模测试：现有 scale-bench 场景 + 新增"一年离屏 + 回村"的 E12 情境耗时。
- 存档往返：导出导入逐字节一致；分片丢失一片时报错而非静默。
