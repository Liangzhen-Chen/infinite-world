# 09 走查：R1（run-001）二十题，与 R2 / R3 修订后的结论摘要

（编号约定见附录 A §A.14：本章正文的 E01–E20 即 R1-E01…R1-E20；§9.21 的 E1…N8 即 R2-*；§9.22 的 E1…N5 即 R3-*。文件名保留以维持既有链接。）

每个事件：情境里的个体怎样建模 → 触发与规则链 → 预期逐条由什么算出 → 现有实现的错误（verdict-a/b）为何在目标下不会发生 → 需要新增的是数据还是概念。结论先说：**二十个事件全部由八个概念 + 转移协议 + 投影 + 动作层算出；run-001 范围内新增的全是数据（法典条款、章程、速率表、失真表、模板），没有一处需要新的存储概念。**

> **2026-10-15 修正（run-002 审查后）**：上面的结论只对 run-001 成立，不能推广为"零新概念"。run-002 的盲题（设计时没见过）表明，有三类需求只靠"八概念 + 四种规则 + 数据"做不到，必须新增**规则形状**（01 §1.8）：①**规范条目与规范栈**（戒律、郡法村规、议案效力、域外管辖、罪名谓词，05 §5.2）；②**主观视图与推断规则**（谣言驱动行为、推测产生传闻，05 §5.4）；③**修正项注册**（新包影响他包的派生，05 §5.9）。另有若干必须的字段级扩展：义务的 `onDebtorGone`、持有的 `incompatibleWith`、资源的 `lots`、物品的 `purports/records`、群体子账户、分区与方位。它们都存放在已有八个概念里（组织事实、包数据、账户键、地点树），**存储概念仍是八个**；但"新增的只有数据"这个说法撤回。修订后的走查见本章末 §9.21。本章下面各题按修订后的设计更正了两处写法（E05 货物受潮、E10 上诉）。

## E01 上游过伐，下游秋旱【离屏】
- 建模：溪流 = 两个河段地点，有向路线边（石坳段 → 柳溪段）；每段账户：水量、水质（浊度/毒物/病原）；石坳林地 = 资源点（木材储量）；矿场 = 建筑，经营持有；柳溪渔场 = 资源点 + 种群账户；柳溪田地 = 作物生长事实。
- 链：伐木动作 = transfer(木材, 林地 → 伐木者)；林地覆盖率派生下降 → 河段入流系数派生下降；矿场日流量规则 = transfer(污染, src → 石坳段)；顺流时钟规则按日把污染与水量沿有向边传递（迭代规则，容差声明）；旱灾 = 天气时钟减入流。柳溪段账户变化 → 渔场容量派生降 → 种群账户下降 → 渔获下降；作物产量派生读柳溪段水量与水质各一次（I4：一个起因一次扣减）；疫病规则读水质暴露 → 腹泻病例事实；药材需求流量上升 → 价格投影上升。
- 预期：①水质下降的起因链可追溯（事件 cause 指向伐木与排污事件）②柳溪鱼价粮价涨（本地存量降）、石坳柴价跌（木材入市存量升）③病例集中下游（暴露派生只在下游段）、药价涨④柳溪村民对石坳村的立场：harm 事件（起因链归因到石坳的伐木/排污经营者）→ impress → 沿 member_of/resides 传导到村级立场⑤玩家回来只得 tell 版本（"上游把水弄坏了"），排污量数字只在账户里。
- 现状错误：无水系、无污染源、价格与事件无因果、无村对村立场（verdict-a E01 全部部分/缺失）。目标下由河段账户与顺流规则直接给出。
- 新增：数据（河段地点与有向边、污染资源种类、顺流规则参数、入流系数表）。

## E02 镇长暴毙【离屏】
- 建模：周廷 = person；镇长 = office（所属青石镇治理组织）；酒坊 = building + operates；雇工 = employed_by + wage 义务；钱庄贷款 = loan 义务（债务人周廷）；侄子 = person，guardian_of 持有（周廷 → 侄子）。
- 链：自然死亡（npcLife 时钟）→ transition(gone)：①权能：holds_office 关闭 → 职位继任规则 deputy_then_election（副职代理、补选到期项）；俸禄义务累计止于死亡时刻（闭式读到 accruedTo=死亡时刻）②照护：guardian_of → succeed（族谱顺位：法域继承表给出下一顺位亲属）③经营与用工：operates/owns(酒坊) → estate；employed_by 雇主侧 → estate；工资继续累计，遗产付不出 → 停工反应④财产与债：loan 债务端 → estate⑤清偿：遗产按法典顺序付工资、贷款；不足记 bad_debt；永不对死者立 default⑥分配：净资产按继承表；无继承人 → 官府封存（法域规定）⑦日程：死者无持有 → 无日程。
- 现状错误：遗产先分后还债且对死者立违约案；雇工合同死亡即终止；监护只改"待指定"；头人死后无人代理（verdict-a E02）。目标下由协议顺序与交接类直接给出。
- 新增：数据（法典清偿顺序、监护顺位、职位继任规则）。

## E03 玩家当村长，村升为镇，再被罢免【主动】
- 建模：柳溪 = settlement（事实 rank）；村长 = office（职级 head，所属柳溪治理组织）；管事 = office（由村长职位 appointed）。
- 链：当选（选举包动作）→ holding.open(holds_office)；职权、额度、俸禄、职名由 `职级 × rank` 查表派生。升格议案 = 治理动作，前置读设施种类（集市、驿站）与 condition ≥ 阈；通过 → fact.set(rank=镇)（altered）→ 反应"确保镇级应有职位存在"创建空缺职位；税率税基由新 rank 派生。罢免 = vacated：holds_office 关闭 → 任免权与公库权限的派生即刻为假；管事的 appointed 授予者是村长职位而非玩家 → stay；新镇长可用撤换动作。
- 现状错误：被任命者随任命人免职而失职；升格后职名"村管事"写死；升格条件只数设施个数（verdict-a E03）。
- 新增：数据（升格条件表按设施种类、等级职位表含名称）。

## E04 矿脉见底，夜间盗采【连锁】
- 建模：黑岩铁矿 = node（储量账户）+ owns(矿主)；矿工 = employed_by + wage；工匠玩家。
- 链：欠薪累计 → 停工反应（正规产量规则暂停）→ 铁入市流量为零 → 存量降 → 价格投影升 → 制造成本派生读同一价格。NPC 自治：需求（钱）+ 机会（熟悉矿口）+ 性格 → 提案 "盗采" 动作（参与者模板 agent，不限玩家）→ transfer(矿石, node → 矿工)（同一账户扣减）+ 无许可 → offense:illegal_mining；巡检在场见证 → 立案；私卖 = 物品来源事件链 → 买方持有赃物 → offense:fencing 可追；储量账户归零 → 采掘动作前置失败。欠薪 → wage 义务违约 → 民事案件 → 判决执行义务按清偿顺序（工资优先）。
- 现状错误：NPC 不会盗采；矿口无法典辖区；无买赃罪名；无工资优先（verdict-a E04）。
- 新增：数据（罪名表 illegal_mining/fencing、清偿顺序、矿口挂父节点）。

## E05 冬季托运到远方【主动】
- 建模：船 = item 实体（容量事实）+ owns(船主)；托运 = delivery 义务；护卫 = escort 义务（工资按天闭式）；两道关卡 = 地点，各自法域；汇票 = bill 义务（持票人）；星湾 = LOD2 纲要节点。
- 链：下单动作前置：载量 ≤ 容量（超载拒绝或分批 = 两张运单）；在途 = move 原语按路线逐段，天气时钟标记港口"滞留" → 船位不动 → escort 义务的 accruedTo 继续累计（9 天工资）；每段进入关卡地点 → 关税反应规则按该地法域税表 transfer 到该政体公库；风暴反应 → 货物（药材、粮是 `lots` 资源）该批次的暴露量 fact.set（批次元数据白名单字段）→ 腐坏时钟规则按保质曲线把相应数量转入 sink:decay → 合同货损条款按损失派生索赔义务（计量物没有 condition 字段；只有车船这类物品个体才有）；到达星湾 → 首次到达生成（种子物化骨架）；到达前价格投影对玩家"未知"；汇票兑付动作前置：兑付地存在该钱庄 branch 持有。
- 现状：多数合理；护卫费一次算定、无货损、到达前无法下单（verdict-a E05）。目标：义务累计与条款派生解决前两者；"向未到达的远方下单"允许——目的地是 LOD2 节点即可作为路线终点，细节到达时物化。
- 新增：数据（车船模板、关税表、网点持有、货损条款）。

## E06 夏夜铁铺火【离屏】
- 建模：铁铺 = building（材质性状、事实 forge.lit）；粮仓 = building + owns(玩家) + leases(米商) + 库存账户；关帝庙 = org（寺观）+ building；相邻关系 = 地点间距离边。
- 链：铁匠日程派生 → 收工离店；反应规则"炉火未熄 + 经营者不在 + 风大 → 概率 ignite"；spread 规则读相邻边距离、风向、材质（K2 flammable）、雨 → 粮仓、偏殿按概率引燃；burning → condition 下降 + 库存 transfer → sink:destroy → 粮价投影升；租金义务金额 = 条款 × condition 派生系数 → 0；庙的香火流量派生随 condition 降；修缮 = project 义务（募捐 = transfer 入寺观公库）；ignite 事件带 offense:negligent_fire（起因：疏忽）→ 法域罪名表含 → 立案 → compensation 义务给邻舍。
- 现状错误：不看风向、不烧库存、毁损仍收租、无失火罪、起火源与日程无关（verdict-a E06）。
- 新增：数据（蔓延参数、负责人疏忽规则、罪名）。

## E07 首领巨蟒出巢，兽群下山【连锁】
- 建模：青鳞蟒 = creature + controls(领地地点集合)；野猪 = population 账户（按地点）；麦田 = 地点 + 作物事实；猎犬 = creature + tamed_by(玩家) + 健康事实。
- 链：首领领地扩张 = holding.open(controls, 新地点) → 这些地点对其他物种的容量派生降 → 迁徙时钟规则按流量把野猪账户移向容量更高的邻地（含麦田）→ 害兽压力派生 → 作物损失；击杀（战斗）→ transition(gone) → controls 关闭 → 容量恢复 → 回迁流量按速率逐日（不瞬间）；猎犬受伤 = vital → 健康事实；不治 → 恶化时钟规则 → 死亡或退化；巢穴空置 → 时钟规则 N 天后另派占据者（不同物种）；击杀事件高显著度 → 传闻链 → 名士条件派生读玩家知情集合外的"公众知情"；猪肉入市 transfer → 存量升 → 价格投影降。
- 现状错误：首领无领地挤压、兽群不回迁、外伤不恶化、名声不计击杀、野味越猎越贵（verdict-a E07）。
- 新增：数据（容量表、迁徙速率、名士条件含武功）。

## E08 昏迷者能不能施治疗术【连锁】
- 建模：阿蔓 = person（未成年事实）+ status(unconscious)；父亲 = guardian_of 持有人（在外地）；叔叔 = kin，无监护持有；玩家法师；医师在场。
- 链：施法动作读"同意"（裁决输入，附录 A §A.15）：canConsent(阿蔓) 派生 = 假（失能）；代理同意 = guardian_of 持有人（父亲，不在场 → 不能当面同意；法典可规定书面/传讯同意）；叔叔的同意无效（无持有）；紧急救治条款 = 法典数据（哪些状态、哪些法术类别可免同意）；强施 → 施法照常裁决（无同意转对抗检定）+ 描述标签 unconsented → 规范栈谓词命中 offense:unconsented_magic + 见证 → 家属（kin 持有）可立案；医术动作（医疗包）不在"需同意"表中（法典数据）→ 不受限；救活 → gift/help 事件 → impress → 沿 kin 持有传导。
- 现状：同意能力与叔叔无效正确；监护人代为同意不支持；紧急条款只覆盖濒死；无非魔法诊疗；治疗不触发立场（verdict-a E08）。
- 新增：数据（同意代理规则、紧急条款、医术动作）。

## E09 催熟术冲击粮市【主动】
- 建模：催熟术 = spell 实体 + registered 持有（法域管理职位）；开班 = 学堂组织 + service 义务；册子 = item（teaches）；邻村农户 = NPC 自治施法者；粮商商会 = org + member_of。
- 链：未登记授课 → 动作打 offense:unlicensed_teaching → 立案；登记后合法。学习 = learn 原语，前置派生（识字技能、资质、前置技能）→ 学会人数受限；书本只对识字者产生 learn（E09②）。NPC 学会后自治包在农忙目标下提案施法 → 产量派生读生长加成（原语上限 + 地力 + 天气）→ 粮入市 → 价格投影降 → 农户收入派生降；粮商收益派生受损 → harm-to-interest 规则 → impress(商会 → 玩家) → 沿 member_of 传导到成员。
- 现状：登记不管授课；NPC 不施法；商会整体立场未核实（verdict-a E09）。
- 新增：数据（罪名、生长原语上限、利益受损反应规则）。

## E10 跨政体婚姻的分产【离屏→连锁】
- 建模：韩旭 = person；婚姻 = kin:spouse × 2 + 缔结地事实；布庄股份 = share 持有（0.3）；长子、幼女 = kin:child；莎尔 = member_of(部盟)。
- 链：病逝 → transition(gone) → estate；适用法派生（冲突法表）：股份按财产所在地（青石镇 → 王国法）、动产按婚姻缔结地；继承表给出分配；莎尔主张均分 → 分产争议动作 → create(case) → frozen 持有覆盖该 share → 分红义务改付案件托管；监护：guardian_of 候补顺位（父母优先 → 莎尔）；判决事件 → 改分股份（总和 1.0，I8）→ 执行到期项 = 判决 + 上诉期；上诉动作 → 阶段"上诉中"，执行是否暂停读王国法典的 `appealStaysExecution`（本例：分产判决上诉期间暂停执行，股份保持冻结；别的法典或案件种类可以规定照常执行、改判后回转，见 run-002 E13③）；二审判决 → 执行；判决事件 → impress（莎尔 → 王国）沿 member_of 传导 → 部盟对王国立场变化。
- 现状：不看财产所在地与婚姻地；无冻结；上诉不暂停；无势力后果（verdict-a E10）。PR-02 延后部分已有 estateLaw/equityFrozen 思路，吸收。
- 新增：数据（冲突法表、上诉期、appealStaysExecution）。

## E11 掌门坐化，门派争位【连锁】
- 建模：清虚观 = org（章程：继任 duel）+ 公库；掌门 = office；两长老 = holds_office(长老)；玩家 = member_of + certified(道士认证，所属清虚观认证职位)。
- 链：坐化 → transition(gone)：掌门职位 vacate → 继任规则 duel → 决斗动作（参与者模板 agent，两 NPC 由自治包接受约斗）→ 战斗包结算（约定生死为条款）→ 胜者 holding.open(holds_office)；公库是组织账户不动；掌门私产 → estate；玩家的 member_of 与 certified 不受影响（stay）；败方长老 defected → 追随者按立场比较各自 defect → 成员数派生降 → 香火流量派生降；新掌门对玩家立场 = 印象投影（玩家支持事件在其知情集合内）。
- 现状：NPC 间不能决斗、无继任流程、无集体出走、玩家站队不影响（verdict-b E11）。
- 新增：数据（章程继任规则 duel、追随者分流阈值）。

## E12 玩家离开一年后回村【离屏】
- 建模：存款 = deposit 义务；借款 = loan 义务（12 期）；铺面 = leases；狐狸 = tamed_by + custody_of(邻居, 条款: 候补)；冬麦 = 玩家田地（owns）+ 作物事实。
- 链：全部义务按 accruedTo 闭式累计，分期到期项逐期尝试清偿 → 老秦摔腿（健康事实）→ 收入派生降 → 付不出 → overdue 事件 + 罚息累计 + 三期 default（不免除）；退租 = leases 关闭 → 租金累计止于当日；托养：custody_of 候补条款（受托人死亡 → 同户成年人；迁走 → 宠物回主人处等待/无人照看分支）；冬麦生长时钟 → 成熟 → 无收割动作 → 腐烂规则（transfer → sink:decay）或 NPC 自治在需求下盗收（offense:theft）；玩家知情集合只含驿传 tell 事件；老秦摔腿事件不在集合内 → 回村问人（打听动作）才知。
- 现状：玩家放贷不逐期记逾期、无罚息、借期上限 90 天、伤病不算无力偿还；无托养；无私田与腐烂（verdict-b E12）。
- 新增：数据（义务日程条款、托养候补、腐烂规则）。无新存储概念。

## E13 部盟与郡交战，玩家护送使节【主动】
- 建模：战争 = 政体关系状态 + 时钟阶段；边关 = 地点 + controls(封闭)持有；使节护送 = escort 义务；子爵 = office(peerage) + fief。
- 链：开战阶段 → holding.open(controls:closed, 关卡) → 路线通行派生为不可 → 贸易流量停 → 盐、铁按供给地距离派生（封关 = 无穷）→ 价格按品类升（依赖哪些货经该关）；护送途中遭遇规则读 standing(区域控制者, 队伍) → 拦截战斗；议和事件 → 阶段"解封"按天解除持有 → 存量随流量恢复 → 价格回落（不重置）；册封 = 治理动作 → holding.open(holds_office: 子爵) + fief → 俸禄/封地收入/额度自册封时刻派生；立场双键分离。
- 现状：战时涨价不分品类、无拦截、议和当场恢复、不能因功受封（verdict-b E13）。
- 新增：数据（战争阶段表、品类供给路线、册封动作凭据）。

## E14 玩家建国，同伴叛变【主动】
- 建模：建国 = create(org:polity) + governs(废城及周边) + 法典数据副本；石彪 = member_of + holds_office(伯爵) + fief；邻国 = org。
- 链：承认 = 各政体关系投影（外交包按立场与利益决定），不自动；法典只对 governs 地点的法域生效；叛变 = defected：member_of 关闭 → 伯爵职位 vacate → fief retain_disputed → create(claim)；玩家的除爵动作 = holding.close(fief, revert)（在此之前石彪保留实控：法域仍按 governs 派生为玩家政体，实控只影响通行、执法可达与税收实收，B-S30）；邻国接纳 → 邻国 governs 主张 → 战争/外交裁决 claim；部下按 standing 比较各自 defect。
- 现状：无授爵除爵入口；叛变自动分裂；无人员分流（verdict-b E14）。
- 新增：数据（claim 为案件种类数据、授爵/除爵动作）。

## E15 涝灾后疫病，寺观求神迹【离屏→连锁】
- 建模：河堤 = 设施（condition）；农田 = 地点事实；伤寒 = 病种数据；黄连 = 资源点账户 + 市场；寺观 = org + 公库 + 神祇实体（神迹条件与冷却事实）；镇公库 = 账户。
- 链：灾害时钟 → 溃决 → fact.set(田地 condition) + 河段水质 → 感染率派生 = 基率 × 水质暴露 × 人口密度 → 病例事实；药材需求流量升 → 存量降 → 价格升；采药 = transfer 受资源点储量限制；义诊 = service 义务，消耗玩家账户药材与时间；神迹 = 宗教包动作，前置读神祇事实（条件、冷却、代价）→ 有限效果；公库拨款 = transfer 受 I2（不得低于留底）；改宗 = member_of 变更（由立场与需求驱动）→ 香火流量派生升。
- 现状：传播率随户数反向、不接水质、无诊疗、公库只能玩家动用、香火不随信众（verdict-b E15）。
- 新增：数据（病种、神迹条件、NPC 官府赈灾的自治目标）。

## E16 争水杀人，缺席审判【离屏】
- 建模：分水口 = 资源点（水量账户 + 取水持有）；王二、李三 = person（性格数据）；李家 = 家户组织。
- 链：自治包：水量不足 → 争执目标 → 性格暴烈 → 斗殴动作 → 战斗 → vital 致死 → transition(gone)；事件带 offense:homicide + 见证/证据 → 立案；王二逃亡 = move 到他政体 → wanted 持有范围由引渡派生 → 无引渡则不可执行；李三财产 → estate → 继承表；harm 事件 → impress 暴跌 → 沿 kin/household 传导到王二全家；复仇 = 自治决策（性格 + 立场 ≤ 阈）→ 新犯罪事件；分水争议 → 村民大会议案到期项（治理包，NPC 可提案）；玩家回村：tell 版本由失真表生成（死因细节替换）。
- 现状：NPC 伤人上限 hp-1、不逃亡；无水源；议案只玩家提；转述无内容失真（verdict-b E16）。
- 新增：数据（失真表、NPC 提案目标、水源账户）。

## E17 蛇巢古书与隐藏职业【主动】
- 建模：《御兽经》残卷 = item（teaches: 隐藏职业契机 + 前置）；驭兽师 = office(认证资格，隐藏)；猎人行会认证 = certified；巢穴 = 地点 + controls(青鳞蟒)。
- 链：读书 = learn 前置派生（猎人等级、驯兽经历 = 知情集合内的驯服事件计数）→ 不满足无效；满足 → 契机事件 → 取得动作 → holding.open(certified: 驭兽师)；宠物名额 = 职业被动派生（读全部 certified 持有）；原 certified 不动；借阅 = holding.transfer(owns) / 抄写 = create(item) → 他人 learn 按识字与资质；巢穴有 controls 持有且持有人在场 → 进入动作触发遭遇规则（首领认知：守界警告 → 敌对按记忆）。
- 现状：宠物上限写死两职业；书本传播无地区模型；进巢不自动开战（verdict-b E17，后者按首领认知设计可接受）。

## E18 掌柜卷款，股东连坐【连锁】
- 建模：丰和米行 = business（经营账户）+ share(玩家 0.4)；掌柜 = employed_by + operates（动用经营账户的权限）；雇工 = wage 义务；秤具 = item（owns 米行）+ pledged（当铺）。
- 链：自治包：掌柜需求（钱）× 机会（经营权）× 性格（贪）→ 挪用动作 = transfer(经营账户 → 私囊) + offense:embezzlement + move 逃亡 → 立案 → 引渡派生；工资累计 → 停工；股东责任 = 章程数据（有限/无限）→ 债权人追偿义务按责任类别落到股东；当票到期项 → 绝当 → owns → 当铺；信誉 = 公众对米行实体的立场投影（harm/breach 事件传播）；商会按章程开除条件 → member_of 关闭（店铺可为组织成员）；股份价值 = 净资产 × 份额 → 缩水。
- 现状：无 NPC 卷款、无股东责任、NPC 不能典当、店铺不是商会成员（verdict-b E18）。
- 新增：数据（责任类别、挪用动作、店铺可入会）。

## E19 名士诗作与识字率【离屏】
- 建模：沈砚 = person + 名士资格（office 种类 notable）；《原野行》= item/作品实体（署名）；学堂 = org + 教师职位 + service 义务；识字率 = 投影。

- 现状：NPC 无作品与名士；办学不能动公库；赞助无回报（verdict-b E19）。
- 新增：数据（作品实体模板、传播参数、公库拨款动作）。无新存储概念。

## E20 伐木建房，触怒林地议会【主动】

- 新增：数据（非人法典、照会阶段、补植动作）。
