# 02 不变量：每条由哪一层保证、怎样自动测试

不变量是架构的验收标准，不是文档承诺。每条都对应一个测试组；迁移期间允许标记"目标中"的失败并按阶段收紧（见 10 迁移路线）。基线 23 项预期失败（tests/baseline，旧版核心）不受影响，原样保留。

## 2.1 清单

| # | 不变量 | 保证层与机制 | 自动测试 |
|---|---|---|---|
| I1 守恒 | 每笔价值变化是账户到账户的转移；含源汇账户的全局总量在任意两时刻相等 | L0 账本：存量字段只有 `transfer()` 能改；源汇是账户；事务内校验 | 性质测试：随机事件流后 Σ账户(含源汇) 为常数，每个资源种类一条；三年日结守恒（现有 agriculture 长测改读账本） |
| I2 非负 | 任何账户不为负，除非该账户所属实体有授信义务覆盖缺口；公库拨款不得低于留底 | L0 事务校验 + 义务种类声明授信 | 性质测试 + 回归（公库赤字拨款被拒，E15） |
| I3 单一写入 | 状态只在内核归约事件时改变；规则/包/工具/LLM/界面只提交提案 | L0：状态对象在归约之外冻结（开发模式用 Proxy 抛错）；包没有写入口 | 外部写检测器（遍历包模块的 import，禁止 import 内核内部写 API）；重放逐字节一致（现有） |
| I4 幂等起因 | 同一起因事件对同一规则只触发一次 | L0 幂等键 (规则, 起因事件) | 重复派发同一事件 → 转移数与事件数不变；E01 产量不重复扣 |
| I5 交接声明 | 每种持有在注册时声明交接规则、标的消失规则、互斥与份额约束，否则启动失败 | L1 注册表 | 注册表完整性测试；新包加入时自动覆盖 |
| I6 转移完备 | 转移协议完成后，消失/被免实体名下无存活的持有、权能、日程；职位持有人 ≤ 1 | L1 协议末步扫描断言；失败整体回滚 | 随机实体随机触发 → 扫描为零；E02/E03/E11/E14 脚本 |
| I7 义务两端 | 每个义务两端解析到存活实体或遗产/案件托管账户；对已消失实体不立违约 | L1 协议 + 义务种类的违约规则读取债务人状态 | 死亡后推进 → 无 default 事件，有 bad_debt/清偿事件（E02③） |
| I8 份额守恒 | 同一标的股份总和恒为 1.0；互斥持有同时只有一个 | L1 持有约束，事务内校验 | 继承/转让/冻结随机序列后求和（E10） |
| I9 法域可解析 | 每个地点能沿包含树解析出法域；生成新地点必须挂到有法域的父节点 | L1 派生 + 构建期校验 + 生成器前置检查（拒绝而非兜底） | 构建期全量扫描 world/geo；运行期远方生成测试；E04 矿口 |
| I10 派生不落盘 | 黑名单字段不出现在作者数据与存档；覆盖项必须标注 | L1 schema 黑名单 + 数据校验器 | 数据覆盖测试扫描 world/ 与存档快照；A1 名单作初始黑名单 |
| I11 读取派生 | 权限、额度、俸禄、职名、服务在读取时由当前持有算出 | L1 视图 | 免职/升格/受封后立即读取（E03、E13④） |
| I12 知情可溯 | NPC 知情集合 = 见证 ∪ 被转述；投影给 LLM 或界面的每条事实可回溯到其中一条；私密事件不出现在非在场者的卡上 | L3 知情投影 + 场景卡审计 | 场景卡每行附来源事件编号（渲染前隐藏）；N6/N7/N16 类试玩的确定性断言 |
| I13 时间单调 | 时间单调不减；到期项按时间序处理；`accruedTo` ≤ 当前时刻 | L0 时钟 | 现有时间测试 + 义务累计重放 |
| I14 离屏等价 | 任一层级推进 N 天的账户总量与逐日推进相等（闭式规则）或在声明容差内（迭代规则）；玩家逼近时补算无可见跳变 | L0 时钟层级 + 规则声明 closedForm/tolerance | 等价测试：同种子两种步长比对；现有 advance-registry 快照改为"逐日 vs 一次"对照 |
| I15 单一账户 | 一个实体同一资源同一用途只有一个账户；组织公库 ≠ 首领私囊；势力时钟与组织共用公库 | L0 账户键唯一 | 结构测试（V4 已做一半） |
| I16 事件主写 | 每个状态变化都对应事件日志里的一个事件及其原语列表；从快照 + 事件可重建状态 | L0 归约 | 重放测试（现有）+ "差分=原语"对照（迁移期：deriveWorldEvents 的差分与事件原语一致） |
| I17 缓存可重建 | 任何投影缓存丢弃后重算结果相同 | L3 版本键 | 随机丢弃缓存重算比对（立场、知情、价格） |
| I18 词汇封闭 | 事件动词、标签、持有种类、资源种类、罪名标签只来自 L1 词汇表 | L1 校验器 | 构建期扫描包声明；运行期提案校验拒绝未知词汇 |
| I19 依赖方向 | import 只向下；包之间无 import；L1 不 import 包 | 构建期 import 图测试 | 解析全部模块 import，向上或包间边即失败（含动态 import） |
| I20 提案受限 | 任何提案（含 LLM 与界面构造器）的每个原语幅度 ≤ 由规则与当前状态派生的上限；未知引用拒绝；未声明的 create 拒绝 | L0 事务 + 06 动作层校验器 | 意图语料（06 §6.11）：超幅提案全部被裁剪或拒绝并带原因 |

## 2.2 测试组织

- `tests/invariants/`：每条不变量一个文件，文件名即编号（`i01-conservation.test.mjs`…）。性质测试用 fast-check（指南 11.1 已要求），事件流生成器从动作目录与时钟规则随机抽样。
- `tests/probes/`：事件推演脚本化。run-001 每题一个脚本：夹具世界 + 扰动 + 断言；断言由非实现者编写（PR 原因分析第二条）；主会话汇总合理率。
- `tests/intents/`：动作层意图语料（06 §6.11）。
- 迁移期分组：`target:` 前缀的测试允许在 PLAN 登记的阶段前失败，`npm test` 分别报告"目标中"与"必须通过"两组；合入门槛只看后者，但前者的通过数只能升不能降（防回退）。
- 基线：`tests/baseline/` 的 19 E + 4 M3 旧版核心预期失败不动。

## 2.3 不变量与 run-001 错误的对应

| run-001 主要错误 | 违反的不变量 | 目标下为何不再发生 |
|---|---|---|
| 遗产先分后还债、对死者立违约案 | I6、I7 | 协议顺序：清偿在分配前；违约规则读债务人状态 |
| 建筑毁损后租金照收 | I11 | 租金是义务，金额由建筑 condition 派生 |
| 罢免后被任命管事随之失职；升镇后"村管事"名称写死 | I11 | 任命由职位发出；职名由聚落等级派生 |
| 野味越猎越贵 | （市场投影） | 价格读本地可售存量与需求流量，猎物入市即压价 |
| 矿口无法典辖区、盗采不立案 | I9 | 法域不可解析即数据错误；矿口挂父节点 |
| 议和当场恢复战前物价关卡 | （市场投影、持有） | 价格不存；封闭是持有，按阶段解除，存量随通路恢复 |
| 无授爵/除爵入口、叛变自动分裂 | I6、动作层 | 爵位是职位；封地持有的 defected 交接类 = 保留实控立 claim |
| 放贷不逐期记逾期、限 90 天 | （义务） | 义务日程是数据，分期到期项逐期产生逾期事件 |
| 宠物不能托养、上限写死两职业 | I11 | custody_of 持有带候补；名额由职业被动派生 |
| 首领死后无 NPC 继任、NPC 间不能决斗 | I6 | 职位空缺走继任规则；决斗是动作规则，参与者模板为 agent，不限玩家 |
| NPC 犯罪不致死、不逃亡、不卷款 | （自治包） | 自治决策产出的事件走同一原语：vital 可致死、move 可逃亡、transfer 经经营持有可挪用 |
| 离屏事件直接写记录不发布 | I16 | 没有不经事件的写入 |
| 同一势力两份公库 | I15 | 账户键唯一 |
