## 5.1 经济

**账户**：人（钱袋、随身物）、建筑/商号（库存、经营账）、聚落（公库、粮仓、公产、聚合市集账户）、组织（公库）、遗产与案件（托管）、资源点（储量）、源汇。铸币按政体分资源种类。资源种类带商品类标签 `goods:*`（第12章 §12.4.5），替代品按商品类聚合。

**转移是唯一动作**：
- 买卖 = 同一事件里钱与物两笔互逆转移；报价来自市场投影，当日缓存保证一致（L3）。
- 税 = 反应规则在交易事件后从买方/卖方向法域公库的转移，税表是规范栈中的条目（按商品类标签 × 聚落等级，主权法典与次级规范都可设）；关税与通行费 = 经过关卡或 `controls` 节点时按该节点规范栈税表与控制者条款的转移（run-001 E05③）。
- 利息、租金、工资、分红、俸禄 = 义务按 `accruedTo` 闭式累计，到期清偿即转移。土地租约与建筑租约分两种条款：建筑租约的租金读 condition 派生系数；土地租约不读 condition，遇灾减租只能来自合同条款、规范条目（例如通过的"霜灾减租"村规）或出租人的动作（E17②③）。
- 存款 = 钱庄对储户的义务；汇票 = 不记名债权 + 代表它的票据物品，清偿前提是兑付地有该钱庄的 branch 持有（run-001 E05⑥）。
- **票据结算**（run-002 修订，E7①）：以票据缴税或付款 = 票据物品 holding.transfer 给收款人 + 被清偿义务标记 `settledBy: 票据`（附条件清偿）。收款方"可用余额"派生时把未兑付票据列为应收而非现金。票据兑付时最终确定；若被拒付或识破为伪造（`represents` 为空），反应规则重开被清偿的义务（obligation 状态回到未清，起因指向拒付事件），收款方账面自然"冲回"——因为钱从未进入其账户，不需要逆向转移。伪造与行使伪造票据是否构成罪名由规范栈谓词判定（§5.2）。
- 质押 = pledged 持有；绝当 = 到期项把 owns 转给当铺（run-001 E18②）。
- 股份 = share 持有（份额）；分红 = 组织 → 持有人的义务；价值 = 组织净资产 × 份额（run-001 E18⑤）。组织章程 `acceptsShares: false` 时，"入股"提议被路由为捐赠（转移 + 功德/立场事件，不开 share、不生分红义务，E11⑤）。
- 雇佣 = employed_by 持有 + wage 义务；停工 = 反应规则 `当 wage 欠额 ≥ 阈 → status(employee, striking)`；辞工/挖人 = 持有关闭/新开。
- 托运 = delivery 义务 + 车船物品实体（容量事实）+ 在途位置（move 原语按路线逐段，天气与封闭使其滞留）；护卫 = escort 义务，工资按实际天数累计（run-001 E05②）。**运力**由派生得出：`min(车船容量, 所 owns 役畜种群数量 × 每头载量)`，役畜是商队或驿站 owns 的种群账户，马瘟使其数量下降 → 运力降 → 托运价与在途时间上升（E14①）。
- 远期交付 = forward 义务（青苗契等）：对价先付，实物到期交付（N1）。

**价格是投影**：
```
价(地点, 商品类) = 基准(资源模板)
               × 本地稀缺( 有效存量 ÷ 有效需求，钳制在 priceFactorLimits )
                   有效存量 = 本地可售存量（批次按品质档）
                            + Σ 未到期、交付地为此的远期/托运义务 × 可靠度(债务人违约史派生) × 时间折扣
                            − Σ 本地存量上已承诺的未到期交付
                   有效需求 = 近期需求流量 + 预期需求（季节、疫情、工程材料需求）
               × 供给地到岸成本( 最近有存量的供给地沿可通行路线：距离 + 运力 + 风险 + Σ沿途关税与通行费；封关 = 无穷 )
               × 季节(资源种类 × 季节表)
               × 法域政策(规范栈：战时按品类、管制、税)
               × 店家与关系(店主加成、立场、声望)
               × 已注册修正项(槽 economy:price，§5.9)
```
- 沿途关税读各节点规范栈的税表，不读路线边上的存储字段（01 §1.5）；所以联邑对铁锭加征关税后，依赖经该关进口的地区涨得多、本地有矿的地区涨得少（E8①）。
- 路线风险由沿线 `controls` 持有人（首领、山贼）与近期 harm 事件派生，镖价、托运价读同一风险（N4③）。
- 远期项让大量预售提前压低秋季的"可自由买到的存量"、让交付违约史差的卖方的契约打折——"预售让现货价提前反映预期"（N1②）不需要改市场代码之外的任何包。

不存价格状态。战后不"重置"，价格随存量与通路恢复而回落（run-001 E13③）；猎物/作物入市即压价（run-001 E07⑥、E09③）；生活魔法的产量变化经账户进入同一公式（U10 方向正确，只需改读账户）。

**一处计算、多处引用**：制造成本、建造成本、俸禄购买力、股份估值、损失评估全读同一投影；22 处价格计算归一。

**生产投入**：产量派生（作物、矿、工坊）开放修正槽（§5.9），农具、耕牛、肥料的存量以修正项进入；农户的投入决策是自治包读价格与自身账户的成本收益判断，所以农具涨价 → 少买农具 → 下季产量修正降（E8⑥）。

**统计层的经济**：远方聚落只有聚合账户（粮、木、铁、钱、药材）和聚合流量（产量、消耗、贸易），按月闭式结算；聚落实体的"聚合市集账户"可作为义务端点（聚合收货人，07 §7.3）；玩家到达时按种子物化个体账户，并从聚合账户"借出"初始存量（守恒）。

## 5.2 规范层：法域、法典、次级规范、成员规范与案件

### 5.2.1 规范条目

法律、村规、郡法、门规、戒律、条约里的约束都用同一形状——**规范条目**（01 §1.8）：

```
规范条目 = {
  source:   来源组织（政体 / 治理组织 / 门派 / 寺院 / 行会 / 家族）,
  scope:    适用谓词（下列一种或组合）
            place_subtree(地点)            —— 属地：事件发生在该子树
            member_of(组织) / certified / holds_office(该组织职位)  —— 成员：行为者具有该身份
            citizen_of(政体) / holds_office(政体爵位)            —— 属人（域外管辖用）
            property_in(地点)              —— 物之所在（租约、地产）
  layer:    sovereign | subordinate | membership | personal | contract
  priority: 同层内的次序（数据给出；第三方绑定的冲突裁决见第12章 §12.4.4）
  content:  罪名谓词 / 民事条款 / 程序条款 / 税表 / 授权表 / 豁免 / 冲突法 / 兼任规则 / 合同效力
  version, enactedBy（事件）, effectiveFrom
}
```

规范条目存为来源组织实体的"法典/章程"事实（01 §1.2），不是新存储概念；一方包与第三方包的法典文件（第12章 `law/codes.json`）在纪元边界转换为这些事实；议案通过是对其的 fact.set 事件。

### 5.2.2 规范栈

`normStack(行为者, 地点, 时刻)` 是 L1 派生，返回有序列表：

1. **合同层**（只对民事条款）：当事人的条款快照。
2. **次级属地层**：从地点向上，沿包含树收集 `administers` 该节点的治理组织（村民大会、镇、郡府）的次级规范，以及第12章 `place.lawCode` 槽位的地方法典绑定——**槽位绑定就是"地点子树"类条目的单一赢家约束**（同一节点同一层只能有一个绑定，冲突按第12章 §12.4.4 报错）；越具体（越靠近事件地点）越靠前。
3. **主权层**：最近 `governs` 政体的法典。
4. **成员层**：行为者所属组织（member_of、certified、holds_office）的门规戒律，与地点无关。
5. **属人层**：任何政体法典里 scope 为 citizen_of/爵位、且声明 `extraterritorial` 的条款（例：王国法"本国贵族在境外杀害本国贵族者，归国可诉"）。

**生效规则**：
- **下级只在授权内生效**：主权法典（或上级次级规范）的**授权表**写明下级可以设哪些条款族、可约束谁（本地居民 / 一切在场者 / 本地财产）、可设的刑罚上限、哪些主权条款 `reserved`（不可被下级覆盖或豁免，例如叛逆、铸币）。越权部分无效，议案动作的预览给出世界内原因（"村规管不到外村地主的租约"，E17③）。第12章的地方法典绑定视为主权方以安装配置授予的完整地方立法权，只受 `reserved` 限制；core 政体法典缺省只保留叛逆、主权与铸币类条款。
- **民事、程序、税条款**：按栈序取第一条覆盖该事项的条款（合同 > 次级 > 主权 > 包缺省），未写的事项用 `inherit` 回落上一层。
- **罪名**：属地层（次级 + 主权合成一部"行为地法"）独立判定一次；属人层各自独立判定，产生的案件只能在该政体能执行处执行（境内或经引渡），法典可声明"一事不再理"条款；成员层判定交给来源组织的内部程序。
- **罪刑以行为时法为准、程序从新**：案件记录立案时所用规范条目及版本；之后法典修订或第12章卸载时，罪名与刑罚按行为时版本（刑罚取轻），程序按现行；合同效力随条款快照冻结。

### 5.2.3 罪名判定：对原语与持有状态的谓词

罪名不再由"动作本身的规则打上"。罪名表的每一项是谓词，由法律包的立案反应对**每个事件**按规范栈求值：

```json
{"offense": "offense:smuggling",
 "when": "anyPrim(op in ['move','transfer'], commodity == 'goods:salt', crossesNode(scope)) && warrantCover(actor,'goods:salt',now) < qty",
 "roles": {...}, "penalty": {...}, "evidence": "witness || evidenceChain"}
```

- 谓词能读：事件动词与原语（op、资源与商品类、来源去向、经过的节点）、事件的描述标签、参与者的持有与状态、知情集合（`knows(x, 事件)`，用于共犯与故意）、地点与时刻。表达式用 RX（第12章 §12.8.1）。
- **动作与任一包都可以附加描述标签**（`unconsented`、`deceive`、`forced`、`cause:negligence`、`duel:consented`、`lie`）以及第12章的**合法性标注**规则（`rules/tagging.json`，对提案与事件的原语、持有状态求谓词后打 `offense:*` 标签，上位回退匹配）。合法性标注与本节的罪名谓词是同一形状的两种存放位置：前者由包随内容提供、在裁决第 3 步就能给出预览，后者在法典里；立案反应二者都读。"罪名标签由动作或任一包的合法性标注规则打上，并由规范栈的罪名表认定"。
- 结果：新禁令只加数据。盐引制度（N8②）= 一条合法性标注或罪名谓词，运输包零改动；禁活契（N7）= 合同效力条款；戒律禁杀生（E4①）= 寺院的成员层条目，谓词 `vital(target: creature, lethal) || transfer(from: population, purpose: hunt)`。

**角色**（run-002 修订，E4③、E7③④、E16②）：罪名条目的 `roles` 声明谁以何种身份担责：

| 角色 | 条件（谓词模板） |
|---|---|
| principal 主犯 | 事件的发起者 |
| accomplice 共犯 | 在同一起因链上有参与原语（护送、提供工具、望风、companion）∧ `knows(x, 意图或计划事件)` 在行为时为真 |
| instigator 教唆 | 其 tell/request 事件是行为的起因 ∧ 内容指向该行为 |
| negligent 过失 | 持有带注意义务的职位（数据：职位的 `dutyOfCare` 列表，如税吏核验票据）∧ 相关检定失败或未执行 |
| vicarious 代负 | 行为者是其 tamed_by 驯兽或 employed_by 雇员 ∧ 条件（主人在场且未制止 / 受其指使 / 在职务范围内） |

不满足任何角色条件的参与者不担责（不知情的护送者、合法授课的教师）。知情集合是见证与转述派生的，证据也要能证明"知道"（收据、证言、文书）。

### 5.2.4 法典其余内容（主权法典的数据清单）

- 罪名表（上节形状；illegal_mining、negligent_fire、unlicensed_teaching、unconsented_magic、breach、theft、assault、homicide、fraud、forgery、smuggling、bribery、vote_buying、illegal_logging、fencing……）；每条有角色、刑罚种类与幅度、证据要求、追诉期。
- 程序：阶段与期限（报案 → 缉捕/通缉 → 审理 → 判决 → 执行 → 上诉），法院层级（村镇初审、郡府复审、王都终审；非人政体按议事制度）；**`appealStaysExecution`**（按案件种类：例如王国"民事判决上诉期间原判照常执行，改判后回转"、"死刑上诉暂停"，E13③）；宣告失踪/死亡与撤销的期限（04 §4.5.1）。
- 民事规则：清偿顺序、继承表、`onDebtorGone` 覆盖与限定继承、放弃继承期限、婚姻财产、监护顺位、紧急救治条款、同意代理（监护人代为）、未成年保护、股东责任类别、**宽限条款 `grace`**（天灾阻断、羁押停息……，04 §4.1）、质押物被盗时的风险负担（E16③）。
- 兼任规则 `plurality`：哪些职位可兼、俸禄是否只取最高（E9②）。
- 冲突法：财产所在地、婚姻缔结地、侵权地、户籍地、合同缔结地的选法顺序（N1⑤）。
- 引渡与协查：由 allied_with 条款与政体关系投影派生（U12/L1 已有方向）。
- 授权表（§5.2.2）与域外条款。
- 非人政体各自成表（林地议会：滥伐、采灵芝、惊扰精怪；部盟：习惯法均分；城邦：商事）。
- 完整性校验：每个政体七类民事规则齐全或显式 inherit（11 §11.2 第 1 条、第12章）。

### 5.2.5 次级规范与议案

- 村民大会、镇议事、郡府是治理组织（`administers` 聚落或行政区）；它们的议案动作（提案 → 表决 → 通过）通过时的效果 = 对本组织规范条目 fact.set（新增、修改或废止一条），写明范围与生效日。
- 能立什么由上级授权表决定：例如王国授权村规"本村公产使用、本村居民之间的租佃减免、本地禁令（罚金上限）"，于是"霜灾减租"对本村地主有效、对外村地主无效（E17③）；"限制教授此术"可作为本地禁令通过，罪名谓词只在本村子树生效（E16⑤）；"限制囤积青苗契"可限制本地缔结的 forward 义务数量（N1③）。
- 议案越权：通过事件照常产生（世界里确实表决了），但越权条款被解析器标为无效，并在公告与预览中给出原因；这本身可以成为后续政治事件的材料。

### 5.2.6 成员规范：门规与戒律

- 寺院、门派、行会、家族的章程可含成员层条目：谓词 + 内部制裁（罚香火/贡献度 transfer、立场 impress、禁足 status、开除 = holding.close(member_of)）+ 内部程序（住持裁断、长老会）。
- 与政体法律独立：狩猎在王国合法，在寺院戒律下是破戒（E4①）；两者可以同时命中同一事件。
- 驯兽代负同样适用：猎犬自行捕猎是否算破戒，看戒律条目的 vicarious 条件（主人在场、指使）（E4③）。

### 5.2.7 案件

**立案是反应规则**：`当 事件 E 使 normStack(行为者, E.地点, E.时刻) 中某罪名谓词为真 ∧ (见证非空 ∨ 证据链非空) → create(case{来源条目与版本, offense, 角色与当事人, victim, evidence})`。NPC 之间的犯罪与玩家犯罪走同一规则（起因是自治包的决策事件）。属人层条款立的案在被告进入该政体可执行范围前停在"缉捕"阶段（E10②）。

**案件是实体**：阶段是时钟到期项；执行是原语（罚款 transfer 到公库、监禁 = move 到牢房 + impaired、劳役 = employed_by 公家、赔偿 = compensation 义务、剥夺持有、流放 = banished 持有）；上诉 = 阶段，执行是否暂停读 `appealStaysExecution`；通缉 = 法域对人的 `wanted` 持有，范围由引渡派生，逃到无引渡政体即不可执行（run-001 E16①）；讼师 = service 义务，影响证据评分；新证据（收据等文书）在上诉审进入证据评分（E13①）。

**民事争议**同一种类：分产、欠薪、欠租、货损索赔、监护侵吞。冻结 = case 对持有/账户的 `frozen` 持有；分红入案件托管；判决改分股份保持总和 1.0。

**证据链**：物品个体带来源事件 → 赃物身份派生（买赃可追，run-001 E04③）；见证由感知派生（01 §1.5）；现场遗留 = 事件携带的 mark（K2 的 mark 机制）；文书物品的 records 可作书证。

## 5.3 组织与职位

**组织实体**：章程数据（议事方式：会长定/投票/长老定；继任规则；解任触发 `removalTriggers`；投票权重 `votingWeight`；是否接受入股 `acceptsShares`；责任类别：有限/无限；会费；开除条件与 `expelOn`；成员规范（门规戒律）；可设职位表）、公库账户、职位实体集合（按章程或聚落等级派生应有职位，缺的创建为空缺）、成员持有、对外立场投影、计划（势力时钟阶段，K6 效果）。

**治理是组织的特例**：聚落或行政区的治理组织 `administers` 它；政体 `governs` 若干地点；职位的职权、俸禄、额度由 `职级 × 所辖聚落等级` 查表派生（V3 的 rankedOffice 方向正确，扩到所有职位）；任命由职位发出（appointed 的授予者是职位）。

**首领** = 首领职位的持有人；更替只动这一个持有（run-001 E11）。公库属于组织实体；个人只有经职位派生的动用权限，免职即失（run-001 E03④）。

**爵位**是职位种类 `peerage`（所属政体）；封地是爵位授予的 `fief` 持有，其派生权能见 01 §1.3（不含封地内聚落的公库，E9③）；额度取官职与爵位中的最大值（T123 决定保留）；兵役、贡赋是义务。

**身份冲突的裁决顺序**（E4②、E9②）：新开持有时，①新持有种类自身的 `incompatibleWith`；②相关组织章程的 `expelOn` / 职位的兼任条款；③规范栈的 `plurality` 条款。三处任一给出 forbid 则拒绝；给出 auto_vacate 则同一事务关闭旧持有；给出 flag 则派生"身份冲突"标记——额度、派任务、俸禄视图读这个标记（例如行会章程声明"会员出家 → 会籍保留但停派狩猎配额"）。

**建国** = create(org{kind: polity}) + governs 持有 + 法典数据（可从模板复制再修订）；承认是各政体关系状态（外交包），不自动（run-001 E14①）；法典只覆盖 governs 的地点（run-001 E14②）。

**同盟与条约** = allied_with 持有（条款：互助、通商、引渡、关税优惠）；立场沿其传导（§5.6）。

**怪物社会、门派、商会、教派、家户、学堂、剧团、走私网、镖局**都是组织，差别只在章程数据与成员模板（creature 也可作成员，V4 已允许）。

**组织的反应规则**：成员受害 → 组织立场（K4 传导）；成员退出/叛离 → 补缺/分裂；公库不足 → 计划暂停；首领空缺 → 继任规则；成员数 → 香火/会费流量派生（槽 `organizations:offeringFlow`，名士作品、神迹、竞争者等以修正项进入，N3⑤、E11③）。

## 5.4 知识与传播

**知情集合**（投影）：`知道(x) = {见证的事件} ∪ {作为听者的 tell 事件} ∪ {读过的文书 records} ∪ {开局/pack.install 的作者知情种子}`。NPC 记忆流 = 知情集合按显著度 × 时间衰减排序，低显著度细节模糊化（遗忘只影响投影，事件日志完整）。

**主观视图**（run-002 修订，I25）：`subjectiveView(npc)` 是该 NPC 眼中的世界：
- **自知域**取真相：自己的身体与状态、自己的账户、自己的持有与义务、此刻在场能直接感知的实体与景象。
- **其余事实**取"知道的最新版本"：对某实体某事实，取知情集合中最近、置信度最高的说法（见证 > 可靠转述 > 传闻 > belief）；`belief` 事件覆盖较弱的说法，被更高显著度的见证或 reveal 推翻。
- **不知道的**取先验：模板缺省（"船按期会回来""钱庄照常兑付""小芸在家"）。
- 视图只按决策需要的字段惰性计算（决策规则声明读哪些字段），结果按版本键缓存（07 §7.5）。

NPC 决策（§5.7）、自治、对话答复、推断规则、智能层 LLM 输入都只读主观视图；真相视图只供内核校验与结算。所以"东家溺亡"的传闻会让储户挤兑、让外地商户拒收汇票（E2③），而钱庄的真实偿付能力只决定兑付动作能否成功（I2）；小芸失踪期间村民按自己的版本行动，没人"知道"她在精怪处（E15①）。

**推断规则**（run-002 修订）：没有源事件的说法来自推断。形状：

```json
{"id": "ship-overdue",
 "premise": "exists(o: obligation.delivery|escort, knows(self,o) && overdue(o, 7d) && carrierRouteHasStorm(o))",
 "candidates": [{"belief": "carrier_lost_at_sea", "weight": "0.5 + trait(self,'pessimistic')*0.3"},
                {"belief": "delayed_by_storm", "weight": "0.5"}],
 "confidence": "0.4 + 0.1*daysOverdue/7",
 "tellable": true}
```

- 前提读主观视图（期望事件未发生、观测到异常：逾期未归、库房见底、陌生人出没、作物枯黄）；候选命题的权重按性格；输出只能是 `belief` 事件（I26：不能产生 transition 或改真实状态）。
- `tellable` 的信念可作 tell 的源，按失真表扩散——"逾期 → 溺亡"、"人没回来 → 被拐/被吃"（E15①）、"公库空 + 灾 → 要民变"（N2⑤）这类谣言就是这样产生的；源头可追溯到推断规则与前提事件（I12）。
- 推断规则由包以数据提供（manifest 的 `inferences`）；离屏反思产出的 belief 也走这一形状。
- 更正：本人出现（见证）或 reveal 事件推翻 belief；立场按衰减回升（E2⑤）。

**转述事件** `tell(讲者, 听者, 版本, 源)`：版本由讲者的性格与立场从失真表生成（夸大数量、省略主体、偏向己方、细节误传："被打死"→"被毒死"是失真表的一条规则：死因细节在二手转述时按概率替换为同类死因，run-001 E16⑤）。传闻 = 沿路线以旅行时间为延迟的 tell 链，对有见证且分量够的事件、以及 tellable 的 belief 自动生成（K5）；私密与未成年保护标签阻断；渠道：当面、带信、公告、商队、吟游诗人（各有延迟与失真参数）。

**谎言**：带 `lie` 标签的 tell，保留真相链接；揭穿 = reveal 事件（U8 已有）。

**伪造物**（物品的谎言，E7①）：物品带 `purports`，真实属性另存。持有者与接收者在主观视图里看到的是 purports，除非他知道真相（制作者、见过鉴定事件者）。鉴定 = 检定动作（技能 + 工具 + 对照真品），成功产生"识破"事件进入知情集合。行使伪造物是否犯罪由规范栈谓词判定（`tender(item) && item.purports≠真 && knows(actor, forged)`）。

**文书**（E1③、E13⑤）：账簿、契据、收据、书信、告示是物品个体，事实 `records: [事件编号 + 版本文本]`。记账是反应规则：组织或商号作为当事方的事件，按章程追加到其账簿的 records（私密子事件只记入其自己的账簿）。阅读动作 = tell(源 = 该物品, 版本 = records 内容, 听者 = 读者)，于是新掌柜翻账簿就知道"剑卖给了赵三"。文书可偷、可毁、可伪造（purports）；毁掉文书不删除事件，只删除这条知情来源。

**技艺与书本**：书是物品个体，事实 `teaches`（技能/法术/配方 + 前置 + 品级 + 版本 + 作者）；读书 = learn 原语，前置派生（识字技能、资质、前置技能）（run-001 E09②、E17①）；抄写 = create(item, 复制 teaches, 品级不超原本)（run-001 E17④）；师徒 = service 义务；游学/迁居把持有的书与技能带到新地（RW-05 方向）。识字率 = 聚落居民识字技能的派生比例（run-001 E19②）。作品传播 = 沿路线与驿传边、按各地识字率加权的 tell/copy 链（run-001 E19①）。

**法术登记** = spell 实体与法域管理职位之间的 `registered` 持有；"未登记授课"是规范栈的罪名谓词（`learn` 事件的来源是授课 service ∧ spell 无 registered）（run-001 E09①）。

**玩家的知情**与 NPC 完全一样地派生；场景卡、返场摘要、人物面板、地图迷雾都只读玩家知情集合（I12）。

## 5.5 生态

**资源点与种群**都是带账户的实体；容量是地点派生（地形、季节、被 controls 的领地、污染、设施）。

**再生** = 时钟规则从 `src:regrowth` 流入，逻辑斯蒂闭式（可一次算 N 天，I14 精确类）；采伐、狩猎、盗采、捕鱼、采药都是从同一账户的转移（run-001 E04①、E15②、E20①）；归零即无产出；古树是慢再生子存量（年计）。

**河段有向边**：污染与水量按日沿边传递（迭代规则，声明容差）；下游产量、渔获、疫病派生各只读该段账户一次，不重复扣减（run-001 E01）。

**首领领地** = `controls` 持有 → 相邻地点容量下降 → 迁徙流量规则逐日把种群移到容量更高的邻地（含农田 → 害兽压力）；首领死亡只关闭持有，回迁按流量速率发生；空巢由"若干天后另一生物占据"的时钟规则处理（run-001 E07）。

**家畜**是被 owns 的种群账户；饲草是账户约束；繁殖、挤奶、剪毛是转移（RW-10）；役畜决定运力（§5.1）。

**种群相互作用表**（run-002 修订，N2⑥）：生态包数据 `{捕食者, 猎物, 系数, 季节}`、`{竞争者, 竞争者, 系数}`；时钟规则按表把猎物账户转入 `sink:death`、捕食者增长读猎物密度（迭代规则，声明 tolerance）。鸡鸭鸟类压蝗、狼群压鹿都是这张表的行；新物种包只加行。

**疫病**（run-002 修订，统一个体与群体两种形状）：
- 感染率派生 = 病种基率 × 水质暴露 × 密度（居民或畜群/面积）× 隔离/净水/医疗措施（修正槽 `health:infectionRate`）。
- **智能层与规则层的人**：病例是人的慢变事实（病种、病程、严重度），传播沿路线与家户。
- **种群（畜群、野马、蚕群）与统计层人口**：拆为子账户 S/I/R（01 §1.6），时钟规则按感染率与康复率在子账户间转移（迭代规则，声明 tolerance）；死亡转入 `sink:death`。马瘟、蚕病、远方疫情都是这一形状（E14⑤、N5③、E20⑥）。
- **医疗的两种形状**：个体诊疗 = service 义务 + heal（同意规则）；群体 = 药材 transfer 到 `sink:consume` + 医者服务能力派生 → 以修正项提高 I→R 康复率（槽 `health:recoveryRate`）；兽医与人医是不同动作与技能（E14④）。
- 物化与聚合时两种形状互相转换（按种子把 S/I/R 分配给个体，或把个体病例计入子账户），总数守恒（I28）。

**天气与灾害**：天气是时钟规则的种子派生（现有马尔可夫链保留）；灾害是时钟阶段 → 原语（河段水量、田地事实、设施 condition、路线封闭持有）；灾害概率与损害开放修正槽（风水、堤防、防火设施，N3①）。

## 5.6 立场（态度性关系）与舆论

**立场是投影**：
```
standing(holder, target) = 基线(文化/势力关系表，组织间基线为数据表，见第12章的 edge 扩展)
                         + Σ 印象(holder 主观视图内与 target 相关的事件 × 事件权重 × 价值乘子 × 归因系数 × 衰减)
                         + 传导(沿 member_of / kin / household / allied_with 持有，K4 系数)
```
维度：信任、亲近、敬重、畏惧、欠情（义务账派生）、恋慕（成年且长期）、竞争。

- **价值乘子**（run-002 修订，E9⑥、E6③）：事件权重表的每行可声明相关价值（门第、平等、虔诚、护生、勤俭……）；乘子 = 持有者价值排序中该项的权重。于是同一件事在不同性格的人那里分化；林地议会价值"圣兽"高，所以射杀角鹿的 harm 权重大。
- **状态评价**：对持续状态（"贵族兼任村正""寺院收了猎户"）的态度不是一次性事件。时钟规则（月）对选定状态谓词产出 `impress` 事件，幅度同样按价值乘子，见到状态的人才评价（读主观视图）。
- **归因系数**（E16④、run-001 E01④）：印象沿起因链分配给链上的贡献者，系数按角色数据给出（行为者 1.0、教唆者、授艺者、雇主……各有较小系数），所以学生用所学法术行窃，授课者的声誉也小幅下降，但不构成犯罪。
- **同盟传导**：组织间 allied_with 持有带传导系数，林地议会的不满沿同盟传播（E6③）。

**存储**：印象以 `impress` 事件存在（由反应规则对 harm/gift/breach/help/judgment 等产生，或由状态评价时钟规则产生）；现状的七份态度账合并为一个可重建缓存（I17）。

**舆论** = 聚落内各人立场的聚合投影（公众对某实体），供场景卡与界面。

**双键分离**：standing(部盟, 玩家) 与 standing(部盟, 王国) 是不同键（run-001 E13⑤）。

## 5.7 NPC 决策（动作层与离屏自治共用）

NPC 面对请求（玩家或其他 NPC 的 request 事件、自治包的内在需求）时的裁决规则，按指南 5.7 顺序，是 L1 的规则骨架，各包提供数据。**全部输入读该 NPC 的主观视图**（I25）：

1. 禁区与价值：red_lines（作者数据）命中 → 拒绝，理由模板引用该禁区；价值排序决定后续权重。
2. 关系：standing 各维度；欠情（义务账：对方为我履约而我未回报）。
3. 代价与收益：请求的代价（钱、时间、风险、名声、家人）与收益（报酬、立场增益、需求满足）**按 NPC 相信的世界**估算——他以为钱庄要倒，就不收它的汇票；他不知道票是假的，就会收。
4. 处境：忙（日程占用）、心情（状态）、更急的事（目标进度）。
5. 冲突：现有义务是否冲突；身份冲突标记（§5.3）；所属组织的成员规范。

输出四种之一：同意 / 有条件同意（开价或前提） / 拒绝（理由 + 替代方案："该找谁"由本地职位与服务派生） / 拖延（创建待办到期项）。NPC 的自主行动也包括空间上的选择：走近（去听、去看、去帮忙）、避开（绕开仇人、躲到柜台后）、跟随，都是 move 到相邻分区，读主观视图里的站位与立场；偷窃、潜行、偷听的机会评估读站位、遮挡与声音（01 §1.5）。决策是确定性的（输入 + 战役种子噪声），所以无 LLM 时可直接用，有 LLM 时作为必须遵守的约束给模型渲染。同一规则驱动离屏自治：需求（温饱、钱、安全、家人、地位、好奇、信仰）→ 目标 → 动作提案（自治包），经同一校验与原语执行，所以 NPC 的犯罪、辞工、卷款、报复、改宗、自荐补选、挤兑都是这条链的产物（run-001 E16、E18、E11；run-002 E2）。机会评估含跨法域价差项（同一商品类在相邻法域的价差，派生），私盐、走私因此随税差增减（N7②，第12章 §12.10.2）。

## 5.8 日程（派生）

日程 = 基准作息（作者数据或按职务模板生成）⊕ 职务片段（holds_office/employed_by/operates 的工作地与时段）⊕ 季节修正 ⊕ 义务占用（等候、会面、带路）⊕ 做客/留置（guest_of：并入东道日程，E15②）⊕ 状态打断（患病、照护、拘留、节日）⊕ 位置约束（在途时只有路上的作息）。读取时合成，不复制存储（V3 已朝此方向）。死者没有持有 → 没有日程（run-001 E02⑤）。日程同时是画面客户端站位投影的输入（08 §8.8）。

## 5.9 派生的开放：修正槽与修正项

run-002 的 N3（风水影响火灾与洪水、与寺观争香火）、E8（关税进到岸成本）、N1（预售影响现货价）说明：派生公式如果是封闭的，新包只能改别人的代码。规则如下：

- **派生方声明修正槽**：每个派生规则声明开放的槽 `{id: "facilities:fireRisk", stages: ["add","mul","clamp"], bounds: [0, 0.5], inputs: [...]}`；未开放的派生不能被修正（例如守恒相关的量、规则的合法性判定）。
- **包注册修正项**（数据，manifest `modifiers`；第12章扩展点表的"修正项"一行，合并语义 extend）：
  ```json
  {"id": "fengshui:siting", "target": "facilities:fireRisk", "stage": "mul",
   "when": "fact(subject, 'fengshui:rating') != null", "value": "1 - 0.1*fact(subject,'fengshui:rating')"}
  ```
  `when` 与 `value` 是只读视图上的 RX 表达式；修正项不能写状态、不能读真相以外的随机。
- **合成顺序确定**：基础值 → 全部 add（按包 id、修正项 id 字典序求和）→ 全部 mul（连乘）→ 派生方的 clamp/bounds。与加载顺序无关（I27）。
- **可解释**：派生结果附修正项清单与各自贡献（界面"为什么这么贵"、调试与推演断言用）。
- **跨层**：统计层聚合变体读同一组修正项（按聚落聚合的事实计算）。
- **预算**：每个槽声明最多可挂的修正项数与总幅度上限，超出在加载期报错（第12章 §12.8.3 的平衡预算）。
