# 05 统一模型：经济、法域与案件、组织与职位、知识与传播、生态、立场与 NPC 决策

每节说明：该领域在八个概念上怎样表达、哪些是数据、哪些是派生、哪些反应规则把它和别的领域相乘。

## 5.1 经济

**账户**：人（钱袋、随身物）、建筑/商号（库存、经营账）、聚落（公库、粮仓、公产）、组织（公库）、遗产与案件（托管）、资源点（储量）、源汇。铸币按政体分资源种类。

**转移是唯一动作**：
- 买卖 = 同一事件里钱与物两笔互逆转移；报价来自市场投影，当日缓存保证一致（L3）。
- 税 = 反应规则在交易事件后从买方/卖方向法域公库的转移（税表按政体 × 聚落等级，治理包数据）；关税 = 经过关卡地点时按该地法域税表的转移（E05③）。
- 利息、租金、工资、分红、俸禄 = 义务按 `accruedTo` 闭式累计，到期清偿即转移。
- 存款 = 钱庄对储户的义务；汇票 = 不记名债权，清偿前提是兑付地有该钱庄的 branch 持有（E05⑥）。
- 质押 = pledged 持有；绝当 = 到期项把 owns 转给当铺（E18②）。
- 股份 = share 持有（份额）；分红 = 组织 → 持有人的义务；价值 = 组织净资产 × 份额（E18⑤）。
- 雇佣 = employed_by 持有 + wage 义务；停工 = 反应规则 `当 wage 欠额 ≥ 阈 → status(employee, striking)`；辞工/挖人 = 持有关闭/新开。
- 托运 = delivery 义务 + 车船物品实体（容量事实）+ 在途位置（move 原语按路线逐段，天气与封闭使其滞留）；护卫 = escort 义务，工资按实际天数累计（E05②）。

**价格是投影**：
```
价(地点, 资源) = 基准(资源模板)
               × 本地稀缺(本地可售存量 ÷ 近期需求流量，钳制在 priceFactorLimits)
               × 供给地运输(最近有存量的供给地沿可通行路线的距离与风险；封关 = 无穷)
               × 季节(资源种类 × 季节表)
               × 法域政策(战时按品类、管制、税)
               × 店家与关系(店主加成、立场、声望)
```
不存价格状态。战后不"重置"，价格随存量与通路恢复而回落（E13③）；猎物/作物入市即压价（E07⑥、E09③）；生活魔法的产量变化经账户进入同一公式（U10 方向正确，只需改读账户）。

**一处计算、多处引用**：制造成本、建造成本、俸禄购买力、股份估值、损失评估全读同一投影；22 处价格计算归一。

**统计层的经济**：远方聚落只有聚合账户（粮、木、铁、钱）和聚合流量（产量、消耗、贸易），按月闭式结算；玩家到达时按种子物化个体账户，并从聚合账户"借出"初始存量（守恒）。

## 5.2 法域与案件

**法域**：地点向上找 `governs` 持有；法典是政体数据：
- 罪名表：事件标签 → 罪名（illegal_mining、negligent_fire、unlicensed_teaching、unconsented_magic、breach、theft、assault、homicide、fraud、smuggling、bribery、vote_buying、illegal_logging、fencing……）；每条有刑罚种类与幅度、证据要求、追诉期。
- 程序：阶段与期限（报案 → 缉捕/通缉 → 审理 → 判决 → 执行 → 上诉），法院层级（村镇初审、郡府复审、王都终审；非人政体按议事制度）。
- 民事规则：清偿顺序、继承表、婚姻财产、监护顺位、紧急救治条款、同意代理（监护人代为）、未成年保护、股东责任类别。
- 冲突法：财产所在地、婚姻缔结地、侵权地、户籍地的选法顺序。
- 引渡与协查：由政体关系投影派生（U12/L1 已有方向）。
- 非人政体各自成表（林地议会：滥伐、采灵芝、惊扰精怪；部盟：习惯法均分；城邦：商事）。

**立案是反应规则**：`当 事件带 offense:X 且 法域(事件地点).罪名表含 X 且 (见证非空 ∨ 证据链非空) → create(case{law, offense, offender, victim, evidence})`。罪名标签由动作本身的规则打上（盗采动作在无许可时标 offense:illegal_mining；授法动作在未登记时标 offense:unlicensed_teaching；施法动作在未同意时标 offense:unconsented_magic），法律包不猜测意图。NPC 之间的犯罪与玩家犯罪走同一规则（起因是自治包的决策事件）。

**案件是实体**：阶段是时钟到期项；执行是原语（罚款 transfer 到公库、监禁 = move 到牢房 + impaired、劳役 = employed_by 公家、赔偿 = compensation 义务、剥夺持有）；上诉 = 阶段，执行暂停（E10④）；通缉 = 法域对人的 `wanted` 持有，范围由引渡派生，逃到无引渡政体即不可执行（E16①）；讼师 = service 义务，影响证据评分。

**民事争议**同一种类：分产、欠薪、欠租、货损索赔、监护侵吞。冻结 = case 对持有/账户的 `frozen` 持有；分红入案件托管；判决改分股份保持总和 1.0。

**证据链**：物品个体带来源事件 → 赃物身份派生（买赃可追，E04③）；见证由在场派生；现场遗留 = 事件携带的 mark（K2 的 mark 机制）。

## 5.3 组织与职位

**组织实体**：章程数据（议事方式：会长定/投票/长老定；继任规则；责任类别：有限/无限；会费；开除条件；可设职位表）、公库账户、职位实体集合（按章程或聚落等级派生应有职位，缺的创建为空缺）、成员持有、对外立场投影、计划（势力时钟阶段，K6 效果）。

**治理是组织的特例**：聚落的治理组织 `administers` 聚落；政体 `governs` 若干地点；职位的职权、俸禄、额度由 `职级 × 所辖聚落等级` 查表派生（V3 的 rankedOffice 方向正确，扩到所有职位）；任命由职位发出（appointed 的授予者是职位）。

**首领** = 首领职位的持有人；更替只动这一个持有（E11）。公库属于组织实体；个人只有经职位派生的动用权限，免职即失（E03④）。

**爵位**是职位种类 `peerage`（所属政体）；封地是爵位授予的 `fief` 持有；额度取官职与爵位中的最大值（T123 决定保留）；兵役、贡赋是义务。

**建国** = create(org{kind: polity}) + governs 持有 + 法典数据（可从模板复制再修订）；承认是各政体关系状态（外交包），不自动（E14①）；法典只覆盖 governs 的地点（E14②）。

**怪物社会、门派、商会、教派、家户、学堂、剧团、走私网**都是组织，差别只在章程数据与成员模板（creature 也可作成员，V4 已允许）。

**组织的反应规则**：成员受害 → 组织立场（K4 传导）；成员退出/叛离 → 补缺/分裂；公库不足 → 计划暂停；首领空缺 → 继任规则；成员数 → 香火/会费流量派生。

## 5.4 知识与传播

**知情集合**（投影）：`知道(x) = {见证的事件} ∪ {作为听者的 tell 事件}`。NPC 记忆流 = 知情集合按显著度 × 时间衰减排序，低显著度细节模糊化（遗忘只影响投影，事件日志完整）；看法 = 离屏反思规则产出的 `belief` 事件（可错，被更高显著度事实推翻）。

**转述事件** `tell(讲者, 听者, 版本, 源事件)`：版本由讲者的性格与立场从失真表生成（夸大数量、省略主体、偏向己方、细节误传："被打死"→"被毒死"是失真表的一条规则：死因细节在二手转述时按概率替换为同类死因，E16⑤）。传闻 = 沿路线以旅行时间为延迟的 tell 链，只对有见证且分量够的事件自动生成（K5）；私密与未成年保护标签阻断；渠道：当面、带信、公告、商队、吟游诗人（各有延迟与失真参数）。

**谎言**：带 `lie` 标签的 tell，保留真相链接；揭穿 = reveal 事件（U8 已有）。

**技艺与书本**：书是物品个体，事实 `teaches`（技能/法术/配方 + 前置 + 品级 + 版本 + 作者）；读书 = learn 原语，前置派生（识字技能、资质、前置技能）（E09②、E17①）；抄写 = create(item, 复制 teaches, 品级不超原本)（E17④）；师徒 = service 义务；游学/迁居把持有的书与技能带到新地（RW-05 方向）。识字率 = 聚落居民识字技能的派生比例（E19②）。作品传播 = 沿路线与驿传边、按各地识字率加权的 tell/copy 链（E19①）。

**法术登记** = spell 实体与法域管理职位之间的 `registered` 持有；未登记授课打 `offense:unlicensed_teaching`（E09①）。

**玩家的知情**与 NPC 完全一样地派生；场景卡、返场摘要、人物面板、地图迷雾都只读玩家知情集合（I12）。

## 5.5 生态

**资源点与种群**都是带账户的实体；容量是地点派生（地形、季节、被 controls 的领地、污染、设施）。

**再生** = 时钟规则从 `src:regrowth` 流入，逻辑斯蒂闭式（可一次算 N 天，I14 精确类）；采伐、狩猎、盗采、捕鱼、采药都是从同一账户的转移（E04①、E15②、E20①）；归零即无产出；古树是慢再生子存量（年计）。

**河段有向边**：污染与水量按日沿边传递（迭代规则，声明容差）；下游产量、渔获、疫病派生各只读该段账户一次，不重复扣减（E01）。

**首领领地** = `controls` 持有 → 相邻地点容量下降 → 迁徙流量规则逐日把种群移到容量更高的邻地（含农田 → 害兽压力）；首领死亡只关闭持有，回迁按流量速率发生；空巢由"若干天后另一生物占据"的时钟规则处理（E07）。

**家畜**是被 owns 的种群账户；饲草是账户约束；繁殖、挤奶、剪毛是转移（RW-10）。

**疫病**：感染率派生 = 病种基率 × 水质暴露 × 人口密度（居民/面积）× 隔离/净水措施（E15①）；病例是人的慢变事实；传播沿路线与家户。

**天气与灾害**：天气是时钟规则的种子派生（现有马尔可夫链保留）；灾害是时钟阶段 → 原语（河段水量、田地 condition、设施 condition、路线封闭持有）。

## 5.6 立场（态度性关系）与舆论

**立场是投影**：`standing(holder, target) = 基线(文化/势力关系表) + Σ 印象(holder 知情集合内与 target 相关的事件 × 事件权重 × 衰减) + 传导(沿 member_of/kin/household 持有，K4 系数)`。维度：信任、亲近、敬重、畏惧、欠情（义务账派生）、恋慕（成年且长期）、竞争。

**存储**：印象以 `impress` 事件存在（由反应规则对 harm/gift/breach/help/judgment 等产生）；现状的七份态度账合并为一个可重建缓存（I17）。

**舆论** = 聚落内各人立场的聚合投影（公众对某实体），供场景卡与界面。

**双键分离**：standing(部盟, 玩家) 与 standing(部盟, 王国) 是不同键（E13⑤）。

## 5.7 NPC 决策（动作层与离屏自治共用）

NPC 面对请求（玩家或其他 NPC 的 request 事件、自治包的内在需求）时的裁决规则，按指南 5.7 顺序，是 L1 的规则骨架，各包提供数据：

1. 禁区与价值：red_lines（作者数据）命中 → 拒绝，理由模板引用该禁区；价值排序决定后续权重。
2. 关系：standing 各维度；欠情（义务账：对方为我履约而我未回报）。
3. 代价与收益：请求的代价（钱、时间、风险、名声、家人）由视图估算；收益（报酬、立场增益、需求满足）同样估算。
4. 处境：忙（日程占用）、心情（状态）、更急的事（目标进度）。
5. 冲突：现有义务是否冲突。

输出四种之一：同意 / 有条件同意（开价或前提） / 拒绝（理由 + 替代方案："该找谁"由本地职位与服务派生） / 拖延（创建待办到期项）。决策是确定性的（输入 + 战役种子噪声），所以无 LLM 时可直接用，有 LLM 时作为必须遵守的约束给模型渲染。同一规则驱动离屏自治：需求（温饱、钱、安全、家人、地位、好奇、信仰）→ 目标 → 动作提案（自治包），经同一校验与原语执行，所以 NPC 的犯罪、辞工、卷款、报复、改宗、自荐补选都是这条链的产物（E16、E18、E11）。

## 5.8 日程（派生）

日程 = 基准作息（作者数据或按职务模板生成）⊕ 职务片段（holds_office/employed_by/operates 的工作地与时段）⊕ 季节修正 ⊕ 义务占用（等候、会面、带路）⊕ 状态打断（患病、照护、拘留、在途、节日）。读取时合成，不复制存储（V3 已朝此方向）。死者没有持有 → 没有日程（E02⑤）。
