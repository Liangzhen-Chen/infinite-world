## 五、修订后的预计与仍未解决

**预计 run-002 自然得出**（设计者自评，需新的独立审查复核）：E 组约 114/119（96%）、N1–N5 约 28/30（93%）、N6–N8 约 16/18（89%，依赖第12章），总计约 158/167（≈ 95%），修订前为 114/167（68.3%）。

**仍可能判为"数"或有风险的条目**：
- E8⑥ 农具影响下季投入：形状有了（产量修正槽 + 农户投入决策），但依赖自治包的投入决策数据，容易被判"数"。
- E14① 托运价与在途：运力派生已定，"在途变长"取决于运力不足时是排队还是分批，需运输包数据。
- N2⑥ 鸟类与蝗：相互作用表已定，迭代容差未经实测。
- N6③ 他包组织基线立场：第12章 edge 扩展点给了位置，基线表的 core 形状（05 §5.6"组织间基线为数据表"）仍较薄。
- N8 卸载、N7 卸载的边角：以第12章为准，本次未复核。

**仍未解决的设计问题**（不阻塞迁移，进入相应阶段时定）：
1. 规范谓词对每个事件求值的性能（S4 实测；预计需按动词与商品类建条目索引）。
2. 授权表、先验表、价值词表、`mark:*` 标签族、布局模板库都是待写数据，量大。
3. 批次合并规则（S1）。
4. 多继承人分担不可分履行义务的缺省规则（法典数据）。
5. 主观视图的性能与 belief 堆积（11 §11.2 第 8 条）。
