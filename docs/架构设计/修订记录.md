## 十四、对复杂度的控制

- 概念总量不增：存储概念 8；新机制全部落在持有、义务、标签、修正项、规范条目、动作、账户、事实里。
- 一处定义：附录 A 收拢全部枚举与术语，各章只引用；判别表回答"该用哪种概念"；用词约定消除 `kind` 多义与"—"歧义。
- 同形复用：规范补丁 = 规范条款的修正项；公共知情 = 传闻的聚合变体；自治候选 = 动作的 `satisfies`；仪式 = 动作 + rite 块；神职 = 职位；亡魂 = 新实体；议案 = interim 实体；破产 = 案件种类；降级与节奏 = 输入事件。
- 新章节各自只回答一个问题（13 内容边界与超自然、14 时间、15 价值），并在开头写明"做到哪里、不做哪里"。
- 内容包档与最小示例包让第三方作者不必理解不变量。
