## 0. 一句话

现有规范栈已经有三层（主权法 sovereign / 地方法 subordinate / 成员规范 membership），15 个政体各有一部"诉讼章"模板——**法院名、程序文字、上诉路径确实按政体不同，但 12 条罪名的罚则、证据门槛、决斗许可、法定货币 15 部完全相同**。所以回答亮圳的问题："各地法律是否真的不同"——**结构不同，数值相同；文字不同，后果相同**。本稿做三件事：(1) 让 15 部模板的罚则、程序、证据、刑种、计价单位真的按文化圈推出；(2) 在 sovereign 与 subordinate 之间插入 **custom（习惯法）** 与 **clan（家法/部盟）** 两层，并让 clerical（教法）走现有 membership 层；(3) 定"风俗成法"规则：同一法域同类纠纷按习惯方式结案 N 次且结果一致，自动沉淀为 custom 条目，成文法政体再用议案（05 §5.2.5）升为 code 或废止。

## 3. 风俗成法规则（G3）

```
输入：法域 J（executableCodeAt 的法典 id）；案件结案记录 case{offense | civilKind, outcome, basis}
basis ∈ {code, local, custom, clan, clerical, oral}：adjudicateLegalCase（law.mjs:813）结案时记 normSnapshot.layer（现有 :172–176 已带 layer）
规则（反应规则，时钟：每案结案事件触发）：
  同一 J、同一 offense/civilKind、basis ∈ {oral, clan, clerical}（即"按习惯方式"而非成文）结案的案件集合 C
  若 |C| ≥ customs.precedentThreshold（5）且 结果一致率 ≥ customs.consistencyMin（0.8）
     一致 = penalties 字段逐项相同（kind、unit、multiple/baseFine/valueMultiplier、toVictimKin），容差 fineScale ±10%
  → 创建运行态 custom 条目 {source:"precedent", culture: 地点文化, jurisdiction: J, cases: C 的 id, penalties: 众数结果, effectiveFrom: now}
     写入 state.law.customs（存档内）；事件 `custom_formed`，可被公告、传闻、历史（history.json presentTrace）订阅
  → 之后同类案件 normClause 命中该条目（custom 层）；界面 explain 输出"按本地习惯第 n 条（五案成例）"
升格/废止：成文法政体的治理组织以议案 resolution.kind:"norm"（05 §5.2.5）把 custom 升为 code 条目或声明废止（废止 = effectiveUntil）
衰减：custom 条目若连续 M 年（数据 `customs.lapseYears` 10）无案件引用 → 自动 effectiveUntil（事件 `custom_lapsed`），表示风俗淡忘
反向：成文法条目若 N 次被 custom 层以"让位"覆盖（denied 记录）→ 不自动废止，只产生公告与舆论话题（public-opinion.mjs 现有 topic 形状），立法是人的事
```

落点：law.mjs:813 adjudicateLegalCase 结案后新增一次 `precedentScan(J, offense)`（纯函数读 records，不扫全表：按 `case:${J}:${offense}` 索引）；customs 运行态读取合并进 norm-stack 的 custom 层。确定性：无随机。

**边界**：(a) 玩家刷案——同一原告/被告对出现 ≥ 2 次的案件只计 1（防自导自演）；(b) 执法者受贿案（bribery 现有）不计入；(c) 上诉改判以终审结果计；(d) 怪物社会自治地（autonomy.factions）结案 basis 一律 oral，也适用本规则，于是炭阶共灶议会自己长出成例。

### 3.5 王法与乡俗的张力规则（【待定·亮圳②】取向 A 下生效；取向 B 下西境无 sovereign 王国模板，本节不触发）

```
对西境任一地点 P（sovereign = 王国 western 行模板 T，custom 层 = culture_forge/north/coast 的习惯条目）：
  clause(path) 的取法：按当地文化 lawSources 权重（custom 0.5 > code 0.3 > clerical 0.2）→ 习惯优先
  但 T.reserved = ["penalties.homicide", "penalties.trafficking", "penalties.enslavement", "recognition.legalTender.accepted"] 命中 → code 胜，记 denied
  张力事件（反应规则，数据 tension.*）：
    每一次 denied（乡俗让位）→ 当地舆论话题 `topic:royal_law_over_custom` +1（public-opinion.mjs 现有 topic 形状），同文化见证者对王国郡守职位持有人立场 −1
    累计 denied ≥ tension.petitionThreshold（12）/ 年 → 当地治理组织自治候选发起议案：请求王国把该条移出 reserved（approvalBy 王都职位，05 §5.2.5 上级批复，期限 90 日）
      批准 → reserved 去掉该 path（nation.amendments 现有机制写入），乡俗生效；驳回/逾期 → 话题再 +3，立场再 −2
    反向：custom 判决被上诉到郡府复审改判（courtHierarchy 第 1 级，王国法官）→ 同一事件族，方向相反（王国一侧 +1）
  可解释：每次判决 explain 列出"王法保留 / 乡俗让位 / 议案中"三态
```
首版 reserved 只放上表四项；其余罪名乡俗优先。这样西境玩家看到的是：偷盗赔偿按乡俗、杀人按王法罚金、酒馆里有人骂王都——张力从判决与舆论里长出来，不靠剧情。

## 9. 边界情况

1. **当事人文化 ≠ 地点文化**：custom 层按地点文化；clan 层按各当事人自己的文化（原告与被告可命中不同 clan 条目，冲突 → 上一层 code/custom 裁）。
2. **无文化地点**（野外）：placeChain 到郡 → 郡 cultureMix 最大者（01 §3.4）。
3. **lawSources 含 oral 且无 custom 条目**：案件进合议程序（courtHierarchy 第 0 级 = 当值帐/共席），判决即首例 basis:oral → 五例后成 custom。
4. **玩家在西境杀人**：取向 A（接受跨圈王国，主会话推荐）：sovereign reserved 含 homicide → code 罚金 100；custom wergild 让位并 denied；界面说明"王法保留此罪，乡俗命价不适用"，并触发 §3.5 张力事件。取向 B：无 reserved，命价适用。两种都已写全。
5. **旧快照**：casePenalty（norm-stack.mjs:178）比较"较轻者"只认 baseFine/detention；新刑种 kind 不同（wergild vs fine）时不可比 → 规则：kind 不同取**案发时快照**（有利被告的既有原则延伸，不混合）。
6. **怪物社会**：autonomy.factions 只有 illegal_mining；首版各补 theft/assault 两条（形状同 custom），不设公堂（现状"不收罚铜"保留：sanction 只有 standing 与 expulsion）。
7. **远郡法院未物化**：applicableLawAt（law-codes.mjs:91）已能在无法院时给出适用法；案件挂起到物化（现状）。
9. **兽裔玩家**（④已定：首版开放，数据开关可关）：clan 层按玩家 culture_beast 取 clan_beast；在东陆犯案走当地 code/custom，其 clan 条目只在砾耳法域生效。
8. **决斗死亡**：western death:true 仍要 witnesses ≥ 1 且双方 `consent` 事件（duels.mjs 现有）；无见证 → homicide。

## 13. 自检（随机抽三条）

抽法：对 §2.1、§2.2、§2.4、§2.5、§3、§4、§5、§6、§7 共 9 条按 (条号×7919) mod 9 取三条：§2.2、§3、§5。
