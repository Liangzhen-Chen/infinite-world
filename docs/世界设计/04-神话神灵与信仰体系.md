## 0. 一句话

十二位原创神不增不减，各归一圈、各得"面"；神是不在场的 agent，有香火账户与神迹预算，不能被杀、被驱、被封。神之下是**泛称神职**（城隍、土地、灶神、山神、河伯、井主、家宅精灵、记名树守）——是职位，持有人是亡者或精灵，可考取、可受贿、可罢免。神之外是**民间信仰的日常**：家户神龛的供奉义务、许愿与还愿、路祭、门神、预兆、托梦、占卜。一切传说与真相分层：人们信什么写在知情层，神与精怪真实如何写在事实层，二者可以不一致。全部原创、泛称或现实古神；今天仍有成规模在世信众的宗教之正统崇拜对象不出现、不改编、不作原型；现实古神只存在于宗教与朝拜系统，互动上限为对话与赐物（13 §13.1A）。致敬志怪与欧陆民俗的地方逐条注出处。

## 2. 五圈神话谱系与信仰结构（内容）

每圈给：上位神（原创十二神中的哪几位）、宇宙观与起源传说（知识层，多版本可矛盾，形状同 history.json 的 accounts）、神职层、民间信仰日常、灵异通道、致敬出处。

### 2.1 西陲混融边境（sphere:marches）

- **上位神**：垄息（耕作与分粮）、归汀（归家与无籍者）。两圈的神在此都有分堂：葭界的芦衡观（验汀道院分支）、镜缓一脉的止波寺（见 §3 止波寺归属）。
- **起源传说**（legends/marches.json，三版）：河谷人说大河是归汀送一个迷路孩子回家时拖出的辙；垄渠人说第一道渠是垄息用陶种印压出来的；下渡船家说两种说法都是上游人编的，渡口比神早。`truthRatio` 0.5：事实层只记"河谷早于任何现存教团建立"（history.json 纪元）。
- **神职层**：灶龛（每户，灶神位空缺——边境不设持有人，只是供位 → `householdShrine` 0.6 的"共灶会灶位"）、渠口石（渠神位，持有人可为土地型精灵或空缺）、归途殿（复活登记，归汀）。
- **日常**：开灶前留病者一碗（垄息 ritual，已是数据）；借宿一夜还一夜（归汀 cost）；修渠灶饭日。
- **灵异**：边境是两圈生灵的低密度交汇处（03 §3.5），传闻层特别杂。
- 出处：共灶、借宿的"互惠"结构参照 Montanari 对中世纪乡村共餐的记述与《荆楚岁时记》社日共食。

### 2.2 东陆志怪圈（sphere:eastern_zhiguai）【已决·亮圳 11-10：A】①中陆诸邦作东陆核心

- **上位神**：衡檐（契约与履约，中陆）、量阴（饮水与分配，灰盐）、葭界（河岸边界、符契与安息，篆汀）。
- **宇宙观**：天有司（不作神实体，作"天"的非人格化上位，誓言见证对象）；地有冥府（sphere:nether，§7）；人间有官府；三者结构同构——**神职即官职**。这是致敬《聊斋志异·考城隍》（宋公以文章考中城隍）、《席方平》（冥府诉讼与冥吏受贿）、《陆判》（判官）、《王六郎》（溺鬼积德被授土地神）：地方神职由冥府或当地治理组织**任命**，候选是德行记录好的亡者或受供的精灵，任命走现有 offices 任免 + 科举式考试（education.examinations 新增 `exam_divine_office`，考题即事迹计数与知情层的"阴德"）。
- **神职层（divine_office，§5）**：每城一城隍（owner 冥府政体 org_nether_court 与当地衙署共管 `coOwned`）、每里一土地（owner 当地治理组织）、每户一灶神位（owner 户，持有人缺省空缺；年末"述职"= 家户事实 `shrine.report` 事件进入冥府知情）、每山一山神、每渡一河伯、每井一井主（灰盐：量阴神职的下级，03 盐井石人）。
- **民间信仰日常**：家户神龛 householdShrine 0.9：灶神位日供（upkeep 义务：每日一撮米 goods:grain 或一盏油）、门神（mark 贴于门槛分区 threshold，§6 ward）、路祭（旅人出行 transfer 少量食物到路口 shrine 账户）、许愿 = `vow` 义务（债务人 = 许愿人，债权人 = 神职或神的账户，`deferredPrice` = 还愿物），还愿 = settle；不还 → 神职的 grievance 反应（§4）。
- **灵异通道**：托梦（dream）为冤魂与城隍常用；预兆（omen：乌鸦、灯花、犬吠）；占卜（oracle：签、龟甲、拆字——占卜职业 09 册）。
- **冥府**：§7。
- **科举与神职**：中陆的现实科举（exam_river 源头）与神职考试并列，形成"生前考功名，死后考城隍"的世界幽默，全部走同一考试机制。
- 出处：《聊斋志异》（中华书局三会本）：考城隍、王六郎、席方平、陆判、聂小倩（葬骨安息）、画皮、促织（许愿与神意）；《搜神记》卷四（神祇）、卷五（蒋侯——地方神职受封母题，只取结构）；《太平广记》卷二九一–三一五神部；《夷坚志》城隍判案；《东京梦华录》卷八中元、卷十除夕；《荆楚岁时记》灶祭与门神。
- 若中陆**不**作东陆核心（保留欧式城邦）：衡檐改归 sphere:western_folk（契约神与西境习惯法的"宣誓助证"相合），东陆上位神只剩量阴、葭界，城隍—科举结构落在镜沼芦语渡（渡口城）与雾杉联邑；中陆改用 §2.3 的堂区模型。§3–§9 规则不变，只改 deities.json 的 sphere 与 aspects 字段、regions 的 cultureMix。

### 2.3 西境民俗圈（sphere:western_folk）

- **上位神**：楔声（工艺与工伤责任，寒炉）、覆灯（极夜守候与冬储，星湾）、镜缓（有限记忆与哀悼，星湾）、泊纱（潮窗救助，琥珀）。
- **教团结构**：四神各有教团，但**结成"守候同盟"**（faction_western_concord，新组织，kind 教团联盟）：一堂区一教堂（05 册），每座教堂主奉本地行业最相关的一位（矿区楔声、渔港泊纱、极夜覆灯、墓地与档案镜缓），其余三神以**侧龛**（aspect 面）供于同一堂内——这就是 01 §2.3 "教团统一、同一神多面只在知情层争论"的落法。
- **宇宙观与起源**：冬是常态，光是借来的——覆灯的"罩内未点的双芯灯"象征。起源传说三版：第一盏灯是从海里捞上来的（琥珀）；是矿里挖出来的（寒炉）；本来就没有第一盏，灯是一代代传芯（星湾）。
- **神职层**：无城隍式官僚。地方守护是**精灵**而非职位：家宅精灵（03 §3.2，Kobold/Nisse 型）、田野老妇、井泉水妇、界犬——它们可被 `enshrined_in`（户、田、井、坟地）但**不占 office**；教堂不承认它们（知情层：堂区牧者说那是迷信——Keith Thomas《Religion and the Decline of Magic》第 2、8 章 堂区教会与民间魔法并存的张力），民众照供。
- **民间信仰日常**：householdShrine 0.15 = 灶后小人供食角（每晚一碗粥 upkeep）；收割留最后一束（田野老妇，02 册 yield 规则）；亡者夜留门留食（死者归来窗 window:dead_return，Lecouteux《Return of the Dead》第 4 章固定日期）；仲夏火（跳火净化：status pollution 清除）；教堂钟声为 ward（03 banes）。
- **灵异通道**：预兆（矿中敲击、海上鬼火）、夜行者的出神斗法（Ginzburg）、死者队列（Wild Hunt，群体 omen 事件）。
- **亡者**：无转生（burial.rebirth false）；安葬在堂区墓地 = rested；坟中坐者是**未得葬仪或生前凶暴**者（13 §13.7"不当死亡"文化数据）。
- 出处：Grimm《Deutsche Sagen》No. 71–80（家宅精灵）、No. 1–3（矿山小人）；Grimm《Deutsche Mythologie》第 31 章；Lecouteux 2009 第 4、7 章；Ginzburg 1966；Thomas 1971；《Eyrbyggja saga》第 51–55 章（Fróðá 奇事——死者归来被"门庭审判"逐出：这正是**用法律程序驱鬼**的原典，落为 07 册西境习惯法的"门庭审判"条目与本册 §6 仪式 rite:door_doom）。

### 2.4 风脊天穹圈（sphere:steppe_sky）

- **上位神**：听绳（井水、远行、共同草路）。
- **宇宙观**：天穹与大地是**非人格化上位**（不作神实体，不供奉；作誓言见证对象 `witness: "sky"` 与仪式对象）；听绳是人与路之间的神。
- **起源传说**：第一口井是狼刨出来的 / 是天上落下的绳子砸出来的 / 没有第一口井，是一队人走出来的路（三版，truthRatio 0.4）。
- **神职层**：几乎无固定场所；**敖包型石堆**（shrine 3/千人，沿路线分布）是地点实体，无持有人；井主精灵（03 井中听者）可 enshrined_in 井；萨满（巫师变体，09 册）是**职业**不是神职，通道为出神（trance）与托梦。
- **日常**：帐内火位（householdShrine 0.8）：火是家户的"神龛"，禁忌是用刀拨火、往火里倒水（规范条目 norm，违者 slight）；离井前标绳给下一队（听绳 ritual，已是数据）；接羔祭火、转场祭路。
- **灵异**：风马（03）、狼灵订约、干风鬼。
- 出处：《蒙古秘史》校勘本第 1、103、255 节（誓约、火、长生天作见证的结构——只取"天作见证"的非人格化用法，不收"长生天"名号与崇拜；长生天属今天仍有成规模在世信众的体系，仍排除。草原圈的现实古神见《命名与古神方案》§3.2（皮尔瓦，神话谱系不同、仅取马神职司；特利皮努归西陲圈））；《江格尔》汉译本；《元史·祭祀志》洒马奶祭（取仪式形状，不取对象）。

### 2.5 翡翠林冠圈（sphere:canopy）

- **上位神**：枝留（林地再生与抚育，林民）、砾闻（踪迹、口证与被遗忘者，兽裔）。
- **宇宙观**：世界是一棵不断换绑的树；死者是被记住的名字。信仰核心是**记名与遗忘**：记名树（shrine 5/千人）上刻亡者名，家户或养育群按周期重述（upkeep 义务 = `ancestorUpkeepDays` 的林冠版）；断祀 N 周期 → 亡者转为嗅迹亡魂（03 §3.4）；重新记名 → rested。
- **神职层**：记名树守（divine_office，owner 育芽小院 / 寻迹静舍，持有人常是年老林民或兽裔口述者——**活人**也可持有这类职位；13 §13.8 "持有人是亡者或精灵"在此放宽为"亡者、精灵或经口证大会推举的活人"，写入 officeModel 枚举 `living_keeper`）。
- **日常**：拆旧绳挂木牌（枝留 ritual）；晒嗅布日；猎前报树、光、风向。
- **灵异**：菌母的轮作好坏、嗅迹亡魂的气味。
- 出处：记名与遗忘的结构致敬《搜神记》卷十六无主孤魂与祭祀"血食"断绝之说（取"断祀则厉"的规律），以及凯尔特民间传说中的"名字即存在"母题（Jacobs《Celtic Fairy Tales》；林冠不收凯尔特诸神作为原创神的面；罗马时期高卢-日耳曼的地方古神可作现实古神（阿尔杜因娜、阿布诺巴），见《命名与古神方案》§3.2）。

## 4. 神祇作不在场 agent：香火账户与神迹预算（D2）

```
月结：power += incense_in × powerPerIncenseUnit − power × decayPerMonth
神迹 m 可行 ⇔ power ≥ m.costPower ∧ 距上次同 miracle 同场所 ≥ cooldownDays ∧ 前置（信者在场、守信日数、actor 代价已缔结为义务）
幅度上限 = min(m.magnitudeCap, power × maxMagnitudePerPower)                      → 槽 faith:miracleQuota（faith.mjs:75 现有槽推广）
执行：transfer power → sink:miracle；发事件 miracle{deity, aspect, target, magnitude}；actor 代价 = obligation.create 或 transfer（真实损失，13 §13.8）
神祇决策（NPC 决策 05 §5.7）：候选 = 预算内的 miracles；需求 = domains 对应的世界状态偏差（契约被篡改事件 → 衡檐；旱 → 量阴/葭界）；神不主动显现，只回应仪式请求（现有 rw07_sign 口径）
```
现有 faithRainQuota（baseQuota + income/coinsPerQuota）是这个公式的特例（powerPerIncenseUnit = 1/coinsPerQuota），接入后数值相等（§11 不变量）。
