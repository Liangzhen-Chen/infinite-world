# 13 建筑、聚落形态与服饰器物

（2026-11-09 分册稿。依据：docs/产品原则.md；00 §3.14（N1–N5）、§3.15（O1–O4）；01 §3.2 `dress`/`building`、§3.5、§4.3、§4.8；13 §13.3；AUDIT3 P7（MATERIAL_RESISTANCE 硬编码）；world/drafts/d12-matprops。现状取证基准 F:/dnd-wt/SAT。只写设计，不改代码。所有数字是数据参数首版建议值。）

---

## 0. 一句话

房子、街巷、衣裳、器物的地区差别**全部从三样东西推出**：当地有什么材料（01 §4.8 可得性）、当地气候要什么（保温、排湿、防风、防盐）、当地文化偏好什么（01 §3.2 `building`/`dress` 的 goods 偏好）。建筑是**模板 × 材料**，聚落是**布局模板 × 人口 × 功能需求**，服饰是**衣物物品 × 气候 × 身份标志**，器物风格是**批次属性**而不是新物品 id。材料属性表从代码里的 MATERIAL_RESISTANCE 搬进数据，成为磨损、保温、火险、价格的共同来源。

## 2. 概念模型

```
材料 material:*（goods 子类）── 属性表（密度、保温、防潮、耐火、耐盐、工作性、腐朽率）
建筑模板 building:*（形制）── requires materials[] by role（墙/顶/架/地） ── rooms/features 骨架 ── 气候适配分
聚落布局 layout:* ── 街区排布规则、功能地点位置、墙/门、路网
衣物物品 item（goods:cloth_*/garment_*）── 材料 → 保温/防水 ── culture.dress 偏好 + statusMarkers
器物批次 batch{origin, maker, style} ── style = maker 文化（派生，批次元数据 01 §1.6）
```

### 3.4 服饰（无新文件：物品 + 文化字段）

- 衣物物品统一加 `garment: {"slot": "body|outer|head|feet|hands", "material": "material:hemp", "coverage": 0.8}`；保温/防水从材料表派生（§4.3）。现有 item_clothes 等补字段。
- 文化 `dress`（01 §3.2）：`materials[]`（偏好 goods）、`statusMarkers[]`（`{item|material|feature, requires: "rank>=citizen" | "member_of:faction" | "office:*"}`）、`signature`（文字层：袖口补缀 / 行会色条 / 结绳披肩 / 反光矿片 / 班次帽沿——转为 `features[]` 词，用于识别与叙述）。
- 标志**不是**法律：僭越是否违法由法典（07）决定；文化层只产生 `slight`（01 §4.7）或**误认**（旁观者按标志推身份 → 现有 purports/identity 机制）。

### 3.5 器物风格（批次属性）

- 物品实例/批次元数据（01 §1.6）加 `style: culture_id`，**制造时** = 制作者 culture(x)（01 §4.1）；采集品无 style。
- 文化 `crafts.signature`（新字段）：该文化器物的特征词与偏好材料：`{"vessel": "material:lacquer", "textile": "material:felt", "container": "material:bark_birch", "paper": "material:reed_paper"}`——用于 remote-generation 给生成工匠选配方（同 goods 类下优先本地材料的配方）与 demandWeight（01 §4.8）。
- 异乡风格溢价：`exoticMul(style, 郡) = 1 + (1 − aff(style 文化, 郡文化))·0.3`，进市场估值修正项（限 `prestige ≥ 0.3` 的材料或 `goods:ornament` 类；日用品不溢价）。

### 3.6 书与文书载体

- 书/文书的 `medium: material:*`（纸：`material:reed_paper`、`material:bark_birch`、`material:parchment`（goods:hide 子类）、`material:bamboo_slip`；石：碑）→ 耐久（decayPerYear）与重量；`script` 的 `medium` 限制（12 §3.2 楔刻符只上石木金）。

## 4. 规则

### 4.1 建筑形制派生（生成期）

```
对聚落 S、文化 c（share ≥ 0.15）、用途 u：
  candidates = templates with u ∈ uses ∧ forms ∩ c.building.forms ≠ ∅
  若空 → candidates = templates with u ∈ uses（文化偏好让位于可建）
  对每个模板 t：
     materialPick[role] = argmin_{m ∈ t.requires[role] ∩ available(S)} value(m, S)      可得（01 §4.8）且最便宜
     若某 role 无可得材料 → t 不可建
     fit(t) = climateFit 满足度（insulation(materialPick.wall) ≥ insulationMin 等，每项 0/1 取均值）
     score(t) = 2·[forms 命中 c 偏好] + fit(t) − 0.2·buildCost(t)/median
  选 score 最大者；并列按 id
生成建筑实体：rooms/features 骨架按模板，airModel 按模板缺省乘 footprint；记录 `template`、`materials{role: m}`（存档事实）
```
- 白石镇与五村已有 458 地点**不重生成**；只给它们补 `template`/`materials` 字段（由散文"夯土下墙与可拆木楼"→ courtyard_house 变体 `building:river_house`：wall rammed_earth、frame timber、roof thatch_reed；作为 marches 的首版模板之一）。

### 4.2 建筑磨损与维护（接 facilities.maintenance）

```
wearPerYear(b) = Σ_role weight_role · materials[role].decayPerYear[climateClass(郡)] · template.wearMul   （weight: wall .4 roof .4 frame .2）
维护需求（k10b 现有公共维护与 facilities.wear）读 wearPerYear 替代常数
修缮材料 = 磨损最大 role 的材料 goods，数量 = footprint/50 单位
火险 = 1 − min(fireResist(roof), fireResist(wall))·0.5 → hazardClock 火灾权重
```
西陲现有建筑：补字段后 wearPerYear 用 rammed_earth/timber/thatch 在 dry 类 ≈ 0.4·0.01+0.4·0.1+0.2·0.01 = 0.046/年 → 与现有 facilities.wear 常数对齐（02/08 校准时若偏差 > 20% 调材料表而非加常数）。

### 4.3 穿什么：服饰派生

```
需求：insulationNeed(郡, 季) = clamp((15 − meanTemp(季))/25, 0, 1)      meanTemp 读 weather.regions 季节均温
      moistureNeed = humid/coastal 类 ≥ 0.5；saltNeed = coastal
个体穿着（生成 NPC 衣柜 2–3 件；玩家按物品）：
   选 garment 物品使 Σ coverage·insulation(material) ≥ insulationNeed ∧ 材料 ∈ c.dress.materials 优先 ∧ 可得
   不足 → 状态 `cold`（environment 暴露现有 hazard）；超出 → 夏季 `overheated`
身份标志：NPC 若满足 marker.requires → 衣柜加该 marker 物/特征；旁观者据此 **推断**身份（识别规则：看到 marker → 知情条目"此人像是公民/行会成员"，truth 按实际）
玩家穿外地服：旁观者先按服饰推文化（叙述投影）；立场初值仍按 01 §4.7 真实文化；谎称出身 + 对应服饰 → purports 可信度 +（现有 identity 机制的修正项 `identity:dressMatch` +2）
```

### 4.4 器物风格与配方选择

```
生成工匠的配方集 = 本地 goods 类需求 → 同 goods 类配方中 优先 (材料 ∈ c.crafts.signature 且 available) 者；无则任一可得
制造事件 → 批次 style = 制作者 culture(x)；运到他乡 → exoticMul（§3.5）
```

### 4.5 聚落布局生成

```
layout = cultures[主文化].building.layout
walls = pop ≥ layout.wallByPop（null 永不）→ features 城墙 + gates 个门楼（gatehouse 模板，兼 toll）
市场位置/数量、官署、场所按 layout 规则落点；街区坐标按 districtShape 生成（grid：方格；radial：极坐标；ring：环绕中心井；tree_graph：按冠路图；linear：沿岸线；terraced：沿等高线）
街区名按 12 §3.3 naming.place
curfew=true 的布局：夜间（windows midnight）里坊门关 → 移动受限（现有 primitiveLimits / 门 access）
```

## 5. 边界情况

1. **材料不可得的文化偏好**：中陆人在草原没有瓦 → 模板让位（§4.1 第二行），住毡帐或土屋；叙述投影提示"按家乡样式本该…"（knowledge 层）。
2. **可移动建筑**（yurt/hide_tent `portable`）：是**物品**还是地点？——是地点实体，但可 `move`（原语），移动后坐标变、features 随之；拆装用时 buildHalfDays；整户转场（草原秋季转场节日）= 批量 move。存档事实：地点有 `portable: true` 与 `movedAt`。
3. **树上建筑** `anchor: living_tree`：锚定实体是树（生态物种/地点特征）；树死 → 建筑 wear 跳到 1；`rebindDays` 换绑义务（文化记录 architecture 已写"承重枝按轮次换绑"）。
4. **混居聚落**：各文化按份额生成各自住宅模板；公共建筑按主文化；街区 culture 翻转（11 §4.5）后**新建**才换模板。
5. **已有白石镇建筑**：只补字段，不改 rooms/features（存档事实）。
6. **服饰与战斗**：甲胄（armor 物品）另有现有 combat 规则；garment 只管保温/身份；两者可叠穿，slot 不冲突（armor 在 `armor` 槽）。
7. **兽裔/木精/狐族不穿衣**（cultures 散文）：`dress.materials = []`、`insulationNeed` 由物种 form 轴的 `fur/bark` 抵消（13 §13.3 物种 schema 加 `naturalInsulation`）；它们的标志是耳饰/尾结/苔绳（feature 词，非 garment）。
8. **火灾**：芦苇顶 fireResist 0 → 火险高；hazardClock 火灾读 §4.2；这就是"水乡用瓦、草原用毡"的后果层。

## 11. 自检（随机抽三条）

抽法：§4.1–4.5 共 5 条，(条号×7919) mod 5 → §4.4、§4.3、§4.2。

1. **§4.4 风格与配方选择**：输入（goods 类需求、配方材料、crafts.signature、available）齐；style 写入时机（制造事件）与 exoticMul 公式、限定条件都有；验收 V7。开发者会问"批次元数据现在有没有 style 位"——01 §1.6 批次有 origin/quality/taint，加 style 是同类字段。**判定：可开工。**
2. **§4.3 服饰**：需求公式读 weather 季节均温（weather.regions 有季节权重，均温需 02 的 growingSeason.meanTempC 按季折算——02 给四季均温表，本稿依赖它）；选衣算法、不足状态、标志推断与 purports 修正项都写了。**判定：可开工，卡里写明依赖 02 的季节均温字段；在 02 之前可用 growingSeason.meanTempC ± 10 的粗折算（已补）。**
3. **§4.2 磨损**：公式、权重、climateClass 派生、修缮材料与数量、火险、西陲校准值与校准纪律都有；落点 facilities wear。**判定：可开工。**
