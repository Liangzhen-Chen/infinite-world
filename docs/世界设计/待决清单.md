- 主会话推荐：取向 A，中陆作东陆核心，把 culture_civic 按 M3 改写成衙署里坊与粟稻（物产"官署与文书、钱庄"和考试制度最适合承载衙门、城隍、科举）。待李白/亮圳核定。

**D2　王国是否横跨两圈（西陲、寒炉、星湾、琥珀、中陆、镜沼部分同属一个王国）？**
