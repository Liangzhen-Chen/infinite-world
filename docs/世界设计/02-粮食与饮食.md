## 3. 作物与气候（B1）

### 3.1 新文件 world/ecology/crops.json

```json
{
  "$schema": "ecology/crops@1",
  "entries": [
    {
      "id": "crop_oats",
      "goods": "goods:grain_oat",
      "harvestItem": "item_oats",
      "substrate": "field",
      "sowWindows": [{"fromDay": 5, "toDay": 25}],
      "growthDays": 180,
      "minimumTemperatureC": 4,
      "frostFreeDaysMin": 120,
      "rainMm": [400, 1000],
      "biomes": ["earth", "wet", "grass"],
      "seedPerHa": 120,
      "yieldPerHa": 1700,
      "areaUnitsPerHa": 100,
      "perennial": false,
      "doubleCrop": false,
      "storageDays": 180,
      "sources": [{"work": "FAO Ecocrop: Avena sativa", "note": "最低生长温度 4–5 ℃，生育期 90–200 日，年雨 400–1000 mm"}]
    }
  ]
}
```

字段：
- `substrate`：`field`（旱地）/ `paddy`（水田，需 biome wet 且 rainMm ≥ 800 或有渠）/ `log`（原木，真菌）/ `water`（水面：菱、芦米、海藻）/ `pasture`（牧草，不收获，供牲畜 niche grass）/ `orchard`（多年生）。读它的规则：§3.3 arable、13 册田地地块 biome（biomes.json 已有 田/圃/果园/苇/汀 词）。
- `sowWindows`：年内日序窗（现 crop.sowDays [5,25] 等价 `fromDay:5,toDay:25`）；可多窗（两熟）。
- `frostFreeDaysMin`：须 ≤ 郡 growingSeason.frostFreeDays。
- `rainMm`：[下限, 上限]，郡 rainMm 落在区间内才 arable；paddy 另看渠（地点 feature kind `canal`，13 册）。
- `doubleCrop`：true 时若郡 frostFreeDays ≥ 2×growthDays + 20 则一年两季（稻—粟轮作就是这样来的，不写"中陆两熟"）。
- `storageDays`：进粮仓的保质；agriculture.mjs:313 的校验改读它。
- `sources`：出处必填（E-CROP-SOURCE）。

### 3.4 arable 规则（01 §4.2 细化）

```
arable(crop, county) = [meanTempC ≥ crop.minimumTemperatureC]
                     ∧ [frostFreeDays ≥ crop.frostFreeDaysMin]
                     ∧ [rainMm ∈ crop.rainMm  ∨ (crop.substrate == paddy ∧ county 有 canal 设施)]
                     ∧ |crop.biomes ∩ county.biomes| ≥ 1
                     ∧ substrateOK: log → county.biomes ∋ forest; water → ∋ wet ∨ salt; pasture → ∋ grass ∨ dry
seasons(crop, county) = crop.doubleCrop ∧ frostFreeDays ≥ 2·growthDays + 20 ? 2 : 1
```

落点：新模块 server-plugin/crops.mjs（纯函数，读 crops.json + regions.json），被 agriculture.mjs（字段 grainItem 改派生）、remote-generation.mjs:288（店铺货源）、household-subsistence.mjs:283（foodItem）调用。

```
├ goods:seasoning {salt, vinegar, sauce_bean, spice_seed, fresh_herb, honey}
├ goods:drink {water, tea, tea_dairy, broth}
└ goods:alcohol {ale, mead, wine_grain, wine_rice, wine_dairy, wine_fruit}
```

**挂法不手填**：物品的 `goods` 由 tags 映射表 `world/ontology/goods-map.json`（`{"grain":"goods:grain", "legume":"goods:legume", ...}` 加 `byName` 例外 ≤ 10 条）在加载期派生；现有 95 件食物据此全部拿到 goods；派生失败（无可映射 tag）是加载错误，提示补 tag。这样满足 01 §3.5 "goods 必填"又不逐件手写。

### 4.2 county 的 staples（01 §4.2 补两项：水产与进口）

```
cropScore(crop, county)   = arable · seasons · yieldPerHa · pref(goods(crop))           pref 读当地主文化 cuisine.staplePreference（_default 0.1）
pastoralShare(county)     = |biomes ∩ {grass, dry}| / |biomes|
aquaticShare(county)      = |biomes ∩ {wet, salt}| / |biomes| · [industry 含 渔 ∨ 咸鱼 ∨ 海草 ∨ 河鱼]      （industry 是现有数组，按关键词类匹配一次登记在 goods-map 的 industryHints）
candidates = {作物 goods: cropScore} ∪ {牲畜 yields goods: husbandryScore = Σ 本郡物种 perHeadDay · 承载 · pref} ∪ {水产 goods: aquaticShare · 2000 · pref}
staples(county) = candidates 按分值前 2；若前 2 均为非谷且 pref(goods:grain_*) 最大者 ≥ 0.5 → 追加 1 项 "进口谷" = 邻郡可产谷中 pref 最高者（标 imported:true）
```

输出用途：
- agriculture：郡的 `grainItem` = staples 中第一个 grain 类 goods 对应的 harvestItem（无 grain 则该郡无公仓谷物，公仓存奶干 / 鱼干 —— 粮仓校验改为 grain ∨ meat_dried ∨ fish_dried 三类且 storageDays ≥ normalStorageDays）。
- household-subsistence `foodItem`：改为 `staplesOf(county)` 里本户或本地市场**有存量**的第一项（没有则回落 item_wild_food 觅食，行为与现状相同）。
- remote-generation 店铺货源：粮店卖 staples 的 harvestItem 与其加工链前两级产物。

### 4.4 文化偏好不进"每铜币有效饱腹"（口径说明）

household-budget.mjs:323 的采购规则（李白 2026-11-10 口径：无拍定系数）**保持不变**。偏好只从三处起作用，全部是派生：
1. 供给侧：本地生产者按 staples 与 methods 生成什么（§4.2、§5）；
2. 市场侧：需求权重 demandWeight = Σ share·pref（01 §4.8），抬高偏好品的价、压低非偏好品的价——于是"每铜币饱腹"自然偏向便宜的非偏好品，这是真实的（穷人吃粗粮）；
3. 礼俗侧：待客与节日物资按 goods 偏好（§7）。

**不做**"吃不惯的东西饱腹打折"：没有生理依据，且会让规则绕回拍定系数。如果产品希望"外乡人想家"，走 06 册情绪修正（mood），不走营养。

## 7. 饮食禁忌与宴饮礼俗（B5）

### 7.1 待客（hospitality）

规则（接 01 §4.7 第 4 行）：
```
场景：行为者 x 进入 NPC h 的住所 / 店铺并停留 ≥ hospitalityMinutes（数据 10）
h 的候选动作 offer(goods ∈ cuisine(h).hospitality.offer，本户有存量者)      ← 自治候选，transfer 到 x（小额，账本 purpose: hospitality）
x 的回应：accept → 立场 +k1；decline → 若 refusalIsSlight 则事件 slight(x→h)，立场 −k2；
          order 违背（东陆客人先要酒；草原客人先吃肉）→ slight
k1=1、k2=2、hospitalityMinutes=10 写在 world/rules/tables/balance/social.json
```
NPC 对 NPC 同规则（自治候选）。无存量则不 offer，不伪造。

### 7.2 座次与共食

- `hospitality.seating` 只影响叙述与"失礼"判定（坐错 → slight），不影响结算。
- 林冠 `soup_shared_by_consent`：共食须本人同意——culture_ms_huipeng 已写在 facts.food，转为规则：hospitality.offer 前先问（dialogue 分支），未同意即分食 = slight。

### 7.3 节日饮食

festivals.json `resourceNeeds[].item` 允许写 `goods` 类（`{"goods": "goods:dish_flatbread", "quantity": 1}`），结算时取参加者持有的该类任一物品；festival.mjs:145 校验改为"item 存在 ∨ goods 已登记"。远郡节日由 06 册按 cuisine 生成物资需求（东陆中元施食 goods:grain_rice；西境收获节 goods:dish_bread + goods:alcohol_grain；草原接羔 goods:dairy_curd；林冠菌收 goods:fungus）。

### 7.4 禁忌与丧食

- `taboo[].when == mourning`：本人 kin（family-state）有死亡事件 ≤ days → 食用 forbid 类 → 事件 `taboo_breach`（不是罪，风俗事件族，06 册的失礼事件族之一），立场 −k3（数据 3），且本文化 NPC 不向其 offer 该类。
- 窗禁食（fasting）：读 culture.windows（01 §4.6）。
- 非人文化：木精不吃（metabolism 0）；兽裔食虫；狐族护幼者先分盐（culture_ms_taideng facts.food）→ 转为 `famine.rationPolicy: "protectors_first"`（§8）。

## 12. 边界情况

- **已物化聚落有公仓**：仍按 settlements[] 的 crop 运作；本册的 staples 只影响未物化聚落与家户采购候选。
- **郡没有任何 arable 作物**（星湾雪灯 85 日无霜）：staples 走水产与进口；公仓物品为 fish_dried（storageDays 180 满足校验）。
- **两熟算一季时间**：第二季只在第一季收获事件之后开播窗（sowWindows 第二窗 fromDay = 第一季收获日 + 10），由 agriculture 日推进判定；不写死日期。
- **真菌原木**：crop_log_fungus 的"田"是林地地块（biome 林），产出按 crops.yieldPerHa 干重；接种物品 `item_spawn_log` 由 fam_log_inoculate 产生，是 durable 类（会耗尽，lifecycle）。
- **非人代谢**：巨魔"一顿一大袋"= species maintenance × metabolism 2.5（creature-nature 允许到 4）；mealCap 按人·餐给，巨魔的池 = cap × metabolism（item-class.mjs:338 dayMg 乘 mouthWeight，一处改动）。
- **酒的饱腹**：按 kcal 守恒，不另给；醉酒走 status。
- **茶叶不饱腹**：干叶 satiety 0，茶汤 hydration 来自水；奶茶有 satiety。
- **外来 goods 偏好漂移**：01 §4.8 的运行态 +δ 上限 0.6，存档内。
- **玩家建档出身**（已定：首版开放兽裔出身，做成数据开关 `playerOrigins.allowMonsterSocieties: true` 可随时关闭——李白决定，亮圳未特别要求）：选兽裔时玩家 cuisine 读 culture_beast（食虫合礼、拒菌汤无事）；开关关闭或未选时缺省 culture_river。两种情况下规则不变。
