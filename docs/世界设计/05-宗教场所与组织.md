## 0. 一句话

场所数量由"人口 × 文化密度参数"推出（01 §4.3），不手摆。四类场所一张 schema：**shrine**（龛、祠、敖包、记名树、路口龛）、**temple**（寺、观、堂区教堂、抚育堂）、**abbey**（修道院、道院、禅院：有田产与宿舍的自养机构）、**household shrine**（家户事实）。职能、经济、人员都是现有机制的组合：公库（已有）、庙产 = 土地持有 + 佃租（已有 fieldRent）、放贷 = credit.mjs 的一个出借方、施粥 = relief 按公库余额派生频次、庙会 = 节日 marketDay 在场所会场、义学 = school。人员是职位（offices）；出家是 member_of + devotee_of 双持有，不是职业选择；职业（僧侣、道士、祭司）仍是战斗职业，只是**在哪学得到**由场所派生。与法律：教法只对成员生效（clerical 层）、圣域 primitiveLimits、淫祀禁令、教产税率都是法典数据；与节日：场所是会场与组织者。

- `tithe`：西境堂区 `{"share": 0.1, "of": "harvest", "from": "parish_households"}`，其他圈 null。

## 4. 密度与类型派生（E2、E3；01 §4.3 的实现细则）

```
对未物化聚落 S（pop、households、cultureMix），对每个 share ≥ 0.15 的文化 c：
  d = cultures[c].faithDensity;  M = cultures[c] 所属教团章程 model
  n_shrine(c) = round(pop·share·d.sitesPerThousand.shrine / 1000)
  n_temple(c) = pop·share ≥ d.minTempleSettlementPop ? max(1, round(pop·share·d.sitesPerThousand.temple/1000)) : 0
  n_abbey(c)  = S 为郡治或省治 ? round(pop·share·d.sitesPerThousand.abbey/1000) : 0
  若 M == parish 且同盟 parishOne：同盟内各教团的 n_temple 合并为 1 座（主奉 = 与 county.industry 最匹配的神：industryHints 表 矿→楔声、渔港→泊纱、极夜→覆灯、其余→镜缓），其余为侧龛 aspects；n_abbey 独立
  若 M == none：n_temple = n_abbey = 0；shrine 全为 oboo，位置沿 routes.json 该郡路线每 20 km 一处（数据 `obooSpacingKm`）
  若 M == keeper：temple = 抚育堂/静舍 各 ≤ 1；shrine = 记名树，每个养育群（household cluster）1 株
  shrine 类型分配（东陆 many_small）：按 shrineMix 表 {earth_lord: 0.4, hearth_public: 0.1, well: 0.1, mountain: 0.1(仅 forest/stone 郡), river: 0.1(仅 wet), roadside: 0.2}
  households_with_shrine = round(households·share·d.householdShrine)  → 家户事实 shrine（04 §8）
生成顺序：街区 → 店铺 → 信仰场所（本步）→ 职位 → 神职（04 §5.2）→ 灵地登记
```
数量感（由 01 §2 的 faithDensity 表推导，不写死）：王畿城 pop 8000、civic 0.85 → shrine ≈ 54、temple ≈ 8、abbey ≈ 4；铜脊城 pop 8000、forge 0.9 → shrine ≈ 4、temple 1（parishOne 合并）、abbey ≈ 1。验收 V2 断言"王畿 temple+shrine 数 ≥ 5 × 铜脊"由表推导。

白石镇与五村：**不重生成**（已物化）；只把现有止波寺、芦衡观、归途殿、河湾石坛补 `faith` 块（§11 M1）；五村灶龛作为 shrine 实体经议案新设或由共灶会组织时钟在首个修渠灶饭日创建（世界事件，非回填）。

## 6. 寺观经济（E6）

### 6.1 收入
- **香火**：ordinaryRite 1 铜 + 树脂（已有）→ 公库；`incenseShareToDeity` 比例同事务转入神的 incense 账户（04 §4 守恒对）。
- **服务费**：度亡（rite:funeral 阶段材料 + 主祭费 = 数据 `funeralFee` 按文化：东陆 20 铜、西境 10 铜 + 什一粮抵、林冠 0）、占卜（oracle 动作 2 铜）、义学（已有 4 铜/课由公库付主持——即支出）、法会。
- **庙产**：abbey 与东陆 temple 可 owns 田地（生成时按 `landPerAbbeyHa` 数据 20 ha、temple 2 ha；来源 = 聚落公共田划拨事件，账本可查）→ 佃出，收租 fieldRent（customaryShare 3/10 现有）→ 公库。西境修道院自营（labor 由住众）。
- **什一**：西境堂区 `tithe` → 义务 `tithe`（每户收获后 10% 转堂区公库；07 册 clerical 法条支持强制性；拒缴 = 教法纠纷，不是王法罪）。
- **庙会摊租**：§9。
- **放贷利息**：§6.3。
- **布施**：玩家与 NPC 的 donate（transfer）。

### 6.2 支出
relief（3 铜 + 干粮 / 次）、medicine、school、assembly、repair（faith.json uses 单价不改）、职位月俸、神的 incense 分成、什一的再分配（西境堂区 1/3 转贫户，Thomas 1971 第 2 章堂区救济）。

### 6.3 频次派生（替代"文字规则"）
```
relief_per_day   = floor((treasury − reliefFloorCoins) / relief.coins / 30)   上限 = 当地 hungry 人数（body thresholds）
lending_capacity = treasury × lendingCapOfTreasury；利率 interestBps（东陆 300、西境修道院 0 只借实物、草原无、林冠无）
→ 注册为 credit.mjs 的 lender（现有钱庄接口），借款人须 devotee_of 或 当地居民（章程 `lendTo`）
repair 当 facility wear > 阈 自动排入（k10b 公共维护已有）
```
东陆寺观因此是地主与钱庄、西境修道院是农场与医院——不是写死，是章程数据 + 密度 + 田产比例推出。

## 7. 人员、出家、受戒、受箓、还俗（E4、E5）

- **出家** = 仪式 `rite:ordination_<culture>`（04 rites.json）→ 两持有：`member_of(教团, role: novice)` + `devotee_of(教团)`；probationDays 后 role → ordained（事件）。出家者 citizen_of 不变（东陆：户籍保留，但家户 `members` 中标 `cleric: true`，不计家户口粮 mouthWeight——由寺观供食；西境：同）。
- **受箓**（道士）：`permit:talisman_authority`（faith.mjs 已声明 permit 种类）→ 护符配方 `authority` 字段读它（13 §13.6）；无箓画符 = purports 真符而无效。
- **受戒**：章程 `vows` 成为该人的成员规范（norm-stack 成员层），违者 = 破戒事件 → 教团处分（罚、逐出 = holding.close member_of）。
- **还俗** = holding.close(member_of)（devotee_of 可留）；exitPenalty 立场；东陆 7 日内须向里正登记（norm:register_laicize）。
- **职业**：僧侣 / 道士 / 祭司 仍是 professions.json 战斗职业；**入职地点派生**（01 M4）：有 `office_temple_abbot` 持有人且其持该职业认证的场所即可认证。出家不是入职：俗家弟子可学职业而不出家（止波寺"白日可问学"现状即如此）；出家人不一定有战斗职业。
- **人数**：staffing.perWorshippers → 每场所职位数；住众由 population.mjs 生成时按 `residentsPerAbbey` 抽，身份 cleric。
- **继任**：住持空缺 → 教团任命（office-succession 加 `faith_office` 规则：候选 = 本场所 ordained 成员中 standing 最高者；无 → 教团他处调任；再无 → 空缺，服务停摆）。

## 9. 与节日的关系（F5 庙会）

- 场所是 festivals 的 `venue.location` 候选；**庙会** = 节日 `calendar.marketDay: true` 且 venue.siteClass == temple → 当日市场投影在该场所开摊（market.mjs 场地 = 寺前），摊租 `fairStallFee`（数据 2 铜/摊）入公库。
- 东陆按 01 §4.6 窗派生：上元灯（temple 挂灯 feature lamp lit）、中元（施食 relief 频次 ×3 当日）、城隍诞（office_city_god 任职日为 window:city_god_birthday，每城不同——**由任命事件派生**，真实世界各城城隍诞不同日正是如此）。
- 西境：堂区节 = 主奉神的仪式日；收获节什一入库日。
- 草原：赛会在敖包旁（oath_witness）。
- 林冠：嗅迹日在静舍晒台。

## 10. 与法律的关系（01 §4.4 clerical 层）

- **教法只对成员生效**：章程 rules 进成员层；非成员不受戒律约束。
- **婚丧登记**：西境 `marriage_register`、`funeral(register)` 服务 = 法典 recognition 的证据来源（07 册：西境法典 `recognition.marriageProof: parish_register`）。
- **圣域**：`sanctuary.primitiveLimits ["vital"]` → 场所内 vital 原语被拒（01 §1.5），例外 self_defense；追捕者须等出门 —— 王法可声明不承认（法典 `sanctuaryRecognized: false`）。【已决·亮圳 11-10：A】②跨圈王国下：王法成文法 `sanctuaryRecognized` 对西境堂区设 true、对东陆寺观设 false（王畿律不认寺观避罪，依《唐律疏议》无寺观避罪制），形成"西境教堂可避、东陆寺观不可避"的差异。（B 未采用）
- **淫祀禁令**（东陆 code）：无 divine_office 登记的 shrine 收香火 ≥ 阈 → 衙署可查禁（罪名 offense:illicit_cult，上位 offense:fraud）；出处《史记·滑稽列传》西门豹、《唐律疏议·职制》"私祈"条。西境无此罪，家宅精灵供食合法。
- **教产税**：法典 `clericalLandTaxBps` 修正 sovereignty.maxTaxBps（东陆免半、西境免全——数据）。
- **出家脱籍**：东陆法典 `clericRegistry: true`（度牒制形状：出家须登记，07 册）；西境无。
- **寺观放贷**受王法利率上限与教法上限之较小者。
- 神职受贿、错判：阴律与王法协查（13 §13.7 allied_with）。

## 14. 边界情况

- **聚落多文化**：按 share 各算；share < 0.15 的文化走家户神龛，不建场所（01 §6.1）。
- **边境白石镇**：已物化，一寺一观是事实；派生值若要求更多 shrine，由共灶会时钟在节日创建灶龛（世界事件），不回填。
- **草原无公库**：萨满收礼是个人收入（labor），敖包无账户；誓约见证走 oath 仪式，记录在 records。
- **林冠非货币经济**：补植承诺 = `vow` 义务（04 §8），成活苗数 = settle 条件。
- **神职空缺的庙**：服务 witness/funeral(register) 停摆，香火仍收（入公库），信众转向他庙（standing 下降）。
- **玩家出家**：同 NPC 流程；玩家可同时持战斗职业。玩家出身兽裔（已定可配置）→ 缺省 devotee 砾闻静舍，出家进寻迹静舍。
- 【已决·亮圳 11-10：A】①中陆作东陆核心：王畿按东陆寺观模板生成，城隍庙与禅院在中陆诸邦，衡檐证契堂随 04 §2.2。（B 未采用）
- **复活登记点**：机制不变；归途殿 faith 块 services 加 `revive_register`（叙述归属，不改 rules.death）。
