# 道途百科：数值与机制借鉴研究

研究日期：2026-10-20。结论：值得借鉴的是来源、约束与反制的组合，不是等级规模或数值。A3 当前不增加本报告提出的新玩法。

依据为本地 CSV；下文“表号:r”指文件名前两位与 CSV 逻辑记录号，含换行单元格仍算一条。已浏览23派的概述与入门结构，重点核对公共武学、成长及效果表，并抽看本项目四类数据形状。百科含旧服数据、空白项和作者自报疑误；计算表45–47只保留结果值，不能还原电子表格公式。因此可评价结构与明显激励问题，不能认定各流派胜率、耗时或经济平衡已获验证。

## 1. 他们的核心数值框架

**等级与承载上限。** 个人经验约束最高技能：最低经验呈偏移后的技能等级立方增长，反解为 `L上限≈常数＋经验^(1/3)`；经验跌破门槛会掉技能，多数知识技能例外。专项还受基础技能与知识等级限制，可概括为 `专项上限=min(各前置允许值)`。另有兼修承载：`Σg(各武功等级)^3 < 系数×理论知识等级^3`，其中高段的 g 降低斜率；超载分阶段反噬。它限制的是组合总负担，并非每门单独封顶。（32:r11；02:r10–11；11:r38）

**内力、精力与身体。** 应区分当前可用量、已练出的上限、还能增长到的极限；常规补益达到极限停止，个别物品可以突破，故“极限”不是普适硬界。内力极限形状为 `N≈(aB+bL+c·kL²)×通脉倍率×闭关倍率＋根骨天赋项＋身份常数`：B 为基础内功，L/k 为所选心法等级/系数。应选实际贡献最大的心法，不是最高系数者。闭关成功次数受先天根骨约束；精力极限为 `J≈(d·灵慧+e·先天悟性)×突破倍率×闭关倍率`。百科要求逐步截断，统一最后取整可能不同。（39:r13–26；45:r10；33:r16–20）

经脉另给血量、激发等级、暴击、护体等分段加成，并有单脉与全通奖励；冲穴耗分档药材，随机成功但有次数保底，高档药冲低档穴不提高成功率。这里的经脉养成与内精公式中的突破倍率不可自行合并。年龄只查到容貌、易容限制及减龄物品，未见年龄直接参与内精极限公式，不能推断“越老内力越强”。（37:r10–20；31:r21；33:r25）

**学习来源与门槛。** 导师、秘籍、任务掉落、周期事件、宝箱、研究和练习并存；来源限定可学区间，具备技能不等于已学绝招或有权使用。门槛交叉读取经验、先后天属性、基础技能、容量、身份与性格；部分高级技能须先教到一定等级才能练习。理论知识既解锁又辅助战斗，个别技能之间还有辅助研究与解除反噬关系。（23派；25–30）

**相生相克与触发。** 基础能力、专项、激发配置、武器和资源存量共同决定效果。连击通常逐击判断，可附加毒或控制；控制又使部分后续攻击必中，存在连锁放大。特殊防御先增强招架/闪避，失败后还可能免伤；其形状多为 `攻击评分的随机函数 < 防御评分`。知识可以提高攻击评分，抵消特殊防御；另有耗内力免伤、以血换伤害。反震则同时检查徒手、加力、双方内功及当前内力差，不是固定返伤率。某种吸取收益随双方容量差分段折减，另种吸取累积反噬负担。（25:r19；35；40:r30、44、68、79–82；41:r13–33）

**师门与任务。** 拜师晋阶可要求经验、基础功夫、切磋与介绍凭证；宗师评价综合基础、专项与当次招式，随机招式使同一配置反复评价可能得到不同结果。任务敌人按玩家经验区间阶梯增长，百科因此建议主动压低经验；宗师又解锁闭关、资源容量及每日限次任务。表32主要是“经验→任务怪技能”，不是独立师门等级公式。（02:r13；06:r11；21:r13；32:r10、13–33；38）

**天赋与性格。** 有限天赋槽装配主动或被动能力：资源换短时增益、恢复、脱战、容量或研究效率；可通过物品随机重置。性格同时给战斗收益与绝学准入，选择从扮演偏好变成构筑门票。幸运能消除部分药品失败，部分复合天赋保留不被重置，长期收益并不对称。（31:r10–32）

## 2. 合理性评估

**好的结构。** 立方经验门槛使固定经验投入的等级回报递减；基础与专项双层结构容许通用训练支撑专精；兼修负担使“学得多”有代价；吸取收益递减降低强者反复收割弱者的效率。血、内力、精神、材料与行动恢复时间互相约束，能产生短期爆发与续航取舍。知识参与破防，让非直接伤害技能具有用途。

**不能误称为软上限。** 原例兼修阈值、药品次数、闭关次数多是硬限制；真正值得提炼的软化结构是收益折减与高段斜率变化。心法容量含平方项，再乘突破和闭关倍率，会放大领先；经脉后段单点奖励还增加，不能以“成长慢”证明战力不膨胀。需要同时看单位工时成长、有效生命、耗能和每交锋期望伤害。

**拖时长与防刷。** 周期抽奖、极低概率观景、冲穴失败消耗、每日限次、随机宗师评价客观上拉长等待或消耗；是否专为留存、防刷设计，是推测而非作者证言。任务随经验跳档却鼓励弃经验，是明确的逆向激励。单人沙盒应让高难度来自对象本身、订单、资源与环境，成长按实际游戏时间和有效工时结算，不要求玩家现实守点。

**付费边界。** 百科出现元宝游学提示，另有宝箱、重置书、突破上限物品；可指出其具有售卖加速或构筑便利的空间，但没有价格、来源与掉率证据，不能认定这些物品均收费或测算付费差距。（06:r85；29；33）

**组合风险。** 高频连击叠控制、控制必中、二次全免伤与容量差触发高倍率，可能形成压制循环与胜负断崖。反震及专名豁免堆叠会提高查攻略成本。多资源只有在恢复、转换和行动时间都计价时才构成取舍，不能只增加条数。

## 4. 不借鉴清单及理由

- 不复制名称、招式、原系数、数表、地图流程与剧情；机制用本项目世界条件重新表达。
- 不用经验倒退换简单任务、按玩家经验刷新敌人强度；对象能力应可由自身事实解释。
- 不用现实周常守点、随机评价刷合格、冲穴抽奖充当主要成长；以工时、训练质量、真实机会和突破事件承担节奏。
- 不用性格、性别、婚姻或伤害亲友作为强力技能通票；门派规矩可作社会条件，需能交涉且不替代能力判断。
- 不照搬无代价全免伤、连控必中、容量比跨线暴增及专名豁免；它们破坏统一裁决和可读反制。
- 不采用离派删已学技能或靠换派搜集特例；身份变化影响许可、授课与服务，已获得知识保留，实际遗忘须有规则事实。
- 不把百科未给出的年龄公式、付费目的、空白效果及旧服装备值当成确定事实；保留未知，不据此立实现卡。
