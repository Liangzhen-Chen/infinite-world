## 0. 一句话

一张 schema 装所有生灵：家山羊、路鬃野猪、苔灯狐、坟中坐者、灶下行釜、冤魂，差别只在 `origin` 与六条标签轴。普通动物按栖地与种群（现有生态引擎原样），超自然生灵按**出处必填、六轴标签、传说/真相双层、按圈亲和准入、按配额限活动实体**五条规则入九省。妖怪志 949 条是知识层索引，不是待填的格子：每条先成"书本与传闻"，有独有钩子的才成物种模板，配额只管同时活动的实体。

## 1. 现状订正与引擎位置

### 1.1 现状订正（取证后与 00 不同处）

- 168 条怪物的 25 处栖地 **全部挂在西陲聚落的 scope 链下**（habitat_copper_ridge → site_copper_ridge → loc_bs；habitat_white_canopy → site_white_canopy → loc_capital → loc_hw），但其中 20 处 `site_*` 远方野地（铜砾岭、乌岩阶、盐苇、玻璃沙丘、淤峡、雨石盆、泥炭洲、白冠林、冰回谷、赤褶、月崖、冠雪、深星坳……）**主题上就是远省**（名字与 regions.json 郡名一致：白冠郡、赤褶郡、冠雪郡、灰盐郡）。因此"远郡零怪物"不准确：**约 100 条怪物已经是远省物种，只是地点 parent 挂错在西陲**。迁移 M1 把这 20 处 site 的 parent 改为对应郡（id 不变）。
- species.json 5 条新 schema 条目都是**对 monsters.json 中同 id 的补充**（monster_bent_horn_goat 等），不是独立物种；即"新 schema"现在只是 husbandry/interactions/niche 的旁表。

## 2. 物种 schema 迁移（C2）

### 2.1 目标形状（13 §13.3，不改其定义；此处给落文件与迁移映射）

文件：
- `world/ecology/species.json`：普通动物与家畜（origin `beast:*` / `livestock:*`），现 species.json 5 条扩为 168 条 + 新增；
- `world/supernatural/beings.json`（新）：origin `super:*`，`sources` 必填；
- `world/supernatural/quotas.json`（新，§7）；
- `world/supernatural/banes.json`（新，§6）。
monsters.json **保留为旧表直到 M3 完成后删除**（删除优先：两表并存只在迁移期）。

旧字段 → 新字段映射（工具 tools/migrate-species.mjs 一次性执行，id 不变）：

| 旧（monsters.json） | 新 | 说明 |
|---|---|---|
| id, name, aliases | id, names.default, names.aliases（文化→名，旧 aliases 进 `_` 键） | id 不变 |
| template, levelRange | combat.template, combat.levelRange | 战斗参数原样 |
| habitatTags（文字）、wildlife.habitat | habitat（栖地 id）、habitatTags 保留为叙述 | — |
| grouping, diet, intelligence, taming, tamingRule | grouping, niche.diet（枚举化：herbivore/carnivore/omnivore/detritus/none）, intelligence, taming | diet 文字→枚举由表映射 |
| drops | yields.death | 13 §13.3 "旧写法的裸列表视为 death" |
| wildlife{population, capacity, recoveryPerWeek, activeHours, predatorOf, distinction, gather} | wildlife 原样；predatorOf → interactions[kind:predation] | 两处写法并存期由加载器合并，M3 后只认 interactions |
| appearance, habits, threat, materials, voice | prose.* | 叙述层 |
| folklore（散文） | legend.origin_story（知情层） | **传说层**，不被规则读 |
| nature{lineage, group, kind, civilized, reproduction, metabolism, affinity{weak,resist}, spirit} | origin（§2.2 表）、form、drives、culture、lifecycle.reproduction、maintenance、truth.weaknesses（affinity.weak → to: bane:magic_fire 等）、truth.immune（resist） | 18 条逐条映射见 §2.2 |
| tags（trait） | tags 原样 | — |
| bodyMassKg, territoriality（100 条有） | body.massKg, territoriality | 缺者按同 trait 均值补？**不补**——缺字段加载报错，由内容卡补齐 68 条 |

## 4. 生灵的地区出现与密度（C1 扩展，01 §4.9 细化）

```
present(species, county) = habitatFit ∧ culturalAdmission
  habitatFit         = ∃ 该郡地点 habitat 的 biomes ∩ species.habitatBiomes ≠ ∅        （普通动物与超自然同）
  culturalAdmission  = species.culture == null
                     ∨ affinity[sphere(species.culture)][sphere(county)] ≥ admissionThreshold（quotas.json，首版 0.3；按 01 表推导）
                     ∨ county.sphere == sphere:marches
densityCap(species, county) = quota(archetype, county.sphere) × affinity[...]            （§7）
capacity(species, habitat)  = habitatDerivation 现有公式 × min(1, densityCap / 原型族现有活动数)
```
超自然生灵的 `wildlife.population/capacity` 不手填：由 densityCap 与栖地面积派生（与普通动物同一派生，只多乘一个亲和与配额因子）。对**依附宅院的**（anchor:place 户 / anchor:object）不走栖地，走 §5 年久成精时钟。

## 5. 年久成精与宅院精怪（C5）

输入：器物的创建事件时刻（账本 origin 事件）或作者字段 `madeAt`；建筑 `foundedYear`（factions 已有 foundedYear 字段形；locations 需补——13 册建筑册给 `builtYear`，首版缺者由聚落 foundedYear 推）；人气 = 该地点近 360 日事件密度；灵地 = wildlifeAwakening.spiritLands 的派生版（05 册寺观 → spiritLand pointsPerDay）。

```
每月时钟（闭式）：对每件 durable 类物品与每栋建筑
  age          = (now − madeAt) / 360
  risk(age)    = 0                                   age < awaken.minAge（数据：器物 60 年、建筑 100 年）
               = base · (age − minAge) / minAge · (1 + activity) · windowMul   否则
  activity     = clamp(eventDensity / ref, 0, 1)；windowMul = Π 命中阈限窗 efficacyMul（01 §4.6）
  roll < risk → create(creature, origin: super:spirit/object, anchor: 该物, species: 按物品 goods/tag 查 beings.json 的 `awakensFrom` 表)
awakensFrom 表（beings.json 每条 object 类条目写）：行釜 ← tags 含 cooking_pot；瓦灯魅 ← kind lamp；画中人 ← tags 含 painting；书斋纸灵 ← book；古镜 ← mirror；扫帚 ← broom（《太平广记》卷三六八扫帚精）
```
成精后：器物仍是物品（持有不变），生灵以 `anchor:object` 依附；主人不知（知情层）直到作祟事件被观察。安抚 = 供奉 transfer（13 §13.4）；驱除 = 仪式（04 册）；**毁物即灭**（标的 gone → 生灵 transition gone）。
东陆 `legend.truthRatio` 0.5 下，宅院传闻一半是真精怪、一半是风声（推断规则给候选）。西境无此母题（methods 没有 aging_spirit → 时钟对西境文化地点的 base 读 culture 数据 `supernatural.objectAwakenBase` = 0），家宅精灵走 householdShrine 走另一条。

## 14. 边界情况

- **普通动物成精**：wildlifeAwakening 立意后 origin 由 beast → super:cultivated（transition，事件），此时才要求 sources？不——要求的是**物种模板**有出处：每个可 awaken 的 beast 条目写 `lifecycle.awaken.becomes: <beings id>`（如 赤耳林狐 → 苔灯狐），目标条目有出处即可；无 becomes 的物种不能 awaken。
- **物种与具名个体**：两可条目拆为模板 + creature；名字在 creature 事实 `trueName`。
- **边境密度**：marches 不设准入但受配额与亲和密度（.7）。
- **精灵不吃**：maintenance 为香火/怨气（13 §13.3），metabolism 0；供奉是 transfer 到其账户。
- **人形异族作文化**：兽人、哥布林、巨魔是 culture_far_orc/ms_* 的居民，既是 beings 条目又是人口；population.mjs 按 species 取名已支持。
- **玩家建档出身**（已定：首版开放兽裔出身，数据开关 `playerOrigins.allowMonsterSocieties` 可随时关闭——李白决定，亮圳未特别要求）：选兽裔 → 玩家 species = culture_beast 的居民物种（已存在于怪物社会 beings 条目），受 01 §4.7 待遇与本册 §4 准入规则（玩家自身不受准入限制，只影响他携带的物种迁移）；关闭 → 无影响。
- 【已决·亮圳 11-10：A】①§3.1 按中陆作东陆核心写："王畿、细嵌"的宅院器物精怪与城隍冤魂留在中陆诸邦。（B 未采用）
- 【已决·亮圳 11-10：A】②王国跨圈不影响本册：生灵准入读圈亲和，不读政体。
