## 0. 一句话

12 个战斗职业不删不并：它们是**原型**（archetype）。每个原型在每个文化圈有一个**变体**（称呼、师门、材料、仪式名、流派被动表），变体由师承文化派生、不新增职业 id——中式剑客与西式骑士"本质相似"在于同一套 skillTree/promotions/check，"又不同"在于 school 被动表、兵器形制与材料、入职任务、产物链。入职与培训从"11 个在白石镇"改为**由"哪里有持该职业认证的师傅"派生**，九省每省 ≥ 3 种战斗职业可入门。战斗职业的产物链（护卫、押运、剿匪、决斗、比试、驱邪、授徒、赏金）做到和生活职业的配方链一样细：有订单、有工时、有物料、有守恒。

## 2. 原型—变体模型（G8 改为"有文化变体"）

### 2.1 不变的东西（原型层）

`professionId` 12 个、`skillTree`、`promotions` 的阶与守/攻二选一、`combatAction` 数值、`entry.skill/minimumProficiency/difficulty/minutes`、`abandonFee`、一人一战斗职业（training.mjs:41）。**理由**：北极星二.1 派生优先——文化差异是数据派生，不是另一棵技能树；13 §13.6 "职业 = 认证资格职位 + 被动派生表"不变。

### 2.2 变体层：数据形状

**(a) 文化记录 `combat`（01 §3.2 已定，本稿补全）**

```json
"combat": {
  "archetypeNames": {"profession_warrior": "武夫", "profession_knight": "将门骑卫", "profession_swordsman": "剑客", "profession_mage": "方士", "profession_priest": "祝", "profession_witch": "巫", "profession_taoist": "道士", "profession_monk": "僧", "profession_archer": "弓手", "profession_assassin": "游侠", "profession_spellblade": "剑符士", "profession_summoner": "召灵师"},
  "rankNames": {"profession_warrior": [["团练", "锐卒"], ["队正", "陷阵"], ["都头", "先锋"], ["指挥", "破阵"], ["都统", "骁将"], ["镇军", "虎贲"]]},
  "schools": ["school:gate_sword", "school:wayfarer_sword", "school:militia_spear", "school:talisman_hall"],
  "signature": {"weapons": ["sword", "spear"], "armor": ["light", "medium"], "materials": ["goods:iron", "goods:lacquer", "goods:bamboo"]},
  "entryTaskPool": ["task:guard_ward_gate", "task:escort_tax_grain", "task:duel_measured"],
  "native": ["profession_taoist", "profession_monk"],
  "absent": []
}
```
- `archetypeNames` / `rankNames`：显示名；缺省职业本名（01 §4.5）。
- `schools`：该文化有的流派词（形状见 (b)）。
- `signature`：该文化师傅**教得出**的兵器族与**惯用**材料；不限制学生持什么（兵器能不能用由 skill 的 weapons 与物品 tags 决定），只决定入职任务、师门赠予、晋升试炼用的器物与 **产物链的材料来源**（§5）。
- `native`：此圈原生的原型（东陆：道士、僧侣；西境：骑士；草原：弓箭手；林冠：弓箭手/猎人）——原生只影响 **school 数量与师傅密度**（§4），不影响能否学。
- `absent`：该文化**没有师傅**的原型（如草原无僧侣）——仍可由他乡师傅教（01 §5 跨文化学艺），只是本地学不到。

**(b) 新文件 world/meta/schools.json（流派 = 修正项表 + 师门规矩 + 信物）**

### 2.3 careers.json 42 条 variants 的处置

- `region_*` 关键词路由**删除**（违反二.2）；其"地带实战计数 → 变体晋升名"的意图改为：`promotions` 阶名由 §2.2(c) rankName 派生 + **地形事迹计数**走隐藏职业同形的 metric（`terrainFights:{coast,mountain,forest,…}` 按战斗发生地点的 `biomes`，不按地名字），满 `minimum` 可在晋升时选 `terrainTitle`（纯称号，无数值）。

- 迁移：careers.json 保留 `entryTask`、`ultimate`；`variants` 字段整体删除，由 schools.json 与 rankNames 替代。无存档影响（无人读）。

## 3. 入职与培训按地区分布（M4 的实现）

### 3.1 规则

```
canInitiate(x, professionId, 地点 P):
  师傅集合 T(P, professionId) = { m ∈ 当地 NPC | certified(m, professionId) ∧ m.school ∈ cultures[culture(m)].combat.schools ∧ 机构 I 有 openHours ∧ m 在 I 任教（employed_by/operates/holds_office） }
  T 为空 → 本地不可入门（世界内原因："这里没有教 X 的师傅"），给最近邻：有 T 的最近聚落（routes）
  难度 = profession.entry.difficulty + 01 §5 跨文化项（langGap + affinityGap + variantSwitch）+ school.secrecy×2
  费用 = profession.fee × 文化 feeScale（数据，首版全 1）；时间 = entry.minutes × (1 + (1 − aff))
```
- 删 `entry.location`（01 M4）；`trainingInstitutions` 改为**派生**：机构 = 师傅任教处。rules.training.institutions 7 条保留为白石镇的**显式登记**（存档等价），其余由生成期派生。
- 师傅从哪来：remote-generation 物化聚落时，按文化 `combat.native/schools` 与聚落等级生成持证师傅：`n_masters(P, archetype) = round(pop × share × mastersPerThousand[archetype])`，`mastersPerThousand` 在文化记录 `combat.density`（首版：native 原型 0.6/千人、非 native 且非 absent 0.2/千人、absent 0；镇级以上才有法师/召唤师）。生成的师傅是普通 NPC（occupation = displayName），有 `certified` 持有与 school。
- 玩家可以**自己成为师傅**：certified + 任一机构 operates/employed_by → 进入 T；npc-growth.mjs:70 teachNpc 现有。

### 3.2 入职任务（entryTask，careers.json 现有 `entryTask` 形状扩展）

`task:{id, name, description, check:{skill, difficulty}, needs:{item?, location?:谓词, witnesses?}, minutes, kind: guard|escort|duel|vigil|hunt|ward|exorcise|recite|ride|track}`——任务 kind 读现有动作（护卫 = service 义务；决斗 = duels.mjs；守夜 = rite stage window night；狩猎 = quest-wildlife；驱邪 = ritualOperations）。每文化 `entryTaskPool` ≥ 3，入职时按师傅 school.entryTask 取；无则从 pool 按骰值键 `school:entry:${x}` 抽。

## 5. 战斗职业的产物链（与经济同样细致）

### 5.1 原则

生活职业的产物由"配方 × 工位 × 材料 × 技能"派生（K3 卡）；战斗职业的产物同理由"**服务配方** × 场所/路线 × 对象 × 技能"派生。服务配方（`world/meta/services.json`，形状对齐 recipes.json）：

```json
{
  "id": "service_escort_grain",
  "name": "押运税粮",
  "archetypes": ["profession_warrior", "profession_knight", "profession_archer"],
  "minimumStage": 1,
  "inputs": [{"kind": "time", "minutesPerKm": 12}, {"kind": "ration", "goods": "goods:ration", "perDay": 1}, {"kind": "wear", "slot": "weapon", "perEncounter": 2}],
  "output": {"kind": "obligation", "service": "escort", "risk": "transport:risk", "feeBasis": "cargoValue × 0.03 + km × wagePerKm"},
  "demandSources": ["settlement-trade.orders", "transport.bookings", "tax.convoys"],
  "events": {"encounter": "wildlife/npcCrime 读 route risk", "success": "cargo arrives → fee transfer；fame +", "failure": "cargo lost → breach 义务；reputation −"},
  "ledger": {"fee": "src:service → 雇主→受雇者", "ration": "sink:consume", "wear": "sink:destroy(部分)"}
}
```

### 5.2 首版服务配方（每圈都可用，需求来源不同）

| 服务 | 需求来源（现有系统） | 产出/结算 | 地区色彩（由数据推） |
|---|---|---|---|
| 护卫 guard | 商铺夜间（shop.mjs 商号 `operates`）、寺观节日（06 festival laborDemand）、家户失窃后（law 案件） | service 义务，按日工价 ×1.2 | 东陆衙门差役；西境堂区守卫；草原护帐 |
| 押运 escort | settlement-trade orders（08 M4 泛化后九省）、transport bookings、税粮 convoy（finance-tax） | 见上 | 草原护群转场（season window）|
| 剿匪/除害 bounty | law.wanted 现有赏金、quest-wildlife 野兽害 | bounty transfer（victimPledgeShare 现有）| 林冠除巨蛇；西境坟中坐者（13 配额） |
| 决斗/比试 contest | duels.mjs 现有；06 赛会（那达慕型）、东陆比武 | 赏金/立场/fame；nonlethalConflicts 计数 | 草原摔跤与骑射三项 |
| 驱邪/度亡 rite | 13 §13.5 仪式族；06 葬仪主祭 | 仪式费（training ritualFee 现有）+ 供品 sink | 道士符、修士驱魔、萨满出神 |

| 守夜/巡逻 patrol | 聚落治理组织 `administers` 的公共项目（public-projects） | 俸禄（office-salary）| 西境堂区守夜 |
| 战时服役 levy | rules.military 现有征发与军饷 | 军饷、训练 | 全部 |

守恒：所有费用都是雇主账户 → 受雇者的 transfer；口粮与磨损进 sink；没有"打怪出钱"（08 M14）。

### 5.3 兵器甲胄由材料推（北极星：材料属性 × 技能 × 意图 → 产物）

- `MATERIAL_RESISTANCE`（action-limits.mjs:15）迁入 `world/rules/tables/materials.json`：`{tag:"material:steel", hardness:5, density:7.8, flex:2, edgeHold:4, sources:["goods:iron"+"goods:charcoal" 经 recipe]}`；action-limits.mjs:60 读表（AUDIT3 P7 修）。
- 兵器配方输出的 `combat{attack,defense,hit}` 不再手填：`attack = form.baseAttack × edgeHold(material)/4 × workmanship`、`defense = form.baseDefense × hardness/5`、`weight = form.volume × density`；form 表在 `materials.json.forms`。现有 12 件兵器反推 form/material 标签后数值相等（迁移校验）。
- 地区兵器差异 = 本地匠人（铁匠配方 teachers 所在地）+ 本地材料（规则：寒炉铁多 → steel 多；草原角筋 → 复合弓；翡翠硬木 → 长矛与弓）。不写"草原弓"物品名单。

## 6. 战斗原语与技能成长

### 6.1 战斗原语（接 06 §6.4 原语模板）

现有 combatAction.kind 四种 `guard/strike/aim/evade`；补 `charge`（骑冲，需 mounted）、`grapple`（摔跤，nonlethal）、`shoot`（远程，aim 后）、`ward`（仪式类防御，接 13 ward:*）、`feint`。每种是 06 §6.4 原语模板（vital/status/move 组合），技能条目只给 `kind` 与数值；文化变体**不新增 kind**，只在 school 修正项里改数值。
- 护甲减伤改 PoE 形（08 调研 §1.5 建议、§1.23 表）：`reduction = defense/(defense + 5×damage)`，封顶 0.75——替换 combat.mjs:82 的线性相减；首版用 balance 表开关 `combat.armorModel: linear|diminishing`，缺省 linear（存档等价），BalSim 对比后切换。
- 地形：rules.combat.terrain 5 项 → 读地点 `biomes/facilities` 派生（现有），school 修正项 `when` 可读 terrain。

### 6.2 技能成长（现有 practice/npcGrowth 不变，补三条）

1. **流派被动随阶解锁**：school.modifiers 每条可带 `minStage`；`stage` 读 skill proficiency ÷ practice.stageSize（现有 300）。
2. **兼修负担**（道途 §1 "Σg(各武功)^3 < 系数 × 理论知识^3"，08 M30）：一人只能一个战斗职业（training.mjs:41 现有硬限）保留；**跨流派**学第二个 school 的技能走 01 §5 `variantSwitch +2` 且 `learning:gain` 乘 `1/(1+0.2×已有流派数)`（修正项，数据），不设硬上限。
3. **实战成长 vs 练习成长**：practice.dailyCaps 阶内递减现有；实战（encounter）成长 `npcGrowth.work.successGain 6/failureGain 2` 复用（combat 视为 work），每日上限同 `dailyGain 12`——不靠刷怪（北极星二.6）。
4. **失传与秘传**（K5）：school.secrecy 3 的流派只在 `mentor_of` 链内传（holdings.json `mentor_of` 现有）；最后一位持证者死亡且无徒 → 流派 `extinct`（运行态事件），其 token 与 recipes 成为"古谱"书本（books.grades 现有），从书学难度 +secrecy×3 —— 这是"去远方学艺"的理由（10 文档细化）。

### 6.3 法术体系变体（J8）

spells.json 不加文化字段。法术 school（火/水/…）是机制；**施法形式**（符箓/祷告/卢恩/萨满鼓）= 文化 `combat.magicForm: {methods: ["符文","媒介"], names: {"spell_light": "照明符"}, materials: ["goods:paper_talisman"]}`：methods 读 rules.magic.methods 现有枚举，决定施法时消耗哪种材料与 `castSeconds` 修正（符文 +材料 −时间；咒文 +时间 −材料；数据）。同一 spell_light 东陆是"照明符"（消耗符纸），西境是"烛光祷"（消耗蜡），草原是"火位请光"（消耗奶酒奠）——效果 effectSpec 同一个。careers.json 的 `faith_light/shadow`、`element_*` 变体改为法师/祭司/巫师的 school 条目（§2.3）。

## 8. 边界情况

1. **散学**（无 school）：有 certified 无 terms.school → 无修正项、无门规、显示名按 mentorCulture；允许（野路子）。
2. **师傅文化 ≠ 流派文化**（西境人学了东陆行路剑再回西境授徒）：school 的 culture 是流派归属，mentorCulture 是师傅文化；学生变体名按 **mentorCulture**（01 §4.5），流派修正项按 school——于是西境出现叫"游剑客"却练行路剑的人，这是正确的涌现。
3. **换师承**：新认证覆盖 terms（旧 certified 关闭，holdings `certified` exclusive:false 允许并存一段，首版规定战斗职业 certified 唯一）；旧流派修正项停止、门规解除；`variantSwitch +2`。
4. **远郡师傅生成**与已物化存档：只对未物化聚落生效（01 M3）；已物化王畿若无师傅 → 玩家需去别处或自己成师。
5. **玩家冒充流派**：持他派 token（偷来）+ purports → identity_linked 现有机制识破；token tradeable:false 阻止市场流通，不阻止偷。
6. **流派灭绝**：extinct 后 schools.json 条目不变（世界数据），运行态 `state.schools[id].extinct=true`；古谱可复兴（学会 ≥ 3 技能并 certified → 复活事件）。
7. **一人多战斗职业**：仍禁（training.mjs:41）；多生活职业现状允许。
8. **兵器反推失败**（现有 12 件无法由 form×material 复现数值）：允许 `combatOverride` 字段 + 理由（derived-fields.json 的 Override 纪律），列入迁移报告。

## 13. 需产品负责人拍板的事

1. 【待定·亮圳①②】仍待核定（主会话推荐：中陆作东陆核心 / 接受跨圈王国）；对本稿只影响 §7 两处数据。④已定（兽裔开放、可关）。
