## 0. 一句话

**流通与传播没有自己的状态。** 货在哪、人在哪、书在哪、谁信什么神，已经全部是存档里的实体与事件；"文化传播"只是这些东西随商路与迁徙移动后，01 的派生规则（个体文化 §4.1、需求权重 §4.8、场所密度 §4.3、法律层叠 §4.4）读到了不同的输入。本稿做四件事：把省际贸易从 4 条手写燕麦航线变成由物产与需求推出的航线网；把封冻、封山、禁航写成从气候数据推出的路线季节；把迁徙从"饿了搬家"扩成有目的地选择与移民区的规则；把关卡、关税、违禁从手填地点变成按政体边界派生。文化融合与冲突由此自然发生，不写剧情。

> 交叉引用：传送法阵（设施服务、按次收费、互通由本地规矩与法律派生、无永久解锁）的产品方向见 `01-地区文化圈总纲.md` §12「地区节律与远行」（S2-TP1）。

## 2. 概念模型

```
省/郡 (regions.json) ──trade.exports/imports──▶ goods 类（词）
                     ──seasonal──▶ 路线季节（派生到 routes.closedSeasons 的等价物）
                     ──polity──▶ 政体边界 → 关卡（派生地点）与关税（sovereignty）
航线 lane = 派生（供给郡, 需求郡, 路径, 周期, 承运）         不落盘，每周期重算
商队 caravan = 现有承运资产 + 承运人 NPC（在途实体）              存档事实
迁徙 migration = npc-life 现有记录 {person, from, to, reason, status}  存档事实
移民区 = 街区 culture 运行态改写（01 §6.3）                      事件产物
传播 = 无状态；全部读上面这些
```

## 3. 数据结构

### 3.1 省与郡新增字段（world/geo/regions.json，接 01 §3.3）

```json
{
  "id": "prov_fengji",
  "trade": {
    "exports": [{"goods": "goods:horse", "surplus": 0.6}, {"goods": "goods:wool_felt", "surplus": 0.5}, {"goods": "goods:rope", "surplus": 0.3}],
    "imports": [{"goods": "goods:grain_millet", "deficit": 0.7}, {"goods": "goods:tea", "deficit": 0.5}, {"goods": "goods:iron_tool", "deficit": 0.6}, {"goods": "goods:salt", "deficit": 0.8}]
  },
  "seasonal": {
    "sandstorm": {"seasons": [0], "modes": ["cart"], "effect": "slow", "mul": 1.5},
    "snowbound": {"seasons": [3], "modes": ["cart", "horse"], "effect": "closed", "terrain": ["山口", "山地"]},
    "freeze":    {"seasons": [3], "modes": ["boat"], "effect": "closed"},
    "storm":     {"seasons": [3], "modes": ["ship"], "effect": "risk", "riskAdd": 3}
  },
  "customs": {"tariffBps": 800, "contraband": ["goods:horse"], "exitBan": ["goods:horse"], "entryBan": []}
}
```

- `trade.exports/imports`：**手工首版**（§6 给九省表，依据 regions.industry 文字与 01 §2 各圈主粮）；`surplus/deficit ∈ (0,1]` 是相对强度。长期由 02/08 的产出与消费推出后，此字段退化为校验值（E-TRADE-CONSISTENT：派生结果与手填差 > 0.3 报警，不报错）。
- `seasonal`：季节 0–3 = 春夏秋冬（weather 现有 season 索引）；`effect ∈ closed / slow / risk`；`terrain` 限定只作用于该地形的路段；`modes` 限定运输方式（`ship` 为海船，新模式词；现有 cart/boat/horse/walk/pack）。→ §4.2
- `customs`：政体级关税与违禁**按 goods 类**（不写物品 id）；`tariffBps` ≤ sovereignty.maxTaxBps（现有）。郡缺省继承省。→ §4.4
- `polity` 已有（文字）。本稿要求加 `polityId`（如 `polity:kingdom`、`polity:steppe_tents`、`polity:canopy_league`、`polity:orc_bands`、`polity:lignum_union`、`polity:salt_wells`、`polity:bay_towns`、`polity:charter_cities`），政体边界 = 相邻郡 `polityId` 不同。

## 4. 规则

### 4.1 航线派生（每周期重算，不落盘）

```
对每对聚落 (A, B)，路径 P = 寻路(A, B, 当季可通模式)（engine.mjs:859 现有），hops ≤ maxHops：
  对每个 goods g ∈ exports(郡(A)) ∩ imports(郡(B))：
    priceA = value(g, A)，priceB = value(g, B)           统一估值（15 §15.2，market.mjs 现有）
    cost   = Σ_P lengthKm · distanceFactorPerKm + toll + tariff(§4.4) + risk·0.02
    margin = (priceB − priceA − cost) / priceA
  lane(A,B) 成立 ⇔ 存在 g 使 margin ≥ minMargin；货种取 margin 前 goodsPerLane 名
  每聚落最多 maxLanesPerSettlement 条出航线，按 margin 降序
数量 = min(A 公共仓可售(g), B 需求缺口(g), 承运容量)               现有 accounting 规则（只扣公共仓未过期批次）
```
- 稀缺价差（替代"只由距离推"）：`value(g, 郡) = base · scarcity`，`scarcity = clamp((demandWeight / availableStock)^exponent, floor, ceiling)`；`demandWeight` 读 01 §4.8（文化偏好加权）；`availableStock` 读本郡公共仓 + 店铺存量。这项进 market.mjs 的估值表，是**修正项**（挂槽 `economy:value`，附录 A），不是新模块。
- 西陲现状兼容：五村的燕麦环线在新规则下 margin 由各村公共仓余粮差推出；手写 4 条作为**校验样本**——同一存档首个周期派生航线集 ⊇ 原 4 条的 (seller, buyer, goods:grain_oat)（§8 V1）。

### 4.2 封冻、封山、禁航、沙尘（路线季节派生）

```
closed(route, season, mode) = route.closedSeasons ∋ season                              手写路线保留
                            ∨ ∃ 郡 ∈ 路段所在郡: seasonal[k].effect == closed ∧ season ∈ seasons ∧ mode ∈ modes ∧ (terrain 为空 ∨ route.terrain ∈ terrain)
slowMul(route, season, mode) = Π seasonal[k].mul   (effect == slow 命中项)
risk(route, season, mode)    = route.risk + Σ seasonal[k].riskAdd (effect == risk 命中项)
```
- 落点：engine.mjs:859 的 `edge.closedSeasons.includes(season)` 改为上式；action-affordances.mjs:121 的"本季封路"文案读命中项的 k 给原因（"冬季封山""海湾结冰""风暴季"）；remote-generation.mjs:273 删 `frost?[3]:[]` 写死，生成路线 `closedSeasons: []`（全部由 seasonal 派生）。
- 水运：`boat` 河船，`ship` 海船（新模式词，承运与邮递.md 的 register 加 ship：木料 120、铁 8、载 6000 kg）。星湾 `freeze` 冬季 boat/ship 全封；琥珀 `storm` 冬季 ship 风险 +3（不封，走私夜运正是这时，smuggling 现有 contrabandPremium）。
- 后果链（全是现有机制）：封季 → 航线 margin 中 cost = ∞ → 该季无航线 → 需求缺口 → scarcity 上升 → 冬储价值（覆灯神与冬储会的意义由此而来，不写剧情）。

### 4.3 货物、技术与书的传播

**货**：§4.1 航线 + 现有店铺补货（shop.mjs 按 origin 的 route source）。remote-generation.mjs:278 `SHOP_POOLS` 三张**写死物品名单** → 改为按 goods 类派生：`pool(type) = items with goods ∈ shopGoods[type]`（数据 `rules.economy.shops.goodsByType = {tavern:[goods:food_ready, goods:drink], smithy:[goods:iron_tool, goods:hardware], merchant:[goods:salt, goods:cloth, goods:light, goods:container]}`）∩ available(goods, 郡)（01 §4.8）。这样王畿客栈卖蒸饼与茶、寒炉客栈卖黑面包与麦酒，都不是特判。

**技术（配方）**：配方没有"传播状态"；配方在 B 可学 ⇔ B 有人会教（10 §4.4 personTeaching）∨ B 有书。传播的三条真实路径：(a) 工匠迁徙（§4.5）；(b) 书随商队（书是物品，走 §4.1，`goods:book`，B 的识字者买到后可学）；(c) 玩家带回。**派生指标**（知情层用）：`spread(recipe) = |{郡 : teachersAt(郡, recipe) > 0}|`，传闻"某地新出了会做 X 的匠人"由 14 文档的派生传闻读它。

**书的语言门槛**：书有 `language` 事实（附录 A §A.15）；跨圈买来的书要先学语言或请人翻译（12 文档 translation 动作）。

### 4.4 边境：关卡、关税、违禁、通行

```
crossing(route) = 郡(from).polityId ≠ 郡(to).polityId
tariff(g, 进入郡)  = value(g) · customs.tariffBps / 10000                    （≤ sovereignty.maxTaxBps 现有上限；15 §15.7 关税机制现有）
contraband(g, 郡)  = g 的上位词链 ∩ customs.contraband ≠ ∅                   按 goods 类
exitBan/entryBan   = 同上；命中 → 关卡查验（现有 smuggling 查验流程）→ 没收/罚金走规范栈（罪名 offenses.json 现有 smuggling）
通行条款 regions.neighbors.terms（文字）→ 转为 customs 的结构化项：
   "须请向导同行"（翡翠）  → entry 要求同行者持 member_of(林盟) ：`escortRequired: "faction_forestcouncil"`
   "互不进入"（中陆↔雾杉）  → `entryBan: ["*"]` 对非成员；有 recognition 的使节除外
   "臣属"                   → 关税减半（`tariffMul: 0.5`），王国内部省界无 entryBan
```
- 关卡地点由 §3.4 派生；守卫薪酬出自关税账（finance 现有税账）。
- 【已决·亮圳 11-10：A】王国横跨两圈（01 问题②）：西陲↔寒炉↔星湾↔琥珀↔中陆↔镜沼的王国辖区之间都是**王国内部省界**（关税减半、无 entryBan、王法上覆乡俗——01 §4.4 层序），只有对风脊、翡翠、赭牙部、杉根联邑、灰盐诸井、星湾诸湾、特许城邦是真边境。（B 未采用）规则本身不认政体名，只体现在 regions.polityId 的分布。

### 4.5 迁徙与移民区

```
触发（现有 npc-life.mjs:654–700 理由）+ 新增两条：
   机会 opportunity：本聚落 wage(职业) < 0.6 · 最佳可达聚落 wage 连续 90 日        读 labor-market 现有工价
   跟随 follow：师傅（mentor_of 持有者）或配偶迁出 → 同行（现有 marriageMoveDays 机制推广）
目的地选择：
   score(S) = wageWeight·(wage_S / wage_home − 1)
            + affinityWeight·aff(culture(x), culture(S))                        01 亲和表
            + kinWeight·[有亲属/同乡户在 S]                                    kinship 现有
            − distancePerKm·km(home, S)
            − (1 − aff)·outsider.standingPenalty / 100                           外来者待遇（01 §4.7）
   候选 = 可达（§4.2 当季）∧ km ≤ maxKm 的聚落前 candidates 名；取 score ≥ minScore 的最大者；无 → 不迁
入住：现有 strangerHost（按 trust/affection 找户）→ 没有户收 → 租屋（现有 lease）或**新建户**（population 的 household 创建，成员 = 迁入者）
移民区（01 §6.3）：街区内连续 enclave.householdsToFlip 户同文化迁入且该文化户占比 ≥ sameCultureShare → 街区 culture 改为该文化（运行态事件 `district_culture_shift`）
   → 01 §4.3 的场所密度重算（只对新生成；已有建筑不动）→ 该街区出现外来式灶龛/小堂/记名树
   → 01 §4.8 需求权重随居民文化重算 → 店铺进外来货
融入：个体 culture(x) 按 01 §4.1 随 yearsIn 漂移（yearsToLocal 只是说明：0.3·20/(20+10) = 0.2 < 0.5 出生项，所以**一代人不翻转，二代翻转**——子女 birthCulture 按户文化 descent，户主漂移后入户文化随之）
```
- 玩家可以**组织迁徙**：雇人（labor）、给路费（transfer）、提供住处（lease）→ NPC 决策按同一 score（玩家的报价进 wage 项）。这是"把寒炉铁匠请到风脊"的玩法入口，不需要新动词。

## 5. 边界情况

1. **航线全封的聚落**（星湾冬季）：margin 无解 → 无进货 → 冬储依赖；若公共仓见底 → famine → 迁徙 `refuge` 现有理由触发，但目的地也不可达 → 滞留（真实）；春季解封后迁出。不补"冬季空运"。
2. **两郡同政体但不同圈**（西陲↔寒炉，取向 A 下）：无关卡，但 aff 照算 → 标价与立场有差，法典同一部。
3. **走私航线**：contraband 命中的货不进合法 lane；走私网组织（factions 走私网现有）按 smuggling 现有 contrabandPremium 定价，路径避开关卡（寻路对走私者加 checkpoint 节点惩罚）。
4. **迁入者带职业**（寒炉铁匠到风脊）：到达后 personTeaching 成立 → 风脊能学 craft/metal（10 §4.4）；但工位（铁炉）需建（13 模板 + 材料可得），材料不可得 → 只能教不能产——这就是"技术传播受物产约束"。
5. **游方师傅**（10 的行路剑）：迁徙理由 `wander`（新，仅对 school 无 seat 的 member），目的地 score 中 wage 项换成"愿学者数"（standing ≥ 门槛的居民数）。
6. **怪物社会**与人类聚落之间：航线按同一规则（它们有公共仓与货）；aff 走 01 表（culture_ms_* 在 marches 圈）；关卡只在政体边界——怪物社会 polityId 各自独立 → 有关卡（现有"各与邻村立约，官府不派人进驻"的文字转为 customs：`tariffBps 0, entryBan []`）。
7. **玩家携货跨境**：同一 tariff/contraband 判式；查验由关卡守卫 NPC 自治执行（现有 smuggling 查验）。
