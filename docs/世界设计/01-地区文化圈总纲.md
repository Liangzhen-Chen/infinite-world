## 0. 一句话

九省不变，上面加一层"文化圈"（sphere）：**西陲河谷**是王国的混融边境（现有全部内容所在地，燕麦、黑麦、芜菁、一寺一观、战士与侠客并列）；往东的**中陆、镜沼、雾杉**成为东陆志怪圈（衙门与城隍、符箓与水鬼、雾山与木客）；往北往西的**寒炉、星湾、琥珀**成为西境民俗圈（矿精与山中小人、坟中坐者与极夜守候、海难鬼火与一堂区一教堂）；**风脊草原**自成天穹圈（以羊计价、赔命价、听井的萨满）；**翡翠林盟**自成林冠圈（树居林民与兽裔、嗅迹口证、真菌轮作）。地区差异一律由文化记录与地理数据经规则推出，不绑时代、不按地区 ID 特判。

## 1. 为什么是这五个圈，而不是另起新省

1. **北极星一.2：九省 31 郡全规模、不缩减。** 现有 geo/regions.json 的九省已有地形、气候、物产、邻省条款与要人（见 00 §A1），改省等于推倒。
2. **现有数据已经暗含分野。** 中陆"官署与文书、市集与银钱"、镜沼"符箓与验阵、芦纸"、雾杉"雾、杉、木精"天然是志怪土壤；寒炉"矿、炉、楔契氏族"、星湾"极夜、覆灯、有限记忆"、琥珀"海港、救船、一座教会"天然是欧陆民间信仰土壤；风脊与翡翠本来就自成一格（lore/cultures.json 的 culture_steppe、culture_canopy、culture_beast）。
3. **西陲必须是边境。** 它是唯一有 548 名具名居民、486 样物品、391 条配方的省，而且已经同时有止波寺（bld_bs_still_temple）与芦衡观（bld_bs_reed_dao）、战士与侠客、燕麦面包与芦纸。把它定为"两圈交汇的王国边境"既解释了这种混合，也让存档一字不改（§7）。
4. **圈是词汇层级，不是实体**（13 §13.2）：圈不行动、不持有；它只是文化属性聚合出来的画像（§3.6.1），圈间亲和度由画像推导（§3.6），另给一组作者可抄的缺省值。任何规则读的都是文化记录字段，圈只是文化记录的上位词与缺省来源。

### 2.1 西陲混融边境（sphere:marches）

- **地理气候**：河谷平地、丘陵、河滩；四季分明，春汛秋旱（regions.json prov_xichui）。四郡：垄渠（耕作磨坊）、下渡（渡运芦编）、环城（官仓驿传）、上闸（羊毛水磨）。
- **主粮与饮食**：燕麦（item_oats 为 agriculture.grainItem）、黑麦、豌豆、芜菁；水磨燕麦、腌豌豆、燕麦薄饼（item_oat_flatbread）；干粮（item_ration）。**现有 486 样物品全部留在此圈**（00 §B2 的 origin 统计）。
- **代表怪物**：现有 168 条 monsters.json 全部在此（路鬃野猪等）；六处怪物社会（炭阶灰窟、苔灯坞狐族、榆根里木精、裂炉营、回汐埠、灰棚集）。边境特色：东西两圈的生灵都会**越界出现但密度低**（§4.9）。
- **神话信仰**：垄息（耕作分粮）、归汀（归家与无籍旅人）两位原创神；止波寺与芦衡观并立，共灶会以自家口粮祭祀（deities.json）。
- **宗教场所密度**：由信仰档位 `faith.model = "communal_hearth"`（共灶会聚落祭祀）按 §4.3 推导：shrine 2 / temple 0.8 / abbey 0.1 每千人、家户神龛 0.5（全部待校准）。白石镇一寺一观、五村灶龛是存档事实，不重生成；推导只对未物化聚落生效。
- **节日**：修渠灶饭日等 4 个（festivals.json culture_river）。
- **主流战斗职业**：战士与侠客并列授徒（professions.json entry.location 11 个在 loc_bs）；本圈师傅不改变职业称呼（变体名 = 职业本名）。
- **法律来源**：王国成文法为主（law_hw_property 等 5 部）+ 水渠轮值习惯（culture_river.facts.law "争田先量渠口，再请相邻户作证"→ 转为 custom 条目，§4.4）。
- **流通**：粮与麻布换寒炉铜器矿具；林道入翡翠须请向导；河运经琥珀出海；官道通王都（regions.neighbors）。

### 2.2 东陆志怪圈（sphere:eastern_zhiguai）

- **地理气候**：中陆温和四季分明（王畿、阶槛、细嵌、白冠、赤褶五郡）；镜沼湿季沼涨、旱季盐裂（芦语渡、灰盐、潮汀）；雾杉终年多雾、冬季大雪封山（杉根、雾岭、冠雪）。
- **主粮与饮食**：中陆平原——粟与稻两熟区（新增 goods:grain_millet、goods:grain_rice；温度数据见 02）、蒸饼与粥、豆酱、茶；镜沼——芦米粥、菱粉糕、熏河鱼（culture_reed 现有散文直接转 goods）、盐渍瓜；雾杉——荞麦、菌、崖蜜、腊肉。待客先茶后酒；丧家素食（§4.7 礼俗规则）。
- **代表怪物**（以妖怪志候选 docs/妖怪志/映射方案.md §3–4 为来源，逐条有古籍出处）：中陆里坊——画精、古镜、灶下行釜（器物精，《太平广记》《酉阳杂俎》）、城隍判案中的冤魂；镜沼——蛟、鼋、水鬼找替身（《夷坚志》）、鲛人传闻；雾杉——山魈、木客、彭侯（《搜神记》《述异记》）、松精。
- **神话信仰概要**：原创神衡檐（契约与履约见证，中陆）、量阴（饮水与分配尺度，灰盐）、葭界（河岸边界与安息，篆汀）继续为上位神；**地方神职作职位**（13 §13.8）：每城一城隍、每里一土地、每户一灶神位、每山一山神、每渡一河伯——持有人是亡者或精灵，可更替、可受贿、可错判。冥府按民俗结构（十殿、判官、鬼差、孟婆）落在 sphere:nether，由 04/14 写。
- **宗教场所密度**：**多而小**。由信仰档位 `faith.model = "polytheist_dispersed"`（多神分散祭祀）按 §4.3 推导：shrine 8 / temple 1.2 / abbey 0.6 每千人、家户神龛 0.9（待校准；文化记录不再手填 faithDensity，见 §4.3.2）。合理性参照：北魏洛阳一城寺院"一千三百六十七所"（《洛阳伽蓝记》卷五，周祖谟校释本，转引自 https://koreascience.or.kr/article/JAKO201421154209481.pdf 注）；南宋临安寺观与淫祠密布（《梦粱录》卷十五"城内外诸宫观""城内外寺院"）。只判合理，不绑朝代。
- **节日**：按历法窗派生（§4.6）：岁首、上元灯、清明扫墓、中元放河灯（亡魂窗）、中秋、腊祭；镜沼加"验阵日"（符箓校验市集，接现有 industry "符箓与验阵"）。每文化 4–6 个，日期来自 `culture.windows`。
- **主流战斗职业**：同一职业原型，变体名由师承文化派生（§4.5）：战士→武夫、骑士→将门骑卫、侠客→剑客、法师→方士、祭司→祝、道士（本圈原生，西境变体为"驱魔修士"）、僧侣（本圈原生）。流派：剑客分"行路剑"与"门内剑"（现有 promotions 的 defense/attack 两枝直接对应）。
- **法律来源**：成文律令为主（新法典 law_zhonglu_statute：王畿律，罪名表复用 offenses.json）+ 宗族规约（clan，family-law.json 增 `polity:"zhonglu_clan"` 条目：父系、长子承祀、析产均分）+ 衙门判例（custom：由案件结果自动沉淀，§4.4 第 3 条）。中陆有科举式考试（现有 exam_river "乡试式"是西陲借来的形式，本圈为源头）。
- **流通**：王都是王国税粮与文书的终点（regions.neighbors "臣属"）；镜沼盐、芦纸、符箓外销；雾杉林产秋冬外运、夏季放牧。
- **中陆诸邦（【已决·亮圳 11-10：A】，设计条文）**：中陆定为"中陆诸邦"——王畿、阶槛、细嵌、白冠、赤褶五郡各自成邦。**整体偏中式**（衙署、里坊、粟稻、城隍、科举，即 culture_civic 的 M3 改写），**但各邦保留自己的风俗，不是整片一个样**。邦与邦的差异**不手写成五套文化**，全部按本稿已有的派生规则推出：(a) 主粮与饮食按各郡 `growingSeason` 与 biomes 走 §4.2（同为粟稻两熟，邦与邦的排序与次粮因气候而异）；(b) 各邦居民构成按郡级 `cultureMix` 覆盖省级值（§3.3、§6.1、§6.2），混居比例不同则 §4.3 的场所组合不同；(c) 各邦法俗：成文法层同属王畿律，custom 与 clan 层按当事人文化与该邦判例沉淀（§4.4，细嵌另有契约城邦模板 law_city，见 07 §2.4）；(d) 与外圈的亲和度仍按 §3.6 的四项公式由数据推出，不新编系数。culture_civic 是否要为个别邦拆出子记录（如 culture_civic 下的邦级 facts 覆盖）：（待实现时定）。

### 2.3 西境民俗圈（sphere:western_folk）

- **地理气候**：寒炉冬长夏短、山口积雪（铜脊、退楔、赭牙、黑炉）；星湾极夜、海湾结冰（雪灯、覆灯湾）；琥珀海风大、春秋多雾、冬季风暴（琥珀港、浅绳湾、盐风群岛）。
- **主粮与饮食**：寒炉——大麦、黑麦、酸菜、麦粒炖菇、黑面包、麦酒（culture_forge 散文直接转 goods）；星湾——鱼干、油烩块根、腌肉、冬储（culture_north）；琥珀——海藻豆饭、烟熏小鱼、盐（culture_coast）。待客递麦酒与面包；冬储仪式化（§4.7）。
- **代表怪物**（出处为欧陆民间传说原典，游戏内全部原创命名、不用真实宗教圣物）：寒炉矿坑——矿中小人（Kobold / Bergmännlein，格林兄弟《德意志传说》Deutsche Sagen 第 1 卷矿山诸条）、山中老人（Rübezahl 型，Praetorius《Daemonologia Rubinzalii》1662）；星湾——坟中坐者（draugr / haugbúi，《埃尔比吉亚萨迦》Eyrbyggja saga、《格雷蒂尔萨迦》Grettis saga），极夜游行的死者队列（Wild Hunt，Grimm《Deutsche Mythologie》第 31 章）；琥珀——溺者灯（海上鬼火 / 沉船亡魂，Lecouteux《The Return of the Dead》第 7 章）、换生儿（changeling，Grimm《Deutsche Sagen》"Die Wechselbälge"诸条）、夜行者（benandanti 型夜间魂游斗法，Ginzburg《The Night Battles》1966/1983）。
- **神话信仰概要**：原创神楔声（工艺与工伤责任）、覆灯（极夜守候与冬储）、镜缓（有限记忆与哀悼）、泊纱（潮窗救助）为上位神；**一堂区一教堂**，教团统一（同一神多面只在知情层争论，13 §13.8）；教堂之外是**家宅精灵与田野精灵**（household spirit：Kobold / Nisse 型，Grimm《Deutsche Sagen》第 71–80 条）、井泉与树的地方守护——按 13 §13.3 精灵类型收录，不按具名神。
- **宗教场所密度**：**少而大**。由信仰档位 `faith.model = "church_unified"`（单一教会集中）按 §4.3 推导：shrine 0.8 / temple 0.35 / abbey 0.15 每千人、家户神龛 0.15（家宅精灵的供食角落；全部待校准）。合理性参照：英格兰 13 世纪约 8000–9500 座堂区教堂对应约 300–400 万人口，即每千人约 2–3 堂（含村级小堂），每座堂区覆盖一个或数个村（https://www.history.org.uk/historian/resource/9594/norfolk-and-suffolk-churches-the-domesday-record ；https://ndarchive.forwardinfaith.com/2017/06/26/the-english-parish-part-1/ ）；我们的 temple 只算镇级堂，村级小堂记在 shrine。
- **节日**：岁末守夜（极夜）、仲夏火、收获节、矿山保护日（楔声）、亡者夜（死者归来窗，Lecouteux 同书第 4 章"the dead return at fixed dates"）；每文化 4–5 个。
- **主流战斗职业**：战士（本名）、骑士（本名；本圈原生）、侠客→游剑客 / 决斗士、法师→术士、祭司→堂区牧者、道士→驱魔修士、僧侣→修士（修道院农场与医院，§2.3 场所）。
- **法律来源**：习惯法为主（custom 0.5：邻里法庭、宣誓助证、赎罪金 wergild 型赔命价——《萨克森明镜》Sachsenspiegel 第一卷；《萨利克法典》Lex Salica 的赔命价表）+ 王国成文法（code 0.3）+ 教法（clerical 0.2：婚姻、誓言、安葬归教团规范）。决斗合法（law.duels 现有）。
- **流通**：寒炉铜铁矿具换西陲粮麻；星湾咸鱼灯油毛皮经琥珀出海；琥珀港是王国海路出口，盐风群岛走私夜运（smuggling 现有）。

### 2.4 风脊天穹圈（sphere:steppe_sky）

- **地理气候**：夏短而热、冬季风大、春季沙尘（逐风集、井环、蹄原）。
- **主粮与饮食**：奶食为主（凝乳、酸奶、奶酒）、炒籽、风干肉；谷物靠交换（culture_steppe 散文转 goods：goods:dairy_curd、goods:meat_dried、goods:grain_millet 进口）。待客先奶茶后肉；主客座次有别。
- **代表怪物**：狼灵与风魔（蒙古、布里亚特口传史诗中的 mangus 型多头魔，出处《江格尔》《格斯尔》汉译本）、石人（草原石像成精，《蒙古秘史》无，取《元史·祭祀志》石像祭仪作背景——**此条待 03 文档查原典，暂不收**）、井中听者（听绳神职的精灵化，原创，挂 super:spirit/place）、干风鬼（旱魃型，《诗经·大雅·云汉》"旱魃为虐"、《神异经》）。
- **神话信仰概要**：原创神听绳（井水、远行、共同草路）；天穹与大地作非人格化的上位（不作神实体，只作仪式对象与誓言见证）；萨满作职业（巫师变体，§4.5），出神（trance 状态，13 §13.6）与托梦为主要通道。
- **宗教场所密度**：几乎没有固定建筑。由信仰档位 `faith.model = "nomadic_mobile"`（游牧移动祭祀）按 §4.3 推导：shrine 3（敖包型石堆，随路线分布）/ temple 0 / abbey 0 每千人、家户神龛 0.8（帐内火位；待校准）。
- **节日**：春季接羔、夏季那达慕型赛会（赛马、摔跤、射箭——接现有 training / 比试）、秋季转场、冬季祭火。日期由牧草窗派生（§4.6：`window: "grass_peak"`）。
- **主流战斗职业**：弓箭手（本圈原生，骑射）、战士→巴特尔（勇士）、骑士→那颜骑卫、巫师→萨满、驯兽师地位高。

### 3.6 圈亲和度（派生，加载期）

**原则**：亲和度 = 两圈文化在主粮、文字/语系、信仰模式、法律传统四项上的相似度，加上有无商路往来（接触度），按权重相加。全部输入都是已有或 §3.2 新增的文化字段与 regions.json 的 `neighbors`；没有任何一处手填亲和值。所有权重、参数标**待校准**，首版值与理由见 §3.6.6。

#### 3.6.1 圈属性画像（由文化记录聚合）

圈本身不存属性；加载时对每个圈 A 取其所有文化 c 的份额 `share_A(c) = Σ_{郡 k ∈ A} cultureMix_k[c].share / N_郡(A)`（郡等权，因远郡人口未物化；郡缺 cultureMix 时继承省），然后：
- 类别属性（`lang.native`、`lang.family`、`lang.script`、`lang.second`、`faith.model`）：画像是份额分布 `p_A(v)`；两圈相似度 = `Σ_v Σ_u p_A(v)·p_B(u)·sim(v,u)`。
- 向量属性（`cuisine.staplePreference` 去掉 `_default`、`lawSources` 按 kind 汇成五维权重）：画像是份额加权平均向量，再按下式比较。

首版五圈各只有一个主导文化（share ≥ 0.8），下面的实例表直接用主导文化的字段写画像；次要文化（如中陆 culture_salt / culture_reed / culture_mist）按同样规则参与聚合，只改小数点后第二位，不另列。

#### 3.6.2 四项相似度（各取 0–1，对称）

```
stapleSim(A,B) = Σ_g min(pA_g, pB_g) / Σ_g max(pA_g, pB_g)         g 取两方 staplePreference 的键并集（不含 _default）；加权 Jaccard；任一方为空集 → 该项"缺失"（§3.6.5）
langSim(A,B)   = min(1, base + sameScript·0.3 + 0.15·[B.native ∈ A.second] + 0.15·[A.native ∈ B.second])
                 base = 1（native 相同）| 0.5（family 相同）| 0；sameScript 要求双方 script 非 null 且相等
faithSim(A,B)  = faithModelSimilarity[A.model][B.model]              §4.3.1 的档位相似矩阵（数据，对称，对角 1）
lawSim(A,B)    = 1 − ½ · Σ_kind |wA_kind − wB_kind|                 kind ∈ {code, custom, clan, clerical, oral}；两向量各和为 1，所以结果落在 [0,1]
```

#### 3.6.3 接触度（由省际商路得出）

数据来源：`world/geo/regions.json` 省条目的 `neighbors[].kind`（现有枚举：贸易、臣属、通行、互不进入；见 regions.json prov_* 的 neighbors 字段）。**不读 routes.json**（现有 462 条全是白石镇内部路，lengthKm 多为 0，不表示省际往来）；若 02 文档以后给省际路程，可把 `edgeStrength` 换成按 lengthKm 衰减的函数，公式其余不变。

```
edgeStrength(kind) = {贸易: 1.0, 臣属: 1.0, 通行: 0.6, 互不进入: 0}        0 即无边
pathStrength(path) = Π_edges edgeStrength · hopDecay^(hops − 1)           hopDecay 0.5
contact(A,B)       = max over 省 a ∈ A, b ∈ B of pathStrength(最强路径 a→b)   同圈 = 1；无任何路径（全是"互不进入"或不连通）= 0
```

无商路时：`contact = 0`，亲和度只剩四项相似度——没有往来的两圈仍可能因同语系或同信仰而相近，这是有意的（例：与世隔绝的同族聚落）。

冥界 `sphere:nether` 无省，接触度不走商路，而走丧葬：`contact(A, nether) = netherBase + netherAncestorCult · share_A(burial.ancestorCult == true)`（0.5 + 0.5·祖灵崇拜份额）。理由：活人与阴间的"往来"是祭祀与归来，祖灵崇拜文化每年固定开门（中元、记名日），无祖灵崇拜的文化只在丧葬时接触。

#### 3.6.4 加权公式、对称性、自身恒 1、落点

```
aff(A,B) = Σ_k w_k · sim_k(A,B) / Σ_k w_k      k ∈ {staple, lang, faith, law, contact}，只对双方都有定义的 k 求和（§3.6.5）
w = {staple: 0.20, lang: 0.25, faith: 0.30, law: 0.10, contact: 0.15}（和 1，待校准）
```

- **对称**：五个 sim 都是对称函数，所以 aff(A,B) = aff(B,A) 恒成立，不需要再手工维护两份。
- **自身恒 1**：A = B 时四项相似度为 1（Jaccard 自比 1、native 相同 1、矩阵对角 1、L1 距离 0）、contact 同圈定义为 1，加权和为 1。
- **落点**：加载期派生。`tools/load-world.mjs` 载入 spheres.json、cultures.json、regions.json 后算出 6×6 表，放在内存里的 `world.spheres.affinity`（只读）；§4.7、§4.9、§5、13 §13.2 读这个表。**不落盘、不进存档、不写回 spheres.json**（I10）。`load-world.mjs --print-affinity` 打印推导表与 `affinityReference` 的差值，供复核（§3.6.7）。
- **文化级亲和**：§4.7/§5 要的是两文化的亲和度；定义 `aff(c_a, c_p) = c_a == c_p ? 1 : aff(sphere(c_a), sphere(c_p))`。同圈不同文化也用圈表（同圈内差异由 §4.1 的文化归属与 §4.7 的 outsider 字段表达，不再细分）。

#### 3.6.5 缺失维度

某圈某项无定义（冥界无主粮、无语言；将来可能有"无法律"的荒野圈）→ 该项不进分子也不进分母，其余权重归一化。这是**整类规则**（对所有非地理圈/缺项圈一致），不是冥界特例。

## 4. "地区差异从世界数据推出"的规则（逐条可实现）

每条给：输入、公式、输出、落点（哪个现有模块读）、不落盘声明（I10：以下全部是派生值，任何出现在存档里的都是校验错误）。

### 4.1 个体的文化归属（派生）

输入：出生户文化 `birthCulture`（出生事件记录，不可变）；居住史（residence 事件序列 → 各地点文化的累计年数 `yearsIn[c]`）；师承（`apprentice_of` / 职业认证持有的师傅文化）；信奉（`devotee_of` 教团的文化）。

```
score[c] = 0.5·[c == birthCulture]
         + 0.3·yearsIn[c] / (Σ yearsIn + 10)
         + 0.1·[c == mentorCulture]
         + 0.1·[c == devotionCulture]
culture(x) = argmax score；并列取 birthCulture
```

输出：`culture(x)`，供 §4.5 变体名、§4.7 外来者判断、dialogue.mjs:46 模板键、faith-state.mjs:12 使用。落点：替换 faith-state.mjs:12 的静态回退链（npc→户→聚落）为上式；现有数据里 npc 自带 `culture` 字段的，视为 `birthCulture`。无迁居史的人结果与现在完全相同（只有 0.5 项非零）。

### 4.2 主粮与饮食结构（派生）

输入：郡 `growingSeason`；作物表 agriculture.crop[*]（sowDays、growthDays、minimumTemperatureC、yieldPerHa，02 补齐九省作物）；郡 biomes；当地文化 `cuisine.staplePreference`；牲畜物种 `husbandry.yields`。

```
arable(crop, county)   = [growingSeason.meanTempC ≥ crop.minimumTemperatureC] · [growingSeason.frostFreeDays ≥ crop.growthDays] · biomeFit(crop.biomes, county.biomes)
cropScore(crop)        = arable · crop.yieldPerHa · pref(goodsOf(crop))          pref 读 staplePreference，缺省 _default
pastoralShare(county)  = |biomes ∩ {grass, dry}| / |biomes|
staples(county)        = 前 2 名 cropScore > 0 的作物对应 goods；若 pastoralShare ≥ 0.5 且 cropScore 最大值 < 0.3·max(yield)，则 staples = 牲畜 yields 的 goods（奶、肉）前 2 + 进口谷 1
```

输出：`staples(county)` 列表，供 household-subsistence 的 `foodItem` 选择（现在写死 item_oats → 改为按 staples 取本地有存量的物品）、agriculture 的 `grainItem`（现在全局一个 → 按郡）、remote-generation 的店铺货源、02 文档的配方族生成。落点：agriculture.mjs、household-subsistence.mjs、remote-generation.mjs:288。

对西陲：燕麦 pref 1.0、黑麦 0.9、芜菁 0.8，其他 _default 0.1；growingSeason 填成让燕麦与黑麦排前二 → 与现状一致（§7）。

| secular_sparse（预留） | 0.2 / 0.05 / 0；0.05 | 禁教、无神或高度世俗化地区 |

`minTempleSettlementPop`：低于此人口的聚落不单建 temple（null = 永不建）。theocratic 低、church 高，因为教会以堂区（数村）为单位。

#### 4.3.2 密度的派生（加载期）

```
density(c) = faithModels[cultures[c].faith.model].density       缺档位 → E-CULTURE-FAITH-MODEL 加载失败；density == null 的档位（nether_court）不参与 §4.3.3
```

文化记录不得含 `faithDensity`（E-CULTURE-FAITHDENSITY-HANDWRITTEN）。想让某文化"庙更多"，只能换档位或改档表——改档表则同档所有文化一起变，这是故意的。

对照（推导 vs 01 原手填，原手填留作对照用）：eastern 8/1.2/0.6/0.9 → 同；western 原 0.6/0.35/0.08/0.15 → 推导 0.8/0.35/0.15/0.15（shrine 与 abbey 上调，因 church 档把村级小堂与乡野修道院的参照折算后比原手填高；差 < 2 倍，不进复核清单）；marches 原文只有"中等偏东式"无数字 → 推导 2/0.8/0.1/0.5；steppe 3/0/0/0.8 → 同；canopy 5/0.5/0/0.6 → 同。无离谱项。

#### 4.3.3 场所数量（生成期）

输入：聚落人口 `pop`、聚落 cultureMix、各文化 `density(c)`（§4.3.2）。

```
对聚落 S 的每个文化 c（share ≥ 0.15，density(c) ≠ null）：
  n_shrine(c)  = round(pop · share · sitesPerThousand.shrine / 1000)
  n_temple(c)  = pop · share ≥ minTempleSettlementPop ? max(1, round(pop · share · sitesPerThousand.temple / 1000)) : 0
  n_abbey(c)   = round(pop · share · sitesPerThousand.abbey / 1000)   （abbey 只在郡级以上聚落）
  households_with_shrine = round(households · share · householdShrine)
```

输出：生成期（remote-generation 物化骨架时）创建对应建筑实体，类别 `shrine | temple | abbey`，`devotee_of` 指向该文化的教团；家户神龛是家户的一个事实 `shrine: {deityOffice}`（灶神位、门神位、火位，按文化 officeModel）。落点：remote-generation.mjs 的街区生成后新增"信仰场所"步；白石镇与五村**不重生成**（已有建筑是存档事实），只对未物化聚落生效。

数量感（用 §4.3.1 档表算，不是写死）：中陆王畿城 pop 8000、civic 份额 0.85 → shrine 54、temple 8、abbey 4；寒炉铜脊城 pop 8000、forge 份额 0.85 → shrine 5、temple 2、abbey 1。这就是"中式寺观多、西式一两座"的可测版本——换档位或改档表就变，V4 的断言按档表现值算，不写死倍数。

### 4.4 法律来源的层叠（派生）

输入：地点所在郡 `polityLaw.code`；地点文化 `lawSources`；现有规范栈（norm-stack.mjs）。


【已决·亮圳 11-10：A】王国横跨两个文化圈，王国法律只管大事，小事仍按各地风俗，法从俗出（分层条文见 07 §2.4.1；见 §11.2）。做法：

- （B 未采用）

**风俗成法规则**（G3）：同一法域内，同一罪名/民事争议**以习惯方式结案 ≥ N 次（数据 `customs.precedentThreshold`，首版 5）且结果一致率 ≥ 0.8** → 反应规则自动把该结果写成一条 `custom` 条目（`source: "precedent"`, 带来源案件 id 列表），进入该文化的 customs.json 运行态（存档内，是事件产物不是派生）。成文法政体可用议案（05 §5.2.5）把 custom 升为 code 或废止。

### 4.6 节日与阈限时间（派生）

输入：文化 `windows`；历法（ontology/calendar.json：12 月、29/30 日交替、19 年 7 闰）；festival 的 `trigger.window` 或固定 `calendar`。

```

windowStart            = 固定月日 → 直接；"grass_peak"/"harvest"/"first_frost" 等**物候窗** → 由该郡 weather 状态机当年第一次满足条件的日期（例：harvest = 主粮作物成熟事件；first_frost = 日最低温 < 0 首日）

```

### 4.7 外来者的待遇（派生）

输入：行为者文化 c_a、地点文化 c_p、二者亲和度 `aff = aff(c_a, c_p)`（§3.6.4 的文化级定义：同文化恒 1，否则取加载期推导的圈表 `world.spheres.affinity`）；地点文化 `outsider`。

```
priceMarkup(x, 地点)      = (1 − aff) · outsider.markup                       → 修正槽 economy:outsiderMarkup（卖给他时加价，买他货时压价）
initialStanding(x, 地点)  = base − (1 − aff) · outsider.standingPenalty         → 立场初值（standing.mjs 现有槽）
teachWilling(师傅, x)      = standing(师傅, x) ≥ outsider.teachStanding · (1 − aff) + schoolSecrecy（10 文档）
礼俗失礼                   = 行为者不按 hospitality.order 行事（拒茶、先酒后茶、丧家食肉）→ 事件 `slight`（不是罪），立场 −k（数据）
```

输出：三个修正项与一个事件族。落点：market.mjs 报价读修正槽；standing 初值；npcGrowth.teach 前置；dialogue 的招待分支。**同文化、同圈内 aff=1 → 全部为 0，现有存档行为不变。**

### 4.8 地区可得性与流通（派生，接现有）

输入：物品 goods 类；本郡配方可产集合；settlement-trade 的省际价与周期；文化 cuisine/dress/building 偏好。

```
available(goods, 郡)   = 本郡可产(goods) ∨ ∃ 邻郡可产 ∧ 贸易周期内有承运（settlement-trade 现有）
demandWeight(goods, 郡) = Σ_c share_c · pref_c(goods)                            → 市场投影的需求侧权重（15 §15.2 的"需求留存"项乘它）
文化传播（11 文档细化）：外来 goods 连续 M 个周期在本郡成交 → 本郡文化 staplePreference 对它的运行态偏好 +δ（事件产物，存档内；上限 0.6）
```

落点：market.mjs 需求侧；settlement-trade.mjs。西陲内部 pref 与现状一致。

### 4.9 生灵的地区出现（派生，03 细化）

```
present(species, 郡) = 栖地匹配(species.habitat, 郡.biomes) ∧ 文化准入
文化准入             = species.culture 为空 ∨ aff(sphere(species.culture), sphere(郡)) ≥ presenceAffinityMin ∨ sphere(郡) 的 outsider.policy 缺省为 open（即边境圈）
密度上限             = 13 §13.9 配额表 × aff
```

`aff` 读 §3.6 推导表；`presenceAffinityMin` 是 spheres.json `affinityModel` 里的数据参数（首版 0.2，待校准；见 §3.6.8 末段理由）。即：狐妖主要在东陆，但在边境西陲可见（现有苔灯坞狐族正好是这样）；坟中坐者主要在星湾，边境也可能遇到；首版推导表下草原狼灵（steppe–canopy .20）恰在阈值上可入林冠、西境矿精不入草原（western–steppe .13）——这些结论随属性与阈值变，不写死到规则里；要把某物种带去不准入的圈只能靠迁移事件改 habitat。

## 6. 边界情况

### 6.1 混居聚落
- 聚落 `districts[].culture`（已有）给街区文化；`cultureMix` 给总体份额。
- §4.3 的场所按份额各算：中陆王畿城若有 10% 西陲人，则有 1 座西陲式灶龛会所；5% 草原人不足 0.15 不单建，走家户神龛。
- 市场一个，需求权重按 §4.8 加权；两种法典不并存——法域只有一个（place.lawCode），但 custom 层按**当事人文化**取条目（family-law 已这样做：family-state.mjs:88 按 culture 找规则）。冲突时成文法优先并可解释。

### 6.2 边境郡
- 郡覆盖 `sphere`（例：西陲环城郡可标 eastern 的 cultureMix 0.4），亲和度按郡算。
- 边境居民的 `lang.second` 由郡 cultureMix 第二文化的母语派生（出生时开立初值，附录 A §A.15）。
- marches 圈的 outsider.policy 缺省 open（markup 0.05）。

### 6.3 迁移
- 迁居是事件（residence 变更），§4.1 的 yearsIn 从事件派生；无新存储。
- 子女出生入户按**户**文化的 `descent`，户文化 = 户主 culture(x)（派生）。
- 一个人迁居 20 年后 culture(x) 可能翻转 → 变体名、立场初值、师傅意愿随之变；他已有的职业认证与 school 不变（条款快照）。
- 文化漂移的供奉版（生灵"认"北境仪式）见 13 §13.2，同一公式的权重项。
- 整户迁徙与移民区（11 文档）：连续 K 户同文化迁入同街区 → remote-generation 把该街区 culture 改为该文化（运行态，事件产物）。

### 6.4 玩家来自外地
- 建档新增一步：选出身文化（任一 culture 记录，含怪物社会的 6 条——选兽裔就是兽裔）。兽裔/怪物社会出身**首版开放**，做成数据开关：rules.json 新增 `playerOrigins: {"allowBeastkin": true, "allowMonsterSocieties": true}`，为 false 时建档列表过滤掉 culture_beast / culture_ms_* 条目，其余规则不变；已建档存档不受开关影响（出身是存档事实）。依据：李白决定（2026-11-09），亮圳未特别要求，故留可随时关闭的配置而不写死（见 §11.4）。缺省 = 起始聚落的主文化（现在的存档等价于选 culture_river）。
- 由此派生：母语与第二语言初值、度量显示、§4.7 在各地的初始立场与标价、§4.5 显示名（玩家无师傅时用自身文化）、§4.1 的 birthCulture。
- 玩家在他乡学艺走 §5；入籍走现有 citizen_of。
- 玩家可以**说谎**自己的出身（purports，现有身份键机制）；被识破走现有 identity_linked。

### 6.5 无文化的东西
- 物品、建筑、生灵都可能没有文化字段：物品永远没有（§3.5 原则）；建筑取地点文化；生灵 `culture` 为空表示普通动物，§4.9 不设准入。
- 任何规则遇到"文化记录缺某字段"都是加载期错误，不是运行期回退。

## 12. 地区节律与远行（产品方向）

> 来源：主会话合并方案 regional-season-plan C 节与 S2-TP 接口稿 §7 落地稿，随 S2-TP1 入库（原拟 §5，§5 已是「跨文化学艺」，改为本节，标号 5.x 顺延为 12.x）。

**出处**：亮圳原话，李白转。

「我总是觉得你们在过分地追求真实，一定要把所有地方都拎上一个真实的地理位置，但实际上一个魔法世界，它各个地方确实就是可以变差异很大的，它就是可以有不一样的季节和不一样的，完全不一样的历法，节气，农忙的。……我们可以后续通过各种菜单等等之类的提示帮助玩家理解当地的具体这些设定是什么样子，但我不太想要把全世界的都弄得一模一样，这样太真实。」（亮圳 11-27 19:11）

「世界尺寸的话我是希望尽量广袤的……当玩家真的需要通过游戏内的交通工具才能触达另一个地方的话，会让我觉得更加真实。另外我希望传送法阵是这个游戏核心的赶路工具，但它不是像大多数RPG游戏那样，开一个塔之后你就可以永久的马上穿梭到那个地方。……传送法阵由各地的权威所掌、统领，然后他们会收使用这个法阵的费用，所有人都可以自由地使用这个法阵。不同的地区之间如果有联系，他们的法阵就会相互开通……一个人想从上海去欧洲，就不能坐火车，只能坐飞机，而且需要签证和护照，是这种感觉。」（亮圳 11-27 19:13）

「可以先设计好MVP，我期待看到的是一个镇子，下面有几个村子，这几个村子都有低阶的传送阵，可以相互传送。有些村子过于落败没有传送法阵等等，反正能让我大概体会到这个游戏的玩法，但不必把整个传送阵在全世界都做出来，地图不用太着急。」（亮圳 11-27 19:15）

**12.1 各地有各地的节律。**
- 世界共用一个时钟，但各地区的季节、节气、历法、农忙可以完全不同：四季分明、只分干湿、冬长夏短，都是设定。
- 现实气候只给数值作参照，不约束世界。
- 新加一种地区节律，只加设定数据。

**12.2 帮玩家看懂本地。**
- 菜单的「此刻」显示当地的季节和节气，以及玩家熟悉的历法日期。
- 每一项都能展开，说明它在本地是什么意思、和玩家的家乡有何不同。
- 外乡人不懂本地农时、节日而错过或闹笑话，本身就是玩法。

**12.3 世界要大，路要真实。**
- 横穿世界是一趟以月计的远行。
- 步行、车马、船按真实的时间和花费结算。
- 越远，风貌越不同。

**12.4 传送法阵是交通与经济的一部分。**
- 法阵是设施，归当地权威掌管，向所有人开放，按次收费。
- 有没有法阵取决于聚落的规模和兴衰，破落的村子建不起，也养不起。
- 两处法阵通不通，取决于两地之间有没有联系：同归一镇所辖、同属一个政权、结盟或签了通行条约。联系断了，法阵也就断了。
- 没有「到过一次就永久解锁」。
- 远行到关系疏远的地方，要先取得对方签发的通行文书，就像签证和护照。
- 法阵缓解远行之苦，但不让世界变小。

**12.4a 法阵规矩从当地长出来（产品方向）**

**出处**：亮圳原话 11-27 19:38，李白转（语音转写，「传送证」即传送阵）：「……不同的政权之间，他们有一个共同的约定……传送证如何相互管理，这就类似于现在的国家之间如何决定两个国家之间是否需要签证……一个国家之内有一套关于传送证的法律……这个法律也会和他们当地的习俗呀，信仰呀，宗教呀，文化呀有关系。……下面的一些小的行政区划，他们想要什么样的传送证规则，只要符合他们那个政体的法律，他们可以凭借自己的情况去定。……应该是从当地的风俗习惯文化当中长出来的，只要符合法律，怎么样都没问题。」

- **三层**：
  - 政权之间的公约，决定两国的法阵通不通、要不要通行文书；
  - 一个政体之内的法律，与当地习俗、信仰、文化相连，划出底线；
  - 镇、村这些下级的本地规矩，只要不违法，自己定。
- **本地规矩管的事**：
  - 多大的聚落才设法阵；
  - 和谁互开，村到村要不要经镇中转；
  - 收不收钱、收多少；
  - 镇向村抽几成；
  - 共同贸易体之间免费，关系差的两镇不互开；
  - 上级强令互通的，照样可以收高价。
- **人数够也可能没有法阵**：村子太穷，养不起。
- **MVP**：只有白石镇一套规矩（八户以上、公库养得起的聚落设阵；同归白石镇的互传，最远三十公里，超距经镇中转；钱归法阵所在的村社；镇向村抽两成）。法律与公约两层先留位置，空着即按「无法之地」处理。
- 新增一种规矩只写设定，不改程序。

**12.4b 法阵分档方向（以后做）**

**出处**：亮圳 11-28 02:48 答复，李白转（主会话 TP 裁定记录末节）。正式设定里法阵分小、中、大三档，最高档能跨大洲传送。MVP 只做最低档（最远三十公里）；中、大两档留到 MVP 之后，届时只在法阵档的设定里加行、改本地规矩的最远距离与费率，不改程序（加一档只加数据）。

**12.5 MVP 的范围。**
- 一座镇子（白石镇）和它下辖的村落（河湾、榆坡、苇汀、砾泉、桑坂）。
- 多数村子有低阶法阵，彼此互通，按次付费。
- 砾泉村人数够但太穷，没有法阵，只能步行（亮圳 19:38「有些村子人数到了，但自己经济很差，没有传送证」）。
- 镇周边六处怪物社会自治，不归白石镇管，不设法阵。
- 全世界的法阵网、世界放大与九省重排在 MVP 之后做。
