# 12 语言、命名与度量

（2026-11-09 分册稿。依据：docs/产品原则.md；00 §3.13（M1–M5）、§3.16 Q2–Q3；01 §3.2 `lang`/`units`、§6.2、§6.4；13 §13.2；15 §15.3；附录 A §A.15"文书事实 language"。现状取证基准 F:/dnd-wt/SAT。只写设计，不改代码。所有数字是数据参数首版建议值。）

---

## 0. 一句话

语言是**行为者身上的一张熟练度表**（现有 `languages` 映射），文字是另一张（新 `scripts`），两张表决定能不能听懂、能不能读、要不要通译、翻译要多久；九省十二种语言之间有**可懂度矩阵**，所以"方言"和"外语"是同一条规则上的两个数值。命名是**文化记录里的构词规则**（人名、家名、地名、店名共用一套形状），由 population 与 remote-generation 读。度量衡与钱的显示单位是**视角投影**（15 §15.3），结算永远用规范单位；草原"以羊计价"是法典的法定单位，不是特判。

## 2. 概念模型

```
语言 lang:*  ──intelligibility──▶ 其他 lang:*（对称矩阵，0–1）
            ──script──▶ 文字 script:*（可空 = 无文字）
行为者 a.languages {lang: proficiency 0–300}；a.scripts {script: proficiency 0–300}（新）
文书/书 x.language, x.script（事实）
文化 c.lang {native, second[], script}（01 §3.2）──▶ 成员初值
文化 c.naming {person, family, place, shop}（构词规则）──▶ population / remote-generation
文化 c.units（显示）；法典 recognition.legalTender.unit（结算单位）；市场 value（兑换）
```

- 文化记录 `lang`（01 §3.2）：`native` 一种、`second[]` 0–2 种；成员初值 §4.1。

### 3.2 文字表（domain-rules.json 新键 `scripts`；domain-rules.mjs:77 `known` 集合加 `scripts`）

```json
  "script:kingdom": {"name": "王国字母", "kind": "alphabet", "learnMinutes": 2400, "literacyFamily": "family:craft/letters"},
  "script:zhonglu": {"name": "中陆方块字", "kind": "logographic", "learnMinutes": 9600, "literacyFamily": "family:craft/letters"},
  "script:wedge":   {"name": "楔刻符", "kind": "runic", "learnMinutes": 3600, "literacyFamily": "family:craft/letters", "medium": ["stone", "wood", "metal"]},
  "script:knot":    {"name": "系绳记", "kind": "tally", "learnMinutes": 1200, "literacyFamily": "family:craft/letters", "expressive": "numeric_only"}

```
- `kind`：影响学习时长与"能写什么"（`tally` 只能记数与归属，不能写信——写信前置失败给原因"系绳记不记言语"）。
- 识字 = `skill_literacy`（现有）× 该文字 `scripts[script] ≥ 100`；books.minimumLiteracy 100 改读两者之 min。`scripts` 熟练度是新的行为者字段，形状同 `languages`。

### 3.3 文化记录 `naming`（替换散文，world/lore/cultures.json）

```json
"naming": {
  "structure": "（保留原散文，叙述用）",
  "person": {"order": "family_first", "separator": "", "given": {"syllables": [1, 2], "phonemes": ["禾", "澄", "苇", "陶", "岑", "青", "砾", "简"]}, "family": {"source": "clan", "pool": ["禾", "苇", "陶", "岑", "曲", "罗"]}},
  "address": {"stranger": "{trade}师傅", "elder": "老{family}", "official": "{title}", "master": "{family}师傅", "kin": "{kinTerm}", "self": "我"},
  "place": {"settlement": ["{feature}{渡|集|坡|泉|坂|汀}"], "district": ["{direction}街", "{trade}巷"], "shop": ["{family}记{trade}", "{feature}{馆|铺|栈}"], "features": ["榆", "苇", "砾", "桑", "柳", "石"]},
  "household": {"source": "patronymic_surname"}
}
```
- `person.family.source` 枚举：`clan`（姓氏池）/ `place`（祖居地，如星湾"湾口"）/ `matrilineal_group`（母系帐名，草原）/ `trade`（工作名在前，寒炉）/ `nursery`（育苗地，林民）/ `pack`（养育群，兽裔）/ `tree_species`（木精：树种 + 天象）/ `none`。生成器按 source 取池：place 从所在郡地名池、matrilineal 从母亲家名、trade 从职业名。
- `address` 模板键供 dialogue 模板与叙述投影替换；`{kinTerm}` 读 kinship。
- `place` 构词：`{feature}` 从 features 池、`{direction}` 东西南北、`{trade}` 从街区 work；remote-generation 生成街区与店名时**读这里**而不是内置词库。
- population.mjs:174–180 的 `template.naming[culture:species]` → 改读 `cultures[culture].naming`，`species` 仅在 `naming.bySpecies` 覆盖时使用（怪物社会）。人口模板保留 `clans` 作**聚落级姓氏池覆盖**（河湾村只有那几姓）。

### 3.4 单位与法定计价（01 §3.2 `units`；法典 `recognition`）

```json
"units": {
  "mass":   {"name": "斤", "perCanonical": 0.5, "sub": {"name": "两", "per": 16}},
  "length": {"name": "尺", "perCanonical": 0.33, "sub": {"name": "寸", "per": 10}, "long": {"name": "里", "perCanonical": 500}},
  "volume": {"name": "斗", "perCanonical": 10, "sub": {"name": "升", "per": 10}},
  "area":   {"name": "亩", "perCanonical": 667},
  "time":   {"name": "时辰", "minutes": 120, "dayStart": "子正"},
  "money":  {"name": "文", "bundle": {"name": "贯", "per": 1000}}
}
```
- `perCanonical`：一个显示单位 = 多少规范单位（kg、m、L、m²）。校验 E-UNITS-POSITIVE。
- `money.name/bundle` 只影响铜钱数的**显示**（"三贯二百文" vs "三百二十枚"）。
- 法典：`recognition.legalTender = {"unit": "coin_civic" | "goods:sheep", "accepted": [...], "bulkUnit": {...}}`；`unit` 为非铸币时，价格显示为"X 只羊"，换算 = 市场 value（15 §15.2），**不是固定表**。
- 删 rules.currency `copperPerSilver/silverPerGold` 固定换算（15 §15.3 矛盾，00 I2）：铜银金三种铸币互为商品，比价由 market value；08 文档核 market.mjs 读哪个（本稿只记要求）。

### 3.5 对话模板目录（world/templates/dialogue/<culture>/plain/*.json）

## 4. 规则

### 4.1 语言初值、增长、衰减

```
初值（出生/生成/建档）：languages[native] = 300；∀ s ∈ second: 100；
   边境郡（01 §6.2）：cultureMix 第二文化的 native 另加 60
   scripts[culture.lang.script] = 识字者 300、非识字者 0（识字者比例读 education 现有）；无文字文化 → 空
增长（每日结算，读 practice.dailyCaps 的阶递减，阶 = floor(prof/100)，上限 300）：
   浸润：在母语为 L 的聚落停留一整日 → languages[L] += 2·max(0.3, intel(best known, L))   会近缘语学得快
   对话：每次与 L 母语者成功对话（dialogue/haggle/ask）→ +1
   教学：world_learn(entity = lang:L, source npc) → 现有 npcLessonGain（gain 40、teacherMargin 100）；语言是"知识"，走 learning.mjs 的 skill 分支（entity 前缀 `lang:` 新增到 learning 的 kind 判式 learning.mjs:62）
   书：语法/字书（book.teaches ∋ lang:L 或 script:S）→ 现有 book-gates
衰减：连续 360 日未使用（无浸润、对话、阅读）→ 每 30 日 −2，下限 100（不会忘到听不懂）
```

### 4.2 能不能听懂：有效熟练度与可懂度

```
effective(a, L) = max over K ∈ languages(a): languages(a)[K] · intel(K, L)       intel(L,L)=1
degree(a, b)    = max over L: min(effective(a, L), effective(b, L))               替换 obligation-runtime.mjs:93 的"同键取 min"
分档：degree ≥ 200 流利（无惩罚）；100–199 够用（议价与交涉检定 +2 难度；学艺 langGap 3）；50–99 勉强（+4；langGap 6；只能做 greet/haggle/简单 ask）；< 50 不通（"言语不通"，需通译或仿学）
通译：interpreter 现有分支（obligation-runtime.mjs:97）改用 effective；通译费 10 §4.5
```
- 这一条让"方言"成立：西陲人（river 300）到王都（common）：effective = 300·0.8 = 240 流利；到寒炉（forge）：300·0.4 = 120 够用；到风脊（steppe）：0 不通。草原人到中陆：300·0.1 = 30 不通。全部由表推出。

### 4.3 翻译与文书

```
读文书 x：需 effective(a, x.language) ≥ 100 ∧ scripts(a)[x.script] ≥ 100 ∧ skill_literacy ≥ books.minimumLiteracy
翻译动作 translate(x → L2)：译者满足读 x 且 effective(译者, L2) ≥ 200 ∧ scripts[script(L2)] ≥ 100；
   产出新文书实例（create，批次 `translationOf: x.id`，`fidelity = min(effective 两端)/300`）；用时 = x.length 字/（20 字/分钟 · fidelity）
   fidelity < 0.7 的译本：阅读所得知情条目 `truth` 可能降一档（half），按确定性骰值键 `translation:<x.id>`
口头通译同上，fidelity 只影响交涉检定难度（+ round((1−fidelity)·4)）
法庭与契约：契约 `language` 与当事人 effective < 100 → 效力 pending_ratification（附录 A §A.15 validity），须通译在场并记 `interpreter` 字段；这就是"外地人签了看不懂的契约"的真实后果
```

### 4.4 外来词（文化传播的语言面，接 11 §4.6）

```
loanword 运行态（存档内）：聚落 S 的主语言 L 对 goods g：当 g 由外语 L' 文化的商人/移民首次在 S 成交且 S 无本地 goods 同类 → 记录 {goods: g, from: L', since}
效果：叙述投影里该 goods 在 S 显示 L' 风格名（naming.loanStyle 的音译模板，如中陆对草原毡：帐毡→"毡"）；无规则效果
```

### 4.5 命名生成（人名、地名、店名）

```
person(culture, sex, household):
   given  = pick(phonemes, syllables)                                  骰值键 population 现有
   family = by source（§3.3）：clan→pool；place→郡地名池 features；matrilineal_group→母亲 family；trade→职业名；nursery→出生街区名；pack→户名；tree_species→树种+天象；none→无
   full   = order == family_first ? family+sep+given : given+sep+family
place(culture, terrain, role): 按 naming.place 模板 + features 池；同聚落内唯一性校验（现有 nameOk）
shop(culture, owner, trade): naming.place.shop 模板
```
- 远郡 remote-generation 街区名/店名**读文化 naming**（删内置词库）；现有 548 居民名不动。
- 玩家改名/化名：现有 purports 身份键；本稿不加。

### 4.6 度量与钱的显示（纯投影）

```
显示单位 = 观察者 culture(x).units（01 §4.1 派生文化）；法典 recognition.units 覆盖市场公告与契约文本
display(mass 1.2 kg, civic) = 1.2 / 0.5 = 2.4 斤 → "二斤六两"（sub 按 per 取整）
display(price 320 铜, civic) = "三百二十文"；bundle ≥ 1 → "一贯三百文"
display(price, steppe 法域)  = legalTender.unit == goods:sheep → value(铜)/value(羊) → "约一只半羊"（两位有效数字；不取整到只，因为羊可折半以货补）
结算：永远规范单位（kg、铜）；契约金额按签约时法定单位**快照**（15 §15.3），显示折算只用于玩家界面与叙述
```
- 落点：entity-view / 界面投影层（08 §8.x 投影），不进 engine 结算；market.mjs 不读 units。

## 5. 边界情况

1. **无文字文化的成员读书**：scripts 为空 → 读文书前置失败，原因"本族无文字，需人念诵"；可用口头通译把书念给他（translate 的口头分支，fidelity 同）。
2. **非声音通道**：嗅语对人类 effective = 0（人类物种无 scent 通道，13 §13.3 form 轴）→ 不是"不懂"而是"听不到"，文案不同；兽裔之间用嗅语不受 airModel.hearingRadius 限制而受 ventilation 限制。
3. **双语边境人**（01 §6.2）：second 加 60 → 第二语言 160 够用，这就是边境向导的价值。
4. **语言 0 但同圈**：aff 高不等于能交流（10 §5.7）。
5. **玩家建档**（14 文档）：native/second 按出身文化初值；可在建档加 1 种 second 至 100（背景选项）。
6. **怪物社会**：用现有语言不新增（§3.1）；炭阶灰窟人 lang:river 但 `naming` 自己一套（已在 cultures.json 散文里，转结构化）。
7. **死语/古文**：14 文档碑刻的 `language` 可为 `lang:old_kingdom` 之类**历史语言**：在表中登记、`speakers: none`、只能靠书学（无浸润）；intel 对后代语 0.5。首版 1 种 `lang:old_covenant`（复契期契约文，碑刻用）。
8. **固定换算删除后的旧存档**：存档里以铜记账（现有），不受影响；银币作为商品的 value 由市场给。若 08 核出 market 读 copperPerSilver，先保留作**市场初值**而非换算常数（标 `basis: initial_only`）。
