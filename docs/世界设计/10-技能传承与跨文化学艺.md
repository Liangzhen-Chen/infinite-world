## 0. 一句话

学艺是**通用规则**，不是"中式门派系统"或"西式行会系统"：任何技能都挂一个**技艺族**（`family:*`）上位词，任何教学关系都是现有持有 `mentor_of` 的一条条款快照，任何门派/行会/修会都是组织（faction）加一张**流派记录**（`school:*`）。一个用剑的西式战士走进中陆，遇到剑客，能学到的东西 = 剑客会教的 ∩ 同属 `family:blade` 的 ∩ 他的立场、语言、学费够得上的；学到的是**同一棵技能树上的技能**（不新开 id），只是称呼、起点、价钱、时间不同。师承有谱系、有秘传、有失传、有出师，全部由数据与事件派生。

## 2. 概念模型

```
技能 skill ──family──▶ 技艺族 family:*（上位词，ontology/tags.json）
                         │  同族可折算、可走共享路线
职业 profession ──archetype──▶ 自身 id（01 §3.5）；显示名由师承文化派生（01 §4.5）
流派 school:* ──teaches──▶ {family, stageCap, secrecy}   ──seat──▶ faction / 地点
师傅 m ──member_of──▶ school 的 faction；──mentor_of──▶ 学生 x（条款快照：school、culture、tier、tuition）
学生 x ──certified──▶ office（职业认证；颁发方 = school 的 faction）
```

四条原则：
1. **不开新技能 id。** 变体是称呼与起点（01 §4.5）；"西式剑术"与"中式剑术"是同一棵 `skill_swordsman_*` / `skill_warrior_*` 树，差别在族折算、流派修正项（09 文档）与叙述键。
2. **不写名单。** 哪些职业能互学、谁能教什么、哪里有师傅，全部由 `family`、`school.teaches`、师傅的持有与所在地推出。
3. **师承是持有，不是状态字段。** 拜师 = `holding.open(mentor_of)`；出师/逐出 = `holding.close(reason)`；谱系 = 持有链的历史回读（holdings 关闭后仍可回读）。
4. **秘传是规范，不是开关。** 门规是组织成员规范条目（05 §5.2.6）；泄密是违规事件，由规范栈判，不写 `if(secret)`。

## 3. 数据结构

### 3.1 技能加 `family`（world/meta/skills.json 每条新增必填）

```json
{"id": "skill_swordsman_combat_01", "name": "探步量距", "profession": "profession_swordsman", "stage": 0, "action": "aim",
 "family": "family:blade", "subfamily": "family:blade/footwork"}
```

- `family` 必填，`subfamily` 可选（更细的上位词，折算时用 §4.2 的两级比率）。
- 技艺族词表进 ontology/tags.json，`family` 族，`broader` 链：`family:blade/footwork → family:blade → family:melee → family:*`。
- 首版族表（覆盖 395 条技能的分配规则，按 `profession` + `combatAction.kind`/`action` 机械分配，开发者照表填）：

| family | 覆盖 | 分配规则 |
|---|---|---|
| `family:blade` | 剑、刀、短兵 | 职业 weapons 含 sword/dagger 且 action ∈ aim/strike/parry：swordsman 全 16、warrior 8（剑击与格挡）、spellblade 8、assassin 6 |
| `family:shield` | 持盾与阵列 | warrior 4、knight 4 |
| `family:mount` | 骑乘与冲锋 | knight 8（lance/charge） |
| `family:bow` | 弓弩 | archer 16 |
| `family:unarmed` | 拳脚与身法 | monk 10、assassin 4（潜行步法归 `family:stealth`，6） |
| `family:arcane` | 术式结构 | mage 15、spellblade 8、summoner 4 |
| `family:liturgy` | 祷告与仪轨 | priest 16、monk 6（度亡、戒律）、taoist 4（witness_oath 类） |
| `family:ward` | 符、咒、结界 | taoist 12、witch 6 |
| `family:spirit` | 通灵、出神、役灵 | witch 10、summoner 12 |
| `family:craft/*` | 生活技能 23 | 按 life 职业分：`craft/wood`、`craft/metal`、`craft/fiber`、`craft/food`、`craft/earth`、`craft/herb`、`craft/letters`（skill_literacy 归此） |
| `family:element/*` | skill_fire/water/earth/shadow/light/mind/summon/faith 等 31 条 | 按前缀 |
| `family:hidden/*` | 隐藏职业 30 + skill_s1–s4 119 条 | 按触发事迹类别；折算只在同 subfamily 内 |

加载校验 E-SKILL-FAMILY：每条技能 `family` 存在于 tags 且族为 family；缺字段加载失败（不补缺省）。

### 3.2 流派记录 world/lore/schools.json（新文件）

```json
{
  "$schema": "lore/schools@1",
  "entries": [
    {
      "id": "school:gate_sword",
      "name": "门内剑",
      "culture": "culture_civic",
      "faction": "faction_gate_sword_hall",
      "archetypes": ["profession_swordsman"],
      "teaches": [
        {"family": "family:blade", "stageCap": 5, "secrecy": {"0": "open", "1": "open", "2": "member", "3": "member", "4": "inner", "5": "lineage"}},
        {"family": "family:craft/letters", "stageCap": 1, "secrecy": {"0": "open", "1": "open"}}
      ],
      "admission": {"minStanding": 10, "trial": {"attribute": "敏捷", "skillFamily": "family:blade", "difficulty": 15}, "initiationFee": 30, "initiationMinutes": 60},
      "tuition": {"perLesson": "catalog", "markupByTier": {"open": 1.0, "member": 0.8, "inner": 0.5, "lineage": 0.0}, "annualDue": 60, "acceptsLabor": true, "laborHalfDaysPerCoin": 0.1},
      "rule": "不以门内剑伤已停手者；门内所授身法不得在市集演示售艺；对外只称本门名，不称师名。",
      "breaches": ["violence", "secret_disclosure", "unlicensed_teaching"],
      "lineage": {"parent": null, "founded": -121, "historyRef": "history_civic_07"},
      "graduation": {"skillsAtMargin": 3, "yearsMin": 2, "grantsCertification": true},
      "secrecyGate": {"member": {"standing": 20, "holding": "member_of"}, "inner": {"standing": 40, "holding": "mentor_of", "yearsMin": 2}, "lineage": {"standing": 60, "holding": "mentor_of", "yearsMin": 5, "mentorConsentEvent": true}},
      "outsiderOverride": null
    }
  ]
}
```

字段说明（每个字段都有读它的规则，见 §4）：
- `faction`：流派的组织实体（现有 factions 的 学派/学院/职业公会/修会/职业修会/教会 都可挂）；`member_of` 持有指向它。缺 faction 的流派不允许（流派必须能持有财产与成员）。→ §4.4
- `archetypes`：本流派为哪些职业颁认证（可多：止波师承教僧侣也教祭司）。→ §4.4
- `teaches[]`：按**族 + 阶**而不是按技能名单；`stageCap` 以上本流派不会（0–8，与 practice.stageSize 300 的阶一致）；`secrecy` 四档 open / member / inner / lineage。→ §4.3、§4.7
- `admission.trial`：拜师考核走现有 `engine.check`（rules.check difficulties）；`skillFamily` 取学生该族最高熟练度作检定技能。→ §4.4
- `tuition`：`perLesson: "catalog"` 读技能/配方的 `learnFee`；`markupByTier` 乘档位；`annualDue` 年例（周期义务）；`acceptsLabor` 允许以工代费。→ §4.5
- `rule`/`breaches`：形状同现有 rules.training.institutions[].rule/breaches（training.mjs:40–55 直接复用），**training.institutions 三元组改由本记录派生**（§4.4、§7 M2）。
- `graduation`：出师条件。→ §4.6
- `secrecyGate`：各档位的门槛；`yearsMin` 自 mentor_of 开立起算。→ §4.3
- `outsiderOverride`：null 则读文化 `outsider`（01 §3.2）；流派可更严或更宽（如镜沼验阵学派对外开放 open）。

### 3.3 师承持有的条款快照（holdings `mentor_of` 的 `terms`）

```json
{"kind": "mentor_of", "holder": "npc_zl_sword_master", "subject": "player", "openedAt": 1234567, "writer": "learning",
 "terms": {"school": "school:gate_sword", "mentorCulture": "culture_civic", "tier": "member", "tierSince": 1234567,
           "tuition": {"mode": "coins|labor", "perLessonMul": 0.8}, "lineageDepth": 3, "lineageRoot": "npc_hist_founder_or_null"}}
```

- `tier` 升档是**事件**（师傅同意 + 门槛满足），写回 terms（持有条款可修订，01 §1.3）。
- `lineageDepth` = 师傅自己 mentor_of（作为 subject）链长 + 1，开立时计算并快照；谱系查询回读持有历史。
- 一个人可同时有多条 mentor_of（学木工又学剑），但 **同一 archetype 的战斗流派只能一条在开**（training.mjs:46 现有"不能另拜战斗师门"的持有版）。

### 3.4 职业认证 `certified` 的颁发方

现有 `certified` 的 subject 是 office；本稿定：每个 school 的 faction 拥有一个 office `office:cert:<school>`（office-succession.json 形状，05 §5.2），认证 = `certified(agent → office:cert:school:gate_sword)`。他法域效力按现有 `recognition.certifications`（holdings.json certified.note）；首版规则：**同圈互认，跨圈需本地流派复核**（一次 trial 检定，免费）。

### 3.5 删除/替换的现有数据

- `professions[].entry.location`（01 §3.5 M4）与 `trainingInstitutions` 删；`rules.training.institutions` 6 条**转写**为 schools.json 6 条（§7 M2 给逐条映射）。
- `skill.learningProfessions` 名单删，改 §4.2 派生；保留 `prerequisites`。

## 4. 规则（公式与判定顺序）

### 4.1 能不能学：资格与门槛（判定顺序）

对 `world_learn(entity, source=npc m)`，学生 x：

```
1. 师傅会不会：personTeaching(m, entity) 现有（entity-view.mjs:127）
   ∨ m 的 school.teaches 含 family(entity) 且 stage(entity) ≤ stageCap            ← 新增一支
2. 秘传档位：tier(x, m) ≥ secrecy[family][stage]（§4.3）；不足 → 拒绝 E-ACTION-SECRECY，给原因与修复："先入门/先取得师傅信任/本门不外传"
3. 师傅愿不愿（01 §4.7）：standing(m, x) ≥ outsider.teachStanding·(1 − aff) + secrecyStanding(tier)        secrecyStanding = secrecyGate[tier].standing
4. 语言（§4.2 的 langMode）：无共同语言且不是身体类族 → 拒绝 "言语不通，请先找通译"（dialogue.mjs:63 同文案）；身体类族允许"仿学"
5. 阶与前置：learning.mjs:66–91 现有（prerequisites、stage>0 需认证或共享路线 §4.2）
6. 学费与时间（§4.5）
7. 检定与增益：现有 check（难度 §4.2）与 npcLessonGain
```

所有拒绝都带世界内原因与 `repair`（06 §6.7 第 7 条），不出现"不支持"。

### 4.2 学什么起点、多难：技艺族折算 + 01 §5 难度

```
transfer(x, entity) = max over s ∈ skills(x) with family(s)=family(entity):
                        prof(x, s) · r(s, entity)
   r = 0.6  同 subfamily（如 blade/footwork ↔ blade/footwork）
     = 0.4  同 family 不同 subfamily
     = 0.2  同上位 family（melee）                       ← 只到一级
     = 0    其他
初始熟练度(x, entity) = min(transfer, (stage(entity)+1)·300 − 1)      学第一次时写入；已有记录不动
共享路线（替代 learningProfessions）：stage>0 且 x 未持 entity 所属职业认证时，
   允许 ⇔ ∃ 职业 p 已认证，p 的 entry.skill 与 entity 同 family，且 prof(x, p.entry.skill) ≥ stage·300   （learning.mjs:88–91 现有判式，只换来源）
难度 = base(=catalog.difficulty ?? check.difficulties.普通 15)
     + langGap   (prof(x, lang(m)) ≥ 100 ? 0 : ≥ 50 ? 3 : 6)              01 §5
     + affinityGap round((1 − aff)·5)
     + variantSwitch (x 已有同 archetype 他文化认证 ? 2 : 0)
     + familyJump   (transfer == 0 ? 0 : 同 subfamily ? −2 : 0)            会相近东西的人学得顺
学时倍率 = (1 + (1 − aff)) · langTimeMul      langTimeMul = 仿学 2.0 / 通译在场 1.3 / 共同语言 1.0
```

- `langMode`：共同语言（obligationCommunication degree ≥ 50，obligation-runtime.mjs:93）→ normal；有通译（同函数 `interpreter` 参数，通译收费 §4.5）→ interpreted；无 → 仅 `family:blade/shield/mount/bow/unarmed/craft/*` 等**身体类族**（族词表 `bodily: true`）可"仿学"，`gain × 0.5`；`arcane/liturgy/ward/spirit/craft/letters` 不可。
- 例（亮圳的例子）：西式战士 x（skill_warrior_combat_03"盾后直刺"family:blade/strike 400、lang:common 100、lang:zhonglu 0）到东陆志怪圈的剑客师傅 m（school:gate_sword）处。学 skill_swordsman_combat_01（blade/footwork，stage 0）：transfer = 400·0.4 = 160 → 起点 160（上限 299）；难度 = 15 + 6（无当地话；但 m 若有 lang:common ≥ 50 → langGap 用**双方最佳共同语**，= 0）+ round((1−aff)·5) + 0 + 0；学时 120·(1+(1−aff))。aff 由 01 §3.1 亲和表推导，**不写死**：按 01 首版表 x 所属圈（marches 或 western）对 eastern 为 .7/.3 → 难度 17 或 19、学时 156 或 204 分钟。可见"会不会说官话"与"两圈远近"都比"是不是中国人"影响大——这是对的。
- 【待定·亮圳】师傅所在地（01 问题①；主会话推荐：中陆作东陆核心，待核定）：取向 A（推荐）上例发生在王畿（culture_civic）；取向 B（东陆只放镜沼＋雾杉）则 school:gate_sword 挂 culture_reed 或 culture_mist，上例发生在芦语渡或杉根。公式与数字不变，只换 school.culture 字段。

### 4.3 秘传档位 tier(x, m)

```
tier(x, m) = max t ∈ {open, member, inner, lineage} 使得：
   open    恒成立
   member  x 持 member_of(school.faction) ∧ standing(m,x) ≥ gate.member.standing
   inner   x 持 mentor_of(m→x) ∧ years(mentor_of) ≥ gate.inner.yearsMin ∧ standing ≥ gate.inner.standing
   lineage inner 全部 ∧ years ≥ gate.lineage.yearsMin ∧ 存在事件 mentor_consent(m, x, "lineage")（师傅的同意事件，A1b：只来自本人）
```
- 升档不自动发生；学生请求（动作 `learn.request_tier`）→ 师傅按 npcDecision 答（dialogue.mjs 的 request 分支）→ 同意写事件并改 terms.tier。
- **外人**（culture(x) ≠ school.culture）不改公式；只是 standing 门槛被 01 §4.7 的 `(1 − aff)·standingPenalty` 拉低了起点，要多花人情（§4.5）。`outsider.policy = closed` 的文化：`lineage` 档对外人**永不**开放（数据里 `secrecyGate.lineage.requiresCulture: true`），这是唯一的硬门，而且是数据。

### 4.4 师傅在哪：技艺的地区分布（K4）

```
teachersAt(settlement, family, stage) = { m ∈ residents(settlement) :
     personTeaching(m, 任一 entity of family/stage)                    现有：职业服务、工位配方
   ∨ (m member_of f ∧ school(f).teaches ∋ (family, stage)) }
hasSchool(settlement, school) = school.faction 的 seat 在该聚落 ∨ 任一 member_of 居民在该聚落
```
- 远郡物化（remote-generation.mjs）新增"流派与师傅"步：对聚落 S、每个文化 c（share ≥ 0.15）：
  `n_school(c) = Σ_{school ∈ cultures[c].combat.schools} [pop·share ≥ school.minPop]`（`minPop` 进 schools.json，首版 剑/武馆 800、符箓学派 1500、修会 2000、工匠行会 400）；每个落地的 school 生成 1 位师傅（职业 = archetypes[0]，熟练度 = 600 + 200·stageCap 上限 1200 = npcGrowth.maximumProficiency）与 2–4 名 member_of 弟子，驻地建筑用 13 文档的 `hall` 模板；生活技艺的师傅由现有按 industry 生成 work 的街区师傅承担（personTeaching 工位分支已覆盖）。
- `rules.training.institutions` 三元组 → **派生**：`(seat(school), archetype, m)` 对任一 m 持 member_of 且 role 含 archetype 且 prof ≥ 认证下限（professions.entry.minimumProficiency 100 + teacherMargin 100）成立。training.mjs:18 的 find 改为读此派生表（§7 M2）。
- 结论：走到九省任何一处，"这里能学什么"= 这里住着谁；没有师傅就真的学不到，要么去远方，要么带书，要么请人来（迁徙，11 文档）。

### 4.5 学费与人情

```
lessonFee(x, m, entity) = catalog.learnFee(缺省 12) · tuition.markupByTier[tier] · (1 + (1 − aff)·outsider.markup)      进现有 fee 位（learning.mjs:102）
以工代费：tuition.acceptsLabor → fee 可改为义务 obligation.create(kind:"tuition_labor", debtor:x, creditor:m, amount: ceil(fee·laborHalfDaysPerCoin) 个半日工, deadline: +30 日)；
          履行 = x 在 school 驻地做 npcLabor 半日（现有 labor-market 工时），每半日 settle 1
年例：member_of 开立时创建周期义务 obligation(kind:"annual_due", amount: tuition.annualDue, period: 360 日)；逾期 → 规范栈 breach "dues_unpaid" → 成员规范处分（停课 = tier 降 open）
人情（礼物）：transfer(x→m, item 带 goods:gift 或 m 文化 cuisine.hospitality.offer 的物) → standing(m,x) += min(value/10, 5)/次，7 日衰减（06 §6.7 重复衰减现有）；不是贿赂（无职务对价），不入 bribery
```

### 4.6 学成判定与出师

- 单课学成：现有（learnMinutes 累计 + check）。
- **熟练度天花板**：现有 `teacher − teacherMargin(100)`；外人不加额外天花板（不写"外人学不精"的特判——真实世界里学不精是因为教得少，那由 tier 与 standing 表达）。
- **出师 graduation**：条件 `|{s ∈ school.teaches 族内技能 : prof(x,s) ≥ prof(m,s) − teacherMargin}| ≥ graduation.skillsAtMargin ∧ years(mentor_of) ≥ yearsMin` → 学生可请求出师（动作 `learn.graduate`）→ 师傅同意事件 → `holding.close(mentor_of, reason:"graduated")` + 若 `grantsCertification` 则 `holding.open(certified → office:cert:school)`；出师者可自己收徒（他成为 member_of 且 role 含 archetype，§4.4 派生自动成立）。
- **逐出**：school.breaches 命中 → 规范栏处分 → `holding.close(mentor_of, reason:"expelled")`，认证不撤（学过的不会忘），但 `member_of` 关闭 → 以后 tier 只到 open。
- 玩家与 NPC 同一套（training.mjs 现有只对玩家；NPC 自治走同管线，AUDIT3 06-18 的依赖）。

### 4.7 失传、秘传、独门

```
holders(entity) = |{a : knowsKnowledge(a, entity)}|（现有 npc-growth.mjs:67 知识判式）+ 书本 book.teaches ∋ entity 的在世物品实例数
status(entity) = holders == 0            → lost（失传）
              = holders ≤ rareThreshold(3) ∧ 全部 holders 同一 school → unique（独门）
              = 全部 holders 的 school.secrecy[stage] ≥ inner → secret（秘传）
              = 其他 → common
```
- `status` 是派生，不落盘；进知情层（传闻："据说只有雾岭崖居人还会…"由 14 文档的传闻派生读它）与市场（独门配方产物 `demandWeight` 的稀缺乘子，15 §15.2 的供给侧，首版 ×1.5）。
- **失传风险事件**：holders 中最后一位 NPC 年龄 ≥ npcLife.elderAge(60) 且无 mentor_of 弟子 → 时钟规则每 90 日发 `lineage_at_risk` 事件 → NPC 自治候选"收徒"（autonomy 登记）+ 传闻种子；死亡后 → `lost`，只能靠**研究**（learning.mjs:94 项目路径现有）或**古籍**（14 文档碑刻/旧书）复原，研究难度 = 技能阶×5 + 20。
- 独门的来由不写剧情：首版数据让某些族只有一个流派教到高阶（§6 实例表的 `stageCap` 分布自然造成），"去远方学艺"的理由由此产生。

### 4.8 相近技能映射的"反向"：他乡的人看你

显示名走 01 §4.5（`archetypeNames`）。补一条：**旁观者**按**自己文化**的 archetypeNames 称呼你（王畿人叫西式战士"武夫"，他自称"战士"），叙述键 `observerCulture`；这只是叙述投影，无规则效果。

## 5. 边界情况

1. **师傅是玩家**（npc-growth.mjs:70 `teachNpc` 现有）：玩家没有 school → tier 永为 open、无秘传；玩家可**创派**：组织创建（05 现有 faction 创建）+ 新 school 记录作为**运行态**（存档内，形状同 §3.2，`source:"player"`），`teaches` 只能列玩家已认证 archetype 的族，`stageCap` ≤ 玩家各族最高阶。这是寒潭剑宗示例包（12 §12.7）的无包版本。
2. **跨物种**：兽裔学人类剑术——无文化特判；`family:blade` 要求 `anatomy.hands`（13 §13.3 物种 schema 现有 form 轴）→ 蛇形生灵拒绝并给原因。npc-growth.mjs:105–110 现有跨物种授业检定保留。
3. **流派驻地被毁/组织解散**（12 §12.8.4 墓碑）：school 退役 → 既有 mentor_of/certified 不关（历史事实），tier 冻结在当前值，不能再升；认证在他法域仍按 recognition。
4. **师傅迁居**：mentor_of 不随地点关闭；但授课要求在场（learning.mjs:97）→ 学生要跟着走或等；年例照收，逾期停课——这就是"追随师傅游历"。
5. **同族两套认证**（剑客改学骑士式）：variantSwitch +2；战斗职业认证只能一门在职（现有），第二门只能学到 stage ≤ 共享路线允许的阶，不能认证，除非放弃原职（现有 switchCooldownDays 30）。
6. **无文字文化**（兽裔、木精，12 文档 `script: null`）：书本来源对其成员不可用（识字前置失败并给原因"本族无文字"），只能师徒与仿学；这类文化的 `craft/letters` 族师傅不生成。
7. **语言 0 但同圈**：aff 高不等于能交流；langGap 独立计（§4.2），仿学规则适用。
8. **怪物社会**（culture_ms_*）：它们的 school 记录按同一形状（首版各 1 个，如苔灯坞狐族"尾结藏形"教 `family:stealth` stageCap 3，secrecy member 起——外人要先成为 member_of，而它们 `outsider.policy closed` → lineage 永不开放）。
