## 二、甲级（7 条，全文）

1. 菜单路由在生产代码里没有处理函数（03d #1）
   - 位置：server-plugin/kernel/transport/menu-entry.mjs:19、:27-31、:43-48；server-plugin/index.mjs:31。
   - 设计原文：menu-entry.mjs:4 自述"处理函数由规则层与各卡经 installMenuDispatch 交入一次"。
   - 代码实际：installMenuDispatch 全仓无调用者（我抽查属实），一切菜单请求回 E-ACT-WRITER-NOT-READY。
   - 理由：无（docs/卡回报/ds-b6-19.md:41、ds-b6-20.md:51 只记排期，不是裁定或问题.md）。
   - 影响：玩家菜单入口不通。
2. 实例与批次的 material 偏离、品质乘子不进读数（04c #1）
   - 位置：server-plugin/kernel/item-state.mjs:210-214（aggregated）、:415-418、:352-355、:575-605。
   - 代码实际：一律按模板聚合；item.mjs:690 的 aggregateMaterialFor 专供实例与批次偏离，本文件没调用（我抽查 aggregated 只调 materialView 模板口径，属实）。
   - 理由：无。影响：同一模板的实例，换了材料或品质，读数不变。
3. faultChanceMult 叠加方式写成 none（04f #7）
   - 位置：world/ontology/dimensions/item.json:40（我抽查属实）。设计原文：卷三乙 :174 写 stacking mul，:1339 写"可修正维度，基值 1"。
   - 代码实际：modifiable true 而 stacking none，品质、取向、附件对故障概率的修正叠不上。理由：无。
4. 区域足迹代表格只按区域归属行筛，没核 zoneAt 恰为 place（06a #1，06e #2 同）
   - 位置：server-plugin/kernel/place.mjs:445，实现在 kernel/footprint.mjs:691-701（判据 :695-696）。
   - 理由：无（问题.md:644 只说展开落格那一支不加这个筛选，不是这一支）。影响：落在别的体积或建筑里的格会被当成本地点的代表格。
