# 季节迁徙实现与未完成项

依据指南3.8.3和第13章阶段2。当前源仅启用褐背短鹿、弯角野山羊在北林与南田之间的四条原创路线。冬季第270日出发、春季第0日回迁，冬季比例40%与50%，返程100%、行程一天，均为D029开发初值，指南未指定。路线使用登记的步行道路，经聚落地理节点连接两处野地，不代表动物必然穿过村内建筑。具体沿途位置与风险尚未模拟。

次生栖地初始未见种群为零，不从物种目录生成新的基数。出发扣源地未见种群，迁出总数记账；到达再计入目的地和迁入总数。两地之外的在途行程单独持久化，到达前不能追踪其中动物。目的地按同种容量、已有实际动物及在途预留容量限流，出生也扣除该预留；道路在出发季节封闭就不发车。当前不模拟途中天气改道、危险损失、逐段路程或临时停靠。

普通已接触的无主活体可随群迁徙，保留实际creatures编号、生命和战术记忆；途中location为null，由私有migration行程表示，抵达写新地点和生态标签，不复制个体。宠物、尸体、首领和巢穴个体不参加普通种群路线。迁入前因已有照料规则死亡则记lost，不复活也不重新放入未见种群。旧照料规则尚把已喂过的无主野兽按照料时钟计饥饿，完整自然觅食与离屏决策待阶段4；本轮只保证照料与迁徙按时间先后交错。途中死亡尸体没有可到访的沿途地点，不能采集，仍需完整路段系统。

迁移保留既有生态初始化日期、日结与各项生死计数，只补迁入/迁出零计数及次生栖地，私有迁徙账从存档当前日期开始；不补历史、不改变已有玩家财物或记忆。类别wildlifeMigration不向公开记录工具透露。独立CLI新增--world配套归档，输出必须为不存在的新副本，拒绝密钥路径和版本不符。移除迁徙规则之前需处理仍在途的行程，本轮未提供取消规则的迁移方案。
