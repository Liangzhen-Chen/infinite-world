# 审卷须知（各卷审查员共用；模型 claude-opus-5-5，中档）

## 红线
- 本机只允许三类操作：静态读文件（Read、Grep、Glob、cat、sed -n）、git/gh 只读命令、用 Write 写审查文件。
- 禁止：node -e、python -c、把 heredoc 喂给解释器、运行任何脚本或测试、读密钥、提交 git。

## 轮次规矩（亮圳定）
- 每卷最多审两轮。
- **第一轮**：把全部真问题一次列全，第二轮不再接受新发现。所以第一轮要审彻底。
- **第二轮**：只核对第一轮列出的问题有没有改好，以及改动有没有引出新的矛盾。
- 措辞类小项写进“小项”一栏，只记账，不要求返工。

## 真问题（只算以下几类）
1. 缺维度：子系统需要的维度没有定义，或者没有指明出处。
2. 写死：规则里出现具体 id，或者为具体物品、神、地区、职业单独写规则，或者常数不放在规则表里。
3. 读自然语言判断：规则层用文字匹配、正则、文字字面量来决定逻辑。
4. 系统间接口对不上：与《全书概念台账》的归属冲突；本卷重写了别卷定义的概念；引用的卷、节、入口不存在。
5. 自相矛盾。
6. 不确定：同一个种子不能复现，或者读了墙钟。
7. 机制性漏洞：断言不能交给机器判定，或者存在整类绕过办法。
8. 模板缺节：§0–§8 有缺；子系统的六小节有缺；数据实例里缺“非西陲”或“非人类、超自然”的例子；三类断言（扫描式、不变量式、扩展性式）有缺。
9. 违背北极星：本该由材料属性、职业技能、意图三者共同推出的产物，没有这样推。

## 必读
- 被审的卷，整卷读完。
- 《全书概念台账》中本卷相关的行，以及第五节。
- 本卷素材包，用来抽查 §1 的现状描述和 §7 迁移清单是否完整，至少抽查 5 处 file:line。
- 卷一、卷二只读本卷引用到的章节，核对这些章节是否存在、说法是否一致。注意：卷一、卷二正在做收口前的最后一次修改，章节号对不上时，只按标题和内容判断，章节号问题记为小项。

## 产出
- 写到 `审查/卷X-一审A.md`，或 `一审B.md`，或 `二审A.md`、`二审B.md`。
- 每条真问题写明：位置（行号）、类别（填上面 1–9 的编号）、证据、建议改法。
- 小项单独列一栏。
- 回报不超过 100 字：真问题条数，以及最重要的 3 条。
