## 一、总判

- **五种情况的实物账守恒**（开局、换料、翻修、拆除、损毁，另含燃烧和补缺）：卷十九 §4.1 规则 11 的表（L353–370），以及 A19-1.2、A19-4.2、A19-16.2 三条断言，逐行都闭合了：`laid − taken − lost = materialKg`。拆除和损毁把 `materialKg` 减到 0，取出的记 taken，其余记 lost；翻修先按拆除记、再按新建记；燃烧只记 lost；精度都是 precision 4 下的整数加减，没有出现残差。**没有闭合的另有三条路径**：承载物终止、远方地点物化、扩建。见真问题 4、5、6。
- **卷六还有没有自己推算实物量**：正文（L1–1833）已经没有 `materialKg`、`stationUse`、`stationMinutes`、出墙量、损失累计这些字眼，残留只在历史附录和 Q18 一行（见小项 1）。§4.18 的重置成本读的是需求块，不读实物账，这不属于重拆的范围（见小项 4）。
- **同一个量是否在两卷各定义一次（双写）**：存储层面没有双写，墙料只有 `wallFlowKg` 一份，工位占用分钟只有 `stationMinutesToday` 一份。规则层面有双写：两卷都写了“明细怎么入账”。见真问题 7。
- **脚本**：两个脚本删掉的必含短语，确实只针对已删的段落；保留下来的判据没有一条被放宽（10 N5 反而收紧了，7.5 的“不再只写不超过”仍在查）。但是新写入的内容一条正向检查也没有补，有一条否定检查也查不住第五版的写法。见第四节。

## 三、真问题（11 条）

### 1. 瞬时负荷让“拥挤靠价格疏导”失效（类 5、9）
- 位置：卷六 §4.10 规则 1（L728）、规则 4（L731）、§4.10.5 铁匠炉一例（L743）、A6-10.2（L750）、§2.3 `stationLoad(facility)` 一行。
- 证据：
  - 工费是在“作业开工时”收取的（§4.10.2）。单席的铁匠炉，作业能开工就说明席位空着，求值那一刻负荷要么恒为 0（自己的席位不计），要么恒为 1（计入自己的席位）。“冬前活计集中，负荷升高，工费上涨”在这个式子下根本出不来。
  - 排队的作业（规则 5）不计入负荷。
  - 分母是整栋建筑各固定装置的席数之和。一栋有十台织机、一座炉子的作坊，炉子再满，负荷也只有 1/11。第五版按服务分格，第六版删掉服务这一参数后，这一层区分就没了，而且这次改签名没有写理由。
- 建议：负荷要回到“一段时间内的使用量”，并能按服务过滤。可以二选一：
  - (a) 卷十九把日计数改成“按装置、按日、只保留最近 `loadWindowDays` 日”的短期留存（一份存储，同时供卷十九算利用率、积尘和卷六算负荷，卷六仍然只读）；卷六按 `occupancy[].fixture` 所属服务过滤。
  - (b) 保留瞬时口径，但分子加上同一服务的排队数，分母只算提供该服务的席位。
  
  (a) 要改存储，须先报李白。

### 2. `occupancy` 只列未到期的边，没有满足裁定④的“逐条可查（含起止日）”（类 4）
- 位置：卷十九 §2.1 `occupancy` 行（L133）、§4.3 规则 4（L445–449）、第九版修订记录第一节。
- 证据：视图写的是“此刻未到期的工位占用持有边”，而边释放后就不存在了，所以已经结束的占用查不到。作者用日计数补了日结的需要（自报①），并把卷六改成瞬时负荷（自报③），两处都是从这个读法推出来的。
- 附带问题：日计数的正确性依赖“日结先于次日的任何释放与到期”（L447）。可是 §3.3 写了“一次推进多天”（L333），L374 又写“离屏时逐日结算可折叠为闭式”。单个计数器没办法折叠成闭式：补结时，前几日已经释放的边，算出来的分钟数会落到错误的日子上。
- 建议：请李白确认④的本意。如果④要求能查到已结束的占用，就采用真问题 1 的建议 (a)，以短期逐日留存替代单个计数器，并在 §3.3 写明补结时按事件时间逐日交错处理。如果④只要求查当前，就在第九版修订记录里写明这一解读，并在 L374 说明这个计数器不参与闭式折叠。

### 3. 原地翻修的资产处置与“先拆再建”自相矛盾，留下绕过口（类 5、7）
- 位置：卷六 §4.1 规则 5“原地翻修先拆再建”（L353 前后）、“取出的料记入”（换料与原地翻修记给施工出资方）；卷十九 §4.4 规则 3（L483）、§4.1 规则 7。
- 证据：
  - 拆除时，散料按拆除前的份额分给各持有人。翻修时，旧分录全部 `sink_loss`，散料和新的一万基点又都归出资方。
  - 设施有 A 持 60%、B 持 40% 两个持有人时，A（只要对它有处分权，L482）独资翻修，B 的份额和他那份旧料就一并被抹掉，B 没有任何补偿。
  - 租约的出租人原本是旧持有人。行不终止，租住权边原地不动，可出租人的份额已经被注销了。
- 建议：翻修的资产与散料完全照“拆除”一行处理，即旧分录 `sink_loss`、散料按旧份额分给原持有人，再照“新建”一行把新分录记给出资方。或者照 §4.7 规则 11 扩建的写法，要求翻修的出资方只能是现有持有人，份额不变。两种都只需改卷六一处，卷十九 L483 末句引用即可。

### 4. 承载物终止这条路径没有进实物账，也没有进资产账（类 5、4）
- 位置：卷十九 §4.10 规则 8（L731–735）、§4.1 规则 11 的表；卷六 §4.1 规则 5“拆除”“毁损”两点、A6-1.2。
- 证据：
  - 可移动建筑因为 `carrierItem` 终止而终止，走的是第三种终止起因（A19-16.2 自己列了三种）。可是规则 11 的表只有“拆除”“损毁”两行会把 `materialKg` 减到 0、交出明细。§4.10 规则 8 只写了“行上的东西照终止协议”，没有写墙料怎么处理。
  - 这样 A19-1.2 的“已终止的建筑行 `materialKg` 各料为 0”就不成立了。
  - 卷六只对“拆除或毁损”记资产 `sink_loss`，这类设施终止之后，资产份额会永远留在持有人名下，A6-1.2 的“已拆除或毁损的为零”也覆盖不到它。
- 建议：规则 11 的表加一行“承载物终止”，记法同“损毁”（取出量用 `salvageFraction`，或者明确写全部记损失）；§4.10 规则 8 引用这一行；卷六的“毁损”一点改成“凡设施行终止”，A6-1.2 同步改。

### 5. 远方地点物化（第 0 日之后建行）不在规则 11 的表里（类 4、5）
- 位置：卷十九 L245、L216（“卷十的写回器……世界生成与远方地点物化”）、§4.4 规则 9（L503）、规则 11 的表；卷五 L450；卷六 §4.22 规则 3（L1231）、A6-1.2（“只有开局建行的砌入没有物品腿”）。
- 证据：
  - 物化时的建行既不是“开局（第 0 日）”，也不是“运行期建成（备料账户出账）”。这次砌入没有出料的账户，卷六没法照“砌入的料记出”记腿，A6-1.2 那句“只有开局”就被打破了。
  - 资产分录也一样：第 0 日之后不准用 `src_genesis`；§4.22 规则 3 说物化是“从阶层聚合账户转移”，可资产的键是设施实例，聚合账户里事先不可能持有尚不存在的实例的份额。
- 建议：二选一。(a) 明确全部建筑行在第 0 日就由写回器建好，物化只物化人口；(b) 在规则 11 的表里加“物化建行”一行，并在卷六写明它的物品腿和资产腿怎么记（比如聚合账户在第 0 日持有“未物化建筑份额”这一资源，物化时转换成实例份额）。这件事牵涉卷十，须报李白。

### 6. 卷六的“扩建”在卷十九没有对应的事由（类 4、5）
- 位置：卷六 §4.1 规则 5（L349“新建、补缺、换料、扩建、原地翻修时砌进墙里的料”）、§4.7 规则 11（L625）、A6-19.2；卷十九 §4.1 规则 11 的表、§4.4（全卷 Grep“扩建”只有 L513 一处数据实例）。
- 证据：卷六要求扩建按卷十九的明细记砌入，而且份额不变；卷十九却没有扩建的入口，也没有扩建的明细行。如果扩建实际上要走 `replaces` 原地翻修（改形制唯一的路），卷六又会照翻修把旧份额注销、另发新份额，正好与 L625“扩建不产生新的资产分录、只许现有持有人出资”相反。
- 建议：卷十九明确扩建是什么，是加装固定装置（不碰墙料），还是带 `replaces` 的翻修，或者另设一个入口，并补进规则 11 的表；卷六按卷十九的定义改写 L349 和 L625。

### 7. 两卷互相改写对方的入账规则（双写）（类 4）

### 8. 原地翻修没有处理房间行（类 5）
- 位置：卷十九 §4.4 规则 3（L483）：“先照拆除……不走终止协议，房间行不动；再照规则 6……改写 `form`……”。
- 证据：房间行由建行函数按形制的布局生成，而“一座建筑只建行一次”（L248）。翻修换了形制，旧形制的房间行却原样留下，新形制的房间行也没有生成路径，分区和面积就与新的 `form` 不一致了。
- 建议：写明翻修时房间行怎么办：按新形制的布局，与旧房间按某个确定规则对应，多出的照 §4.16 规则 4 先终止、后继为建筑行，缺的由建行用的同一个纯函数补建；或者规定翻修只许换成布局相同的形制。

### 9. A19-10.2 的新句与同一条断言的前半句矛盾（类 5）

- 建议：把这句改为“与原落脚地及其下地点行之间的地点边计数为 0”。

### 10. A19-1.2 的“任一建筑 `material` 份额和为 1”与新写入的内容冲突（类 5）

- 建议：改成“各料质量之和大于 0 的建筑 `material` 份额和为 1，总质量为 0 的 `material` 为空”。

### 11. 卷六替卷三乙规定了批次的生命周期（类 4）
