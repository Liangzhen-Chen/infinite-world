# 卷三 补维度牵连清单（别卷要跟改的地方）

依据：`卷三-物品与材料.md` 第五版（快照 `版本快照/卷三-v5.md`），按李白 11-13 对 `卷三-推不出类别清单.md` 的裁定补了三样东西：

- 材料表新增 `decomposePoint`（分解点）；常温物态的判法改为"没有熔点或分解点低于熔点时按分解点判"；`meltPoint` 与 `decomposePoint` 至少填一个（卷三 T-2、M-11）。
- 聚集形态 `bulkForm` 归物品模板，不归材料；`bulkform` 族四个固定代号；成形固体类 `class_formed`、粉料类 `class_powder` 在物品一侧由"常温物态加形态"推出；承力四项（强度、锋利上限、耐磨、防护系数）的必填条件从"材料是固体类"改为"物品具有成形固体类时对其结构组材料必填"（卷三 I-7、I-8、C-8）。
- 材料大类分成分大类与派生大类；新增派生大类"炭质"，由 `rules.materials.matcatRules` 按阈值推出；"矿物粉料"大类改名"矿物"（卷三 M-9）。

扫描范围：`docs/统一底层设计/` 下除卷三外的 14 份"卷*.md"。扫描脚本 `F:/dnd-tmp/vols/scan-卷三-补维度.mjs`，结果在同目录的 `.out.txt`。本清单只列建议的改法，别卷一字未动。行号是 11-13 当天的行号。

任务里点名的卷四、卷六、卷十九，现稿里都没有直接写到聚集形态或粉料类，牵连是间接的，分别列在第二节。
