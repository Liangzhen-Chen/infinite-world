## 三、误报逐条（原因类代号）

原因类：
- **代**＝旧代码或代码标识符、错误码（`normalize*`、`E-…-UNNORMALIZED`、`window / document`）
- **斜**＝散文、枚举里的 `/` 分隔（`a / b / c`、`V-23 / V-24`）
- **切**＝"除以"误切词（删除以外、移除以）
- **词**＝"归一""比例""份额"不是除法（归一相位、所归一方、不归一、归一点、比例是曲线输出）
- **均**＝分布参数"均值"（物种均值、群体均值、均值取文化缺省）
- **测**＝验收、不变量、测试、报表说明（"列出界与实际误差之比""占比之差"）
- **例**＝示例、演算行
- **献**＝数据标定口径、文献算式、备查关系
- **说**＝字段定义或概述里的说明文字（运行时算式在别处并已保护）
- **引**＝引用别卷读法（除法在别卷入口，如卷三 M-1）
- **误差**＝误差界通则、误差量推导里的式子
- **保**＝已有保护脚本未识别（括号写保护所在）
- **常**＝除数为常数
- **条**＝分支条件已保证除数为正
- **删**＝已删旧式的说明

## 四、误报类型 → 脚本怎样排除（供修到零误报）
