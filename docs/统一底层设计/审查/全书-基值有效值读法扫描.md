# 全书：读材料数值处"修正前的值 / 有效值"读法扫描

脚本：`F:/dnd-tmp/book/scan-base-vs-effective.mjs`（只读各卷现行稿，不含版本快照与审查目录）。

依据：卷三乙 §4.1 M-12。材料表组件类的条目可以经卷二 §3.5 的 `mounted` 作用域修正材料行的数值，所以一个材料数值有两个取值：行上修正前的值，与修正后的有效值。M-12 定的分工是：**选料与身份读修正前的值；过程、折算与炉温读有效值；别卷经 `materialView` 读到的是有效值**。本扫描找出各卷读材料数值而没写明读哪一个的位置。

判法是文字层面的：一行里出现材料数值字段的代号（42 个：卷三甲 §2.1 的数值字段加四个派生量），说的是材料，又带着读取的迹象，就算一处；这一行、它所在表格前的那段话、或它上一级的列表项里写了"修正前""有效值"或引了 M-12，就算已说明。字段定义行、数据实例、附录、迁移清单、开放问题、术语表不扫。卷三甲、卷三乙另按 M-12 点名的规则号与小节号判。会有漏报（只写中文字段名、不写代号的句子扫不到）与误报（同名的物品维度），列出的位置要人看过再定。
