## 二、问题

### 真问题

1. **`subjectEnd`“只许 `send_close`”与卷十八现行数据和条文冲突**。卷二 §2.6 第 4 步写“现只许取 `send_close`”，卷十八 §4.1.5 主列块仍有 7 格非关闭（`hk_resides` `send_reparent`；`hk_owns`、`hk_certified`、`hk_pledged`、`hk_cursed_by` `send_stay`；`hk_employed_by`、`hk_honored_by` `send_estate`），R18-1.3 仍写“列照旧表逐格迁入并保留”，R18-7.6（卷十八:984）仍写“改指后继待卷二确认”，未随批改。按“只许”这 7 行加载即不合（E-HK-ROW-FIELDS 口径）。意见：属裁定直接后果，应同批改：7 格改 `send_close`（现行行为本就一律关闭，行为不变），R18-1.3 删“逐格保留”、改为三值留在 `subject_end` 族里但行上不许用，R18-7.6 同步。不需李白再定。

2. **规则层与内核之间的三个接点在 kernelApi 无行**。① 卷十八 §3.3 规定持有写者把带关系的写转交 `kernel/relations.mjs#writeRelation`，卷二 kernelApi 闭集里没有这个导出，规则层的持有写者调用它即违例；`relations.mjs` 作为 kernel 新文件也未写进 kernel 文件清单的登记说明。② 提交前重算钩子段写“`kernel/transaction.mjs` 在提交前调持有写者”，但卷二多处规定内核不 import 规则层（`registerAdvanceHook`、`registerTerminationCleanup`、`registerEventDerive` 都是“模块加载时交入函数”），本段没有交入的登记点。③ 第 4 步 ① 由内核调用 `succeedBy` 的顺序提供入口（卷十八 R18-1.8：纯读函数，在规则层），readShapes 只登记返回形状，不给内核取得这些函数的途径。意见：裁定第 2 条已授权“纯登记 `kernel/relations.mjs` 与 holdWhile 钩子”，按现有 register 做法补 kernelApi 行（`writeRelation`，`callers` 写 rules；两个交入函数各一行）属直接后果，同批补；只有当要把持有写者改放 kernel 组时才需李白定。

3. **`succeedBy` 入口的返回形状写不出（编辑疑点 ③）**。readShapes 的 `type` 只有四值与 `shape`，`shape` 须指 §1.5 已登记命名 struct。但先例已有：`struct:effectCallList` 就是登记为命名 struct 的列表类型（`list<struct:effectCall>`）。意见：属直接后果，不需改 readShapes 格式：卷十八定义一个列表型命名 struct（有序实体 id 列表），卷二 §1.5 照录，各入口的 readShapes 行写 `shape`；同批做。

4. **第 4 步 ③ 写点与窗口 0 的删除次序冲突**。卷二“窗口期满”写 `reviveWindowDays = 0` 时 `hold` 记录在第 1 步删除，而 `points` 在第 4 步才写，写下后不再有人删；卷四不变量（卷四:890）要求窗口 0 的个体终止后 `revivals` 下没有它的路径。窗口 0 的个体持有复生点边时即残留。意见：按“窗口 0 时 hold 等同 clear”的现行规则可直接推出，③ 补“`reviveWindowDays` 为 0 时不记点”，同批改，不需李白。

5. **两项登记只到名字，加载不了（编辑疑点 ①④）**。卷二十 §8 问题 5 的八个词表族在 §1.9 无行（`Handle<due_kind>`、`Handle<field>` 已在 §1.5 `dueItem`、`emission` 里使用）；卷十八三条记录类只有中文名、无 `rcls_` 代号，去留表的 `recordClass` 填不了。裁定 6 ④“缺的补登记行”、第 2 条“record_class 三条”都要求可用的登记。意见：属直接后果，同批由定义卷给代号、卷二照录：`weather`、`phenomenon`、`field`、`due_kind` 按卷二十现有条目开头（`wx_`、`phen_`、`field_`、`due_`）；`calendar`、`season_scheme`、`pace_level`、`reaction_priority` 由卷二十按 §1.9 通行的“族名加下划线”写法定并查冲突；三条记录类由卷十八起 `rcls_` 代号。命名不是新设计，不需李白。
