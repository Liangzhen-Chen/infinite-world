## 二 真问题（不可封）

1. **卷八 §2.1 `polity` 的 null 含义与 R8-3.2 矛盾。** :126 写"null 即本组织不属任何政体"。R8-3.2（:645）却规定：非主权组织的 `polity` 为空时，税、征召与持有资格读它的 `realm` 的政体行，也就是 null 表示沿隶属关系取政体。两处对同一个 null 给了相反的含义。改法：:126 改为"null 即本组织不另定政体，税、征召、持有资格沿 `realm` 取（R8-3.2）"；R8-3.2 的"为空"改为"为 null"。
