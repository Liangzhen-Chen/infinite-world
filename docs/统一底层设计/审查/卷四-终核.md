## 三、新真问题（需报李白）

### N-2 "已终止"一词在卷四与卷二新语义下指两件事，复生断言与 D-6 冲突 —— 新真问题，需报李白
- 位置：§4.8.6 行 749"已终止的主体不可 `revive`"；§3.2 行 297"'已身死、还没被终止'（复生窗口期）不是判死"；§5.4 行 1018"本卷不依赖后一点"。
- 类别：5（自相矛盾）、7（断言不能交给机器无歧义判定）。
- 证据：卷二行 398 已定：带 `terminal:true` 的状态实例存在而终止标记未写的那一段"同样算已终止"，即复生窗口期内 `terminated(subject)` 为真。卷四 D-6 允许窗口期内 `revive`。若按全书唯一判死口径（§3.2：只调 `terminated`）去机器判定行 749，窗口期内 `terminated` 为真，断言要求 `revive` 失败，与 D-6 及 X-5（行 1050"窗口内 `revive` 成功"）直接矛盾。§3.2 说窗口期"不是判死"，也与卷二"窗口期算已终止"的说法字面相反。卷四在第三版写时卷二尚未定窗口期取值，所以本卷写成"不依赖"；卷二定下后，卷四这几句措辞就与谓词结果对不上了。
- 建议改法：卷四内区分两个词，不改机制。①行 749 改为"终止协议已执行（`deaths` 记录已被 `settleBody` 删除）的主体不可 `revive`"——D-6 前置要求有 `deaths` 记录，此条即可机判。②§3.2 行 297 改为"窗口期内 `terminated` 为真（卷二 §2.5）；区分'窗口期'与'协议已执行'不是判死，读 death.mjs 自己的 `deaths.*`"。③行 1018 删去"取什么值……本卷不依赖后一点"，改为确认已采用卷二的取值。④附带：主会话所说卷二"复生是独立的协议步骤"落稿后，需核 D-6（移除终止类实例由 death.mjs 的 `revive` 做，P-6 行 328、§4.8.6 行 744 只许 `revive` 与 terminate 第 5 步移除）与卷二新步骤的写者归属是否一致；此点属卷二侧，现仅列为待对齐。
