## 四、新真问题（需报李白）

**N-1 并列取法与 A5-1.2 的"互为逆序"矛盾**（类 5、7）——新真问题，需报李白
- 位置：卷五 L291（"路程相同时取边数少的；仍相同，取途经地点 id 序列字典序最小的"）；L313 A5-1.2（"`routeView(a, b).path` 与 `routeView(b, a).path` 路程相同、途经地点互为逆序"）。
- 证据：字典序比较依赖方向。设 a 到 b 有两条路程、边数都相同的路 a–x–y–b 与 a–z–w–b，且 x < z、w < y。从 a 出发比 [a,x,…] 与 [a,z,…]，取经 x、y 的路；从 b 出发比 [b,y,…] 与 [b,w,…]，取经 w、z 的路。两次结果不互为逆序，A5-1.2 机判必失败；卷二十的声沿这条路扣墙（L779–782），a 听 b 与 b 听 a 的到达量也可以不同。另：L288 只说"一条边只存一次"，没说同一对地点至多一条边；若允许两条平行边（路与河）且路程相同，按"途经地点序列"仍分不出来。
- 建议：并列取法改为与方向无关，例如"把路径按 id 较小的端点为起点写出，比较这个序列的字典序；调用方向相反时把结果倒过来"；再写明同一对地点至多一条边（加载校验），或在地点序列之后再按边 id 序列比。

**N-2 A5-2.2 的"`margin` 未知当且仅当 `rangeShortfallM` 非空"不成立**（类 5、7）——新真问题，需报李白
- 位置：卷五 L353 A5-2.2；L333 规则 3（`margin` 经卷二 §3.3 管线求值）；卷二十 L975（统计层"有场或有光源处的光声"不求值，读取返回未知）。
- 证据：到达强度（`propagate` 在统计层返回未知）、阈值或感官能力值任一未知时，`margin` 为未知而 `rangeShortfallM` 为空。"当且仅当"的反方向会被这些情形击穿，机判失败；卷十三按 L342"未知按没有感知到处理"也区分不出"够不着"与"量不出来"。
- 建议：A5-2.2 改为单向："`rangeShortfallM` 非空 ⇒ `margin` 为未知、`perceived` 为假、未调 `propagate`"；规则 3 补一句其余输入未知时 `margin` 为未知、`perceived` 怎么取（按通道条目的 `onUnknown` 或固定为假）。

**N-3 同一次"看见光"，可及距离取路程、到达量取直线**（类 5）——小项 6 的改法带出，需报李白
- 位置：卷五 L338 规则 8（可及距离"有几何最短路取 `routeView().path.distanceM`，两地不连通取坐标直线距离"）；卷二十 L777（点到点的光"取两地的坐标直线距离（光走直线，不沿路绕），不读几何最短路"）。
- 证据：一盏灯与观察者直线 30 米、只隔一道山脊，绕路 2 千米：卷二十按 30 米算出足够的照度，卷五却按 2 千米判为够不着；反过来两间屋隔着实墙、不连通，卷五取直线 5 米判为够得着，卷二十按直线算照度且光项不扣任何围护，于是隔实墙看得见灯。两卷对"光怎么走"给了两种几何，结果取决于地图有没有画那条边。
- 建议：二者统一到一种几何并写在一处。可选：（甲）规则 8 的可及距离也取直线，光的 `propagate` 补"跨越围护的遮挡"一项（按包含树判，与声的直穿同法，`aperture` 为 0 时遮死）；（乙）光也按 V-7 的 `max(沿路, 直穿)` 两条走法，直穿对光恒为 0。
