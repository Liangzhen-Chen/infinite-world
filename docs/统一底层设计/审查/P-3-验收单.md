## 一、落表情况

- 93 行全部落表，行集合与 §4.5.5 例 1 一致。各短表落格数与卷文自述一致：纤维 28、碳水 27、植物部位 17（夜帽菇按卷文留空）、植物科 17、成堆证据 7、易燃度区间 5、来料反应 21、保暖 11、透气 11、参照材料 5、比热 12（含水银液栏）。
- 逐行核对卷三甲表值：易燃度栏与"极限氧"栏按 `1 − 极限氧 ÷ 42` 换算，93 行中有极限氧的行全部相符，差异 0 条；其余栏卷文只有一处出处，无第二来源可对，没有可报的不符。
- 类别行 33 行（旧 `classes` 22 + `physical` 11 + `physicalMetal` 5，同名合并）：旧营养类别按其 `sources` 重算 `moisture / edibleFraction`；`energyDensity` 不转（旧 kcal 是代谢能，不是卷文口径的干基总能），`mealCap` 不转（旧值凭记忆）；旧单值密度迁入 20 ℃ 固栏（M3a-6，旧物理块注明不含液体）；`appearance[].term` 49 条进 `labels.zh.json`，行内只留 `appearanceRefs`；`nameWords / forms / modifiers / tailForms / excludeTags` 不搬。旧 `heatValue`（高位）与 `charYield`（新表派生列）不转；`memberItems` 指物品代号、物品表未载，不转。
- 卷文差异（单列）：S、Sc 两类超自然组件类属卷十五，本卡未载入，鬼火油、雷击木炭、月华浆果三行的 `classes` 只写 B、E 等已登记的。
