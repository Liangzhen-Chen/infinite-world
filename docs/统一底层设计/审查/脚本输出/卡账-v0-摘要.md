## 四 与排期 v1 的对照（开工排期-v1定稿 §1）

- 阶段数 n：排期 ≈ 5–7；本表 5。差异的原因：R11-7.2 来源 2（要接的入口由另一张卡上线）在 v0 只能用"本对象自己的入口"，因为别对象入口的使用没有机读来源——各卷"本卷使用的别卷接口"是按节号写的文字，没有入口名栏；旧代码里的调用方采集（H2）只按名字对、噪声大。所以 v0 的跨对象入口依赖没有算进去；表间必填引用（来源 1）按卷十一 §4.7.5 算（引用方首卡比被引用表首卡晚一个阶段：信仰晚于神祇、物种晚于身体图、人物晚于物种，等等），来源 4、5 同阶段。n 因此是下界（再加别对象入口依赖只会更大）。灵敏度：把 H2 的旧调用方按名字对到别对象读入口后，n = 16，依赖成环（C-卷七-deity-1→C-卷二十-sys.time_env-1→C-卷七-deity-1），固定卡阶段冲突 0 处——说明在那份噪声输入上算不出可用的阶段，待各卷迁移节写出按入口名的"要接的入口"栏后重算。
- 实现卡（首卡、后续卡、搬迁卡、账本母卡与子卡）：排期 60–120；本表 104（其中首卡加后续卡 86），在区间内。
