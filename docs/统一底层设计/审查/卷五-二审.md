## 四、新矛盾（2 条）

### N-1 天然洞穴：本卷说卷二十"按围护处理"，本卷自己却禁止洞穴挂围护
- 位置：425 行（§4.5 规则 3："卷二十 §4.5 规则 2 把洞穴与房间都按围护加热源处理"）；对照 415 行（天然洞穴"不围合"）、133 行与 516 行（`comp_tract` 与 `comp_enclosure` 互斥）、436–437 行（例中洞穴为 `comp_tract`、`enclosed` 为假，"各级的气温由卷二十给出"）。
- 类别：5
- 证据：卷二十的围护温度只对挂 `comp_enclosure` 的地点成立（卷二十第 248 行 `envelopeUaWPerK` 挂在 `comp_enclosure` 上，第 565 行"围护内的地点给室内温度"）。按本卷第二版，天然洞穴是存量单元，不能挂 `comp_enclosure`，`enclosed` 为假；因此卷二十对它只能给室外温度。425 行据以推卸地下气温的那句前提在本卷自己的结构下不成立，深洞"各级气温由卷二十给出"（437 行）也就落空。这是裁定 2（存量单元互斥）与裁定 7（围合与地下分开）合在一起带出的，矛盾在卷五一侧。
- 建议：改 425 行，不再说卷二十按围护处理天然洞穴，改为"天然洞穴不挂围护，`enclosed` 为假、`underground` 为真；它的气温、光、声怎样由 `depthM`、`underground`、`skyExposure` 推出，请卷二十定"，并把这一点并进 Q13 ⑤（目前 ⑤ 只问"深处是否更暖"，没写明洞穴根本不走围护路径）。437 行例句随之改写。

## 五、小项（只记账）

1. §4.7 规则 8（544 行）的前提写"x 的 `habitats` 对两端的群落都成立"，而第二项（546 行）括注"栖地已不成立"；栖地不成立时按前提根本不进这条规则。第二项实际只会在"栖地成立但容量为 0"（如捕食者无猎物）时触发，括注应改为"容量为 0"。
2. `depthM` 的新定义（423 行）以最近露天祖先的 `elevationM` 为地表参照。坡地村落里海拔低于村行代表海拔的房屋，`skyExposure` 为 0 时会得到正的 `depthM`、被判为地下；A5-5.2（443 行）用"海拔不低于地表参照"一句把这种情形排除在断言外，但没有在规则里处理。宜在生成或迁移时规定建筑行的 `elevationM` 取所在露天祖先的值，或让地表参照取自身坐标处的地表高程。
3. §4.4 规则 3（382 行）矿物储量用 `areaM2`，而 §4.7 规则 1（514 行）生物存量用扣除子行后的 `stockAreaM2`；若有意（地下矿体不受地表建筑影响），宜写一句说明。
4. §4.7 规则 3（523 行）直接读卷二十的规则表 `rules.astro` 求回归年日数；卷二十已给出 `astroView().perYearToPerStep`（卷二十第 450 行），宜改调入口，不读别卷规则表。
