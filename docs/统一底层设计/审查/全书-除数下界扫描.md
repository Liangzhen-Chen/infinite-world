# 全书除数下界扫描（11-13）

范围：`F:/dnd/docs/统一底层设计/卷*.md` 现行各卷（不含 版本快照/、审查/、素材包/）。搜的是规则式里的 `÷`、`除以`，另查了代码体式里的 ` / `（实际只抓到卷二 `lifeDays`、卷二十一 `reserveDaysRX` 两处真除法，其余 ` / ` 都是并列写法）。卷一、卷零没有规则除法。

判据：除数有正下界 = ① 取值域下限 > 0（含左开区间 `(0, x]`，因为四位定点最小正数是 10⁻⁴），② 加载校验，③ 写明为 0 或过小时的分支，④ 由式子或分支保证分子非零时除数必为正。都没有的列入"无下界"。

准绳引用（全书现成写法，建议改法只从这几种里选，不新增设计）：
- 卷二 §3.3 第 6 条（卷二:1121）："凡作除数的量，取值域必须登记正的下界，或由式子保证为正"；`L` 不为正的这次写入没有界。
- 取值域下限：卷五 `areaM2` [1, null]（卷五:90）；卷三甲 `density` [0.01, 25]（卷三甲:94）；卷二十五 `fertilityNeed` [1, 100]（卷二十五:108）；卷二十一 `pharm.refDose` > 0、`overdoseAt` > 1（卷二十一:163）。
- 加载校验：卷二十 `factor` 为正有理数（卷二十:337）；卷五 `controlRatePerDay` 取值域 [0,1] 加载校验（卷五:729）；卷十九 `minutesPerM3` 正整数（卷十九:197）。
- 为 0 / 过小分支："K 为 0 时这一项为 0"（卷五:599）、"Keff 为 0 时充盈比按 1 计"（卷五:687）；"`fireLoadMJ` 为 0 的建筑不抽取"（卷十九:934）；"应到为 0 时为 1"（卷十九:896）；"日需求未知或为 0 时稀缺度未知（不做除法…按未知即不乘并记缺口）"（卷三乙 V-5:1580）；"`N` 为 0 时括号内的查表值取 1"（卷二十五:311）；"D0 = 0 → 不适用：不建实例、不求值"（卷二十一:620）；"L(Q) 不为正时不做除法"（卷十九:323）；"窗口内没有成交时取曲线中点并记缺口"（卷六:859）。
- 规则表最小值键：本次卷二十一定 `rules.med.minDoseMassKg` 的做法（键名以卷二十一第九版为准），用于"值可以合法地很小、但式子需要一个下限"的量。
