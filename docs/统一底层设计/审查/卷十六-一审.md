## 四、§8 四条待定的利弊与证据（只陈述）

**Q16-1 个体变身/成精：真改物种，还是"躯体个体加附身边"**
- 改物种（本稿）的依据：卷四 S-2（卷四:381）"巨型、驯化型、觉醒型都是 extends 原种的行"；卷四 Q-5（卷四:1355）建议"变更经一条原语由效果族触发"；个体 id 不变，持有、账户、事实、立场、行为人连续（A16-12.2、R16-9.3）；卷二十六 R26-1.2 的物种基线随物种自动切换；战力、克制、能力都随行重算。代价：要新开 `person.species` 的偏离写者；部位实例改挂须由卷二十一做（R21-2.6，见 T11）；卷五规则 9"物化个体计入存量"按物种记账，换物种时两边存量要对平，本稿未写。
- 躯体加附身边（卷十五 Q15-3 的建议，卷十五:1204）的依据：卷十五 R15-11.3 借尸还魂已有"躯体个体 + 附身边"的现成写法，不动物种维度、不必新写者。代价：每次变身要凭空建一具躯体个体（质量从哪来、变回时那具躯体去哪）；行为人分在两个 id 上，与本稿"所作所为记在同一 id"相反，卷八b 认定与卷二十二知情都要另做穿透；永久成精（狐成精）用附身边描述很别扭；卷十五自己也只定了"不换身体图的变形"。

**Q16-2 年久成精：生灵归本卷、器物留卷十五**
- 分开的依据：结果形状不同——生灵是同一个体换物种（本卷转化），器物是新建一个个体依附该物（卷十五 R15-12.6 `spawn`，卷十五:847）；器物一支卷十五已写全。
- 合并的依据：两张表同形——`relic.awakenRows{when, species, hazardCurve, order}`（卷十五:230）与 `transform.rows{id, when, variant, hazardCurve, order}`；两个年钩子（`awakenYear`、`transformYear`）同一日、同一种抽法、两个抽取点；卷零 2.12 整条判给本卷，卷十五 M15-29（卷十五:1193）也写"器物成精用同形的行"。合并可做成一张危险率行表、输出两种（转化或建立）。

**Q16-3 首领不留实体类，拆成档、具名个体、职位、巢居边**
- 依据：台账 X-11 禁另立怪物 schema、S-19 禁手填稀有度；卷八 R8-14.7（卷八:1034）已按"职位行"接住怪物团体；旧数据确是这四样的组合——bosses.json 42 个 `boss_` 各配一个 `lair_`、一个 `ability_`，boss-foundation.mjs 每行指向一个普通物种与一个地点。
- 代价与风险：旧首领是"普通物种的强个体"，其档来自个体战力而非物种，按本稿的配额、在世上限、具名规则都按物种档约束，这 42 个落在约束之外（T4）；首领专属能力若要保留只能成为物种行的 `specialAttacks`（一首领一物种，物种表膨胀并撞 `distinctBps`）或个体技能；"具名"一环依赖卷二十七钉住，而手写钉住条件与 R27-2.4 冲突（T2）。
