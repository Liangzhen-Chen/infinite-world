# P-3 材料表补格与暂定规则说明

依据：李白 11-17 裁定及当日两次改令（暂定值按统一规则算出、标"暂定，待试玩调"；valueMult 归卷三乙 §7 M3b-27 离线标定，标定做不了时按 P3-T4 暂定；对照表作废）。实现：`tools/convert-material.mjs`（补格与暂定），`tools/calibrate-valuemult.mjs`（M3b-27）。

## 一、卷文能推出的格（不是暂定）

转换脚本整节读卷三甲 §4.1.5、§4.2.5、§4.3.5、§4.4.5 的数据实例（:344–349、:388–392、:435–439、:477–480），凡键是本表已声明手填维度的都取，行上已有值的只核对（差异 0）。共补 50 格，每格在行的 `sources` 记 `{dimension, name: "卷三甲 §4.N.5 例 k", citation: 卷文行号}`：

- 必填 34 格：valueMult、salvageFraction、workDifficulty 各 5（熟铁、竹、山羊毛、黑火药、鬼火油）；burnRate 4（橡木、黑火药、鬼火油、樟脑）；corrosionRate 3（熟铁、竹、骨）；repairedWith 2（熟铁、竹）；reactionYield 3（竹、山羊毛、石灰石）；edibleFraction、rotRate 各 2（粟、月华浆果）；黑火药爆燃三项 3。
- 非必填 16 格：熟铁、竹、水、骨的 strength、sharpnessMax、wearResistance；水的 specificHeat（三态）与 thermalConductivity（三态）；黑火药 noiseFactor；熟铁 reactionClass（`reaction_forge` 随之登记进 reaction 族，卷三甲 §2.2 首批列有"锻打"）。
- 不取（如实记）：rawForm（物品表未载入）、熟铁 armorMult（damage 族无条目，卷十三 Q13-12）、雷击木炭例 3 的继承写法 `valueMult*:40`（父行木炭的 valueMult 待 M3b-27）。

## 二、暂定规则（标"暂定，待试玩调"）

标记写在卷二已有的行字段 `sources`（卷二 §5.0 :1576 `basis / sources / status`）：每格一条 `{dimension, name: "暂定，待试玩调", citation: "P3-Tn …", status: "vstat_placeholder"}`；`status` 取卷二 vstatus 族的 `vstat_placeholder`。卷二的 `status` 是行级字段，没有逐格的处所，所以放进逐格的 source 条目（见 docs/问题.md "P-3 暂定值"）。不填的格：卷文短表明写未核到的（醪的纤维；醪、夜帽菇、月华浆果的碳水，M-19 与例 5 不许暂填；加载时四格都按 onUnknown gap 报 W-DIM-GAP；纤维一格的 gap 来自卷三甲封卷后勘误 1117p3）。

| 编号 | 规则 | 适用维度 | 出处 |
|---|---|---|---|
| P3-T1 | 取本表同一本源成分（`substance`，空值算一组）已有值的中位数；组内没有已有值时取该维全部已有值的中位数。reactionYield 按反应代号分组，同一反应没有已有值时取全部已有产率的中位数 | burnRate、corrosionRate、deflagThreshold、deflagEnergy、fragmentFactor、edibleFraction、rotRate、salvageFraction、workDifficulty、reactionYield | 方法同卷三甲 §4.5.5 依据代号"推"（:519 能:推、:523 氧:推，同类推定）；数无卷文出处，暂定。rotRate 另注：卷三甲 §7 M3a-4（:968）有规则（旧物品 shelfLifeDays 按材料聚类取 1÷天数中位数）但缺输入（旧物品无指向材料的字段），暂定 |
| P3-T2 | 单餐上限一律 1100 g（成人胃容量约 1.1 L、食物密度约 1） | mealCap | 无卷文出处，暂定（数取 Geliebter 1988，旧 material-props.json 的 mealCitation） |
| P3-T4 | 同本源成分的卷文例值取下中位数；本源成分为空或该成分没有例值的取 1。标"暂定，待 M3b-27 标定" | valueMult | 锚值取卷三甲 §4.1.5 :344（熟铁 10）、:345（竹 1）、:347（山羊毛 2），§4.3.5 :436（黑火药 30）；鬼火油（:437，60）本源成分为空，不作锚；暂定（李白 11-17 第二次裁定；正式值归卷三乙 §7 M3b-27） |
| P3-T3 | 修理用料类 = 本行本源成分在卷三乙 §4.1.1 的类别（`rules.materials.substanceClass`） | repairedWith | 卷三乙 §4.1.1 :559；卷三甲 §4.1.5 例 1、例 2 两例都等于自身类别。"修理用料取自身类别"这一步卷文没写成规则，暂定 |

标注文字：rotRate 19 格标"暂定，待 M3a-4 标定（块 6 物品表首卡）"，valueMult 88 格标"暂定，待 M3b-27 标定（块 6 物品表首卡）"，其余暂定格标"暂定，待试玩调"（块 1 迁移体检）。

暂定格共 439：burnRate 39、corrosionRate 22、deflagEnergy 1、deflagThreshold 1、edibleFraction 24、fragmentFactor 1、mealCap 26、reactionYield 19（18 行）、repairedWith 23、rotRate 19、salvageFraction 88、valueMult 88（P3-T4）、workDifficulty 88。具体数不进测试；测试只验有值、过表头取值域。

T1 的已有值眼下多数只有一两个例值（例：rotRate 只有粟 0.002、月华浆果 0.2 两个，全部 R 行都取 0.101），所以暂定值整类一样的居多；试玩中哪一维显出不合理，改规则或补出处，不逐格手改。

## 三、设定值（designed）与改级判据（李白 11-17 卷三甲补裁，亮圳 15:56）

全书通用：查不到合格出处的数据格不再留空，填设定值，按卷三甲 §2.1"物性格的来源级别"（:166–:172）记 designed；basis 写参照了哪一行、为什么这样取，依据代号用"设"类；不标 measured，不写出处。`cellGrades` 无处可写（docs/问题.md），记在行 `sources` 的逐格条目：`{dimension, name: "设定，可在试玩后调", grade: "designed", code, basis, citation: null}`。

**卷文留空格的设定值**（`tools/data/material-designed.json`，转换脚本整表套用、只填空格）：醪纤维 0.15（参照粟 0.089，发酵耗掉部分干物质、纤维占比升高）；落叶纤维 0.30（参照干草 0.30、秸秆 0.415）；醪碳水 0.60（参照粟 0.796）；夜帽菇碳水 0.58（参照例 8 撤掉的食用菌类推值）；月华浆果碳水 0.85（浆果以糖为主）。逐行核过 M-19（碳水不小于同行纤维）与 [0,1]。卷文自己的"纤:设"两格（夜帽菇 0.08、月华浆果 0.1）同写法补记 designed。

**暂定格改 designed 的判据**：一格由本节二的统一规则算出，若 ① 该维有卷文写明的标定规则待后续卡执行（rotRate 待 M3a-4、valueMult 待 M3b-27），保留暂定，标注不改；② 是引用代号格（repairedWith；§2.1 :166 引用代号格不带级别），保留暂定；③ 其余数值格没有任何卷文规则可等，只能设定，记 designed，basis 写所用规则（P3-T1/T2）与参照行。按此改 309 格：burnRate 39、corrosionRate 22、deflagThreshold / deflagEnergy / fragmentFactor 各 1、edibleFraction 24、mealCap 26、reactionYield 19、salvageFraction 88、workDifficulty 88。仍暂定 130 格：rotRate 19、valueMult 88、repairedWith 23。

## 四、类别行的两项改动

- `energyDensity` 不再从旧 kcal 折：旧 sources 只有 kcal（代谢能），卷三甲 §2.1 口径是干基总能，"能:食"（§4.5.5 :516）要蛋白、脂肪、碳水三项含量，旧数据没有，不填。
- `mealCap` 不沿用：旧值标"凭记忆写入，待 L2 核对"。
