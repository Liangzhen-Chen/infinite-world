# P-3 材料表补格与暂定规则说明

依据：李白 11-17 裁定及当日两次改令（暂定值按统一规则算出、标"暂定，待试玩调"；valueMult 归卷三乙 §7 M3b-27 离线标定，标定做不了时按 P3-T4 暂定；对照表作废）。实现：`tools/convert-material.mjs`（补格与暂定），`tools/calibrate-valuemult.mjs`（M3b-27）。

## 一、卷文能推出的格（不是暂定）

转换脚本整节读卷三甲 §4.1.5、§4.2.5、§4.3.5、§4.4.5 的数据实例（:344–349、:388–392、:435–439、:477–480），凡键是本表已声明手填维度的都取，行上已有值的只核对（差异 0）。共补 50 格，每格在行的 `cellGrades` 记 designed，basis 写"卷三甲 §4.N.5 例 k 卷文例值"与卷文行号（第三轮起；第二轮写在 `sources`）：

- 必填 34 格：valueMult、salvageFraction、workDifficulty 各 5（熟铁、竹、山羊毛、黑火药、鬼火油）；burnRate 4（橡木、黑火药、鬼火油、樟脑）；corrosionRate 3（熟铁、竹、骨）；repairedWith 2（熟铁、竹）；reactionYield 3（竹、山羊毛、石灰石）；edibleFraction、rotRate 各 2（粟、月华浆果）；黑火药爆燃三项 3。
- 非必填 16 格：熟铁、竹、水、骨的 strength、sharpnessMax、wearResistance；水的 specificHeat（三态）与 thermalConductivity（三态）；黑火药 noiseFactor；熟铁 reactionClass（`reaction_forge` 随之登记进 reaction 族，卷三甲 §2.2 首批列有"锻打"）。
- 不取（如实记）：rawForm（物品表未载入）、熟铁 armorMult（damage 族无条目，卷十三 Q13-12）、雷击木炭例 3 的继承写法 `valueMult*:40`（父行木炭的 valueMult 待 M3b-27）。

## 二、暂定规则（标"暂定，待试玩调"）

标记位置（第三轮起）：数值格写在行上 `cellGrades` 该格，记 designed，basis 以"暂定，待…"起头、接所用规则与参照；引用代号格（repairedWith）不带级别，推出依据接在行 `basis` 后。第二轮写在行 `sources` 的逐格条目（`status: vstat_placeholder`）已撤，不留两套（李白 11-17 P3-05）。不填的格：卷文短表明写未核到的（醪的纤维；醪、夜帽菇、月华浆果的碳水，M-19 与例 5 不许暂填；加载时四格都按 onUnknown gap 报 W-DIM-GAP；纤维一格的 gap 来自卷三甲封卷后勘误 1117p3）。

暂定格共 439：burnRate 39、corrosionRate 22、deflagEnergy 1、deflagThreshold 1、edibleFraction 24、fragmentFactor 1、mealCap 26、reactionYield 19（18 行）、repairedWith 23、rotRate 19、salvageFraction 88、valueMult 88（P3-T4）、workDifficulty 88。具体数不进测试；测试只验有值、过表头取值域。

T1 的已有值眼下多数只有一两个例值（例：rotRate 只有粟 0.002、月华浆果 0.2 两个，全部 R 行都取 0.101），所以暂定值整类一样的居多；试玩中哪一维显出不合理，改规则或补出处，不逐格手改。

## 三、设定值（designed）与改级判据（李白 11-17 卷三甲补裁，亮圳 15:56）

全书通用：查不到合格出处的数据格不再留空，填设定值，按卷三甲 §2.1"物性格的来源级别"（:166–:172）记 designed；basis 写参照了哪一行、为什么这样取，依据代号用"设"类；不标 measured，不写出处。第三轮起写在行上 `cellGrades` 该格：`{grade: "designed", citation: null, basis: "<依据代号>：<参照与理由>；设定，可在试玩后调"}`（第二轮写在 `sources`，已撤）。

**卷文留空格的设定值**（`tools/data/material-designed.json`，转换脚本整表套用、只填空格）：醪纤维 0.15（参照粟 0.089，发酵耗掉部分干物质、纤维占比升高）；落叶纤维 0.30（参照干草 0.30、秸秆 0.415）；醪碳水 0.60（参照粟 0.796）；夜帽菇碳水 0.58（参照例 8 撤掉的食用菌类推值）；月华浆果碳水 0.85（浆果以糖为主）。逐行核过 M-19（碳水不小于同行纤维）与 [0,1]。卷文自己的"纤:设"两格（夜帽菇 0.08、月华浆果 0.1）同写法补记 designed。

**暂定格改 designed 的判据**：一格由本节二的统一规则算出，若 ① 该维有卷文写明的标定规则待后续卡执行（rotRate 待 M3a-4、valueMult 待 M3b-27），保留暂定，标注不改；② 是引用代号格（repairedWith；§2.1 :166 引用代号格不带级别），保留暂定；③ 其余数值格没有任何卷文规则可等，只能设定，记 designed，basis 写所用规则（P3-T1/T2）与参照行。按此改 309 格：burnRate 39、corrosionRate 22、deflagThreshold / deflagEnergy / fragmentFactor 各 1、edibleFraction 24、mealCap 26、reactionYield 19、salvageFraction 88、workDifficulty 88。仍暂定 130 格：rotRate 19、valueMult 88、repairedWith 23。

## 四、类别行的两项改动

- `energyDensity` 不再从旧 kcal 折：旧 sources 只有 kcal（代谢能），卷三甲 §2.1 口径是干基总能，"能:食"（§4.5.5 :516）要蛋白、脂肪、碳水三项含量，旧数据没有。第三轮（李白 11-17 P3-06）：有旧 kcal 的 18 个类别行填设定值（`tools/data/material-designed.json`，依据代号"能:设"）：有同类材料行的照抄其值并写明参照行（如谷物取麦、粟平均，蛋取蛋液）；没有同类行的按 :516 燃烧热系数与常见成分估算（坚果、豆、香料籽、稠乳）。
- `mealCap` 不沿用：旧值标"凭记忆写入，待 L2 核对"。

## 五、逐格来源级别 `cellGrades` 的折算（第三轮，李白 11-17 P3-05）

字段落法：材料表表头声明 `cellGrades: {field: "cellGrades", refDim: "refMaterial"}`，各行（类别行、实体行、生成行）写文档字段 `cellGrades`，结构照卷三甲 §2.1 :166–:172；不进卷二 §5.0 公共字段。格的划分只按维度类型：数值、整数、布尔一格；struct 逐字段、map 逐键各一格（`density.solid`、`nutrients.nutr_salt`、`reactionYield.<反应>`）；引用代号、集合与 null 不带。卷文只写明"分态量逐栏算一格"，映射逐键算是同一口径的推广（盐分在全集表是单独一栏）。

折算（卷三甲 §4.5.5 :528）由转换脚本按下列顺序写，后写的覆盖先写的：
1. 全集表每个有值的栏先记 designed，basis"全集表某栏的卷文值，没有依据代号指向出处"。
2. 依据代号：能:饲/食/纯/木 → `energyDensity` measured；氧:试/汽 → `flammability` measured；能:推、氧:推、氧:氧、氧:未核 → designed。citation/basis 带代号与该行备注。极限氧不存（易燃度由它换算），不另成格。
3. 备注逐格出处：分号段以栏名起头、写成"栏名 数值（出处）"或"栏名与出处相符（出处）"且数值等于格值的，该格改 measured（自燃点 9 格、闪点 3 格）；"未核到"段与"用某例值"段不算。
4. 例 5、例 8 短表：纤:饲/食、碳:饲/食 → measured；纤:定、碳:定（按定义取 0）、纤:设、碳:设 → designed。
5. 例 7 易燃度区间两端 → measured；例 11 级别栏 A/B/C → measured/referenced/designed（"同上"展开成上一条出处）。
6. §4.1.5–§4.4.5 实例补格、P3-T1–T4 规则补格、设定值表 → designed。
7. USDA（P3-27）：旧 `verified-sources.json`（标签 old-final-1117）每条一种食物的 FDC 记录。类别行的含水率、可食部分由带出处的 sources 按 selection 取法算出，记 measured，citation 列出所用各条（已含 31 条 class_ 条目的 FDC 编号）；类别行密度同此。材料行按"名称相同，或行上写明总能按同一 FDC 记录的成分重算且该行总能是 A 级"对应，含水率按格值位数取整相等才并入 measured（鲜菜、菜籽油、酥油 3 格）；蛋对应但不等（0.75 对 0.762）不并；夜帽菇的总能是拿白蘑菇类推的"能:推"，不算同一种食物。千卡值不用。类别行外观词条条数 `appearanceRefs` 记 designed（是条数，不是测得的量）。

结果：材料行 measured 125、referenced 5、designed 1231；类别行 measured 36、designed 32。与 :528 自述"A 63（干基饱腹 31、极限氧 16、易燃度 16）"对照：干基饱腹 31、易燃度 16 一致；极限氧不存；另有备注出处 12、例 5 纤维 9、例 8 碳水 26、例 7 区间 10、例 11 比热与保暖 18、USDA 含水率 3。

## 六、byDigestible 与 sharpnessMax 补格（第三轮）

- 仍缺格的判定除表头 always / byClass / ifPresent 外，另把转换稿交真实校验器跑一次，取它报的必填缺格（含 byDigestible，P3-13；anyOf 不补），统一按 P3-T1 补（映射逐键取中位数）。本轮 byDigestible 带进来的干草、秸秆、落叶、茶叶四行营养格卷文都已给，补 0 格。
- sharpnessMax（P3-32）：卷二 §6.12 `rules.dimfill.materialSharpnessMax` 90%，分母为有固相栏的材料；分母内缺格按 P3-T1 补 88 格（designed，basis 写下限键），不降下限。
