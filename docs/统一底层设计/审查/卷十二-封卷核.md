**真问题 X1（局部自相矛盾）**：R12-4.4 :718 与 A12-4.2 :739 对同一指纹下的第二条及以后的第二轮记录，要求同时满足"`sampleSeed` 等于按**本**记录号重算的值、`sampledKeys` 等于由该种子派生的集合"和"抽中集合与最早登记的一条相同"。记录号不同，派生集合一般不同，两条除非碰巧重合，否则不可能同时成立，后来的第二轮记录必报 E-ACC-REVIEW-CHECKLIST。另外"最早登记"没有定次序：记录号与 `submitted` 只到秒（review-put.sh:31、:35），同一秒的两条先后不确定。
