## 一、两卷定位

| 新卷 | 暂定名 | 只放什么 | 不放什么 |
|---|---|---|---|
| 卷三甲 | 物质本源 | 物质本身的数值与固定代号：本源成分、组件类代号、熔点/沸点/分解点、热值/燃点/易燃度、挥发度（新）、含水率、干基饱腹、盐分、来料反应代号、按物态分填的密度/承力/硬度等；各维度的取值域、单位、词表；全部材料数据实例（含 92 种全集）；加载期只做取值域与必填校验 | 任何“由数值推出状态或类别”的规则；任何物品层内容 |
| 卷三乙 | 物态、类别与物品 | 由甲卷数值随时推出的一切：物态（固/液/气）= f(当前温度, 熔点, 沸点) 的状态量；按物态取用密度/承力等的读法；派生大类与组件类判定（织物、陶瓷、蜡脂、谷物、燃料、盐类、锻料等）；物品模板/实例、容器与批次、品质、工具能力、需求块、配方、拆修、耐久、热与燃烧过程、腐坏过程、服装护甲、附件、书、估值、替代折算、运法 | 物质本身的数值（只引用甲卷） |

判据：一条内容若只是“某物质是多少/是什么代号”，归甲；若是“读这些数推出什么”，归乙。

## 三、物态改为状态量（乙卷核心改动）

1. `phaseOf(material, tempC)`：tempC < 熔点 → 固；熔点 ≤ tempC < 沸点 → 液；≥ 沸点 → 气；有分解点且先于熔化者按分解规则（现 decomposePoint 规则移入乙）。熔沸点未知 → 物态未知（按卷五卷二十裁定③通用口径）。
2. 温度来源：物品实例读实例物温（现 itemInstances.temperature）；环境中的材料读卷二十环境温度。不再有全局 refTemp=20 的静态物态；refTemp 只保留为“装载时对未放入世界的模板做显示/校验用的参考温度”，规则层不得据此判逻辑——若做不到不用，就删 refTemp。
3. 依赖物态的类别：凡现行以“常温物态”为条件的类别（class_liquid、class_solid、class_formed、bulkForm 校验、蜡脂排除气体等）改为读当时物态；物品模板的 bulkForm 校验改为“在其设计使用温度区间内为固”，区间是模板数值，不写死。
4. 冰：不新增材料，冰 = 水在 tempC < 0 时的状态；冰的密度、承力等取水的 solid 栏。
5. 蜜结晶、蛋整只按壳判等同类：按全集 4.3 两条在乙卷物品层通用规则处理（组为固的外壳优先等），不加特例。
