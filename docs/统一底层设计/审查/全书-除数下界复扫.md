# 全书除数下界复扫（11-13）

范围：`F:/dnd/docs/统一底层设计/卷*.md` 现行各卷（不含 版本快照/、审查/、素材包/；已封卷各卷在内）。只读，没有运行脚本，没有改卷。

起因：`全书-除数下界扫描.md` 漏收卷二十两处（`卷五卷二十-封卷核.md` F-1）。漏的原因有两种：一是除数是"若干项之和"，扫描时没逐个看分母会不会合计为 0；二是除法没有写成"÷"，而是写成"加权平均""按权重分""占……的份额""均值""之比""归一"。本次专找这四类：
- 甲：除数是若干项之和、合计、总量、份额和、权重和；
- 乙：比值或分数（fraction、ratio、share、占比、均值之比）的分母；
- 丙：除数是上一步算出的中间结果；
- 丁：除数是计数（条数、人数、天数、样点数）。

搜法：逐卷 Grep 了 `÷`、`除以`；`加权平均`、`质量加权`、`加权和`、`按……权重／份额／比例分（给、配、摊、割）`；`平均`、`均值`、`人均`；`占……份额／比例`、`之比`、`比值`、`……比例 =`、`……率 =`、`归一`。每个命中都回原文看了分母有没有正下界或为 0 分支。判据与上次相同。

**只列上次没有列出的新命中**，上次已列入"无下界"或"有保护"的行不再列。另有两行不属于四类，是复扫时顺带看到的，在表里标"顺带"，计入小计。

建议改法只从全书现成写法里选：
- 为 0 分支：卷十九:125"各料质量之和为 0 时……不做除法：`material` 为空"；卷二十:671"两者之和为 0 时不做除法，取 0"；卷二十五:443"容量之和为 0 时覆盖度取 0"；卷二十六:491"最大值为 0 时不做除法，同样整项不计入"；卷三乙:1170"没有任何一份料带档位时该项为 0"；卷六:821"需要量为 0 的……不适用：不做除法"；卷六:1242"为 0 的……这一期不报"；卷六:775"求职工时为 0 时……取曲线上人手最紧的那一端并记缺口"；卷二十一:620"D0 = 0 → 不适用：不建实例、不求值"；卷二十一:1081"`max(平均病程, 一拍)`"。
- 取值域下限加载校验：卷五:588"`shareWeights` 各项……取值域下限大于 0，加载校验；x 自己在求和之内，所以除数恒为正"；卷四:129 `sexes`"权重非负、和 > 0"；卷二十七:137 `seedSampleSize`"≥8，加载失败"；卷十四:534"轮廓非空，加载校验"。
