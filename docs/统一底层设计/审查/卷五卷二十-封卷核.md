### F-1 卷二十除数下界两处，扫描漏收 —— **新真问题，需报李白**

不是本批改动带出来的，是复查同类时发现的。类别：7（机制性漏洞，0 作除数）。第 ① 处同时属于类别 1（式子缺项）。

1. **随风蔓延的权重合计可能为 0**（§4.7.3 第 3 条，第 737 行）。式子是"前几份各为 `蔓延出 × 权重 ÷ 权重合计`"。不随风的场，各目标权重相同，有目标时合计为正，没有目标时蔓延出为零，没有问题。随风的场，原文只写了"按各目标方向与 `env.windDirDeg` 的夹角加权，顺风与逆风的权重比为 `rules.fields.windBias`"，问题有两个：一是夹角到权重的函数没有写出来；二是 `windBias` 没有登记取值域（§2.9 第 325 行只写了含义）。`windBias` 取 0，或者权重在 10⁴ 下截成 0 时，如果全部合格目标都在逆风侧，权重合计就是 0。扫描的方法是搜"÷"，这一处本该命中，但它既没有列进卷二十的三行，也没有列进"有保护"那一段。
   - 建议改法：一句话写出夹角到权重的函数（例如顺风权重为 1、逆风为 `windBias`、中间按夹角线性插值）；`windBias` 登记取值域下限大于 0，加载校验；另补一句"权重合计为 0 时按不随风的等权分配"，或者规定权重在 10⁴ 下的下限不为 0。两种写法都是全书现成的。
2. **`iceFraction` 没有写出式子，干涸的水体会出现 0 ÷ 0**（§4.6.1 第 671 行，§4.6.3 第 4 条）。`iceFraction` 被列为派生量，卷十七封冻禁航要读它，第 700、860 行的实例也读它，但全卷没有给出算式。按字面意思，它是"冰 ÷ （冰 + 液）"。冰和液两个账户都为 0 时（塘干了，又没有冰），这就是 0 ÷ 0，与扫描列出的液体余额那一处同型。因为原文里没有"÷"字样，扫描抓不到。
   - 建议改法：在 §4.6.1 派生量的括号里补上 `iceFraction = 冰余额 ÷（冰余额 + 液体余额）`，并写明两者之和为 0 时取 0（没有冰，不封冻）。

两处都是一句话的补写，不新增设计。按"二审余项常规"，可以只改这两处，再由 Opus 单核一次。
