## 二、真问题

**P1 三参数 id 的父段“群体 id 后接对象 id”没有定义，唯一性无法保证**（R16-4.8 :527）
- 确定性：成立。位次 `idslot_lore` 的 `clocked` 为假，时刻段恒取 `genesisMinute`，序位恒为 0，同一（群体, 对象）每次得到同一 id。
- 唯一性：没有依据。
  - 卷十 R10-12.1 与卷二十七 R27-8.9 规定，`instanceIdOf` 的父段是“主体 id”，也就是一个实体 id。两卷都没有定义复合父段，也没有定义“后接”怎样拼接。
  - 全书只在骰值键的对象段用过“后接”，例如卷十六 :805、:851 与卷二十六。卷二十六 Q12（:1528）为此请卷二十七在文法里补一条“对象段可为主体 id 后接限定成分”，卷二十七至今没有落实（全卷 0 处“后接”）。
  - 实体 id 的字符集含 `_`，长度也没有固定。不加分隔符直接拼接时，两组不同的（群体, 对象）可能拼出同一个字符串。A10-12.2 要求不同父段导出不同 id，这一点因此得不到保证。三参数父段与单参数父段（对象 id）之间是否一定不撞，同样无从证明。
- 与 R22-4.6 一致：调用形状、对象解析为空则不铸、群体就是聚合体（R22-5.7，聚合体 id 永存）都对得上。与卷二十七 X5 没有冲突：本名键号只管个人的身份键，不涉及知识行 id。
- 改法有两种，都只动一处：
  - 甲：在 R10-12.1 或 R27-8.9 单点定义“父段可以是两个 id 用内核分隔符 `|` 连接”。卷二 §1.10 规定各部件不含 `|`，所以这样拼接是单射，也不会与单个 id 相撞。这一改顺带回答卷二十六 Q12，属封卷后勘误，须李白定。
  - 乙：只在 R16-4.8 写明用 `|` 连接并说明理由。
  - 依“根本口径单点定义不准记账”，建议取甲。

**P2 “所信取值”可能落在 `loreClaims` 的取值域之外**（R16-4.8 :527 与 :171、:283）
- `loreClaims` 每一项的 `dim` 必须在 `lore.claimDims` 内，`value` 不能越出该维度的取值域，否则报 E-BST-LORE-SHAPE（error）。
- R22-4.6 对“以物种、具名个体、地点为 subject 的任一命题”都会触发。命题所说的维度可能不在 `claimDims` 内；个体取值的命题，按卷二十二 N1 存的是身份键。
- R16-4.8 写的是“直接取该群体所信的取值”，两卷都没有说维度不在域内时怎么处理。这样铸出的行会违反本卷自己的形状校验。
- 改法：在 R16-4.8 补一句——所信命题的维度不在 `lore.claimDims` 内或取值越域的，不铸；所信取值写成一项 `{dim, value}`。R22-4.6 只需引用这一句，不必改。

**P3 C16-11 “周期日规则行不再使用”与年锚甲裁定是同类残留**（:1013）
- 这句是二审 T1“不用年锚”方案留下的。照甲裁定，卷十五 `awakenYear` 仍按年锚周期日运行；本卷 :45 与 R16-9.2 也写明状态行的档条件读周期日（月相一类）。这句现在与两处都相矛盾。
- 依“收卷前清同类”，应与 C16-6 同批改掉，例如改成“本卷年钩子 `transformYear` 不用周期日规则行”。修订表 T1 的历史行不改。
