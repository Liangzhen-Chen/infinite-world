# 卷三甲第二版、卷四第七版：文献值上网核对

范围：卷三甲 §4.5.5 全集表的干基饱腹（干基总能）、自燃点、闪点、极限氧，§4.5.5 依据表里的折算常数，卷三甲卷末“实得能量核对脚本输出”里的“真实参考”一栏；卷四 §4.7.5 各食性的 assimilation。没有改动任何卷文件。

判定口径：
- 出处只给一个值时，相差不超过 15% 算一致；出处给了范围时，落在范围内算一致。相差超过 15%，或者超出出处范围（哪怕只超一点），都算偏差。
- 出处只给下限（例如“>400”），或者几个出处互相矛盾、给不出一个可比的值时，记“未核到”。
- 我自己用出处数据算出来的值注明“按出处重算”。成分来自 USDA SR Legacy，燃烧热用依据表里的常数：蛋白 23.6、脂肪 39.3、淀粉/碳水 17.5、乳糖/蔗糖 16.5、葡萄糖与果糖 15.6 MJ/kg。这些常数已在 A0 表核过。
- 假想料（鬼火油、月华浆果）和测试行（测试爆燃料）不适用，不计入小计。
