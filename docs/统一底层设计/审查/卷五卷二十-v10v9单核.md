## 三、扩展标度误差界的确定式（逐项手推复核）

- **`persistence` 每日写入**：`e(a×g) = B(g) + B(a) + 1`；`e_r = e(a×g) × B(f) + 1`；`e_u = e_r × B(c) + 1`；`e(p(1−p)) = 1`，取界 1/4；`ε日 = ⌈e_u/4 + B(u) + 2⌉`。与递推一致。
  - `G_n` 只取了偏导的正侧 `1 + B(u)(1 − 2p + …)`。`u > 2`（数据把 `growthFactor` 或恢复系数调得很大）时，负侧 `|1 − u(2p − 1)|` 可以大于 1。不过这时 `u × p ≥ 1`，定点值与参考值都被钳到 1，实际不超界（小项 2）。脚本单独数了这种写入的次数。
- **`persistence` 取用写入**：`ε取 = ⌈(2 × taken + 1) ÷ K + 1⌉` 正确。`K` 为 0 的分支不做除法。
- **`development`**：`m发 = ⌈2 + δ(均值 E + 1)⌉`；`G = max(|1−ρ|, |1−ρ−δ|)`；联合递推 `Ê ≤ (G+δ)Ê + ⌈2+δ⌉`，在 `G + δ < 1` 时有与天数无关的界。我核过，这个式子不比递推紧。
- **`control`**：每日 `E = (1−κ)E + 1`，易主时 `E = λE + 1`。段内上界 `max(段首 E, 1/κ)` 正确。
  - `κ = 0` 时，卷中写"E 不超过易主次数"，而按卷二的递推是每日 +1（`fixedMultiply8(0, x)` 照规则也计源误差 1）。确定式比递推紧，违反卷二"不得比递推紧"（小项 3）。实际误差确实是 0。
- **场强度**：`fixedPow` 的 `p_j = 2j − 2`，对 `j` 归纳成立（底数不大于 1）；`e读(j)`、`e压 = quenchPerMm + 1`、`e出`、`e分 = 2e出′ + T − 1`、`e入`，以及 `G = |d^k − d^(k−1) × rate| ≤ 1` 都正确。
