## 真问题

**N5　除数没有正的下界：R、D 可以为 0，确定式失效，运行时也会除以 0**　新真问题，需报李白
- 位置：382 行（“R_n⁻ 须为正”只是一句话，没有对应的检查）；778 行（R21-6.2 分母 `D−e_D·10⁻⁸`，对 D 是否为正一句没写）；616–620 行（R21-4.1 只处理 D0=0 的情形）；163、239 行（`refDose>0`，没有下界）。
- 类别：7（这时写入没有界，断言没法交给机器判定；运行时除以 0）。另有 4：卷二⑪新加的要求“凡作除数的量，取值域必须登记正的下界，或由式子保证为正；L 不为正的，这次写入没有界，判为不合格”（卷二 1121 行），第八版没有落实。
- 证据：
  - R：本卷自己的实例 `bneed_reserve` 的 `reserveDaysRX = subject.fatKg × fatSatietyPerKg ÷ need0`（679 行）。卷四 `fatKg` 的取值域是 ≥0（卷四 193 行），onUnknown 为 gap。体脂为 0 的主体 D0>0、需要适用，却有 R=0，`drv=…÷R` 就是除以 0。本卷只处理了 D0=0 一种情形。
  - D：`D=refDose×massPow`。`refDose` 只要求 >0，最小可以到 10⁻⁴；`massKg` 的取值域是 ≥0（卷四 182 行）；`massExp` 最大可以取 2。例如 `massExp=2`、体重 5 克、`refDose=0.0001`，D=2.5×10⁻⁹，定点截断后为 0，Δconc 就是除以 0；即使没截到 0，D⁻ 也不为正，按卷二⑪这次写入没有界。
  - 是改动带出来的：第七版就有这两处除法，但“除数必须有正的下界”是⑪新立的要求。第八版写了“R_n⁻ 须为正”，却没有机制来保证；对 D 则什么都没写。
- 建议改法（只动单点，不加栏目）：
  - R：在 R21-4.1 那一处补一句，例如“R 的定点值不超过 e_R 个单位时，与 D0=0 同样处理（这项需要对 x 不适用）”；或者在加载期按取值域区间求 `reserveDaysRX` 的下界，必须大于 0，否则报 E-MED-NEED-CYCLE。
  - D：在 R21-6.2 补一句同样的规定，例如“D 的定点值不超过 e_D 个单位时本次摄入不求浓度”或报错。也可以给 `refDose×massPow` 登记一个下界：给 `massKg` 设摄入的最小体重，放在规则表里。
  - 选哪一种属于玩法取向（不适用、钳到下限，还是报错），交李白定。改完后补两条验算或断言（R=0、D 很小），只核这一条即可。
