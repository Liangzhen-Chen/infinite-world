### 1.2 修法（整类判据，不按行号或名字写特判）

以卷二十四表 B 定的登记位为准：动词行由登记卷自己登记，登记处是该卷的 §2 或代号表。别卷的登记、本卷订阅别卷的动词、指向本卷另一节的指针，都不是登记行本身。

- **读者侧与请求侧节**：三级节名是"本卷读取/使用""需（要）/须别卷配合""回填请求""各卷指给本卷"的，不作登记处。编号请求行判据（REQROW）同时认一两个汉字前缀加编号的首格（如"勘11"）。
- **引用判别**（B 散文登记句式与 C 散文句式命中后再判；一行里所有命中都是引用时，这行不作登记处）：(甲) 他卷归属：命中所在分句里，命中之前点名了别卷（不是本卷，也不是该表的定义卷），命中之前没有"本卷"，分句里也没有"本卷登记/由本卷登记/本卷发出"；(乙) 他卷注释：命中落在"卷X[ §n]（……）"的括注里，X 不是本卷；(丙) 订阅：命中所在句写"订阅"，又没有本卷登记或本卷发出的说法。表 C 表格行首格的结构判据不经这道判别。
- **指针**："动词由本卷登记，§n"或"本卷登记的 verb 族条目/事件动词/动词行（§n）"，登记单元在指针行之外再加上被指的那一节。被指的节里已经有上面报过的登记单元时，并入那个单元，不另计。指针只认对象是动词的写法："本卷登记到表 B 的字段，§2.1"这种说的是字段，不按指针处理。
- **已撤销**：登记卷里写到该代号的每一句都含"撤销/撤下/删去/退役/作废/废止"的，列"已撤销"，不计数。
- **模板前缀**：以 `_` 结尾的代号是命名前缀，列出来但不单独成一个单元，跟同族的具体代号一起核。这与盲区扫描 `norm` 里"前缀"的口径相同。
