R23-4.3 的写法是“提交事件 id | 演者 id”：

- 主体是确定性派生的事件 id，在 R27-8.5 上款所列的 id 范围内（R27-8.9）。
- 限定成分是演者 id，属于实体 id。
- 只有一个限定成分，没有计数。

两边一致。R27-8.9 父段（:687）也已改为指向 R27-8.5，引用链没有断。
