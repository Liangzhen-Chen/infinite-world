# 卷十九 建筑与设施 第一轮审查 A

审查员：claude-opus-5-5 中档，11-13。审查对象：`卷十九-建筑与设施.md` 第一版（1068 行，整卷读完）。
已读：审卷须知；写卷须知全部补充裁定（含"设施类型由派生得出"，按此不把派生类型本身记为问题）；台账卷十九小节、X-26/X-29/S-18/S-20/N-06、第五节；素材包；卷五 §2.1、§3.3、§4.1、§4.5、§4.6、§4.13；卷三 §2.1、§4.1、§4.5–§4.8、§4.11；卷二十 §2.7、§4.5；卷二 §1.9、§1.12、§2.1、§2.6、§5.0、§5.7。

重点三处的结论：
- 自洽：类型、功能量、运营水平三者成环；建造用料与墙厚的关系前后相反；房间行拿不到建筑的围合变化，"屋漏连带腐坏"这条链断了。
- 跨卷归属：与卷五，缺建筑的进入门槛缺省档；与卷三，导热、隔声两个材料维度已经登记但本卷没有用，护甲系数被本卷自行解释，品质滚档另抄了一套常数。
- 北极星：三方都进入了产物，方向是对的。但"材料→墙体"这一环推反了，"技能→产物"的对照断言机器判不了，"进入权即可开工"让意图一方可以绕过。
