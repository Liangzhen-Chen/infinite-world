# 卷三 推不出类别清单（交李白定）

对象：`卷三-物品与材料.md` 第四版（快照 `版本快照/卷三-v4.md`）。第四版里材料与物品的 `class` 族类别一律派生，行上不手写，也没有任何显式指定的通道。本清单列出按现有维度推不出正确类别的材料，每条写明拟补的维度或拟改的推导规则。正文没有替它们另想办法，裁定后再动正文。

现有的派生来源只有两条（卷三 M-9）：

1. 材料大类类别：`categories` 各条目的 `materialClass`（金属、木质、矿物粉料等）。
2. 常温物态类 `class_solid`、`class_liquid`：`meltPoint`、`boilPoint` 与 `rules.thermal.refTemp` 按 T-2 求出的常温物态。

## 一、结论

卷三出现的材料共 24 种。逐种核对的结果：

| 结果 | 种数 | 材料 |
|---|---|---|
| 推得出 | 6 | `mat_wrought_iron`、`mat_cold_iron`、`mat_test_alloy`、`mat_stoneware`、`mat_resin`、`mat_ghost_fire_oil` |
| 推不出 | 17 | 见第二节 |
| 无法判断 | 1 | `mat_test_blast`（扩展性测试 E-3 只说它挂爆燃组件，没给形态与熔点；按它实际填的行落入上面某一类） |

推不出的 17 种归为 3 类缺口。缺口甲 15 种，缺口乙 4 种（其中 2 种同时属于甲），缺口丙 3 种（3 种都同时属于甲）。

说明两点。第一，卷三里多数材料只在物品的 `material` 里被引用，没有给出完整的材料行，"推得出"指按它的物性如实填写后推得出，例如陶器要填 `meltPoint`。第二，缺口是按类出现的，别卷的同类材料（各种木、皮、布、纸、谷物、粉料）同样受影响，种数会随内容增加，所以应按缺口修，不按材料修。

## 二、推不出的材料

### 缺口甲：受热不熔的固体，常温物态求不出（15 种）

这些东西受热不熔化，而是炭化、分解或直接烧掉，所以如实填写时没有 `meltPoint`。T-2 拿当前物温同 `meltPoint`、`boilPoint` 比，缺了 `meltPoint` 就得不出"常温为固"，`class_solid` 不成立。后果是 `strength`、`sharpnessMax`、`wearResistance`、`armorMult` 四项对它们成了不适用（这四项的必填条件是 `byClass:class_solid`），而竹刀要锋利上限、皮甲要防护系数。

| 材料 | 大类 | 该有的类别 | 现在推出的 |
|---|---|---|---|
| `mat_bamboo` | 木质 | 木质类、固体类 | 只有木质类 |
| `mat_oak` | 木质 | 木质类、固体类 | 只有木质类 |
| `mat_elm` | 木质 | 木质类、固体类 | 只有木质类 |
| `mat_wicker` | 木质 | 木质类、固体类 | 只有木质类 |
| `mat_charcoal` | 未定（见缺口丙） | 固体类 | 无 |
| `mat_bamboo_charcoal` | 未定（见缺口丙） | 固体类 | 无 |
| `mat_thunderstruck_char` | 继承木炭 | 固体类 | 无 |
| `mat_leather` | 皮革 | 皮革类、固体类 | 只有皮革类 |
| `mat_rawhide` | 皮革 | 皮革类、固体类 | 只有皮革类 |
| `mat_sheepskin` | 皮革 | 皮革类、固体类 | 只有皮革类 |
| `mat_silk` | 织物 | 织物类、固体类 | 只有织物类 |
| `mat_hemp_cord` | 织物 | 织物类、固体类 | 只有织物类 |
| `mat_paper` | 纸 | 纸类、固体类 | 只有纸类 |
| `mat_dry_grass` | 植物 | 植物类；固体类见缺口乙 | 只有植物类 |
| `mat_tea_leaf` | 植物 | 植物类；固体类见缺口乙 | 只有植物类 |

拟改法（二选一，建议第一种）：

- **补一个维度 `decomposePoint`（分解点，摄氏度）**：受热不熔而分解、炭化的温度，同 `meltPoint` 并列。T-2 改为"物温低于已有的熔点与分解点中较低的那个 → 固"。再加一条校验：每种材料的 `meltPoint` 与 `decomposePoint` 至少填一个，这样每种材料都有确定的常温物态，不再有求不出的情形。这个维度对烧制、烘焙、炭化也有用，属于通用物性。
- 不加维度，改 T-2 用已有的 `heatDamagePoint`（热损点）代替缺失的熔点。坏处是热损点的含义是"开始受损"，金属也有热损点且低于熔点，一个量担两个意思，以后容易算错。

不建议的做法："没填熔点就当它是固体"。气体同样可能没填熔点，会被错判成固体。

### 缺口乙：松散料与成形固体分不开（4 种）

`class_solid` 现在同时担着两个意思："常温是固态"和"成块、能受力，所以要填强度、锋利上限、耐磨、防护系数"。粉、粒、散叶是固态，却不成块，不该填这四项。

| 材料 | 现状 | 问题 |
|---|---|---|
| `mat_black_powder` | 没填熔点，所以不是固体类；粉料类由"矿物粉料"大类给出 | 结果碰巧对。一旦如实补上熔点（硫 115 度就化），它立刻变成固体类，被要求填强度 |
| `mat_halite` | 岩盐有熔点（约 800 度），推出固体类 | 作为食盐是散粒，被要求填强度、锋利上限、防护系数 |
| `mat_dry_grass` | 属缺口甲 | 缺口甲修好后它会变成固体类，被要求填强度 |
| `mat_tea_leaf` | 属缺口甲 | 同上 |

另有一处同根的问题：粉料类现在挂在"矿物粉料"这个材料大类上，把"是什么成分"和"是什么形态"混成一项。铁屑、面粉、木屑都是粉，却各属金属、谷物、木质，推不出粉料类。

拟改法：

- **补一个维度 `bulkForm`（聚集形态）**，枚举，新词表族 `mform`，首批四项：成块、纤维片材、颗粒、粉末。它是材料自己的物性，必填。
- 派生规则相应改两条：`class_solid` 改为"常温物态为固，且聚集形态是成块或纤维片材"；`class_powder` 改为"常温物态为固，且聚集形态是粉末"，不再由"矿物粉料"大类给出。"矿物粉料"这个大类可改名为"矿物"，只表示成分。
- 如果嫌一个固体类担两件事仍不清楚，可再拆出一个"承力固体"类专管那四项必填，固体类只表示物态。这一步要改卷二 §5.2 的必填条件，建议一并定。

### 缺口丙：大类词表里没有它的位置（3 种）

| 材料 | 问题 |
|---|---|
| `mat_charcoal` | 材料大类十六项里没有"炭"。放进木质，就派生出木质类，于是木炭能拿去修竹器（竹的修理用料类是木质类），不对；不放进任何大类，又违反 `categories` 必填 |
| `mat_bamboo_charcoal` | 同上 |
| `mat_thunderstruck_char` | 继承木炭，同上；它另带超自然子类，那一条推得出 |

拟改法：在 `matcat` 词表加一项"炭质"（代号拟 `matcat_char`），条目带自己的 `materialClass`。这是加数据，不加维度，也不改规则。若李白认为炭应当由属性推出而不是另立大类，可改为按"是某个炭化反应的产物"推出（读 `reactionProducts` 的反向关系），代价是材料类别要读别的材料行。

## 三、顺带发现：物品一侧同样推不出的类别（不计入上面的种数）

任务点名的是材料。改写过程中，物品一侧有几处原先手写的类别删掉后没有派生来源，一并列出，供同批裁定。

| 情形 | 现状 | 拟改法 |
|---|---|---|
| 鱼肉同别的肉分不开 | 鱼露配方的第一项只能写到"肉类"大类，羊肉也能做鱼露 | `matcat` 加子项"鱼肉"，`broader` 指向肉类；卷四 `diet_piscivore` 的 `feeds` 同样要靠它 |
| 胶料 | 符墨配方的粘结料暂写成"蜡脂"大类，蜂蜡对、骨胶反而选不到 | 补材料维度 `adhesion`（粘结力，score），胶料类按阈值派生 |
| 料坯同成品分不开 | 修理用料类原写"金属料坯"，现改成金属类，于是一把斧子也能当修理用料 | 物品的料坯类由"它是某种材料的 `rawForm`"派生（读已有关系，不加维度）；`repairedWith` 改指料坯类 |
| 货币的经济大类 | 铜钱按材料与功能会派生成金属原料 | 由卷六登记功能维度 `denomination`（面额），`categoryRules` 加一条"有面额 → 货币" |
| 非经济物的经济大类 | 没有哪条功能维度能表示"不进经济" | 需李白定：补一个功能维度（例如不可让渡），还是取消"非经济物"这一类、让它们因无人出价而自然不流通 |
| 原先手写、现已不带类别的物品类 | 手工具、筐篮、挽具、成衣、配件、书、饲料、饮料叶、节庆物、腌菜 | 目前没有规则读这些类别，所以没补派生条目；别卷若要用，各加一条 `rules.items.classRules`。其中手工具（有能力且挂工具组件）、成衣（可穿戴且合人形身体图）、书（可读且文书种类为空）、饲料（用度类按每畜计）现有维度就够；筐篮、挽具、节庆物、腌菜现有维度不够，用到时再报 |

另记一项不属于类别的同类问题，供参考：来源方式 `sourceMode` 在卷三 C-2 里仍保留"规则未命中时实体行显式写值"的写法（卷二 §1.6 末条）。它不是类别，本轮裁定没有点到，正文未动；是否一并取消请李白定。

## 四、请李白定的事

1. 缺口甲：补 `decomposePoint`，还是改用 `heatDamagePoint`。
2. 缺口乙：是否补 `bulkForm`；固体类是否拆成"物态"与"承力"两个。
3. 缺口丙：炭另立大类，还是按反应产物推出。
4. 第三节各项是否同批处理；`sourceMode` 的显式写法是否一并取消。

## 五、卷三甲第二版补记（2026-11-13，claude-fable-5-2 中档）：菌类的本源成分推不出

来历：卷三甲一审第 11 条指出本源成分不得"借记"。牛粪饼已改记动物产物；酒、醋、烧酒是水溶液，按溶剂记水是事实。剩下一行按现有十二项填不对：

| 材料 | 现值 | 为什么不对 | 留空行不行 | 拟改法（请李白定） |
|---|---|---|---|---|
| 夜帽菇（卷二十一登记的菌类） | 草本植物质 | 菌类不是植物；"草本植物质"的定义是非木质的草本组织（叶、茎、籽、果） | 不行：它可食、可腐、不可燃，一条派生大类也推不出，留空即身份落空（卷三乙 M-9） | 甲：本源成分加第十三项"菌"（改核心词表，须裁定）；乙：把"草本植物质"一项的定义放宽为"非木质的植物与菌类软组织" |

裁定前卷三甲全集表里这一行保留现值，备注标明未决（卷三甲 §8 Q-A9），不作为任何规则的正例。它现在的后果：食草食性的 `eats` 对它成立（牲畜会吃蘑菇，符合实际），谷物大类因含水率高进不去，没有推错。
