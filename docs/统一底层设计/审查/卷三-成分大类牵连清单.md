# 卷三第六版（成分大类与选材组合）牵连清单

依据：李白 11-13 对十六项手写"成分大类"的裁定；`审查/卷三-补维度终核.md` N-1 到 N-4；`审查/全书同类-选材与组合.md` 里属于卷三的条目。卷三已改完（快照 `版本快照/卷三-v6.md`）。下面是别卷里引用到被改内容的地方与建议改法。**别卷一字未动**，行号是 11-13 扫描时的行号，改时请按原文定位。

扫描范围：`卷*.md` 除卷三外的 14 卷。扫描词：`matcat`、成分大类、材料大类、`categories`、`acceptsMaterial`、`substitutePool`、`substituteKey`、`materialCompMin`、`charYield`、`allowedMaterials`。卷八b、卷十五等尚未成卷的，只在第三节列出成稿时要遵守的接口。

## 卷三这次改了什么（别卷据此判断）

1. 材料表新增基础维度 `substance`（本源成分，封闭十项：`subst_metal`、`subst_stone`、`subst_mineral`、`subst_glass`、`subst_wood`、`subst_plant`、`subst_fiber`、`subst_hide`、`subst_bone`、`subst_flesh`），只在材料行上填，可空。它不是类别。
2. `matcat` 族只剩派生大类七项：`matcat_char`、`matcat_wax_fat`、`matcat_grain`、`matcat_textile`、`matcat_paper`、`matcat_ceramic`、`matcat_supernatural`。材料的 `categories` 改为纯派生，任何行不许手写。
3. 旧代号去向：`matcat_metal`→`subst_metal`；`matcat_woody`→`subst_wood`；`matcat_stony`→`subst_stone`；`matcat_mineral`→`subst_mineral`；玻璃→`subst_glass`；`matcat_plant`→`subst_plant`；`matcat_leather`→`subst_hide`；骨角→`subst_bone`；`matcat_meat`→`subst_flesh`；`matcat_liquid` 撤销，改读 `class_liquid`。织物、纸、陶瓷、蜡脂、谷物、超自然的代号不变，但成员改由规则推出。
4. 需求块候选项可以只写 `where`（任意材料加属性谓词）；`matcats` 选择器只收派生大类。
5. `acceptsMaterial` 由大类名单改为 `map<材料组, RX>`。
6. 物品的 `substitutePool` 改派生（池集合，可一物多池），`substituteKey` 撤销；`pool` 条目加成员条件 `when`；`class_fuel`、`class_salt` 不再读用度类。
7. 材料的物理行为（起火、燃烧、爆燃、腐坏、受热变态）逐份触发；`materialCompMin` 只管"能不能当这一类东西用"。受热起损点按各份材料的变态点取最小值。
8. 聚合表登记 `pharm`、`agents`、`soilNutrient` 为 `sum`；别卷新增材料数值维度必须登记聚合口径。
