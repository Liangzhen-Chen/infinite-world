## 五、小项（只记账）

4. `check-卷三-实得能量.mjs` L91–92 的注释过时；`check-卷三.mjs` 没有补第七版锚点的注释行。
5. 豁免引用里有两处节号不符：乙 361 引"§2.3"，甲 108 引"§2.2"。
6. 第七版没有引出新矛盾，但顺带记一句：`dmean` 的理由（"占干物质的量，按湿重加权会多算"）同样适用于 `energyDensity`、`heatValue` 这两个按干基填、在聚合表走 `sum` 的量。现行 L1655 的 `satietyTotal` 是逐份乘（1 − moisture），所以算出来是对的。这条是第六版以前就有的写法，不在本轮范围。
