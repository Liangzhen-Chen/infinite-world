## 三、真问题

### K1 卷二十七 R27-3.9 的授予途径比卷二十二窄，上界式会被突破（新，类 4，单点改 卷二十七:413）

- 现文：“这类边只经卷二十二 `grantLore` 新增（传授事件或研究产出 `grant`，R22-9.4），……故一个评档块内的增量 ≤ 块内这类授予的受者人次”。
- 卷二十二现稿：秘传 `knows` 边还可经阅读（R22-6.3，:509；:526 咒书例即秘文读通得持有边）、研究 `mint` 产出后 `grantLore`（R22-9.4，:631）、被授予（神授、开局，R22-10.2，:669）、承接者经 `carryKnowing` 重授（R22-10.8，:675）新增。卷二十二自己的性能登记（:826）写的是“只经 `grantLore` 新增（R22-10.2 四条途径）”，并声称“与其 R27-3.9 同一口径”——两处口径不一。
- 后果：按 R27-3.9 字面只数“传授事件与研究 grant”的受者人次，阅读、mint、神授、承接带来的钉住个体不在界内，上界不成立。
- 改法（单点）：括注改为“经卷二十二 R22-10.2 各途径，含阅读、研究 `grant`/`mint`、被授予、`carryKnowing` 承接”，增量界改为“块内对秘传行调 `grantLore` 的受者人次”。同时把卷二十二:826 的判据出处补进本条（见记账 1）。注：卷二十二 R22-9.6（:633）“只经 R22-10.2 的个体传授事件流动”措辞本身也窄于 R22-10.2，属卷二十二，转其作者。

### K2 卷三乙 §4.15.1 把 `contentRef` 写成“只指文字作品的显示内容”，与卷二十三和 11-14 裁定一不合（新，类 4，单点改 卷三乙:1557）

- 卷三乙:223 自己写 `contentRef` “含义归卷二十三”；卷二十三 :132、R23-1.1（:263）与 11-14 裁定一：`contentRef` 是 `ref knowledge`，指向一条“作”（知识表生成行，`workkind` 非空），适用于一切挂 `comp_work` 的载体（雕刻、画、曲谱都在内），不是“文字作品”，也不是“显示内容”。
- 新句等于在卷三乙重新给 `contentRef` 下定义且定窄、定错层（“显示内容”暗示显示层文字）。
