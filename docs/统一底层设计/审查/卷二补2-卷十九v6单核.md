### ⑧ fixedLn 与非整数次幂

- **逐位一致**：六步只用 BigInt 的加、乘、整除与比较，`W`、20 项、`LN2` 都是登记常数，没有浮点，也不查表。第 2 步的 `n` 只要按整数比较确定（如用位长），结果就是唯一的。两个平台只要都按 BigInt 实现，结果必定相同。
- **推导复核**：
  - 定义域 `X ≥ 1`，所以 `x ≥ 10⁻⁸`。`2⁻²⁷ ≈ 7.45×10⁻⁹ ≤ 10⁻⁸`，所以 `n ≥ −27`；`log₂(e⁴⁰) ≈ 57.7`，所以 `n ≤ 57`。
  - 第 2 步：`n ≥ 0` 时 floor 之后仍有 `W ≤ m < 2W`（`W` 是整数）；`n < 0` 时是乘法，没有丢位。
  - `u = (m−W)/(m+W) < 1/3`。级数截尾不超过 `2u⁴¹/(41(1−u²)) ≈ 1.5×10⁻²¹`，小于 `2×10⁻²¹`。
  - 各次整除每次丢不足 1 个 10⁻¹⁸。`p` 每轮乘上 `t2/W < 1/9`，先前的误差随之收缩，总量远小于 10⁻¹⁵。
  - `|n|×LN2` 的截断不超过 `57×10⁻¹⁸`，小于 `6×10⁻¹⁷`。
  - 第 6 步向零截断，丢不足 10⁻⁸。合计小于 `2×10⁻⁸`，与附录 E 实测最大值 1.0×10⁻⁸ 相符。
  - 边界：`fixedLn(1) = 0`；上端返回 3999999999，不超过 40。
- **`fixedExp` 的界 `5×10⁻⁸y + 4×10⁻⁸`**：
  - 相对误差的来源：插值本身的误差 `h²/8 = 7.45×10⁻⁹`，`expFrac` 截断不超过 10⁻⁸，插值截断不超过 10⁻⁸，合计约 2.75×10⁻⁸，小于 5×10⁻⁸。
  - 绝对误差的来源：`expInt` 截断带来的绝对误差不超过 `e×10⁻⁸`，加上末次截断 10⁻⁸，合计约 3.72×10⁻⁸，小于 4×10⁻⁸。
  - 结论：这个界成立。
- **非整数次幂的界 `(2|k|+7)×10⁻⁸×y + 4×10⁻⁸`**：
  - 指数入参的误差 `δ ≤ (2|k|+1)×10⁻⁸`，推导正确。
  - 但从这里到 `y` 的误差，用的是线性近似 `y(e^δ−1) ≈ yδ`。界里多留的"一个单位"只能盖住二阶项 `δ²/2`，前提是 `δ` 不超过约 1.4×10⁻⁴，也就是 `|k|` 不超过约 7000。
  - 正文对 `|k|` 没有任何约束，只要求乘积落在 [−40, 40]。反例：`x` 贴近 1、`|k|` 很大时，`fixedLn` 一个最小单位的误差会被放大成指数里的大偏差，这个界不成立。
  - 结论：缺前提。见新真问题 2。
