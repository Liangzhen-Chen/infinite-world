## §1 领域总述

### 1.1 真实世界怎样运转

1. **气质相对稳定，且各维相关。** 胆大的人多半不谨慎，勤勉的人多半有节制。群体（物种、文化）只移动分布的中心，不决定个人。
2. **价值是后天的。** 人从所处文化继承一套"什么要紧"，再按自己的气质偏离一些。
3. **需要不止于吃睡。** 长期无人说话、无事可乐、所处环境丑陋、无处敬神，人都会难受，只是难受得慢。
4. **心情是被推着走的量。** 每件事推一下，推力随时间消退，同样的事重复发生推力递减；同一件事落在不同人身上，推力大小甚至方向都不同。
5. **长期难受会积成压力，压力过线人会失常。** 失常有轻重，重的若无人照看会要命。
6. **心情很好时偶尔有超常发挥。**
7. **临阵的斗志是另一个量**，受伤亡、指挥、同伴去留左右，与平日心情相关但不相同。
8. **人不是最优化机器。** 同样处境下的选择有随机成分，心乱时更随机。

### 1.2 本作现状

- 人格：`world/people/baseline.json` 的 `personality` 是 `{traits, values, flaws}` 三个中文自由文字数组（281 处）。`duels.mjs:19`、`npc-crime.mjs:42`、`nation-founding.mjs:223` 把它序列化后用中文关键词正则打分，分值 25/20/30 为手填（调研 06a 第 95 行；06b 第 211–213 行）。`npc-cognition.mjs:40` 用 `flaws` 文字决定转述是否省略数量（06b 第 214 行）。`finance-assets.mjs:82` 读一个未定义来源的风险厌恶数（待核）。
- 心理需求、想法、心情、压力、崩溃、疯狂、灵感：无实现。`mood` 只见于 `pets.mjs` 与 `weather.mjs`。
- 士气：只在军团级（`military.mjs`、`war-diplomacy.mjs`，15 处）。
- 身体需要：已实现，入口分散（归卷二十一）。
- 调研 09：3.10 部分；8.4 部分；2.4 已实现但只含身体需要。

### 1.3 本卷的总机制（一句话：三种数据行加一条推进规则）

```
人格 personality ─┐                                    ┌→ 容器档上的修正项 ─→ 任何已登记的修正键
价值 values ──────┼→ 想法行 thought ─→ 心理量 gauge ───┤   （驱力权重、决策噪声、身体能力、技能、过程槽）
偏好 preference ──┘     （推多少）       （容器实例）   └→ 发作行 episode ─→ 另一个容器实例（崩溃、疯狂、灵感）
事件、现状、身体状态 ─→ 想法行的触发                         驱力权重 + 噪声 ─→ 卷九决策管线
```

- **心理量 gauge**：一个 0–1 的量，存为一个心智类状态容器实例。心理需求、心情、压力、士气都是心理量，区别只在数据。
- **想法行 thought**：一条"在什么条件下、对哪个心理量、推多少"的数据。想法不落状态，由事件与现状算出。
- **发作行 episode**：一条"某个心理量落在某个区间时，按危险率触发一段有时限的失常或超常"的数据。崩溃、疯狂、灵感、奇想是同一种行。
- **推进规则只有一条**（R26-4.4），对全部心理量、全部个体相同。
- 心理状态影响行为只有一条路：容器档上的修正项，经卷二 §3.3（求值管线）求值。本卷不新增任何状态顶层键。

### 2.3 本卷登记的状态容器行

格式按卷二 §1.11（状态容器），本卷只登记行并遵守以下约束（校验码 E-PSY-GAUGE-STATUS）：

1. `target` 为心智类；`severity` 取值 [0,1]；`contagion`、`immunity` 为空；`severity.perDay` 为空（推进由 R26-4.4 给出，不由容器自带速率）。

## §3 统一入口

### 3.1 读入口

本卷不新增 view。心理读数是人物的一部分，一律经卷二 §2.1（入口清单）登记的 `personView`；容器实例经 `statusView`。

| 读什么 | 入口 | 返回 |

| 心理量当前值与档、活跃想法、进行中的发作 | `personView(engine,state,id).psych` | `{gauges: map<gauge,{severity, stage, input}>, thoughts: list<{thought, gauge, magnitude, eventRef?}>, episodes: list<{episode, status, since, picks}>}`，全部为代号与数值，惰性求值 |

## §4 子系统

### 4.1 人格向量与联合分布

#### 4.1.1 维度

读：`persInnate`、`personality`（§2.1）；pers 族条目；`personality_default` 联合分布；物种行与文化行的 `personalityBias`。

#### 4.1.2 统一入口

读：`personView().dims.personality`（修正后）与其 `base`（基值）。写：无常规写者，采样不落状态；永久改变只经 `persInnate` 的偏离行（§3.3）。

#### 4.1.3 规则

- **R26-1.1 先天向量的采样**（派生形状，纯函数）。加载期对 `corr` 做一次定点下三角分解 `corr = L·Lᵗ`（整数开方用卷二 §1.10（随机实例化）已有的牛顿法；任一主元不为正即 E-DIM-SAMPLE-CORR），结果冻结。对个体：按卷二 §1.10（随机实例化）的联合种子键取第 k 个标准正态数 `z_k`（k 为该轴在 `marginals` 中的声明序号）；`x = L·z`；`persInnate[k] = clamp(mean_k + sd_k × x_k, 取值域)`。全程定点。
- **R26-1.2 表达人格**（派生）。`personality[p] = clamp(persInnate[p] + Σ 已知的群体基线[p], [-1,1])`，群体基线来自主体物种行与文化行的 `personalityBias`；某一来源未知时该项不计入，不以 0 代替。
- **R26-1.3 暂时改变**只经修正项：任何来源（状态容器档、信条、传统、职位、附魔）都可以挂以 `person.personality[<轴>]` 为目标的修正项，由唯一管线求值。
- **R26-1.4 永久改变**只经 `persInnate` 的偏离行。本版不设自发漂移规则。
- **R26-1.5 分档只属显示层。** 规则只读数值；"胆大""怯懦"之类的称呼由显示层按语言包的档位表给出，规则不得读。
- **R26-1.6 轴的顺序只增不改。** 新轴追加在 `marginals` 末尾，并使表头的采样版本号加一。

#### 4.1.4 交互

- 卷四：物种行提供 `personalityBias`；人物本体提供物种与出生地。卷七：文化行提供 `personalityBias`。
- 本卷内：`personality` 供 §4.2 的价值派生、§4.4 的想法缩放、§4.9 的驱力与噪声。
- 别卷读者（卷九决策、卷二十二转述失真、卷十三决斗、卷八b 犯罪倾向、卷八建国、卷六风险取舍）一律读 `personView().dims`，不得自设人格字段。
- 通道：只读，不走账本、持有、事件。

### 4.2 价值与偏好

#### 4.2.1 维度

读：`valueOffset`、`values`、`prefOffset`、`preference`（§2.1）；pers 条目的 `valueLoad`；文化行的价值缺省值，轴词表见卷七 §4.25（价值轴词表）；文化对各类事物的偏好权重，经卷七 §4.28（文化偏好输出接口）。

#### 4.2.2 统一入口

读：`personView().dims.values`、`.preference`，`preferenceOf()`。写：无常规写者；永久改变只经 `valueOffset`、`prefOffset` 的偏离行。

#### 4.2.3 规则

- **R26-2.1 个人价值偏离的采样**（派生，纯函数）：对价值族的每个键独立取正态数，均值 0、标准差 `rules.psych.valueSd`，钳到取值域。
- **R26-2.2 个人价值**（派生）：`values[v] = clamp(文化缺省[v] + Σ_p valueLoad_p[v] × personality_p（基值） + valueOffset[v], [-1,1])`。文化未知则整项未知，按 `gap` 处置；某轴上没有 `valueLoad` 的人格轴不参与求和。
- **R26-2.3 个人偏好偏离的采样**（派生，纯函数）：对键域里的每个键独立取正态数，均值 0、标准差 `rules.psych.prefSd`；惰性按键求值，种子键的维度部件带上该键。
- **R26-2.4 个人偏好**（派生）：`preference[c] = clamp(rules.psych.prefCultureGain × f_c + prefOffset[c], [-1,1])`，`f_c` 是文化对 c 的偏好权重除以同一权重表的最大值（0–1）；文化未给 c 权重或文化未知时该项不计入。
- **R26-2.5 对一个具体对象的偏好**：取该对象全部类别、材料类别、分类学类别、审美代号（含上位链）在 `preference` 中绝对值最大的一项；并列取代号字典序最小者；全部未知则未知。
- **R26-2.6 喜恶门槛**：绝对值不低于 `rules.psych.prefThreshold` 才算喜或恶，只供显示与 §4.7 的取材使用，不另存。
- **R26-2.7 作用途径只有三条**：经想法行的 `valueScale`、`prefWeight` 与 `conduct` 触发进入心理量（§4.4）；经驱力行的 `valueLoad` 进入驱力权重（§4.9）；经 `preferenceOf()` 供决策管线给候选加权。价值与偏好不直接改任何别的量。

### 4.3 心理需求

#### 4.3.1 维度

读：need 族、gauge 族及其容器行；`gaugeTarget`、`gaugeInflow`；主体所在地点的维度（如房间美观聚合值，见卷十九 §4.11（房间评价））；效果族表。

#### 4.3.2 统一入口

读：`personView().psych.gauges`；`needSatisfiers()`。写：只经 `status.mjs`（§3.3）。

#### 4.3.3 规则

- **R26-3.1 心理需求就是登记在 need 族的心理量。** 它的匮乏程度是该心理量容器实例的 severity：0 为满足，1 为极度匮乏。需求没有自己的状态字段。
- **R26-3.2 谁有这种需求**由该心理量行的 `applies` 决定：为真而无实例则建（累积型初值取 `initialRX`，追随型初值取当拍目标），为假而有实例则撤。
- **R26-3.3 匮乏怎样变化**按 R26-4.4：累积型需求按 `gaugeInflow` 的修正后值每日增长；追随型需求向 `gaugeTarget` 的修正后值靠拢。
- **R26-3.4 需求怎样被满足**只有两条路：一是指向该心理量的想法行（环境持续供给，如所处场所的美观）；二是效果族输出里对该容器的 severity 减量（动作、设施服务、物品使用、仪式都经卷二 §3.9（效果族表）的同一形状）。
- **R26-3.5 满足途径的索引是派生的**：加载期扫描效果族表，凡输出中对某需求容器给出负向 severity 变化的族，计入 `needSatisfiers(need)`。作者不手写"某需求靠什么满足"。
- **R26-3.6 需求怎样催人行动**：只经该容器各档上的修正项去抬高相应的驱力权重（§4.9）。没有"需求到目标"的专用分支。
- **R26-3.7 需求怎样影响心情**：只经一条 `state` 触发的想法行读该需求心理量并推心情（§4.4）。
- **R26-3.8 身体需要不在此列。** 它们的容器、数值、阈值分别归卷二、卷四、卷二十一；它们对心情的影响经 `status` 触发的想法行（R26-4.1）。

#### 4.3.4 交互

- 卷十九：提供房间与场所的美观聚合值；本卷不另算美观。单件美观值见卷二十三 §4.1（作品实体与单件美观值）。
- 卷七：祈祷类需求的满足由仪轨与崇拜动作的效果族输出给出；崇拜深度见卷七 §4.13（崇拜等级）。

- 卷二十一：身体需要；本卷只读其容器实例。
- 通道：声明写者（容器）与事件。

### 4.4 想法与心情

#### 4.4.1 维度

读：thought 族；心情心理量及其容器；主体的状态实例；主体已知的事件集合及知悉时刻，见卷二十二 §4.1（主观视图）；立场数轴，见卷十八 §4.4（立场数轴）；行为的价值评价行，见卷七 §4.26（评价行）；`personality`、`values`、`preference`。

#### 4.4.2 统一入口

读：`personView().psych.thoughts`（活跃想法及各自推力）、`.psych.gauges`。写：心情容器只经 `status.mjs`。想法没有写者，因为想法不落状态。

#### 4.4.3 规则

- **R26-4.1 想法何时成立**（派生）。按行的触发种类：
  - `state`：`when` 为真（未写即恒真）且 `xRX` 已知，即成立一条，`x = xRX`。
  - `status`：主体每有一个属于行上所写族的状态实例，成立一条，`x` = 该实例 severity。身体需要、伤病、药效对心理的影响都走这里。
  - `event`：主体已知的每个事件，若动词等于行上所写动词、且主体在事件中的角色等于行上所写角色，成立一条；`related` 角色要求事件受事者与主体之间存在行上所写关系（未写关系则任何受事者都算）。已过时长从知悉时刻起算，超过 `durationDays` 即不成立。
  - `conduct`：主体作为施事的每个已知事件，取该行为在评价行中的价值向量 `e`，`x = Σ_v e_v × values_v`（对已知项求和）；正为合乎本人价值，负为违背。
- **R26-4.2 推力**（派生，定点）：`m = (基础推力 + prefWeight × 对象偏好) × P × V × R × D × K`。
  - 基础推力：`curve` 在 x 处的值，或 `value`。
  - `P = clamp(1 + Σ_p persScale_p × personality_p, rules.psych.scaleMin, rules.psych.scaleMax)`；无 `persScale` 则为 1。
  - `V = Σ_v valueScale_v × values_v`；无 `valueScale` 则为 1；`values` 未知而行上写了 `valueScale`，该条不成立。
  - `R = stanceWeight × 主体对事件受事者的立场（归一到 [-1,1]）`；无 `stanceWeight` 则为 1。
  - `D` = `decay` 在"已过时长 ÷ durationDays"处的值；无 `decay` 则为 1。
  - `K = rules.psych.stackTable[k]`，k 为同一行的成立条目按知悉时刻从新到旧的序号；序号达到 `stackLimit` 或超出表长的条目不计。
  - 对象偏好按 R26-2.5 取事件所涉对象；未知则该加项不计。
- **R26-4.3 同组取一**：同一 `group` 内只保留绝对值最大的一条；并列取想法行代号字典序最小者。
- **R26-4.4 心理量的推进**（时钟形状；全书心理量唯一的推进规则）。每拍对每个适用个体、每个心理量 g，记 `S_g` 为指向 g 的全部成立想法的推力之和，`Δt` 为本拍时长（日）：
  - 追随型：`目标 = clamp(modified(gaugeTarget[g]) + S_g, [0,1])`；`sev' = sev + (目标 - sev) × (1 - exp(-ratePerDay × Δt))`。
  - 累积型：`sev' = clamp(sev + (modified(gaugeInflow[g]) + S_g) × Δt, [0,1])`。
  - `exp` 用卷二 §1.10（随机实例化）的定点指数表。拍长在线层取 `rules.psych.tickMinutes`；离屏层的拍长与聚合形态按卷二十七 §4.1（三层模拟矩阵）声明。规则声明 `closedForm`：输入在区间内不变时，一拍 Δt 与分成若干拍的结果之差不超过定点截断误差乘以拍数。
- **R26-4.5 同拍快照**：一拍内所有心理量都从拍初快照读彼此的值，写出的增量在拍末一并生效；结果与心理量的遍历顺序无关。
- **R26-4.6 想法不落状态。** 活跃想法是事件日志、知情记录与现状的纯函数；复演不需要额外数据。按台账的判别口诀"能由别的维度算出即派生"，想法不登记容器实例；登记为容器实例的是心理量与发作。
- **R26-4.7 心情怎样起作用**：只经心情容器各档上的修正项。本规则不规定心情好坏改什么。
- **R26-4.8 外部来源怎样推心理量**：除想法行外，任何来源都可以挂以 `person.gaugeTarget[<心理量>]` 或 `person.gaugeInflow[<心理量>]` 为目标的修正项。

#### 4.4.4 交互

- 卷二十二：提供"主体知道哪些事件、何时知道、是否亲历"。信迟到二十天，悲伤也迟到二十天。`witness` 角色的判定依赖知情通道条目上的"亲历"字段（§8 Q6）。
- 卷十八：提供立场读数；本卷不存关系。
- 卷七：提供评价行（行为到价值向量）；本卷不存"什么是美德"。
- 卷二十一、卷四：提供身体类状态实例；本卷只读其族与 severity。
- 卷二十四：事件与动词；本卷登记发作开始与结束两类事件行。
- 卷二十九：想法、心理量、档的显示名经语言包，见卷二十九 §4.1（显示层隔离契约）。
- 通道：读事件；写只经声明写者。

### 4.5 压力累积与崩溃

#### 4.5.1 维度

读：压力心理量（累积型）及其容器；episode 族；`personality`、`values`；主体的技能等 map 维度（供 `bind`）。

#### 4.5.2 统一入口

读：`personView().psych.gauges`、`.psych.episodes`。写：容器实例只经 `status.mjs`；绑定修正只经 `modifier.mjs`；开始与结束各发一个事件。

#### 4.5.3 规则

- **R26-5.1 压力是一个累积型心理量**，推进按 R26-4.4。它的来源全是数据：读心情的 `state` 想法行（心情低则流入为正、高则为负）、`conduct` 想法行的负半边（违背本人价值）、心理量行 `baseRX` 给出的自然消解。
- **R26-5.2 发作的资格**（时钟）。每拍对每个个体、每个 `exclusive` 组：若该组已有进行中的发作则跳过；否则候选 = `applies` 为真、且 `gate` 所指心理量的 severity 落在 `[minSeverity, maxSeverity)` 内的发作行。
- **R26-5.3 是否触发与触发哪一条**。`H = Σ 候选的 hazardRX`（未知或非正的候选不计）；触发概率 `1 - exp(-H × Δt)`；用卷一 §8.2（骰值键）的骰值键取一个均匀数判定是否触发，再取一个均匀数按各候选危险率占比选出一条（候选按代号升序累加）。键的规则 id 前缀登记进种子键登记表。
- **R26-5.4 开始**。输出清单：挂上该行的容器实例（severity 取 `severityInitial`）；按 `duration` 取时长并声明到期，由调度器执行，本卷不自写计时；发开始事件；若有 `bind` 则按 R26-5.5 处理。
- **R26-5.5 绑定**。`pick` 为加权：在主体该 map 维度的各键中按值（取非负部分、整数化）加权抽 `count` 个，用骰值键；若行上写了 `stage` 与 `value`，为每个抽中的键写一条运行态修正项，目标为"该维度[该键]"，来源为本发作的容器，时长与发作相同。`pick` 为取顶：取该 map 维度基值最大的 `count` 个键（并列按代号升序），不抽签、不落状态，读时现算。抽中的键经 `psych.episodes[].picks` 读出。
- **R26-5.6 结束**，下列任一成立：到期；主体作为施事发生了 `exitOnVerb` 的事件；`exitOnGateLeave` 为真且心理量离开区间；容器实例被别的规则移除（如诊治）。结束时：移除容器实例与来源为它的运行态修正项，执行 `aftermath`，发结束事件。
- **R26-5.7 转入**。因到期而结束、行上有 `failTo`、且期间 `exitOnVerb` 未发生：立即对 `failTo` 所指发作行执行 R26-5.4，不再判定资格。
- **R26-5.8 发作怎样改变行为**：只经其容器档上的修正项，以及容器所属族的布尔字段。本卷没有"崩溃时做某事"的分支；闹事、出走、暴食都是驱力权重被修正后由决策管线选出来的。
- **R26-5.9 崩溃分轻重**只是数据：不同发作行的 `gate` 区间不同。

#### 4.5.4 交互

- 卷九：执行输出清单；决策管线读被修正后的驱力权重。
- 卷二十：到期。卷二十四：开始、结束事件类型行由本卷登记，见卷二十四 §4.2（事件类型注册表）。
- 卷二十一：诊治可降低或移除发作容器，见卷二十一 §4.8（诊治）；本卷只提供容器的可诊治标记。
- 卷十八：他人目睹发作后的立场变化由卷十八按事件来源行处理。
- 通道：事件、声明写者。

#### 4.5.6 验收断言

- **A26-5.S 扫描式**：`.mjs` 中 episode 族字面量为 0；`psych.mjs` 不 import 任何行为、战斗、治安模块；不存在以发作代号为条件的分支；危险率、时长的数值字面量为 0（P26-6）。
- **A26-5.I 不变量式**：同一主体同一 `exclusive` 组进行中的发作至多一个；每个进行中的发作恰有一个容器实例，反之亦然；来源为某发作容器的运行态修正项在该容器移除后数量为 0；同种子复演，发作的开始时刻、种类、时长逐位相同；一万个体在恒定危险率下的触发频率与 `1 - exp(-H×Δt)` 之差在统计容差内。
- **A26-5.X 扩展性式**：加一条发作行与一条容器行，不改 `.mjs`，该发作即可被触发、挂修正、到期、执行善后。

### 4.6 疯狂

#### 4.6.1 维度

读：episode 族中 `duration` 为空的行及其容器；压力心理量；容器的可诊治标记与危及生命档。

#### 4.6.2 统一入口

同 §4.5.2。

#### 4.6.3 规则

- **R26-6.1 疯狂不是另一套机制**：它是 `duration` 为空的发作，即不会自行到期。进入途径两条，都已在 §4.5 定义：别的发作经 `failTo` 转入（R26-5.7），或自身的 `gate` 与危险率直接触发（R26-5.3）。
- **R26-6.2 退出途径**只有 R26-5.6 中不含到期的三条：容器被诊治或别的效果移除；`exitOnVerb` 发生；`exitOnGateLeave` 为真且心理量离开区间。
- **R26-6.3 致命性是涌现的**：疯狂的容器档只挂修正项（压低进食与自保驱力、抬高攻击驱力、使人不能行动等），死亡由身体规则、战斗规则、治安规则各自得出。本卷不写"疯者某日后死亡"。
- **R26-6.4 疯狂期间其余心理量照常推进**；同一 `exclusive` 组不再触发新的发作（R26-5.2）。
- **R26-6.5 是否算疯**只由数据决定（行的 `duration` 为空），代码里没有"疯狂"这个类别。显示层按发作行的显示名呈现。

#### 4.6.4 交互

- 卷二十一：诊治与照护；容器的危及生命档由卷二十一的照护规则读。
- 卷八b：疯者伤人的责任与处置按法典条目，本卷不参与。
- 卷十六：超自然个体"失常后变为另一物种"是 `aftermath` 里的效果族调用，转化规则归卷十六。
- 通道：事件、声明写者。

### 4.7 灵感与奇想

#### 4.7.1 维度

读：episode 族中 `gate` 指向心情高区间的行；主体的技能 map，技能定义见卷十四 §4.3（技能与熟练）；`preference`；主体所在地点的维度（如人口）。

#### 4.7.2 统一入口

同 §4.5.2；所系对象经 `personView().psych.episodes[].picks`。

#### 4.7.3 规则

- **R26-7.1 灵感是 `gate` 指向高心情区间的发作**，资格、触发、开始、结束全按 R26-5.2 至 R26-5.6。
- **R26-7.2 灵感系于哪项本事**由 `bind` 给出：在行上所写的 map 维度里按值加权抽取（R26-5.5 加权），熟练的更容易被抽中；抽中的键得到一条运行态修正项，发作结束即撤。代码不知道那个维度是技能。
- **R26-7.3 奇想是带 `exitOnVerb` 与 `failTo` 的灵感**：发作期间容器档把创作驱力抬到压倒其余；所需材料类别由 `bind` 取顶从本人 `preference` 得出（R26-5.5 取顶），不落状态；主体完成一件作品（`exitOnVerb` 所指动词）即成功结束并执行 `aftermath`；到期未完成则经 `failTo` 转入行上所指的发作。
- **R26-7.4 作品本身不由本卷产生**：产物仍由材料属性、职业技能、意图三者推出；本卷只提供意图一侧的两个读数——抬高的驱力与 `picks`。
- **R26-7.5 触发门槛都是行上的数据**：对技能水平、聚落人口、心情区间的要求分别写在 `applies`、`hazardRX`、`gate` 里。

#### 4.7.4 交互

- 卷十四：技能 map 的键与数值；灵感的修正项经唯一管线作用于技能读数。
- 卷二十三、卷三：创作动作读 `picks` 作为材料意图；作品完成发出的动词供 `exitOnVerb` 匹配；传奇作品的升级见卷二十三 §4.6（传奇）。
- 卷九：决策管线读被抬高的驱力权重。
- 通道：事件、声明写者。

### 4.8 个人士气

#### 4.8.1 维度

读：士气心理量（追随型）及其容器，容器所属族按台账为士气族；指向它的想法行；`gaugeTarget` 上来自所属队伍、指挥者、恐惧值的修正项。

#### 4.8.2 统一入口

读：`personView().psych.gauges`。写：只经 `status.mjs`。军团士气不在本卷，聚合入口归卷十三 §4.8（军团士气）。

#### 4.8.3 规则

- **R26-8.1 个人士气是一个追随型心理量**，推进按 R26-4.4。它与心情是两个量；二者的联系只是一条读心情、推士气的 `state` 想法行。
- **R26-8.2 临阵的推力全是想法行**：同伴倒下、敌人溃退、己方获胜是 `event` 触发（角色为亲历）；自身伤痛是 `status` 触发；饥寒同理。
- **R26-8.3 队伍对个人的影响只经修正项**：队伍组织行、指挥者职位行可挂作用域为成员、目标为 `person.gaugeTarget[<士气心理量>]` 的修正项，作用域解析按卷二 §3.5（作用域与状态键表）。恐惧值对士气的影响由卷十八以同样形状登记，本卷不读恐惧值。
- **R26-8.4 士气怎样改变行为**：只经容器各档的修正项（抬高自保驱力、压低攻击驱力、改变战斗相关维度）。逃跑、投降是决策管线在这些权重下选出的动作，不是本卷的规则。
- **R26-8.5 谁没有士气**由心理量行的 `applies` 决定；没有实例的个体不参与军团聚合。
- **R26-8.6 士气的种类可加**：需要另一种"斗志"（如守城意志、围猎兴奋）时，加一个心理量行与若干想法行，机制不变。

#### 4.8.4 交互

- 卷十三：军团士气 = 成员个人士气的聚合加指挥与伤亡修正，由卷十三定义；它读成员的 `psych.gauges`，要聚合哪个心理量由它自己的规则表给出代号。战斗事件的动词由卷十三登记。
- 卷十八：恐惧值以修正项形式进入。卷八：指挥者职位行的修正项。
- 通道：事件、声明写者。

#### 4.9.1 维度

读：`driveWeight`、`decisionNoise`（§2.1）；drive 族条目；pers 条目的 `noiseLoad`；`rules.psych.noiseBase`、`rules.psych.driveMax`。

#### 4.9.2 统一入口

读：`personView().dims.driveWeight`、`.dims.decisionNoise`、`decisionJitter()`、`preferenceOf()`、`needSatisfiers()`。写：无。唯一使用方是卷九 §4.12（NPC 决策管线）。

#### 4.9.3 规则

- **R26-9.1 驱力权重的基值**（派生）：`driveWeight[d] = clamp(base_d + Σ_p persLoad_d[p] × personality_p + Σ_v valueLoad_d[v] × values_v, [0, rules.psych.driveMax])`，人格与价值取基值；`values` 未知时价值项不计入。
- **R26-9.2 驱力权重的修正**：心理需求的匮乏、心情、压力、发作、士气，以及信条、传统、职位、附魔，一律以修正项作用于 `person.driveWeight[<驱力>]`，经唯一管线求值。这是心理状态进入决策的唯一通道。
- **R26-9.3 决策噪声的基值**（派生）：`decisionNoise = clamp(rules.psych.noiseBase + Σ_p noiseLoad_p × personality_p, [0,1])`；修正同上（压力、发作、醉酒等容器档可抬高它）。
- **R26-9.4 扰动函数**（派生，纯函数）：`decisionJitter(主体, decisionKey, seq) = decisionNoise（修正后） × z`，`z` 为标准正态数，由卷一 §8.2（骰值键）的骰值键（规则 id 取本接口登记的前缀，对象取主体，时刻取 `decisionKey` 所含时刻，序号取 `seq`）经卷二 §1.10（随机实例化）的分位数表得出。噪声为 0 时扰动恒为 0。
- **R26-9.5 与决策管线的分工**：候选怎样生成、每个候选对各驱力的贡献、成本、效用怎样合成、并列怎样取舍，归卷九 §4.12（NPC 决策管线）。本卷的承诺只有三条：权重非负且有上界；同一 `(主体, decisionKey, seq)` 的扰动恒定；本接口不读候选内容。
- **R26-9.6 旧的人格打分全部并入这条通道**：是否应战、是否铤而走险、有无立国之志，都是决策管线里的普通候选，由驱力权重与扰动决定；不存在针对某一种决定的专用分值。

#### 4.9.4 交互

- 卷九：读上述五个入口；动作目录条目需带"该动作对各驱力的贡献"字段，见 §8 Q2。玩家角色同样有这些读数，但玩家的动作由玩家选，不经决策管线（§8 Q8）。
- 卷二 §3.7（旧派生槽的对照与过程主体槽）已有的决策成本过程槽照旧，本卷的容器档可以挂以它为目标的修正项。
- 卷二十七：离屏层少算或不算扰动的降级方式由卷二十七声明，本接口保持纯函数。
- 通道：只读。

- 【西陲】`npc_example_west_smith`：某驱力 `base 0.30`、人格项 `0.5 × 0.60`、价值项 `0.4 × (-0.25)`，得 0.50（附录二）；只计沉稳 0.60 与谨慎 -0.14 两轴（其余轴按 0 示意），噪声为 `0.15 - 0.10×0.60 + 0.10×0.14 = 0.104`。有人下战书时，"应战"候选对攻击与声望驱力有贡献、对自保驱力有负贡献，他应不应战由这些权重加一次扰动得出。

#### 4.9.6 验收断言

- **A26-9.S 扫描式**：`.mjs` 中 drive 族字面量为 0；`duels.mjs`、`npc-crime.mjs`、`nation-founding.mjs`、`npc-cognition.mjs` 中对人格的文字匹配与手填分值为 0；决策相关模块中 `Math.random` 为 0；除 `personView` 外没有第二个返回人格或权重的函数。
- **A26-9.I 不变量式**：权重恒在 `[0, rules.psych.driveMax]`；噪声为 0 的个体在同一候选集上的选择与扰动序号无关；同种子复演三十日，全部 NPC 的决策序列逐事件相同；开与不开 AI 档，决策序列相同（扰动不读任何模型输出）。
- **A26-9.X 扩展性式**：加一条驱力行不改 `.mjs`，每个个体即有该驱力的权重；加一条以某驱力为目标的修正项（挂在任一容器档、信条或职位上），对应个体的选择分布随之改变。
