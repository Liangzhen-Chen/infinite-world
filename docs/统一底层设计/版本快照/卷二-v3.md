## 读法

- 本卷是全部领域卷（卷三至卷二十九）的**格式母本**：维度表怎样写、怎样读、怎样校验、修正值怎样叠加、随机实例怎样生成、效果族怎样接入。各卷只在本卷格式里填自己的维度与规则，不另起格式。
- "维度"= 有固定代号、单位、取值域的可比较量；"维度表"= 一类实体全部维度的定义加类别行与实例行；"入口"= 读某类实体任一维度的唯一函数；"修正键"= 可被外力改动的维度；"效果族"= 一类效果怎样从维度算出来源、对象与幅度的数据行。
- 锚点：`DF 01 §2.1`、`CDDA 02 §7`、`RW 03 §3.2`、`EVE 04 §2.4`、`CK3 05 §2.8`（调研编号 § 节）；代码写 `文件:行`；审查意见写 `A-M1`（审查 A 必改 1）、`B-二.3`、`RA-N2`（复审 A 新必改 2）、`RB-M3`（复审 B 必改 3）、`V1-Cn`（卷一复审冲突 n，由李白裁定归本卷）。
- 规矩三档：**必须**（校验器硬拦或门禁阻断）、**应当**（扫描告警、基线只降）、**可以**（建议）。未标注即"必须"。
- 本卷所辖子系统（对卷零）：维度表加载与取值、继承展平、随机实例化、派生与聚合、修正求值、效果族表、校验器、入口与缓存、写者与依赖声明、显示名隔离与输入边。

## 〇 本卷的十个结论

1. **一种文件格式服务全部实体类**：`world/ontology/dimensions/<kind>.json`；取值顺序：实例覆盖 > 展平后的类别行（按 precedence 组从具体到一般）> 派生 > 采样 > 未知；**代码无默认值**，缺失处置由表头 `onUnknown` 声明；"不适用"与"未知"分开（RA-N5）。
2. **继承只有一套**：`extends`（= 卷一 copyFrom）+ `abstract` + 集合增删 `+:`/`-:` + 数值 `relative`/`proportional`，加载期一次展平成有效行，再参与 precedence（V1-C3）。
3. **代号全 ASCII，显示名全在显示层**；规则层一行都不读任何语言；输入边只做"文字→封闭代号"，翻不出退回菜单（李白裁定）；验收用例见 B10、G4。
4. **22 类实体各一个入口**，与卷一"首批九张表"的关系见 §5.25 对照表（V1-C7）；入口纯读；依赖由 `declareInputs` 的传递闭包生成，叶子声明由静态分析核对，动态键与 state 外传禁止（RA-N1）。
5. **修正键 = 注册开放枚举**；运算 `add/mul/max/min/set/post` 与作用域封闭；map 的 number 值按子键寻址（RB-M4 统一）。
6. **求值管线九步、定点、确定**：基值 → add → mul（叠加惩罚查冻结系数表，n 从 0 起）→ max → min → set → post → clamp → round；标度 10⁴、向零截断；系数表 S[1]=0.8691（本机核算，附录 E；RA-N2）。
7. **派生有封闭聚合原语**；环检测分维度级（自引用须 `recursive`）与实例级（展开关系图）两层（RA-N3）；mode 平局、空关系、rank 越界有定义（RA-N4）。
8. **状态容器唯一**；每档只有修正项；`capacity/awake` 不是容器字段，是由 `body.*` 能力经 `rules.capacity` 阈值派生的谓词（V1-C5）。
9. **效果族表**是全部效果的唯一来源：神迹、法术、怪物特殊攻击、设施服务、物品使用都是"效果族行 + 需求块 + 实体维度"的组合，只填数据即接入（V1-C4）。
10. **校验器 L0–L4 硬拦、L5 报告**；首期 L0–L3 + 三条不变量；迁移先补维度再改读者，physicalMetal 名称匹配删除不搬。

### 1.3 行、继承与取值顺序

**两种行。** 类别行 `classes.<class_id>`（按类写；类别键须在 `_vocab.json` `class` 族，否则 E-DIM-CLASS-UNKNOWN）；实例行（在 `instanceTable`、表 `generated` 节或存档 `state.created`；带 `basis`，真实量带 `sources`，否则 E-DIM-INSTANCE-BASIS）。

**成员关系单一来源**：实例自己声明 `classes`（含组件类）与 `tags`；类别行不列 members；`memberLinks` 只用于成员偏差检查。`tags` 与 `classes` 都沿 `_vocab.json` 的 `broader` 上位链展开后参与 `memberOf`（RB-S4：class 族同样展开）。

**继承：唯一一套，加载期展平**（卷一 I45、§3A.6 的 copyFrom/extend/delete/relative/proportional 在此定义；V1-C3）：

| 写法 | 语义 | 适用类型 |
|---|---|---|
| `"extends": "<class_id>"` | 复制父有效行的全部维度为缺省（= 卷一 copyFrom） | 类别行 |
| `"abstract": true` | 只供继承，展平后丢弃，不进 precedence | 类别行 |
| `"<dim>": v` | 子覆盖父（标量整值替换；set/map 整值替换） | 全部 |
| `"<dim>+": [...]` / `{...}` | extend：并入父集合 / 父映射 | set、map、list |
| `"<dim>-": [...]` | delete：从父集合/映射剔除键 | set、map、list |
| `"<dim>~": Δ` | relative：父值 + Δ（Δ 带目标单位） | number、integer |
| `"<dim>*": f` | proportional：父值 × f | number、integer |

- 同一维在同一行只能用一种写法（E-DIM-EXTEND-CONFLICT）；`~`/`*` 要求父有值（E-DIM-EXTEND-NOPARENT）；运算用 §3.3 定点算术并按 precision 截断。
- `extends` 目标须是同表类别行，且为 `abstract` 或与子行同属子行所在的每一个 precedence 组（RA-S2：按"该类别所在的所有组"检查，E-DIM-EXTENDS-TARGET）；链深 ≤4、无环（E-DIM-CYCLE）。
- 展平后 `extends/+/-/~/*` 消失，只剩有效行；**实例行不得用继承写法**（实例偏离只写整值；E-DIM-EXTEND-ON-INSTANCE）。
- 全部表由同一加载器展平一次（卷一 I45 夹具：每表一份继承夹具，展开结果与手写等价）。

**取值（唯一算法）**：
```
value(kind, id, dim):
  if !applicable(id, dim) → {known:false, applicable:false}      # required 的 byClass/ifPresent 条件不满足：不适用（RA-N5）
  own = instanceRow(id)[dim];                 if own !== undefined → own (source=instance)
  group = precedenceOf[dim] ?? 'default'
  chain = precedenceGroups[group].filter(c => memberOf(id,c) && flat[c] exists)
  for c in chain: v = rowValue(flat[c], dim); if v !== undefined → v (source=class c)
  if dimensions[dim].derived → evalDerived(id, dim)            # §1.12
  if dimensions[dim].sample  → sample(id, dim)                 # §1.10 纯函数
  → {known:false, applicable:true}                             # 未知，按 onUnknown 处置
```
- 多类别冲突取 precedence 更前者；两个互不相含的类别同时命中同一维且值不同 → W-DIM-PRECEDENCE-TIE。precedence 是每组一个全序，表达不了"此维更具体、彼维更一般"，需要时开新组。
- precedence 默认由 `broader` 深度派生（深者先）；手写只在同深度打破平局，与深度矛盾即 E-DIM-PRECEDENCE-BROADER。

**三层示例**（附录 A 的表）：`class_workshop_hot extends class_workshop extends class_public_building`。public_building{public:true, lodging:false, allowedMaterials:[matcat_woody,matcat_stony], wearPerDay:0.0003, capacityBase:1}；workshop{extends:public_building, public:false, capacityBase:2}；workshop_hot{extends:workshop, fixtures:[fixture_forge,fixture_hearth], "allowedMaterials-":[matcat_woody], "wearPerDay*":2, upkeepPerDay:{class_fuel:12}}。展平 workshop_hot 有效行 = {public:false, lodging:false, allowedMaterials:[matcat_stony], wearPerDay:0.0006, capacityBase:2, fixtures:[…], upkeepPerDay:{class_fuel:12}}。实例 `bld_hw_forge`{classes:[comp_facility, class_workshop_hot], props:{capacityBase:3}}：`capacityBase`=3（instance）；`wearPerDay`=0.0006（class_workshop_hot）；`allowedMaterials`=[matcat_stony]；`lodging`=false。

**覆盖顺序总表（高→低）**：`state.created` 偏离行 > 作者实例行 > `generated` 节 > 展平类别行（组内 precedence）> 派生 > 采样 > 未知。扩展包不得改写 core 类别行（E-DIM-NAMESPACE-OVERRIDE）。

**分类机制判定表**（四套）：属于哪类 → `classes`（含 `comp_*`）；跨类主题标签 → `tags`（`sphere` 是一族）；类别行复用数据 → 继承写法；两类都命中谁赢 → `precedenceGroups`。`components` 字段不存在。

### 1.4 单位

`_units.json` 封闭，每条 `{id, dimension, si, calibrate?}`。首批：`kg g L m3 m cm kg_per_L MJ_per_kg_dry satiety_per_kg_dry fraction percent score axis count day minute year celsius copper per_day per_year kg_per_day m_per_minute m2`；`satiety_per_kg_dry copper score axis` 标 `calibrate:true`。必须：unit 存在（E-DIM-UNIT-UNKNOWN）。可以：量纲签名比对（W-DIM-UNIT-DIM，首期不做）。存储值一律 SI 口径；出处原值单位在表头 `sourceUnits` 登记换算。无量纲系数一律是带名字的规则表常数。

| `number` / `integer` | `[min,max]`（null 无界） | 配 `precision` |
| `boolean` | 无 | |

### 1.6 缺失处置（RA-N5）

- 无任何常量缺省（表头、代码皆禁）。`required` 决定缺失是否加载错误。
- **三种状态**：`applicable:false`（required 条件不满足，如不可燃物的 heatValue）——不进缺口统计、不触发 onUnknown、消费者视作"此维度在该实体上不存在"；`known:false, applicable:true`（应有而缺）——按 `onUnknown`；`known:true`。
- `onUnknown` 的可判定语义：
  - `skip`：**整个实体**从依赖该维度的规则求值中排除（规则遍历时过滤掉）；
  - `gap`：**该项**从规则求值中排除（如求和时该项不计入、比较时该实体不进入候选），并把 `(kind,id,dim)` 记入 `state.gaps` 与 L5；**不是以 0 参与**——求和 Σ 的实现是"对 known 的项求和"而非"未知当 0"；
  - `error`：读到即抛 E-DIM-UNKNOWN-READ。
- 多维同时未知且处置不同：`error` > `skip` > `gap`。
- 扫描（卷十二）：对 Fact 的 `??`/`||`/三元/`if(!fact.known)` 分支中出现常量替代值即 E-VIEW-FALLBACK；合法形态只有 `if(!fact.known) return/continue/skip` 与 `gaps.record(...)`。
- 推不出的派生枚举必须显式写值 + basis（`sourceMode:"buy_only"`、`categoryKind:"non_economic"`），规则表只含正向推导、无兜底项。规则表数值称"标定值"。

### 1.7 出处与标定

类别行与实例行带 `basis`（一句理由）；number 维度优先由 `sources[]` 推出：`sources[] = [{name, citation, <原值字段>…, range?, item?}]`，`selection = {method:"single"|"mean", reason}`（single 取首条；mean 对各成员分别推算后取平均），推算公式沿 item-class.mjs deriveFromSources（含水、可食部分、干基能量、密度 = 出处 kg/m³ ÷ 1000），推出值与直写值并存必须相等（E-DIM-SOURCE-MISMATCH）；成员偏差（干物质比例、干基能量、鲜重能量相对偏差任一超 `memberDeviationThreshold`）须有实例行（E-DIM-MEMBER-DEVIATION）；真实量须 `citation`；世界内量表 `calibrate:true`；`status: verified/approximate/placeholder`，placeholder 进 world/ 即 E-DIM-SOURCE-PLACEHOLDER；`verified-sources.json` 冻结清单（只增不删、降级需人工批准）对所有表生效。`basis/sources[].name/citation/note` 是文档字段，在 state-owners.json 的 `display` 集合里登记，规则层不读。

### 1.8 组件 = 带 requires/enables 的类别

`_vocab.json` `class` 族条目带 `requires`（本表维度列表）与 `enables`（行为代号列表，须 ⊆ 表头 `behaviors`）即为组件类，前缀 `comp_`；实体写进 `classes`。校验：requires 维度存在（E-DIM-COMPONENT-REQUIRES）、enables 已登记（E-DIM-COMPONENT-ENABLES）、`conflicts` 不同挂（E-DIM-COMPONENT-CONFLICT）。规则层按组件类遍历。首批组件类（示例，真值在 `_vocab.json`）：`comp_burnable comp_edible comp_drinkable comp_rottable comp_wearable comp_container comp_tool comp_weapon comp_readable comp_durable comp_consumable comp_raw_material comp_crafted comp_work comp_relic comp_vehicle comp_livestock comp_sapient comp_settlement comp_region comp_facility comp_jurisdiction comp_route`。

### 1.9 代号、显示名与语言边界

**代号**：实体 id、类别 id、枚举值 `^[a-z][a-z0-9_]{1,47}$`；维度键与 struct 字段名 `^[a-z][a-zA-Z0-9]{0,47}$`。前缀表由表头 `idPrefix` 与词表族 `prefix` 声明；首批实体前缀 `item_ mat_ species_ plant_ body_ npc_ creature_ loc_ bld_ fac_ recipe_ org_ office_ polity_ law_ deity_ faith_ culture_ profession_ skill_ know_ offense_ status_ evt_`；词表前缀 `class_ comp_ terrain_ biome_ sphere_ ability_ layer_ matcat_ fixture_ season_ tier_ service_ damage_ taxon_ tissue_ sense_ attr_ pers_ value_ ethic_ doctrine_ tenet_ tradition_ power_ labor_ req_ penalty_ juris_ bank_ eff_ rel_ agg_ usage_ pool_ quality_ diet_ water_ site_ heritage_ ethos_ martial_ aesthetic_ descent_ burial_ unitset_ norm_ taboo_ aspect_ offering_ legit_ succession_ taxbase_ carrier_ family_ orgkind_ politykind_`。
- **kind 只由加载期注册表给出**：加载器扫全部表建 `idIndex: id → kind`，运行期 `kindOf(id)` 查表，不解析字串（RA-S7）；代码里 `startsWith('bld_')` 即 E-VIEW-ID-PARSE。`faction_*`→`org_*`，`monster_*`→`species_*`，`profession_life_N`→`profession_<domain>_<role>`，加载器拒绝旧名。

**静态显示名**：`labels.<lang>.json` 以 id 为键，多形态 `{label, short, adj, plural, …}`。ontology `label`、professions `aliases`、目录 `name/purpose/description`、material-props `appearance[].term` 等全部是显示/文档字段（§6.11 迁出）。校验器对 labels **只查键存在**，不读值（RB-S3）。

**生成名**：实体只存 `nameParts: struct{bank: ref vocab bank, pattern: ref vocab pattern, parts: list<struct{slot: enum, wordId: ref vocab word}>, seq: integer}`；显示名由投影层按当前语言拼；重名与查人比较 nameParts 或 id。**state 内不得存 `name` 字串**（现 npcs.*.name 删除，§6.11；RA-N8）。

**玩家命名**：`state.displayNames[id] = {text, lang}`；display:true；唯一写者 display-names.mjs；UI 语言与 `lang` 不同时照原文显示并加语言标记（RA-S3）；不进存档哈希的规则层部分（卷一 §8.3 的排除表由 state-owners 的 display 集合生成）。

**语言边界（李白【11-13】裁定；卷一 R-2 引用本节）**：
1. 规则层（含 consistency-review.mjs、consistency-service.mjs、consistency-evidence.mjs、consistency-outcome.mjs）一行不读任何语言；AI 叙述解析改为要求 AI 输出固定代号格式的结构化结果，规则只校验代号在合法集合内。
2. 输入边只做"文字 → 封闭代号集合"：输出 `{action:<动作目录代号>, slots:{<槽位代号>: <候选编号|数值>}}`；翻不出、歧义、缺参数 → 退回菜单，不猜、不填默认值。
3. 不开 AI 时只走菜单与结构化代号；语言包只做菜单项显示名**整串精确对应**；**相等口径**（两种语言同一口径）：NFC 规范化后逐码元相等；不做大小写折叠；不裁首尾空白；不忽略标点。禁止关键词、正则、子串、近似匹配。
4. 输入边模块组（`server-plugin/input/`、`projection/`）可整体删除，删除后菜单完整可玩；中英对等。
5. `lookupByLabel(lang, text)` 只在输入边目录存在，精确等于，返回代号或 `null`；同名两项 → 返回 `ambiguous`，输入边退回菜单。
6. 机器扫描条款见 §7 S13（可验收口径）。

### 1.10 随机实例化

**分布对象**（type `distribution`）：
```json
{"dist":"normal","mean":0,"sd":0.35,"clamp":[-1,1]}
{"dist":"lognormal","mu":3.69,"sigma":0.12,"clamp":[25,80]}
{"dist":"uniform","min":0.5,"max":1.5}
{"dist":"triangular","min":0.8,"mode":1.0,"max":1.3}
{"dist":"categorical","weights":{"terrain_hill":3,"terrain_plain":5}}
{"dist":"curve","curve":"<curve dim>","x":"<dim>"}          // 由另一维度查曲线，无随机
{"dist":"joint","group":"personality","marginals":{"pers_openness":{…},"pers_diligence":{…}},"corr":[[1,0.3],[0.3,1]]}
{"dist":"ref","name":"personality_default"}                   // 引用 _distributions.json
```
参数校验：normal `sd>0`；lognormal `sigma>0`；uniform `min<max`；triangular `min≤mode≤max`；categorical 权重非负且和>0（E-DIM-SAMPLE-WEIGHTS）、键在枚举域；`clamp ⊂ domain`（E-DIM-SAMPLE-DOMAIN）；joint 的 corr 对称且对角为 1、半正定（E-DIM-SAMPLE-CORR，RA-S9）；其他 E-DIM-SAMPLE-PARAM。首批实现 uniform/normal/lognormal/triangular/categorical/curve；joint 只定格式，卷二十六实现（首批按 marginals 独立采样）。

**种子键**：`seedKey = sha256(utf8(template.seed + "|" + kind + "|" + instanceId + "|" + dimension))`，`joint` 把 dimension 换成 `"joint:" + group`，一次抽整个向量分发。`template.seed` 字符集 `^[A-Za-z0-9_-]{1,64}$`（RA-S4），其余部件按代号规范不含 `|`。`instanceId` 由卷十确定性导出（坐标、父 id、序号），登记 seed-keys.json role `id`。`dimension-sample.mjs` 的键登记 role `seed`，受 E-SEED-KEY 比对；Math.random 只在 legacy/。

**自带 PRNG 与定点算术**（全部 BigInt 整数运算）：
- 第 i 个均匀数（i 从 0 起，i=0 用 seedKey 本身）：`h_i = sha256(seedKey + (i===0 ? "" : "|" + i))`；`u = BigInt("0x" + h_i.slice(0,16))`（64 位）。
- normal 分位数表 `_distributions.json.normalQuantile`：4097 点，`z_j = Φ⁻¹(j/4096)` 的 4 位定点值（j=0 与 4096 分别钳为 −3.9000、+3.9000），离线由脚本生成并冻结，带 sha256；运行期 `j = u >> 52n`（高 12 位）、`f = u & (2^52−1)`，`z = z_j + ((z_{j+1} − z_j) × f) >> 52n`（整数线性插值，向零截断），再 `mean + sd × z` 定点乘法截断。
- exp 表 `_distributions.json.expTable`：`expInt[k] = e^k`（k=−40..40）与 `expFrac[m] = e^(m/4096)`（m=0..4096），均为 8 位定点整数（标度 10⁸），冻结带哈希；`exp(x)`：x 定点 → `k = floor(x)`，`r = x − k`（0 ≤ r < 1），`m = floor(r × 4096)`，`e^r ≈ expFrac[m] + (expFrac[m+1] − expFrac[m]) × (r×4096 − m)`，`exp(x) = expInt[k] × e^r`，全程整数截断，最后降到 10⁴ 标度（RB-S2）。lognormal = `exp(mu + sigma×z)`。
- uniform：`min + (max−min) × u / 2^64`（整数）；triangular：逆 CDF 用整数开方（牛顿法固定 32 步）；categorical：`u mod Σw` 累加命中。
- 结果按维度 `precision` 向零截断后 clamp。
- 采样是纯函数 `sample(engine, kind, id, dim) → value`，不写状态。

**只存偏离值**：采样值不写回，每次重算（WeakMap 记忆）。实例偏离采样值（成长、磨损、玩家改造）时由该维度的声明写者写 `state.created[id].props[dim]`。**派生维度不接受偏离行**（E-DIM-DERIVED-WRITTEN；受伤等走状态容器修正，RB-M1）。`sample` 只对"实例无值、类别行无值、无 derived"生效。生成不写任何显示文本。

### 1.12 派生与聚合原语

`derived` = RX + 封闭聚合原语（`_vocab.json` `aggregate` 族，前缀 `agg_`）：

| 原语 | 签名 | 空关系 | 平局 | 用途 |
|---|---|---|---|---|
| `wsum(map, kind, dim)` | Σ portion×dim(kind,key)，定点乘后截断再求和 | 空 map → 未知 | — | 密度 |
| `exists(rel, filter?)` | 关系中有满足 filter 的对象 | false | — | sourceMode |
| `count(rel, filter?)` | 计数 | 0 | — | 下游引用 |
| `nearest(tree, dim)` | 沿包含树向上第一个 known 值 | 到根仍无 → 未知 | — | lawCode、气温 |
| `mode(rel, dim)` | 众数 | 未知 | **代号字典序最小** | 文化 |
| `maxOf/minOf(rel, dim)` | 极值 | 未知 | — | 链式档位 |
| `lookup(curve, x)` | 查曲线，x 出域取端点 | — | — | 年龄曲线 |
| `rank(enum, ±k)` | 有序枚举位移；越界 **饱和到端点**（RA-N4） | — | — | tier−1 |
| `first(rules)` | 规则表为有序列表，首条 when 为真者的值；都不真 → 未知 | 未知 | 顺序决定 | categoryKind、sourceMode |

- `filter` 与 `when` 是 RX，变量范围 = 关系对象的基值维度 + 主体的基值维度；`rel` 来自 `_vocab.json` `relation` 族（前缀 `rel_`，closed），每条 `{id, from: kind, to: kind, via: "<state key path 或 index>", inputs:[状态路径]}`，`inputs` 供依赖闭包（§2.3）。
- **派生变量一律读基值**；修正只施于最终被读的维度（`sizeClass` 看未修正的 `volumeL`）。
- **环检测两层**（RA-N3）：维度级——节点是 `(kind.dim)`，边是公式引用；自引用必须带 `recursive:{relation}`，否则 E-DIM-DERIVED-CYCLE；非自环的维度级环一律报错。实例级——对带 `recursive` 的维度，加载期沿其 relation 展开实例图（如配方输入/输出图）判环，有环即 E-DIM-DERIVED-CYCLE 并列出环路；卷六 `valueBase` 由配方成本推时须以"基础材料外生"打破。
- 派生结果按 precision 截断。

### 2.3 记忆与依赖声明（RA-N1：叶子也不手写并集，静态核对）

```js

```

## 三 修正值体系

### 3.1 结论：注册开放枚举

| | CK3 封闭枚举（05 §2.8） | EVE 开放集合（04 §2.2–2.4） |
|---|---|---|
| 键在哪定义 | 引擎代码几百个键 | dgmAttributeTypes 数据表，一行一个 |
| 加一种可修正行为 | 改引擎 | 加一行数据 |
| 语义与单位 | 引擎保证 | 表元数据 unitID/stackable/highIsGood |
| 错字 | 编译期报错 | 静默新键 |
| 作用域与运算 | 编进键名 | 单独字段 |
| 叠加惩罚 | 无统一规则 | 属性级元数据 + 通用曲线 |

**决定**：键集合**开放于数据**（`modifiable:true` 的 number/integer/map<…,number> 维度即修正键，键名 `<kind>.<dimension>` 或 `<kind>.<dimension>[<key>]`），**封闭于代码**（代码不得出现键字面量；E-MOD-KEY-UNREGISTERED）；运算、阶段、作用域封闭；单位、精度、边界、叠加规则是键的元数据。额外两个命名空间 `body.<capability>`（§3.6）与 `process.<slot>`（§3.7）。

### 3.2 修正项的格式

```json
{

 "target": "person.dailyFoodNeed",          // 或 "facility_type.upkeepPerDay[class_fuel]"
```

### 3.3 求值管线（九步、定点、全序）

**定点算术**（RA-N2）：标度 `SCALE = 10⁴`（rx.mjs `SCALE=10000n`）；一切输入先转定点（`fixedUnits`：小数第 5 位起**截断**）；乘法 `fixedMultiply(a,b) = a×b / SCALE`（BigInt 整除，**向零截断**）；加法 `checkedFixed` 溢出即错；无修正时返回基值原生值（derived.mjs:244–250 口径）；最终按维度 `precision`（≤4）向零截断。中间不做四舍五入。

**全序键** `order = (priority desc, |value| desc, source.id asc, id asc)`；`set` 阶段只按 `(priority desc, source.id asc, id asc)`（RA-N2）；`post` 阶段按 `(priority desc, id asc)`。

```
modified(target, subject):
  base = fixedUnits(dim(subject, dimension))                  # 0 基值
  rows = applicable(target, subject)                          # when 为真、scope 命中、未过期；(source.id,target,subject) 去重
  rows = per (target,stage): dedupe stackGroup → keep max by order
  if rows empty → return native base
  v = base
  v = v + Σ fixedUnits(add_i)                                 # 1 add：绝对量，不受罚
  P = pos mul by order; N = neg mul by order                  # 2 mul：正负分开
  pen = 0; for each m in P: s = m.unpenalized ? S[0] : S[min(pen++, 8)]; v = fixedMultiply(v, SCALE + fixedMultiply(m.value, s))
  pen = 0; for each m in N: 同上
  for m in max rows by order: v = max(v, m.value)             # 3 max
  for m in min rows by order: v = min(v, m.value)             # 4 min
  if set rows: v = set rows by order [0].value                # 5 set
  for c in post rows by order: v = lookup(c.curve, v)         # 6 post（曲线点为定点，线性插值截断）
  v = clamp(v, bounds(subject kind, base))                    # 7 clamp（bounds / boundsRelative / boundsByKind）
  return truncate(v, precision)                               # 8 round（向零截断）
```
- **叠加惩罚系数表** `rules.modifiers.stackingTable`：出处公式 EVE 04 §2.4 `S(n)=exp(−(n/2.67)²)`，n 从 0 起；表值由离线脚本（附录 E，F:/dnd-tmp/vol2/stacking.mjs）用双精度算出后**四舍五入到 4 位**并冻结：`S[0..8] = [1.0000, 0.8691, 0.5706, 0.2830, 0.1060, 0.0300, 0.0064, 0.0010, 0.0001]`，n ≥ 9 取 0。运行期只查表。（第二版的 0.8694 有误，RA-N2 指出；EVE 公开表的 86.9% 与 0.8691 一致。）
- `S[min(pen,8)]`：受罚序号超 8 取 S[8]→之后取 0。`unpenalized` 的条乘 S[0] 且不占序号。维度 `stacking:none` 时全部用 S[0]。
- **逐位一致的判定依据**：整条管线只有 BigInt 加、乘、整除、比较与查表，无浮点运算；输入（基值、修正值、表值）都是 JSON 十进制字串经同一 `fixedUnits` 转换；故同输入在任何 Node 版本、任何机器上结果逐位相同。B3/B5 用严格相等。
- `explain(target, subject)` → `[{stage, id, source, value, penalty, before, after}]`，逐段复算等于结果。

### 3.4 递减规则

`stacking:penalized`：防护/抗性、感知、速度、产率倍率、说服与观感倍率、价格倍率；`none`：容量、计数、寿命、日耗。来源豁免 `unpenalized:true`（种族基线、技能本身）。第三种曲线用 `post`。同一 `(source.id, target, subject)` 只计一条。

## 四 校验器

### 4.1 分级、时机与分期

`server-plugin/dimensions-validate.mjs` 在 `loadWorld` 跑 L0–L4，任一 error 即加载失败；内容管线调同一函数；运行态写回（偏离行、修正项、状态实例）调同一函数，失败即拒写并发 `dimension_write_rejected` 事件，状态不变。

| 级 | 检查 | 首期 |
|---|---|---|
| L0 语法 | JSON 可解析且无重复键（逐字符扫描，E-DIM-DUPLICATE-KEY）；表头四字段；id 格式与前缀；`behaviors` 非空 | 必须 |
| L1 结构与取值域 | 类型在清单；单位存在；precision 0–4；domain；enum 来自词表（无内联）；ref 格式（kind/kinds/vocab/dim/nullable）；set 唯一与大小；list 长度；struct 递归；显式 `[]`；curve 单调；distribution 参数、clamp、corr；`onUnknown` 存在；`derived` 可编译、变量存在、自引用带 recursive；`modifiable` 类型；`sample` 与 `derived` 不并存；继承写法合法、每维一种 | 必须 |
| L2 引用闭合 | 所有 ref 存在（含 generated/created）；类别键在词表；precedence 行存在、不含 abstract、与 broader 深度一致、每维有组；extends 目标与无环；**派生依赖图无环（两层）**；需求块无环；修正项 target 注册、stage/scope 合法、RX 可编译；效果族引用闭合；声明节点 uses 无环；词表字段按族 schema | 必须 |
| L3 必填完整 | `required` 四策略（不适用不计缺）；组件 requires；实例行 basis/sources；sources 推出值 = 直写值；成员偏差；全局 id 唯一（跨表）；实例行无继承写法 | 必须 |
| L4 跨表不变量 | 首期三条必须：INVARIANT-MASS-VOLUME（质量 = 密度×体积，容差 1 ulp of precision）、INVARIANT-PORTION-SUM（material map 和 = 1.0000）、INVARIANT-SEVERITY-ORDER；其余应当：职业 workstation 是 facility_type、文化 language 在词表、罪名 act 是动词、修正预算 budget、物种 bodyPlan 部位材料是 material、法典 offense 存在 | 三条必须 |
| L5 齐全率 | 不阻断；每表每维 `known / applicable / notApplicable / unknown` 四列（RA-S10）；写 `logs/dimensions-coverage.<date>.txt` | 应当 |

校验器只读维度表、词表、单位表、规则表、存档 created、state-owners.json；labels 只查键；规则里不含实体 id 字面量，前缀表来自表头；输出按 (table,row,dim) 排序。

### 4.2 报错格式

```json
{"code":"E-DIM-DOMAIN-RANGE","severity":"error","level":"L1","table":"material","row":"class_timber","dim":"heatValue",
 "path":"world/ontology/dimensions/material.json#/classes/class_timber/heatValue","got":75,"want":"[0,60] MJ_per_kg_dry",
 "message":"取值越界","hint":"木材高位热值约 19–21；核对 sources 单位"}
```
一行人读：`E-DIM-DOMAIN-RANGE  material/class_timber.heatValue  got 75  want [0,60] MJ_per_kg_dry  — <path>  (hint)`。`code` 形如 `E-<区>-<名>`/`W-…`，区 `DIM/MOD/EFF/VIEW/SEED/I18N/WRITER/PHASE`；`path` 为 JSON 指针或 `文件:行`；`got/want` 必填；同 (code,table,row,dim) 只报一次；末行 `errors=N warnings=M tables=22 rows=R known=K applicable=A`。message/hint 是校验器输出，允许中文。
