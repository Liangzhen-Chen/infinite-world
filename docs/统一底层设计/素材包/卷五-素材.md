### 1.2 十号卷目表“卷五”原文（十 §2，行 412–416）

- 标题：卷五 地点、地形与资源场。
- 子系统清单（原样）：1 地点包含树与坐标；2 分区、方位、感知通道（光、声、气味）；3 地形 / 群落 / 海拔维度表（温度、降水、高程→群落；一处解析取代 6 套）；4 地质与矿脉；5 地下层与洞穴；6 站点类型；7 资源场与再生律（renewable 接线；一律按 props 不按 id）；8 采集律（谁采、用什么能力、NPC 也采）；9 发展度与控制度；10 地形修正（建筑、补给、防御、路速）；11 法域槽派生；12 文化槽派生（一套解析）；13 进入权与私宅许可；14 省郡骨架与邻省条款（结构化）；15 边境混居与迁徙表达；16 地点环境状态读取（接卷二十）。
- 维度：地点（地形/群落/海拔/站点类型/发展/控制）、资源场。
- 接口：卷十（生成写入这些字段）、卷二十（天气、温度）、卷二十五（栖地、农田）、卷八（治安值、法域）、卷十七（路速、风险）。
- 作者：Fable。篇幅：约 800 行。
- 卷零 §0.7 第 7 行改名：§4.7 标题定为“资源场、再生律与栖地容量”。

## 2. 参考游戏做法

### 2.1 地点、世界生成、群系（子系统 3、5、6）

- 01-矮人要塞 §5：世界先播种高程、降雨、温度、排水、火山、野性六个场，不合参数则整图重做；植被与群系由高程/降雨/温度推出而非直接摆放；之后侵蚀、河流、命名区域、加地质与地下层，再播野生动物、初始化天气、放置文明。
- 01 §7.1 表第 1–4、9 行：世界生成（六场→群系→地质→文明→逐年历史）；地质与矿脉；地下层与洞穴（三层洞穴、岩浆海、地下群系、遗忘兽、地狱）；生物群系与善恶/野性（决定动植物、天气、复活地区）；站点类型（要塞、山厅、城镇、村庄、森林居所、暗堡、洞穴、塔、金库、巢穴、神殿、遗迹，由实体的 DEFAULT_SITE_TYPE/LIKES_SITE 偏好驱动）。
- 01 §2.6 领域：同一套词表可描述神、生物、材料、地区、庙宇；邪恶地区由常驻实体的领域塑造地貌，噩梦/黑暗领域地区出怪。
- 03-环世界 §12（引用关系图）：BiomeDef 向下引用植物、动物种类的出现率、天气出现率、疾病平均间隔；§15 表第 47 行：生物群系 = 温度/雨量/植被/动物/疾病/可采集的一张表；§10.4：户外温度随纬度/季节/时刻/生物群系。
- 02-大灾变 §17 表第 44 行：区域/世界生成靠 region_settings、overmap_terrain、mapgen、调色板、map extras，引用地形、家具、物品组、怪物组；§13 引用图：天气、家具/地形的种植与收获引用物品。
- 04-EVE §2.5：地图表给每个星系一个 security 数值字段与恒星类型；恒星与行星类型也是带属性的 type，“世界环境也走同一套属性”。

### 2.2 地质、矿脉、资源（子系统 4、7、8）

- 01 §2.1（无机物 token 小节）：成层方式（沉积/变质/火成/土壤/含水层/岩浆）、`ENVIRONMENT` 与 `ENVIRONMENT_SPEC` 定矿脉/矿簇的分布与频率、`METAL_ORE` 定矿石出金属的概率；加一种矿物只写 raw（01 §5 末“新增内容只填 raw”）。
- 01 §3.6：树木多格逐年生长、每主干格出原木、幼苗自然再生；农业按季选作物；害虫按栖息地刷出。
- 02 §17 表第 33、34 行：农业 = 家具 plant_data + 季节 + harvest；采集（forage）= 区域设置里的森林物品组。
- 03 §15 表第 29 行：种植由肥力/温度/光照到生长，收获量是 Stat。
- 04 §4.2/§4.4/§5.1：矿石→矿物→部件的多级链是数据；采矿量计入主权“工业指数”；越低安小行星越肥、行星资源越多（资源丰度由 security 字段派生）。

### 2.3 感知、环境、气味（子系统 2、16）

- 02 §17 表第 45、46、48 行：场（火/烟/酸/气）有强度层、衰减、免疫；排放源 emit 指向场；气味有 scent_types 类型表（仅一行，无细节）。
- 03 §10.4/§10.5：温度按房间；房间印象由财富、美观、空间、清洁合成。
- 01 §3.4：材料热属性驱动温度（本卷只涉及地点环境读取，主体在卷二十）。

### 2.4 发展度、控制度、地形修正、领地类型（子系统 6、9、10）

- 05-CK3 §6.5 表第 48 行：每伯爵领 1–7 男爵领，地形决定可建建筑与修正（农田补给 +50%、发展 +20%；山地防御 +12）。
- 05 §6.5 第 49 行：城堡/城市/寺庙/部落四类领地、1–4 级，谁能持有看政体与神职教义。
- 05 §6.5 第 50 行：每点发展 +150 补给、+0.5% 税与征召；控制每缺 1 点 −1% 税 −0.5% 征召。
- 05 §6.1 第 11 行（旅行）：速度与安全两参数，危险按男爵领地形/建筑/控制/观感；每 20 男爵领一事件；§6.7 第 77 行：战斗优势受地形、建筑影响，补给不足减值。
- 05 §2.8：修正键表的伯爵领/省组（控制、发展、观感、补给、堡垒等级、建筑槽）；键名 `<scope>_<what>_<add|mult>`。
- 05 §2.5 与 §6.5 第 54 行：文化“地域”类传统按山地领占比门控（如山地补给 +25%）；游牧政体的季节/地形/领地类型影响繁殖与迁徙。

### 2.5 圣地、文化槽、边境混居（子系统 11、12、15）

- 05 §2.4：圣地绑在男爵领上，三层修正（持有者/伯爵领/全信仰）；“地点 × 信仰 → 修正值”三元表是宗教接入地图的接口。
- 05 §3.3：文化接纳由传承、语言、风气、相邻或同地区等重合算出基线；融合与分化条件含控制比例与相邻语言（05 §8 启示 13）。
- 05 §4 表：伯爵领文化/信仰 → 封臣观感、民粹派系、改化任务；§6.4 第 44 行：领地改化由总管任务推进。
- 04 §5.1：同一 security 字段同时决定 CONCORD 是否来、精炼加成、泡泡可用、小行星肥瘦、任务报酬（治安字段由卷八b 持有，卷五提供 place 维度）；虫洞/Pochven 等按零安处理（04 §9.3 第 43–45 行，十 6.15 不适合）。
- 04 §9.3 第 41 行：探索与扫描（十 6.14 已归卷十七，不在本卷）。

### 2.6 种群与栖地（§4.7）

- 01 §3.6、§7.1（4）：生物按群系与野性/善恶出现；害虫按栖息地。
- 03 §15 表第 30、47 行：动物（驯养、产出、狩猎）与生物群系（植物、动物、疾病 MTB）。
- 02 §17 表第 39、44 行：怪物进化/怪物组按区域设置生成。

### 2.7 各游戏自陈的局限（与本卷相关）

- 01 §6：枚举表（含领域、站点类型相关的 historical_entity 类型）写在代码里；§5 生成器至 2025-07 才开放。
- 02 §16：地形/家具的使用函数与特例仍在 C++。
- 03 §14：BiomeDef、GenStepDef 的 workerClass 须 C#；求值顺序写死。
- 05 §8 启示 12–14：不用年份/名字门控大事件；不写死历史分裂；修正键用开放属性集合。
