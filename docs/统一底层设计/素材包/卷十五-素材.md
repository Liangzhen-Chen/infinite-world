## 2. 参考游戏做法

（DF=01，CDDA=02，RW=03，CK3=05；EVE=04 无直接相关段落。）

**DF《矮人要塞》**
- 01 §2.8 交互与综合征：交互 = 源 + 目标 + 效果；源可以是生物动作、攻击、食入、神、秘密、地区、扰动、实验等；综合征写在材料里（毒液、酒、邪雨），按注入/接触/吸入生效，效果是一组身体与能力影响。吸血鬼、狼人、死灵法师、木乃伊、龙息、邪恶云雨、毒蛇、酒都是同一套数据，没有各自的代码分支。
- 01 §3.5：神诅咒亵渎者为吸血鬼/狼人；由死亡相关神授予刻有秘密的石碑（死灵术）；神造天使守金库，外观材料取自神的领域；每世界若干种神金各挂一领域。
- 01 §7.5 #56 交互与综合征、#58 死灵与亡灵（秘密石碑→死灵法师→塔→起尸）、#61 神金与神造物；#18 奇想心境与神器（×120 价值）；#23 死亡、尸体与鬼魂（未葬者化鬼骚扰生者，纪念碑安息）；#68 程序化生成器脚本（神罚、神造物、死灵实验等开放为 Lua）。
- 01 §8.1 第 3 条：效果层统一为"源→目标→效果"+挂在材料上的综合征，是"一类一起覆盖"的范本。

**CDDA《大灾变》**
- 02 §10 附魔值：一条附魔 = 载体条件（手持/穿戴）+ 一组对角色数值（130 余项）的加/乘；载体可以是物品、突变、生化插件、效果；物品走 relic_data。突变实例的全部效果就是一条附魔。
- 02 §11 效果与条件效果：effect_type 有强度、时长、每级叠加修正、移除/阻断其他效果；effect_on_condition 有条件+效果列表，可按激活/定时/事件触发，物品、突变、配方、法术、陷阱、怪物死亡都接受钩子。
- 02 §17 #54 魔法/法术/附魔/遗物、#55 条件效果脚本。

**RW《环世界》**
- 03 §15 #43 机械体（类比部位，同一健康模型）、#44 灵能/头衔（psycast 是健康状态，人格武器是特质；影响市值）、#45 异象（变异体、收容强度 Stat；卷十六为主）。
- 03 §7 / §16 第 4 条：伤、病、义体、药效、环境状态用同一结构（与综合征=状态容器相关）。

**CK3（05）**
- 05 §6.1 #14 灵感与文物：文物分穿戴槽与宫廷槽，稀有度定耐久与修理，由委托决议产出，丢失生宣称。

**EVE（04）**：无相关段落（04 §9.1 #7 植入体判不适合）。
