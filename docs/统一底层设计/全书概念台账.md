# 全书概念台账（定稿）

（2026-11-13 设计作者核定。依据：草稿 `全书概念台账(草稿).md`、10 号文档 §二 卷目、卷零 §0.7、卷二附录 G、卷一附录甲。本文只做归属裁定，不改任何已成稿卷。）

## 0 效力与读法

1. **效力**：29 卷开写以本表为准。一个概念只在"定义方"一处写全（字段、取值域、公式、状态机、不变量）；使用方只写"使用方式"栏给出的那一句引用，不得复述定义、不得另起字段名。
2. **三层分工（总则，后文所有裁定都由它推出）**
   - **格式层 = 卷二**：凡跨两卷以上使用的通用形状——状态容器、效果族与 effectCall、需求块、配方行形状、修正键、词表族、封闭枚举、派生维度、种子键、持有边、Text/Sealed——格式、校验、加载、读函数只在卷二。
   - **语义层 = 领域卷**：某张表的字段含义、取值域、通用规则（公式、状态机）归卷目中拥有该子系统的那一卷，且只归一卷。
   - **数据层 = 登记方**：其他卷只向那张表"登记行"，不新增字段含义、不另写规则。本表"使用方式"写"登记行"的，都是这一层。
3. **判别口诀**（各卷遇到本表没列的概念时自行套用，套不出再报）：
   - 可转移、可花费、守恒 → **账户**（机制卷六 §4.1，资源种类行由领域卷登记）。
   - 有档位、随时间衰减、挂修正 → **状态容器**（格式卷二 §1.11，实例由领域卷登记）。
   - 能由别的维度算出 → **派生维度**（格式卷二 §1.12），不许手填。
   - 是"正在做的事" → **动作**（卷九 §4.1）；是"能不能做" → **谓词**（卷二 §2.5）。
   - 是"发生过的事" → **事件类型行**（卷二十四 §4.2）。
4. **章节号**：卷一、卷二用成稿章节号；卷三起用卷零口径 `§4.n`（= 卷目子系统序号；卷八、卷八b 按卷零 §0.3）。
5. **理由栏简写**：`目` = 10 号卷目该卷子系统原文即此归属；`零#n` = 卷零 §0.7 第 n 行已定；`G` = 卷二附录 G 已定；`甲` = 卷一附录甲已定；`X-nn` = 见第一部分冲突裁定。
6. **使用方式栏简写**：`读 xxxView` = 调卷二 §2.1 该类实体的唯一读函数；`登记行→表` = 只加数据行；`调入口` = 调定义卷的单入口函数（函数名由定义卷在其 §5 给出，使用卷不得自拟）；`经账本` = 只通过转移写；`订阅` = 订阅事件。
