# 农田害兽实现与未完成项

依据指南3.8.3，原种群模型与粮食模型各自运行，捕食者减少无法影响收成。本轮将农事与生态按日交错，先以当天开始时的实际种群计算农田损伤，再结算该日的恢复、捕食和迁徙。长等待与逐日等待一致，不以整个月后的动物数量倒算此前农田。

当前仅配置公共燕麦田、斑鼻田鼠和北林赤耳林狐巡游。田鼠18只以下不计损伤，24只达到完整压力，每天最高增加12基点损伤，累积上限35%。狐按每只每周1.5的初值乘猎物密度进行有限捕食，数量从实际未见田鼠扣除并计predated；剩余两只代表难以触及的藏穴，不补回已灭绝动物。巡游必须有连续可步行道路，出发季道路封闭不隔空扣猎物。全部数值为D030开发初值，不是指南给定。跨区捕食是区域周度抽象，已接触捕食者的逐段移动、狩猎动作和已接触猎物的自治死亡尚未实现。

损伤在作物成熟时冻结，收获计算潜在产量与实际产量之差，ledger.potentialHarvested=harvested+pestLost。实际harvested才进入种粮或粮仓；害兽损失发生在收获前，不再倒扣仓内粮食。分批收获保持累计差额，防止后续损伤反向扣已存谷物。成熟后延迟收割损失、仓储鼠害、其他作物和牧草未接入。新报表分开生长新增百分比与当天收获前损失，不把无收获当无新增损伤。

guard须到有正在生长作物的公共田，耗90分钟和体质/已有农夫技能检定。成功后未来四小时在害兽实际活动时段减损50%，从完成工作时起算，不能恢复已损伤作物、杀动物或领取报酬。田鼠18:00至06:00活动，白昼巡田不覆盖其夜间损伤；重叠保护按时间并集，不叠加减损。当前保护不要求玩家持续留在田里，采用短期驱赶效果；持续值守的玩家位置/疲劳和NPC守田班次仍待后续动作计划。
