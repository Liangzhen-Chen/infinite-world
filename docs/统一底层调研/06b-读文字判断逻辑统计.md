# 06b 读文字判断逻辑统计（master，只读审计）

日期：2026-11-13　范围：`server-plugin/`（主统计）、`extension/`（单列）、`tools/`（单列），`tests/` 不计。
方法：只用 Grep 静态检索加人工逐行判读，没有运行任何代码。**计数单位是“行”**（一行里有多个判断也只算 1）；命名正则或词表的定义行不计，只计使用它的行（例如 `business.mjs:651` 的 `SLEEPING` 不计，计 `:766`）。

判读口径：
- **计入**：读描述性文字字段（activity、purpose、name、terrain、climate、industry、occupation、task、content、reason、rules、personality、polity、title、contextReason、error.message 等），用正则、includes、startsWith 或 === 去决定分支或数值。
- **不计**：只用于显示或拼装给玩家看的文字（例如 `npc-cognition.mjs:41` 把数字替换成“若干”、`remote-generation.mjs:425/430/433` 取地名词干、`notables.mjs:102` 挑一条报错文字）；ASCII 代号比较。
- **待定**：①玩家输入或模型叙述的解析（输入本身就是自然语言）；②中文枚举值的精确比较（`status==='濒死'`、`type==='送货'` 之类），它们不是描述，但同样依赖语言；③其它判断不清的行。
