## 读法

- **列**：子系统｜出处（设计文件:行或 §）｜实现状态与代码位置｜统一维度 / 统一入口｜写死或读文字。
- **状态口径**（沿用 00 册）：**已实现** = 有数据、有读它的规则、有入口用到；**部分** = 三者缺一，写明缺哪段；**未实现** = grep 不到或只有名字。
- **维度 / 入口口径**（沿用 06a §四）：维度 = 该子系统的判断是否只读结构化字段；入口 = 是否只有一个读函数（如 itemView、facilityKind、canAct）。写"有/无/部分"并注明。
- **写死或读文字**：引用 06a 的实例 id 字面量、自由文本正则、手填常数、跨系统直写；AUDIT2 的 id 写死 97 处；AUDIT3 的硬编码条目。
