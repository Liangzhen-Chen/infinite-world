# run-008 设计预审（第六轮，独立预审，非正式判分）

审查对象：docs/架构设计/ 第五轮修订后的设计正文（目标架构.md、01–15 章、附录A）。
审查者：未参与任何设计与修订的独立子代理。只读设计文档、run-008/events.md、待用户确认.md 末尾决定、事件推演测试.md 的判分纪律；未读代码，未读其他 run 的文件。09 章走查、修订记录、根因分析只作检索线索，不作证据。

## 判分口径

- **自**＝自然得出：只用设计正文写明的机制，加上可以放进设计规定位置、按设计规定形状写的数据，就能得到预期。每条都写出所用章节；需要加数据的，写出数据放在哪个文件、什么形状。
- **补**＝需补数据：方向对，但数据放在哪、什么形状、谁来触发，设计没有说明；或者只能靠类推设计者本意（例如把专为 A 场景写的规则套到 B 场景）。
- **缺**＝设计缺口：现有机制表达不了，或者按现有机制推出的结果与预期相反，而且加数据也补不上。
- **矛**＝设计矛盾：不同章节（或同一章节内）的规定互相冲突，结果取决于读哪一处。

计数：E 题每条编号预期算 1 条，二阶后果算 1 条；N 题按"加什么 / 装上后各条 / 二阶（N1–N5）/ 卸掉后 / 同装 / 易错"拆条，每类算 1 条。E 题的"易错"不计分，但如果易错项在设计下确实会发生，会在备注里指出。

从严原则：预期结果如果依赖未定义的触发方、未定义的行为主体、未定义的数据形状，一律不算"自"。

### E1 里正之死与转生（7 条：自 5 / 补 2）

| 条 | 判定 | 依据 |
|---|---|---|
| ① 遗产按族谱给法定继承人；存款先抵扣贷款，余额进遗产 | 补 | 前半句：04 §4.2 第 2、9 步，继承表（民事②），结论自然得出。后半句不成立：loan 的 `onDebtorGone` 缺省是 `assume_by_heirs`（01 §1.4），贷款随继承转移，不在遗产里先清偿；民事十类（附录A §A.7）没有**抵销**条款。法典把 onDebtorGone 覆盖为 accelerate 后，贷款进入第 8 步清偿，但遗产手里的存款是对钱庄的债权，不是现金，须先由遗产向钱庄支取。谁代表遗产去支取（遗产管理人）没有定义；interim 实体又"没有位置"（01 §1.2），无法满足 obligation.settle 的在场要求（06 §6.3）。见矛盾 C3 |

### E4 失智的老族长（7 条：自 5 / 补 1 / 缺 1）

| 条 | 判定 | 依据 |
|---|---|---|
| ① 确诊失智后可申请监护，设立前后的行为效力分开计算 | 缺 | 设计没有**成年人的监护设立程序**：guardian_of 只由 kin:parent 为未成年人开立，或在宣告失踪时开立 property_only（01 §1.2、04 §4.5.1）；案件种类 `declaration` 只有失踪、死亡、撤销（附录A §A.7）。行为能力只有二值：失能状态的人 `canAct` 为假，什么提案都发不出（06 §6.5）。所以如果把失智做成失能状态，他根本当不了地契、投不了票、口授不了遗嘱，与情境矛盾；如果不做成失能状态，他的行为完全有效。"限制行为能力"没有表达方式。设立监护之前的行为可以靠"签约时无行为能力"的民事事实认定（05 §5.2.7）事后撤销，但监护本身设立不了 |
| ② 当铺收押公田地契属无权处分，族人可撤销，当铺可向林翁追回当本 | 自 | 林翁以族长职位 actedAs 处分族产：章程 `authority` 把"族产处分"声明为 `requiresRatification`（05 §5.3，数据在章程）→ 处分成立但处于 pending_ratification；族中指定职位不追认 → 失效 → 已履行部分按民事⑨返还（当铺退还地契，林翁返还当本，形式是 compensation 义务） |
| ③ 大会投票以最后一次有效表态为准，或认定无效后重计 | 补 | 议案表决由章程议事方式决定（05 §5.2.5），但同一人对同一议案多次表态时取哪一次、表态时的行为能力怎么认定，没有规定数据位置与形状 |
| ④ 两份口授遗嘱都缺见证，按法定继承，不能任选一份 | 自 | 04 §4.4 与民事② `testament`：形式要件（见证人数）不满足即无效，没有有效遗嘱时按继承表；"多份取最后一份有效者"只在有效的遗嘱之间比较 |

### E6 被附身的税吏（5 条：自 2 / 补 1 / 缺 2）

| 条 | 判定 | 依据 |
|---|---|---|
| ① 贿银收归公库或追缴；刑责按"非本意"条款减免或审理，不能直接定罪 | 缺 | 附录A §A.3 把"被附身"列为失能：宿主 `canAct` 为假，什么提案都发不出。可是三天里"放行商队、收受贿银"确实发生了，这些事件的行为者是谁、附身生灵怎样借宿主的身体行事（actor 记谁、actedAs 记什么），设计没有定义。13 §13.4 只写了"人借生灵对人施加算人对人"，这是反方向的情形。行为者没法确定，罪名表的 roles（principal = 事件发起者，05 §5.2.3）就求不了值，"非本意"豁免也就无处挂载 |
| ② 驱魂属精神类，被附身者无法同意时须由亲属或法定代理人同意，否则违规 | 补 | 附录A §A.15 同意的来源只有三种：本人、代理（guardian_of、章程授权的职位）、法典紧急条款。亲属本身不是同意来源；被附身的成年人通常没有 guardian_of（成年人监护设立不了，见 E4①）。民事④"同意代理范围"能否把亲属加进来，数据形状没有写 |
| ③ 私盐运到远方售出，远方盐价下跌，本郡关税少收 | 缺 | 前半句自然得出（15 §15.2）。后半句得不到：关税是"经过关卡节点时按税表自动发生的转移"（05 §5.1、15 §15.7），是反应规则，不经过税吏的任何动作，也不依赖稽查。税吏放行与否都不影响扣缴，"关税少收"无从发生。设计没有查验、申报、漏征这一层，走私和受贿在税额上没有效果 |
| ④ 追查商队首领，证据依赖目击者传闻 | 自 | 05 §5.2.7 证据评分：证人可信度、见证版本完整度；指控只能依据自己的主观视图 |
| 二阶：同僚怀疑他装疯，好感下降；关卡常驻道士，开支增加 | 自 | 推断规则"症状 → 病 / 祟 / 装"（13 §13.4）；组织候选"雇用"→ employed_by + wage |

易错检查："把附身当成本人意志直接定罪"在设计下会以另一种形式出现：行为者无法归属，可能被记到宿主身上（见①）。

## 矛盾清单

### 落题矛盾（3 处，均使当轮不达标）

**C1 委托代理的权能来源（落 E3②）**
- 附录A §A.2："委托、代办 → **义务**（不是持有）；以他人名义行事时事件记 actedAs"。
- 附录A §A.15 `authority(actor, op, target)` 的来源只有五项：持有的 derives.authority、法典授权表、章程 authority、有效决议、认可条目 issuers，**没有义务**。06 §6.3 transfer 的动用权来源、05 §5.3"代理与追认"列出的代理来源，也都只有持有（holds_office、operates、guardian_of、appointed、commands）。
- 后果：受托代管人（同伴、掌柜、经纪人）以委托人名义做的任何行为，按 §A.2 成立，按 §A.15 和 06 §6.3 在事务内被拒绝。

**C2 成年时终止监护（落 E19⑤）**
- 04 §4.3 guardian_of 一行的"标的 gone"列写着"close（被监护人成年或消失）"。
- 04 §4.1、附录A §A.0 与 §A.3 规定：事实改变（成年）不是触发，零交接；01 §1.2 又把"是否成年"列为禁止存储的派生值。成年那一刻不会产生事件，也不是实体消失。
- 后果：监护在成年时是否关闭、由什么关闭，两处规定互相冲突。凡是"派生值跨过阈值时要关闭或开立持有"的情形（成年、服刑期满以外的年龄限制、聚落降级）都有同样的问题。

**C3 无位置实体的账户与"价值有位置"（落 E10①；E1① 同时受影响）**
- 01 §1.2 规定 interim（遗产、清算、案件、工程、议案）和非聚落的 collective（政体、组织）"没有位置"。
- 01 §1.6 与 15 §15.1.1 规定：价值的位置 = 所属实体的位置；transfer 要求物理可达，obligation.settle 要求债务人（或代理）与债权人同处一个节点。
- 15 §15.1.1 只给"不在场的**债权人**"安排了托管账户；无位置实体作为**债务人**或付款方（工程发工钱、遗产支取存款、政体公库收关税）时，在场条件无法判定。interim 实体也没有定义代理人或执行人。

### 不落题矛盾与不一致（5 处）

**C4 citizen_of 的标的**：01 §1.3 写作 person → **settlement**；01 §1.2 写"按 home 所在聚落的**主权政体**开立"；05 §5.2.1 的 scope 写作 `citizen_of(政体)`，05 §5.6 写"沿它传导到政体"。标的模板到底是聚落还是政体，三处说法不一致。

**C5 creature 能否被 owns**：01 §1.3 与 04 §4.3 规定 owns 的标的只有 item / building / node / population；01 §1.10 的精怪与驯兽个体一行却写"被 owns / tamed_by……"，05 §5.5 写"幼崽归属缺省为母畜 owns 持有人"（母畜是 creature 个体），15 §15.2 也给生灵个体估值。家畜个体能不能被买卖、能不能进遗产，由此说法相反。E5 的"把鲤精卖给酒楼"、N5 的坐骑交易都受影响，但没有落在计分条目上。

**C6 借尸还魂**：13 §13.7 写"借尸还魂 = possesses 对尸身（vessel 形态）的变体"，而尸身是 wreck（thing 模板）；13 §13.4 与 04 §4.3 规定 possesses 是生灵 → **人**。

**C7 交接表不完整**：I5 规定每种持有必须声明 handover 三项与 onSubjectGone，否则启动失败；但 04 §4.3 的 core 注册表示例里没有 kin、household_member / household_head，而它们恰恰是继承、监护顺位、祖先回溯（N8②）所依赖的持有。

**C8 持有变更原语的权能校验不对称**：06 §6.3 的 holding.open 要求 `authority`，holding.close 列出了发起者限制，holding.transfer 却只校验"可转让、对价同事务"，没有说谁有权发起。非所有人能否转让所有权，取决于读哪一行（E3①、E18① 的根因之一）。

## 修改建议（按严重度）

**S1（严重）非所有人处分与占有**：在原语层区分**占有**（位置事实）与**所有**（owns）。holding.transfer 补上权能校验。定义"无权处分"的表达：非所有人对物品开立 pledged 或 transfer owns 时，提案**成立**，但打上 `unauthorized_disposition` 描述标签，效力由民事⑨（善意取得、返还）决定，而不是在事务内拒绝。不记名票据的债权人改为"持票人 = 占有人"，或另设 `bearer` 条款；补上挂失与止付的程序条目。影响 E3①、E18①，并波及 E4②、E12。

**S2（严重）委托代理（C1）**：二选一：①把 `authority()` 的来源扩展到"代理类义务"（委托条款写明权能范围与是否可转委托）；②把委托改成持有 `agent_for{scope}`，并在附录A §A.2 改口。同时写明越权的处理（voidable / 拒绝）。

**S3（严重）无位置实体的执行人与在场规则（C3）**：给 interim 与非聚落组织定义**执行职位**（遗产管理人、工程管事、公库出纳；缺省由继承人顺位、发起人、组织首领担任），无位置实体的清偿按执行人或指定网点的位置判定在场；把 `autoSettle` 写进 06 §6.3 的在场例外。影响 E1①、E10①、E19，也涉及税收入库。

**S4（严重）派生阈值跨越不是事件（C2）**：增加一个由框架产生的事件 `threshold_crossed{derived, entity, from, to}`（成年、人口跨过等级线、寿限），钩子与反应规则可以订阅它；guardian_of 改为钩子 `event(threshold_crossed: adult)` → close，并从"标的 gone"列移出。也给 E9 的降级（以及宽限期）提供挂点。

**S5（严重）行为能力分级与成年人监护**：在失能（`canAct` 为假）与完全能力之间加一档**限制行为能力**（可以发起行为，但效力待定或可撤销）；增加案件种类 `case:incapacity`（申请 → 鉴定 → 判决开立 guardian_of，效力只及于此后的行为）；guardian_of 的持有人模板放宽到 office 或 org（公库、寺观收养）。影响 E4①、E9③、E6②。

**S6（严重）税收的征管层**：现在关税是节点上的自动转移，税吏、放行、受贿、漏征都影响不到税额。建议把关税改为"申报 → 查验检定（读税吏的 `effective` 与 `dutyOfCare`）→ 征收"，没有被查验的货物按实际申报额缴税；走私与受贿从此有可表达的税额后果。影响 E6③，也是 E20"关税减少"一环的前提。

**S7（中）附身者的行为归属**：规定附身期间宿主身体所做行为的 `actor` 记为附身生灵（`actorAs` 记宿主的身份键），宿主保持失能；罪名表增加"非本意"豁免谓词的标准形状。影响 E6①。

**S8（中）复活与 restored 的一般化**：把 04 §4.5.1 的 restored 语义提升为通则（适用于 declared / death / 还阳），写明哪些动作或程序可以产生 restored（神迹动作、冥府案件），以及尸身 wreck 和亡魂实体如何处理；婚约（promise）在配偶复活时的效力写进民事②或③。影响 E2①②③。

**S9（中）个体与种群单位的转换**：定义"捕获 / 显形"转换：种群账户 −1 进入一个显式汇（如 `sink:individuated`），同一事务内 create(creature)，并保留守恒对；修正 C5，明确 creature 个体能否被 owns；补上人格承认条目（`recognition.what: personhood`），把 citizen_of 的持有人模板放宽到"被承认为人的 creature"。影响 E5①③、N5①。

**S10（中）幻象物本体**：定义带 `illusion: {expiresAt, source}` 的物品实体：不进账户、不能作为制造或货币的投入、到期 destroy；被 pledged 或出售时，按 purports 与真实价值 0 结算损失。影响 E7①。

**S11（中）征用与议案待执行期**：execute 类决议通过时，冻结或登记其标的（`pending_execution` 持有或 frozen），征用的标的与补偿对象按表决时点确定；补偿条款纳入民事或程序族。影响 E16①②。

**S12（中）知情与记忆的分离**：区分"印象"（立场的输入，不随遗忘消失）与"记忆可得性"（主观视图能否检索到）；后者作为一个开槽的派生值（`social:recall`，按年龄、显著度修正）；自知域里"自己签过的条款"也受它影响，但文书不受。影响 N4 全组。

**S13（中）tell 的采信**：知情域在"可靠转述"之外，读讲者对听者的信任立场与命题的先验可信度（开槽的派生 `social:credence`），避免任何自述都被当作亲历者转述而采信。影响 E1⑤。

**S14（中）包间同一判定的唯一赢家**：给反应规则、动作和表行增加 `decides: <判定 id>` 声明，同一判定 id 由多个包声明时，按槽位冲突（§12.4.4）处理；表行的主键重复时报冲突。影响 N6 同装、N7 同装。

**S15（低）若干缺失的数据形状**：抵销（民事①）；存款利率派生（15 §15.5）；追诉时效的中止与中断（刑事、民事）；投票多次表态的取舍（章程 decision）；加工与添附的取得（民事⑩）；未来货物或债权作担保（pledged 的标的扩展到 instrument）；河段多出边时的分水规则（05 §5.5）；运行期新建路线边（工程完工产生或恢复路线边）；由坐标派生的空中路线；卸载策略可读法域条款；梦境等地点类别的原语限制（patchable 扩展到原语前置）；俸禄表作为可议案修改的规范条目；玩家角色死后的接续（继承人、转生）。
