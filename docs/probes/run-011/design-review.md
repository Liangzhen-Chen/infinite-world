### E1 清洁术取代挑粪工（6 条：自 4 / 补 2 / 缺 0 / 矛 0）
- ① 卫生改善 → 痢疾发病率下降可查：**自然**。05 §5.5 感染率 = 病种基率 × 水质暴露 × 密度 × 措施（槽 `health:infectionRate`，§A.16）；"净秽术"是注册动作（06 §6.4），outcomes 用 `fact.set` 写包声明的扩展事实（12 §12.2.3 `ontology/facts.json`，如 `hygiene:cleansed{building, until}`）；需加数据：`rules/modifiers.json` 一行 `{target: health:infectionRate, stage: mul, when: fact(settlement,'hygiene:coverage')>阈, value: …}`；发病事件进编年史即"可查"（01 §1.7）。
- ② 挑粪工收入归零、转行或离镇：**自然**。挑粪是 service 义务（01 §1.4）由家户的自治候选发起（05 §5.7.1，需补一条候选 `need:hygiene`，applicability 读主观报价比较两种服务）；家户改请法师后无新 service 义务 → 收入为零；挑粪工若受雇于商号，用工候选"销量 ÷ 人均处理量 < 在岗工时 → 解雇"（05 §5.1）；转行 = `need:money` 下的辞工/跳槽候选读 `wageQuote`（§A.17）；离镇 = 迁居/逃户候选（§A.17）。数据：候选行与 `need:hygiene` 词条（12 §12.3.3 上位 `need`）。
- ③ 粪肥供给消失、肥价涨、秋收下降：**需补数据**。后半段自然：肥料存量以修正项进 `economy:yield`（05 §5.1 "农具、耕牛、肥料的存量以修正项进入槽"）、肥价由市场投影随存量下降上涨（15 §15.2）。前半段缺口在"人粪从哪个源流入"：01 §1.6 规定 `src:*` 只能由声明了该源的规则引用，可用源族只有 regrowth / birth / weather / mint / craft / issue / genesis / harvest / **husbandry**；`src:husbandry` 定义为"物种 `yields.alive` × 头数流入 **owns 持有人**指定账户（缺省畜群所在建筑）"，person 既无 owns 持有人也未写明其物种数据可声明 `yields.alive`（§A.15 capacity 条暗示人类有 `lifecycle.maturity`，但 01 §1.10 的 person 行未引用物种数据）。设计未说明"人口的夜香产出"该挂哪个源、按什么口径（按居民数？按 `body.satiety` 消耗？），须补：01 §1.6 写明 `src:husbandry` 对 `resident_of` 人口的用法，或为 `sink:consume` 声明副产品。
- ④ 失业者及亲属、农户对玩家好感下降：**需补数据**。05 §5.6 立场只由 impress 事件（反应规则对 harm/gift/breach…）与"状态评价"时钟（对状态谓词产出 impress）产生。失业不是玩家造成的事件（无 harm，无起因链指向玩家），要靠状态评价谓词"我的主顾改请了某人"——谓词可读"任何状态"，但对"竞争导致失客"的谓词需要读主顾的 service 义务对手方（visibility 仅当事人，须经知情门控 §A.15），设计未给出这类"竞争归因"谓词的形状；农户一环更远（粪肥断供 → 玩家），只能靠推断规则产出 belief，而 05 §5.6 的印象公式只计"事件"，未写 belief 是否进事件权重表。亲属传导本身自然（kin 传导系数，05 §5.6）。
- ⑤ 法术服务收入计入玩家、可征税：**自然**。service 义务清偿 = transfer 入玩家账户（01 §1.4）；税 = 反应规则按税表条目（05 §5.1、§A.7 税表 `base` 族开放）。数据：王国法典税表加一行 `{base: service, rateBps, recipient: treasury}`。
- 二阶 秋收下降推高粮价、抵消省下的钱：**自然**。田地储量账户减少 → 有效存量降 → 稀缺项升（15 §15.2）；"省下的钱"即少付的诊疗 service（05 §5.5）。前提是③的肥料链成立。
- 备注（易错"未算粪肥上游"）：正是③所指的源未定义处。

### E2 一头野猪三份赏钱（7 条：自 7）
- ① 野猪只死一次、尸体与首级只有一份：**自然**。首领是 creature 实体，`transition(gone, death)` 一次（04 §4.2 第 2 步同事务 create 尸身 wreck）；I4 幂等起因；首级 = 物种 `yields.death` 表经 `src:harvest` 流入残骸账户，割取 = 从残骸账户 transfer（13 §13.3；01 §1.6）。数据：野猪王物种行 `yields.death: [{resource: 'goods:boar_head', qty: 1}]`。
- ② 赏金只从公库扣一次：**自然**。bounty 义务 `creditor.open + firstToSatisfy`，完成事件确定债权人后清偿一次（01 §1.4）；同刻多人完成按争夺池 lottery（14 §14.2 缺省表）；清偿是 transfer，I1/I2。
- ③ 三人行为有时间线、可作举证：**自然**。事件带 seq、时间、起因链、见证（01 §1.7、14 §14.2）；证据项 = 证言（证人可信度）+ 现场 mark（05 §5.2.7）。
- ④ 判赏结果按法典或悬赏条件、可追溯：**自然**。谁清偿由条款快照的 `firstToSatisfy` 谓词决定（数据：悬赏条款写"交付首级到县衙"或"致死事件的起因链含其行为"），输家可立 claim 走民事案件（§A.2 claim；05 §5.2.7），判决读证据评分；解析可解释（05 §5.2.2）。备注：若条款写"致死者"，须读 death 事件 `causes` 各因权重——权重如何分配设计未写（见 E11②，不在此重复计分）。
- ⑤ 输家对赢家及县衙好感下降：**自然**。判决/清偿事件 → impress（05 §5.6 事件权重表 judgment 行），归因系数沿起因链分给县衙职位（05 §5.6 归因）。
- ⑥ 野猪王死后田地损害停止：**自然**。害兽压力由种群/首领 `controls` 持有派生（01 §1.5、05 §5.5）；持有人 gone → controls close（04 §4.3），迁徙与践踏规则读不到它。
- 易错（三人都记为击杀者 / 赏金三份）：**自然**。vital 事件的 actor 唯一（§A.15 行为归属），bounty 单次清偿；三人的行为各有事件但只有一条 transition。

### E3 伪造族谱入族分祠田（6 条：自 6）
- ① 识破概率与鉴别者能力相关：**自然**。伪造族谱 = `purports` 有、`represents` 空的文书物品（01 §1.2、05 §5.4）；鉴定 = 检定动作（技能 + 工具 + 对照真品），成功产生"识破"事件进知情集合；族长"眼花"= 其技能/状态进难度。
- ② 已分祠田收成追还：**自然**。入族 = `holding.open(member_of 宗族)` 与分祠田 = `holding.open(leases/owns 份额)`，开立事件带 `deceive` 描述标签（06 §6.5）；`validity(event, j)` 读标签 → void/voidable（§A.15 效力）；返还走民事⑨ 不当得利 / 撤销 → compensation 义务（§A.7 ⑨、05 §5.2.7 救济顺序）。数据：王国法典民事⑨ 的 `unjust_enrichment` 条目。
- ③ 伪造文书定罪：**自然**。core 罪名表有 `forgery`（05 §5.2.4），谓词读 `purports ≠ 真` 与 `knows(actor, 伪造事件)`。
- ④ 祭祖仪式是否作废、宗族有处理：**自然**。仪式是带 rite 块的动作，其效果（祖灵 upkeep 的转移、impress）已发生且不回滚（04 §4.5.1 通则）；"作废"只能是宗族章程成员层条目的反应（05 §5.2.6：谓词 + 内部制裁 + 内部程序）。数据：宗族章程 `rules` 一条 `{when: reveal(forged_lineage), do: [impress, 再祭 schedule]}`。
- ⑤ 族长失察威望下降：**自然**。角色 `negligent` 读职位 `dutyOfCare`（05 §5.2.3）；揭穿 reveal 事件沿起因链按归因系数给族长 impress（05 §5.6）；状态评价时钟也可读"接纳了伪族人"状态。数据：族长 office 的 `dutyOfCare` 列表。
- 易错（伪谱写入即成真实血缘）：**自然**。kin 持有"不可转移"、只由出生/婚姻/过继事件开立（01 §1.3），文书只是证据、不是真相（05 §5.4 文书）；入族开的是 member_of，不是 kin。

### E4 逃进寺里的人（6 条：自 6）
- ① 庇护特权仅王国法典有效、城邦不承认：**自然**。庇护 = 王国法典一条规范条目（程序或豁免类，scope `place_subtree(金顶寺)`，§A.7），限制在该子树内对人开立 `guest_of{detained}` 的权能（`authority()` 读法典授权表，§A.15）；规范栈按事件地点解析（05 §5.2.2），城邦法典对王国境内事件只经属人层罪名生效，不含此条。数据：王国法典 `procedure.sanctuary` 或 `exemption` 条目。
- ② 强行入寺是越境执法、引起外交事件：**自然**。城邦捕快在王国境内无权能 → 开立 detained 照常成立但标 `authority:none` → `offense:unlawful_detention`（05 §5.2.4、§A.15 受限）；捕快 citizen_of/holds_office 城邦 → 属人传导到政体（05 §5.6）→ standing(王国, 城邦) 下降；照会 = 政体自治候选读 `diplomacy:leverage` 与 standing（05 §5.7.3、§A.17）。
- ③ 剃度与否影响庇护效力：**自然**。条目 `when` 用 RX 读 `member(x, 寺) / devotee_of`（§A.13）；数据写在①的条目里。
- ④ 住持选择影响两政体对寺的好感：**自然**。拒绝交人 = refuse 事件（06 §6.6 社交族）→ impress（事件权重表 refuse 行，05 §5.6），组织作为持有者读首领知情集合（§A.15 知情门控）。
- ⑤ 出寺即可被抓：**自然**。城邦 `wanted` 的执行范围由引渡（allied_with 条款）派生（01 §1.3 wanted、05 §5.2.4）；有引渡则王国执法者可执行，无引渡则城邦捕快出寺抓人仍是②的非法拘禁——"可被抓"成立但合法性随条约数据。数据：两政体 `allied_with` 条款 `extradition`。
- 易错（逃犯隐身挂起）：**自然**。逃犯是 person，`guest_of{voluntary}` 并入东道日程（05 §5.8），义务照常到期（I29），钉住（被 wanted 的 subject 侧，§A.15 钉住 (b)）。

### E5 年关前一天的过户（7 条：自 7）
- ① 过户须走登记程序、当日能否生效按规则：**自然**。`holding.transfer(owns 田)` 在事务内即成立并写缔结快照 `concluded{form}`（01 §1.3、06 §6.3）；"是否算数"由法域 `recognition{what: holdingKind, selector: form}` 条目对快照求值（§A.15 承认、§A.7 认可条目）；税表读 `holdings(x, kind)` 缺省只含视角法域承认的持有（§A.13），所以未登记的过户在郡府眼里不算。数据：郡法典 `recognition` 一行"田产 owns 须 `form: registered`"。
- ② 监护人自我交易可能无效：**自然**。十岁儿子 `capacity: limited`（§A.15 民事④ majority 表），受让事件标 `capacity:limited`；父亲同时以 guardian_of 的 `derives.authority` 代管（05 §5.3 法定代理），民事④"代理权范围"可把自我交易排除在 scope 外 → 行为成立并标 `ultra_vires` → `validity` voidable（§A.15 权能/效力）。数据：法典民事④ `agency.scope` 排除 self-dealing。
- ③ 在途汇票款项计在何方名下有规则：**自然**。存款 = 钱庄 → 储户义务，换汇票 = 该义务清偿 + 新建 bill（01 §1.4）；钱始终在钱庄网点账户（15 §15.1.1），玩家持有的是债权（估值表"债权"行，15 §15.2）；户等税以什么为税基是税表 `base: property` 条目的数据（§A.7），可写入或排除 instrument。
- ④ 佃户租约随田主变更续接：**自然**。04 §4.5 "owns 的转移不关闭标的上的 leases（债权人随新主）"。
- ⑤ 规避税收可追缴：**自然**。状态类罪名谓词（05 §5.2.3 `on: state`）读 `countEvents({actor, verb: holding_transferred, window})`（§A.13）在结算点前后对称往返；判决 → `tax`/judgment 义务。数据：法典一条 `offense:tax_avoidance` 条目。
- ⑥ 换汇手续费真实扣除：**自然**。兑换 = 两笔互逆 transfer + 手续费（15 §15.3 汇率段），I1。
- 易错（年末只看瞬时快照、往返无成本无记录）：**自然**。每次过户是事件（I16），兑换有费与排队容量（15 §15.3 `exchange`），⑤可追缴。

### E6 两村赌秋收（6 条：自 6）
- ① 公田能否作赌注按法典与议案规则：**自然**。公田 = 村治理组织 owns 的 node；赌约 = 议案 `execute` 以组织权能缔结一条附条件义务（05 §5.2.5；义务种类由包声明 `wager`，完成条件 = 两田账户比较），能否处分公产受上级授权表限制（05 §5.2.2），赌约效力受法典 `contract_validity`（§A.7）。数据：`ontology/obligations.json` 的 `wager` 种类 + 王国授权表对"公产处分"的条款。
- ② 秋收量按实际产出比较：**自然**。田地是 node，收获 = 从田地账户转出（05 §5.5）；谓词读两账户的收获事件总量（`countEvents`/账户）。
- ③ 毁约由何方法院管辖：**自然**。程序条目 `forum.civil: [contract_place, defendant_residence, property_place]`（§A.7 第七轮）。
- ④ 两村立场随结果变化：**自然**。breach/settle 事件 → impress，沿 member_of/resident_of 传导（05 §5.6）。
- ⑤ 传闻扩散后其他村效仿或谴责：**自然**。传闻 = tell 链（05 §5.4）；谴责 = 公共知情 → 舆论投影（05 §5.6）；效仿 = 组织自治候选（05 §5.7.3）applicability 读 `knownEvents(self, {verb: wager}, window)`（§A.13 主观版本）。数据：候选行。
- 易错（公田被当村长私产）：**自然**。owns 持有人是组织实体，村长只有职位派生的权能；处分走决议与 `actedAs`（05 §5.3、06 §6.3 transfer/holding.transfer 校验）。

### E7 矮人与人合办作坊的计件（6 条：自 6）
- ① 劳动纠纷默认按王国法典、合股协议可另约：**自然**。规范栈的民事条款按"合同 > 次级 > 主权"取第一条覆盖者（05 §5.2.2）；合股协议 = 条款快照（合同层）；作坊在人类郡 → 主权层 = 王国法典。
- ② 矮人工匠认证在王国是否承认有规则：**自然**。`recognition.certifications`（§A.7、§A.15 承认）；无条目缺省承认。
- ③ 罢工 → 产能降 → 铁器价涨：**自然**。停工反应 `status(striking)` → `laborHours` 折减（05 §5.1 生产投入）→ 工坊闭式产量降 → 有效存量降 → 稀缺项升（15 §15.2）。
- ④ 分红按协议、亏损按比例：**自然**。share 持有 + dividend 义务按份额（01 §1.3/§1.4）；亏损 = 组织无法清偿的义务，按合股协议条款（合同层）由股东以 promise/补资义务分担，缺省读章程 `liability` 与民事⑦（05 §5.3、§A.7）。数据：合股协议条款。
- ⑤ 矿料从联邑采购需过关：**自然**。关税与通行费由沿途节点规范栈税表与 `controls` 派生（01 §1.5、15 §15.7）。
- 二阶（矮人加班 → 人类工匠对矮人好感降 → 族群情绪）：**自然**。状态评价时钟对状态谓词产出 impress（05 §5.6），impress 的 target 可为类别键 `category:culture:dwarf`（05 §5.6 对类别的立场），个体立场 = 对个体 + 类别 × 权重；加班本身是事件（laborHours 片段），谓词可读。数据：状态评价谓词行"罢工期间同岗他族在岗"与类别系数。
- 备注（易错：同一作坊按各自政体法典分别结算）：规范栈的民事选择不含属人层（05 §5.2.2 生效规则），属人层只对罪名独立判定 → 不会出现分别结算。

### E8 帐篷迁走了，仓库还在租（6 条：自 5 / 补 1）
- ① 租期内毛皮仍归该帐：**需补数据**。所有权本身自然（毛皮是 `lots` 计量物，在该帐 org 的账户里；账户不随租约转移）。但**毛皮放在哪个账户、位置在哪**设计未写明：15 §15.1.1 "账户所属实体有位置"，org 的位置 = `seat`/执行人（§A.15 执行人）；若毛皮记在帐 org 的账户上，其价值位置随帐的 seat 迁到远方郡，与"半仓毛皮留在玩家仓库"相反；若按 `bailment`（01 §1.4：保管人建筑账户用途 `held:<义务 id>`），位置正确，但题目是 `leases`（承租）而非寄存，设计没有写"承租人在所租建筑内的计量物记在哪个账户"（建筑账户只有一个所有者侧的库存）。须补：01 §1.6 或 15 §15.1.1 写明"承租建筑内的存货 = 承租人实体的账户、用途 `stored:<building>`、位置取该建筑"，或规定租仓一律转为 bailment。
- ② 届满欠租计算、法典期限后才可处置：**自然**。rent 义务闭式累计（01 §1.4）、I29；处置 = 民事⑥ `lien`（占有人对标的开立 pledged）与民事⑩ 无人认领期限（§A.7）。数据：王国法典民事⑥/⑩ 条目。
- ③ 受潮虫蛀价值随时间下降：**自然**。`lots: true` + 腐坏时钟按保质曲线与暴露量转 `sink:decay`（01 §1.6）；报价按品质档（15 §15.2）。数据：皮毛资源的保质曲线。
- ④ 该帐去向在远方骨架有对应：**自然**。帐 org 有职位持有人 → 钉住 (b)；是 rent 义务债务人 → 钉住 (a)；钉住实体至少按规则层处理（07 §7.2、§A.15），迁入的远方郡在义务到期时骨架物化（07 §7.3 第 5 条）。
- ⑤ 追讨须找到该帐、消息有延迟：**自然**。玩家面板读主观视图（05 §5.4）；去向只经传闻/商队 tell（通道延迟，§A.8）。
- 易错（帐成员消失、债务无人承担）：**自然**。成员是稀疏持有/义务的名册种子（07 §7.2 统计层），义务两端解析到存活实体（I7）。

### E9 抱错的两个孩子（6 条：自 6）
- ① 族谱能否改写按法典程序：**自然**。kin 边是真相（01 §1.3），改写只能由判决关闭旧 kin、开立新 kin（06 §6.3 holding.open 的授予者权能含"判决"；04 §4.5.1 已有判决重开 kin:spouse 的先例）；案件种类族 `case:*` 开放（§A.9 第 2 条），接生婆的供述是 tell + 证据评分（05 §5.2.7）。数据：法律包一条 `case:filiation` 程序（申请 → 证据 → 判决原语）。
- ② 米行继承权按改写后或原收养事实：**自然**。继承表只计当前法域 `recognized` 的 kin，并以 `withFrame({time: 死亡时刻})` 回读（04 §4.4、§4.3 kin 行）；亲生/过继的顺位是继承表数据（民事②）。
- ③ 已有婚姻与子女如何挂接：**自然**。kin:spouse 与 kin:child 是独立的边，改父母边不动它们（01 §1.3）。
- ④ 对养父母、生父母好感各自独立：**自然**。立场按 (holder, target) 双键（05 §5.6），印象是对个体的事件汇总。
- ⑤ 合作商对新继承人信任下降：**自然**。信任 = 基线 + 印象（05 §5.6）；新继承人没有与合作商的既往事件，印象项为零，低于原继承人；"消息扩散"= tell 链进入合作商知情（05 §5.4）。
- 易错（技能记忆关系随身份互换）：**自然**。kin 边改写不触碰技能、知情集合、其他持有（只有协议与钩子能动持有，04 §4.1）。

### E10 登记官偷学法术（6 条：自 6）
- ① 登记材料是否保密有规则：**自然**。施法要领 = 文书物品（`records`、`teaches`，05 §5.4），随登记 `registered` 持有（01 §1.3）交到登记房；保密 = 文书 `visibility` + 登记职位的 `dutyOfCare`（05 §5.2.3 negligent 角色）+ 法典程序条目。数据：郡法典 `procedure.registry.confidential: true` 与职位 dutyOfCare。
- ② 泄密可调查追溯：**自然**。登记官的 learn 事件 `source` = 该文书，亲戚的 learn `source` = 登记官（同意/授艺，06 §6.3 learn）；罪名谓词读事件链 `anyPrim(learn, source ∈ registered 文书) ∧ holds_office`（05 §5.2.3）。数据：`offense:breach_of_office_secrecy`（上位 `offense:abuse_of_office`）。
- ③ 冷货铺竞争使鲜货价降：**自然**。保鲜术 = 对批次暴露量/保质曲线的修正项（槽在腐坏派生，缺省开槽 §A.9 第 3 条）→ `sink:decay` 减少 → 有效存量升 → 价降（15 §15.2）。
- ④ 罢免后待审事务转交：**自然**。待审 = approval 义务，债务人"批复职位（经持有人）"（01 §1.4）；holds_office vacate → 继任/代理承接（04 §4.6），义务不动。
- ⑤ 玩家好感降、他法师登记意愿降：**自然**。泄密揭露事件 → impress；登记动作的自治候选 utility 读 `law:riskPerceived` 与对官府的 standing（§A.17）。数据：登记候选行。
- 易错（来源记为玩家亲授）：**自然**。learn 事件记真实 `source`（文书/登记官），不记玩家；合法性由规范栈谓词判（"未登记授课"不命中，因法术已登记；命中的是②）。

### E11 医师与和尚争病人（6 条：自 5 / 补 1）
- ① 神迹须本人同意、子女不能替代清醒本人：**自然**。治疗类读同意（06 §6.3 vital、§A.15 同意）：来源只有本人、代理（guardian_of / 章程 / mandate，且仅当本人 capacity limited/none）、法典紧急条款；老太 capacity full 时儿子不是代理。数据：状态数据须把"病重但清醒"声明为非失能（§A.15 capacity 由状态数据声明）——注意 01 §1.2 / §A.3 把"重病"列为失能类例子，包须自行把该病程状态声明为不影响 capacity。
- ② 痊愈归功于实际起效者：**需补数据**。两次 heal（开刀 vital(heal)、神迹 rite 效力 `super:efficacy`）各是事件；"痊愈"是病程事实跨阈值的 `threshold_crossed` 或 fact 变化事件，归功靠其 `causes: [{event, weight}]`（01 §1.7）。设计规定了"主因在首位、权重之和为 1、归因系数沿各因分配"（05 §5.6），但**没有写多因时权重由谁、按什么规则算出**（按各 heal 的 delta 占比？按时间先后？）；§1.8 时钟规则的 `causes` 只给"起因选择器"，无权重公式。须补：01 §1.7 写明多因权重的缺省算法（如按原语幅度占比）与规则可声明的 `causeWeights`。
- ③ 不治时两人声誉受损程度不同：**自然**（前提②的权重）。death 事件起因链 → 归因系数 × 价值乘子（虔诚 / 理性，05 §5.6）→ 不同人对两人的印象不同。
- ④ 信徒与病人群体立场分化：**自然**。价值乘子按持有者价值排序（05 §5.6）；对类别立场（医师/僧人）同节。
- ⑤ 玩家回来听到的版本取决于来源：**自然**。tell 版本经讲者失真表（05 §5.4）、回程见闻只取知情集合（08 §8.2）。
- 易错（两项治疗都判为治愈、疗效叠加）：**自然**。两次 heal 各有阶段上限（06 §6.7），病程事实钳制，"治愈"是一次阈值事件；无同意的神迹走对抗检定，失败即不生效且被察觉（06 §6.7 status/vital）。

- ① 王国爵位是否因入赘/改姓失效按王国法典：**自然**。爵位是 office（种类 peerage，05 §5.3）；解任触发 `removalTriggers` 写在章程/职位表（04 §4.6；职位表是法典 `schedule` 条目，§A.7），谓词可读 kin:spouse 开立事件的对方文化、household_member 变更或 `identities` 名称事实（§A.15 身份键）。数据：王国法典职位表的 `removalTriggers`。

- ③ 门规是否允许弟子入赘外族：**自然**。成员层条目谓词读 `holding_opened(kin:spouse)` 事件与对方 culture（05 §5.2.6），命中 → 内部程序。数据：铁拳门章程 `rules`。
- ④ 其他贵族好感变化：**自然**。事件权重表行 + 价值乘子（门第）（05 §5.6）。
- ⑤ 议会对玩家身份认定：**自然**。议会成员资格 = member_of 议会 org，按章程 `admission`（05 §5.3）谓词（household_member 望族 / citizen_of 林地）。数据：议会章程。
- 易错（改姓后族谱断链）：**自然**。改姓只改 `identities`/名称事实，kin 边不动（01 §1.3、§A.15）。

### E18 风暴潮淹了盐田（6 条：自 6）
- ① 盐田恢复需若干晴天、与天气挂钩：**自然**。盐田 = node，产盐 = 再生时钟从 `src:regrowth` 流入（05 §5.5 田地同形）；灾害时钟对 node `fact.set(flooded)`；再生 rx 读 `weather:precipitation` 槽与 `flooded` 事实。数据：采集包盐田 node 模板与再生规则。
- ② 盐价从沿海向内陆传导、有延迟：**自然**，附观察。内陆本地存量未变时稀缺项不变；内陆商号进货候选只读主观 `market_report`（05 §5.1、§5.4），统计层按月闭式（07 §7.2.1），延迟由此产生。观察：15 §15.2 的"到岸成本"项读"最近有存量的供给地"是真相投影，沿海存量归零会**即时**抬高智能层内陆的到岸项——这是部分瞬时传导，与"有延迟"不矛盾但不完全符合直觉，见专项②。
- ③ 减免盐税影响公库收入：**自然**。议案 `norm` 改税表条目 → 税反应规则按新条目转移（05 §5.1、§5.2.5）。
- ④ 井水变咸 → 改去远处取水或生病：**自然**。水源 node 的水质账户（01 §1.6）；感染率读水质暴露（05 §5.5）；取水 = `need:温饱`（hydration）候选读主观水质与距离（§A.17 身体需求）。数据：候选行与"咸度"水质指标资源。
- ⑤ 渔获短期下降、鱼价涨：**自然**。渔场 population 账户迁徙流量规则读容量（盐度作 `ecology:capacity` 修正项，§A.16）；捕鱼 = 从账户转移（05 §5.5）；存量降 → 价升。
- 易错（盐价只在湾会涨 / 井水无持续效应）：**自然**。到岸成本沿路线传导；水质是账户存量，不自动复原。

### E19 盗刻名士诗集与技艺书（6 条：自 6）

### E20 债主坐了公堂（6 条：自 6）
- ① 有回避规则时应回避或改派：**自然**。程序条目 `recusal{decisions, when: RX}`（§A.7 第七轮），RX 可读 `obligations(x, role)`（§A.13）；命中 → 该职位对该事项 `effective` 为假，代理承接（04 §4.6）。数据：县法典 `recusal.when` 加"决定者与当事人互为债权债务人"。

## 3 矛盾清单

**落题矛盾：0。** 以下为不落题的章节不一致（不计入关口，按严重度排序）：
1. **14 §14.2 vs §14.6（并行合并序）**：阶段 3 的串行顺序键是 (层级, 包 id, 规则 id, 对象骰值键序)，跨郡交错；§14.6 说并行"按郡 id 固定顺序合并写入，合并后的事件序号与串行执行完全相同"——两种顺序不同，除非合并时按同一骰值键重排，文中未写。I31 的"串行 vs 并行逐字节一致"在现文下不成立。
2. **§A.4 赦免钩子 vs 01 §1.4 / 05 §5.2.7（judgment 义务的债权人）**：01 把 judgment 的债权人写为"原告/公库"，05 把赔偿单列为 compensation；§A.4 赦免"判决义务 cancel"未区分，落在 N2③（已记为缺口而非矛盾，因为三处各自不矛盾、只是钩子过宽）。
3. **12 §12.4.2 报错示例 vs §A.4**：示例把 `suspend` 列为 `handover.gone` 的合法值；§A.4 明说 suspend 是"说明性模板…不是协议动作"，I6 禁止持有人 gone 取 stay/suspend 类。
4. **05 §5.6 vs 01 §1.3（传导种类清单）**：05 的 core 传导声明含 `resident_of`，01 §1.3 `derives.conduction` 的 core 清单无 `resident_of`。
5. **01 §1.3 `pins` 位置**：`derives` 一项内列"钉住侧 pins"，同节又把 `pins` 列为独立字段；12 §12.2.3 又写在 derives 里。三处不一致。
6. **05 §5.2.2 民事选序 vs 13 §13.4 契约冲突法**：民事条款"合同 > 次级 > 主权 > 包缺省"不含成员层，而 13 §13.4 pact 依赖生灵规矩（成员层形状）经冲突法参与效力判定；成员层民事条款（门规对契约）的位置未定义。
7. **01 §1.2 / §A.3 vs §A.15（"重病"）**：前两处把"重病"列为失能类（capacity none），§A.15 又说部分能力由状态数据声明；若包照 01 的例子把重病做成失能，E11 的"清醒的本人"无法同意——不是冲突，但例子误导，见修改建议。
8. **目标架构 §0.1 / 01 §1.4 第 12 行 vs §A.0**：正文大量保留"（第 N 轮，R*-X*）"历史叙述，违反 §A.0 "修订的历史叙述只进修订记录"的自定规则（可读性问题，见专项④）。

## 5 专项

### ① 时序与并发
- 强项：五阶段 + 排序键 + 争夺池 + 骰值键含序号（14 §14.2、§14.5），E2 的三人时间线、E5 的年末结算点（到期项缺省在当日最后一刻）、E11 的同刻两次治疗都能给出确定顺序；补算不递归、刻集合由日程堆唯一确定，使逐日/一次推进同序。
- 问题：(a) §14.6 并行合并序与阶段 3 顺序键不一致（矛盾清单 1），I31 的并行承诺现文不成立；(b) 反应深度上限只豁免 settlement/legal 类，social/autonomy 链被截断后"不在下一刻自动续算"，E16⑤ 一类"听说 → 改计划"的多跳社会反应可能被 `reaction_cut`，设计把它推给时钟规则但未给出被截断链的补偿口径；(c) 阶段 4 产生的争夺型提案只再开一次 3′，其余延到下一刻，与"刻末回执"承诺（06 §6.5 第 8 步）相容但未写延后时回执如何表述。
- 结论：可实现、可测；修 (a) 后无结构性风险。

### ② 守恒与套利
- 强项：I1/I2 无例外、源汇显式且有每日预算、制造/发行/个体化守恒对、`lots` 批次 taint/purports、价值有位置、15 §15.9 四十余条防线；E5 的年关往返（手续费、登记承认、状态类罪名）、E12 的内幕、E7 的分红、N6/N7 的材料与种群都能守住。
- 问题：(a) E1③ 人口副产物无源可挂——只要不补，任何"人产生的废物/副产品"内容都要么无法成立、要么被迫违规引用源；(b) N2③ 赦免钩子 cancel 判决义务可被"犯罪 → 判赔 → 招安"套利（受害者债权被抹）；(c) N4 遗嘱重复处分：I8 会拒绝第二笔，但分配步的失败回滚口径未写，可能让整个遗产卡在 distribution；(d) E8 承租人存货的价值位置：若按 org 账户 = seat，货物会随 seat 瞬移（与"价值有位置"自相矛盾的实现风险）；(e) 15 §15.2 到岸成本项是真相瞬时投影，远方存量归零会即时改变智能层本地价格——不是守恒漏洞，但与"NPC 只经 market_report 知情"的滞后设计并存时，玩家可凭本地报价变化推断远方真相（信息侧漏）。
- 结论：守恒本体无漏；四处补法均为数据/钩子口径，不动原语。

### ③ 性能
- 07 §7.5 的预算分解（2.0 s/日 恰在 B14.2 上限）仍是最大风险；本轮新增负担：(a) E16 类 companion 生灵的逐刻感知（听觉衰减）在智能层按在场人数 O(n)，可控；(b) E1 类"每户一条 service 义务"在 3.5 万居民规模下使到期堆与清偿事件线性膨胀（每户每月一次），应归入 `autoSettle` 并允许按聚落聚合变体（07 §7.3 第 7 条已允许 auto）；(c) N5 地籍记账反应对每次 owns 开立追加 records，属 settlement 类不受截断，文书 records 无上限，需归档策略（07 §7.6 只写事件分段）；(d) 状态评价时钟（E1④、E7 二阶）若谓词无守卫会进全局限额，设计已有熔断。
- 结论：无新的数量级风险；records 增长与 service 义务密度需进 scale 测试。

### ④ 复杂度与可理解性
- 附录 A §A.15 单条目动辄千字（期间口径、权能、受限），是"唯一定义处"但不可检索；正文仍大量保留"第 N 轮 / R*-X*"修订标注（违反 §A.0 自定规则），读者须同时拿着修订记录才能理解；`judgment` 与 `compensation`、`suspend` 模板、失能例子（重病）三处语义边界模糊，本轮各产生一条失分或不一致。
- 积极面：判别表 §A.2 覆盖了本轮 28 题几乎全部"用哪种概念"的问题；"先发生、后定效"（validity）与"法律只打标签"让 E3/E5/E13/E20 这类钻空子题都有自然落点。
- 建议：把 §A.15 拆为按派生名的小节并加索引；清理历史标注；给 judgment/compensation 画一张"判决产出的义务种类"表。

### ⑤ 章节一致性
