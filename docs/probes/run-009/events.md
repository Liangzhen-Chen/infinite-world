### E1 ★ 结义兄弟分属两国（玩家与NPC长期关系 / 跨政体）
- 情境：玩家（王国某郡县尉）十年前与猎人阿鲁结义；阿鲁后入兽人部盟任百夫长。今年秋，王国与部盟边境开战。
- 经过：两人在战场相遇；阿鲁战败被俘，玩家私放；三月后阿鲁战死，遗孤托付玩家，玩家护送遗孤回部盟营地。
- 系统：S20 S24 S37 S39 S22 S17 S21 S27 S45
- 预期：①结义好感不因开战归零，但双方对对方势力的立场仍各自按势力传播；②私放俘虏在王国法典构成罪名，知情者仅限在场者，传闻需时间扩散；③事发后玩家县尉职可被罢免，罢免后俸禄与权限即时按新身份计算；④结义不构成族谱亲属，遗孤监护需另走收养/托孤程序；⑤护送穿越战线时关卡与敌对立场生效。
- 二阶：部盟方因玩家私放而对玩家好感上升，可能让玩家在部盟境内获得“义人”传闻，与王国内的“通敌”传闻并存。
- 易错：把“结义”当族亲，遗孤自动成为玩家继承人；或私放罪在无人目击时也被全城知晓。

### E2 ★ 徒弟当了考官（师徒多年演变 / 身份反转）
- 情境：玩家法师二十年前收徒林照，五年后因故逐出师门（好感-60）。如今林照为郡法师公会认证考官，玩家年迈申请高阶认证。
- 经过：林照未回避，判玩家不过；玩家上诉，并发现林照登记在册的成名法术源自当年玩家笔记。
- 系统：S42 S40 S34 S28 S20 S32 S41 S45
- 预期：①考官与考生存在师徒/恩怨关系时应触发回避或可据此上诉；②法术登记有时间先后，玩家需举证（笔记/证人），不应凭玩家自称直接改署名；③改署名若成立，林照名士声望与公会职位应连带受损；④二十年离屏中林照的职业成长应由离屏推进合理产生，而非玩家到场才生成。
- 二阶：林照门下弟子对玩家好感沿师门关系整体下降，玩家之后在公会内的事务受阻。
- 易错：逐出师门后师徒关系被删除，系统找不到回避依据；或回避规则只看亲属不看师承。

### E3 ★ 化形被识破的山魈掌柜（非人视角玩家）
- 情境：玩家是山魈精怪，化人形在王国镇上租铺子卖山货，货源是夜里回山中采集。已与房东签三年租约，与人合股。
- 经过：秋夜采集时被猎户撞见原形，猎户以猎兽为由射伤玩家；次日化形被识破的传闻传开，道观要求驱邪，房东欲解约。
- 系统：S5 S7 S13 S10 S21 S20 S27 S28 S29 S37 S30
- 预期：①王国法典对精怪的人身地位决定猎户行为是“狩猎”还是“伤人罪”，林地共同议会法典下结论不同；②以化形身份签的租约应属“可撤销”（欺诈问题），而非自动无效；③合股伙伴可主张退股，但已发生利润按股分配；④传闻扩散有边界：邻郡顾客未必知道；⑤铺子货源中断导致山货价格回升。
- 二阶：山中原本因山魈存在而回避的野兽返回采集地，影响其他采集者收获。
- 易错：系统把玩家当野生动物对象处理，资产/契约全被清空；或身份暴露不影响任何NPC好感。

### E4 ★ 看着遗产被分的亡魂（亡魂玩家 / 死后清算）
- 情境：玩家商人病死，继续以亡魂游玩。生前有钱庄存款、当铺一枚玉坠（赎期剩20天）、一条老狗。遗嘱指定长子继承。
- 经过：亡魂试图到钱庄取款；对次子托梦告知藏银处；老狗守墓不肯随长子回家；玉坠赎期届满无人赎。
- 系统：S22 S11 S12 S8 S30 S35 S21 S28 S45
- 预期：①存款已转入继承人，亡魂无权提取，利息归属切换日=死亡日；②托梦若属精神类施法，应检查被托梦者同意或至少给出规则一致的处理；③藏银信息只被次子知道，长子不知，可能引发分产争议并进入诉讼；④当铺赎期不因死亡自动延长，继承人可在期内赎回；⑤宠物按遗产随继承人，但其“守墓”行为应由宠物性格驱动。
- 二阶：次子挖出藏银后，因不在遗嘱内是否属遗漏遗产，需重新分配。
- 易错：亡魂仍被系统视为户主，继续收利息、交税或在村民大会有投票权。

### E5 ★ 以新补旧的分红（商业欺诈与审计）
- 情境：郡商会下属“兴隆矿号”连续三年分红一成五，宣称经营东山银矿。玩家入股后当选商会监事。
- 经过：玩家查账发现矿脉储量早已见底，分红来自新股本；消息走漏前，会长先赎回自己的股份。
- 系统：S13 S11 S6 S40 S21 S27 S28 S9
- 预期：①矿号分红资金必须可追溯来源，账面利润须与矿脉实际开采量守恒；②爆雷后清偿顺序按法典（债主优先于股东），先撤出的会长可被追回；③监事权限来自职位，玩家卸任后应失去查账权；④传闻扩散前后入股者的损失应不同；⑤银价不因“假矿号”产量变化（因为从未有真实产量）。
- 二阶：商会公库因担保矿号受损，其他会员分摊，可能引发会长被罢免与首领更替。
- 易错：分红凭空生成金钱（守恒漏洞），或会长提前撤资在系统中无痕可查。

### E6 ★ 巡夜队里的内应（城防与治安巡逻）
- 情境：冬季，镇上连续三夜失窃。玩家为镇治安副职，自掏组织公库组建五人巡夜队，按固定路线走。
- 经过：盗贼团掌握巡逻时间表，因为其中一名巡夜队员是内应；玩家改为随机巡路，第四夜抓获盗贼。
- 系统：S19 S29 S40 S24 S1 S18 S27 S10
- 预期：①NPC间犯罪概率应受巡逻覆盖与昼夜影响，固定路线可被摸清；②内应身份应有证据链，抓获盗贼后可供出内应；③巡夜队员工资由组织公库支付，公库不足应欠薪；④被盗店铺的损失应减少库存而非仅是一个标签；⑤冬季夜长使失窃窗口变大。
- 二阶：内应被抓后，其家族与其他巡夜队员的好感/信任下降，巡夜队人手不足。
- 易错：巡逻只是装饰状态，不影响犯罪率；或内应被抓前系统已“全知”地标记他。

### E7 ★ 山洪预警跑输了谣言（灾害预警与谣言）
- 情境：夏汛，观象台道士在午夜预测上游山洪，玩家托驿传向下游三村报信。
- 经过：谣言（夸大成“三村全淹”）先于正式驿报到达；甲村不信（对玩家好感低），乙村过度反应抛售存粮，丙村按时撤离。洪水实际只淹乙丙两村低地。
- 系统：S2 S16 S21 S20 S9 S4 S1 S19 S30
- 预期：①驿报到达时间应符合距离与夜间行路；②谣言与正式消息的内容应可不同，NPC按信任度选择；③乙村抛售使当地粮价下跌，灾后再上涨；④深夜多数NPC在睡眠日程，响应时间更长；⑤预测命中与否影响道士与观的声望/香火。
- 二阶：甲村因未受灾而对“预警”整体失去信任，下一次真实预警时撤离率下降。
- 易错：预警瞬时到达所有村；或谣言与正式消息在知情边界上混为一谈。

### E8 两派争学堂（宗教团体竞争 / 教育）
- 情境：镇学堂只有一个教席，玄真观与归一寺争夺；两家各自编写识字教材，夹带自家教义。
- 经过：玄真观靠一次有限神迹（求晴）在村民大会议案中胜出；三年后识字率上升，改宗玄真观的人数增加；归一寺上诉称议案程序违规。
- 系统：S30 S31 S32 S23 S20 S40 S27 S28
- 预期：①神迹消耗有限额度，不能连续使用；②教材内容影响识字率与改宗倾向，但两者应分开计算；③议案若程序违规（法定人数不足），应可撤销；④归一寺香火下降，寺产收入随之下降；⑤学生家长对两家的好感依孩子受教育效果变化。
- 二阶：识字率提高后，书本传播技艺加速，镇上工匠产出提升。
- 易错：神迹结果被当作随机好运而不扣额度；或改宗与识字两个数值互相覆盖。

### E9 ★ 握手与刻符：两种成交（跨文化贸易与误解）
- 情境：玩家作中间商，在星湾港与湾会商人握手约定买一船香料，转售给矮人联邑商号（联邑以刻符契约为准）。
- 经过：货船因风暴在港滞留十天；香料价格上涨，湾会商人认为握手已成交，矮人商号以“未刻符”为由拒收；玩家已付一张汇票定金。
- 系统：S15 S27 S28 S9 S14 S20 S12 S1
- 预期：①契约成立应按各政体法典判断，同一行为在两地结论不同；②诉讼管辖应由争议地/政体决定，不是全局统一；③在途滞留期间货物所有权与风险归属应明确；④汇票定金在湾会法下不可退，矮人联邑法下可主张退回；⑤关税按实际过关时间与品类计算。
- 二阶：此事传闻在两地商圈对玩家好感产生相反影响（湾会觉得守信，联邑觉得轻率）。
- 易错：系统只有一套全局“契约有效”布尔值，无视政体差异。

### E10 ★ 碑上被凿掉的名字（玩家制度被后人修改）
- 情境：玩家任镇长时通过议案“公库每年拨三成办学”，并立碑。卸任后离开十五年，期间受封男爵，封地含该镇。
- 经过：继任镇长改议案为修城墙；玩家归来发现碑上名字被凿；玩家以封君身份要求恢复旧议案。
- 系统：S23 S24 S32 S18 S45 S41 S21 S26 S20
- 预期：①议案可被后续合法议案修改，不随玩家卸任自动失效也不永远不可改；②十五年离屏应真实累积：识字率回落、城墙完工；③封君权限与镇议会权限的层级须按法典，不能任意推翻；④凿碑者身份应可查（传闻有知情边界）；⑤玩家名士声望在当地下降，但在外郡不变。
- 二阶：恢复办学会削减城墙维修经费，若遇兵灾城防弱化。
- 易错：玩家回来时世界只做一次性补算，导致十五年间多次议案被压缩成一次。

### E11 ★ 六十年后的出生村（长期存档合理性）
- 情境：存档运行六十年后，玩家（若已转生或以后代身份）回到起步村。
- 经过：检查村落人口、林木、渔获、矿脉、物价、首领怪物、名士作品。
- 系统：S22 S3 S5 S6 S9 S38 S41 S45 S25
- 预期：①族谱人口不爆炸也不灭绝，婚育与迁徙比例合理；②林木与渔获有恢复周期，过伐后应有恢复而非永久归零；③矿脉储量单调递减不可复原；④物价不因长期累积出现无边界通胀；⑤40个首领被杀后的刷新或空缺有规则，不能全部灭绝导致生态失衡；⑥名士作品有流传、失传或被引用。
- 二阶：若升格为镇，人口与产业应与镇级相符，俸禄与公库额度同步。
- 易错：长期运行后累积数值溢出或趋于极端（价格、好感、人口）。

### E12 ★ 信鸽比驿报快（组合玩法①：宠物+驿传+物价+汇票）
- 情境：玩家训练三只信鸽，往返甲郡与乙郡。甲郡发生旱灾。
- 经过：玩家通过信鸽得知旱情，比官方驿报早四天；用汇票在乙郡大量收购粮食，驿报到达后粮价上涨，玩家高价卖出。
- 系统：S8 S16 S21 S9 S2 S12 S27 S20
- 预期：①信鸽速度应符合宠物属性，且受天气影响；②乙郡NPC在驿报到达前不知旱情；③大量收购本身应推高物价，并引起NPC察觉；④如王国法典有“囤积居奇”罪，可追诉；⑤汇票兑付需时间与手续费。
- 二阶：粮价上涨导致乙郡贫户吃不起饭，好感对玩家下降，或官府开仓平粜。
- 易错：玩家获知消息后系统让全世界同步知情；或收购不影响供需。

### E13 ★ 义诊同意书里的小字（组合玩法②：施法同意+医疗+法术）
- 情境：玩家医师兼法师在村里办义诊，病人需签同意书接受治疗术。
- 经过：同意书里附加一条“同意施用记忆类法术以便诊断”；玩家借此读取村长记忆，获知公库秘密。
- 系统：S35 S33 S34 S27 S20 S21 S24
- 预期：①施法同意应按法术类别逐项生效，而非全局布尔；②不识字病人签的同意书效力存疑；③读取记忆若超出诊疗目的属违法；④法术是否已登记影响合法性；⑤事情败露后义诊信誉与玩家好感大幅下降。
- 二阶：村里对所有医师的信任下降，求医率下降，疾病传播加重。
- 易错：系统只检查“有同意记录”，不检查同意范围与签署能力。

### E14 ★ 收养凑户数升镇（组合玩法③：监护+升格+俸禄）
- 情境：玩家是某村里正，村人口差15人可升镇。战乱后附近有大量孤儿。
- 经过：玩家以个人名义收养15名孤儿，人口过线，申请升镇，自任镇长领镇级俸禄；不久其中5名孤儿被亲族领回。
- 系统：S22 S25 S24 S33 S23 S27 S9
- 预期：①监护义务（供养、医疗）应自动生效，不供养会生病并影响好感；②升格条件应不仅看人口，还看产业/税基；③人口跌回线下时镇级应有降级或宽限规则；④俸禄额度按当前聚落级别派生；⑤收养动机若被揭露，村民大会可罢免。
- 二阶：孤儿成年后对玩家好感、族谱继承权引发新的分产争议。
- 易错：人口一过线永久升镇，事后跌破无任何反应；或收养后孤儿不需要供养。

### E15 ★ 远方郡的旧情人（恋人 / 远方骨架）
- 情境：玩家与医师素问相恋，素问被调往远方郡行医。玩家此前从未到过该郡。
- 经过：二人靠驿传书信往来三年，有一封信丢失；素问在远方结识他人并订婚；玩家首次到达该郡。
- 系统：S16 S20 S44 S45 S33 S22 S21
- 预期：①远方郡骨架生成时，须与已存在的素问及其三年离屏经历一致；②丢失的信件对双方好感产生不同影响；③好感随时间与距离衰减，但不应凭空归零；④订婚应进入族谱/婚姻系统；⑤远方郡医疗水平应与素问在那里行医的效果一致。
- 二阶：素问未婚夫对玩家好感低，在当地传闻中玩家成为“负心人”或“旧情人”。
- 易错：远方骨架覆盖或重置素问；或离屏期间她什么都没发生。

### E16 ★ 兽人冠军的证书（非人视角 / 跨政体认证）
- 情境：玩家是兽人部盟武者，秋节时进入王国县城参加比武大会。
- 经过：玩家夺冠，获国王赏赐“武师认证”与一个低阶爵位；比武中触发“拳师”隐藏职业契机；部盟法典禁止接受外国爵位。
- 系统：S37 S41 S42 S43 S20 S39 S26 S1 S27
- 预期：①王国认证在部盟不自动有效；②接受爵位在部盟构成罪名，可被罚或失去部盟身份；③隐藏职业契机不因种族被错误屏蔽或错误放开（按设定）；④部分王国NPC对兽人冠军存在偏见，好感按立场计算；⑤节庆期间客流使县城物价短期上涨。
- 二阶：部盟与王国外交关系因此事出现微妙变化（荣誉或羞辱）。
- 易错：认证与爵位是全局属性，所有政体都承认；或种族导致隐藏职业逻辑报错。

### E17 ★ 合同在异乡到期的驼帮（商队长途经营）
- 情境：玩家商队雇8名驼夫，合同一年，从王国出发经草原诸帐至星湾，途经首领怪物领地，雇护卫护送。
- 经过：合同在草原中途到期，驼夫要求加薪否则散伙；途中遇狼群，护卫伤亡；冬季提前到来，商队滞留。
- 系统：S10 S15 S14 S1 S9 S17 S44 S7 S38
- 预期：①合同到期应按约定处理（续约/遣散费/返程费用）；②工资支付币种与当地汇率；③草原诸帐收“过帐礼”与王国关税性质不同；④护卫伤亡需抚恤；⑤滞留期间货物损耗与食宿成本累积。
- 二阶：散伙驼夫留在草原，成为当地雇工或流民，影响当地劳动力市场。
- 易错：合同到期时系统强制传送驼夫回原籍；或滞留不产生任何成本。

### E18 ★ 成交后死去的竞拍者（拍卖竞价）
- 情境：县衙拍卖查抄田产，玩家与富户王某竞价，王某以高价胜出。
- 经过：成交后、付款前，王某暴毙；其子继承；次高出价者玩家要求递补。
- 系统：S22 S28 S11 S4 S24 S21
- 预期：①继承人应继承付款义务或可按法典放弃；②递补规则应明确（重新拍卖或次高递补）；③田产在过户前的收成归属；④县衙公库收入因延迟到账；⑤消息传开后其他竞拍者反应。
- 二阶：若重新拍卖价格下跌，县衙公库亏损，县令考绩受影响。
- 易错：死亡后拍卖记录直接作废，田产无主；或玩家自动获得田产。

### E19 ★ 水力纺车（技术突破与扩散）
- 情境：工匠阿石发明水力纺车，产量提高三倍。镇上有织户行会。
- 经过：布价下跌，手工纺妇失业；村民大会议案禁用；阿石出走矮人联邑，联邑布产崛起；同时法师推广纺织生活魔法。
- 系统：S10 S9 S23 S32 S3 S40 S42 S43 S36
- 预期：①产量提高导致布价下跌；②水力纺车占用水源，影响下游；③禁用议案仅在本镇有效；④技术通过书本或工匠流动扩散；⑤阿石可能触发“机关师”隐藏职业。
- 二阶：联邑布匹倾销回王国，关税与贸易冲突。
- 易错：技术只在发明地生效，或扩散瞬间全世界同步。

### E20 被当成神迹的开水（公共卫生与宗教）
- 情境：夏季疫病流行。某观推广“净水祭”（煮沸饮用），同时法师用生活魔法净水术。
- 经过：病例减少；观称是神迹，香火大增；医师与法师争论功劳。
- 系统：S33 S30 S31 S21 S3 S20 S36 S34
- 预期：①煮沸与净水术均应真实降低发病率；②神迹额度未被消耗；③香火增加来自传闻与好感；④净水术若未登记属违规；⑤水源污染程度影响效果。
- 二阶：其他村仿效，但若水源不同效果不同，引发怀疑。
- 易错：系统把自然结果记为神迹消耗。

- 应作用系统：S20 S22 S27 S28 S37 S45 S42

### N4 ★ 新增：小冰期（十年尺度气候变化）

- 易错：只改天气描述，不影响农业和物价。

### N5 ★ 新增：保甲连坐制

- 应作用系统：S27 S20 S21 S29 S22 S24
- 装上后：①邻户互相监视，举报率上升；②邻里好感下降；③精怪户、外族户如何编保；④连坐罚款入公库。
- 冲突：与现有个人罪责原则、跨政体法典。
- 易错：连坐对玩家无效；或非人户不编保。

- 与N7同装：丹药喂兽规则需统一；与N6同装：灵石作为丹药原料时资源竞争。
- 易错：卸包后属性回退导致角色数据异常。
