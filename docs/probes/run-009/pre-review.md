## 口径

- **自然得出（自）**：只用正文写明的机制 + 数据可得；需加的数据在正文规定了位置与形状（如 `ontology/holdings.json`、`rules/tables/valuation.json`、补丁、修正项、法典条目）。需推测设计者本意的不算。
- **需补数据（补）**：机制大体在，但所需数据的位置或形状正文未说明，或结果依赖未定义的表 / 换算口径。
- **设计缺口（缺）**：正文没有能产生该结果的机制。
- **设计矛盾（矛）**：两处正文对同一问题给出冲突规定，且该条结果取决于取哪一处。不落题的矛盾 / 不一致单列在文末。
- 计数：E 题每条编号预期 1 条 + 二阶 1 条；N 题按“加什么 / 装上后各条 / 冲突（N1–N5）或卸掉后、同装（N6–N8）/ 易错”拆条，N1–N5 的“冲突”行按一条计（与 N6–N8 的“同装”对称）。

## 逐题判分

### E1 结义兄弟分属两国（6 条：自 6）
- ① 自。立场是投影（05 §5.6）：基线 + 印象（结义事件的 impress）+ 传导；开战不删印象，故不归零；阿鲁对王国的敌意经玩家的 citizen_of / holds_office 传导项部分作用于玩家，双键分离（05 §5.6 末条）。结义本身在 core 无结构持有，只以印象存在——对本条够用。
- ② 自。俘虏 = `guest_of{detained}`，东道为王国军 / 官府；县尉有权职位无依据关闭 → 成立并命中 `offense:unlawful_release`；无权者只能走劫狱（vital/status + move）（05 §5.2.7、06 §6.3）。见证由感知派生（01 §1.5），传闻沿路线延迟扩散（05 §5.4）。
- ③ 自。罢免 = holds_office `vacated`，权能即刻消失；salary 累计止于持有终止，`effective` 读当下（01 §1.4、04 §4.5、A.15）。
- ④ 自。结义不是 kin，继承表只计 kin（04 §4.4），不会自动成为继承人；收养 = 开立 `kin:过继`（01 §1.3），授权来自部盟法典授权表 `delegation`（A.15 `authority`）；需加数据：部盟法典的收养授权条目。
- ⑤ 自。护送 = escort 义务；封关 = `controls` 封闭；遭遇规则读 `standing(控制者, 队伍)`、`combat:deterrence`、`transport:risk`（09 E13、A.17）。
- 二阶 自。部盟成员对玩家的印象按价值乘子为正、王国成员为负；转述版本由讲者立场经失真表 `bias_toward` 生成（05 §5.4），两地传闻版本并存。

### E2 徒弟当了考官（5 条：自 3 / 补 2）
- ① **补**。“恩怨”可读：认证动作的前置补丁 `append` 一条 `standing(考官, 考生) > θ`（05 §5.2.8、06 §6.4），形状有。但“师徒”依据读不到：core 把师徒建模为 service 义务（05 §5.4），逐出即 cancel，无持久结构；RX 回读历史只有 `withFrame({time})`（须给定时刻）与 `countEvents`（窗口 ≤ 365 天，A.13），二十年前的授艺不可查。认证结果不是案件，正文也没有对职位决定的复核 / 上诉程序。回避的依据数据与上诉路径都未规定。
- ② 自。法术登记是 `registered` 持有，开立带缔结快照（时刻）（01 §1.3、A.15）；署名是慢变事实，只能经判决改；民事事实认定由证据评分对命题求值，笔记是文书 `records`、证人按可信度计（05 §5.2.7）。玩家自称不改任何事实。
- ③ 自。判决事件 → 印象下降（名士声望 = 公众知情中的作品与事件投影，09 E19）；公会职位经章程 `removalTriggers`“被判某类罪名”（04 §4.6）。需加数据：公会章程的解任触发与剽窃类罪名 / 民事条目。
- ④ 自。林照对玩家立场 −60 属“强立场”→ 钉住 (d) → 按智能层逐日自治（07 §7.2、A.15 钉住），二十年的申请认证、受聘考官由自治候选（`need:地位`）逐步产生，不是到场才生成。
- 二阶 **补**。“沿师门”传导要求一条声明 `derives.conduction` 的持有（05 §5.6），core 传导清单无师承；师徒在 core 是 service 义务（不传导），与 12 §12.7.3 示例包的 `disciple_of` 持有口径不一。需新增师承持有种类，但这与 05 §5.4 的 core 表示冲突，属推测本意。

### E3 化形被识破的山魈掌柜（6 条：自 4 / 补 2）
- ① 自。罪名谓词读目标是否被法域承认人格 `recognized(x, j, 'personhood')`（A.7、01 §1.2）；王国与林地议会各自的 recognition 条目给出不同结论；故意要件读 `knows`（05 §5.2.3）。
- ② 自。租约缔结快照记 `inName`（化形身份键，01 §1.3、A.15 身份键）；`validity` 读描述标签按合同效力条款判 voidable（A.15 效力）。需加数据：王国合同效力条款“以非本名身份键隐瞒本体缔约 → voidable”，以及给该类缔约打 `deceive` 的合法性标注（`rules/tagging.json`）。
- ③ **补**。退股 / 退伙没有规则：章程字段（05 §5.3）只有 `acceptsShares`、`liability`、`authority.issuance`，民事⑦只管责任与增发；撤销后已分配利润是否返还（民事⑨不当得利会要求返还）与预期“已发生利润按股分配”谁优先，正文未定。
- ④ 自。传闻是沿路线带延迟的 tell 链，公共知情按显著度截断（05 §5.4、07 §7.3 第 8 条）。
- ⑤ 自。货源中断 → 本地有效存量降 → 稀缺项升（15 §15.2）。
- 二阶 **补**。“因山魈存在而回避”只能来自 `controls` 持有的容量挤压（05 §5.5），题中玩家未必持有 controls；野兽回到采集地如何“影响其他采集者收获”——物种 `interactions` 只在物种之间，草药是资源点储量，遭遇风险也未接入采集产出——路径未定。

### E4 看着遗产被分的亡魂（6 条：自 5 / 补 1）
- ① 自。死亡 → deposit 的 `onCreditorGone: estate`，债权人自死亡时刻为遗产（04 §4.2 第 4 步）；亡魂是带 `soulOf` 的新实体，无任何持有（13 §13.7），不能支取；利息闭式按 accruedTo 连续，归属随债权端切换。
- ② 自。托梦是 tell 通道 `dream`（A.8、13 §13.4），不是精神类状态，不读同意；规则一致。
- ③ 自。只有次子的知情集合含该 tell（05 §5.4）；分产争议 → `create(case)` 并 frozen（04 §4.2 第 9 步）。
- ④ 自。当铺借贷 `onDebtorGone: assume_by_heirs`，日程不变、质押随行（04 §4.2）；遗产期内由执行人以 `actedAs: estate` 赎回（04 §4.4、A.15 执行人）。
- ⑤ 自。tamed_by 持有人 gone → estate → 继承人（04 §4.3）；守墓由物种 `drives`（attachment）与自治候选驱动（13 §13.3、05 §5.7.1）。需加数据：一条犬类 `need:attachment` 的守墓候选。
- 二阶 **补**。藏银（埋藏的容器物品）在真相层属于遗产，分配步按遗嘱 / 继承表转移（04 §4.2 第 9 步）；遗嘱未提及的财产是否按继承表补分、遗产关闭后发现的**财产**怎么办（04 §4.4 只规定“关闭后新发现的债权”），正文未定。

### E5 以新补旧的分红（6 条：自 6）
- ① 自。分红只能从组织账户 transfer（I1），每笔有起因事件；账簿是文书 `records`，可被做假（purports），真相是账户（05 §5.4 文书、01 §1.6）。
- ② 自。清算：债权清偿后才按份额分净资产（04 §4.2 第 9 步、§4.4 清偿顺序）；会长以明显高于 `value(股份)` 的价格赎回 = 明显不等价转移，按民事①⑨撤销追回（04 §4.4、15 §15.2 股份估值）。
- ③ 自。查账权来自监事职位的 `derives.authority`，卸任即失（04 §4.5、A.15 权能）。
- ④ 自。入股决策读主观视图（05 §5.7 第 3 条），成交价不同 → 损失不同。
- ⑤ 自。银价读账户存量，矿脉无产出即无流量（15 §15.2）。
- 二阶 自。担保 = 新义务种类（`ontology/obligations.json` 形状已定）；会员分摊按章程 `liability`（09 E18：债权人追偿按责任类别落到股东）；会长罢免经章程 `removalTriggers` 或 charter_vote（04 §4.6）。

### E11 六十年后的出生村（7 条：自 6 / 补 1）

### N7 御兽契约包（7 条：自 5 / 补 1 / 矛 1）
- 加什么 自。结契 = 新持有种类（creature ↔ agent），派生 companion 类权能；对灵智首领用 pact 义务（13 §13.4）。
- ① **矛**。要让“猎杀结契兽”在各政体构成伤人，包能用的只有合法性标注（`rules/tagging.json`）打 `offense:bonded_harm`（上位 `offense:assault`）。12 §12.4.5 与 §12.10.3 说立案反应规则“按上位回退匹配”即可立案；05 §5.2.3 说“罪名认定只以规范栈的法典谓词为准……合法性标注只作证据材料”，嫌疑记录只在法典谓词命中时产生，而各政体 assault 的谓词不会命中射杀动物的事件。两处结论相反；补丁也不能给他人法典新增罪名条目（op 只有 append 前置 / 不相容、exempt、mul、add、reduce、narrow）。
- ② 自。首领随主 → 离巢超 N 天 controls 关闭 → 容量回升、回迁按流量（05 §5.5）。
- ③ **补**。“结契兽进城需法典规定”同样要给既有政体法典加条目；绑定 `place.lawCode` 会与他包和 core 争槽，标注又受 ① 的矛盾影响。包怎样为“一切政体”加一条管制，正文未给途径。
- 卸掉后 自。结契持有 close（pack_removed）；兽是 core creature，留存；需要时经 `src:aggregated` 并回种群（01 §1.6）。
- 同装 自。喂丹是 N8 的服用动作，目标过滤与效果是其数据；若两包都声明“喂丹于契约兽”的判定，`decides` 唯一赢家（12 §12.4.4）。
- 易错 自。首领实体不是包实体，卸载不动它。

### N8 丹药炼制包（8 条：自 8）
- 加什么 自。配方（药材 → 丹药资源，`src:craft`）+ 服用动作（fact.set 属性或扩展事实 + 状态）。
- ① 自。工坊配方投入进入“派生需求”（15 §15.2 第六轮项），药材存量被分流，医疗与炼丹按价格竞争。
- ② 自。丹毒 = 包状态（`ontology/statuses.json`）。
- ③ 自。伪丹 = 批次 `purports`；行使伪造物且知情命中 core fraud / forgery（05 §5.2.4、A.15 批次表象）。
- ④ 自。认证资格职位 + 被动表（03 §3.5）。
- 卸掉后 自。写入 core 属性的 fact.set 是已发生事件不回滚；写入扩展事实的按 dormant / fallback / drop（12 §12.5.4）；以修正项实现的随包卸下回落，寿命类有 `agingCatchUp`（05 §5.5）。三种口径都一致可算。
- 同装 自。与 N7：见 N7 同装；与 N6：两包都给灵石挂同一 `goods:*` 共享词则在市场投影里争同一存量（12 §12.4.5“唯一需要协调的是词汇”），否则是两种资源、不竞争——由词汇决定，可确定。
- 易错 自。属性回退走派生重算，不产生异常写入（I17、I27）。

## 修改建议（按严重度）

**一级（阻断设计关口或日常集）**
1. 身体需求入本体：在 A.15 登记 `stamina`、`satiety`（人与生灵同形）、宠物 `loyalty`（或明确为 standing 的某维度），写明是慢变事实、由哪些原语改（vital 族扩展或 fact.set 白名单）、消耗表与恢复表放在哪个数据文件（动作 `cost` 加 `body` 段；睡眠 / 进食动作的 outcomes；时钟规则逐时消耗）。
2. 统一 X1：规定法典罪名条目可写 `matches: offense:<族>`（命中带该标签或其下位词的事件即视为谓词为真），把“上位回退”定义为法典谓词的一种写法，05 与 12 同口径；同时给补丁加 `append(clause)` op，让包能向一切政体追加罪名 / 管制条目（受 `patchable` 与 `reserved` 约束）。
3. 统一 X2：等级线条目改为 `{rank, rx: 人口与设施 / 税基的 RX, graceDays, hysteresis}`，自动升降与升格申请读同一条件；09 E03 改为引用它。
4. 统一 X3：`normFree` 只能是守卫索引的快速路径（无 move 守卫的条目不求值），声明了 move / 地点子树 / 时段守卫的条目照常求值；同时让日程合成读规范栈的“时段禁令”（05 §5.8 加一项“规范约束”），NPC 才会因宵禁改作息（N3②）。
5. 交易价格口径：在 15 §15.2 写明零售价 / 收购价的来源（`value` 加方向因子，或店主加成表分买入 / 卖出两列），并给出 06 §6.9.2“人物议价规则”的数据位置与形状。
6. 期间口径：定 core 历法月长；给义务条款加“按锚计额”（`perAnchor: amount`，与按日累计二选一，闰月按 `obligationsSkip`），并写明月利率 → 日利率的换算式。
7. 钉住个体常驻统计层地区：规定其所在聚落骨架物化、与其有日常接触者（同户、同雇主、在场者）按需物化，并入 07 §7.3 第 5 条触发清单。

**二级（E/N 题的结构性缺口）**
8. core 预置持久师承持有（`mentor_of`，带 `derives.conduction`），05 §5.4 改口；职位决定（认证、受理、批复）的回避条款族与复核 / 上诉程序。
9. 受理管辖（forum）程序条款：谁的法院可受理、平行诉讼怎么处理。
10. 同意形状加 `purpose`，规范栈可读“超出同意目的”的使用；民事④加“签署人无法阅读且未被告知”的效力条目。
11. 抚养 / 供养义务种类与收养、托孤（遗嘱指定监护人）程序；遗嘱未涵盖财产与“关闭后新发现的财产”的处理。
