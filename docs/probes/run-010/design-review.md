## 判分口径

每条预期判为四类之一：
- **自**（自然得出）：只用设计正文写明的机制 + 设计规定位置与形状的数据即可得到；需写明章节与所需数据。需推测设计者本意的不算。
- **补**（需补数据）：机制在，但数据的位置或形状设计未说明。
- **缺**（设计缺口）：无机制，或按设计会得出相反结果。
- **矛**（设计矛盾）：不同章节冲突；不落题的也列入矛盾清单。

## E 题逐条

### E1 两家钱庄的利差循环（6 条：自 2 / 补 3 / 缺 1）

- ① 利息按实际天数、同一笔钱不"生息两次" — **自**。01 §1.4 loan / deposit 义务，累计闭式以天数或锚计数为输入（附录 A §A.15 期间口径）；钱只在一处（I1），借款是玩家的义务、存款是钱庄的义务，各自累计是正确结果；抵押存单再借 = `pledged` 指向 instrument（01 §1.3）。数据：`ontology/obligations.json` 的 loan / deposit 条款 `per` 与利率区间；钱庄经营条款 `rateTerms.per`（15 §15.5）。
- ② 汇费、出境关税从本金扣减，净利可为负 — **补**。关税：税表条目 `commodity: goods:coin`（附录 A §A.7，15 §15.3 铸币是 `goods:coin`）在关卡节点征收，可成立。汇费：设计只给了"兑换是两笔带手续费的转移"（01 §1.6、15 §15.3）与"汇兑 = 两网点间的内部 bill"（15 §15.1.1），**开汇票本身的手续费**（谁收、按什么表）没有位置；汇票作为随身物品过关是否按其 `represents` 的金额计税也未说明（可成为"带票不带钱免关税"的面）。
- ③ 调息按合同固定 / 浮动条款生效，不追溯 — **补**。固定：条款快照冻结（01 §1.4）自然成立。浮动：条款形状里没有"浮动利率 / 重定价"的写法，而闭式从 `accruedTo` 一次算到现在，若利率是在条款外读取的派生值则会**追溯**改写已计利息（没有"调息事件推进 accruedTo"的规定）。
- ④ 恒丰存款骤增后存息下调，波及全村储户 — **补**。15 §15.5：`loanable` 升 → 压力项降 → `interestRate` 降 → `depositRate = interestRate × spread` 降，自然成立；但"波及储户"只及**新签与续签**（已签条款冻结），已有活期存款是否随行重定价与 ③ 同一缺项（浮动 / 活期条款形状）。
- ⑤ 传闻"有人借钱套利"使万通好感下降、授信收紧 — **自**。推断规则产出 belief（05 §5.4）、状态评价时钟读主观视图产出 impress（05 §5.6）、`interestRate` 读借款人 standing 与主观风险（15 §15.5）、放贷同意走 npcDecision（05 §5.7）。数据：`rules/inferences.json` 一条、状态评价谓词一行（`social:eventWeight` 事件权重表）。
- 易错（借款被记为新增财富）：I1 / I2 排除，存款是钱庄负债（义务），不是玩家的"财富"派生以外的东西。
- 二阶 恒丰把存款再放给农户，玩家抽资时农户贷款被提前收回 — **缺**。钱庄放贷是组织候选（05 §5.7.3），抽资 = 支取转移，钱不够只会走 I2 → 停兑 → 挤兑 / 破产（05 §5.2.7、15 §15.5）。**没有"债权人依条款提前收回"的机制**：义务日程在条款快照里冻结，原语只有 create / settle / cancel，债权人 cancel 等于免债；`due()` 不读任何"call"事件。只能 emit(request) 请农户自愿提前清偿，结果取决于农户决策，与预期"被提前收回"不同。修法：义务条款加 `callable{noticeDays}`，`due()` 读 `called` 事件（核心闭式语义，需改 L1）。

- 易错（债挂个人、随"无遗产"清零）：① 排除。
- 二阶 佃户被双重收租、对两方好感同降 — **自**。钱庄 `pledged` 只给违约处置权（01 §1.3），收租是 emit(request)，佃户若付则是自有资源转移，对寺的 rent 义务未清 → 寺追讨；两方的索要 / 追讨事件按事件权重表产 impress（05 §5.6）。数据：事件权重表 demand / threat 行。

### E6 这是谁的狗（5 条：自 5）

- ① 所有权证据能被检验 — **自**。牙牌 = 文书 / 凭证物品 `purports` / `represents`（01 §1.2），耳缺 = 外貌事实 + `identify()`；鉴定 = 检定动作 → 识破事件进证据评分（05 §5.2.7）。

- ③ 判还则钱五补偿饲养与医疗费 — **自**。民事⑨ 无因管理 `negotiorum_gestio`（附录 A §A.7）：必要支出 → 受益人 compensation；支出额由账本事件求和。
- ④ 技能属于狗本身、不回滚 — **自**。技能是 creature 慢变事实（01 §1.2），持有转移不动事实。
- ⑤ 判还后狗可能凭亲密度跑回 — **自**。creature 走同一自治候选（`drive:attachment`，13 §13.3；05 §5.7）；`tamed_by` 的 vacated = 出走（04 §4.3）。数据：生灵候选 `return_to_bonded{applicability: standing(self, x, 'attachment') > 阈}`。
- 易错（两只黑子 / 技能重置）：实体唯一；④。

### E7 识字率 8% 的告示（5 条：自 4 / 补 1）

- ① 认知按信息来源分层 — **自**（需按"告示 = 文书"建模）。告示是物品个体，阅读前置 `canRead`（05 §5.4）；不识字者只得到"有一份文书"的知情；塾师读后 tell；谣言由失真表与推断规则产生。注意：附录 A §A.8 把"公告"列进**可观测域**（取真相）——若把张贴建模成"公告"事件，全员当场知道条文，预期反转；两种对象（公告事件 vs 告示文书）的分工未写明，见矛盾清单 X-a。
- ② 拖欠只发生在误信者身上 — **补**。税的缺省征管 `collection: automatic` 是反应规则直接转移（05 §5.1、附录 A §A.7），**根本不存在"拖延交粮"**；只有 `assessed` 才产生 tax 义务并由农户动作清偿。而 automatic 在纳税人账户不足时怎么办（转为义务？记欠？）设计未写。要得到预期须：田税条目 `collection: assessed`（位置明确）+ 农户纳税候选读 belief（候选数据）+ automatic 不足时的处置（**无规定**）。
- ③ 塾师纠偏、速度受好感网络限制 — **自**。tell + `credence` 读信任 standing（附录 A §A.15）。
- ④ 税额按真实条文 — **自**。`taxDue` 读规范栈（附录 A §A.7），belief 不改事实（I26）。
- ⑤ 识字率高的邻村误传更少 — **自**。识字率 = 识字技能派生比例（05 §5.4）；一手阅读多、二手转述少，失真表作用于转述。
- 易错（张贴即全知 / 谣言改税额）：①（按文书建模）与 ④ 排除。

### E8 两门挂名（5 条：自 5）

- ① 先查门规是否禁双籍 — **自**。`member_of.incompatibleWith` → 章程 `expelOn` → 法典 `plurality` 三级裁决（05 §5.3，01 §1.3）。数据：两派章程 `expelOn: [member_of 他派]`。
- ② 同一时刻只在一个擂台，缺席方好感降 — **自**。位置事实唯一（01 §1.2）；点名出战 = request → promise 义务；缺席 = 违约 → impress（01 §1.4 promise 行）。

- ⑤ 消息沿师兄弟扩散 — **自**。tell 链按路线与通道（05 §5.4）；同门同地，`mentor_of` 传导（01 §1.3）。
- 易错（同时出场 / 被逐后进库房）：②；进入权由 member_of 派生（01 §1.3）。

### E9 以米付薪、米价腰斩（5 条：自 4 / 补 1）

- ① 计价物不随米价折银 — **自**。合同只记资源种类与数量（15 §15.3）。
- ② 实物足额发放不构成欠薪，停工是另一类纠纷 — **自**。欠薪停工反应读 wage 欠额（05 §5.1），足额清偿则不触发；自愿停工 = 雇员候选（`need:money` 读 `wageQuote` 与现有条款实值，附录 A §A.17 辞工 / 跳槽行）。数据：候选一条 `strike_for_terms`。
- ③ 跳槽者使对街铺产能升 — **自**。`laborHours` 读 employed_by（05 §5.1）。
- ④ 东家产能、收入降 — **自**。同上。
- ⑤ 法典"实物折价"条款按条执行 — **补**。`obligation.settle` 只按义务资源种类结算（06 §6.3）；"以物抵债"只在 15 §15.2 作为 `value` 的消费者被提及，**清偿时以他种资源按估值折抵的条款形状与结算路径**没有写（民事族开放，但 settle 原语不读它）。
- 易错（米价跌被识别为欠薪）：②。

### E10 囤柴、租仓与限价令（7 条：自 7）

- ① 收购量受存量与卖家意愿约束 — **自**。可售 = 库存 − 自用保留、深度 `maxShare`、店家成交是 NPC 决策（15 §15.2）。
- ② 限价令只约束令后本镇交易、不追溯 — **自**。镇规 = 次级规范条目（05 §5.2.5），`effectiveFrom`；罪名按行为时（05 §5.2.2）；过去的 transfer 事件不改。数据：镇规一条状态 / 事件类罪名 `price_cap`。
- ③ 近林存量降、煤脉消耗快 — **自**。林地 / 矿脉是账户（05 §5.5）；镇民候选读主观报价选砍柴或买煤。数据：候选两条（`need:*` 开放族）。
- ④ 冻病发病率升 — **自**。`weather:temperature` 槽的消费者含燃料需求与体力消耗（§A.16）；病种感染率修正项读家户燃料账户。数据：冻病病种 + 修正项。
- ⑤ 堆柴升火险、起火损失照实 — **自**。`facilities:fireRisk` 修正项读库存性状（03 §3.4）；燃烧 → 库存 transfer → `sink:destroy`。
- ⑥ 镇民对玩家好感降 — **自**。状态评价时钟对"囤积"谓词产 impress（05 §5.6）。数据：状态评价行。
- 易错（外镇柴无限流入 / 限价改已付成本）：到岸成本只影响报价，实际流入靠商号进货候选与托运；②。
- 二阶 仓主因火险加租或解约 — **自**。出租人候选读 `derived('facilities:fireRisk', 仓)`；加租 = 新条款 request（已签冻结）；解约 = 授予者关闭 leases（06 §6.3 holding.close 发起者可为授予者）按租约条款。数据：候选一条、租约 `terminableOn`。

### E11 三人求一婚（6 条：自 6）

- ① 选择由性格与好感决定 — **自**。npcDecision 读红线、价值、standing（05 §5.7）。
- ② 私斗按法典（禁私斗则胜方也罚）— **自**。决斗动作打 `duel:consented` 描述标签，法典可不豁免（05 §5.2.3、12 §12.10.2）。
- ③ 婚后药铺产权按寡妇财产规则 — **自**。民事③ 婚姻财产（附录 A §A.7）；法典可声明钩子 `event(holding_opened: kin:spouse) → holding.rescale(...)`（附录 A §A.4 法典可声明钩子）。数据：法典民事③ 条款与钩子。
- ④ 落选者后续行为合理 — **自**。拒绝档位产 impress（06 §6.6）；迁居 / 婚配候选（05 §5.5、§5.7）。
- ⑤ 诗作名声独立累积 — **自**。作品 = 署名物品，传播 = tell / copy 链（05 §5.4），名士投影读事件。
- ⑥ 玩家回来知道多少取决于关系 — **自**。知情来源与传闻。
- 易错（同时与两人订婚）：**未被结构排除**——婚约是 `promise{kind: betrothal}`（04 §4.5.1），core 只对 escort / delivery / custody 族声明 `exclusive`（01 §1.4）；要排除须在 obligations.json 对 betrothal 声明 `exclusive{on: debtor}`（形状已有）。药铺自动过户：取决于 ③ 的条款，不会无故发生。

### E12 扩建压了邻居地基、地基又被卖了（5 条：自 5）

- ① 权利人随买卖转为钱庄、钱庄继受诉权 — **自**（分区粒度建模）。宅基是 node，owns 转移（04 §4.5）；"越界部分"= 扩建出的子地点 / 房间位于陈家 node 上（01 §1.5 建筑房间是子地点；空间只到分区粒度，11 §11.1）；民事⑩ 添附 `accession` 与返还请求属于 node 的现持有人（附录 A §A.7）。"二尺"这种几何重叠不可表达，只能表达"这间后院建在邻地上"。
- ② 玩家无权出租越界部分，布商可索赔 — **自**。非所有人开 leases = 无权处分标签（附录 A §A.15 占有），效力按民事⑨；布商对玩家 compensation（民事⑧⑨）。
- ③ 拆除损失与补偿可计算 — **自**。`value(建筑)` = 重置成本 × condition（15 §15.2）；destroy 经判决 / 决议授权（06 §6.3）。
- ④ 一人未同意则交易全部或部分无效 — **自**。owns 按份额（01 §1.3），一人处分他人份额 = `unauthorized_disposition`，钱庄善意有偿则取得、否则可撤销（附录 A §A.15）。
- ⑤ 时序越界在先、出售在后 — **自**。事件全序 `seq`、行为时 frame（14 §14.2，附录 A §A.15）。
- 易错（货物凭空消失 / 租金全额照收）：destroy 走残骸承接，内容物 reparent（04 §4.2）；租金 = 条款 × condition 系数，建筑没了则租约 `subject.gone: close`（04 §4.3）。

### E13 精怪借路、祠堂挡道（5 条：自 5）

- ① 精怪会协商 — **自**。精怪聚落 = 组织（05 §5.3），灵智生灵走 NPC 决策与计划（05 §5.7.2；13 §13.3 `drive:*` 是需求输入）。数据：精怪组织候选 `migrate{horizon > 1}`，步骤：request 借路 → 否则改道。
- ② 借路祭仪可减少损失 — **自**。仪式 = 带 `rite` 块的动作（13 §13.5，`rite:passage` 族），outcomes 可产 impress / promise 义务（精怪为债务人：不践踏）。数据：仪式动作一条。
- ③ 绕道导致减产、数值可查 — **自**。精怪群移动 = population 账户间 transfer（05 §5.5）；践踏 = 反应规则对途经田地 / 采菌林 transfer → `sink:destroy`；`explain()` / 修正项清单可查（05 §5.9）。数据：生态包反应规则 `trample`。
- ④ 谈判结果改变双方立场 — **自**。impress。
- ⑤ 南泽增、月见山减 — **自**。种群迁徙 = 逐地点账户转移（05 §5.5）。
- 易错（固定路径 / 无因果记录）：路线由通行性派生（01 §1.5），祠堂挡道须工程完工事件 fact.set 改分区邻接（01 §1.5 第六轮），作者不写则路仍通——这是数据义务而非缺陷；事件皆带 `causes`。

### E14 认证医师在远方开刀失败（6 条：自 6）

- ① 首次到达先生成骨架、人物一致 — **自**。07 §7.3 第 5 条骨架 / 完全物化；酋长是职位持有人 → 钉住 → 骨架必含（附录 A §A.15 钉住 (b)）。
- ② 部盟按其法典处理、认证不豁免 — **自**。属地层判定（05 §5.2.2）；`recognition.certifications` 只决定执业资格的承认，不进豁免条目（附录 A §A.7 豁免四条）。数据：部盟法典血偿条款（compensation 判决）。
- ③ 王国吊销与否由王国规则决定、与部盟判决分离 — **自**。`certified` 的终止由行会章程 `removalTriggers` 或程序 `review` 决定（04 §4.6、附录 A §A.7）。注：`removalTriggers` 按真相自动求值（04 §4.6）而组织行动按主观视图（05 §5.7.3）——口径未定，见矛盾清单 X-f。
- ④ 部盟对人类医师整体好感降、影响执业 — **自**。对类别的立场 `category:certified:医师`（05 §5.6 第七轮），求医候选读它（附录 A §A.17）。
- ⑤ 酋长继承顺位改变 — **自**。继承表按查询时 kin 派生（04 §4.4）。
- ⑥ 消息传回王国有延迟 — **自**。传闻沿路线延迟（05 §5.4，07 §7.3 第 8 条）。
- 易错（一地吊销全世界失效 / 未检查同意）：③；治疗类读同意，未成年由监护人代理同意（06 §6.3，附录 A §A.15）。

### E15 借我的钱、入我的股（6 条：自 6）

- ① 资本只增 200 两 — **自**。两笔 transfer + `holding.rescale`（06 §6.3），I1。
- ② 分红与利息循环时现金守恒 — **自**。I1。
- ③ 亏损时股值降、本金不变 — **自**。股份价值 = 净资产 × 份额（05 §5.1）；本金在条款快照。
- ④ 利息与分红各计一次税 — **自**。税表按事件类（`base` 开放，附录 A §A.7），幂等键条目 × 起因（I4）。数据：税表两行。
- ⑤ 死后股与债同入遗产、老母只继承净额 — **自**。share 持有人 gone → estate（04 §4.3）；loan `onDebtorGone` 缺省 assume_by_heirs（01 §1.4）→ 随分配转给继承人、`liabilityCap` = 所继承财产估值（04 §4.2 第 9 步）——净额由限定继承实现。注：民事① `setOff` 只对**同两方**互负债务（附录 A §A.7），这里债权人是玩家、股份义务人是粮铺组织，不同实体，不会自动抵销；预期"可以相互抵销"只在玩家回购股份（对价）时成立。
- 易错（资本双计 / 清算顺序错乱）：① 与 04 §4.4 清偿顺序。
- 二阶 净额为负时老母是否还债 — **自**。民事② 限定继承 / 无限（04 §4.4、附录 A §A.7）。

### E16 被风暴吹到外港的商船（6 条：自 6）

- ① 货仍归船主与托运人、救助报酬按比例扣 — **自**。搁浅不是 destruction，owns 不动；位置事实随船（01 §1.2）。救助报酬 = 民事族新条款（`civil:*` 开放，附录 A §A.7）在 salvage 事件后由反应规则创建 compensation。数据：湾会法典 `civil:salvage{share}` + 救助动作。
- ② 搁浅期间工资是否照计按合同和法典 — **自**。wage 按 `laborHours`（只计 `effective` 且未被状态打断）或固定 `per: anchor`（01 §1.4）；在途只有路上的作息（附录 A §A.3）；宽限只来自 `grace`（I29）。
- ③ 该港局部降价 — **自**（条件成立时）。有效存量 = 本地可售存量 − 已承诺的未到期交付（15 §15.2）：承运中的货仍承诺交付他地，**不会自动压价**；只有托运人 / 救助方把货在本港出售（或无权处分）后，成交才改变存量与报价。设计给出的是正确的条件结果，不是无条件降价。
- ④ 到货延期按在途滞留处理、违约金可计算 — **自**。delivery 滞留按天、货损与违约条款（01 §1.4）。
- ⑤ 王国汇票在湾会能否兑付取决于两地钱庄关系 — **自**。兑付前提 = 兑付地有该钱庄 `branch`（05 §5.1）；无网点时可向当地钱庄转让债权，按 `value(债权) = 面值 × 可靠度 × 折现` 贴现（15 §15.2），当地钱庄收与不收是 NPC 决策读对王国钱庄的 belief 与 standing。
- ⑥ 玩家首次到达时骨架与已发生事件一致 — **自**。钉住义务端点到期 / 到达即骨架物化（07 §7.3），物化只"借出"存量、不改事件。
- 易错（搁浅货归港口 / 骨架覆盖事件）：①、⑥。

### E17 一个驿站、两枚官印（5 条：自 5）

- ① 任命生效后只有玩家有权签发、旧印文书无效 — **自**。权能 = `authority()` 读 `holds_office`（附录 A §A.15）；前任持有已 vacated（调任），其签发 = 无来源 → 文书只有 `purports`、`represents` 为空 = 伪造物（01 §1.2）；物品 `authority` 派生自创建者当时的持有（01 §1.10）。
- ② 持旧印路条过关按法典（善意可免）— **自**。行使伪造物谓词读 `knows(actor, forged)`（05 §5.4）。
- ③ 俸禄只发一人、前任已领追回 — **自**。salary 止于持有终止、只累计 `effective` 日（01 §1.4）；多领部分 = 民事⑨ 不当得利返还。

- ⑤ 守卫判断取决于是否收到任免通报 — **自**。守卫按主观视图（I25）；公文到职位须阅读（05 §5.4）；鉴定 = 检定。
- 易错（权限跟印走 / 两人同领俸）：①③。

### E18 生在渡船上的孩子（5 条：自 4 / 补 1）

- ① 身份在各政体规则下分别判定、可多重 — **自**。citizen_of 由出生反应规则按各政体法典的出生户籍条款开立（01 §1.2 C4；附录 A §A.15 承认的消费者"出生户籍条款"）；河段是节点（01 §1.5），其父链给出出生地法域；城邦可按"生于本邦船户之船"（RX 读容器链 `located`）开立；各法域对他法域的 citizen_of 经 `recognized`。数据：三部法典各一条 citizen 条款。
- ② 族谱自动挂父系、诸帐按母系另记 — **补**。kin 双亲边自然开立（01 §1.2）；"族谱"= 家户组织的文书 records（05 §5.4 记账反应）；但**新生儿入哪一户（household_member 的开立规则 = 父系 / 母系）**没有位置：文化记录字段表（13 §13.2）没有 descent 项，民事③ 也未列。
- ③ 渡船医疗条件影响母婴风险 — **自**。生育反应规则的风险派生缺省开槽（附录 A §A.9 第 3 条），修正项读所在地设施性状与在场医者的 `serviceCapacity`。数据：医疗包风险派生与修正项。
- ④ 继承权在不同法典下结论不同 — **自**。继承表只计 `recognized` 的 kin（04 §4.4），按 frame.jurisdiction。
- ⑤ 命名礼影响宗教好感 — **自**。仪式动作 outcomes → 对教团的 impress（13 §13.5；05 §5.6 组织立场）。
- 易错（出生地记为玩家所在郡 / 单一政体判身份）：出生事件地点 = 河段节点（位置事实），①。**边缘缺口（不落题）**：陆路路线边上的位置（"所在路线段 + 进度"）不是节点，`normStack(actor, 地点)` 对途中事件（拦路抢劫、路上分娩）无定义——见矛盾清单 G-2。

### E19 野蜂、催产术与出租蜂箱（6 条：自 6）

- ① 授粉提升果园收成、有上限 — **自**。`economy:yield` 修正项 + bounds [0, 3]（附录 A §A.16）。数据：修正项读邻近蜂群账户。
- ② 魔法与授粉不线性叠加 — **自**。派生方声明的阶段含 max（§A.16 yield 行：add, mul, max, min, clamp）；两项用 max 阶段或 `exclusiveGroup`（§A.16 末）即不叠加。数据：两条修正项的 stage / exclusiveGroup。
- ③ 蜂蜜大量上市压低蜜价 — **自**。`src:husbandry` 活体产物（01 §1.6）；报价随存量（15 §15.2）。
- ④ 邻田溢出授粉有一致规则 — **自**。修正项 `when` 读 `distance(a, b)` / 分区邻接（附录 A §A.13）。
- ⑤ 蜇伤病例增 — **自**。时钟规则按蜂群密度概率产 `harm:injury`，医疗包订阅（03 §3.2）。数据：生态包时钟规则。
- ⑥ 冬季蜂群自然减员、同伴数量随之变 — **自**。蜂群是被 owns 的种群账户（01 §1.3，`tamed_by` 只对 creature），季节死亡按物种 `lifecycle` 进 `sink:death`；"同伴数量"就是该账户数量。

### E20 批量培训工匠压低工钱（5 条：自 5）

- ① 技能受书本品级与时长限制 — **自**。learn 每日上限与衰减、书 `teaches` 品级（05 §5.4、06 §6.3）。
- ② 供给增 → 铁匠工价与铁器价同降 — **自**。`wageQuote` 稀缺项 = 用工需求 ÷ 可雇劳力（15 §15.2）；铁器存量升 → 报价降。
- ③ 未认证学徒能否接单按行会规则 — **自**。`certified` 派生开店资格（01 §1.3）；成员层规范对会员、法典 `recognition.certifications` / 行会与政体协议生成的补丁对非会员（05 §5.2.8）。数据：行会章程 + 补丁一条。
- ④ 三方行动可追溯 — **自**。事件 `causes`、`explain()`。
- ⑤ 书本外流后技艺在他村扩散 — **自**。抄写 = create 复制 teaches、读书 = learn（05 §5.4）。

- **X-h `derives` 的键集（不落题）**：01 §1.3 / 12 §12.2.3 列 derives 只有 authority / 称呼 / 额度 / schedule / 服务 / conduction / pins；12 §12.7.3 示例 `disciple_of` 声明 `derives.canLearn`。要么 derives 开放任意键，要么示例改用 `rules/derivations.json`。
- **X-i owns 与 tamed_by 的分工（触及 E6，未反转）**：动物既可被 `owns`（物种 ownable，01 §1.3 第六轮）又可被 `tamed_by`（"宠物是财产，进遗产"）。两条持有都进遗产、都可转让，哪一条是法律所有权、驯服是否自动开 owns，设计未写。E6 的"归属判决"应只动 owns，但文中没说。
- **X-j 田税的两套征收模型（触及 E7②）**：05 §5.1 税 = 反应规则直接转移（automatic），15 §15.1.1 又把"税"列入条款 `autoSettle` 的义务。两者按 `collection` 可并存，但 automatic 在账户不足时的处置缺失（见 E7②），是缺口而非矛盾。

**边缘缺口（不落题，建议记录）**
- G-1 债权人依条款提前收回（E1 二阶）：见 E1。
- G-2 路线边上的位置没有法域：01 §1.5 法域从节点上溯，"所在路线段 + 进度"不是节点；途中事件（劫道、路上签约、路上分娩）的 `normStack` 无定义。建议：边带 `jurisdictionRule: from | to | nearest | split(进度)`。
- G-3 新建工程的半成品不是世界对象：project 在完工事件才 create 设施（01 §1.4）；停工的半截建筑不能被看见、烧毁、损耗或占用分区。建议：开工即 create(building, condition 0) 并以 project 推进 condition。
- G-4 批次 `taint` 的写入者（E5⑤）：见 E5。
- G-5 污染源：源汇表无污染源，水质 / 污染账户只能靠具体污染物资源表达；应写明或加 `src:pollution` 守恒对。
- G-6 `escrow:*` 用途账户与出纳权能的边界（N3 易错）。
- G-7 婚约 `promise{betrothal}` 未声明 exclusive（E11 易错）。

## 修改建议（按严重度）

**严重（影响玩法正确性或可被利用）**
1. 义务的"提前收回 / 重定价"缺位（E1 二阶、E1③④）：给义务条款加 `callable{noticeDays}` 与 `rate: {floating: 派生 id, resetOn: anchor}`，`due()` / 闭式读 `called` / `rate_reset` 事件并推进 `accruedTo`。否则活期存款、可召回贷款、浮动利率三种常见合同都表达不了，且浮动利率会被闭式追溯改写。
2. `collection: automatic` 在纳税人账户不足时的处置（E7②、X-j）：写明转为 `tax` 义务（或记欠），否则"拖欠税粮"这一最基本的治理冲突不存在。
3. 批次 `taint` 的写入规则（E5⑤、G-4）：法律包反应"嫌疑记录成立 ∧ 事件含取得批次 → fact.set taint"，并写明 taint 在 settle / 转卖时的传播是否读知情。
4. 托管用途账户的权能边界（N3 易错、G-6）：`authority(出纳, transfer, escrow:*)` 缺省为假，只有托管义务的 settle 到期项可动；否则赏金、讼费担保、遗产托管都可被挪用而面板不知。
5. 路线边上的法域（G-2）：边带法域规则；否则途中事件无规范栈，劫道不立案。

**中等（结果偏差或口径未定）**
6. 公告 vs 告示分工（X-a）：一句定义。
7. 解任触发的视角（X-f）：章程谓词按组织知情集合求值。
8. 开放债权人的多人分赏（N3④）：允许 `firstToSatisfy` 返回加权集合，清偿按权重拆成多笔 settle；或债权人 = 队伍 project 实体。
9. 以物抵债（E9⑤）：`obligation.settle` 加 `with: {resource, lot}` 参数，按 `value` 折抵，受民事条款允许。
10. 家户归属规则（E18②）：文化记录加 `descent: patrilineal | matrilineal | bilateral`，出生反应规则据此开 household_member。
11. 半成品工程（G-3）。
12. owns / tamed_by 分工（X-i）：驯服 = 开 tamed_by 并在物种 ownable 时同事务开 owns；判决只动 owns。
13. 自动创建义务的授权来源（X-c）；反应链深度对包规则一律计数（X-d）。

**轻微（文字一致性）**
14. X-b、X-e、X-g、X-h 按清单改字。
15. 汇票手续费与汇票过关的计税口径（E1②）：票据不计关税（价值未过关）或按 `represents` 计，写一句。
16. 婚约 exclusive（G-7）：core 为 `promise{kind: betrothal}` 声明 `exclusive{on: debtor, policy: forbid}`。

## 专项

### ① 时序与并发
- 骨架完整：五阶段全序、锚实体排序、争夺池 3′（整提案原子）、补算不递归且先于读取事务编号、刻回滚重跑、调度配置为输入事件（14 §14.2–14.6）。E12⑤、E17④、N1① 都能由此确定地得出。
- 风险 1：X-d——settlement / legal 类反应不受深度与提案上限约束，包规则若声明这两类即可成环（12 §12.8.3 的"全局上限"被 14 §14.2 的例外抵消）。
- 风险 2：阈值到期项"其余阈值在该派生的输入事件之后的阶段 4 重算"（附录 A §A.15）要求引擎知道每个派生的输入集合——派生缺省开槽后输入集合随修正项变化，依赖追踪的实现成本与 I31 的确定性都压在"版本键"上，设计没有写修正项加入后阈值重算的触发集如何更新。
- 风险 3：跨区陈旧读的 `tolerance` 与 I31"逐字节"并存：补算不足一步长的差额按容差处理，但事件序列仍要求逐字节相同——只要容差不进入事件（只进入派生值）即可成立，建议写明"容差只作用于派生值，不产生事件"。

### ② 守恒与套利
- E1 的利差循环被 `depositRate = interestRate × 0.4`、借款侧压力项、汇兑费 / 关税、期间口径（闰月不成期）共同封住；E15 资本双计、N3 赏金双发、N7 能量凭空、N8 税款不退都由 I1 / I2 / 事件只追加排除。
- 漏洞 a：汇票随身过关不计关税（E1②）——"带票不带钱"可绕过货币出境税；需明确票据过关口径。
- 漏洞 b：`escrow:*` 可被出纳动用（G-6）。
- 漏洞 c：浮动利率闭式追溯（E1③）：若利率派生被修正项或市场改变，`amountDue` 从 `accruedTo` 起全段按新率算——可被"先借后改率"的政体候选利用；需结息事件。
- 漏洞 d：`taint` 无写入者 → 赃物洗白（G-4）。
- 其余 15 §15.9 防线逐条核对，与本轮题目相关的（当日报价缓存、可替代物洗白、虚假远期、挤兑、mark 刷立场、装卸循环）在正文有机制与位置。

### ③ 性能
- 07 §7.5 的分解预算合计 2.0 s 恰在 B14.2 上限，无余量；且估算未计入：每次派生读的修正项查找（派生缺省开槽后每个派生读都要扫槽，07 没有给"无修正项的槽零开销"的实现约束）、`identify()` / `recognized()` 的热路径（11 §11.2 第 27 条已自认）、状态类罪名的周期扫描、阈值重算的依赖追踪。建议在 scale 测试里把"空槽读开销 ≤ 5%"列为单独预算。
- 感知快照去重、候选索引、normFree 快速路径的设计合理；D1–D3 只改计算时机的口径清楚。
- 存档：知情集合无界靠归档段与可截断索引，口径可行。

### ④ 复杂度与可理解性
- 附录 A §A.15 单条目动辄数百字、内嵌"第 N 轮 / Rx-Xn"标记，正文到处是修订脚注；对实现者与第三方作者的阅读成本高。建议定稿时把轮次标记全部移入修订记录（根因分析 (c) 已要求，但正文仍大量残留）。
- 概念数量：8 存储概念 + 19 原语 + 32 不变量 + 5 层规范栈 + 四域 + 四轴 frame + 8 钩子模板——可学，但"同一件事有两种表达"的地方（公告 / 告示、owns / tamed_by、tax 反应 / tax 义务、invited / 包自定名单）会让作者选错形状。
- 法典数据完整性（十类民事 + 程序 + 认可 + 授权表）× 九省政体 + 冥府 + 非人政体，是最重的内容负担（11 §11.2 第 1 条自认）。

### ⑤ 章节一致性
- 见矛盾清单 X-a…X-j：无相反结果型冲突；10 处口径未定或示例与枚举不一致，其中 X-a、X-f、X-i、X-j 触及本轮题目但未反转结果。
- 附录先于正文的纪律基本做到（本轮未发现正文使用而附录未登记的枚举词），但 12 §12.7.3 示例与 §A.4 / 01 §1.3 的枚举有两处不符（X-g、X-h）。

### ⑥ "只加数据"
- N6–N8 22 条全部由数据得出：配方、物品阶、状态、持有种类、钩子、修正项（含 exclusiveGroup）、补丁 append(clause)、物种数据、税表、卸载策略、core `stage` 作为跨包量纲。没有一条需要新原语或改引擎。
- N1–N5 中需要新义务 / 持有种类的（stipend、mail_hold、contract:mercenary、zhenfa:admitted）都在 ontology/*.json 的既定形状内。
- 但本轮的"补"条（E1②③④、E7②、E9⑤、E18②、N3④、N3 易错）全部落在**core 闭式或原语的语义**上（due()、settle、automatic 征收、开放债权人解析、household 开立规则、escrow 权能），不是包能用数据补的——这正是"只加数据"边界的现状：契约内很开放，契约本身还有上述缺口。
