# run-010 设计预审（第八轮预审，常规档，独立审查员）

审查对象：docs/架构设计/ 现行正文（目标架构.md、01–15 章、附录A）。判分只依据设计正文；学科覆盖表、修订记录、走查（09 章、12 §12.10）与自评不作证据。审查员未参与任何设计与修订，未读 daily/review-001 与其他 run 目录。

## 口径

- **自**＝自然得出：只用正文写明的机制加数据即可得到，并指出所用章节、需加的数据及其在设计规定的位置与形状。
- **补**＝需补数据：机制大体在，但数据的位置或形状设计没有说明，或结果须推测设计者本意。
- **缺**＝设计缺口：缺机制。
- **矛**＝设计矛盾：不同章节冲突（不落题的也列在文末）。
- 计数：E 题每条编号预期 1 条，有二阶后果的另计 1 条；N 题拆为"加什么 / 装上后各条 / 卸掉后 / 同装或冲突 / 易错"，有几项计几条。E 共 111 条，N1–N5 共 36 条，N6–N8 共 22 条，合计 169 条。

### E1 两家钱庄的利差循环（自 3 / 补 1 / 缺 2）
| # | 判 | 依据与需加数据 |
|---|---|---|
| ① 按实际天数计息、同一笔钱不两次生息 | 自 | 借款与存款各是一条义务（01 §1.4 loan / deposit），钱是真实转移（I1、15 §15.1.1 价值有位置），钱庄只能贷手里的现金（15 §15.5 loanable，I2）；存单可作质押标的（01 §1.3 pledged → instrument）。条款取 `per: day`（附录A §A.15 期间口径）即按实际天数。注：§A.15 内部对"以天为底 / 按锚"有冲突，见矛盾 X1；本题合同取按日，不受影响。 |
| ② 汇费、出境关税扣本金，净利可负 | 自 | 汇兑与兑换是带手续费的两笔转移（15 §15.3 汇率段）；跨境铸币按税表 `subjects: cargo` 计关税（附录A §A.7 税表条目）；汇票兑付前提是兑付地有出票钱庄 branch（01 §1.4 bill），否则只能运铸币。数据：钱庄汇兑手续费（bill 条款）、两地税表行。 |
| ③ 调息按合同固定 / 浮动生效，不追溯已计利息 | 缺 | 01 §1.4 只有"条款快照签约时冻结"（即固定利率）；15 §15.5 `interestRate` 写 `clamp(..., terms.minRate, terms.maxRate)`，但没有说存续合同是否随派生利率重定价，也没有"调息事件把 `accruedTo` 推进到调息时刻再换率"的分段规则。闭式 `amountDue = f(条款, accruedTo, t)` 若读新利率，会把上次结息以来的天数一并按新利率计——恰是题目要防的追溯。浮动利率条款与调息分段需要补机制。 |
| ④ 存款骤增后存息下调，波及全村储户 | 缺 | 方向可得：存款增 → loanable 增 → 压力项降 → `interestRate` 降 → `depositRate = interestRate × spread` 降（15 §15.5）。但"波及已有储户"要求活期存款随派生利率浮动，与③同一缺口：存款义务的利率是冻结的快照还是浮动，设计未定。 |
| ⑤ 套利传闻使万通好感降、授信收紧 | 自 | 传闻 tell 进入万通决策职位持有人的知情（05 §5.4、§5.6 组织知情）；事件权重表加一行"在他行套利"的负向权重（`rules/tables` 事件权重表，05 §5.6）；授信读 standing（15 §15.5 违约史项、06 §6.4 `lend` 前置示例 `standing > -20`）。 |
| 二阶 抽走资金引发农户贷款被提前收回 | 补 | 抽走存款只会让 loanable 下降、利率上升，或在现金不足时停兑 → 破产（15 §15.5）。"提前收回"需要贷款条款里的随时催收 / 加速到期条款，以及钱庄在流动性紧张时发起催收的自治候选；义务条款与候选的形状是有的（01 §1.4、05 §5.7.1），但催收条款与"加速"在 onDebtorGone 之外的用法设计没有给形状。 |

## 修改建议（按严重度）

**严重**
1. **零售成交口径**（日常题集 8 条失分的同一根因，见 daily/review-002）：15 §15.2 规定"一笔数量为 q 的买入不按报价结算，而是沿稀缺曲线积分"，又有 14 §14.6 向零取整，但没写舍入在单价还是总额上做。结果是"标价 4 文买 3 个"不保证 12 文，卖 5 张兔皮按向零取整几乎必然少给 1 文。建议：商号零售与收购在 `q ≤ 本地有效存量 × 小额阈`（数据）时按 `quote(side) × q` 结算、只对总额舍入一次；超过阈值才走积分；或者把"牌价"作为 operates 条款，由店主定价候选写入。
2. **X1 计息口径**：二选一并改全篇。若保留 `per: anchor`，须删改附录A §A.15 历法条与 15 §15.9 那一行，并规定闰月对按锚条款的处理（闰月按 `rateBasis` 折日计息，或作为一锚），否则闰月套利重新打开；03 §3.3 示例统一为同一写法。
3. **床位 / 房间占用与物品个体寄存**（D04⑤、N1 三条）：给"按夜占用房间或床位"一个持有形状（标的可为房间地点，带 `until` 与 `contest`），或允许 `leases` 以房间为标的；给物品个体寄存一个可由商号组织持有、随 operates 易手而不 `revert` 的形状（扩 `custody_of` 的 holderKinds，或让 `bailment` 接受物品个体）。

**中等**
4. **浮动利率与调息分段**（E1③④）：义务条款加 `rateMode: fixed | floating{index, resetAnchor}`；调息事件先把 `accruedTo` 推进到调息时刻再换率，保证不追溯。
5. **在途位置的法域与船籍**（E18①）：规定路线段的法域（端点同法域取之；界河按中线或首段；不可定时取冲突法条款），并在冲突法里加"船舶所属"（船籍）选法项。
6. **委托承接与合击分赏**（日常 D23③、N3④）：给"张贴委托 → 接下 → 交付"一个标准形状（接下 = promise + 付款义务，以委托文书为 `exclusive` 的标的）；bounty 加 `split: winner | byContribution(causes 权重) | equal`，多债权人按份清偿。
7. **NPC 收信即读**（日常 D25⑤）：core 预置反应或候选"收件人在场且 `canRead` → 阅读"，不识字者找代读。
8. **法术专有权**（E3②）：若要做，`registered` 派生专有范围，侵权谓词读法术效果签名的相似度（给一个 core RX 函数与阈值数据）；若不做，在 11 §11.1 写明。
9. **禁飞 / 空中进入**（N7）：`primitiveLimits` 增 `move` 键（按 mode 限制进入），派生空路到达目的地时校验目的地点的进入限制。

**轻微**
10. 税表加按派生值分档的字段（`bands: [{rx, rateBps}]`），覆盖"按亩产分等"（E7④）。
11. 定义建筑与其坐落地块的关系事实，并在民事⑩写"地上物附合于土地"的缺省（E12①②）。
12. core 预置"减损 / 豁免"类共享词或 `exclusiveGroup` 词族，并在 05 §5.9 写明 max 与 min 同时出现时的语义（N8 同装）。
13. 贷款条款加催收 / 加速到期条款与钱庄流动性候选（E1 二阶）。
14. X2–X6 的措辞统一。
