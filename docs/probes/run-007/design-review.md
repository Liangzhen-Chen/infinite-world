## 判分口径

- **自**（自然得出）：只用设计正文已写明的概念、规则形状、不变量、协议、统一模型、动作层、空间、时序、扩展点与契约附表，加数据即可得到；必须指出用到哪几节、加什么数据、数据放在设计规定的哪个位置与形状。需要"推测设计者本意"的不算。
- **数**（需补数据但设计未说明数据位置或形状）：机制存在，但完成该条所需的数据没有设计规定的落点或 schema；不计自然得出。
- **缺**（设计缺口）：没有机制能得出，或设计规则会得出相反结果。
- **矛**（设计矛盾）：不同章节说法冲突；落题的记在题上，不落题的记在"全部设计矛盾清单"。
- 计数：E 题每条编号预期各 1 条 + 二阶后果 1 条（E6、E19 无二阶，不计）；N 题按"加什么 / 装上后各条 / 卸掉后 / 同装 / 易错"拆条。N 题额外检查"只加数据"、命名空间、装卸与实体转换、冲突、存档兼容、对 core 派生输入的影响（契约附表 B/C 是否够用）。
- 达标线：自然得出 ≥ 95% 且零矛盾（用户 2026-10-15 决定）。

### E1 ★ 围城中的借据与法典切换

建模：围城 = 05 §5.10 战役 `project`（阶段 围城），求解器输出 `controls` 持有封闭郡城的路线节点（01 §1.5 通行性 = `controls` 封闭标记）；城破 = `holding.transfer(governs)`（05 §5.10、01 §1.3 governs 行）；钱庄股份 = `share`；分期借款 = `loan` 义务（条款快照含签约地与规范栈版本，01 §1.4）；粮柴 = `lots` 资源与燃料资源（01 §1.6）。

| 二阶 部盟对"人类商人"的好感基线传播到玩家粮行雇工 | **数** | 05 §5.6 基线 = "文化/势力关系表，组织间基线为数据表（12 章 edge）"：只按文化或组织键，没有"文化 × 职业/持有种类"的键形状，"人类商人"这一角色基线无处写；传导边列表（member_of / kin / household / allied_with / citizen_of / holds_office / devotee_of / 种群）不含 employed_by，粮行雇工只能因自身文化为人类而得到人类基线，"商人"项不传到雇工。机制有、数据形状无。 |

|---|---|---|

## 二、新增内容题 N1–N5

### N1 ★ 新增：改元与闰月历法

设计里的时间：01 §1.9 "单一世界时间（分钟）"、14 §14.1 刻 = 分钟；"月""季"只以 RX 函数出现（`season()`，§A.13；`month` 只在 12 §12.8.1 白名单）；义务日程 `period: "month"`（03 §3.3）；节庆、阈限时间窗来自文化记录"日历窗口"（13 §13.2）。全篇没有历法数据形状（月长、闰月规则、年号），没有"日历"扩展点（12 §12.2.3 表无此行）。

| 条 | 判定 | 依据 |
|---|---|---|
| 加什么：改元 + 阴阳历闰月 | **数** | 年号可作政体慢变事实（议案 `norm`/`fact.set`，05 §5.2.5）并由投影按观察者法域渲染——这部分有落点；闰月改变 `month`、`period: month`、季节窗口的语义，是 L0/L1 时钟内核的行为，没有任何数据位置能声明"本历法第 N 年有闰月"；包不能改公式分支（12 §12.1）。只加数据不成立。 |
| ① 闰月期间俸禄是否多发、利息是否多算要统一 | **缺** | salary "按月"（01 §1.4）与 loan `principal*rate*days/360`（03 §3.3）各自声明累计闭式，设计允许每个义务种类自选口径且没有全局"月与日换算"规则；闰月到来时 `period: month` 是否多出一期、按月累计与按日累计是否对齐，没有规则能回答——两种口径并存是设计许可的结果，与预期相反。 |
| ② "三年为期"按月数还是年号年要一致 | **缺** | 同根：`terms.maxMonths` 用月数，条款快照里"三年"若写年则 12 还是 13 个月无定义；年号年与历法年的关系无定义。 |
| ③ 改元前订立的文书仍有效 | **自** | 文书 records 引用事件编号与世界时间（05 §5.4），年号只是投影；效力按条款快照（05 §5.2.2）。 |
| ④ 节庆按新历自动重排，不出一年两个端午 | **数** | 节庆日期的数据形状（现状 festivals.json，目标 13 §13.2 "日历窗口"）未规定如何以历法日期表达、闰月中的节日如何取舍；`window(id)` 只是派生函数名。 |
| 易错 月数与日数换算不一致导致两种利息口径并存 | **缺** | 同①。 |

N 题专项：命名空间无涉；装卸——历法若为核心数据则不可卸；契约附表 B/C 无时间类槽，不够用；存档：改变历法语义会改所有到期项的解释，需纪元边界。

### N2 ★ 新增：各政体度量衡

设计里的单位：账户存量"整数，单位由资源种类定"（01 §1.6）；"计量单位、数字格式按 locale 目录分层"（11 §11.1）——locale 是玩家界面语言，不是世界内政体；文化记录字段（13 §13.2）无单位；计价单位 `recognition.legalTender = {unit: 某铸币}`（15 §15.3、§A.7）限定为铸币，`quote = value ÷ value(计价铸币)`。

| 条 | 判定 | 依据 |
|---|---|---|
| 加什么：王国斤、矮人锭重、草原以羊计价 | **数** | 斤/锭只是同一物理量的显示换算，可写成单位表，但世界内"按观察者所在政体显示单位"的落点未规定（locale ≠ 政体，文化记录无单位字段）；"以羊计价"要求 legalTender.unit 指向非铸币资源，15 §15.3 的 `value(铸币)` 公式（金属含量 × 发行信用 × 充裕度）对羊不适用，信用分支要求 issuer/backedBy，也不适用。 |
| ① 跨政体交易自动换算，总物量守恒 | **自** | 存量只有一个规范单位（01 §1.6），换算只在投影，I1 守恒天然成立。 |
| ② 税按入境地度量计 | **自** | 税按规范数量 × 税率（§A.7 `rateBps`），显示单位无关。 |
| ③ 车船容量按物理重量 | **自** | 容量事实与运力派生都用规范单位（05 §5.1）。 |
| ④ 换算差套利应有上限或损耗 | **自** | 显示换算不改存量，不存在换算套利；跨境真实差价由 15 §15.3 汇率与关税、运输成本约束（15 §15.9 固定兑换比套汇行）。 |
| 易错 同一批货两地换算后数量增加 | **自** | 同①，守恒不被显示改变。 |

N 题专项：若把"锭"做成独立资源种类（而非单位）会破坏守恒与可替代性——设计未警示但判别表（§A.2）"计量的东西 → 账户"足以引导；契约附表无需扩充；无装卸问题。

### N3 ★ 新增：船货保险

建模：保单 = 义务种类（上位 `contract:insurance`，01 §1.4 已点名）；保费 = 货主 → 商会 的一次性/upkeep 义务；赔付 = 商会 → 货主 的条件义务，清偿由反应规则订阅载体 `destruction`（04 §4.2）触发；保费派生 = 包的 `rules/derivations.json`，开放自己的槽（05 §5.7.4 已以"保险包的保费派生开放槽"为例）。

| 条 | 判定 | 依据 |
|---|---|---|
| 加什么：商会承保，保费按航线风险 | **数** | 义务种类、反应规则、派生都有落点；但"航线风险"是 core 派生值 `transport:risk`（§A.16 槽），§A.13 没有任何读取路线风险或路线上 `controls` 持有人的 RX 函数（只有 `reachable`、`distance`），包的保费派生读不到它；需契约次版本加函数。 |
| ① 沉船按保单赔付，从商会公库出 | **自** | destruction 事件 → 反应规则 `obligation.settle` + transfer（商会公库 → 货主），I2 不足则 overdue → 破产案件（05 §5.2.7）。 |
| ② 故意沉船骗保可查出并定罪 | **自** | destroy 由所有者发起记入起因链（06 §6.3）；`offense:fraud` 谓词读 `causes(event)` 与 actor = 被保险人（05 §5.2.3）；两步立案与证据评分。数据：罪名条目。 |
| ③ 风暴季保费上升 | **自** | 派生读 `season()`（§A.13）与季节风险表（包 tables）。 |
| ④ 同一货物重复投保最多赔一次 | **自** | 义务种类 `exclusive{on: subject, among: [contract:insurance], policy: forbid}`（01 §1.4、I8）。 |
| 易错 已有沉船事件不触发理赔，或与托运赔偿重复支付 | **自** | 反应规则按动词 `destroyed`/`transition(destruction)` 订阅（03 §3.2 第 2 条）；避免双付 = 赔付义务条款 RX 读货主已获 compensation（`obligations(x, role)`，§A.13）扣减——可表达但设计无"代位求偿"缺省，见专项②。 |

N 题专项：命名空间 `insure:*` 私有词 + 共享上位 `contract:insurance`；卸载：存活保单按 uninstall.json `obligations.convert → core:compensation` 或 cancel；存档兼容由退役表承载；契约附表：需要 `transport:risk` 读函数（缺口）。

### N4 ★ 新增：军功授田

建模：军功 = 战役事件计数（`countEvents({actor, verb: kill}, 战役窗口)`，§A.13，非候选/推断可用）；授爵 = 政体创建 `peerage` 职位 + `holding.open(holds_office)`（05 §5.3）；授田 = `holding.transfer(owns)` 公田/抄没田（node）→ 军户；佃农 = `leases`；伪报 = 自述 claim 与真相事件不符。

## 六、专项评估①–⑦

**① 时序与并发**：五阶段 + 争夺池 + 补算不递归 + 刻回滚重跑基本自洽；两处未定：(a) 阶段 2 锚实体 id 序对非争夺型稀缺标的的系统性偏向（X13）；(b) 阶段 4 反应产生的争夺型提案（两条反应同时 `holding.open` 同一互斥标的）在 3′ 之后如何裁决未写（L13）。环状互读的 tolerance 累积只说"计入 I14"，无上界。结论：无结果相反型问题，两处补字即可。

**② 守恒漏洞与玩家套利**：15 §15.9 防线对本轮题目基本覆盖（军需券伪造、内部调拨免税、度量衡显示换算、风水叠加 bounds、远期压价）。新发现：(1) 船货保险 + 承运人货损赔偿可双收（无损失填补上限/代位，M12）；(2) N1 根因：若各义务种类按月/按日口径不一，闰月时可选按月计息存款、按日计息贷款套利；(3) 种马租用的幼崽归属缺省由包定，不破守恒但是分配争议点；(4) 身份模型缺失不是套利而是反向泄露（化名债务/通缉瞬间归本名）。

**③ 性能与降级**：07 §7.5 估算已贴近 2 s；本轮暴露三条未入成本模型的读路径：`knownHoldings` 门控让每次立场传导查知情集合（缓存键须含知情版本）；`countEvents` 在税表免税额（每笔交易）与状态类罪名的窗口查询需事件窗口索引（07 §7.5 已提"事件窗口索引"但无预算行）；N8 类食物链 30 物种 × 地点的 O(n²) 迭代在统计层月步长可接受，规则层按日的成本与容差未估。若加 S1 认人派生，感知成本上升。无新硬伤。

**④ 复杂度与可理解性**：存储概念仍 8，但枚举面持续膨胀（8 触发、5 形态、13 卸载策略、9 退役区、30+ 槽、60+ RX 函数、附录 A 已超 4.5 万字）；可理解性靠判别表与附录 A 收口，但本轮发现判别表对"身份/化名""历法""牲畜血统""土地价""征服后的治理"仍无行；03 §3.3 示例与 12 章布局不符会误导第一个第三方作者；09 章历史叙述未拆分（修订记录自知）。建议：新派生先进判别表与 §A.13 再进正文（本轮 X4、X8 都是正文先于附表）。

**⑤ 章节间一致性**：X1–X15 共 15 处，其中结果相反型 1 处（X2 生灵死亡建遗产还是残骸）；附录 A 作为唯一定义处总体有效（枚举未见二次定义），失效集中在：旧章节措辞未随附表更新（05 §5.1、03 §3.3、09 E01）、附表滞后于正文新增函数（month、路线风险）、引用了不存在的条款（`conquest`）。

**⑥ "只加数据"是否成立**：成立——N4、N6（除地价）、N3（除风险读取）、N8 的规则部分、N2 的显示换算；不成立——N1（历法是内核语义，无数据位置）、N7（core 动作前置不可扩展）、N8 普通物种无扩展点、N2 非铸币计价单位、N5 若复用 kin。根因三类：(a) 时间/历法未数据化；(b) 扩展点清单在"动作前置"与"普通物种/相互作用表"两处封闭；(c) 估值派生覆盖面不全（物品个体有，土地、生灵个体无）。契约附表 B/C 对本轮 N 题够用的只有 N4、N6、N8。

**⑦ 对照标杆仍平庸或缺位的维度**：(1) 身份、化名、伪装、认人——B06 社会维度无此项，而 CK3 的秘密/把柄、Shadows of Doubt 的证据链都以身份为前提；(2) 历法与年号——仙武世界的时间质感，B17 无指标，设计里时间只有分钟；(3) 主权变更后的治理连续性——B18.1 军事只到战役结算，征服后的郡府、职位、公库无形状；(4) 不动产与生灵个体估值——B18.2 商号有、地产与牲畜无；(5) 官员考评/政绩——治理维度只有立场与解任触发；(6) 民事时效与遗产重开——B18.4 只有程序成本；(7) 保险与代位——金融维度缺位。
