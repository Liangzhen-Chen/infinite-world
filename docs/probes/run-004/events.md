# run-004 事件清单（2026-10-15 盲出题第三稿，同一出题者；留作后续验收题，未参与设计）

注：出题者自评覆盖不足——盗采、借贷分期、当铺、入股与出租、在途滞留、建筑、驿传送信、远方仅被 1 题涉及，使用前需补题。

## 一、20 个随机事件

**E1 债主死在途中，汇票该谁兑**：深秋，青石村商人周掌柜带汇票搭货船去邻郡收账，风暴溺亡；货物滞留下游码头；独子 12 岁由舅舅监护。涉及灾害、运输滞留、汇票、钱庄、继承、监护、传闻。预期：①汇票归入遗产，监护人代持，钱庄只对合法继承人兑付；②滞留货物按日计仓储费，算进遗产债务；③船主赔偿按契约，天灾可免责；④死讯沿驿路延迟传播，家乡比码头晚几天知道；⑤舅舅不能把遗产过户到自己名下。易错：监护人被当成继承人。

**E2 欠薪罢工撞上秋收**：秋收季，玩家在白水镇开酒坊雇 6 人，钱存定期未到期，欠两个月工资，工人停工、粮食没人收。涉及雇工、欠薪停工、钱庄定期利息、农业、物价、关系。预期：①停工当天产出归零；②提前取定期损失利息，数目一致；③没人收的庄稼按天受损，雨天更大；④工人好感下降并沿亲属传播；⑤补发后隔一段时间才复工，好感不立刻回满。易错：欠薪只挂玩家账上，工人照常产出。

**E3 当铺里的祖传剑**：冬季，武者李三押祖传剑给母亲买药，到期未赎，当铺卖给玩家；族兄称剑属族产不能抵押。涉及当铺、分产争议、法院讼师、药材价格、物品个体。预期：①按族谱和登记确定族产还是个人财产；②判为族产则当铺担责，玩家作为善意买家按法典处理；③药价上涨与冬季药材短缺对得上；④剑的持有历史完整可查。易错：转手后过去权属记录丢失。

**E4 寺观义诊引发挤兑**：春季疫病，玄清观义诊用香火钱买药；病人涌来药材耗尽，药商抬价，观主借分期贷款续买。涉及香火、义诊、药材、物价、借贷、组织公库、传闻。预期：①公库扣款与实际买药量一致；②药价涨幅与周边库存挂钩、有上限；③观主个人借款与观的公库借款分开记账；④义诊使声望上升、下月香火增加；⑤还不上时追索观产而非信众财产。易错：贷款记成观主个人的债。

**E5 学塾先生被任为里正**：夏季，柳溪村先生被选为里正，学塾停课，开始领俸禄。涉及任免、俸禄、公库、教育、日程。预期：①就任当天日程换成公务；②学生识字进度停止不倒退；③俸禄从公库按村级支出；④出现“先生做官”传闻并影响家长好感。易错：同时出现在学塾和公堂。

**E6 候鸟改道带来的连锁**（离屏）：上游湿地被围垦，雁群改落另一湖泊；猎户收入降，新湖区外地猎人多，渔猎冲突。涉及栖地迁徙、狩猎、钓鱼、围垦、NPC 犯罪、离屏。预期：①改道可追溯到围垦；②原猎区猎获减、新湖区增；③湖区鱼获因惊扰略降；④冲突伤人生成 NPC 犯罪记录；⑤玩家回来只能通过传言得知且有误差。易错：离屏期间种群不更新或凭空消失。

**E7 玩家剃度后经营的店铺**：玩家原为商人有两间铺子，出家为僧，戒律不得私蓄财产。涉及身份变化、戒律、店铺、出租、入股、税。预期：①出家时要求处置财产（转寺院、转亲属或出租）；②出租租金去向符合戒律；③商会资格与税务优惠失效；④分红权按处置结果转移。易错：剃度后商人权限仍在。

**E8 驿卒被劫，信件泄密**：冬季山路，县令致郡守密信被山贼劫走卖给对立势力。涉及驿传、知情边界、势力立场、NPC 犯罪、护送。预期：①信件内容只有拿到信的人知道；②郡守收信延误、政务推迟；③对立势力知情后行为改变；④玩家护送下一封信时被劫风险按护卫人数下降。易错：信被劫后内容仍送到郡守手里。

**E9 怪物抢占了矿洞**（离屏）：首领怪物占铜山矿洞为巢；停产铜价涨，矿主欠薪，矿工转去盗伐。涉及首领、开矿、物价、欠薪、林木、盗采。预期：①占据期间矿脉储量不减；②铜价延迟上涨并影响铁匠成本；③欠薪使矿工离开、林木消耗加快；④讨伐后需修缮才恢复产出；⑤首领被杀后不刷新或按规则刷新。易错：被占期间盗采照常产出。

**E10 双胞胎争长子身份**：玩家（商人家族长子）失踪三年归来，已被登记死亡，家产由孪生弟弟继承。涉及族谱、继承、分产、上诉、店铺、钱庄、传闻。预期：①死亡登记经法院与证人撤销；②撤销前弟弟的处置合法有效，玩家只能要求补偿；③钱庄户主变更有记录；④族人好感分化并传播。易错：一回来自动恢复全部财产。

**E11 法师申请登记新法术**：夏季，玩家研究出“驱蝗术”申请登记，审批中蝗灾来临，先用了。涉及登记、法律、灾害、农业、物价、声望。预期：①未登记施法按当地法典定罪，量刑考虑救灾情节；②受保护农田减产明显更小；③粮价涨幅比不施法小；④村民好感升、官府立场降；⑤登记通过后其他法师可学。易错：只记好处不生成违法记录。

**E12 车队超载与关卡税**：玩家车队运丝绸过星湾诸湾会关卡，超载，按货值征税。涉及运输容量、关税、跨政体法律、物价、护送。预期：①超载车速下降或部分货装不下；②按诸湾会税率征收；③汇票能否缴税看诸湾会是否认可该钱庄；④到货后当地丝价小幅回落。易错：跨政体套用本国法典。

**E13 宠物狼伤人**：玩家的狼在集市咬伤孩子。涉及宠物、医疗、饲主责任、关系、传闻。预期：①饲主赔偿覆盖医药费；②伤势发展可能感染；③“狼伤人”传闻使集市戒备玩家；④官府可令拴养或扑杀，玩家可上诉；⑤狼对玩家的忠诚不受官府决定影响。易错：伤害没有归到饲主名下。

**E14 镇级升格后的税改**：石桥村升镇，新设市税，商人联合抵制。涉及升格、议案、公库、税、商会、物价、立场。预期：①市税须先通过议案；②商会可集体决定关店；③关店期间物价涨、公库收入降；④妥协后抵制结束、成员分别复业。易错：升格后自动开征新税不走议案。

**E15 渔村神迹与改宗潮**：春季渔村连月无渔获，海神庙祭仪次日鱼汛回来。涉及祭仪、有限神迹、改宗、钓鱼、天气、传闻、物价。预期：①鱼汛回来有自然原因（如水温），神迹受次数限制；②一批人改信海神，原寺观香火减少；③鱼价回落；④消息传到别郡时更夸张。易错：神迹无限触发，或传闻与真相完全一样。

**E16 书本传出的禁术**：玩家抄医书 20 份售出，夹带未登记的精神类法术。涉及书本传播、登记、同意、法律、医疗、商人。预期：①识字的买书人才能学会；②NPC 对不同意者施展时生成违法记录；③追查源头能查到玩家并核对抄书数量；④医疗技艺正常传播。易错：施法时没有检查同意。

**E17 决斗致死后的官职空缺**：郡里捕头与武者决斗战死。涉及决斗、官职、决斗合法性、遗孀抚恤、组织。预期：①按当地法典判合法性；②官职空缺由有任免权者补任，空缺期治安下降；③俸禄停发、抚恤按规定发放；④捕头同门好感下降并可能报复。易错：死者仍占官职。

**E18 远方郡的首次商路**：玩家首次到达草原诸帐领地“赤沙郡”。涉及远方生成、经济、法典、宗教、知情边界、运输。预期：①生成后物价与当地物产一致（马便宜茶贵）；②法典按诸帐规则；③当地人对玩家家乡之事一无所知；④再次到访面貌一致不重随机。易错：重复到访时又生成一遍。

**E19 公库亏空与里正连任**：玩家任里正期间修堤超支致公库亏空，账目有记。涉及公库、选举、修缮、涝灾防护、立场、传闻。预期：①连任表决态度受堤坝实际防灾效果影响；②账目透明度决定传闻是“贪污”还是“修坝”；③未连任当天收回权限；④堤坝耐久按季度下降。易错：卸任后权限还在。

**E20 精怪聚落的雇工**：玩家雇狐精当账房，其聚落认为是“出卖族人”。涉及雇工、非人政体关系、精怪个体、店铺、跨族契约。预期：①契约效力按双方政体规定判断；②聚落对玩家立场下降；③工作效率受狐精性格影响；④辞职时工资按实际天数结算。易错：精怪被当成普通人类，政体关系不起作用。

## 二、新增内容题

**N1 新契约：佃租分成**：地主出地佃户出力按比例分收成。应作用：农业、天气、法律、税、继承。预期：①按比例分配，歉收共担；②佃契随土地继承；③违约按法典裁决；④地主的税以实际分得部分计。

**N2 新灾害：蝗灾**：应作用：农业、物价、魔法、宗教、迁徙。预期：①粮价上涨；②部分农民逃荒；③祭仪需求增加；④鸟类捕食减轻损失。

**N3 新职业：镖师**：应作用：护送、战斗、商会、职业认证。预期：①镖局可接托运委托；②被劫后镖局负赔偿；③声誉影响接单；④镖师可考认证。

**N4 新组织类型：漕帮**：应作用：运输、水源、工资、法律。预期：①垄断水运运费上涨；②罢运时沿岸物价波动；③首领更替遵循组织规则。

**N5 新物种：灵蚕**：应作用：农业、物价、栖地、魔法。预期：①丝价下降；②需要桑林，林木消耗增加；③法师可研究相关法术。

## 三、第三方作者内容包题

**N6 新门派：青崖剑派**（功法、门规、山门）。应作用：组织、职业认证、战斗、教育、宗教立场、法律。装上：①有固定驻地可招弟子；②功法按已有技能规则计进度；③门派公库按收支变化；④与其他门派关系由引擎按立场生成，作者不手写；⑤门派名人出现在传闻里。卸载：成员恢复散修，已学功法保留；存档引用不崩溃。同装：同名门派按命名空间区分；势力范围重叠时自动生成竞争关系。

**N7 新法典：南海郡法**（罪名、刑罚、审判程序）。应作用：法律、法院、讼师、税、治理。装上：①该郡案件按新法典审理；②讼师需另学该法典才能在当地辩护；③与其他政体引渡规则一致；④税率按新法典。卸载：回到默认法典，已判维持原判，在审改按默认法典。同装：两包覆盖同一郡时按优先级或提示冲突，不能两套同时生效。

**N8 新城镇：盐泉镇**（煮盐经济、盐专卖）。应作用：资源存量、物价、税、运输、雇工。装上：①盐泉有储量上限；②产盐使周边盐价下降；③官府专卖，私贩违法；④雇工数随产量变化。卸载：镇消失或冻结，玩家资产按规则折现不凭空丢失。同装：两包的盐相互竞争，价格按总供给计算。
