# run-002 事件清单（2026-10-15，盲出题：Claude 子代理，提示词 docs/probes/run-002/proposer.prompt.md；均未参与架构设计）

用途：①对目标架构做纸上走查（设计是否泛化到没见过的题）；②迁移后作为真实推演题。N6–N8（第三方内容包题）另附于文末。

## 一、20 个随机事件

**E1 死当的祖传剑**（玩家行为 + 离屏）
- 情境：深秋，玩家（武者，黑石村人）把亡父的长剑当在青柳镇当铺，当期三个月，随后首次前往远方的赤崖郡。
- 经过：冬季大雪封路，玩家被困在途中。当期过了半个月，剑成了死当，当铺按市价卖给猎户赵三。开春后当铺掌柜病故，侄子接手铺子。
- 系统：当铺、季节天气、在途滞留、远方生成、离屏推进、医疗、继承、传闻、法律
- 预期：①死当日期按当票约定计算，与玩家在不在场无关；②有成交记录，剑归赵三所有，原当票失效；③玩家回来后能从新掌柜或邻里那里得知"剑卖给了赵三"；④未到期的其他当票随继承转给侄子，继续有效；⑤找赵三买回属于私下交易，价格受他对玩家的好感影响；⑥如果法典有"天灾滞留宽限"条款就生效，没有就不生效。
- 易错：掌柜死后，旧当票被清空，或者当铺直接消失。

**E2 海难谣言引发挤兑**（世界自发）
- 情境：夏末台风季，星湾商船载着"汇通号"钱庄东家的货出海。镇公库的钱存在这家钱庄。
- 经过：风暴过后船没按期回来，港口传出"东家溺亡"。实际上东家只是被困在一座小岛上。储户挤兑，钱庄暂停兑付汇票。
- 系统：风暴、在途滞留、传闻、钱庄存款与汇票、物价、立场、治理公库
- 预期：①谣言传播有范围也会走样，离港口越远越晚知道；②准备金不够时应停兑，不能凭空付款；③外地商户拒收该庄汇票，相关货款结算延迟；④镇公库可用余额被冻结，俸禄发放受影响；⑤东家回来后谣言被更正，但钱庄信誉不会立刻恢复；⑥东家一直活着，任何继承流程都不应触发。
- 易错：把传闻里的死亡当成真实死亡处理。

**E3 药铺东家病逝，留下幼子**（世界自发 + 边界：人死后的店和债）
- 情境：春季，桃溪村药铺东家（医师）死于时疫。留下 8 岁的儿子、两名学徒，以及钱庄的分期贷款。玩家是药铺的小股东。
- 经过：族老指定死者的妹妹为监护人。学徒已经两个月没领到工钱。
- 系统：疾病、公共卫生、继承、监护、店铺、雇工欠薪、借贷分期、入股、职业认证
- 预期：①店铺所有权归幼子，经营权由监护人代行；②欠薪随遗产成为债务，学徒可以停工；③贷款继续按期还，不因借款人死亡而消失，逾期才动抵押；④玩家股份不变，先还债后分红；⑤药铺停业期间本村药价上涨，看病要去外村；⑥东家的医师认证不会传给儿子。
- 易错：把幼子直接当成能签约、能经营的成年店主。

**E4 猎人剃度**（玩家行为 + 边界：身份变化）
- 情境：秋猎季，玩家（猎人，猎户行会会员，养着一条猎犬）在山寺入教，剃度为和尚。
- 经过：第二天行会照常给玩家派猎鹿配额。玩家仍带着猎犬上山。
- 系统：宗教入教与戒律、职业身份、组织成员资格、狩猎、宠物、隐藏职业、传闻
- 预期：①入教后戒律生效，主动狩猎算破戒，香火和寺内好感下降；②派任务时要识别出身份冲突，行会资格是否保留由行会规则决定；③猎犬自行捕猎是否算玩家杀生，要按明确的规则判定；④猎人技艺数值保留，职业标签改变；⑤满足"放生、护生"条件时，可能出现隐藏职业契机；⑥村里传开"猎户出家"。
- 易错：身份已经变了，任务和权限仍按旧身份发放。

**E5 学堂里的强记术**（NPC 行为）
- 情境：冬闲时节，镇学堂的先生是低阶法师，自创了"强记术"，没去登记。
- 经过：先生对全班童生施法加快背书。部分家长不知情。
- 系统：法术研究与登记、精神类施法须经同意、监护、教育与识字率、法律、传闻
- 预期：①对未成年人施精神类法术需要监护人同意，没有同意就是违法施法；②未登记本身违规，与效果好坏无关；③获得同意的孩子学习进度确实加快；④事情传开后，学堂生源和先生的好感下降；⑤被检举后走法院流程，可以请讼师；⑥孩子已经学会的字不会因为判决被收回。
- 易错：因为效果是正面的，就免除了同意要求。

**E6 角鹿迁徙踩了麦田**（世界自发）
- 情境：初秋，角鹿群照例从林地共同议会的领地南迁，穿过梨花村待收的麦田，撞坏篱笆和打谷场。
- 经过：村民大会表决驱赶，部分村民射杀了几头。林地议会把角鹿视为圣兽。
- 系统：动物迁徙、农业收成、建筑损毁、狩猎、村民大会议案、跨政体法律、外交立场、物价
- 预期：①按踩踏面积减产，粮价小幅上涨；②在王国地界射杀，按王国法典判定，不一定构成犯罪；③林地议会对本村和王国的好感下降，并沿盟友关系传播；④鹿肉和鹿皮进入市场，价格下降；⑤下一季迁徙的数量因猎杀而减少；⑥议会只能走外交交涉，不能跨境直接审判村民。
- 易错：在王国地界直接套用林地议会的法典定罪。

**E7 伪造汇票过关卡**（玩家与 NPC 连锁）
- 情境：仲夏，商人钱四拿着一张伪造的星湾汇票入郡，玩家受雇护送他的车队。
- 经过：在关卡缴税时用这张汇票抵扣。事后钱庄发现汇票是假的。
- 系统：汇票、税与关卡、护送、车船容量、罪名、NPC 犯罪、讼师、关系
- 预期：①税款实际没收到，关卡公库账面要冲回；②钱四是主犯，不知情的护送者不同罪；③如果有证据证明玩家知情，玩家构成共犯；④税吏有过失，但不算伪造；⑤玩家的护送工钱是否结清可查，双方关系下降；⑥传闻在商人圈扩散，钱四信用下降。
- 易错：护送者被自动连带同罪。

**E8 矮人联邑加征铁税**（世界自发 + 玩家经营）
- 情境：春季，矮人联邑对出口铁锭加征三成关税。玩家开着一间铁器铺，雇了两名学徒。
- 经过：边镇铁料涨价，本郡一座停产的小铁矿重新开采。商会出面集体议价。
- 系统：关税、外交、物价供需、矿脉储量、店铺、雇工工资、商会、农业投入
- 预期：①铁锭和铁器涨价，涨幅与当地对进口的依赖程度挂钩；②本地铁矿开采量增加，储量下降加快；③玩家铁铺利润下降，一旦欠薪学徒就停工；④商会议价的结果可以检验；⑤王国与联邑之间的好感发生变化；⑥农具涨价，影响下一季农业投入。
- 易错：关税只改了价格，没有带动开采量和开工情况的变化。

**E9 村正受封男爵**（边界：身份变化后的权限）
- 情境：玩家是石桥村村正，领俸禄。因斩杀首领"铁甲蜈后"立功，被王国封为男爵，封地包括石桥村。
- 经过：玩家想继续兼任村正，村民大会提议另选村正。
- 系统：爵位、首领怪物、任免官职、俸禄、公库、村民大会、立场
- 预期：①爵位收入按男爵级计算；②同一职位的俸禄不重复计算，能否兼领按规则判定；③村正改选后玩家自动失去村公库权限，但封君对封地的权限独立保留；④可调动的人力和任务额度按新身份重算；⑤首领总数减一；⑥村民对"贵族兼村正"的态度按各自性格出现分化。
- 易错：额度和权限写死在旧身份上。

**E10 决斗杀了子爵次子**（玩家行为）
- 情境：在城邦与王国交界处，玩家接受子爵次子的挑战，在城邦境内决斗。
- 经过：子爵次子身亡。城邦法典允许双方同意的决斗，王国法典视之为杀人。
- 系统：决斗、跨政体法律、法院上诉、爵位继承、家族、立场传播、NPC 性格、传闻
- 预期：①按事发地（城邦）的法典判定，原则上不构成犯罪；②王国能否追诉按规则判定，玩家进入王国可能被起诉，并可以上诉；③长子仍在，子爵的继承顺序不变；如果死者是唯一继承人，继承顺序要随之改变；④子爵家族对玩家的好感骤降，并沿亲族传播；⑤见证人知道实情，传闻版本随距离走样。
- 易错：按当事人的国籍而不是事发地选法典。

**E11 台风吹倒寺塔**（世界自发）
- 情境：秋季台风，海边慈航寺的木塔倒塌，压毁了僧舍。
- 经过：住持发起募捐重建，一位名士题写匾额助捐。玩家出木料，并说要"入股"。
- 系统：风暴、建筑损毁与修缮、宗教香火、组织公库、名士作品、林木存量、雇工、入股
- 预期：①只有邻近建筑受损，远处的不受影响；②重建消耗当地木材存量，木价上涨；③名士匾额带动香火和捐款增加；④寺院公库收支可查，捐款不能凭空出现；⑤玩家的"入股"按捐赠或功德处理，不产生分红；⑥施工人数受当地劳力供给限制。
- 易错：把宗教组织当成商号发放分红。

**E12 冰钓时同伴落水**（玩家与同伴）
- 情境：腊月，北湖结冰，玩家带着同伴阿青（武者）和宠物狐去冰钓。
- 经过：冰面破裂，阿青落水。救上来后冻伤高烧，但意识清醒。玩家想给他施治疗术，阿青拒绝。
- 系统：季节天气、钓鱼、同伴、宠物、疾病、施法须经同意、关系
- 预期：①冰面破裂的概率与冰厚、气温相关；②阿青清醒时拒绝，治疗术就不能施加；③强行施法属于违规，关系下降；④可以改为求医用药，冬季药材供应少，药价偏高；⑤病情按天推进，玩家离开后阿青也继续养病；⑥宠物狐可以报警、取暖，但不能"治疗"。
- 易错：默认同伴同意接受一切法术。

**E13 讼师受贿**（NPC 之间犯罪）
- 情境：仲春，郡城法院审理一桩分产引出的田界之争。被告请了讼师孙某，争议田地当时由佃户耕种。
- 经过：原告暗中贿赂孙某，孙某出庭敷衍，被告败诉。玩家是被告的朋友，手里有贿赂收据。
- 系统：法院与上诉、讼师、NPC 犯罪、分产、出租、职业认证、传闻知情边界
- 预期：①被告可以上诉，新证据应影响上诉结果；②孙某受贿单独立案；③改判之前原判继续有效，田租暂归原告；④孙某的讼师认证可以被吊销；⑤收据是实体物品，可能被偷或被毁；⑥知情者只限经手人，不应全村皆知。
- 易错：上诉时忽略新证据，或者一上诉就直接撤销原判。

**E14 草原马瘟**（世界自发）
- 情境：初春，草原诸帐爆发马瘟，商队的马匹大批死亡。
- 经过：汗帐封锁马市。玩家（医师）尝试医治病马。野马群也受到感染。
- 系统：疾病、公共卫生、运输运力、物价、外交、非人政体治理、狩猎
- 预期：①托运价格上涨，在途时间变长；②马价上涨，马皮价格下跌；③封锁令只在汗帐辖区内有效；④医治牲畜的效果有单独的判定，不完全等同于给人看病；⑤野马数量下降，可猎数量随之减少；⑥疫情的传闻比疫情本身先到王国边镇。
- 易错：疫病只影响人，不影响牲畜和运输。

**E15 采药少女失踪**（离屏 + 玩家介入）
- 情境：盛夏，在雾岭（精怪聚居地边缘）采药的少女小芸迟迟未归。
- 经过：她其实被山魈精怪留下做客。父亲出钱悬赏，玩家入夜循迹进山寻找。
- 系统：采集、精怪聚居地、NPC 日程、昼夜、传闻、个人战斗、外交立场
- 预期：①失踪期间村里流传多种说法，比如被拐或被吃；②玩家到之前，小芸按精怪的日程活动，状态合理；③玩家如果攻击精怪，整个聚居地的立场下降，此后采药受阻；④和平交涉成功可以开通采药路线；⑤悬赏以小芸实际回家为准结算；⑥夜里进山遇险的概率更高。
- 易错：失踪者在离屏期间被"冻结"，或者被直接判定死亡。

**E16 弟子用法术行窃**（玩家行为引发的连锁）
- 情境：玩家（法师）在镇上开班，教授已经登记的"开锁小术"。
- 经过：学生王五结业后，用这门法术夜里潜入当铺行窃，当铺门锁和库房被破坏。
- 系统：开班授业、法术登记、罪名与连带责任、当铺、建筑损毁、传闻
- 预期：①王五是主犯，教授合法登记的法术不构成犯罪；②如果玩家明知王五的意图，另行论处；③失窃物品与账目同步减少，当票持有人的权益按法典处理；④玩家的授课声誉和生源下降；⑤可能有人提出"限制教授此术"的议案；⑥王五被捕后仍掌握这门法术。
- 易错：教授者被无条件连坐。

**E17 晚霜与佃租**（世界自发 + 玩家决策）
- 情境：清明后突然降霜，玩家出租给佃户老周的十亩地受灾。
- 经过：秧苗冻死七成，老周交不起秋租，请求减租。村民大会表决"霜灾减租"议案。
- 系统：天气、农业、出租、租约与债务、村民大会议案、立场、物价
- 预期：①减产幅度取决于作物种类和霜冻时间；②租约约定的租额不因灾害自动改变；③议案只在村规管辖范围内有效，对外村地主不一定有效；④玩家减租，老周和邻里的好感上升；坚持收租则好感下降并传开；⑤粮价上涨，玩家自有存粮升值；⑥老周违约时可以走债务流程。
- 易错：遇灾自动免租，或者议案越权约束外村人。

**E18 斩杀首领后的空巢**（玩家行为 + 离屏）
- 情境：玩家击杀首领"赤鬃熊王"，熊王盘踞的黑松坡从此空出来。
- 经过：一个月内，狼群迁入，还有人来盗伐松木、盗采矿点。说书人把这件事编成段子，玩家得了"屠熊"名号。
- 系统：首领怪物、栖地、狩猎、林木存量、盗采、名士作品、隐藏职业、离屏
- 预期：①首领不再刷新，首领总数减一；②空出的栖地被其他物种占据，周边可猎物种发生变化；③松木与矿脉储量下降；④说书段子扩大知情范围，玩家声望上升；⑤可能出现隐藏职业契机；⑥玩家回来时看到的变化与离屏经过的天数相符。
- 易错：首领在离屏期间重生。

**E19 商会会长被流放**（边界：人不死但离位）
- 情境：星湾城邦法院判商会会长金老三流放三年。玩家持有商会两成股份，并有投票权。
- 经过：商会需要改选会长。金老三名下有对外出租的房产和未兑汇票。
- 系统：首领更替、组织公库、入股、出租、汇票、跨政体法律、驿传
- 预期：①流放不等于死亡，财产仍归金老三，租金照收；②按商会章程改选，玩家按股份投票；③新会长接手商会公库的权限；④金老三在流放地仍能通过驿传通信；⑤王国境内是否执行城邦判决，取决于两国外交关系；⑥流放期满后可以回来，但不会自动官复原职。
- 易错：把流放当成死亡，触发了继承。

**E20 无人押送的药材**（离屏 + 远方）
- 情境：仲夏，玩家托运一车药材，送往一个从未去过的远方郡，那里正在闹疫情。
- 经过：途中山洪冲断桥梁，车队滞留十天，部分药材霉变。当地药价暴涨。
- 系统：托运、在途滞留、洪涝、药材、医疗、义诊、物价、远方生成、离屏
- 预期：①玩家没有亲自到场，远方郡至少要生成接收货物所需的骨架，或者规则明确由其他机制处理；②滞留时长与灾情持续时间相关；③霉变按药材保质期计算；④到货后按当地供需定价；⑤承运方的违约责任按契约认定；⑥药材到货后，当地义诊和疫情有所好转。
- 易错：远方郡还没生成，货物"消失"或者无处结算。

## 二、新增内容题

**N1 新契约：青苗预售契**（开春先付钱、秋后交粮）
- 应自动接入：农业、天气灾害、物价、钱庄借贷、法律违约、传闻、村民大会
- 预期：①歉收年农户交不足粮，按契约触发违约或展期；②大量预售会让秋季现货粮价提前反映预期；③商人囤契可能形成垄断，大会可以提议限制；④契约可以继承，签约人死亡后由继承人履约；⑤跨政体签订的契约，按签约地的法典判定；⑥违约纠纷可请讼师，判决会影响双方信用。

**N2 新灾害：蝗灾**
- 应自动接入：农业、野生动物（鸟类捕食）、物价、宗教祭仪、生活魔法、公库赈济、迁徙
- 预期：①旱年之后发生蝗灾的概率更高，蝗群按风向在郡与郡之间迁移；②粮价上涨，与各地储粮量相关；③寺观举行祭仪，香火上升，但神迹有限，不能必然灭蝗；④驱虫类生活魔法能减轻损失，施法需要登记；⑤公库开仓赈济会消耗余额，余额不足时可能引发民变传闻；⑥鸡鸭和鸟类数量的变化会影响灾情。

**N3 新职业：堪舆师**（风水选址）
- 应自动接入：建筑、职业认证、宗教、教育、法律诈骗、名士、店铺
- 预期：①选址建议影响建筑的灾害概率，比如火势和洪水；②没有认证就执业，可能被告诈骗；③可以开班授业，书本能传播这门技艺；④出名的堪舆师成为名士，被人请动的价格上涨；⑤与寺观可能存在竞争或合作，对香火有影响；⑥可能有某种隐藏职业的契机与之关联。

**N4 新组织类型：镖局**
- 应自动接入：护送、运输、个人战斗、组织公库、关卡、立场、首领怪物、法律
- 预期：①托运时可以投镖，镖失时由镖局公库按约赔付；②镖师伤亡涉及抚恤与欠薪；③路线上首领怪物或山贼越多，镖价越高；④镖局与关卡、沿路势力之间的好感影响通关；⑤总镖头更替，沿用组织首领更替的规则；⑥连续失镖导致信誉下降，生意流向竞争对手。

**N5 新资源/物种：灵蚕**（食灵桑、吐灵丝）
- 应自动接入：农业与林木（桑树存量）、采集、店铺手工、物价、税与关卡、疾病、盗窃、精怪
- 预期：①过度采摘灵桑会导致桑树存量下降，蚕群减产；②灵丝价格随供需波动，跨境出口要缴关税；③蚕病会大面积传染，可以求医或用魔法；④成为偷盗目标，盗窃案走正常的法律流程；⑤精怪聚居地可能视灵桑林为领地，引发外交摩擦；⑥会出现"养蚕/织丝"的职业认证或作坊雇工需求。

## 四、第三方内容包题（N6–N8，同一出题者追加）

**N6 第三方包：门派「寒潭剑宗」及其功法**
- 内容：一个新门派，包括驻地、5 门功法、门规、首领和弟子。
- 应自动作用的系统：组织、战斗、教育、好感、门派与门派之间的外交、地图
- 装上以后：①门派驻地出现在指定的郡，弟子 NPC 按日程活动；②玩家可以拜师，学习功法后战斗数值变化；③与已有门派之间的关系有初始值，并能变化；④离屏时门派会自行招收弟子、更换首领。
- 卸掉或与他包同装：①卸载时，已入门的玩家标记为「门派已散」，已学功法保留或失效须有明确规则，存档不能报错；②与另一个包争用同一块驻地时，要有冲突检测，拒绝加载或自动迁移；③两个包里的功法同名时，用命名空间区分。

**N7 第三方包：「南岭郡法典」**
- 内容：一套新的地区法典，例如允许私人决斗、禁止活契、对盐重税。
- 应自动作用的系统：法律、法院、税、决斗、契约、跨政体冲突
- 装上以后：①在南岭郡境内，罪名和刑罚按新法典判定；②盐税提高，盐价上涨，私盐贩子增多；③在该郡发生的决斗，按新法典判定不追究。
- 卸掉或与他包同装：①卸载后，已判的案件不变，未结的案件改按原法典判；②两个法典包同时覆盖同一个郡时，要有明确的优先级或报冲突，不能静默合并。

**N8 第三方包：盐井城镇「卤泉镇」**
- 内容：一个带新经济玩法的城镇，有盐井、盐商行会、盐引制度。
- 应自动作用的系统：开矿（盐井储量）、经济、行会、税、运输、治理
- 装上以后：①周边郡的盐价随卤泉镇的产量变化；②盐商需要持盐引才能运盐，无引运盐违法；③盐井储量随开采减少；④镇上的官员、行会首领能正常任免、更替。
- 卸掉或与他包同装：①卸载时，玩家手里的盐引、股份要有处置办法（折现或作废），存档不能出错；②与 N7 同装时，南岭盐税能作用于卤泉的盐，两个包自动配合而不是互相覆盖。
