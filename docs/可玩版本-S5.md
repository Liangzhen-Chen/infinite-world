# S5 可玩版本：交易、租田与钱庄

本页对应 `tests/s5-playthrough.test.mjs`。脚本从创建零级角色开始，在同一局中通过玩家菜单取得材料和农具、租田种收、出售自产粮、学习识字、存款和签发具名存单，最后核对完整存档重放。不调用模型，不修改开局钱袋、库存或能力。当前脚本尚未通关，实际断点见文末；未跑到的步骤不算通关。

## 怎么启动

在工作树的 PowerShell 中运行：

```powershell
$env:TEMP='F:/dnd-tmp'; $env:TMP='F:/dnd-tmp'
node --test --test-isolation=none tests/s5-playthrough.test.mjs 2>&1 |
  Select-String -Pattern '^ℹ (pass|fail)|^✖|^not ok' |
  Select-Object -First 40
```

这是无 AI 试玩，会启动本地临时服务并清理测试存档，无需 API Key，不连接已有酒馆或原存档。需要允许本地端口；浏览器和酒馆部署不在这条脚本的验证范围。

## 玩家操作

1. **集日交易。** 雨月初五十一时找严辙，买四份净麦粒再卖回：本脚本买入花 12 铜、卖回得 6 铜，实际损失 6 铜。议价成交只覆盖现有报价区间；NPC 主动还价对话仍是 A2 todo。
2. **取得农具和种子。** 河湾铁匠铺按同店普通铁器的节奏，七天进一把铁镰、最多两把；铁镰已在审批目录，此次补齐常备农具的进货缺口。向段岩直接购买铁镰和可用于翻土的矿镐，价格照常由市场派生；无需先转行学习锻工。到公共粮仓买八份带壳燕麦作种粮。若需筹钱，可采集北林现有无主药草向实际在场商人出售，须遵守单笔份额及每日深度，不会重访刷新库存。
3. **租入南田。** 南田登记在河湾聚落名下，不属于陈柏个人。在议事处选择“租入资产”，填写 `location=loc_hw_fields`、`quantity=1`（租一亩）、租期 `days` 和可选月租 `coins`；`item` 可指定已有种粮。省略亩数表示整块登记面积：南田14公顷为210亩，不应以一亩收成支付整片田租。依 05:129、§5.7.3，公产使用与出租是聚落首领职位的职权；随席位保留的职权由 `seatPowers` 数据决定。读取现任者的主观视图决定是否同意，无人在任或本人缺席均拒绝，并提示合法任职、当面办理。租金进入聚落公库。可用 `deadline` 指定租期内约定交租日的绝对分钟；若回执提出 `conditions.prepay`，可用菜单已有的 `deposit` 填当场先付租金再谈（`coins` 仍为月租）。条件金额是当前提案还须追加的差额：脚本先提先付1铜，收到再付9铜的条件后，以合计10铜重谈。先付真实入公库，首期余款及后续月租形成应付。NPC 按先付、关系、信用风险和已知偿付记录重新决定，仍可能提出条件或拒绝；不能由玩家代填同意或窥见玩家钱袋。约定日后未交按既有宽限和违约规则处理。
4. **春播前学习，再种到成熟。** 趁学堂仍能进入，先付每课2铜学习识字、按市场价购买羊皮纸，并实际练到熟练度100；这些步骤发生在播种前。 田租月锚点为 `ceil(预期年产量×签约时当地作物报价×3/10÷12)`，沿用0.8–1.5倍议价区间；建筑仍按原房租。产量复用实际私田收成函数；面积、作物决定每季数量，180日作物在每年5..25日的单个播种窗只能种一季。惯例租率按现金篮子反推：三口之家两名劳力，春播容量84亩，正常质量1、当地粮价5.069784173铜计年市场估值48264.345铜；沿现有收购价差0.6，售粮实收28958.607铜。全部售出再购回口粮、种粮，并计住房、布衣、燃料，必要支出10664.262铜；0.6/1.15−10664.262/48264.345=0.30078，取3/10后收支比约1.15173。这是明确假设的现金标定篮子，不是长期浸泡结论。 当前新租率脚本手算一亩月租16铜，先付10后首期余6铜；亩数、作物和租价固定，超约播种拒绝。面积沿整亩口径：一亩为 `1/15` 公顷，种粮 `ceil(120/15)=8` 份。等到实际播种窗口再下种。有效承租和本人持有均可操作，其他人不能占用。作物累计180个温度合格日才成熟；燕麦基准产量为 `1700/15` 份，再乘实际天气、水分及有效产量修正并取整。租期须覆盖实际生长期和搬运时间。
5. **分批收割并出售。** 默认力量十，安全负重 `10+2×10=30` 公斤。每份燕麦重 0.5 公斤，每趟可收量为 `min(田间余量,floor((30−当前负重)/0.5))`。余粮仍在田间，不会被抹掉；先卖掉一趟再返回收下一趟。雨雪不宜下田时须实际等候再操作，等待期间时钟和租金照常推进。收割工时按实际取得份额分摊。售价读取当时真实市场报价，整笔只取整一次，不预填粮价或收益。租期内作物归承租人，须在到期前收走；到期未收留田随田主。
6. **找买家、交租与存钱。** 公共粮仓的现有规则只出售余粮、接受捐粮和交割已登记村际粮约，没有向农户现购散粮的渠道。脚本先真实背粮走到白石镇，按严辙的实际营业窗售粮；他的资金不足时，再真实步行回河湾，依次找渡口郑水生、果园梅绫、北林吴朔等现有交易者。白石市场、烘坊、仓行的旧路线实测仍剩17份未交割，因此不把“找到一个买家”当成全部售出。每笔最多五份，遇每日深度耗尽实际等到次日，不刷新钱袋或库存。报价按当时输入计算，例如白石普通报价 `3×3×0.6×1.00105×5=27.02835`，整笔取整为27铜；后续深度变化须重新报价。若获准秋后交，卖粮后先到公库办理点，用“清偿义务”交清各笔租金，再安排余款存款；到期身在公库时，原租赁规则可先收当期租金，累计应计减实际已付才是剩余欠租，不能重复计算或把欠租当利润。识字、纸张和练习已在春播前办妥。清租后先尝试小驿站汇兑柜；建筑若确已停用，则真实步行到白石镇，在严辙实际在场的营业窗使用既有镇级派生钱庄，原柜员不会被移到田边。存款：手续费一铜，其余形成真实存款债权。脚本保留原先六铜存入、五铜本金的具名存单和隔三日（必要时等实际营业窗）支取两铜检查，再把支付教学等实际支出后仍可存下的自产粮销售款存入另一笔债权。每步检查钱物守恒、账本、负重和事件来源。

## 工坊库存与已知限制

本人持有或有效承租的工坊使用“工坊存取”：`mode=inspect` 查库存、`deposit` 从行囊存入、`withdraw` 取回行囊。雇工从工坊库存领料，产出留库；取回超过负重会拒绝，应分批搬运。库存有独立 stock 账户，物品仍归存放者，单件品质、制造者和物理位置保留。店铺库存分离属于 S7，本版本不扩展店铺。

田租按签约亩数和作物产值派生，后续月份仍须支付；不在收款处时形成待交付租金债务。同一登记地点仍沿用一份有效资产租约的限制，本卡没有扩展多人分畦出租。卖粮后有钱入账不等于经营盈利，存款也不代表租债已清偿。租约结束会失去操作权，应事先收走作物和工坊物品。
