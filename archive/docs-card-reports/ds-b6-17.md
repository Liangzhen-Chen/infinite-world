## 自定裁定（书里推得出的纯技术选择）

- **Text、Screened 的运行期载体**：模块私有 WeakMap（textcore/text-types.mjs），只有该文件的构造函数造得出；Screened 只经 `makeScreened`（groupApi callerFiles gate/screen.mjs）。卷二只写了编译期品牌，运行期载体卷文没写，这是我选的做法。
- **显示名键写法**：照卷二十九 :250 原句"封闭枚举值的键写成枚举名、一个点、值"，存档不可用状态的显示名键是 `reply_result.save_unavailable`。只核第 6 条说该前缀是自补；我对照原句认为前缀正是卷文格式，保留并改成常量带出处。若李白另有裁定，只改 reply-composer.mjs 一处常量。
- **轮换序号**：R29-2.3 原句"输入里的序号（事件的 id 序号，没有事件的取本次响应的行序号）"；回执形状（卷九 :294）无事件序号字段，内核也无从 EventId 取序号的出口，故只用行序号（R29-2.6 条件只读槽位值，与序号无关）。事件 id 序号的出口主会话记问题.md。
- **卷二勘误 1119k7**（复核第 2 轮定）：§2.7 JSON 补四行——kernelApi `markers.mjs#T`，groupApi `labels.mjs#codeText`、`text-types.mjs#textValue`、`#makeScreened`，各写来源卷:行；勘误前快照 卷二-v17补26-勘误前-1119k7.md，现行快照已覆盖（cmp 一致），不升版本。
- 显示档 RX 建好后 select.mjs、templates.mjs 不用改（已按槽位值交绑定）；display-load.mjs 的 when 现在加载即失败，建好后改一处 compileRX 调用的档位实参即可。
