## 〇、一页摘要

- **六处位面各一句**：
  1. **冥土**（格空间 1，300×200 千米）：五个冥区（冥府、长眠原、风原、记名林、边境渡口）加冥河、黑湖与荒原；居民就是去向记录——死者从开局起按文化累积到各冥区，玩家来时从记录物化，"见过的死者真的能再遇见"；活人只能出神或借开门术进去，阳间身体照常挨饿。
  2. **天庭**（格空间 2，100×100 千米）：天门区居中，十二神国环列，外圈云海；经飞升台单向门进来，众神使者组织与飞升者住在这里；第一版 NPC 飞升已能进来（折叠在统计层），玩家飞升即结局。
  3. **神国**（天庭内 12 块区域，A4②）：每位有神迹资格的原创神一块，神迹在本国更便宜；12 位现实古神不设神国；神陨时本国随之荒废。
  4. **秘境**（每处一个格空间，1–20 千米）：首批四处（北岭雪窟、雾岭崖中天、盐风潮下宫、苔院根下林），门在隐蔽处、按阈限与引路物开，出门时按数据一次性改年岁与知情。
  5. **梦境**（格空间 3，200×200 千米，待 A6）：出神者的魂经"入梦"术式临时开门进来；肉身与物品进不来，知情可带回；两个出神者可在梦里会面。

## 一、共用于全部位面的做法

### 1.1 位面怎样表示

- **一个位面 = 格空间表一行 + 一个层根地点行 + 它下面的普通地点行**。格空间表每行三项：格空间号 `w`、外包框（以区格计）、根地点（卷五:423）；根地点挂 `comp_layer_root`（卷五:429、:475；卷十五:1064）。位面里的地点是普通地点行，有地形、群落、存量、设施，全部按卷五（卷十五:1064）；同一套位置、足迹、感知、行走、物品规则，只换生成数据（卷五:475）。
- **格空间号建议**：0 主世界；1 冥土；2 天庭；3 梦境；101 起为秘境（每处一个）。号是数据，规则不读号的值（卷十五:1086 A15-15.1 已禁层根 id 字面量，第十节 N11 把格空间号一并入禁）。
- **坐标**：本稿位面内坐标一律千米，原点在该格空间外包框中心，x 向东、y 向北；落格时区格坐标 = 千米 × 10（同附表卷首）。
- **位面与主世界只经门相连**：门是 `edges` 里 `portal` 非空的边，`a`、`b` 两格各在一端的足迹里，通行条件写在需求块 `requirement` 上；穿门一步，路程 0（卷五:209–211、:475；卷十七:350）。直线距离、视线、光声气味不跨格空间，所以往下挖挖不到冥土，往上飞飞不到天庭（卷五:475）。选路可连过多道门（卷十七:375）。
- **门分方向**（第十节 N3，推荐做法）：过门是"`a` 格到 `b` 格或反过来"（卷十七:350），边只存一次（卷十:426），现有一块需求块两个方向通用，表达不了"进冥土容易、回阳间难""飞升只上不下"。推荐把需求块挂到门的两个方向上：`portal` 改为 `{a, b, reqAB, reqBA}`，`reqAB` 管从 `a` 到 `b`、`reqBA` 管反向，取值为需求块或空，**空表示该方向不可过**（不设"不限"值；无条件的方向写一个空组需求块）。门边的边级 `requirement` 须为空（加载校验）。另一做法"需求块可读过边方向"要给需求块加一个只对门有意义的读法，牵涉面更大，不取。本稿各门表都按"进 / 出"两栏写，主世界一端恒取 `a`。
- **临时门**：开门类效果族可建一条带时限的连接边，作术式实例的 `link` 产物，期满撤去（卷十五:1066）。入梦、借术入冥、借术上天都走这一条，不另立机制。**临时门两个方向的需求块不由施术者定，而取目的地格空间层根行上的两个字段** `linkIn`（主世界→该格空间）、`linkOut`（该格空间→主世界），取值同上，空即该方向开不出。第一版天庭层根 `linkIn` 为〔开门术施为成功〕、`linkOut` 为空——借术上得去、回不来，守"天庭第一版只做出口、不造回来的门"；第一版冥土层根两项都为空——开门术开不进内部还没有内容的冥土，不做假入口；块 8 建好冥土内部时只改这两项数据。规则只有"临时门照目的地层根的两项取需求块"一条，不读格空间号，也不设"块 8 前禁止""未解锁"一类状态（卷十五:1065）。由一条测试守住：层根 `linkIn` 为空时开门族对该格空间的目的地候选为空；`linkOut` 为空时所建临时门反向不可过（列入 N3）。

### 1.2 "能真切感受到不同"：位面特征代号

照拍板清单 §3.2：每个位面的层根（以及其下需要不同的区域行）挂一组**位面特征**代号（新开放词表，建议族名 `pfeat`、前缀 `pf_`）；各卷的修正项以"所在处沿包含树向上各行特征之并含某代号"为条件。条件读代号，不读层的 id 或名字（北极星二.1）。首批：

| 代号 | 含义 | 由哪卷的哪一项读 | 用在 |
|---|---|---|---|
| `pf_sunless` | 无日月，恒昏 | 卷二十光照读数上的修正项（光照可修正键待登记，拍板清单 :144） | 冥土、深渊不用（深渊本来 `skyExposure` 为 0，光由卷二十派生） |
| `pf_everday` | 恒昼，无夜 | 同上 | 天庭 |
| `pf_dimlight` | 昏光，可视而无日影 | 同上 | 梦境 |
| `pf_aether_rich` / `pf_aether_thin` | 灵气浓 / 稀 | 卷十五 `field.capRows` 的 `whenRX`（拍板清单 :148） | 天庭、秘境 / 冥土 |
| `pf_divine_near` | 神近 | 卷七神迹 `costPerMagnitude` 上的修正项（拍板清单 :148） | 神国区域 |
| `pf_dead_seen` | 无实体者可见 | 卷十五形态轴 `senseMult` 的修正项（卷十五:159、:736） | 冥土 |
| `pf_no_hunger` | 不饥不渴 | 卷二十六饥渴速率修正（拍板清单 :151） | 天庭（设定，标"设定数待调"） |

新加一个位面只写数据行；要新的差异，加一个特征代号与一条修正项行。时间流速**不**做特征：只有一个时钟（卷十五:1069 R15-15.6，李白 11-13 裁定 Q15-5，卷十五:1318），"仙境一日、人间百年"只用离开时的一次性效果近似（见各节）。

### 1.3 共用的生、死、魔法、神性、因果

- **死**：任何格空间里死去的有心智者都照卷十五 R15-10.1–10.3（卷十五:855–857）建去向记录；载体地点按卷十五:407 的整类规则取死处；"死在位面里去哪"由去向行 `when` 读出（拍板清单 :150 建议 `when` 可读"死亡所在处的特征"）。没有"死在天庭的特殊结算"。
- **出神**：出神类效果族留一条术式实例，产物是本体身上一行失能族状态与一个 `soulOf` 指向本体、无实体物种的魂个体；魂可走出神者之路；本体照常挨饿、受伤；魂在外所受状态带不带回本体由结束输出的效果调用决定（卷十五:1068 R15-15.5）。所以"在阴间逗留太久，阳间身体饿死"是推出来的。**待核**：本体终止时出神实例是否随之结束、魂个体是否同一事务终止（卷二终止协议对术式实例的处置）；若未覆盖，列卷十五勘误。
- **魔法**：施为上限读所在地 `aetherDensity`（卷十五:1102 R15-16.1）；位面浓淡只经 `pf_aether_*` 改容量。传送跨格空间必须经此刻需求块成立的门，或先由开门术建临时门（卷十五:1066）。
- **神性**：神是一行数据加一个账户，行为只有神迹（卷七:906 R7-11.1）；神迹资格读有效档 `miracleSource`（卷七:1027 R7-14.2）。神本体不是个体（A5 未裁，见第三节）。
- **因果**：世俗报应已有卷十五恩债冤债（卷十五:819 R15-9.6）；天劫幅度读事迹计数（卷十五:1106 R15-16.5）；"业"是否为真实计数待 B4。本稿凡读因果处都只读已有的冤债、恩债与事迹计数，B4 若取③，再加一组读业计数的行，不改结构。

### 1.4 共用的往来与离屏

- **物品**：只随携带者经门移动；无实体物种体重为 0（卷十五:736 R15-8.4）。**待核**：卷四携带上限是否读形态轴 `corporeal`；若不读，魂个体能否拿东西须在卷四补一句读法（不写"魂不能带物"的特例）。
- **信息**：托梦、神谕、预兆、占卜只是知情通道（卷七:1064 R7-15.1；托梦通道 `kchan_dream`，卷七:270）；亡魂带着死者截至死亡时刻的知情（卷十五:857；卷二十二:186、:369 `carryKnowing`）；魂回到本体时带回的知情走结束输出（第九节卷二十二条）。
- **离屏**：与凡间无边相连、不属于任何该级政区的地点自成一个模拟单元，无观察锚时在统计层，锚进入即先追赶再转个体层（卷二十七:280、:350）；玩家经门进入另一格空间，在那里以所在区格为中心另成一泡，原处的泡同一事务收起（卷二十七:310、:354）；差分按（格空间, 里块）分片（卷二十七:591）；新增一个格空间不改 `sim-tiers.mjs`、`sim-advance.mjs`（卷二十七:373 A27-1.15）。别的层平时只按统计层存在，触及时按卷二十七与卷十物化（卷十五:1071 R15-15.8）。

  - **安息者**：去向为 `rest`、去处为某冥区的去向记录就是该冥区的人口（拍板清单 :96）。人口数 = 去处为该冥区的记录数，由账本派生，不另存。玩家或被钉住者触及时，照卷十五 R15-10.4（卷十五:858）"无名者的物化"同一办法从记录抽人物化成亡魂个体（`soulOf` 指向死者、带死者截至死亡的知情与立场副本，卷十五:857）；离开现场泡后按卷二十七折叠。这是本方案对卷十五的勘误（`rest` 现在"只留记录，没有实体"，卷十五:857），列第十节 L2。
  - **冥府吏**：殿主、判官、鬼差、渡口神职等是卷八职位行，持有人是亡者或精灵（04 §2.2、§7）；主判职位名原创"殿主"，不用佛典十王之名（04 §7）。显示名随 G1、B5。
  - **非亡者**：守冥兽一类物种行，`habitats` 指向冥土群落（卷十六:775 R16-10.3 允许物种栖在别的格空间的群落）。
- **资源**：灵气稀（`pf_aether_thin`）；冥土材料（如冥石、阴木）作卷三甲材料行，经卷五赋存行落在冥土；冥府账户是普通账户（卷十五:862）。
- **危险**：①对出神者：鬼差按阴律拘押越界生魂（卷八b 的罪名与拘押），被拘期间阳间本体继续挨饿；②迷途：冥土地点要在知情里才能作传送目的地（卷十五:1066），走路靠卷十七选路；③亡魂附身、缠人（卷十五 §4.9）；④魂个体被击散时，出神实例结束，结束输出给本体挂失魂一类状态（卷二十一状态行，轻重是数据）。

### 2.3 规则

- **时间**：同一个时钟（卷十五:1069）。冥土的"一日"与阳间一样长；不做"阴间三日、阳间三年"一类流速；需要这类母题时同秘境，离开时一次性效果近似（数据，非首批）。
- **生死——死者怎样到冥区**：
  1. 有心智者终止 → 卷十五建去向记录、等安葬期限（卷十五:855 R15-10.1）；
  2. 去向行求值（卷十五:856 R15-10.2）：按文化得到葬仪的命中 `rest`，未得的命中 `pool`（并入载体地点的无名亡者）或 `manifest`（显形为亡魂），这些都照旧；
  3. **新增**：去向行加一栏"去处"（`realm: ref place nullable`），`rest` 行的去处取死者文化行的冥途代号所指冥区（总案第六节、卷十五 R15-10.2、R15-10.3 勘误）；`pool`、`manifest` 的去处为空——孤魂野鬼留在阳间，正是"按文化好好下葬才能去该去的地方"由规则推出（卷十五:856）。
  4. **冥途词表**（开放，前缀建议 `mt_`，卷十五登记），条目字段：`realm: ref place nullable`（所指冥区行）、`rebirth: boolean`（此冥途的记录进不进轮回台）、`onward`（可空分流表，见第 6 点）。首批：`mt_judged`（冥府审判→轮回：civic、reed、salt、mist）、`mt_ferry`（边境渡口：river、六个怪物社会中按散文转写者）、`mt_longsleep`（长眠：forge、north、coast、far_orc）、`mt_wind`（化风：steppe）、`mt_named`（记名：canopy、beast）、`mt_root`（归根：far_lignum，`realm` 为空，不入冥土）。对应表见总案第六节。
  5. **改宗者（A2 待亮圳）**：两边的接口都留——默认读死者**出生文化**行的冥途（A2①，照亮圳"按文化"原话）；若 A2 取②，信仰行也加一个可空的冥途字段，去向行先读现奉信仰、为空再读文化。只差数据行与一条 `when`，结构不变。
  6. **渡口分流**：边境渡口是中转区。分流读的不是信仰行上的冥途字段（那一项只在 A2 取②时才有），而是**冥途条目自带的分流表**：冥途词表条目加可空字段 `onward: list<struct{faith: ref faith, realm: ref place}>`（按表序取第一条 `faith` 与死者终止时所奉信仰——卷七信奉边在终止时的事实——相同的行，去处改为该行 `realm`；没有命中则留在渡口）。首批只有 `mt_ferry` 填表（止波寺所奉信仰→冥府轮回台一侧、芦衡观所奉信仰→冥府，总案第六节 river 行），其余冥途为空。字段在卷十五冥途词表（与 `realm`、`rebirth` 同处），读所奉信仰经卷七只读入口；A2 取①或②都成立，与 A2（出生文化与现奉信仰不一致者）无关。分流求值放块 8（随 L2），第一版记录停在渡口。
- **生死——冥土里的个体终止**：已物化的安息者被击散（非安息原因的终止）时，记录去处改为荒原、去向改为 `pool`，计数照卷十五:858 入账，成为冥土里的无名游魂；超度、迁葬等仍按卷十五:859 使其回到 `rest`。**本方案新定**，卷十五勘误（L2）。
- **轮回**（A3②已裁）：第一版去处为冥府、冥途 `rebirth` 为真的记录在轮回台累积（只是记录状态，不建个体）；转生结算——新生个体与死者的关系、知情与身份承继——放块 8（卷十五:1325 Q15-12），见 L7。
- **魔法**：灵气稀，施为上限低；死灵、超度、驱离照卷十五 §4.9、§4.11，在冥土没有另一套。
- **神性**：冥府是组织不是神；城隍类神职由冥府与当地衙署共管（04 §15 ②，`coOwned`）；神迹在冥土照常可发生（卷七 R7-14.x 不读地点名）。
- **因果**：冥府审判是阴律下的案件（卷八b 程序），首批只读已有的冤债、恩债与事迹计数（卷十五:819）；B4 若取③，加读业计数的行。审判结果是冥府内的去处（受罚、轮回台、候补神职"考城隍"，04 §2.2）。审判放块 8（L6）。

### 2.4 和主世界怎样连

- **门**：2.1 表。冥土一侧五门的冥区落点即附表第八节。
- **回程**：
  - 活人出神者：同门反向，出方向 `reqBA` 的出神组成立即可回；或术式实例结束，魂个体终止、本体失能解除（卷十五:1068），不必走门。
  - 死者：一般不回。两种例外都按已有规则：①复生窗口内被复生，亡魂经 `die` 终止、记录删去（卷十五:863 R15-10.9），人在阳间醒来；②西境"亡者夜可返一夜"（04 §2.3 死者归来窗）：坟冢门出方向 `reqBA` 另有一组〔`fromDead` 且此刻在亡者夜阈限内〕（2.1 表）；窗末由一条事件类型行（卷二十四表 C，阶段挂 `move` 效果调用）把未归者经进方向移回（进方向本来读 `fromDead`），详见第九节卷二十四条。门分方向见 1.1 与第十节 N3。
- **信息往来**：亡魂托梦（卷十五:864 R15-10.10；通道 `kchan_dream`）；冥府的事阳间只能经占卜、通灵类知情通道得知（卷二十二）；出神者回来带回见闻（卷二十二条）。
- **物品往来**：纸钱、供品是成对转移——供奉者到供品去处、阴间来源 `roles.srcsinks.offeringRealm` 到载体地点账户，等量同一事务（卷十五:860 R15-10.6）。块 8 起建议加"去处账户"：去处不空的记录，供品入冥区地点名下、以记录 id 为子键的账户，物化的安息者读它作为自己的钱（卷六账户、卷十五 R15-10.6 勘误，L5）。肉身物品只随肉身过门（开门术）。
- **离屏推进**：冥土不属于任何政区，自成单元（卷二十七:280、:350）；冥区若作卷八政区行（冥府治下）并取 `unitAdminLevel` 那一级，则每个冥区各成一单元。冥土平时不推进个体：人口只随阳间的死亡、安葬、断祀、复生事件改记录（卷十五:855–863），这些事件在阳间发生，所以冥土无人时没有自己的统计层生产；冥府组织照卷八、卷二十七矩阵在统计层运行。

## 七、深渊（主世界深层，本方案新定）

### 7.1 怎样进

- 不是位面，没有门。北岭（无主荒山，世界根子行，附表 3.2）之下手写一片体积足迹"深渊"：平面 [300,460)×[150,230) 千米，深度地表下 1,500–4,500 米（北岭地表约 3,000–4,500 米，附表 4.3，即海拔约 −1,500…3,000 米）。附表第一节、第七节已列"北岭之下手写体积足迹种子"。
- 两条手写入口（体积足迹种子，洞系形状交卷十洞穴生成器 `caveCellsOf`，卷十:447）：①北岭裂谷 (330,170)，地表洞口经中层洞窟下行；②黑炉谷旧矿深凿 (175,125)，自寒炉东缘向东穿入北岭之下。
- **与冥土不通**：深渊没有任何门边通冥土；往下挖挖不到冥土是卷五:475 本来的结果。

### 7.2 里面有什么

- 地底巨物：独一份的大物是几项取值的组合（卷十六:774 R16-10.2：省一级 `maxAlive` 为 1、`named` 为真、`ageless` 为真、`growthRate` 为 0）；无光群落的穴居物种；由卷十六程序生成槽按群落补（附表第七节）。
- 资源：神金矿脉（卷十五 §4.13，卷五赋存行按深度给）；地热。
- 危险：**高温是推出来的**——地下基准温度 = 常年气温 + 衰减后的季节项 + `geothermalGradient` × 深度（卷二十:746），卷二十例值每米 0.03 度（卷二十:770）时，地表下 1,500 米约高出 45 度、3,000 米约高出 90 度；所以深渊上部可下、下部只有耐热物种。这不写特例：物种与人的耐温由卷四读体感温度。另有无光、迷路、塌方（卷五、卷十九）。

### 7.3 规则与连接

- 全部同主世界（它就是主世界）：同一时钟、同一套生死魔法；光由 `skyExposure` 为 0 派生。
- 离屏：北岭无主，按卷二十七:280 成无政区单元，深渊随北岭。
- 卷十六:775 R16-10.3 措辞勘误："深渊里的东西是 `habitats` 指向深层洞穴群落的行"，删"卷十五某一层"（总案第十一节影响表已列）。
