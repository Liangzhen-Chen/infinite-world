## 1. 摘要

CK3 把"宗教"与"文化"各拆成一组**可独立取值的维度**，再让人物、领地、法律、战争都从这些维度上**读修正值与开关**：

- **宗教**是四层树：宗教家族（4 个）→ 宗教 → 信仰 → 仪轨（rite）。仪轨持有具体的**教义**（doctrines，按组单选，如婚姻类型、性别、神职、教首、多元/原教旨、丧葬……）与**信条**（tenets，三条核心）。信仰持有**圣地**（通常 5 个，最多 9；至多 3 个"卓越"圣地）、热忱、军事修会、教首。[Religion](https://ck3.paradoxwikis.com/Religion)、[Holy sites](https://ck3.paradoxwikis.com/Holy_sites)
- **文化**是五支柱 + 传统 + 创新：传承（heritage）、语言、风气（ethos，7 选 1）、尚武习俗、美学；传统按时代增加槽位（部落时代最多 5，每时代 +1）；创新按四个时代解锁。[Culture](https://ck3.paradoxwikis.com/Culture)
- 两边最终都落到同一张 **modifier 表**（`common/modifiers`），键名约定统一：`monthly_income_mult`、`levy_size`、`<men_at_arms>_damage_mult`、`opinion_of_same_faith`、`faith_conversion_piety_cost_mult`……；每个修正值标明作用域（人物/伯爵领/男爵领/领地/兵团/阴谋/文化/信仰）。[Modifier list](https://ck3.paradoxwikis.com/Modifier_list)
- **关系是算出来的**：两个信仰互相是"正道/迷途/敌对/邪恶"由神论教义、融合信条、宗教专属教义决定，多元派减半、原教旨加倍；四级关系再派生观感 0/−10/−20/−30、能否通婚、能否圣战、改宗成本 0/100/150/250。两个文化的接纳基线 = 同传承 +20、同语言 +10、同风气且相邻 +10、多数同信仰 +10 ……。[Faith](https://ck3.paradoxwikis.com/Faith)、[Culture](https://ck3.paradoxwikis.com/Culture)
- **法律从维度读开关**：性别继承法要求对应性别教义；平等法可由特定传统解锁；长子继承要创新；北欧选举要 Ting-Meet 传统，塔尼斯特要布立吞/盖尔传承。[Succession laws](https://ck3.paradoxwikis.com/Succession_laws)
- **战争从维度读条件与成本**：圣战只能打敌对/邪恶信仰，耗热忱与虔诚；征服 CB 需仪轨有"穷兵黩武/追逐权力"信条且文化有"好斗"传统；大圣战需教首、热忱 ≥75%、特定信条。[Casus belli](https://ck3.paradoxwikis.com/Casus_belli)、[Holy war](https://ck3.paradoxwikis.com/Holy_war)

**局限**（第 7 节详述）：大量内容是专门写死的——"宗教专属教义"（逊尼/什叶、拉比/托拉、拜火善恶、基督普世/米亚菲派）、特殊教义（耶稣的教导、吉兹亚、马拉基预言……）、按传承/地区硬门控的 29 条地域传统（约 25 条有传承/文化/地区硬门）、独一文化分化/融合表、诺斯分裂 950–990 年、西西里熔炉事件、北方浩劫事件链、大圣战的 1100/1095/800 年门……官方 Scripting 页也明说 AI 与军队行为大多在引擎里，脚本动不了。

## 2. 统一维度是什么

### 2.1 宗教四层：宗教家族 → 宗教 → 信仰 → 仪轨

| 层 | 决定什么 | 出处 |
|---|---|---|
| 宗教家族（Abrahamic / Dharmic / Sinitic / Pagan） | 若干教义与信条按"同家族/异家族"改变敌意与观感；跨家族改宗 +200% 成本 | [Religion](https://ck3.paradoxwikis.com/Religion) |
| 宗教 | 各信仰共享的美德/罪恶、圣建筑类型、神名 | 同上 |
| 信仰 | 圣地、热忱、可用军事修会、教首（若有） | 同上 |
| 仪轨（rite） | 具体实践的信条与教义 | 同上 |

脚本层对应 `religion_family_types / religion_types / faith_types / rite_types / holy_site_types` 五个子目录。教义可在宗教、信仰、仪轨三层叠写：仪轨同组教义优先于信仰，信仰优先于宗教；宗教层教义只在开局生效。[Religion modding](https://ck3.paradoxwikis.com/Religion_modding)

> 四层不是装饰：敌意算法、改宗成本、圣战资格都读"同宗教 / 同家族 / 异家族"这个层级距离。

### 2.2 教义（doctrines）：分组单选，每组一个"开关 + 修正值"

每个教义组恰好选一项，典型组与效果：

| 组 | 选项 | 行为后果（举例） |
|---|---|---|
| 性别 | 男性主导 / 平等 / 女性主导 | 决定可用性别继承法、能否授女性头衔 |
| 宗教态度 | 原教旨 / 正统 / 多元 | 原教旨：异端风险↑、对异信仰观感罚↑；多元：减半，赢圣战改为附庸化而非夺地 |
| 神职传统 | 神权 / 世俗 | 神权：寺庙为租借、启用领地祭司职位 |
| 教首 | 无 / 精神 / 世俗 | 无教首：分歧阈值与热忱加成；精神教首有独立权威；世俗教首绑定世俗统治者 |
| 朝圣 | 禁止 / 鼓励 / 本地 / 强制 / Hajj | 决定朝圣活动可用性与虔诚产出 |
| 神论 | 一神 / 多神 | 一神视其他家族为邪恶、不能用曼陀罗政体；多神视为敌对、可用 |

| 离婚 | 禁止 / 需批准 / 总是允许（100 虔诚） | |
| 私生子 | 无私生 / 可合法化 / 不可合法化 | 决定婚外子女获得的特质 |
| 血亲通婚 | 直系禁止 … 无限制 | 可否与亲属结婚 |

| 神职婚姻 | 允许 / 禁止 | |
| 神职任命 | 世俗可撤 / 精神终身 等 | |
| 丧葬 | 坚忍 / 哀悼 / 火葬 / 天葬 / 木乃伊 / 家族仪式 | 葬礼改变虔诚、金钱或压力 |

### 2.3 信条（tenets）：三选、带美德/罪恶与解锁

信条状态五种：核心 / 允许 / 已知 / 禁止 / 未知；教首可用"允许/禁止某信条、颁布诏书"改状态。每条信条典型携带：一组修正值、一对（美德, 罪恶）特质、若干解锁（职位、决议、CB、反制措施）、互斥与前置。例：

| 信条 | 修正/解锁 | 美德/罪恶 | 最高虔诚成本 |
|---|---|---|---|
| 适应性 | 主流仪轨可吸收任何圣地；异信仰臣民观感 −25% | 善变 / 顽固 | 500（犹太、佛、耆那、异教）/ 1000 / 1500（基督、伊斯兰） |
| 苦修 | 可圣化普通级书与台座文物；−2 勇武、+10% 虔诚收益；解锁隐修 | 节制 / 暴食 | — |
| 神圣谋杀 | 解锁大师刺客职位、成为冒险者；+2 勇武、每杀异信仰者 +3 精神满足 | 复仇 / 怯懦 | 2000 |
| 神圣谎言 | 解锁三级"流言悬赏"反制；+400% 分歧；不可与"圣餐"同选 | 欺诈 / 诚实 | 1000/1500/2000 |
| 追逐权力 | 解锁征服与一生一次入侵 CB；−50% 头衔创建成本 | 野心 / 满足 | — |
| 人祭 | 掠俘 CB；按阶处决贵族得虔诚；排斥和平主义与祭祀仪式 | 施虐 / 怜悯 | — |
| 字面主义 | 字面主义辩论互动；圣战可打缺此信条的仪轨 | 顽固 / 善变 | — |
| 武装朝圣 | 军事修会租借/收回有虔诚与满足；解锁大圣战 | — | — |
| 斗争与顺从 | 成为冒险者；教首可发大圣战 | — | — |
| 祖先崇拜 / 转世 / 仪式自杀 | 各解锁专属决议 | — | — |

新仪轨选信条的成本按宗教分档；原仪轨已有的信条半价；去掉个人信条给压力并锁 3 年。[Tenets](https://ck3.paradoxwikis.com/Tenets)（该页 26.3 万字符，已读两段，By God Alone 段未读完）

宗教专属信条（只能作该宗教核心）：乌拉尔"吉兆出身"、Zunbil"太阳崇拜"、基督"牧灵隔绝"、北非"祭祀仪式"、印度教"守护""神圣毁灭"、佛教"法灭"、希腊罗马"家神"（需罗马已复国且非一神）。[Tenets](https://ck3.paradoxwikis.com/Tenets)

### 2.4 圣地（holy sites）：绑在男爵领上的三层修正值

- 多数信仰开局 5 个，最多 9；至多 3 个"卓越（Eminent）"圣地。
- 三层修正：持有者（需同信仰）、伯爵领、全信仰人物（仅卓越）。例：耶路撒冷持有者 +5% 月虔诚、+5 异信仰观感，伯爵领 +1% 发展、−1 危险；麦加持有者 +5% 月虔诚、+5% 骑士效力；拜占庭 +1 学识、+5 廷臣/宾客观感，领地 +1% 税、+1 民众观感。
- 持有者可借此朝圣；同信仰法理内领主可建圣建筑；可供奉 3 件圣物（最后一件移走则失效）。
- 异信仰持有者不得加成。夺走他人圣地需对方为教首傀儡等条件；移除一处 1000 虔诚、同信仰狂热/地方主义封臣 −20 观感 10 年。
- 改革未改革信仰、创建教首头衔都需控制 ≥3 处常规圣地。
- By God Alone：可新建 10 类圣地（祖先/圣餐/治疗/殉道/奇迹/预言/启示/隐修/英勇/智慧），每类一处，2000 虔诚 + 圣物稀有度合计 ≥3。[Holy sites](https://ck3.paradoxwikis.com/Holy_sites)（该页 20 万字符，已读一段）

脚本层：`county` 必填、`barony` 可选；`character_modifier`（任何同信仰持有者）、`faith_character_modifier`（全信仰）、`faith_character_modifier_scaled`（仅卓越）、`county_holder_character_modifier`、`county_modifier_scaled`；`parameters` 放任意旗标供效果查询（如改宗加成）。[Religion modding](https://ck3.paradoxwikis.com/Religion_modding)

> 圣地是"**地点 × 信仰 → 修正值**"的三元表，是宗教接入地图的接口。

### 2.6 传统（traditions）

- 槽位：部落时代最多 5，每时代 +1。
- 成本：基础 2000 威望（个别 4000/8000）；风气不偏好 +2000；可选前置未满足 +3000（AI 文化首领免）；替换 +50%；仪式洁净类 −1000～−3000；临时事件 −50%。本机草算：2000+2000+3000 = 7000，替换 10,500。
- 建立时间：≤5 伯爵领 5 年；6–29 每领 1 年；≥30 封顶 30 年；替换 +25%；之后锁 50 年。
- 分类：王国 / 战争 / 社会 / 仪式 / 地域。每条有偏好风气、必要前置、可选前置、互斥。
- 风气改革 20,000 威望。[Traditions](https://ck3.paradoxwikis.com/Traditions)、[Culture](https://ck3.paradoxwikis.com/Culture)

### 2.7 创新（innovations）：时代树 + 地域门控

- 四时代：部落（476）、早中世纪（900）、盛中世纪（1050）、晚中世纪（1200）。进入下一时代需本时代 ≥8 项创新、到年、领地发展足够；部落/游牧/Wanua 政体不能出部落时代。
- 四类：军事与民政（随时间发现）、文化（需特定文化/传统，始终激活）、地域（在特定地区有足够存在即解锁，失地不失）、丝路（AUH）。
- 发现进度：基础月几率 + 平均发展（最重要）+ 邻接异文化已解锁领数（次重要）+ 文化首领迷恋（10% 起，随技能升，封顶 45%）+ 文化传播 +40%。
- 创新解锁：法律（Bannus→边境/城主契约；诸侯表→家族长者继承；Gavelkind→联合分割；全体会议→有限王权）、建筑（兵营、城市规划、象栏、驼场、火药厂）、兵团（棉甲→重装步兵、鞍→重骑、火药→火枪/炸炮、长枪方阵→Picchieri）。地域例：长船（北欧）、象兵（印度/东南亚）、战驼（中东/北非/波斯）、乌兹钢（德干）。[Innovations](https://ck3.paradoxwikis.com/Innovations)

### 2.8 修正值（modifiers）：所有维度的公共落点

- 定义：对王朝、家族、人物或伯爵领施加增减的效果；可临时或永久；人物可挂无限多（只显示前 10）。
- 作用域：王朝（永久的作用于全体成员，平民成员改为人物修正）、家族、伯爵领（作用于全部男爵领）、人物。[Modifiers](https://ck3.paradoxwikis.com/Modifiers)
- 键名约定：前缀标作用域/频率（`monthly_`、`county_`、`holy_order_`、`same_culture_`），后缀标运算（`_add` 平加、`_mult` 乘），占位符按名字实例化（`<men_at_arms_name>_damage_mult` → `heavy_cavalry_damage_mult`；`<scheme_name>_scheme_power_add`；`<faith>_opinion`）。
- 分组：人物（技能、收入、虔诚、威望、压力、观感、征召、封臣贡献）、伯爵领/省（控制、发展、观感、补给、堡垒等级、建筑槽）、领地（各类领地建造速度/成本、征召、卫戍）、兵团（按类型维护/招募/规模/伤害/韧性/追击/掩护，驻扎版本）、阴谋（力量/抵抗/隐秘/成功率）、文化与信仰（接纳、佣兵数、改宗/创建虔诚成本、按文化/信仰键的观感）、以及战斗/政体/围城/旅行/建造/AI/特质。
- 示例键：`martial = -3`、`monthly_income_mult`、`domain_limit`、`life_expectancy`、`monthly_county_control_growth_add`、`county_opinion_add`、`development_growth`、`army_damage_mult`、`levy_size`、`min_combat_roll`、`faith_conversion_piety_cost_mult`、`cultural_acceptance_gain_mult`、`opinion_of_same_faith`、`holy_order_hire_cost_mult`、`murder_scheme_power_add`、`monthly_dynasty_prestige`。[Modifier list](https://ck3.paradoxwikis.com/Modifier_list)

> 这是 CK3 的"dogma"：**教义、信条、圣地、风气、传统、创新、特质、建筑、法律、王朝传承**全部输出到同一张键表。差别是 CK3 的键是**封闭枚举**（引擎认识的几百个键），EVE 的属性是开放集合。

## 3. 行为怎样由维度算出

### 3.1 信仰敌意：从教义差异算出四级关系

输入：双方神论教义、融合信条、宗教专属教义；多元派把惩罚减半、原教旨加倍。输出：

| 关系 | 人物观感 | 民众观感 | 通婚 | 篡夺头衔 | 圣战 | 改宗虔诚 | 圣战优势/敌意点 |
|---|---|---|---|---|---|---|---|
| 正道 | 0 | 0 | 可 | 可 | 不可 | 0 | — |
| 迷途 | −10 | −15 | 可 | 可 | 不可 | 100 | — |
| 敌对 | −20 | −30 | 可（Faith 页说否）| 不可 | 可 | 150 | 0.5 |
| 邪恶 | −30 | −45 | 不可 | 不可 | 可 | 250 | 1 |

两页表格在"敌对可否通婚"上不一致（Faith 页：否；Religion 页：可），照实记录。若两信仰互视为正道，同信仰观感加成也适用。[Faith](https://ck3.paradoxwikis.com/Faith)、[Religion](https://ck3.paradoxwikis.com/Religion)

宗教专属教义就是在这个算法里加"同教义 → 迷途"之类的特判：逊尼/什叶/穆哈基玛/赞达卡（伊斯兰）、拉比/托拉/祭司/撒玛利亚（犹太）、Behdin/Korramdin（拜火）、普世/米亚菲派共融（基督）。特殊教义再加一层：耶稣的教导（基督融合→敌对而非邪恶、+30 观感）、先知的教导、摩西的教导、多教交织（达摩融合→迷途）、中华宇宙观、无形和谐、诺斯替（其他诺斯替/二元论→正道）。[Doctrines](https://ck3.paradoxwikis.com/Doctrines)

### 3.2 热忱（fervor）：信仰的"血量"

- 每年 +1.5%；同信仰下每 1% 分歧的仪轨 −0.02%；>20 领的信仰增长更慢。
- 新信仰 100% 起，历史信仰 50%；创建教首头衔 +50%。
- 圣战 CB 攻方扣、守方加；大圣战攻胜攻方 −30、守方 +25%，守胜攻方 −25。
- >50% 同信仰其他仪轨更易改到主流；<50% 反之。低热忱触发异端爆发（一次改 10–25 领），每位叛出统治者给原信仰 +15%。
- 大圣战需 ≥75%，解锁需 >65%。本机草算：从 50 到 75 需约 16.7 年。[Faith](https://ck3.paradoxwikis.com/Faith)、[Holy war](https://ck3.paradoxwikis.com/Holy_war)

### 3.3 文化接纳：从支柱重合算出基线

基线 = 同传承 +20 / 同语言 +10 / 同风气且相邻或同地区 +10 / 多数共享领同信仰 +10 / 同宗教 +5 / 达摩宗教 +5 / 多数为多元派仪轨且相邻 +10。全满 70。接纳决定两文化间观感罚、文化传播目标（+40% 对方已知创新进度）、能否融合（基线门槛 40%，受传统、游牧之道特质、斗争阶段修正）。[Culture](https://ck3.paradoxwikis.com/Culture)

融合三路：统治者自建（持有双方领地，自选支柱/传统/美学，接纳越高越便宜，起始双亲 100% 接纳）；随机事件（非首都文化统治者每年 5%，免费但随机，任一方有坚定传统派则禁）；游牧决议。分化：风气随意改；语言需邻接文化占 ≥10% 领且 ≥25% 接纳；尚武需继承法支持；美学不可改；新文化在原文化领 50 年改化加成。[Culture](https://ck3.paradoxwikis.com/Culture)

### 3.4 美德与罪恶、罪行与羞耻：特质的"含义"由信仰决定

- 宗教层定义 `traits = { virtues sins }`，带可选 weight/scale；同一特质多处出现时取最高权重。观感：观察者信仰视其为美德 +10、罪恶 −10。[Religion modding](https://ck3.paradoxwikis.com/Religion_modding)、[Opinion](https://ck3.paradoxwikis.com/Opinion)
- 罪行类教义把同性、通奸、离经叛道、巫术、杀亲各定为犯罪/羞耻/接受/美德：犯罪或羞耻的特质被隐藏成"秘密"，曝光扣观感；美德则公开庆祝。秘密被勒索：羞耻秘密给弱钩、犯罪秘密给强钩；若仪轨接受该特质，秘密直接变成特质。[Doctrines](https://ck3.paradoxwikis.com/Doctrines)、[Secret](https://ck3.paradoxwikis.com/Secret)、[Hooks](https://ck3.paradoxwikis.com/Hooks)
- 信条再叠一层（美德, 罪恶）对：苦修=节制/暴食、神圣谋杀=复仇/怯懦……[Tenets](https://ck3.paradoxwikis.com/Tenets)
- 文化传统改变特质**出现概率**："好学灯塔"让孩子 3 倍可能沉思、3 倍不易顽劣；"战士文化"反之；"公正"让公正/诚实更常见。[Traditions](https://ck3.paradoxwikis.com/Traditions)

> 同一个特质，在信仰 A 是美德、在信仰 B 是罪恶、在信仰 C 是要藏起来的罪行——**特质本身不含道德值，道德值是（特质 × 信仰）查表**。这是 CK3 最值得我们学的一条。

### 3.5 法律门控

性别法（世俗头衔需性别教义，神职头衔需神职性别教义）：

| 法 | 世俗需 | 神职需 |
|---|---|---|
| 仅男 | 男性主导 | 仅男 |
| 男优先 | 男性主导或平等 | 仅男或皆可 |
| 平等 | 平等（或特定传统，如"平等继承"） | 皆可 |
| 女优先 | 平等或女性主导 | 皆可或仅女 |
| 仅女 | 女性主导（或"母系"传统） | 仅女 |

改性别法需高王权（封建/氏族）或有限部落权威。

继承法：联合分割需 Gavelkind 创新（页注实际按政体解锁，部落/Wanua 锁定）；分割需世袭统治创新；高分割需纹章创新或西哥特法典传统；长子/幼子需长子继承创新；家族长者需纹章或诸侯表创新；神权由教义决定继承人；营地继承（冒险者）、曼陀罗继承、库里勒台（游牧）按政体。选举法 1500 威望/头衔：封建选举（有 Witenagemot/Ting-Meet/Jirga 传统则不可）、北欧选举需 Ting-Meet 传统、撒克逊选举需 Witenagemot、部落选举需 Jirga、塔尼斯特需布立吞或盖尔传承、诸侯选举需神罗头衔。[Succession laws](https://ck3.paradoxwikis.com/Succession_laws)、[Traditions](https://ck3.paradoxwikis.com/Traditions)、[Innovations](https://ck3.paradoxwikis.com/Innovations)

其他法律（边境战争政策、行政法、天朝法、帝国政策、加冕法、枢机俸禄）按 DLC 与政体门控。[Laws](https://ck3.paradoxwikis.com/Laws)

### 3.6 战争：宣战理由、圣战、大圣战

- **圣战**：只能打敌对/邪恶信仰；信仰须有组织且无和平主义/达摩和平主义信条；耗热忱与虔诚、需最低奉献等级；武装朝圣信条降虔诚成本；王国级一生一次；胜则取敌对/邪恶统治者头衔，守方得攻方所付热忱两倍。
- **按信仰变价**：征服 CB 对同信仰付虔诚、异信仰付威望；攻击教首 +500（精神）/+100（世俗）虔诚；同信仰攻击教会/神权 +100；文物战争需异宗教、150 威望；绝罚与废黜挑战者需同信仰；世俗教首征服需同信仰 +1000 虔诚；冒险者入侵若守方同信仰 +250。
- **信条/传统门控**：伯/公级征服需仪轨有穷兵黩武或追逐权力核心信条、文化有好斗传统；王国级征服同信条且无友好/和谐家族团结；掠俘 CB 需人祭信条。
- **文化门控**：强制附庸目标规模看攻方文化创新；瓦兰吉冒险只能打异文化组；异宗教宣称成本更高。
- **战争分值**：−100～+100，来自战斗、占领、俘虏、控制目标；+30 可白和、+100 可强制；页面未给信仰/文化直接改战争分值的规则。
- **大圣战**：导向型需世俗教首、非导向型需精神教首；仪轨需武装朝圣/斗争与顺从/穷兵黩武核心信条或"世界正统统治者"特殊教义；热忱 ≥75% 才能发、>65% 才解锁、仪轨 ≥35 领、距其他宗教解锁 ≥10 年；目标为敌对/邪恶信仰的王国；准备期可承诺出兵或捐金（捐金得半数虔诚），战争箱 20% 先分、其余胜后分；承诺者可指定王朝内无地非继承人为受益人，按战争贡献分地；非导向型胜者为贡献最高的攻方；参与者获十字军/圣战者/信仰战士特质。年份门：1100 普遍解锁，基督最早 800（耶路撒冷顶级领主非基督时 1095），伊斯兰在基督之后，其他宗教 800 需两处圣地在不同宗教顶级领主手中。[Casus belli](https://ck3.paradoxwikis.com/Casus_belli)、[Holy war](https://ck3.paradoxwikis.com/Holy_war)、[Warfare](https://ck3.paradoxwikis.com/Warfare)

### 3.7 成本公式

- **创建仪轨**：极大虔诚，随与原仪轨差异增加（每教义/信条有分歧%与虔诚成本）；需成年、和平、一生一次、独立或公爵以上或教会政体；至少一处核心教义/信条不同；分歧 >100% 则成为新信仰。改革需 3 圣地。
- **改宗**：需知道目标仪轨 50%（同宗教）/60%（跨宗教）的教义信条；跨家族 +200%、从有组织改到未改革 +500%、教首已死 +500%；同宗教已有仪轨 −50%、配偶仪轨 −50%；最低 250。
- **传统**：2000 +2000（风气）+3000（可选前置）×1.5（替换）；风气改革 20,000；建立时间按领数 5–30 年。
- **文化改宗（人物）**：改到首都文化需威望与宫廷牧师认可，近亲一起改。
- **圣地操作**：移除 1000、改状态 1000（5 年一次）、新建 2000。
- **选举法**：1500 威望/头衔。
- **活动**：基础 15–200 金按头衔与政体，再加文化/宗教/事件/时代修正。[Faith](https://ck3.paradoxwikis.com/Faith)、[Culture](https://ck3.paradoxwikis.com/Culture)、[Traditions](https://ck3.paradoxwikis.com/Traditions)、[Holy sites](https://ck3.paradoxwikis.com/Holy_sites)、[Succession laws](https://ck3.paradoxwikis.com/Succession_laws)、[Activities](https://ck3.paradoxwikis.com/Activities)

## 5. 脚本结构（common/ 下）与"参数"机制

**宗教**（`common/religion/`）：
- `religion_family_types`：name、piety_icon_group、graphical_faith、`hostility_doctrine`（注明"仅界面用"）、四个 tenet 背景图。
- `religion_types`：family、theocracy_government_type、`pagan_roots`、开局教义、`traits = { virtues = {...} sins = {...} }`（weight/scale）、保留名、自定义信仰图标、`holy_order_names`、`holy_order_maa`、localization。
- `faith_types`：religion（必填）、color/icon、`religious_head`、`head_of_rite`、`holy_sites` 与 `eminent_holy_sites`（互斥）、tenets（仅当无脚本主仪轨时）、doctrines（叠加到主仪轨）。
- `rite_types`：faith、cultures、convert/create 开关、tenets、doctrines（同组覆盖信仰与宗教）、`tenet_selection_pair`（带 DLC 旗标与回退）。
- `holy_site_types`：county（必填）、barony、五种修正块、`parameters`。
- 页面未记录 `piety_cost`、`is_available_on_create` 的字段定义；教义组只顺带提及。[Religion modding](https://ck3.paradoxwikis.com/Religion_modding)

**文化**（`common/culture/`）：wiki 的 Culture modding 页只到 1.4 版，覆盖文化组与文化块：color、heritage、graphical_cultures、mercenary_names、`character_modifier`（作用于全体该文化人物）、各类王朝/人名/父名字段与概率（和 ≤100）、ethnicities。**支柱、传统、创新的脚本字段该页未写**。[Culture modding](https://ck3.paradoxwikis.com/Culture_modding)

**脚本语言**：
- 作用域（scope）是脚本运行所针对的实体（人物、伯爵领……）；事件目标做作用域跳转（`primary_heir.faith.religious_head`）；`root/prev/this`；`culture:`、`faith:`、`title:` 前缀直接引用；`save_scope_as` 仅在本次脚本内有效；变量存在特定作用域上。
- 效果（做事）、触发（真/假或返回值）、迭代器（`every_/random_/ordered_/any_`）。
- 脚本值（`common/script_values`）每次使用都重算，UI 中每帧重算。
- 脚本化效果/触发是模板，`$NAME$` 参数在调用处填。
- 修正值定义在 `common/modifiers`，每条有 icon 与若干效果键。
- 限制：AI 与军队行为大多引擎硬编码；UI 是独立系统；无字符串操作、一维数组、`while` 默认 1000 次上限、不能 break；值块只有加减除。[Scripting](https://ck3.paradoxwikis.com/Scripting)、[Modding](https://ck3.paradoxwikis.com/Modding)、[Modifier list](https://ck3.paradoxwikis.com/Modifier_list)

**覆盖规则**：单条顶层声明可用后排序文件名覆盖（01 覆盖 00）；holdings、基因、动画、GUI 需整文件覆盖；on_action 的 events 追加而 trigger/effect 覆盖。[Modding](https://ck3.paradoxwikis.com/Modding)

**parameters 机制**：圣地脚本有 `parameters` 任意旗标；信条/传统/教义解锁职位、CB、决议、反制措施的方式在 wiki 上表现为"解锁 X"，与圣地 parameters 同构——其他脚本用触发器查这些旗标。本调研未取到 doctrines/tenets/traditions 脚本字段的官方页（Culture modding 页未覆盖，Religion modding 页未给教义字段），此处只能确认圣地一处。

## 7. 哪些仍是专项脚本 / 局限

1. **宗教专属教义是硬编码的分支**：伊斯兰四派、犹太四派、拜火二派、基督二派各自一组只有该宗教能选的教义，且"同教义→迷途"是逐条写的。[Doctrines](https://ck3.paradoxwikis.com/Doctrines)
2. **特殊教义全是特判**：耶稣/先知/摩西的教导、多教交织、中华宇宙观、无形和谐、被拆解的祭司、裸行祭司（耆那）、诺斯替、马拉基预言（犹太但不含撒玛利亚）、吉兹亚（穆斯林但不含三派）、世界正统统治者、嗣子论三学派事件链（各给不同美德与 +50% 基督领地改宗）。[Doctrines](https://ck3.paradoxwikis.com/Doctrines)
3. **宗教专属信条**：8 条只能作特定宗教核心，部分带世界条件（"家神"需罗马已复国）。[Tenets](https://ck3.paradoxwikis.com/Tenets)
4. **地域传统约 25/29 条有传承/文化/地区硬门**（兵法=汉/中华 + DLC；高加索之狼=格鲁吉亚；流散=不可选不可融合，只有 5 个以色列文化自带）。[Traditions](https://ck3.paradoxwikis.com/Traditions)
5. **独一分化/融合文化表**：Parsi（需拜火）、Beta Israeli（需犹太）、Kuzarim、Ænglish（需非诺斯）等逐条写死。[Culture](https://ck3.paradoxwikis.com/Culture)
6. **历史事件**：诺斯分裂 950–990（80% 控制可阻止）、盎格鲁-撒克逊→苏格兰 867–950、西西里熔炉三年脉冲（诺曼 ×2、邻接西西里 ×4，限定公爵领清单）、北方浩劫（+25 控制、−0.25 发展 15 年、三种结局各 −65 压力）。[Culture](https://ck3.paradoxwikis.com/Culture)
7. **大圣战年份门**：1100 普遍、基督 800/1095、伊斯兰在基督后、其他 800 需两圣地异教——按宗教名字写的。[Holy war](https://ck3.paradoxwikis.com/Holy_war)
8. **DLC 门控**遍布：尚武习俗、风气改革、融合/分化、加冕教义、新建圣地、行政/游牧/冒险者政体、斗争。[Culture](https://ck3.paradoxwikis.com/Culture)、[Doctrines](https://ck3.paradoxwikis.com/Doctrines)、[Government](https://ck3.paradoxwikis.com/Government)
9. **引擎硬编码**：AI 与军队行为、UI、历史系统；脚本无字符串、一维数组、循环上限；修正键是封闭枚举。[Scripting](https://ck3.paradoxwikis.com/Scripting)
10. **接口文档不全**：`hostility_doctrine` 只影响界面；Culture modding 页停在 1.4 且不含支柱/传统/创新；教义字段 `piety_cost/is_available_on_create` 未记录。[Religion modding](https://ck3.paradoxwikis.com/Religion_modding)、[Culture modding](https://ck3.paradoxwikis.com/Culture_modding)
11. **wiki 自相矛盾**：敌对信仰可否通婚两页不同；Traditions 页说成本不随领数变而 Culture 页说建立时间随领数——两者其实说的是不同量，但初读易混。[Faith](https://ck3.paradoxwikis.com/Faith)、[Religion](https://ck3.paradoxwikis.com/Religion)、[Traditions](https://ck3.paradoxwikis.com/Traditions)
12. **本调研未读完的页面**：Doctrines、Tenets、Culture、Traditions、Modifiers、Opinion、Holy sites、Casus belli、Innovations、Ethos、Education、Attributes、Schemes、Court、Activities、Legends、Legitimacy、Dread、Men-at-arms、Army、Hostage、Landless adventurer、Situations——均超过 10 万字符。

## 8. 对 infinite-world 的启示

**可直接照搬的结构**

1. **宗教 = 分组单选教义 + 三条信条 + 若干圣地**；文化 = **五支柱 + N 条传统 + 创新树**。每个维度的取值是一个"修正值包 + 解锁旗标 + 互斥/前置"。我们的宗教与文化系统可以照这个骨架建：先定组，再定每组选项的修正与开关。
2. **关系从维度差算，不手填**：敌意四级 = f(神论教义, 融合信条, 专属教义) × 多元/原教旨倍率；接纳基线 = Σ支柱重合。再让观感、通婚、宣战、改宗成本全部读这个算出的等级。我们"两个族群/两个信仰怎么看对方"应如此派生。
3. **道德是（特质 × 信仰）查表**：特质不含善恶，信仰给它美德/罪恶/犯罪/羞耻标签；标签再决定隐藏成秘密还是公开庆祝、能否被勒索成钩子。这让同一人物在不同社会里"合法性"不同，是涌现剧情的来源。
4. **法律是开关的读取者**：性别法读性别教义，继承法读创新/传统/政体，选举法读传统/传承。法律系统本身不含文化知识。
5. **战争成本是信仰/文化的函数**：同信仰付虔诚、异信仰付威望；敌对/邪恶才可圣战；某些 CB 需特定信条 + 特定传统。把"谁能对谁开战、花什么钱"变成维度查询。
6. **三层圣地修正**（持有者/领地/全信仰）：把地点接进宗教的标准接口；"卓越"等级决定是否有全局层。
7. **热忱**：给每个信仰一个随时间自回升、被分歧与战争消耗、决定改宗方向与异端概率的"血量"。我们的教派兴衰可以用同一条。
8. **成本随差异计价**：改宗/建仪轨成本 = 按教义分歧%累加 × 家族距离倍率，最低 250；传统 = 基础 + 风气不符 + 前置未满 ，替换 ×1.5；建立时间 = min(30, 领数)。
9. **特质出现概率由文化改**（3× 沉思、3× 顽劣）：文化影响"人长成什么样"而不只是数值。
10. **统一修正键表 + 作用域**：所有维度输出到同一张表，键名约定 `<scope>_<what>_<add|mult>`，占位符按名字实例化。这与 EVE 的 dogma 殊途同归。

**要避开的坑**

11. 不要为具体宗教/文化写专属教义与信条（CK3 的逊尼/什叶、兵法、流散）。把"同教义→迷途"这类规则做成教义组的通用属性（如 `同选项关系 = 迷途`），让任何新宗教都能用。
12. 不要用年份/名字门控大事件（大圣战 1100/1095/800）。改为由热忱、领数、圣地归属等**世界状态**触发。
13. 不要写死历史分裂与独一文化表；用分化/融合的通用规则（接纳、控制比例 80%、相邻语言 10%/25%）让它们自己发生。
14. 修正键不要做成封闭枚举——学 EVE 用开放属性集合，否则每加一种行为都要改引擎。
15. 把"解锁旗标（parameters）"做成一等公民并写文档：CK3 这块只在圣地脚本有明确字段，教义/信条/传统的解锁机制在 wiki 上只能看到结果，看不到接口。
16. 文档要和版本同步（CK3 的 Culture modding 停在 1.4）；我们的规则文档应由规则数据生成。
