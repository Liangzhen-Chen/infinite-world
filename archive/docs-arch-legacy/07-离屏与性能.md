## 7.1 现状与预算

P3 已把设计上限场景（九省 31 郡、142 聚落、324 住区、约 3.5 万居民）的日推进从 57.9 秒降到 1.49 秒、月推进 38.8 秒、回合 382 毫秒、峰值内存 3.0GB、存档 23MB；预算：日 ≤ 5 秒、月 ≤ 120 秒、场景与提示 ≤ 150 毫秒、存档 ≤ 64MiB（标杆标准收紧为日 ≤ 2 秒、月 ≤ 60 秒、回合 p95 ≤ 300 毫秒、内存 ≤ 2GB，B14）。advance-layers 已按郡的注意距离分三层（intelligent / rule / statistics），远方普通居民改存聚合，走近可重放补算。目标架构沿用这套分层，把"等价"从经验做法变成规则声明与测试。

## 7.2 三层（沿用指南 5.9 与 P3）

| 层 | 范围（按注意距离派生） | 做什么 | 不做什么 |
|---|---|---|---|
| 智能层 | 玩家所在郡及相邻郡；另加与玩家有持有/义务/强立场的实体，无论在哪 | 逐事件；日程逐人；NPC 决策规则逐人（读主观视图）；分区站位与感知只对玩家所在地点及有事件发生的地点计算；（开 LLM 时）智能层行动提案可来自模型。**常驻统计层地区的 (d) 类钉住个体**：所在聚落骨架物化、日常接触者按需物化，本人自治按智能层逐日、感知只在其有事件的刻计算（附录 A §A.15 钉住） | — |
| 规则层 | 同省或两跳内的郡 | 按日时钟规则；义务到期项精确；人物以日为粒度；自治只对钉住与显著 NPC，每日一次；见证按概率模型 | 不逐分钟日程；不算分区感知 |
| 统计层 | 其余 | 聚落级聚合账户按月闭式（含聚合市集账户、信贷聚合量、人口与畜群的 S/I/R 子账户、未安息亡者、批次腐坏）；**公共知情集合**；个体只保留名册种子与稀疏的持有/义务；种群、资源点按月 | 不物化个体、不生成个体记忆、不算站位与感知 |

层级不写进人物；玩家移动时相邻地区先"补算到现在"再升层（P3 已做）。**钉住**的个体不参与聚合（定义在附录 A §A.15：有到期项指向它、处在一条声明 `pins` 的持有的被钉侧、owns 一个模板声明 `pins: true` 的物品个体（书、手札、交感媒介、署名杰作——契据与账簿不钉住）、或与玩家有持有 / 义务 / 强立场；resides / kin / citizen_of / member_of 不钉住）：**钉住实体无论所在地区层级，至少按规则层处理它自己的规则；其中与玩家有持有 / 义务 / 强立场的（附录 A §A.15 (d)）按智能层**（首领在统计层郡被佣兵团讨伐可以发生并记录；持有配方手札的商人在远方逐日自治）。层级是视角 `frame` 的第四轴（附录 A §A.15）：同一事实在统计层的答案是其聚合变体（§7.3 第 7 条），不是另一份存储。规模口径：钉住人口 ≈ 职位持有人 + 首领 + 在押 / 通缉 / 流放者 + 同行者 + 持书持媒介者 + 有到期项者，远小于居民总数；若某地区钉住比例超过阈值（配置，缺省 20%），scale 测试报警而不是静默降级。

### 7.2.1 运行矩阵：层级 × 规则形状 × 有无 LLM

| 规则形状 / 机制 | 智能层 | 规则层 | 统计层 |
|---|---|---|---|
| 派生 | 全部按需 | 全部按需 | 聚合变体 |
| 反应 | 逐事件 | 逐事件（按日批） | 聚合变体，或声明 `statistics: skip` 的跳过（必须声明容差） |
| 时钟 | 按声明周期 | 按日 | 按月闭式 / 容差 |
| 动作（玩家） | 逐刻 | — | — |
| NPC 自治 | 逐人，按决策时钟（起意频率受节奏） | 只对钉住与显著 NPC，每日一次 | 聚合率（犯罪率、迁出率、挤兑率、招收率等聚合变体） |
| 感知见证 | 分区感知（01 §1.5；I30 第一档） | **见证概率模型**（I30 第二档）：P(在场者见证) = f(地点类型, 时段, 日程聚合的在场人数, 事件显著度)，确定性骰；声明容差（与智能层精确感知比较立案率，纳入 I14） | 聚合（案件数、显著事件计数进公共知情；I30 第三档） |
| 转移协议、义务、案件 | 精确 | 精确 | 精确（钉住；需要个体时骨架物化） |
| 知情 | 个体知情集合 | 个体知情集合（见证来自概率模型） | 公共知情集合（§7.3 第 8 条） |
| LLM | 可选：智能层 NPC 的行动提案可由模型给出，替代自治包的"主意" | 不用 | 不用 |

**智能层永远开启**；LLM 只是它的可选提案来源之一。无 LLM 时，智能层的 NPC 行动提案全部来自自治包的规则决策（05 §5.7），结果合法，只是"主意"更少。这一句统一了 06 §6.9.3、07 §7.3 第 6 条与 08 §8.6 的说法。

## 7.3 等价原则（I14）

1. **义务与日程精确，与层级无关**：它们是稀疏到期项；离开 360 天也只处理真正到期的分期。到期项处理顺序按 14 §14.2 的全序，骰值由种子 + 规则 + 对象 + 时刻 + 序号决定，所以逐日推进与一次推进的事件序列相同（I31）。
2. **累计量闭式**：利息、租金、工资、俸禄、再生（逻辑斯蒂）、作物生长（按积温）、耐久损耗（按天气与使用）都声明 `closedForm`，由 `accruedTo` 一次算到当前时刻。精确等价。只含 transfer 与数值 fact.set、速率只读慢变事实的时钟规则可声明 `equivalence: "auto"`：引擎按"速率 × 天数"推导闭式并在注册与 `pack test` 时用逐日对照验证，推导失败即要求作者显式声明（12 §12.8.6）。
3. **迭代规则按层级放大步长**：价格（依赖需求流量）、疫病传播、迁徙、污染顺流、种群相互作用是耦合迭代，声明 `tolerance`（标杆 B05.2：总量 ±1%、分布 KL ≤ 0.02）；统计层用月步长执行同一规则；等价测试同种子比对逐日与放大步长的结果，超出容差即测试失败，由规则作者改为更好的闭式或降低步长。
4. **补算无可见跳变**：玩家逼近时，规则层/统计层地区先按自己的步长补算到当前时刻，再升层；任何跨区派生读之前也先补算被读地区（14 §14.3）；补算产生的事件不进入玩家知情集合（玩家不在场），只有见证规则允许的公告/景象才在到达时可见。
5. **远方未到达前只有纲要与聚合账户**：细节在首次到达时按种子物化；物化从聚合账户"借出"存量，守恒；物化前任何投影对玩家返回"未知"。
   - **物化分两级**：**骨架物化** = 聚落实体、治理组织与其职位、聚合市集账户、布局（分区由确定性规则生成）、被点名的对手方个体、**被钉住持有的标的**（他组织的建筑、网点、资源点）、被钉住的首领与组织；**完全物化** = 名册全部个体、日程、知情集合（从公共知情抽样）。玩家到达触发完全物化；以下事件只触发骨架物化：任何钉住的义务端点到期或到达（托运送达、汇票在该地兑付、债务人在该地）、玩家持有的标的位于该地、以该地为管辖的案件进入需要当事人的阶段、钉住实体在该地发生 transition、**(d) 类钉住个体常驻该地**（骨架物化含本人、同户与同雇主 / 同组织的在场者、其日程片段的对手方，按需 `materialized`）。
   - **聚合收货人**：义务的收货端可以是聚落实体的聚合市集账户（委托书写"送交某郡市集/官府/某医馆"均解析到实体；未指定具体人时缺省为市集账户）。无人押送的货物到达 = transfer 进该账户，交付事件成立，义务按条款完成；货物随即进入该地聚合需求的结算（药材 → 群体医疗，05 §5.5）。
   - **借出与并回**（B 专项② 第 6 条）：物化的个体与账户带 `materialized` 标记；地区降级或玩家离开后，按同一转换把个体账户与人口**并回**聚合（聚合 = Σ 已物化个体 + 剩余聚合），已物化个体保留（稀疏持有/义务），反复进出不重复借出；并回纳入 I14 等价测试。
6. **智能层行动是提案**，经同一校验；无 LLM 时提案来自自治包规则（§7.2.1）。
7. **跨层规则必须声明聚合变体**（I28）：凡是在个体层有形状、又会在统计层发生的规则（疫病、医疗、需求、腐坏、种群相互作用、犯罪与见证、自治、信贷、传闻、**教育与技艺**（聚落技能分布子账户 `skill:<id>:<阶>`，统计层识字率与"会某技艺的人数"由它派生；读书、授课、认证在统计层按率闭式，物化时按种子分配给个体））注册时同时声明聚合变体，schema 在附录 A §A.15（`aggregate: {target, closedForm|step, split, merge, tolerance}`），以及物化/聚合时的双向转换（按种子分配、计数守恒）。**只含 transfer 与数值 fact.set 的规则可声明 `aggregate: "auto"`**，由引擎按"个体闭式 × 聚合人数"生成缺省变体与缺省容差（rules 档作者因此多数不必手写聚合变体，R5 专项④）。缺聚合变体且不能 auto 的跨层规则注册失败。等价测试比较"一直在规则层"与"统计层 → 物化"的总量与分布，超出声明容差即失败。
8. **公共知情集合**：传闻是跨层规则，它的统计层聚合变体是每个聚落的公共知情集合 = {(事件编号, 到达时刻, 失真版本, 显著度)}，由传闻规则的路线延迟闭式算出（到达时刻 = 源事件时刻 + 沿路线的通道延迟），按显著度与数量上限截断。它是统计层聚落"大家都知道什么"的唯一来源：舆论、聚合自治率（挤兑率读"听说倒闭"）、物化时个体知情的抽样（I12 第五种来源）都读它。远方郡得知消息的时间因此可解释。

### 7.3.1 家户、资产与随机选择的聚合变体

【来源：LAW-astra-001，DS2–DS4 / AS01、AS02、HH01–03、DEC02；POP02、ECO01接点】新增家户预算、维护/退出和随机选择同样受I14、I28、I31约束。不能在前台使用风险分布，离屏却令全部主体按平均效用选同一行为；非线性阈值下“平均人格/财富/状态”的决定不等于群体分布。

聚合变体按实际误差保留最少的必要分层或联合统计，如收入窗口/财富、资产材质与状态、风险偏好与冲动状态；共同冲击保持相关，不能每层独立重抽灾年。没有误差证据不先物化全部人口，也不另建第二份家户/设施账户。家户持有、合同和被钉住资产仍走精确路径，真实库存、工资、租金、维修投入和未清债权继续守恒。

split/merge必须携带持久人格分配依据、必要状态、累计余数和时间窗口；同一主体再物化沿原稳定身份恢复，不刷新性格、不重复借出钱物或抹掉维修/债务进度。集市供给和运输以真实时刻及交付闭环；疾病的接触/密度分母在拆并后保持同一物理含义，不能仅因聚合容量变化而改变感染风险。

等价检验将家户现金流/收支尾部、维护与停业原因、选择份额、疾病及资源分布纳入§7.3已有口径：精确义务、存量与同一路径事件仍按精确协议；声明迭代容差的模型用总量±1%、分布KL≤0.02，明确共同支持集与零概率处理，不能靠任意平滑通过。随机抽样的置信区间不替代守恒或I31；数值方案新增P观测也不放宽这些门禁。保持§7.5候选/推断预算，逐人完整搜索不是默认方案。

## 7.5 成本模型与降级阶梯

一切派生意味着热路径上大量视图计算；规范谓词、感知、主观视图又叠在每个事件与每个决策上。对策分三部分：

**1. 成本模型（加载期估算，超出即 E-BUDGET）**
- 每种规则形状声明**复杂度类**与**索引键**：反应与罪名谓词声明守卫条件（动词、商品类、标签、地点子树、持有种类），加载器从 RX 的 AST 静态提取守卫并建索引；无守卫的条目有全局限额。规范栈求值只扫：属地层按事件地点子树索引、成员层只扫行为者 member_of / devotee_of 的组织、属人层只扫行为者 citizen_of / 爵位所属政体。
- **每事件预算**：最坏谓词求值数 × RX 节点上限（2,000）≤ 每事件总预算（配置，初值 4×10⁵ 节点）；超出的包在加载期被拒并指出哪些条目无守卫。运行期按规则统计耗时，进调试面板；单规则熔断见 12 §12.8.4，**每事件总预算超出**同样熔断最耗时的无守卫条目。
- 感知：候选观察者 = 事件地点按日程聚合的在场者（版本键缓存站位）；分区邻接矩阵按地点预计算；复杂度 O(在场人数)。见证列表写入事件时只存"感知快照版本 + 差异"，知情集合按需展开；**快照存储**（R4 专项③）：感知快照按 (地点, 刻) 去重，一刻内同地点的多个事件共用一版，一版 ≈ 在场 id 集合（≤ 30 个）+ 分区站位，数百字节；全规模一日约 10⁴ 个有事件的地点刻，未压缩约 10⁴ × 300 B × 360 ≈ 1 GB/年（10-27 更正：原写"每年数 MB"算错三个数量级）。去重、压缩与归档后的实际体积必须实测，按 B13.6 原口径分别报告核心快照、历史/感知归档、规则包与总战役体积；不能把归档移出统计目录就算达标，也不能为省空间删掉因果引用。
- **自治候选与推断规则**：候选按 `need` 族建索引，决策时钟对一个 NPC 只求值"当前最紧迫需求"命中的候选，并从 `applicability` 的 AST 静态提取守卫（持有种类、地点类型、技能阶、在场实体种类）先过滤；每 NPC 每日候选求值上限（配置，缺省 40 条）与推断求值上限（缺省 20 条），超出按 utility 的静态上界截断并记 `candidate_cut`。推断规则按 `premise` 中的事件动词 / 义务种类 / 到期项类建索引，只在相关事件进入该 NPC 知情集合或相关到期项发生时求值，不逐日全量扫描；无守卫的候选与推断计入全局限额（同反应规则）。
- 规范栈解析按 (地点, 行为者身份签名) 缓存，纪元或议案事件失效。
- 到岸成本的路线搜索按季节预计算距离表，天气只作乘子；供给地候选限 K 跳内；统计层按月。
- 主观视图：知情版本按话题/实体分片，只对与决策字段相关的实体失效；belief 每 NPC 有上限（最新 N 条 + 显著），其余归档为**摘要**——摘要是知情集合的确定性函数（可从日志重算的投影），决策可以读它；因为它仍只由该 NPC 的知情集合算出，I25 的双世界测试口径不变（R5 专项③ (d)）。
- 缓存命中率目标分投影设定（账户视图 ≥ 95%、价格 ≥ 85%、立场 ≥ 85%、主观视图 ≥ 70%），允许"近似缓存 + 容差"的投影在声明中标明。

**成本量级估算**（R5 专项③ (a)；S4/S7 实测标定，这里给出预算分解的依据）。全规模（3.5 万居民）默认档一天：智能层约 2 郡 × 2,500 人 × 平均 3 个事件（日程 move、交易、对话）≈ 1.5×10⁴ 事件；规则层按日批约 1.5×10⁴；统计层聚合约 10³；合计 N ≈ 3×10⁴ 事件/日。每事件成本 = 规范谓词（守卫索引后平均命中 ≤ 10 条 × ≤ 100 节点 = 10³ 节点；日程类 move 动词在词汇表标 `normFree`——**只是守卫索引的快速路径，不是豁免**：标 `normFree` 的事件只对声明了 move / 地点子树 / 时段守卫的条目求值（宵禁、禁入、擅入私宅照常命中），无此类守卫的条目跳过；占事件的一半以上的日程 move 因此仍只扫个位数条目）+ 感知（在场人数 ≤ 30 × 分区路径 O(1)）+ 反应扇出（≤ 4）。按定点 RX 求值 5×10⁷ 节点/秒估算：谓词 ≈ 3×10⁴ × 0.5 × 10³ ÷ 5×10⁷ ≈ 0.3 s；感知 ≈ 0.2 s；主观视图（每日约 5×10³ 次决策 × 分片命中 70%）≈ 0.4 s；**自治候选与推断**（5×10³ 次决策 × 命中候选 ≤ 40 条 × ≤ 100 节点 = 2×10⁷ 节点 ≈ 0.4 s，推断按索引触发约 0.1 s）≈ 0.5 s；市场与生态闭式（含劳务报价）≈ 0.3 s；归约与索引（含事件窗口索引、争夺池——只含声明 `contest` 的提案，通常个位数）≈ 0.3 s；合计 ≈ 2.0 s，恰在 B14.2 的 2 s 上，所以候选预算是第一个要实测标定的项。**分解预算**（写进 scale 测试）：谓词 ≤ 0.4 s、感知 ≤ 0.3 s、主观视图 ≤ 0.4 s、候选与推断 ≤ 0.4 s、其余 ≤ 0.5 s；任一项超出即先在该项内优化（索引、闭式、缓存、候选上限），B14.8"默认档 30 年降级 0 次"以这组分解预算为依据，不再是无依据的硬门槛。

**2. 降级阶梯（附录 A §A.10）**——降级只改**计算时机与频率**，不改任何语义：
- D0 全量。
- D1：显著度分级——低于阈值的事件**见证按需展开**（事件只冻结感知快照版本 + 差异，07 §7.5 第 1 部分；谁的知情集合被查询才展开谁的见证，展开结果与 D0 逐字节相同，所以 I30 不变、立案不变）；状态类罪名由每日改为每月求值（幂等键期间随之变粗，声明容差：只影响"何时发现"）；主观视图读"最近 N 条 + 摘要"（摘要是可重算投影，恢复 D0 即恢复全量，可逆）。
- D2：规则层地区自治只对钉住 NPC 且每周一次；传闻只传显著事件（容差：传闻到达率）。
- D3：注意距离缩小一跳（更多郡进入统计层）；**带滞回**：降到 D3 后至少保持 N 天（配置，缺省 30）才可恢复，恢复也只升一级；并回与再物化按 §7.3 第 5 条不重复借出，churn 的容差累积计入 I14 的 D3 测试。
- 触发：回合或日推进超过预算 → 自动降一级，并写入**输入事件** `budget_set{level}`（像玩家动作一样进入日志，重放一致，I31）；恢复预算后升级同样记事件。每级的偏差作为容差声明纳入 I14 等价测试；降级永不改变守恒、义务、日程、协议与见证语义。

**3. 预算守卫**
- tests/scale.test.mjs（现有）：回合 ≤ 500 毫秒、场景卡 ≤ 150 毫秒、日 ≤ 5 秒、月 ≤ 120 秒（标杆终值见 B14）；新增"派生读缓存命中率分投影达标"、"每事件谓词求值数 p95 ≤ 预算"、"全规模默认档降级触发 0 次"。
- 空间以分区为粒度（一个集镇十余个分区），不做格子级寻路；站位与感知只在智能层、只对有事件或有玩家的地点计算；离屏地区不算站位。画面客户端的投影按视野裁剪、增量推送（08 §8.8）。
- 知情集合是事件引用，长期游戏下无界：事件日志分段归档（§7.6），知情索引是可截断的缓存，归档段按需重建。

## 7.6 存档结构

- `events/`：按时间分段追加（每段 N 个事件）；旧段可压成快照后归档；事件含提案原文与骰值（动作层可重放，不再调用模型）、序号与纪元（14 章）。
- `core/`：快照 = 实体事实 + 持有 + 义务 + 账户 + 日程堆 + 地区进度 + 节奏与降级等级 + **调度配置**（反应深度上限、每刻提案上限、每事件谓词预算、滞回天数；改变只经输入事件 `config_set`，14 §14.2，R5 专项① (b)）；按郡分片，未加载分片不读；智能/规则层分片全量，统计层分片只有聚合账户、公共知情与名册种子。
- `cache/`：投影缓存（立场、价格、知情索引、场景卡素材、主观视图），带版本键，可整体丢弃重建（I17）。
- 聊天只存战役引用（现状保留）。
- 包与纪元（第12章 §12.5）：`packs.lock`（含纪元历史段）、包仓 `packs/.store/`、实体墓碑表、退役表 `core/registry.retired.json`；事件头带 `epoch`；升级前强制快照；缺包载档报错，不静默跳过。
- 跨版本：存档带 `formatVersion`；`world_upgrade` 是纪元边界事件，附迁移脚本与试运行差异报告（标杆 B13.4）。
- 布局：作者或包提供的分区数据随地点存；自动生成的布局只存种子，不存结果（可重建）。
- 迁移只在发布时写一次（C.7）；早期阶段把持有/义务/账户作为 `state.records` 的新 category 存放，不改存档格式；分片快照在后期阶段引入，附一次迁移。

## 7.7 测试

- 等价测试：对每条时钟规则，同种子跑"逐日 N 天"与"一次 N 天"，闭式类逐字节相等（含事件序列，I31），迭代类在容差内；注册新规则时自动纳入；每个降级等级各跑一次。
- 补算测试：玩家从远处移动到某郡，比较"一直在智能层"与"统计层补算后升层"的账户总量与持有集合；离开后并回聚合，再进入不重复借出。
- 物化测试：无人押送货物送达未物化郡 → 骨架物化、聚合收货、守恒；统计层疫情 + 药材 → 康复率上升，物化后个体病例数等于子账户计数；远方钱庄倒闭 → 公共知情 → 物化掌柜的知情可溯。
- 离屏见证测试：规则层见证概率模型的立案率与智能层精确感知在容差内。
- 规模测试：现有 scale-bench 场景 + 新增"一年离屏 + 回村"的 E12 情境耗时 + 每事件谓词求值数分布。
- 存档往返：导出导入逐字节一致；分片丢失一片时报错而非静默。
