# 学科覆盖表（第六轮，2026-10-16）

方法：不再等盲题撞上空白，而是对照真实世界的学科体系逐条核对"设计里有没有这件事的形状"。每行：条目 → 第五轮设计中的落点（章节 §）→ 状态 → 本轮处理。状态三种：**已有**（第五轮已能自然得出）、**新补**（本轮加入，落点写在"处理"列）、**不做**（故意不建模，给出理由）。处理一律用已有的八概念、规则形状、钩子、视角 frame、开放性宪章表达；一个通用形状覆盖一整类，不为单题加特例。本轮新定义先登记在附录 A（§A.0 规则），正文只引用。

统计见文末。run-008 预审的矛盾 C1–C8 与建议 S1–S15 在对应行标注。
