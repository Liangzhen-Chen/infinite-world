# 环境音与情境音乐

T83 使用 `extension/ambient-audio.mjs` 在首次点击时创建 WebAudio 上下文。所有音色、旋律和噪声由该模块的确定性函数 `synthesizeLoop` 原创生成，采样率为 22050 Hz，单声道环境音循环 8 秒，音乐循环 8 至 32 秒；没有外部采样、模型生成或语音合成。素材许可登记在 `assets/LICENSES.md`，生成器随扩展代码分发，不需要独立音频文件或网络请求。

环境音由当前地点的公开名称和说明选取：河溪湖岸及湿地用水声，林地白天用鸟鸣、夜间用虫声，山地和平原用风，村镇白天加无词集市杂响。室内使用低声房间底噪，酒馆、厨房及炉灶附近加炉火；雨、风暴、雪、雾分别有循环层，室内的天气层降低音量，地下洞穴省略天气层。分类仅用于配乐，不写入世界事实。

五类原创音乐为村镇白天、夜晚酒馆、野外、地下城、战斗。夜晚酒馆优先于普通室内，地下地点优先于村镇；成功的 `combat_exchange` 回执在双方仍有生命时选择战斗音乐，下一次非交锋行动或地点、聊天切换结束战斗音乐。回合尾注的记账结算不结束战斗配乐，编辑、删除和重新生成的回滚会清除战斗配乐。配乐从当前玩家可见信息与实际行动回执选取，不从输入文本或模型叙述猜测战斗。

改变音轨时进行 1.2 秒线性交叉淡入淡出，共同音轨继续循环。重复刷新复用声源和缓冲；连续切换清理上一轮淡出的声源，切换聊天立即停止全部旧声源。主音量使用顶栏和阅读设置已有的 `volume`、`muted`；保存备份仍沿用原设置格式。开始页在“进入游戏”点击中直接调用同源宿主以保留浏览器播放授权；宿主顶栏与设置也提供“开启声音”重试入口。返回开始页停止声音，页面卸载释放上下文。

沙箱验收只运行 Node 单元与接口测试并走查调用路径。隔离浏览器实际试听、首次点击前静音、手机音量与聊天切换截图由主会话补跑 `tests/m6-09.test.mjs` 中的浏览器夹具。
