**M2 distributeStock：正负差额同时出现时，可行的输入也会误报 E-GRID-STOCK-OVER-CAP**（重点②）
- 位置：server-plugin/kernel/grid-stock.mjs:60–79。
- 反例（已实测）：两个区格 A{cap 1, S 0}、B{cap 3, S 3}，N = 1。S = 3，T = 4，E = 2，m = 2。A 的 raw = 2 超过上界 1，plus = 1；B 的 raw = −1，minus = 1。N + S = 4 = Σcap，有可行解（A 1、B 0），但代码先补 plus 时没有余量，再扣 minus 时把 A 扣到 0，最后在 :79 抛 E-GRID-STOCK-OVER-CAP。命令：`node --test F:/dnd-tmp/g6-review-distribute.test.mjs` → `fail 1`，报错文字是 "cannot balance the per-region counts within candidate limits"。不管两个区格谁排前面，结果都一样。B 这种情况（区格全被树桩、采空占满，S_c = cap_c）在砍伐之后很常见。
- 原因：截之前 Σraw 恒等于 N，截之后 Σn = N − plus + minus，真正要补平的只有净差 plus − minus。分两遍"先全补正、再全扣负"时，正的那一遍可能找不到余量，负的那一遍可能扣到不够扣。
- 正确做法：只按净差 Δ = plus − minus 补平。Δ > 0 时从区格次序末尾往前，在 n_c < cap_c − S_c 的区格里依次加；Δ < 0 时从末尾往前，在 n_c > 0 的区格里依次减。在 N + S ≤ Σcap 下可证一定补得平：Δ > 0 时剩余余量 = Σ(cap_c − S_c) − (N − Δ) ≥ Δ；Δ < 0 时 Σn = N + |Δ| ≥ |Δ|。这仍是"正负各自从末尾往前"（卷五 :911）的确定读法，次序与轮流分配不变。:79 的码改成内部不变量（到达即实现错），不报数据码。补一个测试，照上面的反例手算期望 `[{0,0,n:1},{1,0,n:0}]`。

## ③ "按常识设定"的材料值是否编数据

**判定：不是编数据，程序合规，可以保留。** 依据是卷三甲 :174 的来源级别 `designed`（"C 设计设定：basis 写一句设定依据；citation 写 null"），以及李白 11-17 的 1117p4 裁定（卷三甲 :1418）："查不到合格出处就填设定值，记 designed，basis 写参照与理由，不标 measured、不伪造出处"。写者的四布尔每格都记了 `designed`，basis 写明"设：按材料类别与物态的物理常识定（类别「…」的…栏取值）；无卷文出处的设定值，可在试玩后调"，citation 为 null，没有冒充 measured 的。这正是卷文给"没有出处"留的路，不是"没出处就造"。
