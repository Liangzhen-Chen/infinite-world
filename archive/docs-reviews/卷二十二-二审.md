## 二、真问题（残留与新矛盾）

### N1 释放后足迹仍非空：别人的知情条目以引用类型指向他（类 4，**新真问题，需报李白**）
- 位置：R22-5.7（:473）"光持有知情条目、`knows` 边不算钉住……释放后足迹为空"；`state.knowing` 版本字段（:168）；`state.publicKnowing`（:169）。
- 证据：卷二十七 R27-2.3 第 1 项（卷二十七:331）足迹含"任何以引用类型指向该 id 的路径（按 pathTypes 判定）"。卷二 pathTypes 的 id 值只有 `ref:<kind>` 一种类型（卷二:631），没有"记录性引用不计足迹"的类型。本卷别人名下的条目里，`variants[].source`、`corroborated`（:168）、命题的 `subject` 与以个体 id 为取值的 `keyBearer` 命题（:313）、群体条目中以他为当事实体的 factKey，都是指向他的引用，且都不是他自己名下的路径；`releaseKnowing` 只删他本人名下的条目。于是一个人只要向任何人说过一句话、或任何人知道一条关于他的命题，就永远钉住——与一审真问题 3 的"全员永久钉住"是同一后果，只是换了来路。作者称"靠本卷整拍边界先释放实现、未改卷二十七足迹定义"，这一点不成立。
- 可选改法（须李白定，因任一种都触及封卷或裁定③"不改足迹定义"的边界）：① 本卷容器里指人之处一律存身份键而不存 EntityId（R22-1.5 已有 `keys`，`source` 与 `keyBearer` 取值也改键），足迹自然不含；但 `keyBearer` 命题的意义就是"键连到个体"，须另想；② 请卷二 pathTypes 增一种"历史记录性引用，不计足迹"的 ref 类型（属卷二封卷改动，且实质改了足迹口径）；③ 接受这些人钉住，并在卷二十七性能登记里给上界（与秘传例外同法）。

### N2 释放与 A22-1.2"物化期间单调"冲突（类 5，**新真问题，需报李白**）
- 位置：R22-5.7（:473）释放条件"足迹除去本卷两文件所写路径后为空"；A22-1.2（:335）"持有者保持物化期间，`knowsFact(h,f,t)` 对 t 单调"；R22-9.6（:633）、R22-10.7（:674）秘传边不释放；§5.3 勘误 9（:840）"不排也成立，只是折叠晚一拍"。
- 证据：释放把"投影未覆盖"的条目并入群体后删除；此后他对该事实是否知情只看投影 `v(m,f) < share`，可能为假。释放后他若没有在同一拍被折叠，就以物化身份带着"变回不知"的读数继续存在：(a) 折叠评估排在释放之前时，至少空一拍（作者自己承认晚一拍）；(b) 持有秘传边的人释放条件照样成立（秘传边由 lore-holding.mjs 写，被排除在条件之外），知情条目被释放，而秘传边让他永远不折叠——每个整拍边界都把他新得的未覆盖条目再释放一次；(c) N1 的人同理。三种情形都违反 A22-1.2 与 R22-1.3"离开不会让他变回不知"。
- 改法：释放条件加"释放后足迹必为空"（无不释放的秘传边、无 N1 所列外部引用），否则整人不释放；并把勘误 9 由"可选"改为必需（同拍释放先于折叠，见 G7）。

### R1 T2 残留：`atMinute` 回算需要过去的锚，现文不存（类 5）
- 位置：R22-1.3（:311）"知情率是时间的纯函数，投影键不随重锚改变，可回算"；R22-5.4（:470）个别化的 `learnedAt` 回算；R22-5.2（:468）重锚覆写 `since`、`boost`、`rate`。
- 证据：键不变只解决了"谁轮到"，`share(g,f,t_past)` 仍要过去的锚。重锚后用新锚对过去时刻求值，`x′(t) = x(重锚时)+1+floor(r′(t−重锚时)/1440)`，t 早于重锚时它随 r′ 更快下降，低于当时真实进度点，回算会把当时已知判成不知（卷八b R8b-2.4"当时知不知道"即读此）。R22-5.4 "取使之满足的那次条目改写事件的时刻"同样要历史锚。重锚时的 `rateRows` 读数也无处可查。
- 建议：条目存锚段列表（只在注入、重锚、分合时追加，条数以这些事件数为界）；或把 `atMinute` 对先验域的回算明定为只用当前锚段、早于最近一次改写时刻的回算以个别化条目为准，并相应收窄 A22-1.2 与 R22-1.3 的措辞。

### R2 T4 残留：两行形态与卷二十七定义不合（类 4）
- 位置：§5.3（:821）公共知情与持有率三层 `simform_derived`；（:823）研究与谋划统计层 `simform_frozen`。
- 证据：卷二十七:266 `simform_derived`"由（种子、单元、时刻）算出，不结算、不留状态"，而 `state.publicKnowing`/`state.publicLore` 存 `since/rate/boost`，由事件改写；卷二十七:267 `simform_frozen`"仅当该系统在该层没有登记任何时钟形状的规则时合法"，而谋划系统登记了 `plot.exposeCadence` 钩子（:210、:555），:823 没写该钩子在统计层不登记。按卷二十七:268 校验会报 E-SIM-FORM-INVALID。
- 建议：公共知情行写明存储形态为 `simform_frozen`（只由事件改锚）、读数是锚与时刻的纯函数，或给出属于 derived 的理由；谋划行写明败露钩子只在个体层、规则层登记。局部措辞，不改机制。
