# 卷三甲 干基碳水、植物科 上网核对，与 class_grain 读者清单

日期 2026-11-13。只读卷三甲第五版（`卷三甲-物质本源.md`）、卷三乙第五版及相关各卷，不改卷正文、不跑脚本。外部数据全部经网页抓取、由摘要模型读出，个别格可能读错；每格注了出处条目号，入卷前按条目号逐格复核。USDA FoodData Central 接口当天仍限流（HTTP 429），USDA 数改从转载 USDA SR Legacy 的页面取（nutritionvalue.org、getfoodfacts.com），注 FDC 号，标"转载"。

## 口径

- **干基碳水** = 总碳水（差减法，含纤维与糖）÷ 干物质。食物成分表给的是每 100 克可食部，按"碳水 ÷（100 − 水分）"折成干基，这一步是我按出处重算的，注"重算"。饲料表给 % DM 而没有碳水栏的，按"100 − 粗蛋白 − 乙醚浸出物 − 灰分"差减。
- 酒、醋、烧酒、马奶酒的"干物质"按卷三甲的含水率口径取"100 − 水分"，**酒精、乙酸算在干物质里**（同表干基饱腹的口径一致）。
- **淀粉**只在出处有数时另列；没有就写"无数据"，不推。
- 依据代号（建议入卷时用）："碳:食" 食物成分表重算；"碳:饲" 饲料表差减；"碳:定" 按定义（不含有机碳水：盐、纯油脂）为 0，并附一个同类实测为 0 的出处；"碳:未核" 未核到，留空按未知，不填数。
- 换算：入 `nutrients` 时值 = 1000 × 干基比例 ÷ `nutr_carb.refAmountG`。`refAmountG` 本文件不定；`daily_ref_per_kg_dry` 标了 `calibrate:true`，调标定会改变阈值 0.55 换算出的意思（`审查/卷三-谷物淀粉条件上网核对.md` 3.4 第 4 条），建议谷物条件读换算前的质量比例。

出处缩写：
- FAO-EA = FAO《Food Composition Table for Use in East Asia》（1972）。各组页：X6878E04（蔬菜）、X6878E05/E06（菌、芥菜）、X6878E10（糖、肉、血）、X6878E12（蛋、鱼）、X6878E16（乳、油脂、饮料）。栏目原文"Carbohydrate, total (incl. fiber)"。网址 https://www.fao.org/4/x6878e/<页名>.htm
- FP = Feedipedia（https://www.feedipedia.org/node/…），Main analysis 表，% DM。
- USDA-SR = USDA SR Legacy（转载页，FDC 号见行内）。
- 种子行的数取自同目录 `审查/卷三-谷物淀粉条件上网核对.md` 第二节（Feedipedia），本文件不重抓。

### 竹的评估

竹是禾本科，**只凭科这一条会过**，但它被其余条件稳稳挡住：
- ① 本源成分是 `subst_wood`，不是草本植物质 —— 不过；
- ② 部位是 `ppart_stalk`（竹秆）—— 不过；
- ③ 不挂 `comp_edible` —— 不过；
- ⑥ 竹不可食、也不满足 `byDigestible`，营养维度不必填，碳水留空按未知 —— 不过（未知不进候选）。
四条独立地把它排除，不靠科。以后若加竹笋（可食、草本、部位茎）也因部位出局；若加竹米（竹的种子），按六条加科判谷物，这同实际一致（竹米是禾本科籽粒）。秸秆同理：禾本科、碳水 0.88 过线，但不可食、部位是茎，出局。

## 五、需报李白 / 作者注意

1. **第 ⑥ 条对非种子不起作用**：总碳水差减法把纤维算进去，干草、秸秆、落叶、茶叶都过 0.55，鲜菜干菜跨线。它们靠 ② ③ 出局，结论不错，但卷三乙说明里不能写成"碳水把叶茎挡住"。
2. **"主食类"与"含淀粉类"不该改读同一个东西**：主食看"可食、顶饿、碳水高"，应包括非禾本科、非种子的料（薯、芋）；制醪看淀粉。若改读淀粉，需先登记淀粉条目，眼下有淀粉数的只有 4 行。
3. **大豆的去向连带三处**：卷二十五:644"大豆可作主食一份"、:681"大豆也能下曲制醪"、卷三乙 Q-37 的结论；随规则改读实际维度后，大豆能不能入仓、制醪由维度另算，不再自动跟着谷物。
4. **鲜菜三行记十字花科是有条件的**：依据只是数据来源都是芸薹属；内容卡若定为泛指蔬菜，按"来源不唯一"改 unknown（对谷物结论无影响，三行都在 ② 出局）。
5. 未核到：醪、月华浆果的碳水；干草、落叶、夜帽菇、月华浆果、沼泽树皮的科记 unknown。
