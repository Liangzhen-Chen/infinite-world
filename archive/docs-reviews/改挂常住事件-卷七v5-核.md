## (4) 偏离与离场

- **收起不发事件本身正确**：没有新位置，卷十八义务明文不发；卷十九 :748 也照写。不算偏离。
- **离场期间 L 的取法——判为真问题（局部）**。理由，按现文逐条推：
  1. 收起只要求“内部无人”（卷十九 :742），常住边不解除，住户的常住标的在离场子树内；
  2. 卷五 §4.1 规则 8（:324）：离场行的 `tree.ancestors` 为空、后代行的上溯到离场那一行为止，所以 R7-24.6 首段的上溯走不出离场子树；
  3. 首段“一直到根都没有时取根”在这里有两种读法：取真根（L = 全世界居民文化众数），或取上溯链顶的建筑行（其 `culture` 按卷五 §4.12 规则 1 是自家居民众数，通常 L = B）；
  4. 收起期间若遇 `yearAnchor`，① 按读法二删记录、按读法一多半把记录换成别的文化并 `level` 归 0；展开后改挂事件再核，就算回到同一文化的站点也只能从 0 起。
  结果：游牧住户的融入度是否被清零，取决于 `yearAnchor` 是否恰好落在拆帐赶路那几天——同一行为两种结局，规则本身又没定读法（两读者实现会不一致）。这不是只靠记账的措辞项：首段对离场子树没有定义，影响记录取值。
  - 性质：只在卷七内、不牵连别卷、不需新设计种类，属“二审后仅剩局部矛盾”；按二审余项常规可直接只改 R7-24.6（首段或 ①②）一处写明离场期间怎么办（例如“常住标的在离场子树内时，① 不核、② 本次跳过，记录原样留到改挂事件来核”，或作者另给有理由的写法），再单核。
- 离场期间住户随之“离场”时，卷七 L 不必另加事件：展开那次的改挂事件就是重核时刻，前提是上一条把离场期间的读法定下来。不另算新缺口。
