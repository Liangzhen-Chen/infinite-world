## 三、真问题（4 条，建议改完再收）

**R-1 §3.1 第 3 条仍把 `npcs.*.name`、`created.*.nameParts 拼装结果` 当 display 路径举例**（卷一:348）。这与卷一:416、585 以及卷二v4:386 矛盾（npcs 的 display 为空，nameParts 是代号数据且进哈希）。改为只举 `displayNames.*.text` 或直接删去举例。

**R-2 输入边文件清单与显示层组的 glob 会重叠，且超出卷二 inputEdge 的写法。** 卷一:242 把 `extension/input-view.mjs` 列入 `inputEdge.modules`；而卷一:206、卷二v4:399 的显示层组含 `extension/**/*.mjs`，按"互不相交"（E-GROUP-OVERLAP）会冲突。卷二v4:398 的 inputEdge 只写了 `server-plugin/input/*.mjs`，G4/V-21 也只删这个目录（卷一:714），extension 里的键入提交部分删不删没有说清。建议：键入提交部分也放 `server-plugin/input/` 之下，或在显示层 glob 里显式排除它，并在 V-21 写明删除范围。

**R-3 §3.2 排除清单与卷二的扫描排除范围不完全对上。** 卷二v4:1203 的规则层扫描排除 `inputEdge / display / gate / outputGate` 四组；卷一:355 的五组（输入边、显示层组、aiGate、显示闸、语言包数据）没有 `gate`（门禁与扫描模块，卷十二）。卷一:367 只说明它不是显示闸，没有说它在不在排除清单里。需要明确：门禁扫描模块是否排除（建议排除并列为第六组，增项须李白批，并给扫描条），否则"只不作用于五组"与卷二的"四组排除"互相矛盾。另，卷一:355 表头仍写"（第三版现状）"，应改为"第四版"；显示层组其实仍被扫判断（卷一:360 同行已说明），但标题"不作用于"字面上与之冲突，建议改成"不作用于规则层扫描、另按各自扫描条"。

**R-4 blocklist 的位置在卷一内部行文自相矛盾。** 卷一:212 同一句里写"语言包数据 `world/meta/blocklist.json`（按语言分节）"，又写"现 `world/meta/blocklist.json` 的 names/realPeople 迁入，按语言分文件"，"分节"与"分文件"矛盾，且路径与自己迁入的来源路径相同。卷一:137 与卷一:774 ⑤ 已把位置交给李白定，正文 212 行应统一成一种说法（待李白定之前写"按语言分节，位置待定"）。
