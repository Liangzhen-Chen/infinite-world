## 六、问题

### 真问题

1. **天劫、异象、疫病钟三类表 C 行只补了 C24-12 所列六栏，表 C 另几个 onUnknown 为 error 的栏没写。** 涉及卷十五 R15-16.5、卷十六 R16-14.1、卷二十一 R21-10.6 与数据实例 `etype_outbreak`。
   - 卷二十四表 C 定义：`startVerb`、`stageVerb`、`endVerb` 的 onUnknown 为 error，取值只许是 `kindOnly` 行（E-EVT-EMITTER）。R24-4.1 规定每个实例的起始事件都以该行 `startVerb` 填载荷 `kind`；表 C 说明写明子类型动词“由登记该 `event_type` 行的卷登记为 `kindOnly` 行”。
   - 三卷都没有写这三栏，也没有登记对应的 `kindOnly` 子类型动词行。`mode`、`polarity`、`scopeKind`、`stageFlow`（含各段 `pace`）同为 error，也未写。卷二十一自称“取值照卷二十 §4.9 规则第 9 条灾异行的同类取值”，规则第 9 条恰恰包括这几栏和三行 `kindOnly` 登记，现只照了六栏。
   - 这是表 C 必写栏、不补即加载失败的同一类，按“收卷前清同类”应同批补。`check-verb-emitter` ③ 段只核 C24-12 六栏，所以它报“齐”覆盖不到这几栏。补法照卷二十 §4.9 规则第 9 条整类写：各行写 `mode`、`polarity`、`scopeKind`、`stageFlow` 的取法；三栏各引本卷登记的 `kindOnly` 行；`kindOnly` 行的表 B 栏照规则第 9 条末段。另须在卷二十四 C24-12 的名单里写明表 C 应补的栏不止六栏。
2. **“写者在动作事务内连带发出”这一类发出点，感知栏在同批里判成了两种结果。**
   - 判假的（按卷十八 §2.3 ③“另一笔写入的连带处置”，与李白已裁的卷十八持有变化、常住变化两行同口径）：卷二终止、复生两行；卷二十一状态出现、换档、移除三行（伤病多在攻击等动作的事务里写入）；卷二十二 `verb_fact_learned`（`noteKnowing` 写知情时连带发出，转述动作事务里同样调用）。
   - 判真的（理由是“在某动作的裁决事务里调用”）：卷十七 `verb_subject_tract_changed`（`placeSubject` 是落位写者，与卷十八常住变化随 `relocate` 发出同型）；卷十五 `bodyPlanChanged`（R15-14.1 写明它经 §3.3 唯一写者路径同事务发出）；卷十六 `transformed`（转化原语的输出）；卷十四 `skillGained`（`gainSkill` 是 skill.mjs 写入口，与 `noteKnowing` 同型）。
   - 判据 ① 的括注“或写在某动作的裁决里”与 ③“写边、写记录时连带发出”在“写者被动作事务调用”时重叠。同批两种判法并存，就是一类按两种口径落值。须在卷十八 §2.3 判据处写一句定下这一情形（按已裁的 R18-1.11 先例应归 ③），再把上面判真的四行按同一口径改。若要改归 ①，则判假的各行一起改。
3. **卷十四以“条文未写成动作”判假的几行，与卷九 NPC 决策管线矛盾。**
   - 涉及 `practiceStarted`（`takeUp`）、`practiceEnded` 的 `giveUp` 发出点、`focusChanged`（`setFocus`）、`perkTaken`（`takePerk`）。
   - PF-3 写明居民的 `takeUp` “由卷九 §4.12 的决策管线发起”。卷九 R9-12.2、R9-12.7 的候选都是动作代号，决策管线只选动作。卷九卷首也写“一个意图怎样变成世界里的一次改动”经动作目录。所以“是意图，故非动作”的理由不成立。
   - 卷十八判据 ③ 列举的是固定刻、到期项、订阅、不需在场的合同履行、推断、连带处置，没有“意图”或“未写成动作”这一项。把这些行取假，等于给判据加了一条缺省分支。
