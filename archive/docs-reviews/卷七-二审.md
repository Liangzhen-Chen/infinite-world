## 四、新真问题（均为“新真问题，需报李白”）

### N1【类5/类4】融入度的写入时刻有缺口，合法存档可能被加载拒收 —— 新真问题，需报李白
- 位置：R7-24.6 ①③（第 1340 行起）；E-CULT-INTEG-RECORD（§2.8）；A7-24.2；S7-5 豁免句。
- 证据：① 只在“p 迁居的事件”与 `yearAnchor` 前核记录，③ 写“只两种时刻写”。但 (a) 全书没有登记“迁居事件”（卷五 §4.1.2 常住是关系 `rel_residents`，卷五、卷八、卷十八、卷二都搜不到此事件）；(b) 常住地点的主文化会因居民变化在任一调度日改变（卷五 §4.12 规则 3 发主文化变化事件），本卷没有订阅，S7-5 豁免句却说“当地文化变化时据此重置”。结果：年中当地文化变成本人文化或换成第三文化后，记录在到下个 `yearAnchor` 前一直与现状不符，违背 A7-24.2“任一时刻……当且仅当”，此时存档再载入会被 E-CULT-INTEG-RECORD 拒收。
- 建议：① 的触发改为“p 的常住关系变化（写明由哪一卷哪个写者发什么事件，或请其登记）”加“订阅卷五 §4.12 规则 3 主文化变化事件（对该地点常住者）”；或把 A7-24.2 与 E-CULT-INTEG-RECORD 改为只在写时刻后成立、读者对不符记录按“无记录”处理。二选一。

### N2【类1/类5】“常住地点的文化”没有指明读哪一级地点，按卷五口径会读到移民自家住房，机制不生效 —— 新真问题，需报李白
- 位置：R7-24.6 首句 “常住地点的文化为 L（卷五 `placeView().dims.culture`）”。
- 证据：卷五 §4.12 规则 1 写明“居民通常挂在房屋或分区上”，地点文化取本行及后代常住居民的众数。全家迁居者常住的房屋，其文化就是自家文化，L = B，永远不建记录；例中“迁到河谷城”默认读的是城一级，正文没写。这与一审对出生文化所提的 `birthplaceClass` 粒度是同一类问题。
- 建议：在 §2.6 加一个地点层级键（如 `culture.integration.placeClass`），L 取常住地点沿包含树第一个该类祖先的文化；例与 A7-24.2 写明。

### N3【类5】速率钳到 1 时 `level` 会等于上限，与取值域 [0, cap) 矛盾 —— 新真问题，需报李白
- 位置：R7-24.6 ②（`k = clamp(…, 0, 1)`）；§2.6 `kYear`、`kContact` 取值域 [0, 1]；E-CULT-INTEG-RECORD、A7-24.2“`level` 恒在 [0, cap)”；R7-24.7 末句“两者都落在上限上时清零”。
- 证据：k = 1 时增量 = cap − level（无截断余量），一年即到 cap，运行中产生加载会拒收的状态；R7-24.7 末句又承认会落在上限上，与“永远到不了 cap”自相矛盾。自检第 14 项只测默认小速率，没覆盖。
- 建议：k 钳到 [0, kMax]（kMax < 1，进规则表）或加载校验 `kYear + kContact < 1`；删 R7-24.7 末句，或把取值域改为 [0, cap] 并删“到不了”的说法。

### N4【类4】价值混合修正项的值，按卷二 §3.2 写不出来 —— 新真问题，需报李白
- 位置：R7-24.8。
- 证据：修正值 = `level × (L.values[v] − B.values[v])`。卷二 §3.2 规定 `valueRX` “只能经 dim() 读来源与对象的基值”；`level` 不是个体维度而是本卷状态记录，`B.values` 是“对象的文化行”的维度（两跳），都不在 dim(来源/对象) 之内。作用域 `integrated` 只解决“谁吃到”，不解决“值多大”。R7-24.8 没写由谁、以什么形式生成这条修正项。
- 建议：照 R7-11.2 做法，由 integration.mjs 作声明写者，在每次写记录时按当刻 level 计算定值，提交/替换一条 `scope: self`（或 `integrated`）、`value` 为定值的修正项，写明去留；或在 §5.2 请卷二放宽 `valueRX` 可读源（会动已封卷，需李白定）。
