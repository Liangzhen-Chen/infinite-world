1. **只读本事件自身载荷字段**：§4.4.1 字段表 `payloadIf` 行与 §2.4 变量表新行都把可读变量定为封闭集 `event.<字段代号>`，范围是卷二十四表 A 公共载荷字段（`place`、`related`、`causedBy`）与该动词行 `payloadShape` 所列字段，"只取字段值本身，不经它读所引实体的任何状态"。读法限定：§2.4 表头已规定本卷一切 rx 只用"数值、维度叶、四则、比较、逻辑"，不调方法，变量由入口在求值前绑定；`payloadIf` 行又限为"字段代号与比较值、可用逻辑连接"。所以 `dim`（他实体维度）、`agg`、`clock`、`ns` 都在许可集之外。机判：E-STANCE-SOURCE 加了"`payloadIf` 读了本事件载荷字段以外的变量"。读法已限定，不是真问题。
2. **不读别的状态、不读文字**：写明"不读别的状态（不取所引实体的维度、关系或立场），不读文字"。`applies` 原有限制没有改。
3. **不加别的新栏**：diff 只加 `payloadIf` 一栏；三个事件行数据实例补 `"payloadIf": null`，结果不变。读数公式、其它字段都没动。
4. **可空与卷二 §1.6 一致**：类型是 `rx nullable`。事件行必写，不设缺省，引用了卷二 §1.6；写 null 表示"该项不设限"；静态行不写。三种违例（事件行缺、静态行写、越界读）都进 E-STANCE-SOURCE。R18-4.2 写成"`payloadIf` 为 null 或为真"，空即无条件。所读字段为空时条件不成立，这是写明的求值规则，不是常量兜底，与卷二 §1.6 `gap` 的"比较时不进入候选"同向。
