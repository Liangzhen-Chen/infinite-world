# 卷三 谷物“以淀粉为主”条件 上网核对

日期 2026-11-13。只读卷三甲第五版，不改卷。外部数据全部来自 Feedipedia（FAO、INRAE、CIRAD、AFZ 合办的饲料成分库，卷三甲已在用）与 Britannica；USDA FoodData Central 的接口当天限流（HTTP 429），没取到数，本文件不引 USDA 数。数据由网页抓取后经摘要模型读出，个别格可能读错，下表每行注了节点号，入卷前按节点号逐格复核。

## 一、卷三甲现有营养维度（第 1 问）

| 查的内容 | 卷内位置 | 结论 |
|---|---|---|
| `nutrients` 字段口径 | §2.1 第 144 行；§4.4 第 380 行 | 类型 `map<nutrient 代号, number>`，单位 `daily_ref_per_kg_dry`：每千克**干重**含成人日参考量几份，一份 = 该条目 `refAmountG` 克（§2.3 第 187 行，单位标 `calibrate:true`）。整张映射一律干基 |
| `nutrient` 词表族 | §2.2 第 163 行 | 文字写了“蛋白、脂、碳水、盐分及卷二十一要求的微量项”，条目由卷二十一 §4.4 提需求、本卷登记；**实际只登记了盐分一项**（`nutr_salt`，`refAmountG` 5）。全卷与整个《统一底层设计》目录里搜不到 `nutr_carb`、`nutr_starch`、`nutr_protein`、`nutr_fat` 一类代号 |
| 是否区分淀粉 | 全卷 | 不区分。没有淀粉条目，“碳水”也没有定义是差减总碳水、可利用碳水还是淀粉 |
| 材料行的数 | §4.5.5 材料表（第 459 行表头）；§4.4.5 例 1–4 | 营养素只有“盐分”一栏；粟、麦、大豆三行的 `nutrients` 只有 `nutr_salt`。碳水、淀粉、蛋白、脂肪在材料表里**都没有数值** |
| 与之相邻的现有维度 | §2.1 第 141、142 行 | `energyDensity`（干基总能）、`fiberContent`（干基粗纤维）。第 443 行“能:食”依据写明总能是由成分表的蛋白、脂肪、碳水折出来的，但折算用的成分没有存进表 |

**结论：现有维度没有可读的碳水项，更没有淀粉项。按裁定落地“以淀粉为主”，需要先登记碳水（或淀粉）条目并给全部可消化材料行填数，这是加词表条目、加数据，需报李白。**（卷二十一 §4.4 是条目的提需求方，也要牵连。）

## 二、种子的干基成分（第 2 问）

口径：全部为 % 干物质（Feedipedia 的 Main analysis 表；格式“均值（最小–最大，n）”）。
- 蛋白 = 粗蛋白，脂肪 = 乙醚浸出物，淀粉 = 旋光法淀粉（另注者除外）。
- **总碳水**按差减算：100 − 粗蛋白 − 脂肪 − 灰分（含纤维与糖，与 USDA“Carbohydrate, by difference”同一算法）。表里另列“去纤维碳水”= 总碳水 − 粗纤维，供碳水条目若定义成可利用碳水时参考（粗纤维低估膳食纤维，这一列偏高）。
- 总碳水是我按均值算的，不是出处直接给的数。

## 三、能不能分开（第 3 问）

### 3.1 写法甲：“碳水是干物质里最大的组分”

- 用**淀粉**比：谷物各行淀粉都远大于蛋白和脂肪（带壳燕麦最紧：40.6 对 11.0，区间下端 28.6 对上端 14.7，仍分得开）；非谷物各行淀粉 1.3–6.4，都远小于蛋白或脂肪。分得开，两侧都不贴线。
- 用**差减总碳水**比：大豆一行不稳。均值是蛋白 39.6 对总碳水 33.3，只差 6.3；按区间，蛋白可低到 35.3，总碳水可高到约 43.7（100 − 35.3 − 16.6 − 4.4），两者能翻过来，大豆会被判成“碳水为主”。别的非谷物脂肪都在 46 以上，不会翻。
- “最大组分”只比相对大小，不要阈值，但碳水条目若是总碳水，大豆这一格就落在误差里。**不建议用总碳水做“最大组分”判。**

### 3.2 写法乙：“碳水占干物质比例 ≥ 阈值”

**用差减总碳水：**
- 谷物侧最低：黍 76.2（裸燕麦 79.4，粟 79.6）；非谷物侧最高：大豆 33.3（向日葵 32.6）。间隙 33.3–76.2，宽约 43 个百分点。
- 最坏情形（每个组分各取对自己不利的区间端，几乎不会同时出现）：黍约 62.8（100 − 17.2 − 11.1 − 8.9），大豆约 43.7。间隙仍有 43.7–62.8。
- 建议阈值 **0.55**（两侧均值的中点 54.75 取整）。离线距离：黍 +21.2、大豆 −21.7；最坏情形下黍 +7.8、大豆 −11.3。各行组分的文献区间一般使总碳水上下浮动 5–10 个百分点，比离线距离小。
- 碳水条目若定义成**可利用碳水**（去纤维）：谷物最低带壳燕麦 66.7、黍 68.8；非谷物最高大豆 27.1。中点约 0.47，取 0.5 也两侧各留 17 以上。

**用淀粉：**
- 谷物侧最低：带壳燕麦 40.6（区间下端 28.6）；其余谷物均值 ≥ 57.9，区间下端 ≥ 52.2。非谷物最高：大豆 6.4（区间上端 10.2）。
- 间隙按均值是 6.4–40.6，按区间端是 10.2–28.6。
- 建议阈值 **0.2**（区间端 10.2 与 28.6 的中点 19.4 取整）。离线距离：带壳燕麦均值 +20.6、区间下端 +8.6；大豆均值 −13.6、区间上端 −9.8。只有带壳燕麦的下端离线不到 10，这是带壳整粒（壳占重量约四分之一）把淀粉稀释了；去壳燕麦 61.2 不受影响。

**两种写法都分得开，阈值写法比“最大组分”写法稳。** 总碳水 0.55 的间隙最宽；淀粉 0.2 的意思最贴裁定的“以淀粉为主”，但带壳燕麦离线最近。

### 3.3 伪谷物按规则落在哪侧

荞麦、藜麦、苋籽的总碳水 71.9–81.3、淀粉 55.0–61.6，都在谷物一侧，比带壳燕麦还靠里：**按“以淀粉为主”这一条，它们判谷物，靠碳水分不出来。** Britannica 的定义里另一半是“禾本科”，伪谷物不是禾本科；若要把它们排除在外，靠的是来历（科属）的代号，不是成分，现有的五条件和这一条都读不到科属。是否要排除，需报李白。

### 3.4 需报李白

1. **现有维度没有碳水项**：`nutrient` 族只登记了盐分；材料行没有碳水、淀粉、蛋白、脂肪的数。要落地这条，至少要：在 `nutrient` 族登记碳水条目（定清是差减总碳水、可利用碳水还是淀粉，并给 `refAmountG`；需求方是卷二十一 §4.4），再给全部可消化材料行补数。这是新增条目与数据，按决策边界需报。
2. **用哪种碳水**：总碳水阈值 0.55 间隙最宽；淀粉阈值 0.2 语义最贴裁定。“碳水为最大组分”在总碳水口径下大豆不稳，不建议。
3. **伪谷物**：按成分规则判谷物；要排除只能加科属一类的来历代号。
4. 另记：判读时要把 `daily_ref_per_kg_dry` 乘 `refAmountG` 换回干基质量比例，而这个单位标了 `calibrate:true`。若以后调 `refAmountG`，阈值换算出来的意思就会变；建议规则直接读换算后的质量比例，或另设一个不随标定变的比例字段。
