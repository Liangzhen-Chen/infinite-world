## 3. 关键接口与不变量
- stockSupply / budgetStock / upkeepDemand / householdResources（household-budget.mjs、household-subsistence.mjs）：同户同货只算一次；市场需求 = 户内缺口 − 家户自采能覆盖的量；upkeep 类（柴、盐）的需求只出自 upkeepDemand，retained 不再含 upkeep 部分（c201c099）。
- changeItems / engine.itemDelta / BOOKED（items.mjs、engine.mjs:637、stock.mjs:102-125）：itemDelta 只是 changeItems 的公共入口。books 为已记账标记时不再写账本。**本轮变化**：bookStock 判定从 `books===BOOKED`（引用相等）改为 `books?.booked===true`，新增 `bookedBy(writer,purpose)`（带标注的已记账标记）。原因：旧写法下，BOOKED 加 writer 会被当成"有 writer 但无对方账户"→记未入账漂移。money.mjs 自己的 BOOKED 未动。
- harvestForest / siteTake（forest-water.mjs、sites.mjs:457）：来源写入者把货从林木/据点账本记入 `to`（取货人行囊账户），守恒本身在这里成立；调用者随后只做旧字段（行囊 inventory）的同步，books 必须是已记账，否则重复记账。siteTake 的 settledAt 保证日末结算不使账本时间倒退。
- spent.materials（npc-labor.mjs）：行动记录里列出该次制作/加工真实扣的料（item/amount）；加工行程也算。
- 不变量：账本顶层字段集合不增不减（S5F-7）；Σ各账户 = 来源 − 汇；bag 账户与旧字段 inventory 逐项一致；日用自给取货时间只占在家工作日内时段，不与劳动/睡眠重叠。

## 8. 本板块行为链与不变量（后续批次沿用）
行为链：家户成员与库存 → householdUsage（item-class.mjs，唯一一份用度定义：燃料按户按日克数随季，盐按人）→ npc-life householdUpkeep 每日从户内持有扣整份，不足一份记欠量，手里没有记短缺日 → 短缺日/欠量折成 upkeepDemand（household-budget.mjs）→ 市场（market.mjs）把缺口变成采买需求，价格随稀缺升降，同户同货只出一条需求 → 劳动（npc-labor.mjs 行程与加工，记 spent.materials/fee，占工时）→ 资源采集（household-subsistence.mjs 的 upkeepTrips：在家工作日内的时段，经 harvestForest/siteTake 从林木/据点账本取货入取货人行囊，日末结算）→ 回到库存。
本板块不变量：
- I1 同户同货需求只算一次；upkeep 只由 upkeepDemand 表达。
- I2 所有货只经"来源写入者记账 + 行囊旧字段同步"进入行囊，BOOKED 一边不重记；任何新增的家户入库必须带 writer/purpose 标注（bookedBy 或 books.writer）。
- I3 不按物品/聚落/NPC 写特判；燃料选择只按 item-class 与 usageCost。
- I4 行动记录 spent.materials 与 fee 是真实扣量，库存变化 = 行动记录 + 家户用度 + 交易/转移，三者合起来才与库存变化守恒。
- I5 无关住户不被扰动：取货只影响本户成员的行囊、时段与对应来源账本。
- I6 性能：用度/旅程备忘按库存签名失效，不退化为每日全户重算。
