## 3. 规则口径

- 整类、无特例：capacitySource 按组件类有序首匹配，对一切非个体承载者同一；有效身体图读法对一切个体同一；`rewriteSpecies` 不按物种分支。通过。
- 常数：M-7 的 ÷10000 是 bps 单位换算，非规则常数。通过。
- 正文实例代号：`comp_vehicle`、`comp_container` 只在 §4.6.5 示例块。通过。
- 空值：`bodyPlanOverride` nullable、`tissueDelta` never/skip、M-2 无匹配 gap、B-9 三处皆无 gap、M-7 无步态返回确知 0。通过。
- **问题一（真问题）M-7 `typicalSpeedOf(engine, speciesId, gaitId, loadRatioBps)`"纯函数，不读 state"超出所请且有缺口**：所请只是"不要求实体"。本卷 `speciesView(engine, state, speciesId)` 带 state；卷十六 R16-12.2 的变体物种行可在运行期经写回器建行（卷十 :268 第 0 日后物化的行在 `state.created`），不读 state 读不到这类物种行。应改签名带 `state`（仍不要求实体），§3.3/§5.1/§5.4 卷十七行同改。
- **问题二（真问题）类型不复用卷二**：§2.5 `capacitySource: list<struct{class: ref class, dim: ref dim}>`，示例值 `comp_vehicle`、`comp_container` 是卷二 §1.8 独立的 `component` 族（`comp_`，与 `class` 族 `class_` 分开登记，XA-N5），`ref class` 收不了它们。应写 `ref vocab component`（或卷二 `classes` 的 `ref refs[vocab class, vocab component]`）。同类旧账：本卷 `rules.death.corpseClass`、`rules.life.birthplaceClass`、`rules.chargen.playableClass` 都写 `ref class` 却指"组件类"（:254、:262、:264、D-4 :787），须同批清。
