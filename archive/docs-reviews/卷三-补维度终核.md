## 三、作者自定的三处

1. **承力四项的必填条件改由物品一侧决定（I-7）：合理，采纳。** 形态既然不在材料层，“该不该填”只能由物品判断。这是裁定的必然结果，不属于另起炉灶。跨表必填条件的写法卷二还没有，已列入 Q-26 请卷二回填，接口闭合。
   附带后果，记账、不返工：凡是成块的食物、药饼、香饼（例如 731 行砖茶、733 行灵香），它们的材料都要填 `wearResistance`（缺了报 error）、锋利上限和防护系数。从物理上说这些值都存在，填上不算错，但内容量会明显增加。建议迁移卡用强度量表批量给出初值，不为此改规则。
2. **材料组条目加 `structural`：合理，采纳。** 它是 `matgroup` 词表条目上的布尔字段，没有写死某个 id；“装填为假”是一条通用规律（装在里面的料不承力）。与 M-1、T-7 的取组方式不冲突：T-7 碎片取外壳组，`fragmentFactor` 取装填组。
3. **到达分解点后只按热损处理，不自动炭化（T-4）：方向合理，采纳。** 炭化走配方，避免出现第二条产炭通路；木、竹的燃点高于分解点，按现规则会先受损、再起火，次序正确。
   遗留一处现实缺口，记账：被火烧毁、但没有烧尽的木器只能留下 `rawForm` 或灰，永远留不下焦炭。日后可以在规则层加一条通用规律：“因到达分解点而毁坏的那份材料，残余取 `reactionProducts[charReaction]`”。这只读维度，不点名任何物品。本次不要求改。

另有一处与第三条相关、由第五版带出的漏洞，见新真问题 N-2。

## 四、十六项“成分大类”仍手写，算不算例外

**判断：字面上不违反裁定，实质上构成例外，需报李白。**

- 字面上：裁定管的是 `class` 族类别和“新增大类”。`categories` 是材料的属性维度，地位和 `density` 相同，手写不违反“class 族一律派生”。
- 实质上，有两点：
  ① 十个材料大类类别（`class_metal`、`class_wood` 等）是由 `categories` 经 `materialClass` 一对一换名得到的（571 行）。所谓“派生”只隔了一层：手写 `matcat_metal`，就等于手写 `class_metal`。
  ② M-9（539 行）规定“此后新增的顶层大类一律派生”，老的十六项仍旧手写。这是新旧两套规矩并存，属于按出现先后豁免，正是李白说的“例外”的形态。
- 十六项内部也不纯，有两项本身就不是“成分”：
  - “液体”是物态，与派生的 `class_liquid` 重复，还可能相互矛盾。
  - “超自然”说的是来源，不是成分。

  后果已经出现：779 行釉瓮写的是 `accepts:[matcat_liquid,…]`，而鬼火油（1189 行）的大类是蜡脂，常温为液，这只瓮装不了油。这一条见 N-3。

**由维度推出的可行性（建议方案，供李白定）**：可行，约需补 3 个维度，再加一条读关系。

| 大类 | 推法 | 需要的维度 |
|---|---|---|
| 液体 | **删去这个大类**，各处改读 `class_liquid`（常温物态已经能派生） | 无需新增 |
| 炭质 | 已派生 | — |
| 金属 | 金属性：导电率或延展性过阈值 | 新增 `electricalConductivity`（或 `malleability`），数值 |
| 木质、植物、谷物 | 生物来源为植物，再按组织部位区分：木质部 → 木质；种子且淀粉过阈值 → 谷物；其余 → 植物 | 新增 `bioOrigin`（矿物、植物、动物、菌，固定代号），新增 `tissue`（木质部、纤维、种子、叶、皮、肉、骨角、脂，固定代号） |
| 肉类、骨角、皮革（生皮）、蜡脂 | 生物来源为动物或植物，加组织部位；蜡脂也可以改为按脂质含量过阈值 | 同上 |
| 石质、矿物、玻璃 | 生物来源为矿物、不是金属，再看是否为非晶：非晶 → 玻璃；聚集按物品的 `bulkForm`，所以石与矿不必拆成两个大类，可合并为“矿物”，或者另立“岩”并加孔隙度阈值 | `bioOrigin`；新增 `amorphous`（布尔） |
| 皮革（鞣制后）、织物、纸、陶瓷 | 这几项本质是**加工史**，由“是某个反应的产物”推出：鞣制 → 皮革，纺或织 → 织物，造纸 → 纸，烧成 → 陶瓷。读 `reactionProducts` 的反向关系；反应词表已有鞣制、纺、织，还需补“造纸”和“烧成” | 无需新维度；需在 `reaction` 词表补两条 |
| 超自然 | 交给卷十五：由该卷登记的超自然组件类是否存在来推出 | 无需新增 |

代价：材料的大类要读别的材料行的反应产物关系（清单丙当时就因为这个代价没有选它）。另外，成分大类全部改为派生以后，`categories` 就成了纯派生字段，卷二 §5.2 中这一行要改成 derived。

建议分两步。第一步先删“液体”大类，这一步零成本，并顺带解决 N-3。第二步一并补 `bioOrigin`、`tissue`、导电率、`amorphous` 这四维，以及反应产物反查，这一步交李白定。
