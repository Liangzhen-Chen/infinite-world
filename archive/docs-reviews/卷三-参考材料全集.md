# 卷三 参考材料全集（李白·卷三终核2 裁定：先列全集，再改）

对象：`卷三-物品与材料.md` 第六版（现行）的材料层派生规则，以及收尾待办里已裁定要加的三处（N2-2甲 补本源成分词条、N2-3 蜡脂加热值下限、N2-4 补延展性并改锻料选法）。
核对脚本：`F:/dnd-tmp/vols/check-卷三-全集.mjs`（只读两份文档，只打印结果；结果贴在本文件末尾）。

## 一、口径

1. **取值来源**：常见物性手册量级（熔沸点、密度、热值、含水率按食物成分表折干基）。卷三例 5 已有的 27 种材料沿用卷三的例值（松脂热值 30、鬼火油热值 2 等），只给岩盐按终核2小项3补了"可食、盐分"。数值是标定参考，不追求小数位。
2. **列了哪些维度**：凡是有派生规则会读的维度全部列出（本源成分、组件类、熔点、沸点、分解点、热值、含水率、干基饱腹、盐分、韧性、延展性），另列密度、燃点、硬度、易燃度作物性参照。其余现行维度（六类强度明细、防护系数、导热、营养其余各项、反应产率等）不进入任何类别派生，本表不列（**偏离指令"各维度取值"之处**，理由：列了也不影响任何一条核对结果）。
3. **单位**：密度 kg/L；热值 MJ/kg 干重；温度 ℃；含水率 0–1；干基饱腹按 **1 satiety = 1 MJ/kg 干重** 折（卷二 `_units.json` 里 `satiety` 标了 `calibrate:true`，卷三没给标定；本表按能量计，见第六节对谷物阈值的影响）；盐分 = `nutrients` 的盐分项，单位 `daily_ref_per_kg_dry`（成人日参考量取食盐 5 g，纯盐 = 200）；硬度、韧性、延展性为 0–100 分。
4. **组件类缩写**：B=`comp_burnable`，E=`comp_edible`，D=`comp_drinkable`，R=`comp_rottable`，U=`comp_durable`，X=`comp_deflagrant`，S=卷十五登记的超自然组件类。
5. **新增三项**：`decomposePoint`（受热不熔而分解、炭化、升华的温度）；`malleability`（延展性：常温固体在锤击下塑性变形而不裂的程度，0–100；液体、生物组织写"—"，即不适用）；`substance` 分两栏："现词表"是第六版封闭十项里能填的值（填不进就是"—"），"预期"是按物质本身该填的值，其中 `subst_water`（水）、`subst_animal_product`（动物产物：乳、蛋、蜜、血、蜡）是 N2-2甲 已裁定要加的两项（代号暂拟），"缺项:…"表示连这两项加上也没有合适词条。
6. **"预期"三栏**：预期物态、预期派生大类、预期类别都是按真实物性与卷三自己写明的大类含义判的"应得结果"，不是按规则算出来的。预期类别 = 预期物态类 + 预期本源成分的类别 + 预期派生大类的类别（代号对照见第三节）。
7. **预期锻料、预期燃料、预期盐类**：分别对应 `req_basic_forging` 的锻料项（L1012）、物品类别 `class_fuel`、`class_salt`（L750、L751），按"只由这一种材料做成的物品"判。这三条规则的阈值卷三只有键、没有值，脚本用第三节的示意值算，结果单独计数，不计入"推错"。
8. **未覆盖**：物品层只读功能维度或形态的派生规则（`class_formed`、`class_powder`、`class_incense`、`class_vessel`、`categoryRules`、`sourceRules`、`transportRules`、`materialClassMin`）需要物品行才能举例，不在材料全集范围内（**偏离指令"每一条派生规则"之处**）。

### 4.3 顺带发现（不计入推错）

1. 卷三例 5 只给了 5 个本源成分和 5 个派生大类的类别代号，岩石、玻璃质、骨角、肉、谷物"各由其条目给出"，代号没写；本全集按同名规律暂拟。
2. `reactionProducts` 是"一个反应对一个产物"，陶土烧成炻器之后就不能再烧出砖，只能另立黏土一行。实际同一种土烧陶、烧砖都常见，以后会碰到。
3. 蛋作为材料是蛋液，常温为液；一只整蛋（蛋壳加蛋液）按"份额最大那一份"判物态也是液体，于是要求装在容器里才能拿。这是物品层的物态判法问题，可以让结构组（外壳）为固的物品按壳判，是规则层能改的，不算装不下。
4. 蜜放久了会结晶成固体，同一种蜜、同样温度，物态取决于经历过什么。它和冰同属一类问题（见第五节），本全集按常见的液态蜜记，没有计入装不下。

## 五、体系装不下的材料

**冰（1 种）。**

1. 冰和水是同一种物质，规则能读的一切物性（熔点 0、沸点 100、含水率、组件类）完全相同；两者的不同只在密度与承力各项，而这些恰是"结了冰"的结果，拿它们当输入就是循环。卷二十也已写明冰与液是同一材料的两种用途之间的转移。
2. 归类体系规定：材料与物品模板的物态类只按一个全局常温（`refTemp` = 20 ℃）在加载时求一次（M-9、T-2），类别是静态的。于是冰只能推成液体；冰块这件物品模板常温不为固，按 I-8 写 `bulkForm` 即报错，得不到 `class_formed`，冰窖藏冰、冰砖、北地冰屋都表达不了。
3. 什么改法都推不对：改阈值、加条件、补维度，都只是同一组物性的函数，而水和冰的物性相同、应得不同；把常温改成当地气温，则类别不再是加载期静态派生的量，那是改体系，不是改规则。
4. 同族风险（本全集未计数）：结晶蜜与液态蜜、北地与南方的椰子油这一类"同料同温而物态取决于经历或所在地"的东西，都会落到同一个缺口上。

按裁定，体系装不下即停报：建议按收尾待办所写，把卷三拆为"材料本源与归类""物品、容器与替代池"两卷，在前一卷里把"物态"从静态类别中拿出来，改为由物温随时求的状态量，类别只保留与温度无关的部分。
